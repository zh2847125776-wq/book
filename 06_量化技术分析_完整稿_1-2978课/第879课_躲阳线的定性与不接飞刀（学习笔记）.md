# 第879课 期货：躲阳线的定性与不接飞刀（20240308）

> 来源：B站UP主「量化技术分析」期货日评视频 20240308
>
> **核心结论：绿K阳线要先定性成"躲阳线"——明知它要向上就先抛、涨完再接回；接不接由价格决定，焦煤已跑到 1743 附近又 SFP 又背离，"卖飞了就别再接，维持现状"，错过不等于做错。**

*转写体例：「交没/交媒」= 焦煤，「罗洛冈」= 螺纹钢，「东空线/东风线」= 多空线，「关后整理」= 横向整理，「下满回错」= 下反回测，「本益心」= 苯乙烯，「木板价」= 目标价，「一二春/一二纯」= 乙二醇，「菜脯/豆腐」= 菜粕/豆粕，「综理油」= 棕榈油，「绿主/绿柱」= MACD 绿柱，「f1g / F1G」= 前一日焦煤段所用的支撑-压力区域（Fib 区间）。*

## 一、焦煤：先把昨天的绿K阳线定性——"躲阳线"不是猜方向

- 定性口径："昨天的绿豆阳线 你得先给它定性 对吧 咱们定的性是什么 你要考虑要止盈了 要卖了 要抛了？不是 咱们定的性是躲阳线 什么叫躲阳线 就是明明知道它要向上波动 你应该先把它抛掉 等它向上波动以后再把它接回来 相当于做一个小范围的波段"。
- 取证方式（把一天摊开看）："我们来看看把昨天的五分钟周期的所有K线都标出来 今天是3月8号 那就是3月7号的所有K线 这是3月6号的夜盘了 我给你标一下 带着你思考思考这个问题 你不要把你的头寸买飞了 然后是3月7号的下午收盘 这就是焦煤的五分钟周期的这么一个波动 确实波动不大 但是有的绿豆阳线是很大 你不躲就给你造成很大的损失"。
- 更早的平仓信号与 5K 校验："从3月7号 其实3月7号之前我们就谈论过 你要考虑把它平掉 其实这个K线就该平掉了 最后 这已经是最后了 前面有更早的信号 你比如说SFP 但是结构小了一点点 小小的三毫位 但是K线数不够 我们要5个 它只有3个 都是信号"。
- 兑现率的诚实交代："多空线站上去平掉了以后 和打漏多空线接回的订单的价格竟然差不了太多 所以说有的时候（躲不一定划算） 当然不能用焦煤多段交易不太成功来界定所有的红豆绿豆都不用躲 但是我就可以告诉你这个意思 你得寻机再接回来才行"。
- 当下条件（不接）："小周期现在焦煤的状态它是一个空头排列 如果它昨天的K线 你要是说实在我没接回来 就今天又涨上去了 那你就别接了 到此时此刻 你就等下回在这个位置附近再考虑去开单了 我也标一下 应该是它最近的三号位附近和多空线附近 应该是1743左右了 你现在就不要再去接了 因为它已经又SFP又背离"。
- 持仓口径："你要是有空单就拿着 5川20的阳线 昨天是5穿20的阳线 要是空单拿着你就继续拿着 50线不占上不平 你要是说昨天卖了给卖飞了 现在没拿着 你就别再接了 此时此刻已经不适合再接回了 你就维持现状 你现在是什么样就还是什么样"。

【老师点评/批判】前提：躲阳线是一次"先卖后买"的完整波段，必须自带接回计划；只有抛没有接，就是卖飞。反例：3/7 那次平空与打漏接回的价格"差不了太多"，说明小级别躲阳线的毛利被执行摩擦吃掉——但老师明确不许用这一次失败推翻整条规则（"不能用焦煤多段交易不太成功来界定所有的红豆绿豆都不用躲"）。批判：小结构信号（SFP 三毫位）因"K线数不够 我们要5个 它只有3个"被降为"是信号但不够"，5K 法则在这里被当成信号资格门槛而非预测工具。纪律：涨过头（已到 1743 附近 + SFP + 背离）就放弃接回，"维持现状"是标准答案，不是妥协。

## 二、螺纹钢 / 铁矿 / 原油：铁矿"此时此刻不要开设任何新的订单"

- 螺纹："罗洛冈不用说 是吧 50线压得一直很死"。
- 铁矿："铁矿石就比罗洛冈略差一点 罗洛冈肯定是不用管的 一直在跟那跌 铁矿石的话我们看近期就没有特别好的交易点 你要是说从前面SFP看 这个交易点不好 这个阳线占上去的话 你在这个阳线收盘价附近开单 这个止损绝对是太高了 你要说是占上多空线开单的话 逆势交易的话 你就又损掉了 是不是 所以说铁矿石着实不太好做 比罗洛冈是差一点"。
- 结论式禁令："如果你要是此时此刻没有铁矿石 我建议铁矿石现在此时此刻不要开设任何新的订单 做多逆势交易不行 做空 做空你现在负乖率率大 是吧"。
- 系列内部差异："虽然铁矿石是一个系列里头的一个生产链上的东西 但是有的确实合适做 有的不合适"；原油"不用说"。

【老师点评/批判】前提：一个品种可以同时"多头不成立 + 空头不成立"，此时的正确动作是不开新单，而不是从其他品种搬逻辑过来。反例：铁矿 SFP 的止损位摆在阳线收盘价附近"绝对太高"，换成站上多空线开多又属逆势——两个进场法各自死于止损与方向。批判：老师特意拆掉"黑色系联动"的偷懒推理（"生产链上的东西 有的合适 有的不合适"），焦煤、螺纹能做不代表铁矿能做。纪律：负乖离率大即禁止追空，与前两日螺纹"追空的不好"同一口径。

## 三、燃油 / PTA / PVC：持有老单，新单全部"已经错过了"

- 燃油："燃油这部横盘突破以后 我们昨天是在五分钟周期看到一个订单 但是这目前就没有太好的买点了 燃油之前有一个 这里有个红豆好三家 一天两天三天 是吧 二十穿有时当天不适合买 这就是三个多头订单的机会 如果你要拿的话 今天还是多单继续持有 忽略波动 守住五十线就行 不适合开新订单"。
- PTA："PTA我们是空单 我们在昨天还详细讲解了PTA这个空单如何用60MA在分时、在五分钟周期去卡这个价格去开单 那今天PTA继续下跌 那就空单继续持有了 这就不用管了 你要是没有想开新单就不是特别合适了 已经错过了"。
- PVC（持仓与加仓的完整叙述）："PVC我们的订单是SFP的空单 当天就开开了以后破五十线 下满回错（下反回测） 然后继续跌到今天 那今天有同学发了问题说 这PVC用不用止盈啊 咱目标价多少 57515没到呢（应指第877课给的前低 5752 一带） 是吧 你看五分钟止跌了 也没有五分钟关后整理"。
- 加仓点的双保险："我们昨天还谈到了 说是最高高点你没做啊 你就等破东空线走 东空线破了没有呢 你看这波破了吗 下满回错不过 你又到了加仓点 或者说之前你没做 你下回补偿的位置了 包括后面还有一次再测向下 这个机会不知道有还是没有 有的话又一个加仓点 所以说这个PVC你应该现在是持状态"。

【老师点评/批判】前提：目标价未到就不因"5 分钟止跌"改规则；持有与加仓的合法性来自同一根线（多空线 / 前高）被怎样处理，而不是来自情绪。反例：好三家出现当天 20 穿有时，"当天不适合买"——形态成立但节奏不给，三次多头机会都是等出来的。批判：学生问"用不用止盈、目标价多少"其实是在索取规则豁免，老师用"5752 没到"一句话挡回，并顺势复述两种加仓路径，把提问转成复习。纪律：破位与"下反回测不过"是两个不同事件，只有后者构成加仓。

## 四、苯乙烯 / 聚丙烯：不解释"为什么它跟那涨"，只做独立分析

- 苯乙烯："本益心不好做 你看他这几个伙计都在这跌 就他跟那涨啊 你不不需要去探讨这个为什么本益心（涨） 你就说工商银行跟那跌 建设银行跟那涨 为什么呀 那到时候他们肯定会变得归一 是不是啊 那现在你此时此刻开单的话 那就是多单多单多单 你就当对冲了呗 不是你只能这样去思考 但是呢 你就独立分析吧 独立分析的角度来看的话 那他就是做多 你就不能放空他 是吧 别放空就行 新单不好看"。
- 聚丙烯（转写作"基本上"）："前两天的三家也可以做 基本上我们给的也是SFP的空单 空单盈利回测 那这个没法加了 今天还是持续盈利中 现在还是自开单以来的最低价 也是盈利的 不用考虑 继续持有"。

【老师点评/批判】前提：品种间断裂的相对走势不需要理由，"肯定会归一"是长期命题，不能当作今天的进场依据。反例：把苯乙烯的多单"当对冲了"看似合理，但老师说"你只能这样去思考"——一旦以对冲为理由开仓，止损与目标就都失去纪律锚点。批判：改用"独立分析"接管决策，结论只有一句可执行——它就是做多，"别放空就行"，连"新单不好看"都不给抢反弹留门。纪律：连续盈利中且仍是开单以来最低价，即不满足任何平仓条件，继续持有。

## 五、纯碱：60 没碰着就收阴线，"刚一损就到目标价，你就损错了"

- 未到的进场价："纯碱我们要放空 放空贴近多空线放空 但是今天就出阴线了 有同学就忍不住了 这60也没碰着啊 60也没碰着就收阴线了 我要不做空是不是就错过了呀 我觉得大可不必 我们等一等吧 好不好 咱们给的这个开单的价格它还没到呢 你看看 是吧"。
- 抢做的后果被算给学生看："你要现在开单 你到这儿 你刚一损就到目标价了 刚一损就到目标价 又掉下来 你就损错了 等一等吧 好不好 不着急"。
- 下一段预期："50线还没漏 它还能往上再爬一爬 爬上去我们再放空单 应该是1992左右 不着急"。
- 玻璃："玻璃还好 就50线收盘站上 这不这几天一直都没收盘站上吗 你就不用管 继续持有"。

【老师点评/批判】前提：进场价由均线前瞻位置给出（1992 左右，承接上一课"用后天数值画水平线"的方法），未到价即无交易，出阴线不改变条件。反例：抢在 60 未到就做空，结果"刚一损就到目标价"——一笔在正确方向上的交易死于错误位置，属于纯粹的自伤。批判：老师的反驳对象是"错过焦虑"本身（"大可不必"），而不是学生的方向判断；"还能往上再爬一爬"承认还会涨，把不进场变成主动选择。纪律：玻璃用"这几天一直没收盘站上 50 线"作为持有依据，收盘才算数。

## 六、甲醇 / 乙二醇：为更高的胜率"放一放"，顶背离概率高时多单成问题

- 甲醇："甲醇是绿豆坏三甲 现在确实光看日线图 确实又贴近买进信号了 然后时间也差不多了 但是还是60分钟周期不行 是吧 你看它这个关后整理做的非常隐蔽 偶尔会上几下掉下来 上几下掉下来 但是它还是不改此时此刻还在东风线下面这个特征 对吧 就是这个胜率就变低了 你要是看日线图做的话胜率变低 而且前两天漏过一次 是吧 所以说我建议这个甲醇咱先放一放吧 为了更高的胜率 咱们放一放 别着急"。
- 乙二醇的旧条件："一二春我们之前说的是什么呢 下次再做空就是等东风线漏掉了 是吧 东风线漏掉 目前看现在此时此刻开新单就不太合适"。
- 多头排列下的三个反对理由：
  1. "直观一看就是多头排列 所有均线所有价格都在60MA上 现在我找价格进场以后 攻破四天前的低点 攻破60MA 是损 但是实际上这个伙计经历过一段时间上涨之后 已经出着绿柱创新高 顶背离的概率非常高 这个多单就成问题"；
  2. "另外这个20MA对他来讲也是向下有斜率 斜率还很大"；
  3. "你再看60分钟周期 它确实在往上跑 但是规律性也特别明显 之前都没规律 都是在粘合区 可是最近慢慢产生规律了"。
- 双向预案："我认为此时此刻开多单是不合适的 如果有机会 说是这么高的向上幅 我们调一调吧 把多空线打漏了 有机会咱们就开个空单 但是不给这个机会 不漏 或者说过两天这金叉插上去了 确实往上走了 那都到前高再去放空单"。
- 做多的成立条件："你要是做多的话现在条件不满足 想做多怎么做呢 20转过来 60转过来 变成这样 在这个附近考虑去做多单 还有点早 是不是啊 再等两天 这个不用着急"。

【老师点评/批判】前提：进场信号"贴近"不等于"到达"，加上 60 分钟仍在多空线下方，胜率就被折价；"为了更高的胜率放一放"是全课最可复用的弃权理由。反例：甲醇前两天已经"漏过一次"，同样的日线贴近信号有过失败记录，不能当作首次出现。批判：乙二醇段落最见方法——即使均线全多头排列（最像要涨），也用"绿柱创新高 = 顶背离概率高"去否决多单，方向共识与交易资格是两件事；60 分钟"最近慢慢产生规律"被当成新风险而非新机会。纪律：多空各写各的触发条件（打漏多空线开空 / 20、60 转过来才考虑做多），任何一侧都不许用感觉提前进场。

## 七、菜粕 / 豆粕 / 白糖 / 玉米 / 橡胶：条件齐了才动，否则"让它横着"

- 菜粕豆粕："菜脯继续涨 你要是做了 菜脯豆腐要是做了 就守住50线 目标就是60M 这个没啥可说的 这个豆腐都突破了 就说好60M 别漏 漏了就快去把它平掉 是不是啊"。
- 白糖："白糖我们说贴近60 20放空单呢 就是前天漏 但是它这个单子现在不好做 60分钟之后现在再粘合 所以说我们也没有给大家提供更好的切入 那就别管 让它再走一走"。
- 玉米："玉米也不好做 玉米等它这次调完我们再做多吧 它已经翻过来 等它60转过来 20是这样的时候 然后价格测一下这儿或者测一下这儿的时候 咱们再做 现在让它横着吧"。
- 橡胶（现场直播式记录）："橡胶昨天贴近60 但是20在60下面 我们看60分钟有没有发展出好机会 也没有 此时此刻在拉 现在没法下单 咱们一边说话在一边就跟着拉 绿豆戳破了 我们看看如果它要是一会儿尾盘 现在是1点59 那正好下个小时拉回来 下个小时拉回来靠近13880附近 想试试可以试试 你现在在这个位置上去做多没啥太大意思 是吧 那拉回来 太高了"。

【老师点评/批判】前提：持有条件可以简化成一条线（50 线不漏、60M 别漏），但进场必须等粘合解除，均线粘合本身是"没有切入"的合法解释。反例：橡胶在讲话间被拉上去、"绿豆戳破了"，追进去等于在最高位做多——老师宁可给"1 点 59 分、下个小时拉回 13880 附近再想试试"的时间与价格窗口。批判：白糖与玉米都用"再等/再走"回应，说明同一天里多个品种同时不给机会是常态，不是自己漏看了信号。纪律：豆粕突破 60M 后规则反转为"别漏，漏了就快去平掉"，进场条件与持有条件分开写。

## 八、豆油 / 棕榈油 / 纸浆 / 棉花 / 生猪：Fib 区间 16182–16299 卡住不动

- 豆油："豆油这个不考虑 这是我做ELG用的"；棕榈油："综理油还是守住50线 这个不用管"。
- 纸浆："纸浆也没法做"。
- 棉花："棉花15929 起来了 起来了 起来了 是绿豆坏三家 再等一等 这里还有个f1g呢 看什么样 f1g下线是16182 上线是16299 它正好卡在这里头 先随它去"。
- 收尾："升幅（疑为生猪）还在涨 没了 我们来看看大家的具体问题"。

【老师点评/批判】前提：坏三加之后不急于否定，而是看它是否落在 Fib 区间内部——"正好卡在这里头 先随它去"，区间内不作方向判断。反例：棉花 15929 起来了却仍是绿豆坏三家，价格与形态打架时以形态定性、以区间等待。批判：老师两次说明某些图是"我做 ELG/数据用的"（豆油），把示范用单与可交易单分开，防止学生跟着做教学样本。纪律：棕榈油"守住 50 线不用管"、纸浆"没法做"，一句话裁决一个品种，避免逐个纠结。

## 与已有课程的关系

- **与前一课（第878课"接回价提前算与未来预演"）衔接**：878 给出"每小时降一个点 → 1757 接回点"的前瞻算法，本课把同一条线用成否决器——焦煤现在已到 1743 附近（三号位 + 多空线），"你现在就不要再去接了"，接回价一旦超过就作废，两课合起来构成"接回价既要算出来、也要会过期"。
- **"躲阳线"三条线的收束**：875 的"贴多空线才是开单位"→876 的"杠杆 × 幅宽决定能不能用上限止损"→877 的"12 次里 10 次收阳所以要躲"→本课给出完整定义（先抛、涨完再接）与失败样本（平空价与接回价"差不了太多"），并把 5K 法则作为信号资格（"我们要5个 它只有3个"）写进同一套逻辑。
- **纯碱主线第六日**：878 用"日线 M60 的后天数值 1985"画水平线，本课直接推进到"爬上去再放空 应该是 1992 左右"，并以"刚一损就到目标价 你就损错了"回答学生"60 没碰着就收阴线是不是错过"，同一套均线前瞻法在两天内完成从算价到用价。
- **PVC / 燃油 / 苯乙烯的持仓侧续集**：877 的 PVC 5893 止盈线与目标价 5752（本课转作"57515没到"）在本课变成"目标价没到 → 继续持有 + 下反回测不过才是加仓点"；877 燃油 3156 测三次的多单在本课转为"忽略波动、守住 50 线、不开新单"；876 苯乙烯"上升弹性最佳但要斟酌"到本课固化为"独立分析：它就是做多，别放空就行"。
- **甲醇坏三家 / 乙二醇 / 白糖 / 棉花四条旧线索的最终状态**：甲醇自 875（要件一个都不符合）→877（60 分钟没转过来）→878（纯是坏三家）→本课"为更高的胜率放一放"；乙二醇自 876 的 4568、877 的 4567 回测漏第二次、878 的"得破多空线才能继续跌"→本课因"绿柱创新高 + 20MA 斜率向下"否决多单、改写成双向预案；白糖自 875 的 6289 与站上 50 线平空、876 已站上两日、877 未理会、878"可以考虑放空 + 创新低加空"→本课因"60 分钟再粘合"暂不切入；棉花自 875 的 15928 关键价、876"两日到支撑但多单没走好"、877"20–60 之间不好开单"、878"15929 附近开多很难"→本课"起来了但还是绿豆坏三家"，并新增 Fib 区间 16182–16299 作为等待容器。
- **方法母课对照**：本课最高频的三个工具——5K 法则（信号资格）、坏三加（三周期要件否决）、Fib/FPR 区间（等待容器）——可与基础课 5K 形态、3+ 形态、箱体与背离各章互查；"顶背离概率高时不接多"与"躲阳线"是同一纪律的两种方向表达。
