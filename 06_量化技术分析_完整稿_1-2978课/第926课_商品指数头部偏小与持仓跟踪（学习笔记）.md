# 第926课 期货：商品指数头部偏小与持仓跟踪（20240531）

> 来源：B站UP主「量化技术分析」期货日评视频20240531
> **核心结论：商品指数如预期掉下来了，但"头部结构太小"（涉及K线太少、波动太小、颈线与最高价差值太小），所以对这波空头能否带来超额收益"抱有怀疑"，先等它破一个再说；持仓层面则是"该平的分级平、不该平的继续拿"，并给纯碱、棉花定出明确的平仓线。**

## 一、商品指数：头部结构太小，对空头力度抱有怀疑

老师说：「（5月）31号1点25分，这个商品指数掉下来了，是吧，跟咱们想的是一模一样的。什么时候它就正式开跌呢？还是这个点，这个点是206，漏了的话正式开跌。这个头部结构太小，我就怕它跌不动，这个头部结构涉及的K线太少，形态结构波动太小，然后呢，这个颈线和最高价差值太小，所以说这个空头力度，我抱有怀疑。」

进一步：「而且呢，这个头部结构涉及的K线的时间，包括它的幅度，和整体的上涨、单边行情的趋势相比又显小，是吧，绝对值又小，是比值又小，所以说这个，这波空头行情能不能带来大的、超额的、出乎意料的收益不好说，我们先等它破一个再说吧。」

结构判断：指数已按预判回落，但头部形态的量级不足；关键点是206，漏了才"正式开跌"。

订单操作：「先等它破一个再说」——不预设大跌，先看关键点是否被击穿。

【老师点评/批判】
- 前提：头部结构的K线数量、波动幅度、颈线与最高价差值，三者与前期上涨单边行情的比值，决定了空头能走多远；"绝对值又小、比值又小"是怀疑的根据。
- 反例：指数掉下来≠可以重仓做空；老师明确说"跌不动"是他担心的事，即形态太小会导致空头无力。
- 盈亏比：指数层面的超额收益不确定，因此单品种按各自结构处理，不因指数下跌就放大仓位。

## 二、黄金：没有平仓信号，继续持有

老师说：「黄金的话，这个应该是继续持有吧，没有出现任何的平仓（信）号。我们昨天说要小心这个旗形整理失败，那也是创新低的事，它也没有创，那就接着拿着就完事。」

结构判断：昨天担心的"旗形整理失败"需要以"创新低"来确认，未创新低则失败逻辑不成立。

订单操作：持有空单不动。

止损/止盈：无新信号则不平仓；失败信号＝创新低。

【老师点评/批判】
- 前提：昨天对旗形整理失败的警惕是有条件的——必须"创新低"才算失败（对空单而言是反向破坏）。
- 反例：若把"担心"直接当成"平仓理由"，就会在无信号时被洗出；老师说"它也没有创，那就接着拿着就完事"。
- 盈亏比：无信号持有＝让已有盈利继续奔跑，代价是承受一次可能的回撤。

## 三、铜：站上5MA后的分级减仓

老师说：「铜的话呢，也是啊，也跌下来了，是吧。那有疑问就是这个站上5M要不要平？你想平你就平，不要急，这个有盈利嘛，想平也行。（小周期信号指标）没有发出（卖出/平仓）信号，没有发出（平仓）信号，就可以考虑不平，再等一等。」

减仓分级：「包括万一给来个倒压阻，加速下跌三到四个小时，那毕竟它的AC等长没走到，还可以再走一走，包括5M也没有拐出向上，适当的可以，你可以站上5M收盘以后平（掉）一半，5M拐出向上平干净都可以，是吧，就这个还可以再等一等。」

结构判断：AC等长尚未走完、5M未拐出向上，属于"还可以再等"的状态。

订单操作与止盈：站上5M收盘 → 平一半；5M拐出向上 → 平干净。

【老师点评/批判】
- 前提：判断"要不要平"的依据不是价格涨跌本身，而是AC等长是否走完、5M是否拐出向上这两个条件。
- 反例：有盈利就想立刻全平属于"急"，老师说"不要急……想平也行"——主观平仓被允许，但要清楚自己放弃了AC等长的剩余空间。
- 盈亏比：分级减仓（平一半）是"锁定部分利润 + 保留AC等长空间"的折中，比一次性全平或全拿都更可控。

## 四、焦煤：1700漏下来，SFP开空、加仓与"全平"条件

老师说：「焦煤呢，我们昨天说了啊，焦煤之前不好做，反反复复的，昨天还稍微凑合一点。我们最初计划是来到多空线附近，再做向下放空单，但是也说了，如果攻破区间下线也可以放空单，是吧，破了下线还有下反回撤，都可以做空。目前是略微盈利状态。」

风险提示：「但如果这个单子你要是做了的话，下返回来的话，你还是要还得把它平掉，因为从这个位置跑到这个多空线附近，这个位置的话，你要亏的啊。」

订单细节：「看这个价格能不能行，1700啊，就是这个位置，刚刚也漏下来了，是不是，我们给到的一个SFP结构啊，SFP信号K下单的信号K，那这个K线下空单。然后当时说到这里止盈，是不是啊，到这里止盈，止盈了以后，你要等一等啊，如果它到达以后没有出现异色K线，你可以等等让它破一下，破了没破了，破了以后还有下返回撤，所以说这个K线和这个K线，反正应该加仓，对吧，加仓完了以后你就等着呗。那如果这个价格翻到这个结构上去的话，把加仓部分和底仓部分一块全平干净，就完事了，搂着干。」

结构判断：1700为区间下线，刚漏下来即SFP信号K。

订单操作：SFP信号K开空 → 止盈后若无异色K线则等破位 → 破位后加仓 → 价格翻回结构上沿则"加仓部分和底仓部分一块全平干净"。

止损/止盈：止盈到目标位；下返回撤时若跑到多空线附近会亏，需平掉。

【老师点评/批判】
- 前提：入场有两条路——到多空线附近放空，或攻破区间下线放空；两条路都成立，但都必须等价格到位，不能提前。
- 反例：下返回撤时"从这个位置跑到多空线附近"就是亏损区，此时必须平掉，不能硬扛——这是本课对昨日计划的风险补充。
- 盈亏比：1700开空、目标止盈、破位加仓，属于"分批建仓 + 移动目标"的加仓结构；全平条件明确（翻回结构上沿），避免加仓后回吐。

## 五、铁矿石 / 锰硅

- **铁矿石**：老师说「铁矿石不用管，我们给了一个价格883，但是它的开单方法不如那个（螺纹钢的）搂着干好开，就不管它了，反正是同类品种。」
- **锰硅**：「锰硅的话，这正好到了咱们给的关键价了，但是没掉下来，看着没有。这个价格关键不关键，你就要看后来测试不测试，站上还有回撤，打到这里就停住，是吧，所以这个还可以再稍微等一等啊，但是你要看更小周期的话可以做，是吧，我们昨天也讲了，这里就不赘述了啊，小周期自己合计。」

【老师点评/批判】
- 前提：铁矿石被排除的理由是"开单方法不如搂着干好开"——同类品种里只做执行最顺的那一个。
- 反例：锰硅"到了关键价但没掉下来"，说明关键价必须经过"后来测试"才成立；到价不等于可以做。
- 盈亏比：锰硅在关键价停住，若在更小周期做则盈亏比与止损幅度都要重新算，"小周期自己合计"。

## 六、欧线集运 / 原油 / PTA / PVC

- **欧线集运**：老师说「这个也是盈利的，是不是，我们是在这里SFP开的空单，它（当下）K线就能开异色K线的订单。但是我们当时就说了，到这个地方能漏不能漏，当然有的品种已经漏了，就是我们之前开做的这个类似的高位SFP订单，已经漏掉了，包括那个纯碱，但这个欧线集运还没漏呢，你得再等一等。反正就是要么就是到上头就白干，要么就是大跌，你自己合计合计，这个应该继续持有。那个鸡蛋拿了15天才跌的，是吧。」
- **原油**：「原油没有给到太好的机会，原油这个甚至连箱顶都没碰着，这个放不掉空。你可以把原油当指数看，做原油的系列产品就行了。」
- **PTA / PVC**：「PTA没法做，咱不做这个。PVC没法做，空单没法做。」

【老师点评/批判】
- 前提：高位SFP空单的价值在于"能不能漏"，漏了才有大跌，没漏就"到上头就白干"——这是持有还是离场的唯一分界。
- 反例：原油"连箱顶都没碰着"，不构成放空条件；把原油当指数看、去做系列产品，是替代方案而非硬做。
- 盈亏比：欧线集运已盈利且未触发止损，属于"持有等漏"的高盈亏比单；PTA/PVC 直接排除，不做没有结构的品种。

## 七、纯碱：黄线定生死，站回去就平

老师说：「纯碱掉下来了，是不是，纯碱我们做的是，纯碱的话是这里做过一单SFP开的空单止盈，这里又下的空单，然后到这个地方止盈，那这又向下突破，那向下突破一瞬间，你还得开。这个黄线始终是不变的，你不要根据这里去定，根据这个黄线，是不是。」

关键纪律：「这个现在是盈利，但是这里有个小问题，我认为，这个黄线站回去，你还是要把它平掉的，因为它还有一次侧向下的可能性，你等到侧向下的位置再把它接回来，更好一点，自己合计。纯碱是盈利的，这个我们就不说了。」

结构判断：向下突破已完成，黄线是固定的判断基准（"你不要根据这里去定，根据这个黄线"）。

订单操作：向下突破一瞬间继续开空；黄线站回 → 平掉；等"侧向下"的位置再接回来。

【老师点评/批判】
- 前提：判断依据必须固定在同一条黄线上，不能随形态位置临时改标准——"这个黄线始终是不变的"。
- 反例：若黄线被站回还继续拿，就会面对"还有一次侧向下"的回撤；老师给出的对策是平掉后"等侧向下的位置再接回来"。
- 盈亏比：平掉再接回＝用一次小的重复入场换取更低的空单成本，避免在回撤段被动扛单。

## 八、玻璃 / 甲醇 / 乙二醇

- **玻璃**：「玻璃有多单，平干净了。」
- **甲醇**：老师说「昨天创高，今天其实还好。想做波段，就我们讲中国平安的例子，怎么说，上行通道突破，涨不多，马上掉回来了，但是已经掉回来了，是不是。你要是想做波段，觉得下跌不好、不舒服，你在5分钟周期做的波段，对不对，你比如说，这不是通道吗，你有多单，把通道向下线漏掉，你把多单平了，是吧。你看人家这AC等长做得也挺好，对不对，包括（小周期信号指标），是不是，逃顶、抄底，都可以做一做，小周期我就不讲了，你自己合计。」
- **乙二醇**：「乙二醇的情况，还是受制于前期OB区域，这个还是可以考虑，但是这个要是放空的话，就和甲醇就逆反了，不好说，等一等。这个放空也不太合适，现在没有交易机会，等一等。」

【老师点评/批判】
- 前提：甲醇"上行通道突破涨不多"是其固有特征（中国平安旧例），因此波段只能在5分钟周期做，多单平仓条件＝通道向下线被漏。
- 反例：在甲醇放空与乙二醇放空是"逆反"的（方向相反），老师因此选择"等一等"——同类化工品种方向冲突时不硬做。
- 盈亏比：玻璃多单直接平干净＝不参与；甲醇靠小周期逃顶抄底增厚收益；乙二醇"现在没有交易机会"，不交易即最佳选择。

## 九、豆粕：SFP平空后，用"平仓价"把空单捡回来

老师说：「豆粕我们之前给到的是空单和多单指引，是吧，你回想回想在这个地方，然后说是这个地方漏了才能跌得快一点，这漏了以后跌的果然就是快，两个大的阴线。昨天提到的问题是出现SFP，要不要把单子平了？你要是有空单的话，看到SFP、看到一色K线，把空单一平……到现在为止，应该行，因为现在的价格比咱们平仓价格高，是不是，但他就是不往上涨，所以说也让你别做多。」

接回条件：「那有机会，那是你平仓的价格漏掉的话，你赶紧把空单捡回来就行，这个可以再等一等，不着急。」

结构判断：破位后"跌得果然就是快"（两根大阴线），昨日SFP平空的决定被验证为正确（现价比平仓价高，且不涨）。

订单操作：以昨日平仓价为参照——该价格被漏掉就"赶紧把空单捡回来"。

【老师点评/批判】
- 前提：SFP + 一色K线出现时空单先平，是既定纪律；平完之后"不往上涨"说明并非趋势反转，因此不能反手做多。
- 反例：若价格真涨上去，平仓就是正确决策；反之若把"平仓"理解成"转多"，就是误读——老师明确"也让你别做多"。
- 盈亏比：用平仓价作为接回的触发价，等于用同一结构做第二次入场，成本更低、止损更近。

## 十、白糖：又一个来回，区间交易的舒适区

老师说：「白糖跌下来了，你看我们的指引多合适呀，是不是，那这又是一次SFP，对吧，你抄底做多，你得到这得赶紧（止盈），他突不破的，你现在回看这个点也是准的，是不是，而且这个地方把多单一平，后面就下跌。你要是开了空单，从未触发止损，那打到现在又要到（止盈）位置了，要是有空单，是不是。那下次要是你要是没做空单的话，那到这个地方又要做多单了，这都几个来回了，一个来回，这是一对来回，这两个来回了，已经最近都是这样的行情，包括纯碱，是吧，应该做得挺舒适啊。看看下线的位置，然后60分钟我还没站上，就直接半路平了也行啊。」

结构判断：SFP 结构反复出现，区间两边来回做——"一个来回、两个来回"。

订单操作：SFP 抄底做多 → 到上沿赶紧止盈；若开空单则"从未触发止损"，到止盈位止盈；下一次到区间下沿再做多。

止损/止盈：60分钟还没站上就直接半路平了也行。

【老师点评/批判】
- 前提：区间交易之所以舒适，是因为SFP结构反复给出信号，且"他突不破的"——上沿压力有效。
- 反例：若把区间当趋势，多单不止盈就会回吐；老师强调"把多单一平，后面就下跌"，即止盈必须及时。
- 盈亏比：单笔空间有限，但"几个来回"累积胜率高；适合用"半路平仓"控制回撤。

## 十一、玉米 / 橡胶 / 棕榈

- **玉米**：「玉米不做，不考虑。」
- **橡胶**：老师说「橡胶的话，其实又变成砍头K线了，这不太好分析，只能是五分钟，你自己做做呗，那只能是五分钟周期了，你带大周期看不出来，是不是啊，只能是回避这一点下跌，上面这点你都得硬挺着不好，不好提前去预判，要不然之前也就卖飞了。要是到现在还没平的话，收好50线吧，那没有更好的办法了，对吧。」
- **棕榈**：老师说「棕榈（原话转写含混）咱不做啊，这个失败都有，还继续持有就行。」（此处转写不清晰，大意是棕榈仍不参与，已有单子按原计划继续持有。）

【老师点评/批判】
- 前提：橡胶出现"砍头K线"后结构失去可分析性，只能退到5分钟周期做，大周期"看不出来"。
- 反例：大周期硬挺"上面这点你都得硬挺着不好"——即不做预判，否则"之前也就卖飞了"；没平的单子只能"收好50线"作为最后防线。
- 盈亏比：结构不明时缩小周期＝缩小止损与目标；玉米、棕榈直接不参与，保住了资金效率。

## 十二、纸浆：持有空单，破60可考虑加仓

老师说：「纸浆的话，纸浆我们是给空单了，是吧啊，这空单这回是向下，确实收盘突破，正在下反回走，有空单继续持有就行，把60攻破还能考虑加仓啊。」

结构判断：收盘向下突破，正在下反回走。

订单操作与加仓：空单继续持有；把60（均线/60位置）攻破还能考虑加仓。

【老师点评/批判】
- 前提：加仓的前提是"把60攻破"，即突破有效性再确认，而不是已有浮盈就加。
- 反例：下反回走过程中若把回抽当成反转，容易提前平仓错失下跌段。
- 盈亏比：持有 + 条件加仓，是趋势单的标准处理；加仓条件明确，避免越涨越加或越跌乱加。

## 十三、棉花：目标到位后的三级止盈与"反手"预案

老师说：「棉花跌下来了，棉花我们给的空单，SFP下单，止损0.57都写了，是不是啊，我们说0.57还可以几倍杠杆，五倍杠杆都来得及，5525、5735、2.8，三个点不到的亏损，完全可以接受五倍杠杆，是不是啊，从未触发止损啊，跌到现在。」

目标与止盈分级：「那现在我们给的目标价是哪里，你看看，要不就是前低，要不就混沌区间，你看今天盘中最低点，这不这不是到了吗，到了以后，这不是异色K线都来了吗，是吧。有同学说这平不平啊，你自己合计啊，你要是觉得胆小，我就怕回撤，那现在你已经该平了……他就该收阳线了，收阳线就可以平了他，当然，有同学说我等站上五（日）五小时均线，那我再平了他，也可以随你，还有一位兄弟说，哎，反正也在这个混沌区，我脱离混沌区也行，那就多亏点，是吧，都可以随你啊。但是呢，你要记住啊，这混沌区要是漏了的话，你还得把你的空单接回来，终极目标、理想目标价是前低附近的，你别把单子给卖飞了，好不好。我建议中庸一点啊，你现在立刻见着阳线就平了偏左，等到脱离混沌区再平了偏右，看好完美。」

结构判断：SFP空单，目标＝前低或混沌区间；盘中最低点已到，异色K线已现。

止损：0.57（原话"止损0.57都写了"），对应"5525、5735、2.8，三个点不到的亏损，完全可以接受五倍杠杆"，从未触发止损。

反手预案：「棉花也挺舒服的做的啊，一个，我们说该破了，果然它立刻就破了，是不是，时间卡的也挺准啊。这个棉花呀，要是到了前低啊，咱这还能可以考虑抄底呢，为什么呢，因为这棉花呀，它这个低点，它还不是个独立低点……跟这个白糖一模一样，看到没有，白糖也是一二三三个点，只不过它们离得更密集一点，然后左面，你把这些看成一个点就行了，这远端还有一个点，是不是啊，这些点越多吧，它就越可靠，到时候咱们还要做个反手了啊，做不做自己合计啊，明天收个十字星，后天一个打印线做下来，多好，是不是，正好是咱们的标准空头推进结构了。」

【老师点评/批判】
- 前提：止盈可以偏左（见阳线就平）、可以偏右（脱离混沌区再平），但两者都以"混沌区不破就接回空单"为前提——目标是前低，不能卖飞。
- 反例：仓位不同选择不同，"胆小怕回撤现在就平"、"等站上5小时均线再平"、"脱离混沌区再平（多亏点）"三者老师都接受，说明止盈方式要匹配自己的承受度，而不是追求唯一正确答案。
- 盈亏比：0.57止损 + 三个点不到的亏损 vs 前低目标，是本课盈亏比最清晰的一单；且点越多越可靠的多点支撑结构，为"到前低反手做多"提供了依据（标准空头推进结构：十字星 + 打印线）。

## 十五、可复用方法与纪律提炼

1. **头部/形态的"量级"决定行情级别**：涉及K线太少、波动太小、颈线与最高价差值太小 → 空头力度要怀疑，超额收益"不好说"。判断行情级别时，要把形态的绝对值与它和前期单边行情的比值一起看。
2. **关键价位只有被测试才成立**：「这个价格关键不关键，你就要看后来测试不测试」（锰硅）。
3. **同一判断标准必须固定**：纯碱"这个黄线始终是不变的，你不要根据这里去定"。
4. **有盈利时的减仓要分级**：铜——站上5M收盘平一半，5M拐出向上平干净；无信号则不平。
5. **止盈允许"偏左/偏右"**：棉花——见阳线就平偏左，脱离混沌区再平偏右，但都要记住"混沌区漏了要把空单接回来，终极目标是前低，别把单子卖飞"。
6. **平仓价可以作为再次入场价**：豆粕——SFP平空后，"你平仓的价格漏掉的话，你赶紧把空单捡回来"。
7. **加仓要有独立条件**：焦煤"翻到结构上去就加仓部分和底仓部分一块全平干净"；纸浆"把60攻破还能考虑加仓"。
8. **同类品种只做执行最顺的**：铁矿石"开单方法不如搂着干好开，就不管它了，反正是同类品种"。
9. **方向冲突时不硬做**：乙二醇若放空就与甲醇"逆反"，于是"现在没有交易机会，等一等"。
10. **结构不可分析就缩小周期或退出**：橡胶"砍头K线"→只能5分钟做；玉米、生猪直接不参与。
11. **止盈要防止"卖飞"**：白糖"把多单一平后面就下跌"，说明区间上沿必须止盈；橡胶"不好提前去预判，要不然之前也就卖飞了"。
12. **多点支撑更可靠**：棉花与白糖的低点是"一二三三个点"，"这些点越多吧，它就越可靠"，这是日后反手做多的依据。
