# S-3447 放量收阴后缩量收阳修复与次日阴线预警法

> 来源：SRC-001087（股票_20200623量化技术分析）· 证据 E-91664、E-91665
- 性质：局部方法
- 规则版本：原稿未明确
- 完整度分级：已给方向
- 效果证据：原文未提供回测胜率

## 目的与适用环境
用于在连续放量上涨行情末端，应对高位滞涨及放量阴线后的次日修复判定，并防范量价背离引发的再次回落风险（证据 E-91664、E-91665）。适用于上升通道中高位滞涨十字星后放量收阴的短期震荡修复环境（证据 E-91664）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 指数或标的经历连续多日（如4个交易日）放量上涨，处于高位滞涨或高位十字星状态 | 日线级别 | 证据 E-91664 | 仅限多头连续拉升末期 |
| 形态或指标形成 | 高位出现滞涨十字星后放量收阴线 | 当日收盘 | 证据 E-91664 | 形成短期空头回落结构 |
| 确认 | 次日指数收阳线，对前一日放量收阴进行形态修复，但当日量能出现连续放量以来的首次萎缩（缩量收阳） | 次日收盘 | 证据 E-91664 | 缩量收阳构成了新的量价背离 |
| 入场 | 修复日不作为追多入场点，仅作为已有持仓的观察点 | 次日收阳时 | 证据 E-91664 | 原文未给出新开仓指令 |

| 仓位与资金 | 若仓位不是特别重、能轻易进出，提倡在修复后尽量持币过节避险 | 收阳修复日 | 证据 E-91664 | 未给仓位数学公式 |
| 持仓与跟踪 | 关注缩量萎缩幅度及五日均量（如3076亿），监控量价背离发酵 | 收盘跟踪 | 证据 E-91665 | 观察量能萎缩玄机 |
| 加减仓 | 缩量收阳修复日不盲目加仓，仓位较重者借修复减持 | 收盘前 | 证据 E-91664 | 原稿未给出金字塔加仓规则 |
| 止盈与退出 | 预警在接下来的第1个或第2个交易日内必定有阴线调整，短线多头逢阳线冲高止盈退出 | 修复次日或第三日 | 证据 E-91665 | 原稿明确下个或下下个交易日有阴线 |
| 失效与放弃 | 若缩量收阳后次日再次超预期巨量大阳线突破前高，则量价背离被强行化解，预警失效 | 再次放量暴涨时 | 证据 E-91665 | 原文未提及具体反向化解指标 |

## 规则之间怎样衔接
连续放量上涨 -> 高位放量收阴产生修复需求 -> 次日缩量收阳完成修复 -> 缩量收阳引发新的量价背离 -> 预警后1至2个交易日出现阴线回落 -> 指导仓位减持或持币避险（证据 E-91664、E-91665）。

## 案例和失败方式
上证指数在2020年6月22日放量收阴后，6月23日缩量收阳修复，五日均量达3076亿，讲述者据此预警节前或节后前两天必收阴线（证据 E-91664、E-91665）；失败方式为次日直接高开高走再度放巨量拉出中大阳线。

## 版本分歧与证据限制
底本仅增强稿可见；原稿未给出缩量收阳中“成交量萎缩比例”的具体量化阈值（仅提及连续4天放量后的第1天萎缩）。
