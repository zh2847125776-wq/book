# S-2387 牛市核心龙头大票分时低吸持股法


来源：SRC-000241（妖股成妖之路_19（增强版）# 第280章）· 证据 E-65964, E-65973

性质：规则完整的策略
规则版本：原文未明确（未分版）
完整度分级：已给方向
效果证据：原文作者自述对于大市值核心龙头（如东方财富）通过分时低吸参与比追高打板更具确定性且能充分享受主升收益（E-65964, E-65973）
目的与适用环境

用于在牛市增量行情中，针对大市值容量白马核心股（如东方财富、中信证券等），规避打板排单风险，采取日内分时低吸方式建仓并锁仓持股。适用环境为牛市主升阶段且成交量充沛的大市值龙头标的。

规则之间怎样衔接

选定大市值核心白马 -> 放弃追高打板 -> 寻找分时回调低吸介入 -> 格局锁仓持股 -> 待题材周期高潮见顶后止盈离场。

案例和失败方式
成功应用案例：东方财富与中信证券作为牛市大票，通过分时低吸上车并格局锁仓，成功捕获巨大波段收益（E-65964, E-65966, E-65975）。
失败方式：在牛市大票上机械打板导致排不到单或炸板回撤，或低吸后因恐惧日内微小波动过早卖出。
