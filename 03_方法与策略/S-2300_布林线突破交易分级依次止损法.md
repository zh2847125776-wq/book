# S-2300 布林线突破交易分级依次止损法

> 来源：SRC-000013（P1_第三节课（增强版））· 证据 E-65554、E-65555
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见
- 性质：局部方法
- 规则版本：布林线突破分级止损规则V1.0
- 完整度分级：已给方向
- 效果证据：原文强调“风险最小，止损价不高风险可控”
## 目的与适用环境
适用于买入向上突破布林线上轨股票后的防守风控体系，建立分层止损机制，彻底杜绝深度套牢风险。
## 条件与动作
| 步骤或环节 | 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- | :--- |
| 环境过滤 | 标的股票处于向上突破布林线上轨后的持仓状态 | 日K线持仓阶段 | E-65554 | 仅针对突破上轨标的 |
| 形态或指标形成 | 股价上攻乏力，盘中或收盘回落向下逼近、跌破布林线上轨 | 日内分时或日K线收盘 | E-65555 | 波动幅度受大盘影响 |
| 确认 | 识别出盘中跌破上轨、收盘跌破上轨、或下轨收敛三种演化状态 | 盘中或收盘确认 | E-65555 | 需实时监控轨线数值 |
| 入场 | 本规则为防守退出方法，无买入操作，对应持仓处置 | 无 | 无 | 不包含开仓指令 |
| 初始止损 | 以突破日上轨作为初始防守底线 | 开仓时同步设立 | E-65555 | 轨线价格每日动态变化 |
| 仓位与资金 | 触发止损时果断减仓或清仓，不纠错，回收资金寻找新机会 | 触发执行时点 | E-65555 | 原文未明确分批比例 |
| 持仓与跟踪 | 实时对比盘中即时价格与动态上轨数值 | 交易时间内持续跟踪 | E-65554 | 考验看盘专注度 |
| 加减仓 | 止损过程中坚决禁止补仓摊低成本，严格不纠错 | 破位全程 | E-65555 | 严禁浮亏加仓 |
| 止盈与退出 | 依次止损：①盘中跌破上轨：将上轨看成红线止损，风险最小（易卖飞，但普遍采用止损，不纠错，寻找新机会）；②收盘跌破上轨：是否纠错因人而异；③下轨收敛：作为最后止损红线强制离场 | 盘中/收盘 | E-65555 | 收盘纠错规则因人而异 |
| 失效与放弃 | 若次日跳空直接跌破下轨收敛线，无条件全仓市价清仓退出 | 次日开盘竞价 | E-65555 | 极端跳空存在滑点 |
## 规则之间怎样衔接
盘中破位触发第一道最小风险止损 -> 收盘破位触发第二道确认止损 -> 下轨收敛触发终极防守红线。
## 案例和失败方式
盘中跌破上轨止损可能导致在洗盘时“卖飞”；但能确保规避假突破引发的腰斩与深套。
## 版本分歧与证据限制
原稿指出“收盘跌破上轨是否纠错因人而异”，未给出绝对统一的纠错参数。
