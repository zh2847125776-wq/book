# S-2751 二合一关键支撑小代价试错买入策略

> 来源：SRC-005137（第2408课 股票日评：调整结束第二买点出现加仓勇敢进攻（20240517））· 证据 E-69027、E-69028、E-69029、E-69030、E-69039、E-69040
- 性质：局部方法
- 规则版本：原稿口述版
- 完整度分级：已给方向
- 效果证据：原文说明“即使失败代价也很低但是一旦盈利盈亏比是非常可靠的”、“一里一外亏了9个点千分之三很少是不是所以说这个代价非常小就值得去尝试”E-69030。

## 目的与适用环境
在指数日线多头排列、突破后进入回测整理阶段，利用小周期多重技术支撑重合点，以极低止损代价博弈顺势波段上涨。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线/周线周期 | E-69039、E-69040 | 日线多头排列，周线翻上多空线，无减仓或空仓信号，必须保持多头仓位不能空仓；原稿未明确板块资金分配比例 |
| 形态或指标形成 | 60分钟周期 | E-69027、E-69028、E-69029 | 价格贴近60分钟多空线，同时存在微小未补缺口（如独毛缺口），二者重叠构成二合一支撑 |
| 确认 | 60分钟周期 | E-69028 | 60分钟多空线未被跌破（刺破都未发生），维持收敛状态，出现阳线/异色K线 |
| 入场 | 盘中现价 | E-69030、E-69040 | 在现价紧贴支撑位时参与买入或加仓进攻；挑选符合架构的个股或指数标的 |
| 初始止损 | 60分钟收盘/破位 | E-69030 | 以支撑位跌破为界（如打漏多空线3115点），亏损空间约为9个点（千分之三），触发一把止损 |
| 仓位与资金 | 建仓执行时点 | E-69039、E-69040 | 必须保持一定仓位，不能空仓；原稿未明确具体仓位百分比 |
| 持仓与跟踪 | 盘中及日线跟踪 | E-69030 | 持仓跟踪，等待上涨化解指标死叉，看能否拽出红色波次并创新高；原稿未给跟踪均线参数 |
| 加减仓 | 第二买点确认时 | E-69040 | 在调整结束第二买点出现时执行加仓进攻；原稿未明确加仓的具体金额分配 |
| 止盈与退出 | 日线收盘 | E-69021、E-69022 | 大盘若跌破宏观底线触发指数止损，或由个股自身交易架构发出止盈信号退出；原稿未设固定点位止盈线 |
| 失效与放弃 | 盘中或收盘 | E-69023、E-69025、E-69030 | 60分钟多空线被击穿，或日线收盘跌破3096/3090点，方案彻底失效并止损 |

## 规则之间怎样衔接
以宏观多头纪律为底仓持仓要求，以小周期“缺口＋多空线”重叠区为试错锚点；击穿支撑位执行极窄止损，守住支撑位则持股博弈日线突破延续。

## 案例和失败方式
案例为上证指数3124点试错二合一支撑E-69030；失败方式为多空线跌破导致止损，或大盘失守3090点导致回测彻底失败。

## 版本分歧与证据限制
本策略为盘中解盘口述提炼，未给出严格的统计回测胜率与仓位管理量化公式。
