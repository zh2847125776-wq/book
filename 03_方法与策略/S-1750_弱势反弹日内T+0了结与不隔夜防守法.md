# S-1750 弱势反弹日内T+0了结与不隔夜防守法

## 目的与适用环境
适用于大盘大周期均线空头压制、外围外盘剧烈波动（如美联储议息会议大跌）背景下，利用日内冲高锁定短线利润，规避隔夜跳空低开的不可抗力风险。

## 规则之间怎样衔接
识别外围风险 -> 早盘择机低吸做T -> 跟踪日内冲高幅度 -> 尾盘坚决清仓不隔夜 -> 资金安全归宿等待次日。

## 案例和失败方式
- 案例：2022年11月1日至2日连续两天尾盘均未持仓过夜，白天冲高赚钱尾盘抛，次日避开早盘低开冲击。
- 失败方式：贪恋浮盈违反不隔夜纪律将仓位留至次日，次日遭遇外盘利空带崩低开直接由盈转深套。
