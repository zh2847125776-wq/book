# S-1271 补涨补跌因子测算法（比例系数法）

> 来源：SRC-004541（第1871课 补涨补跌公式因子与三级支撑总表）· 证据 E-61522, E-61523, E-61524
- 性质：局部方法
- 规则版本：第1871课牛年收官版
- 完整度分级：已给方向
- 效果证据：通过创指涨幅与上证涨幅比值，测算出上证破颈线后尚缺2%以上跌幅方能追齐创指（E-61523）

## 目的与适用环境
定量计算两个强相关标的（指数之间、或行业板块与代表性成分股之间）在破位后的理论补跌空间与差值。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 两标的具有长期共振属性（如上证与创指，或银行指数与工商银行） | 日线或周线 | E-61524 | 必须具有强相关性 |
| 形态或指标形成 | 选取历史共同起涨点到见顶高点，计算标的A涨幅M%与标的B涨幅N% | 历史基准波段 | E-61522 | 原文提及2440-3731与1184-3576 |
| 确认 | 确立比例系数 $K = M / N$（代表A涨1%，B应涨 $K$%） | 测算初期 | E-61522 | 属于经验估算模型 |
| 入场 | 原文未明确（本方法用于测算补跌差值，非直接买卖信号） | 原文未明确 | 无 | 缺口：不可直接开仓 |
| 初始止损 | 原文未明确 | 原文未明确 | 无 | 缺口：无止损规则 |
| 仓位与资金 | 原文未明确 | 原文未明确 | 无 | 缺口：无资金管理参数 |
| 持仓与跟踪 | 测量标的B破位后的实际跌幅，乘以系数得出标的A应跌幅度，比对实际跌幅 | 调整期跟踪 | E-61523 | 动态核对补跌进度 |
| 加减仓 | 原文未明确 | 原文未明确 | 无 | 缺口：无加减仓说明 |
| 止盈与退出 | 若实际跌幅与理论跌幅差值很小（如应跌4.4%实跌4.1%），补跌预期达成可忽略不计 | 差值收敛时 | E-61523 | 若差值大则补跌未完 |
| 失效与放弃 | 原稿强调此法为估算方法，谁也没说滞后品种一定百分百必须追平，差值极大时仅作方向参考 | 偏离过大时 | E-61523 | 不可机械教条化执行 |

## 规则之间怎样衔接
将形态颈线跌破后的定性空间分析转化为定量比例测算；计算出的补跌目标位与大背景支撑位交叉验证。

## 案例和失败方式
案例：创指破颈线跌6.61%，按比例上证理论应跌4%以上，但实际仅跌2.69%，判定上证仍欠补跌空间（E-61523）。
失败方式：将比例系数视为绝对刚性定律，认为上证必须分毫不差跌满理论跌幅，忽视市场中途突发利好带来的结构反弹（E-61523）。

## 版本分歧与证据限制
原稿指出此为初代基础数学模型，正式使用需加入抓取5-10年数据并经多段平均平滑后的常数系数，完整平滑算法原稿未展开。
