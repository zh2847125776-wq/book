# S-2996 一进二短线接力策略

> 来源：SRC-000264（第983章 一进二秘籍：涨停果断，量能精准）· 证据 E-71262
- 性质：局部方法
- 规则版本：首板干脆封板与次日量价竞价接力法
- 完整度分级：已给方向
- 效果证据：原文作者自述亲身操作该模式成功捕捉首日烂板次日二连板并获利，但原稿未提供系统化大样本回测统计胜率数据。· 证据 E-71265

## 目的与适用环境
解决短线接力中二进三盈亏比极低、盲目追涨首板容易被假突破诱多套牢的问题；适用于大盘处于上升通道、风险偏好提升、盘面热度最高且板块内涨停家数超过10家的强势热点题材中。· 证据 E-71266

## 规则之间怎样衔接
首板根据封板干脆度筛选候选池 -> 次日9:25根据集合竞价量能（1.5万-3万手）与红开幅度（约2个点）过滤假强标的 -> 竞价确认后开盘果断入场 -> 日内跟踪封板力度，次日冲高止盈。· 证据 E-71261, E-71262, E-71265

## 案例和失败方式
成功案例：某只个股首日涨停反复开板，次日以3万手左右量能微幅高开，果断买入后该股迅速封板并连续走高获利；失败方式：盲目追高开板过多的弱首板，或遇板块分歧未换手直接追冲天炮遭高位砸盘。· 证据 E-71261, E-71265, E-71270

## 版本分歧与证据限制
本策略仅增强稿可见；原稿未明确给出单笔交易的硬性止损比例及账户仓位配比数值。· 证据 E-71262
