# S-1711 破功指标系统即时删除与逻辑重构法

> 来源：SRC-004731（第2042课 股票日评：底部缩量反弹而已不要被迷惑（20220927））· 证据 E-63261
- 性质：局部方法
- 规则版本：V1（20220927）
- 完整度分级：已给方向
- 效果证据：原文强调“完全已经破功了，破功就不用看他了”，即时删除破功公式可避免交易者陷入沉没成本与执念。

## 目的与适用环境
当依据特定指标系统（如周线低九、混沌公式等）设定的交易模型被市场价格走势证伪并破位时，执行系统清理与认知重构。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 周线/日线周期 | E-63261 | 存在前期设定的指标或公式逻辑（如周线低九配合混沌公式） |
| 形态或指标形成 | 破位发生时 | E-63261 | 价格跌破公式核心支撑位或反转预期失效（如低九后再度创新低） |
| 确认 | 事实发生即确认 | E-63261 | 指标逻辑被市场走势证伪，判定为“完全破功” |
| 入场 | 不适用 | E-63261 | 破功后禁止依据原公式入场 |
| 初始止损 | 即刻清退 | E-63261 | 原依据该公式建立的头寸必须无条件清退 |
| 仓位与资金 | 0仓位 | E-63261 | 清空相关头寸，回归现金状态 |
| 持仓与跟踪 | 软件系统清理 | E-63261 | 从行情分析软件中直接删除破功公式及指标画线 |
| 加减仓 | 禁止加仓 | E-63261 | 严禁在破功指标下越跌越买补仓 |
| 止盈与退出 | 破功退出 | E-63261 | 依据失效即退出 |
| 失效与放弃 | 建立新逻辑前 | E-63261 | 在市场打出新的有效结构前保持完全空仓 |

## 规则之间怎样衔接
1. 前期依据特定指标构建交易观察模型；
2. 市场跌破关键逻辑点，触发“破功”判定；
3. 执行即时删除公式，重置交易认知，转入均线系统统摄观察。

## 案例和失败方式
- 案例：2022年9月27日上证指数周线低九及混沌公式因价格击穿支撑而破功，讲述者当场删掉公式不再关注。
- 失败方式：指标失效后死守不放，修改参数自我安慰，导致深度套牢。

## 版本分歧与证据限制
原稿未披露混沌公式的具体源码算法，仅记载其在周线破位后的废弃处理原则。
