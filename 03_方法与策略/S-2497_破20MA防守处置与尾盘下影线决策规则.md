# S-2497 破20MA防守处置与尾盘下影线决策规则

> 来源：SRC-005020（第2302课 股票日评：反弹结束耐心等待前低的双底机会（20231122））· 证据 E-66779
- 性质：局部方法
- 规则版本：原文未明确
- 完整度分级：已给方向
- 效果证据：原文未提供回测数据

## 目的与适用环境
日线级别大盘指数或标的跌破20MA且5穿20时，指导持仓多头的防守退出与过夜风险控制。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线处于空头排列大背景，均线向下压制，只看压力不看支撑 | E-66775, E-66780 | 不可假设均线短期金叉 |
| 形态或指标形成 | 日线收盘攻破20MA，形成5穿20死叉，DIF贴近零轴将穿轴 | E-66779, E-66785 | 原文标注死叉贴近零轴空头加速 |
| 确认 | 日线收盘确实跌破20MA；若进一步跌破前低关键支撑（如1962）则破位确认加剧 | E-66779 | 不等待三天确认 |
| 入场 | 不进行任何多头买入操作；两类期待结构（均线粘合突破/双底破翻）未触发前空仓等待 | E-66782 | 禁止逆势左侧入场 |
| 初始止损 | 已有持仓在收盘攻破20MA时必须坚决执行出场止损；收在1962下方更必须走 | E-66779 | 不可等待次日修复 |
| 仓位与资金 | 空仓观望，避免资金暴露于不可控敞口与跳空风险中 | E-66779 | 严格保护本金 |
| 持仓与跟踪 | 禁止隔夜持仓，除非出现特例形态 | E-66779 | 不可抱有安慰剂侥幸 |
| 加减仓 | 原文未明确多头加仓规则；仅述空仓等待结构出现 | E-66782 | 禁止逆势摊平 |
| 止盈与退出 | 收盘破20MA即为离场退出信号 | E-66779 | 原文未提供止盈跟踪 |
| 失效与放弃 | 唯一允许持仓等待次日的特例：尾盘强力拉起且日K线留出长下影线，可允许次日等待阳线；若无长下影线则必须当日离场，放弃一切持股幻想 | E-66779 | 无长下影线不可留仓 |

## 规则之间怎样衔接
打破传统教科书“破线等三天”的教条，以“收盘破20MA立即走”为硬性规则，仅保留“长下影线”为唯一延后观察例外，向下破前低则触发无条件止损。

## 案例和失败方式
创业板指数20231122收盘攻破20MA，盘中最低1960跌破1962，尾盘无下影线必须全部走人；等待三天可能遭遇跳空低开及大幅连续杀跌。
