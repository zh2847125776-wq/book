# S-2518 中字头权重板块逆势选股与排除法

## 目的与适用环境
在指数大盘弱势整理背景下，锁定回调幅度较小、指标率先走强的权重板块，通过严格的负面清单排除不适宜标的，筛选出具备突破潜力且止损明确的个股进行试错操作。

## 规则之间怎样衔接
板块层面确认抗跌与DIF穿轴 -> 打开成分股名录 -> 执行五大负面清单排除（波动小、空头排列、历史最高、破翻结构、无法设止损） -> 仅保留具备突破形态且可设止损的标的轻仓试做。

## 案例和失败方式
2023年12月4日筛选中字头板块：中石油、银行因波动小被排除，人寿与石化因空头排列被排除，神华因历史最高被排除，联通因破翻被排除，中远海控因位置太高无法设止损被排除（E-66947、E-66948）。
