# S-1709 均线逆势交易与空头排列观望过滤法

> 来源：SRC-004731（第2042课 股票日评：底部缩量反弹而已不要被迷惑（20220927））· 证据 E-63256
- 性质：局部方法
- 规则版本：V1（20220927）
- 完整度分级：已给方向
- 效果证据：原文明确指出在均线空头排列下“参与了就是逆势交易”，执行观望可规避缩量反弹后的再创新低风险。

## 目的与适用环境
在均线系统处于标准空头排列时，作为最高权重的强制过滤规则，直接否决任何短线抄底买入冲动，保持绝对空仓观望。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线周期 | E-63256 | 均线系统（5、10、20、60日线等）呈现“标标准准空头排列” |
| 形态或指标形成 | 盘中或收盘 | E-63256 | 出现单日红盘阳线或低位缩量反抽 |
| 确认 | 盘中确认 | E-63256 | 均线空头排列未被扭转，定性为逆势交易环境 |
| 入场 | 禁止入场 | E-63256 | 绝对禁止任何做多开仓买入动作 |
| 初始止损 | 不适用 | 原文未明确 | 本策略为买入禁止过滤法，无入场持仓点位 |
| 仓位与资金 | 持续生效 | E-63256 | 保持0仓位（空仓观望） |
| 持仓与跟踪 | 每日收盘监控 | E-63256 | 跟踪各周期均线排列状态，不因单日K线反弹改变空头定性 |
| 加减仓 | 不适用 | 原文未明确 | 观望期间不进行任何加减仓操作 |
| 止盈与退出 | 不适用 | 原文未明确 | 无持仓头寸 |
| 失效与放弃 | 趋势反转时 | E-63256 | 均线系统重新扭转为空头排列解除或打出底部真涨结构时解除过滤 |

## 规则之间怎样衔接
1. 先由均线系统最高权重（K-30291）判定大势排列方向；
2. 若处于空头排列，直接激活本过滤法，屏蔽所有技术指标的买入提示；
3. 配合缩量反弹二分法定性（K-30289），将反弹定性为不可参与的虚假波动。

## 案例和失败方式
- 案例：2022年9月27日创业板均线标标准准空头排列，逆势买入者在后续交易日遭受进一步回落套牢。
- 失败方式：在均线尚未金叉扭转前抢跑入场，遭遇空头中继加速下行。

## 版本分歧与证据限制
本策略依据2042课原稿讲述者原话提炼，原稿未提供具体的空头排列参数组合数量，统一以标标准准空头排列为准。
