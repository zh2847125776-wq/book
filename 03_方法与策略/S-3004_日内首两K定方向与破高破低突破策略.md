# S-3004 日内首两K定方向与破高破低突破策略

> 来源：SRC-000310（⏱ 00:13:00、⏱ 00:15:00、⏱ 00:16:30、⏱ 00:18:30）· 证据 E-71328, E-71331, E-71333, E-71337
- 性质：规则完整的策略
- 规则版本：2分钟日内前两K突破交易法
- 完整度分级：已给方向
- 效果证据：沪锡空单、沪银多单、沪金多单触发止盈；沪镍空单触发止损

## 目的与适用环境
用于捕捉期货品种早盘开盘后的日内单边动量，依据开盘前两根2分钟K线确立主方向，在形成回调结构后破位切入，预设固定盈亏比退出。 · 证据 E-71328, E-71333

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 早盘开盘阶段（2分钟周期） | E-71328, E-71333 | 仅适用于流动性充裕的主力连续合约日内交易 |
| 形态或指标形成 | 开盘第1根K线（09:00~09:02） | E-71328, E-71333 | 第1根为阴线定空、阳线定多；若为无色K则看第2根K线定方向 |
| 确认 | 方向确立后等待反向回调 | E-71328, E-71331 | 需等待K线形成连续回调波段（如回调4至6根K线） |
| 入场 | 回调结束并跌破前低（空）或突破前高（多） | E-71328, E-71333 | 可通过条件单或手工单在破位瞬间触发开仓 |
| 初始止损 | 开仓同时设定于回调波段极值外 | E-71329 | 必须按品种最小跳价单位设定（如沪锡向上一跳加10点） |
| 仓位与资金 | 单笔标准日内仓位 | E-71331 | 逆势交易预计仓位减半；同品种日内已亏损则后续不易盈利需谨慎 |
| 持仓与跟踪 | 入场后挂单跟踪 | E-71331, E-71336 | 预设1:1.5固定风险回报比条件单自动监控 |
| 加减仓 | 持仓过程中 | E-71337 | 原稿未提及加仓规则；遇极端巨大阳线人工单可一色K平一半 |
| 止盈与退出 | 触及预设目标位或极端K线出现 | E-71334, E-71337 | 条件单达到1:1.5自动止盈；人工单遇极大K线可用一色K/LPA出场 |
| 失效与放弃 | 临近尾盘（14:20后）或空间过窄 | E-71332, E-71340 | 下午14:20后创高创低即使出信号亦放弃；止盈空间过小放弃 |

## 规则之间怎样衔接
首K定多空 -> 回调计数等待 -> 创高/创低破位入场 -> 极值+1跳挂止损 -> 预设1:1.5盈亏比自动止盈或极端K线人工一色K/LPA平仓。 · 证据 E-71328, E-71329, E-71336, E-71337

## 案例和失败方式
- 沪锡主连（sn9999）：首K阴线，回调6根后9:26触发空单，差1跳未打止损，最终触发止盈。 · 证据 E-71328, E-71329
- 沪镍主连（ni9999）：首K阴线，回调4根后触发空单，盘中反弹于9:56触发止损。 · 证据 E-71331
- 失败方式：盘整市中破位后未能走出单边动量，迅速反抽打掉极值止损点。 · 证据 E-71331

## 版本分歧与证据限制
条件单与人工单出场存在分歧：条件单遇极端单边容易过早止盈卖飞；人工单若使用LPA在其他普通订单中容易造成极大回撤，两者机制互有优劣。 · 证据 E-71335, E-71336
