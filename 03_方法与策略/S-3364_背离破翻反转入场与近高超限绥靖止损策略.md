# S-3364 背离破翻反转入场与近高超限绥靖止损策略

> 来源：SRC-000362（期货_期货投机分析20251104（增强版））· 证据 E-75101
- 性质：规则完整的策略
- 规则版本：原稿未明确
- 完整度分级：已给方向
- 效果证据：白银大阴线实体中位线止损未被触及且顺畅下跌，纸浆背离破翻做空成功盈利。

## 目的与适用环境
用于趋势末端出现背离与破翻共振时的反转开仓，并提供在止损空间超标时的替代控险手段。（E-75101）

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 多点连线横盘高点创高或单边末端出现钝化，且指标形成背离 | E-75101、E-75110 | 原稿未给出背离指标的平滑参数 |
| 形态或指标形成 | 价格创新高（或新低）但指标朝反向走形成背离，同时价格反穿关键位形成破翻结构 | E-75101 | 必须同时满足背离与破翻两个要件 |
| 确认 | 破翻与背离两个要件必须同时且（AND）出现，缺一不可，且K线收盘需满足一色K阴线确认 | E-75101、E-75112 | 阳线或无色K不得开单 |
| 入场 | 破翻与一色K阴线收盘确认后立刻挂单入场 | E-75110、E-75112 | 突破即入场或收盘入场 |
| 初始止损 | 首选符合5K法则的近高；若近高亏损测算超过1%绝对阈值，则启用绥靖止损，选标志性大阴线FPR突破点或实体中位线（3号位）加余量 | E-75102 | 实体中位线为止损妥协替代方案 |
| 仓位与资金 | 亏损风险严格控制在投入资金绝对阈值1%以内 | E-75099 | 单笔亏损严禁超过1% |
| 持仓与跟踪 | 持仓浮盈不足5%期间忽略反向拐头，死守初始止损 | E-75108 | 微利期不执行移动止盈 |
| 加减仓 | 原稿未提及加仓规则 | E-75101 | 原稿未明确加仓逻辑 |
| 止盈与退出 | 执行三信号二触发分级平仓规则（破翻、VB上穿、MAVB上穿/拐头） | E-75100 | 按两步分批退出 |
| 失效与放弃 | 若仅有背离而无破翻，或仅有破翻而无背离，策略直接放弃，严禁提前介入 | E-75101 | 缺一不可铁律 |

## 规则之间怎样衔接
入场条件要求背离与破翻双重确认，防守端与近高超限替代止损衔接，持仓期由浮盈容忍规则护航。（E-75101、E-75102）

## 案例和失败方式
白银夜盘11:35出现开空机会，因近高止损达1.1%超过1%阈值，转而选取大阴线实体中位线止损，后续大幅盈利；氧化铝关键价格打漏若未破余量可能为挖坑陷阱，盲目追空易遭反杀。（E-75101、E-75102、E-75107）

## 版本分歧与证据限制
仅增强稿可见；针对开单后指标反向但止损未触发，讲师提出两种取舍（平仓后再加 vs 严格按计划死守止损），原稿记录讲师个人倾向于后者。（E-75102、E-75106）
