# S-1714 5日线上反回测尾盘收盘判定法

> 来源：SRC-004732（第2043课 股票日评：趋势比单个K线更加重要与不放量的阳线不可靠（20220928））· 证据 E-63266、E-63267
- 性质：局部方法
- 规则版本：V1（20220928）
- 完整度分级：已给方向
- 效果证据：原文明确收盘价站在5日线上即回测成功，盘中刺破1%属正常，尾盘收盘判定可彻底过滤盘中虚假破位或假突破。

## 目的与适用环境
用于价格在反弹首次站上短期均线（5日线）后的次日回测检验，通过收盘价唯一定性与盘中1%容差机制，防范盘中噪音干扰。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线周期 | E-63266 | 价格前一日首次收盘站上5日均线 |
| 形态或指标形成 | 次日交易时间 | E-63266 | 次日价格展开对5日均线的“上反回测” |
| 确认 | 尾盘集合竞价/收盘 | E-63266 | 以最终日线收盘价作为回测成败的唯一裁判 |
| 入场 | 回测成功轻仓试探 | E-63266 | 仅当收盘价守在5日线上方且符合小节要求时，才考虑超短试探 |
| 初始止损 | 跌破5日线止损 | E-63266 | 收盘价跌破5日线（超出1%容差）立即止损 |
| 仓位与资金 | 极轻仓或观望 | E-63267 | 空头排列下即使回测成功也仅属负乖离修复，仓位严格受限 |
| 持仓与跟踪 | 盘中容差跟踪 | E-63266 | 盘中下影线刺破5日线在1%以内视为正常物理惯性，不提前恐慌操作 |
| 加减仓 | 跌破即减清 | E-63266 | 收盘打漏5日线判定回测失败，清空试探仓 |
| 止盈与退出 | 修复20日线止盈 | E-63267 | 目标位仅看至20日线负乖离修复，见好就收 |
| 失效与放弃 | 盘中大跌破位 | E-63266 | 盘中跌破5日线幅度远超1%或收盘打漏，回测逻辑彻底失效 |

## 规则之间怎样衔接
1. T日站上5日均线；
2. T+1日盘中忍受≤1%的刺破容差，不因盘中波动过早定性；
3. T+1日收盘价定成败：站稳则回测成功，打漏则回测失败；
4. 无论成败均牢记空头排列威力（K-30295），反弹空间以20日线为限。

## 案例和失败方式
- 案例：2022年9月28日创业板进行5日线上反回测，盘中下刺5日线约1%，尾盘收盘价成为决定回测有效性的核心。
- 失败方式：盘中刚刺破5日线0.5%就误判破位割肉，或盘中冲高未等收盘就重仓追入。
