# S-2244 抑制大面回撤之“多空仓/少出手/精出手”策略

> 来源：SRC-000231（第26章 控制大面回撤）· 证据 E-65358
- 性质：规则完整的策略
- 规则版本：复利防守风控体系
- 完整度分级：已给方向
- 效果证据：原文明确指出“炒股路上，大面是复利路上的最大毒瘤。不控制大面回撤，持续稳定赚钱就是空中楼阁……多空仓、少出手、精出手、提高标准、找准时机，这些都是投资者需要掌握的技巧”。

## 目的与适用环境
在超短线与股票投资全周期中，将“控制大面”确立为复利基石，通过严苛提高标准并强制大幅提升空仓比例，根除平庸无效交易，实现资金稳步阶梯式复利。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| **环境过滤** | 市场处于不确定环境、亏钱期或大盘下倾处于5日线下方 | 每日盘前/盘中 | E-65358 | 弱势与不确定期必须强制空仓 |
| **形态或指标形成** | 盘面缺乏六七板连板高度，板块缺乏接力梯队与板块效应 | 早盘竞价后 | E-65358 | 提高选股标准，杂毛一概剔除 |
| **确认** | 大盘未出现强向上斜坡，大题材大故事未形成共振 | 开盘时点 | E-65358 | 90%的出手时机都是错的 |
| **入场** | 执行“多空仓、少出手、精出手”；非绝对确定性机会坚决一股不买 | 全天交易时段 | E-65358 | 一个月仅等待一两次核心机会 |
| **初始止损** | 一旦试错买入发生走势不及预期或亏损达5%，立即斩仓止损 | 破位瞬间 | E-65358 | 绝不补仓死扛 |
| **仓位与资金** | 空仓为常态；仅在10%的极高确定性时机集中下注核心龙头 | 决策时点 | E-65358 | 大幅收缩无效敞口 |
| **持仓与跟踪** | 保持高标准观察，跟踪龙头分时与筹码承接，不被短期杂音干扰 | 持仓全程 | E-65358 | 聚焦核心之核心 |
| **加减仓** | 严禁在杂毛上分散下注或在回撤期逆势补仓 | 盘中任何时段 | E-65358 | 杜绝加仓恶习 |
| **止盈与退出** | 赚钱周期结束或高标出现跌停，立即清仓收摊空仓 | 周期退潮时 | E-65358 | 及时兑现利润落袋为安 |
| **失效与放弃** | 只有当指数大涨稳居5日线上、大题材爆发出大单一字梯队时，方可结束空仓 | 确定性转折点 | E-65358 | 找准最佳时机方可出手 |

## 规则之间怎样衔接
以“高标准过滤与被动空仓”为核心闭环：
1. 建立心理防火墙：确立“90%出手皆错”的认知，以空仓为默认状态；
2. 提高标准：非总龙头不碰、非四要素共振不碰；
3. 精准出击：一旦极高胜率时机出现，精出手集中打击，利润到手退潮时立即收摊回到空仓。

## 案例和失败方式
- 失败方式：手痒天天想干，天天在杂毛上试错，单日吃-18%大面，将主升浪积累的本金与信心彻底摧毁。
