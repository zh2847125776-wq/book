# S-1702 外盘大幅波动下的集合竞价脱敏应对法

> 来源：SRC-004727（第2039课 股票日评：均线压制的两个条件与钝化不可交易（20220922））· 证据 E-63216、E-63223、E-63224
- 性质：局部方法
- 规则版本：20220922实盘讲解版
- 完整度分级：已给方向
- 效果证据：美联储加息夜美股剧烈震荡（-1%至+1.5%至-1.8%），次日A股早盘集合竞价一跳化解，全天走自身缩量小K线节奏，验证外盘脱敏规律（证据 E-63223、E-63224）。

## 目的与适用环境
用于在美联储议息或美股出现大幅暴涨暴跌的次日，通过早盘集合竞价和首小时量能快速完成外盘影响脱敏，恢复A股自身节奏评估。

## 条件与动作
| 阶段 | 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- | :--- |
| 环境过滤 | 外盘（美股）前夜出现大幅波动（如加息75个基点，美股剧烈震荡跌1.8%） | 隔夜及盘前 | E-63223 | 外部事件驱动环境 |
| 形态或指标形成 | 早盘9:25观察A股指数集合竞价成交量与开盘跳空幅度 | 早盘9:25 | E-63223、E-63224 | 对比量表阈值（创指15亿、上证40亿） |
| 确认 | 集合竞价成交量远低于阈值（如创指7.26亿对15亿，上证18.67亿对40亿），且分时早盘一跳即化解外盘影响 | 9:30-10:30 | E-63223、E-63224 | 注定全天以小K线波动为主 |
| 入场 | 判定日内无大涨大跌基础，严格禁止因外盘大跌而恐慌割肉或因冲高而盲目追涨 | 9:30后全天 | E-63223、E-63224 | 无量能支持则无大行情，维持现状 |
| 初始止损 | 「原文未明确」 | 「原文未明确」 | 无 | 原文未给出专门止损指令 |

| 持仓与跟踪 | 盘中通过60分钟首小时成交量复核日内量能（如创指550亿相比前日508亿仅微增），确认无法产生单边大行情 | 10:30分时 | E-63216、E-63224 | 分时波动在日线级别不值一晒 |
| 加减仓 | 「原文未明确」 | 「原文未明确」 | 无 | 原稿未提及加减仓动作 |

| 失效与放弃 | 若集合竞价显著超越阈值放量且首小时量能呈爆发式增长，则外盘脱敏假设失效，需按放量大K线应对 | 早盘确认 | E-63224 | 量能放量突破时切换规则 |

## 规则之间怎样衔接
9:25通过集合竞价量能判定外盘影响已在开盘消化；9:30后结合首小时成交量确认全天小K线性质，阻断日内噪音干扰。

## 案例和失败方式
- 案例：2022年9月22日美联储加息落地美股下挫，A股集合竞价跳空后迅速走自身小K线节奏（证据 E-63223、E-63224）。
- 失败方式：受外盘大幅波动情绪恐慌，在早盘集合竞价低开时盲目割肉。

## 版本分歧与证据限制
量表阈值以创业板15亿、上证40亿为基准，不同市场阶段阈值可能微调。
