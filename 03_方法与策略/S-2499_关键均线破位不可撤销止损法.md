# S-2499 关键均线破位不可撤销止损法

> 来源：SRC-005021（第2303课 股票日评：技术反弹小结构正常波动大势不改（20231123））· 证据 E-66795、E-66801
- 性质：局部方法
- 规则版本：原文未明确
- 完整度分级：已给方向
- 效果证据：原稿强调跌破均线若不止损，后面会发生严重亏损；芯片、半导体、光伏等品种破位均执行离场（E-66795）。

## 目的与适用环境
在多头持仓遭遇标的跌破关键均线（如20日均线）或极限横盘防线时，实施无条件刚性平仓，规避主观侥幸导致的深度被套。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 市场大势偏空或处于反弹受阻环境 | 日线周期 | E-66795、E-66801 | 适用于弱势防守阶段 |
| 形态或指标形成 | 标的价格跌破20日均线支撑，或击穿设定的横盘区间低点防线 | 日线盘中或收盘 | E-66795 | 支撑结构破位 |
| 确认 | 盘中跌破关键均线或收盘跌破防线，指标绿柱放大 | 破位确立时 | E-66795 | 无需等待反抽确认 |
| 入场 | 不适用（属于离场规则） | 不适用 | E-66795 | 非开仓规则 |
| 初始止损 | 不适用 | 不适用 | E-66795 | 本身即为止损执行指令 |
| 仓位与资金 | 多头持仓全部平仓止损离场 | 触发即刻 | E-66795 | 不留侥幸底仓 |
| 持仓与跟踪 | 在20日均线上方持有；一旦跌漏20日线，坚决止损离场 | 日常跟踪 | E-66795 | 线上持有，线下清仓 |
| 加减仓 | 禁止在破位后补仓摊平成本 | 破位全程 | E-66795 | 严禁逆势加仓 |
| 止盈与退出 | 20日线失守立刻走人；若给有横盘底线（如医药0.430），击穿后必须离场 | 破位瞬间 | E-66795 | 刚性退出 |
| 失效与放弃 | 哪怕止损后两三天价格重新站回该均线，跌破时的止损指令也绝不可撤销 | 止损执行后 | E-66795 | 纪律不可逆，防范破位崩塌风险 |

## 规则之间怎样衔接
均线上方持有 -> 跌破20日线触发止损 -> 彻底清仓离场 -> 排除“过两天站回来就不损”的侥幸心理 -> 空仓等待大级别底部结构形成。

## 案例和失败方式
半导体ETF跌破20日均线后最低价碰触60日均线，出现绿柱二阳线技术反弹，必须坚决离场；芯片ETF在20日均线上方持有，一旦跌漏20日线必须止损，即便过两天重新站回也不能不执行止损；医药ETF以0.430为极限横盘低点，跌破必须离场（E-66795）。

## 版本分歧与证据限制
医药ETF原稿给出了分档防线：20日线漏了考虑走，若不想走则以近期横盘区间低点0.430作为最后极限底线，各品种设防点根据形态略有差异。
