# S-2396 牛市日内强分歧大承接低吸介入法


来源：SRC-000242（妖股成妖之路_20（增强版）# 第318章）· 证据 E-66018, E-66023

性质：局部方法
规则版本：原文未明确（未分版）
完整度分级：已给方向
效果证据：原文作者指出在牛市日内分歧跳水时克服恐惧、低吸承接不拖泥带水的核心标的，能有效避免卖在最低并捕获反包利润（E-66018, E-66023）
目的与适用环境

用于在牛市盘中指数与板块剧烈分歧跳水时，捕捉核心前排标的的低吸机会。适用环境为增量牛市中的日内强分歧时段。

规则之间怎样衔接

早盘拒绝追高 -> 等待午后指数大分歧跳水 -> 锁定承接强劲的核心龙头 -> 分时低吸上车 -> 尾盘与次日享受修复拉升。

案例和失败方式
成功应用案例：海能达与双成药业在午后指数剧烈跳水回落中，分歧资金承接果断，低吸者捕获丰厚修复利润（E-66018, E-66023）。
失败方式：在日内跳水时产生恐慌心理，将手中的核心底仓割肉在全天最低点。
