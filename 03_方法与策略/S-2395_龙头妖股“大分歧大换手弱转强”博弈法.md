# S-2395 龙头妖股“大分歧大换手弱转强”博弈法


来源：SRC-000242（妖股成妖之路_20（增强版）# 第322章）· 证据 E-66017

性质：规则完整的策略
规则版本：原文未明确（未分版）
完整度分级：已给方向
效果证据：原文作者指出通过在大分歧日回封涨停、次日博弈弱转强，是短线超短模式中捕捉超级妖股突破15板天花板的核心战法（E-66017）
目的与适用环境

用于在最高空间板龙头面临老龙跌停或大盘分歧时，捕捉充分换手后的弱转强连板机会。适用环境为高位最高板妖股渡劫节点。

规则之间怎样衔接

最高板遇外部大分歧开板 -> 巨额换手承接回封 -> 次日早盘弱转强高开上车 -> 连板锁仓 -> 断板离场。

案例和失败方式
成功推演案例：华立股份在大分歧日完成空中加油回封，次日博弈弱转强突破天花板（E-66017, E-66021）。
失败方式：在非龙头跟风杂毛上盲目套用弱转强，遭遇天地板闷杀。
