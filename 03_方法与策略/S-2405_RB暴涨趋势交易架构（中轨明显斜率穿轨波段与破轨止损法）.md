# S-2405 RB暴涨趋势交易架构（中轨明显斜率穿轨波段与破轨止损法）


来源：SRC-000021（P2_rb实测与细节掌握（增强版））· 证据 E-66076, E-66077, 证据未逐字回源

性质：规则完整的策略
规则版本：原文未明确（未分版）
完整度分级：已给方向
效果证据：原文课件思维导图列明暴涨架构下中轨带有明显斜率，分为做波段（穿上轨卖回落中轨接）与不做波段（金叉进死叉出）两套完整执行分支，并以跌破中轨严格止损防守（E-66076, E-66077, 证据未逐字回源）
目的与适用环境

用于在行情进入暴涨主升浪、布林带中轨带有明显向上斜率的强趋势中，通过波段高抛低吸或长线金叉持股获取最大化趋势利润。适用环境为单边暴涨主升行情。

规则之间怎样衔接

识别暴涨趋势（中轨明显斜率） -> 金叉进场 -> 【做波段：穿上轨卖出 -> 回踩中轨接回 -> 重复循环】或【不做波段：一路持股至死叉卖出】 -> 跌破中轨止损离场。

案例和失败方式
成功应用案例：在主升浪中股价穿过上轨后回落上轨内减仓，回踩中轨接回，成功吃满多段波段。
失败方式：跌破中轨后不愿止损，行情由暴涨转为暴跌导致严重套牢。
