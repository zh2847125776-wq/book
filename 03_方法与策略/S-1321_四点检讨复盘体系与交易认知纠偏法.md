# S-1321 四点检讨复盘体系与交易认知纠偏法

- **目标**：在实战遭遇假突破或止损出局后，通过结构化四点检讨体系复盘交易失误，纠正认知偏差，避免重复犯错。
- **触发条件**：
  1. 交易头寸遭遇结构性破位止损；
  2. 关键指数推演与实际市场走势发生严重方向性背离。
- **执行步骤**：
  1. **第一点：前高资格审查（下降常态真伪）**：检讨作为阻力或支撑的前高是否为“真下降常态前高”。核查其后序波段是否创出新低；若未创新低，承认将其作为强支撑是底层认知错误；
  2. **第二点：通道与时空破位确认**：检查分时通道线（如60分钟通道下线）是否已被收盘击破；通道下线一旦收盘破位，必须立刻承认多头结构瓦解；
  3. **第三点：序列指标起效条件核查**：检讨是否孤立迷信“低九”抄底。排查低九出现时是否具备连续两个绿柱缩短的动能共振，未见共振严禁轻举妄动；
  4. **第四点：交易哲学偏差纠正（所见而非所想）**：反思开单时是否违背了“根据所见而非所想交易”的最高铁律。若在未突破通道上限时提前预判突破进场，直接确认为买在局部箱体头部的原则性违纪，必须强制复盘记录。
- **失效与风控**：
  - 复盘必须形成书面记录并录入交易日志，若同一错误在随后3次操作中重复出现，强制暂停实盘交易一周。
