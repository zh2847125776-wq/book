## 目的与适用环境
本章债券月末交易的基准与延迟入场分支。

## 条件与动作
| 环节 | 条件或动作 |
| --- | --- |
| 环境过滤 | 债券月末上涨倾向是研究背景，非每月必涨保证 |
| 形态或指标形成 | 基准第18个交易日；延迟版第22个交易日，不是两个都买（E-51347、E-51349） |
| 确认 | 过滤版要求入场前黄金收盘低于24天前收盘（E-51348）；“前24天前”为重复转写，天是否交易日未明确 |
| 入场 | 第18个交易日开盘买进；后文将进场日延至22日（E-51347、E-51349） |
| 初始止损 | 1500美元；过滤版其余离场止损条件不变（E-51347、E-51348） |
| 仓位与资金 | 原文未明确 |
| 持仓与跟踪 | 基准持至入场三天后，原文未说明日序是否含建仓日（E-51347） |
| 加减仓 | 原文未明确 |
| 止盈与退出 | 入场三天后收盘卖出；过滤版维持原条件（E-51347、E-51348） |
| 失效与放弃 | 并非每个月存在第22个交易日，无该日不能机械执行延迟版（E-51350）；黄金未满足过滤不进过滤版 |

## 规则之间怎样衔接、案例与证据限制
50笔、76%属于第22日段的未加黄金过滤比较，不挪给后段89%版本。原稿后续“只要存在…都会买进”是在日历可用性语境，不取消过滤版的黄金条件。另段月末前第五交易日“通常是18日”不是严格恒等，本卡不将其并入。未核手续费、滑点和最大亏损指标口径。
