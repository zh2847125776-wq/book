# S-1432 连续阳线强势标的“开板收阴破5日线”跟踪卖出与5日线防守策略

> 来源：SRC-004601（第1925课 股票日评：两项任务与不知道也是一种结果（20220428））· 证据 E-62075、E-62076
- 性质：规则完整的策略
- 规则版本：V1.0
- 完整度分级：已给方向
- 效果证据：指导连续暴涨标的在面对中途单日上影滞涨或高九信号时保持定力，只要5日线不破坚决不卖，在破5日线时果断离场锁定胜局。

## 目的与适用环境
在持有连续涨停的股票、或外汇/期货等单边走出连续大阳线强斜率上涨的标的时，提供全流程不猜顶持股与开板破5日线离场规则。

## 条件与动作
| 步骤 | 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- | :--- |
| 环境过滤 | 标的呈现极端强势特征，股票连续涨停、或外汇/商品走出多根强斜率连续大阳线 | 主升浪进行时 | E-62075 | 强斜率单边市 |
| 形态或指标形成 | 5日均线以极大倾斜角向上攀升，标的价格始终牢牢运行于5日均线上方 | 每日日线收盘 | E-62075 | 均线斜率巨大 |
| 确认 | 过滤盘中假离场信号：<br>1. 盘中出现滞涨或微小阴线，只要未破5日线，一律视为健康换手；<br>2. 盘面出现迪马克高九（D9），明确其不决定趋势，坚决不卖 | 盘中及尾盘判定 | E-62075、E-62076 | 过滤高九与滞涨 |
| 决策 | 执行“不破不算目标价”持股铁律：完全不计算上方空间上限，全程顺应5日线一直持有 | 持股全周期 | E-62075 | 拒绝主观猜顶 |
| 初始止损 | 以5日均线点位作为动态跟踪移动止损点，每日随5日线上移而上移 | 每日开盘前调整 | E-62075 | 利润动态锁定 |
| 仓位与资金 | 维持原有做多头寸，不盲目加仓，享受单边趋势溢价 | 持仓阶段 | E-62075 | 保持恒定杠杆 |
| 持仓与跟踪 | 每日收盘前15分钟审查价格与5日均线的相对位置，监控开板与收阴形态 | 尾盘关键时段 | E-62075 | 审查收盘位置 |
| 加减仓 | 只要5日均线未发生实质性收盘攻破，严禁主动减仓做多头寸 | 持股全时段 | E-62075 | 杜绝提早下车 |
| 退出 | 触发“开板、收阴、跌破5日线”三位一体卖出条件，在收盘跌破5日线瞬间全额清仓止盈 | 破位收盘时点 | E-62075 | 机械清仓退出 |

## 适用边界与失效
适用于单边强斜率加速趋势；若标的进入宽幅震荡整理、5日线走平穿插，则该移动止损将产生频繁摩擦磨损。
