# S-0063 股票弱势补跌与板块个股共振放空方法
> 来源：SRC-004340（第168课 读书：股票作手回忆录——借补跌择机做空 离场凭客观标准）· 证据 E-0498
- 性质：待验证组合方案
- 规则版本：第168课经典案例推演版
- 完整度分级：已给方向
- 效果证据：利弗莫尔在雷丁未跌时等待其成为最后破位者，破位后做空斩获大幅利润并在接近市场平均跌幅时清仓（E-0498）。
## 目的与适用环境
在系统性大熊市或板块整体显著下行的背景下，针对此前因主力护盘表现抗跌但最终支撑衰竭的滞跌标的，在破位瞬间建立空头；并以板块/市场平均跌幅作为基准进行定量止盈（E-0498）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 市场/板块整体周期 | E-0498 | 市场大势处于明确熊市暴跌；或同板块其他权重股集体大幅下跌（如板块跌2%、多数个股跌5%） |
| 形态或指标形成 | 标的横盘高位 | E-0498 | 目标标的在多数股票暴跌时不跌反涨或高位横盘，形成明显“滞跌/补跌”预期 |
| 确认 | 盘口卖单放量 | E-0498 | 压倒骆驼的“最后一根稻草”大卖单出现，护盘资金无力承受抛压导致价格跳水 |
| 入场 | 破位跳水瞬间 | E-0498 | 盘中跌破关键平台时建立空头（如雷丁111美元跳水时跟进做空） |
| 初始止损 | 开仓同时 | 原文未明确 | 本课未给补跌策略的具体数值止损位 |
| 仓位与资金 | 开仓时 | 原文未明确 | 随破位趋势逐步加仓（如跳水至92美元完成满仓做空） |
| 持仓与跟踪 | 下跌波段中 | E-0498 | 跟踪板块整体及同类标的的平均跌幅数据 |
| 加减仓 | 顺势下跌中 | E-0498 | 跳水加速后顺势加空 |
| 止盈与退出 | 贴近市场平均跌幅时 | E-0498 | 标的跌幅贴近市场前列平均跌幅时（如同类平均跌18%，该股已跌15%），立即清仓止盈 |
| 失效与放弃 | 出现穿越牛熊特征 | 原文未明确 | 若标的具备茅台等极少数穿越牛熊的独立走势，补跌逻辑失效，不可盲目做空 |

## 规则之间怎样衔接
以市场/板块集体大跌作为环境前置过滤；锁定抗跌标的等待其支撑衰竭跳水进场；跌幅贴近市场平均跌幅数值时定量全平止盈（E-0498）。

## 案例和失败方式
1. 成功案例：利弗莫尔在雷丁股票111美元跳水时做空，至1907年2月在跌幅达15%（接近平均跌幅18%）时清仓止盈（E-0498）。
2. 注意事项：课程讲述者特别声明该操作逻辑在A股“能不能这么操作，还是有待商榷的”，不可机械照搬（E-0498）。
