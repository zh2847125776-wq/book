# S-2225 趋势线与多均线层级破位机械止损策略

> 来源：SRC-002713（⏱ 00:07:30 其他画面）· 证据 E-65274
- 性质：规则完整的策略
- 完整度分级：已给方向
- 效果证据：原文痛斥“不斩仓止损，不割肉……颈线破了也不走，就会变成这样……不会止损，你就别在股市混”，明确通过多道客观防线实现机械止损。

## 目的与适用环境
克服交易者因虚假希望、自尊心作祟逃避认错而死扛亏损的心魔，建立不以个人意志为转移的客观技术止损体系。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| **环境过滤** | 个股处于持仓状态，股价由上升转入回调或破位下行 | 日线等周期 | E-65274 | 适用于所有持仓风险控制 |
| **形态或指标形成** | 股价自高位回落，开始逐级下探关键技术防线 | 盘中及收盘 | E-65274 | 监控均线、趋势线与颈线 |

| **入场** | 本策略为出场止损策略，无入场指令 | 无 | 无 | 无 |
| **初始止损** | 设立客观技术防线，一旦触发绝不硬扛 | 即时执行 | E-65274 | 止损客观存在，不以买入价为转移 |
| **仓位与资金** | 出现破位信号逐步或全部清仓斩仓 | 信号触发时 | E-65274 | 原文要求坚决斩仓割肉出场 |

## 规则之间怎样衔接
将5日线（极短线）、上升趋势线（波段趋势）、20日线（中期生命线）及颈线（形态底线）依序排布为多道防锁线，任何一层破位均构成斩仓指令。

## 案例和失败方式
- 失败方式：幻想“纯属空头打压”、“随时会反弹”，在5日线、趋势线、20日线、颈线连续击穿后依然拒绝认赔，导致小亏变成腰斩甚至摘牌归零。
