# S-1625 组合操作与全仓盈亏覆盖管理法

> 来源：SRC-004696（第2010课 股票日评：重视个股兼顾指数与突破回测阴线（20210723））· 证据 E-62932, E-62936, E-62939
- 性质：规则完整的策略
- 规则版本：V1.0（20210723日评标准版）
- 完整度分级：已给方向
- 效果证据：20210722尾盘选股8只，次日仅美亚光电止损，组合等权全仓盈利1.12%（其中1只涨停），大幅跑赢上证-0.68%、深证-1.53%、中小板-1.29%、创业板-2.01%。

## 目的与适用环境
在指数未形成空头排列暴跌结构、提供有序进出可能性的震荡市中，通过一篮子技术选股组合分散风险，以严格止损与个股爆发盈利实现全仓正收益。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| **环境过滤** | 指数维持震荡区间，未形成空头排列暴跌结构，提供有序进出可能性 | 日线 / 盘中 | E-62932 | 指数指示不明确时防范整体暴跌 |
| **形态或指标形成** | 六个多头信号绝大多数实现（如收盘站上M20、封闭缺口等） | 日线 / 尾盘 | E-62933 | 均线不带斜率需靠多信号辅助 |
| **确认** | 尾盘发出一篮子技术选股标的清单 | 日线 / 14:00至尾盘 | E-62936 | 具体选股指标参数原文未明确 |
| **入场** | 尾盘按表操课分散买入选出的多只股票（如8只） | 日线 / 尾盘 | E-62936 | 严守尾盘交易纪律 |
| **初始止损** | 买入同时为每只个股设定明确且严格的止损位（如两三个点） | 盘中 / 实时 | E-62936 | 必须严守每只标的独立止损 |
| **仓位与资金** | 组合内各标的平均分配资金（等权配置） | 建立仓位时 | E-62936 | 总仓位上限原文未明确 |
| **持仓与跟踪** | 个股未触发止损则保持仓位持有，直到触发止盈或止损 | 交易日全天 | E-62939 | 重视个股兼顾指数 |
| **加减仓** | 指数突破失败掉回箱体时，严禁加仓或买入新标的 | 次日尾盘 | E-62939 | 严禁在指数走弱时提升总仓位 |
| **止盈与退出** | 盘中触发止损果断离场；达到目标或盘中冲高按纪律止盈 | 盘中 / 实时 | E-62936 | 具体止盈百分比原文未明确 |
| **失效与放弃** | 讲述者发出全员推送公告提示指数崩溃，无条件清空所有仓位 | 盘中 / 即时 | E-62936 | 未发公告前各守个股纪律 |

## 规则之间怎样衔接
选股信号触发后尾盘建仓 -> 等权分散配置 -> 个股盘中触发止损即刻离场 -> 盈利标的继续持有覆盖亏损 -> 指数回落禁止加仓。

## 案例和失败方式
案例：20210722选股8只，20210723美亚光电盘中触发止损离场，其余7只未触发且1只涨停，全仓等权实现+1.12%收益；失败方式：若指数出现系统性暴跌且未守止损，将导致多只标的同步踩踏亏损。

## 版本分歧与证据限制
选股模型的具体选股公式及参数原文未披露；个股具体止损百分比和止盈细则由各标的独立决定。
