# S-3531 破堆底减半与指标变色清仓的两头赌出场策略

> 来源：SRC-000387（期货_期货投机分析20251224（增强版））· 证据 E-92520、E-92531、E-92532
- 性质：局部方法
- 规则版本：20251224出场管理版
- 完整度分级：已给方向
- 效果证据：兼顾防范卖飞大单边与防范深度回撤两种心理，使交易者在持仓浮盈时亏损回吐更少（E-92520、E-92532）。

## 目的与适用环境
适用于日内短线或波段多空持仓处于浮盈状态时的动态出场管理，专为解决“既怕提前卖飞单边趋势、又怕利润大幅回撤”的双重心理冲突。（E-92520、E-92532）

## 条件与动作
| 步骤 | 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- | :--- |
| 环境过滤 | 账户持有多单或空单头寸，且当前价格已脱离建仓成本区产生浮盈 | 5分钟持仓周期 | E-92520 | 成本区内按初始止损执行 |
| 形态或指标形成 | 盘面已形成明确的跟踪基准（多单看最新堆底，空单看最新堆顶） | 5分钟周期 | E-92520 | 需持续确认最近极值点 |
| 确认 | 观察K线收盘价是否攻破最近堆底（多单）或攻破最近堆顶（空单） | K线收盘时点 | E-92531 | 收盘破位才确认有效 |
| 入场 | 本策略为出场管理方案，不涉及初始开仓入场 | 无 | 无 | 仅作用于持仓阶段 |
| 初始止损 | 本策略承接持仓跟踪，初始止损仍遵循原开仓规则近低/近高 | 开仓初始 | E-92531 | 不修改原始入场硬止损 |
| 仓位与资金 | 第一道信号触发时减仓50%，剩余50%底仓继续由指标系统保护 | 触发即刻 | E-92520 | 需支持分批平仓操作 |
| 持仓与跟踪 | 多单以最新抬高堆底为红线出场点；空单以最新下降堆顶为防守点 | 盘中动态 | E-92531 | 原稿未定义浮盈阈值 |
| 加减仓 | 减半后若行情重启并形成新的抬高堆底（多单），允许按规则重新接回 | 新堆形成第6K | E-92533 | 重新接回需承受额外交易成本 |
| 止盈与退出 | 收盘攻破最近堆底哪怕一跳即平仓50%；随后TRP变色或VB拐头则清空剩余50% | 破位收盘/指标反向 | E-92520 | TRP通常早变，VB通常晚变 |
| 失效与放弃 | 若开仓后直接大幅反向跳空跌穿全部指标，两阶段出场失效，直接全损退出 | 突发跳空时 | E-92518 | 需承担极端滑点风险 |

## 规则之间怎样衔接
以持仓产生的最新堆底（多头）为第一道敏感预警线，以TRP/VB系统变色为第二道趋势反转防线。收盘破堆底触发第一阶段防守（减仓50%锁定部分利润），若随后指标真正反转则清空底仓，若未反转并重新抬高堆底则可按新信号接回（E-92520、E-92531）。

## 案例和失败方式
螺纹钢9:55第6K开单后出现回调，若收盘跌破堆底则先减半，若红豆未破可保留观察（E-92531）；失败方式为盘中假跌破堆底一跳导致减半被洗出，随后行情直接暴拉产生局部“卖飞半仓”的磨损（E-92532）。

## 版本分歧与证据限制
出场规则存在全进全出（单一遵循堆底或单一遵循TRP变色）与“两头赌”（分批减半）的分歧，讲述者明确指出两种皆可，取决于交易者风险偏好，但禁止盘中无规则随意切换（E-92520、E-92532）。
