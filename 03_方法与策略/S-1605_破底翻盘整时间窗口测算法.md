# S-1605 破底翻盘整时间窗口测算法

> 来源：SRC-004688（第2003课 股票日评：收盘站上二十日线与未尽之事还有五件（20210713））· 证据 E-62866、E-62867
- 性质：局部方法
- 规则版本：v1.0
- 完整度分级：已给方向
- 效果证据：原文通过前期25周期形态推导出剩余最多横盘3天必出变盘结果，精准锁定震荡出方向的时空节点。
## 目的与适用环境
在60分钟破底翻形态错过强势立刻起涨后，通过测算前期形态时间总长度，限定震荡盘整的最大容忍窗口，指导变盘前夕的仓位进退。
## 条件与动作
| 交易环节 | 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- | :--- |
| 环境过滤 | 标的完成60分钟破底翻突破，但全天未能拉出大阳线脱离颈线，转入弱势横盘 | 60分钟级别 | [E-62862]、[E-62863] | 仅用于破底翻横盘阶段 |
| 形态或指标形成 | 测算前期形态总时长 $T_{\text{total}} = 25$ 周期（约4~6天），统计已出结构时间 $T_{\text{used}} = 8$ 周期 | 盘后计算 | [E-62866]、[E-62867] | 需准确界定形态起点与终点 |
| 确认 | 计算剩余时间 $T_{\text{remain}} = 17$ 小时（约3~4天），确立“最多横盘3天左右必出结果”的刚性时间窗口 | 计算时点 | [E-62867] | 允许提前向上或向下突破 |
| 入场 | 在盘整周期内若日线站上20日线，可严格依据个股独立买点小仓位试错 | 盘中或尾盘 | [E-62868] | 不可依赖指数带动个股 |
| 初始止损 | 盘整期间以破底翻最低底（3485）或形态颈线（3558）失守为止损点 | 盘中或收盘 | 原文未明确 | 原文未给固定止损百分比 |
| 仓位与资金 | 控制总体试错仓位，防范均线粘合后向下突破风险 | 盘整期间 | 原文未明确 | 原文未明确具体仓位限额 |
| 持仓与跟踪 | 每日监控剩余小时数，观察均线是否开始粘合及红绿柱变化 | 每日复盘 | [E-62867] | 盘整时间越长做多动能越消耗 |
| 加减仓 | 盘整在时间窗口内向上放量突破颈线时加仓；出现异动大阴线减仓 | 盘中突破时 | 原文未明确 | 需成交量配合 |
| 止盈与退出 | 横盘耗尽至第3天仍无向上突破迹象，或均线粘合选择向下突破时离场 | 第3天尾盘 | [E-62867] | 避免时间成本过高 |
| 失效与放弃 | 盘整时间超过25周期仍无方向，或提前有效跌破颈线，原破底翻结构失效放弃 | 60分钟收盘 | [E-62866] | 形态失效立即退出 |
## 规则之间怎样衔接
本方法测算的时间窗口直接与日线MACD绿柱消除倒计时（DIF差值推演）相互印证，形成多周期时间共振。
## 案例和失败方式
案例见上证指数20210713测算25周期总长与剩余3天盘整窗口[E-62866][E-62867]；失败方式为横盘至极限后直接跳空暴跌击穿所有支撑。
## 版本分歧与证据限制
原稿给出了25周期、已过8周期、剩余17小时及最多横盘3天的明确数值，属于局部时间测算工具。
