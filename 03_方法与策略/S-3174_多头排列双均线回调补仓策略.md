# S-3174 多头排列双均线回调补仓策略

> 来源：SRC-000158（专题_技术专题_几种基础补仓与止损操作策略详表（增强版））· 证据 E-73100
- 性质：局部方法
- 规则版本：讲师2022年9月18日直播授课版
- 完整度分级：已给方向
- 效果证据：讲师以手绘K线结构及中国医药实盘走势阐述多头被套救回本金的逻辑

## 目的与适用环境
交易者在多头排列行情中追高被套后，利用整体多头排列所具备的大周期趋势背书，在较快均线（如MA20）或较慢均线（如MA60）企稳反弹处实施补仓，以大幅降低回本所需的价格涨幅。· E-73100、E-73101

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线周期，均线系统维持双均线多头排列（如5与20、或20与60呈多头排列） | E-73100 | 核心前置大前提，大周期走坏的日线多头排列严禁参与 |
| 形态或指标形成 | 追高被套后价格回调，触及较快均线或较慢均线附近 | E-73100、E-73101 | 开单前必须检查乖离率，严禁在正乖离率过大处开单 |
| 确认 | 重新收盘站上较快均线（推荐）；或在较慢均线上方企稳且MACD绿柱缩短2根（较不提倡） | E-73100 | 较快均线拐头向上时可靠性更强 |
| 入场 | 收盘重新站上较快均线后，依靠较快均线开单补仓 | E-73100 | 补仓使回本价格由高位显著下拉至较慢均线与套牢点之间 |
| 初始止损 | 盘中攻破或日线收盘跌破较快均线，立即止损离场 | E-73100 | 严禁死抗，防止较快均线跌破后向较慢均线大幅回撤 |
| 仓位与资金 | 补仓资金严格小于或等于已有底仓，严禁超配资金 | E-73108 | 遵循补仓资金管理极限 |
| 持仓与跟踪 | 依靠较快均线持仓跟踪，保持多头思维持股待涨 | E-73100 | 多头排列有较慢均线拖底支撑，持仓容错度高于空头排列 |
| 加减仓 | 原稿未提供加仓设计；回撤逼近止损线时严格准备平仓 | E-73100 | 原稿缺口：未细化多头反弹中的阶梯减仓比例 |
| 止盈与退出 | 反弹拉升脱离成本区、或触及前高受阻、或再次跌破较快均线时止盈出局 | E-73100 | 原稿指出补仓成功后价格涨到半途即可实现回本出场 |
| 失效与放弃 | 较快均线与较慢均线距离过远（如相差20%）时跌破较快均线，若不止损将承受巨大回撤，策略失效 | E-73101 | 核心均线拐头向下或整体均线进入空头排列，该策略彻底废弃 |

## 规则之间怎样衔接
策略以多头大趋势为保护网；追高套牢后等待价格回调企稳，以较快均线重新收复为触发入场点；以较快均线失守为独立止损点；通过在回调低位补入等量资金，使持仓综合成本下拉至均线附近，以相对较小的反弹幅度实现扭亏为盈。· E-73100、E-73101

## 案例和失败方式
1. 回本效应案例：原单在高位追涨被套，需价格涨回最高点方可回本；在60日线附近企稳且MACD绿柱连续缩短两根后补仓，股价仅需反弹至中途即可全额回本。· E-73100
2. 典型失败方式（距离过远不止损）：较快均线（MA20）与较慢均线（MA60）差值达20%，攻破MA20时交易者未及时止损，导致价格向下寻找MA60支撑，产生20%的额外深度回撤。· E-73101

## 版本分歧与证据限制
讲师指出站在较慢均线（如MA60）开单并以MA60止损的方法并不提倡，因较慢均线难以接准K线；推荐依靠较快均线站上后开单止损。多头排列补仓整体并非本次专题核心（空头排列补仓才是核心），因多头排列只需注意操作细节即可，风险相对可控。· E-73100、E-73101
