# S-1721 集合竞价40亿门槛与四价俱弱空仓过滤法

> 来源：SRC-004735（第2046课 股票日评：打铁还需自身硬与下跌合理（20221010））· 证据 E-63295、E-63296、E-63297
- 性质：局部方法
- 规则版本：V1（20221010）
- 完整度分级：已给方向
- 效果证据：原文强调竞价32亿未到40亿门槛且四价俱弱远离5日线，执行空仓过滤可彻底避免在均线空排加速下行中抄底套牢。

## 目的与适用环境
用于开盘集合竞价量能检验及盘面强弱初筛，在量能未达标且K线四价创新低时启动绝对空仓过滤。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 早盘9:25时点 | E-63295 | 上证集合竞价结束，统计竞价成交金额 |
| 形态或指标形成 | 竞价与K线特征 | E-63295、E-63296 | 竞价金额未达到40亿门槛，且K线四价（高/开/低/收）全部向下创新低 |
| 确认 | 盘中确认 | E-63297 | 价格处于5日均线下方且加速远离5日线，定性为无做多发言权 |
| 入场 | 禁止买入入场 | E-63297 | 绝对禁止任何形式的短线抄底或多头建仓 |
| 初始止损 | 不适用 | 原文未明确 | 本方法为买入禁止过滤法，无持仓点位 |
| 仓位与资金 | 保持0仓位 | E-63297 | 维持100%现金，保持空仓观望状态 |
| 持仓与跟踪 | 每日收盘监控 | E-63297 | 观察价格何时能够收盘站上5日均线以获得初级发言权 |
| 加减仓 | 禁止加仓 | 原文未明确 | 观望期间禁止任何买入加仓操作 |
| 止盈与退出 | 不适用 | 原文未明确 | 无持仓头寸 |
| 失效与放弃 | 收盘站上5日线 | E-63297 | 唯有收盘价放量站上5日线时，方可解除空仓禁令 |

## 规则之间怎样衔接
1. 早盘9:25核验竞价成交额是否跨过40亿量能门槛；
2. 盘中核验K线四价是否创新低以及与5日线的空间距离；
3. 量不足或远离5日线，直接激活空仓过滤，封杀一切抄底冲动。

## 案例和失败方式
- 案例：2022年10月10日上证竞价32亿未达40亿，开盘后四价俱弱远离5日线，执行本法全天保持空仓。
- 失败方式：见竞价较节前翻倍便盲目入场，遭遇全天单边放量杀跌套牢。

## 版本分歧与证据限制
原稿明确给出上证集合竞价门槛为40亿元，四价创新低作为绝对极弱的直观判据。
