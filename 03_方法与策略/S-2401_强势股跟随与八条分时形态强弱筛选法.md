# S-2401 强势股跟随与八条分时形态强弱筛选法


来源：SRC-000243（妖股成妖之路_21 第337章）· 证据 E-66057, E-66058

性质：规则完整的策略
规则版本：原文未明确（未分版）
完整度分级：已给方向
效果证据：原文作者提出“实盘交易中预判永远必须服从于跟随”的交易法则，并制定八条强势股筛选准则有效指导实盘选股（E-66057, E-66058）
目的与适用环境

用于在实盘交易中顺从趋势、执行跟随策略，快速筛选真强势标的并严格回避弱势及问题股票。适用环境为股票日内分时与短线选股。

阶段	条件或动作	时点与周期	证据ID	限制或缺口
环境过滤	顺从趋势，知行合一，确立“预判永远必须服从于跟随”的交易原则	盘前与盘中	E-66057	克服主观分别心
形态或指标形成（入选条件）	四大优先入选准则：<br>1. 必须是涨停板股票，一字板更优（资金不惜涨停价排单）；<br>2. 开盘大幅拉升至少3%以上（拉升6%或10%以上更佳）；<br>3. 分时图稳步扬升、一步一个台阶不急不躁（资金持续吃货）；<br>4. 处于近期箱体上沿或突破近期箱体上沿	开盘及分时运行阶段	E-66057, E-66058	锁定强势做多资金

规则之间怎样衔接

确立跟随原则 -> 依据四大优先准则选股 -> 执行四大回避准则剔除垃圾股 -> 入场并设定止损 -> 收益达到标准后跟踪 -> 跌破最低收益标准果断止盈。

案例和失败方式
成功应用案例：精选开盘强势拉升6%以上、突破箱顶并稳步走分时台阶的涨停板，实现稳健高胜率。
失败方式：试图抄底处于下降通道、跌破箱底或数个跌停的ST问题股，导致连续亏损。
