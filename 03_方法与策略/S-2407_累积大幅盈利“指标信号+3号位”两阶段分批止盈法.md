# S-2407 累积大幅盈利“指标信号+3号位”两阶段分批止盈法


来源：SRC-000289（期货_期货投机分析20250528_多笔订单_触发止盈（增强版））· 证据 E-66093, E-66094, E-66095, E-66096, E-66105

性质：规则完整的策略
规则版本：原文未明确（未分版）
完整度分级：已给方向
效果证据：原文讲述者自述在热卷空单累积盈利超过3.24%时，采用“红K站上低多平一半、突破3号位近高连线平剩余一半”的两阶段分批止盈法，有效兼顾了防范利润回吐与避免提前卖飞单边（E-66093, E-66094, E-66095, E-66096）
目的与适用环境

用于在单边持仓累积大幅盈利（如跌幅达3%以上）后，既锁定大部分已有利润、又防范过早全部离场而卖飞后续大单边。适用环境为期货单边持仓累积大幅盈利后的利润锁定与退出阶段。

规则之间怎样衔接

累积大幅盈利 -> 出现红K站上低多平一半（保利润） -> 标定3号位两近高连线 -> 若突破3号位平剩余一半（清仓） -> 若承压回落继续持有（避免卖飞）。

案例和失败方式
成功应用案例：热卷空单盈利3.24%处，在红K站上低多时平仓50%，剩余50%防守3号位，成功兼顾锁定利润与大单边保护（E-66093, E-66096）。
失败方式：不愿在第一信号平一半导致利润全部坐过山车回吐，或在第一信号一刀切全平导致后续大单边彻底踏空。
