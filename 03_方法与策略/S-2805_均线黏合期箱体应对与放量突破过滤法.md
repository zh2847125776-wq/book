# S-2805 均线黏合期箱体应对与放量突破过滤法

> 来源：SRC-011812（第04课 均线一）· 证据 E-69431, E-69432, E-69433

## 目的与适用环境
针对均线黏合、纠结、无明显方向的市场状态，规避在震荡区间内频繁操作导致的成本抬高与心态失衡，利用箱体与放量异动确认真假突破。

## 规则之间怎样衔接
识别均线黏合 -> 停止小周期/3+频繁交易 -> 绘制箱体区间 -> 评估自身能否承受回撤：能承受则以箱体下轨防守持股，不能承受则空仓等待 -> 观察突破时的量能异动验证真突破。

## 案例和失败方式
案例失败方式：在均线黏合状态下死板使用3+技术频繁做差价，导致股价围绕20日线上下波动时“买来买去把成本做高、操作失误、影响心态”（E-69431）；或在没有量能异动的情况下盲目追突破遭遇假突破套牢（E-69432）。
