# S-2894 两分钟当日内回转策略

> 来源：SRC-000297（期货_期货投机分析20250613_原油跳空_过夜是风险最大来源（增强版））· 证据 E-70250, E-70251, E-70252, E-70253, E-70254, E-70255
- 性质：规则完整的策略
- 规则版本：两分钟周期日内回转策略（外文书籍《日内交易策略》第8~13章实操改良版）
- 完整度分级：规则完整
- 效果证据：书中原版在黄金月度交易测试中实现60.8%胜率，投入保证金盈利34.1%（挂10倍杠杆，净值3.41%）（E-70250）；实盘实操中十债多单成功盈利（E-70254），原油第二笔多单获利1.5倍且尾盘平仓规避次日跳空（E-70253），黄金空单止损亏损0.12（E-70252）。

## 目的与适用环境
旨在规避期货跨日持仓遭遇隔夜跳空与巨大波动的极端风险，利用高K线采样周期的日内微观走势获取确定性盈亏比。适用于隔夜波动大、缺口跳空频繁的品种（如黄金、原油、十债）；必须在支持2分钟自定义K线周期的交易软件（如期货通）中运行（E-70249, E-70250, E-70251, E-70254）。

## 条件与动作
| 环节 | 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- | :--- |
| 环境过滤 | 选择隔夜波动剧烈、跳空缺口多的品种；软件必须支持2分钟周期（K线数量需足够多） | 交易日开盘前或盘初，2分钟周期 | E-70250, E-70251, E-70254 | 普通同花顺无法设2分钟周期，必须使用期货通 |
| 形态或指标形成 | 首根K线定基调：开盘第1根K线为阳线初定做多，为阴线初定做空；盘中价格若创新高转为多头，创新低转为空头 | 首根K线走完及盘中破极值时，2分钟周期 | E-70252, E-70260 | 若未创新高或新低则维持原方向判定 |
| 确认 | 方向确定后，必须等待走完「两个回调K线」（做多需回调2根K线，做空需反弹2根K线） | 2根回调K线走完时，2分钟周期 | E-70252, E-70254, E-70260 | 回调K线不足2根严禁提前入场 |
| 入场 | 两个回调K线结束后，做多在价格突破前高/过高时触发开多；做空在价格跌破前低/创新低时触发开空 | 价格突破/跌破触发瞬间，2分钟周期 | E-70252, E-70254, E-70260 | 必须以突破极值点为触发条件，未突破不进场 |
| 初始止损 | 做多止损设在回调低点（净低）；做空止损设在回调高点（净高）；按固定跳数/点数设定（如黄金0.12、原油0.4、实债0.05） | 入场同时设定，2分钟周期 | E-70252, E-70253, E-70254 | 不能设为固定百分比止损，避免止损幅度过大 |
| 仓位与资金 | 资金配置挂10倍杠杆，按保证金与固定止损点数核算风险敞口 | 入场前资金规划 | E-70250, E-70254 | 原稿未提供单笔仓位占总资金的具体百分比规则 |
| 持仓与跟踪 | 调出软件多空盈亏线工具直观监控盈亏比，无反向触发且未触及止损止盈时持续持有 | 持仓全程，2分钟周期 | E-70252, E-70253 | 必须盘中盯盘，不可漏看行情 |
| 加减仓 | 原稿未提供该策略日内加仓或减仓规则，单笔独立运作 | 持仓期间 | 原稿未明确 | 原稿完全缺失加减仓规则 |
| 止盈与退出 | 止盈目标设定为初始止损距离的1.5倍（盈亏比1:1.5）；无论盈亏尾盘必须全部平仓，绝不过夜 | 触及目标价或尾盘收盘前 | E-70252, E-70253, E-70254 | 严格执行1:1.5盈亏比，尾盘无条件平仓 |
| 失效与放弃 | 每日交易频次严格限制在1到2笔；若临近收盘（如下午14:55）即便触发下单信号亦坚决放弃不开单 | 尾盘临收盘时段，2分钟周期 | E-70254, E-70255 | 尾盘时间不足以走完盈亏比，强行开单失效 |

## 规则之间怎样衔接
开盘首根K线定方向 -> 盘中根据新高/新低动态修正方向 -> 必须等待2根回调K线形成结构过滤 -> 突破极值点触发入场 -> 同步挂出净高/净低止损与1.5倍止盈线 -> 触及目标止盈或触及止损离场 -> 若临近收盘（14:55）直接放弃 -> 尾盘强制平仓清空仓位，杜绝隔夜风险。

## 案例和失败方式
- 成功案例：十债做多止损0.05，盈利0.075/0.08成功退出（E-70254）；原油第二笔创高后做多，止损0.4，盈利1.5倍，尾盘平仓离场（E-70253）。
- 失败方式：黄金空单触发后反向运行触及0.12止损（E-70252）；原油第一笔创新低做空触发止损（E-70253）；十债下午14:55触发做空因无持仓时间而主动放弃不开单（E-70255）。

## 版本分歧与证据限制
该策略源自外文书《日内交易策略》第8~13章，书中统计胜率约60.8%，讲述者在期货实操中要求采用2分钟高采样周期；因普通行情软件无法设置2分钟周期，必须使用期货通；原稿未提供加减仓与总资金仓位配比规则，且原稿明确强调每日仅限1~2笔，不可过度频繁交易。
