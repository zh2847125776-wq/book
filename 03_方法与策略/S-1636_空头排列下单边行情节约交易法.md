# S-1636 空头排列下单边行情节约交易法

> 来源：SRC-004699（第2013课 股票日评：五日线压制与技术指标钝化（20210730））· 证据 E-62970, E-62971
- 性质：局部方法
- 规则版本：V1.0
- 完整度分级：已给方向
- 效果证据：在C浪延展杀跌与均线空头排列下，放弃所有繁琐的支撑压力线测算，只看每日收盘能否站上5日线，以极简规则过滤一切噪音。

## 目的与适用环境
在均线发散空头排列与大级别C浪延展杀跌的单边行情中，极简化交易决策系统，避免因频繁计算支撑阻力而产生逆势抄底冲动。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| **环境过滤** | 均线系统处于刚发散的空头排列结构，大级别波浪呈现C浪延展杀跌特征（3312远非底部） | 日线 / 周线 | E-62970 | 单边空头市场 |
| **形态或指标形成** | 价格处于单边下行通道中，向下运行的5日均线无法提供任何支撑，且上方20日线距离过远 | 日线 | E-62971 | 趋势斜率吞噬空间 |
| **确认** | 执行规则节约法：在单边下行途中，彻底放弃计算向上的压力线与向下的支撑线 | 每日盘前 | E-62971 | 算支撑压力无意义 |
| **入场** | 唯一入场/转折前置观察项：仅当收盘价有效站上5日均线时，才开始评估右侧信号 | 每日收盘前 | E-62971 | 未站上5日线前绝对不买 |
| **初始止损** | 若有任何试探仓位，收盘未能站稳5日线即刻清仓止损 | 收盘 / 即时 | E-62971 | 严防单边阴跌 |
| **仓位与资金** | 维持0%空仓，不持有任何多单，杜绝“死扛解套”思想 | 持续 | E-62970 | 不低估空头杀跌决心 |
| **持仓与跟踪** | 每日仅需核对一个数据：当日收盘价与向下5日均线的相对高低位置 | 每日15:00收盘 | E-62971 | 极简跟踪 |
| **加减仓** | 处于空仓跟踪期，无加减仓操作 | 持续 | E-62971 | 杜绝逆势补仓 |
| **止盈与退出** | 处于空仓状态，无止盈操作 | 持续 | E-62971 | 观望为主 |
| **失效与放弃** | 当价格放量站上5日线并带动5日线拐头向上，单边压制状态结束，转入震荡或筑底规则 | 日线 / 站稳时 | E-62971 | 规则动态切换 |

## 规则之间怎样衔接
确立空头排列与C浪延展 -> 屏蔽所有支撑压力计算 -> 锁定唯一观测指标（收盘能否站上5日线） -> 未站上则持续空仓 -> 站上后再行评估。

## 案例和失败方式
案例：20210730上证处于空头排列单边下行，讲述者指出压力支撑完全不用看，每天只看收盘能不能站上5日线；失败方式：在单边空头排列中不断寻找虚假支撑位加仓抄底，越套越深。

## 版本分歧与证据限制
该方法属于单边极弱市下的极简过滤法；当行情进入宽幅震荡或底部箱体后，需重新启用箱体与黄金分割测算工具。
