# S-2911 期货当日回转2K回调突破交易策略

> 来源：SRC-000299（期货_期货投机分析20250618_当日回转订单白天表现突出_夜盘稍有回撤_总体优秀（增强版））· 证据 E-70379, E-70380, E-70382, E-70383
- 性质：规则完整的策略
- 规则版本：20250618版当日回转规则
- 完整度分级：已给方向
- 效果证据：2025年6月17日实盘统计白天盈利13%（结合杠杆），全天盈利12%至13%，日内胜率约为55% · 证据 E-70398

## 目的与适用环境
用于期货大夜盘高波动品种的日内超短线回转交易，捕捉开盘后经充分回调再度创出极值的单边动量，不隔夜持仓。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 必须为大夜盘、高波动期货品种，排除螺纹钢、热卷、玉米 | 日内开盘前 | 证据 E-70379 | 小夜盘与低波动品种严禁操作 |
| 形态或指标形成 | 开盘首K确定方向，价格顺势创新极值后，必须出现至少连续2根及以上K线的回调（回调1、回调2...），严禁采纳单根K线（回调一）入场 | 2分钟周期盘中 | 证据 E-70382, E-70383 | 单K回调可靠性极低，讲述者实测否定 |
| 确认 | 回调过程中未跌破/升破关键结构，随后价格再度向原方向启动逼近前极值点 | 2分钟周期盘中 | 证据 E-70383 | 回调超过2根K线后等待创极值触发 |
| 入场 | 价格突破回调前的前期最高点（多头）或前期最低点（空头）时立即触发开仓 | 突破瞬间（2分钟周期） | 证据 E-70383, E-70397 | 实际挂单需在突破价位顺势往外放一跳 |
| 初始止损 | 止损价设定在最近波段极值点，且该点必须满足前方至少4-5根K线未破极值的“5K法则”；无回调时参考开盘极值 | 入场成立同时 | 证据 E-70380, E-70381, E-70392 | 极值不足4根K线禁止使用该点止损；止损空间过大则放弃交易 |
| 仓位与资金 | 投入账户部分保证金（例如50万资金投入10万保证金），杠杆根据品种配置，高相关品种同现多空时均分配资金入场 | 建仓时点 | 证据 E-70386 | 原稿未明确具体杠杆倍数与单笔保证金百分比公式 |
| 持仓与跟踪 | 持仓过程中不随波逐流主观调动止损，若价格未创新低/新高则保持原多空计划 | 持仓全程 | 证据 E-70396 | 若未触及止盈止损则耐心持有 |
| 加减仓 | 原稿未明确日内加仓或减仓规则，单笔订单一次性建仓与清仓 | 无 | 原文未明确 | 原稿无加减仓动作记录 |
| 止盈与退出 | 止盈目标位按初始止损风险空间的 1:1.5 固定比例向外延展设置；若至品种收盘时（如沪镍夜盘1点）未触发止盈止损，则于收盘前强制市价平仓离场，空仓过夜 | 触及1.5倍目标位或收盘前时点 | 证据 E-70383, E-70390 | 严禁持仓过夜 |
| 失效与放弃 | 回调中价格直接跌破/升破反向极值反转；或突破时止损空间过大（如原油止损达1.17%）无法承受时，放弃该笔交易 | 盘中触发前 | 证据 E-70394, E-70395 | 止损无法依照5K法则锚定时放弃 |

## 规则之间怎样衔接
首先通过品种大夜盘高波动过滤池进入监控；开盘首K确认日内主基调；价格走出行情并产生≥2根K线回调；回调完成后以突破点顺势放一跳挂单；入场同时依据5K法则设定止损，并按照 1:1.5 设置止盈单；若遇品种收盘则强制市价平仓。

## 案例和失败方式
- 成功案例：沪镍夜盘空单突破进场，持有至凌晨1点平仓获利0.27% · 证据 E-70390；原油次笔多单符合5K止损获利1.1% · 证据 E-70394
- 失败方式：黄金首笔多单无回调强行追高遭损0.15% · 证据 E-70392；原油首笔多单止损点不符合5K法则遭损 · 证据 E-70394；白银多单突破后动能衰竭未创新高遭损0.39% · 证据 E-70396；全天胜率仅约55% · 证据 E-70398

## 版本分歧与证据限制
原稿提到“他书里说回调一也能做”，讲述者明确反驳“咱不做啊 我试了试 可靠性非常低 我们还是要回调二啊”，严格确立2K回调规则；止损若不足5根K线，4根为底线，3根严禁执行。
