# S-1734 弱势反弹终结判定与平仓清算规范

> 来源：SRC-004744（第2054课 股票日评：低开不意外与反弹也合理（20221020））· 证据 E-63340, E-63341
- 性质：局部方法
- 规则版本：原稿初版
- 完整度分级：规则完整的策略
- 效果证据：自10月12日2275点建仓至10月20日宣告反弹正式结束，完整历时5个交易日，锁定全程反弹利润，并在收盘无法站上5日线时全线清仓。

## 目的与适用环境
在超跌弱市反弹行进到第5个交易日、时空目标兑现后，确立反弹行情正式宣告终结的客观判据，并强制清空所有补仓多头头寸。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 均线系统大格局维持空头排列，弱势反弹已持续约5个交易日 | E-63340, E-63341 | 明确为反弹性质 |
| 形态或指标形成 | 价格到达预设阻力区（2480点附近差11点），时间达到4~5天见高点窗口（36周期）；集合竞价萎缩至7.28亿，首小时量能降至686，成交量不足以支撑站上均线 | E-63340 | 时空量全部衰竭 |
| 确认 | 盘中跳空低开跌破关键分时支撑（如2441/2411），且全天弱势震荡，日线收盘价确凿无法站上5日均线（MA5） | E-63340, E-63341 | 收盘站不上5日线为硬核确认 |
| 入场 | 禁止任何新开多单，严禁将盘中反抽5日线的动作当作买点 | E-63340 | 盘中接近5日线是卖点非买点 |
| 初始止损 | 本策略为持仓清算，不涉及新单止损 | E-63341 | 终止反弹操作 |
| 仓位与资金 | 此前持有的创业板指数ETF或创业板50ETF补仓仓位全部出清，账户仓位降至0%（回归完全空仓） | E-63341 | 彻底平掉补仓仓位 |
| 持仓与跟踪 | 盘中若有反抽靠近5日线的机会，属于主力诱多或最后的离场窗口，必须坚决执行抛出 | E-63340 | 逢反抽清仓 |
| 加减仓 | 严禁在20日均线处加仓（空间小、20线走平效果差，不值得冒风险） | E-63344 | 明确禁止20线加仓 |
| 止盈与退出 | 当日收盘站不上5日均线瞬间，正式宣布反弹行情终结，所有遗留持仓必须在收盘前或次日早盘彻底平掉 | E-63341 | 正式宣告反弹结束 |
| 失效与放弃 | 宣布反弹结束后，后市无论涨跌均不参与，耐心等待大级别契机出现 | E-63341, E-63345 | 回归空仓观望 |

## 规则之间怎样衔接
作为2275点突破补仓策略（S-1727）的终点收口动作，与前课“调低敏感性”（K-30326）及“5日线裁判法则”（S-1730）完成全周期闭环。

## 案例和失败方式
- 案例：2022年10月20日创业板指收盘确凿站不上5日线，讲师在收盘后正式宣布反弹行情完结，提示所有持仓者将创业板ETF补仓仓位全部平仓（E-63341）。
- 失败方式：收盘跌破5日线后仍抱有侥幸心理，幻想后续回测20日均线加仓，最终遭遇倒鸭嘴加速暴跌，波段盈利全部吐回。

## 版本分歧与证据限制
原稿明确指出本次反弹从盘中喊单建仓到正式宣告结束“一共就持有了五天”，是一笔定义极其严格的日历波段。
