# S-1737 破位下反回测日内脉冲诱多鉴别与空仓防守法

> 来源：SRC-004747（第2057课 股票日评：技术反弹与切勿上当（20221025））· 证据 E-63350, E-63352
- 性质：局部方法
- 规则版本：原稿初版
- 完整度分级：规则完整的策略
- 效果证据：成功过滤了盘中两次急跌超2%又大幅拉回平盘的剧烈日内诱多波动，杜绝了交易者盲目抄底被套的风险。

## 目的与适用环境
在指数收盘破位后次日出现急跌急拉的剧烈分时反弹中，指导交易者识破技术反弹陷阱，坚决克制冲动、维持空仓。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线破位次日展开下反回测，20日线向下压制，大级别空头排列 | E-63350, E-63351 | 破位下反回测环境 |
| 形态或指标形成 | 盘中出现两次大幅跳水（最低跌幅达2%及2.4%），随后迅速强行拉回至平盘附近；外盘关联品种（如恒生科技）盘中大跌后拉红扰动情绪 | E-63352 | 剧烈分时震荡与外盘假象 |
| 确认 | 盘中最低点已经击穿日线MACD红柱基准价格（2314点），且最高点（2344点）受阻于20日均线（2348点），三条件破产 | E-63350, E-63351 | 确认为纯粹技术反弹 |
| 入场 | 一票否决：严禁买入开仓，严禁跟随盘中拉升抢反弹 | E-63352 | 切勿上当受骗 |
| 初始止损 | 不涉及新单止损 | E-63352 | 全程维持空仓 |
| 仓位与资金 | 账户保持0%仓位，继续维持完全空仓观望 | E-63354 | 严格空仓纪律 |
| 持仓与跟踪 | 不受盘中脉冲拉升及外盘拉红的情绪影响，坚持“只看自己内生结构，不看邻居拆迁” | E-63352 | 屏蔽外盘干扰 |
| 加减仓 | 严禁任何形式的开仓或试仓 | E-63352 | 杜绝手痒 |
| 止盈与退出 | 若有前日未出多单，逢盘中拉回平盘或贴近20线（2344点）必须坚决清仓退出 | E-63351, E-63352 | 借脉冲出逃 |
| 失效与放弃 | 坚守空仓，直至大级别出现“两个支点”的双底结构及人民币升值契机才考虑重新入场 | E-63354 | 耐心等待大级别结构 |

## 规则之间怎样衔接
与三条件模型（K-30336）及观后整理模型（K-30338）配套，作为防范虚假反抽的操作准则。

## 案例和失败方式
- 案例：2022年10月25日创业板指早盘跳水2%后拉平、再跳水2.4%后又拉平，同时恒生科技拉红诱多；讲师严厉提示切勿上当，判定为纯粹技术反弹，坚决要求保持空仓（E-63352）。
- 失败方式：将分时拉回平盘误认为V型反转进场做多，次日遭遇绿柱一与均线死叉共振暴跌，被直接套死在反抽高点。

## 版本分歧与证据限制
原稿指出此类盘中脉冲拉升仅有个别超短线交易者博弈次日绿柱兑现，但对绝大多数交易者而言属于极高风险陷阱，严禁参与。
