# S-3331 破翻结构反向确认入场与近高止损策略

> 来源：SRC-000357（期货_期货投机分析20251028（增强版））· 证据 E-74777, E-74778
- 性质：局部方法
- 规则版本：原稿未明确
- 完整度分级：已给方向
- 效果证据：焦煤空单在破翻与MVB冲上冲突时等待阴线确认入场，止损1271未被触发，后走出下跌常态且MVB冲下加仓盈利。(E-74778)

## 目的与适用环境
用于顶部出现破翻结构但辅助指标（如MVB）尚未背离或处于逆向冲上状态时的安全做空过滤与入场执行。(E-74777, E-74778)

## 条件与动作
| 环节 | 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- | :--- |
| 环境过滤 | 盘面出现破翻形态，但MVB仍冲上无背离，指标与形态发生方向冲突 | 结构出现初期 | E-74777 | 指标与形态矛盾时审慎评估 |
| 形态或指标形成 | 盘中确认破翻结构完成 | 破翻形成时 | E-74777 | 破翻为做空触发原形 |
| 确认 | 破翻发出时若当前K线为阳线，严禁盲目开空；必须耐心等待K线收出阴线变色确认 | 盘中K线收盘 | E-74777 | 阳线坚决不逆势抢空 |
| 入场 | 阴线收盘确认后（或下一根K线开盘）立即执行空单入场 | 阴线确认时点 | E-74778 | 严格在确认后下单 |
| 初始止损 | 止损位固定设于破翻结构上方的前期关键近高价格（如1271），不可随意变动 | 下单同时设定 | E-74778 | 严格以结构高点为硬止损界限 |
| 仓位与资金 | 建立初始单笔试仓仓位 | 开仓时点 | E-74778 | 原稿未载明具体的仓位百分比 |

| 加减仓 | 价格持续下行过程中，若MVB指标由冲上转为冲下，触发顺势加仓指令 | MVB冲下时 | E-74778 | 形成顺势加仓点 |
| 止盈与退出 | 出场方式自主选择：出现反向结构出场、IVB拐头出场、或VB上穿出场 | 利润兑现期 | E-74778 | 给出多重退出选项 |
| 失效与放弃 | 若开仓后价格直接向上突破近高止损位（如1271），策略失效，立即止损放弃 | 扫损时点 | E-74778 | 止损未触发则坚决持仓 |

## 规则之间怎样衔接
破翻结构提供潜在做空信号 -> 阴线变色提供入场过滤器 -> 近高锁定硬止损 -> 下跌常态与MVB冲下提供加仓衔接 -> 反向结构或指标拐头提供退出闭环。(E-74777, E-74778)

## 案例和失败方式
焦煤空单在破翻为阳线时未轻举妄动，耐心等到21:45阴线开单，止损1271未碰，后走出顺畅下跌常态；若在阳线抢跑则易被假破翻直接扫损出局。(E-74777, E-74778)

## 版本分歧与证据限制
原稿强调形态与指标犯冲时，K线颜色确认为核心过滤判据，不可单凭破翻形态单独下单。(E-74777)
