# S-1631 底部破翻与破底翻双买点阶梯交易法

> 来源：SRC-004698（第2012课 股票日评：一日缩量止跌与3312肯定要破（20210728））· 证据 E-62953, E-62957, E-62958, E-62961
- 性质：规则完整的策略
- 规则版本：V1.0
- 完整度分级：已给方向
- 效果证据：20210728上证探至3312点，因小周期连底背离都不具备，严格判定未达进场条件，成功规避后续进一步破位风险。

## 目的与适用环境
在市场经历单边大幅杀跌后，规范从左侧底背离确认到右侧破翻、破底翻的双阶梯买入与止损纪律，杜绝盲目接飞刀。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| **环境过滤** | 市场经历单边大幅杀跌，必须完成“放量不会止跌，缩量才能止跌”的量能初筛 | 日线 / 盘中 | E-62953 | 放量阴跌期严禁进场 |
| **形态或指标形成** | 5分、15分、30分、60分多周期自下而上依次形成底背离结构，价格创新低而指标不创新低 | 多周期 / 盘中 | E-62958 | 小周期无底背离则日线不成立 |
| **确认** | 收盘价有效站上向下运行的5日均线，且5日线出现走平拐头迹象 | 日线 / 收盘 | E-62957 | 站上5日线为右侧确认标志 |
| **入场** | 第一买点：破翻结构成立时介入第一批仓位；第二买点：破底翻结构成立时介入第二批仓位 | 日线或60分 / 确认时 | E-62957 | 分批进场，严禁一次性满仓 |
| **初始止损** | 第一买点止损设在“跌破前低”；第二买点止损设在“跌破前高” | 进场即刻 | E-62957 | 止损位明确客观，破位坚决执行 |
| **仓位与资金** | 第一买点轻仓试探，第二买点确认后再行加码 | 建仓期 | E-62957 | 具体分配比例原文未明确 |
| **持仓与跟踪** | 跟踪5日线与向上均线支撑，观测成交量是否持续放大 | 每日收盘 | E-62961 | 强势反弹必须依赖放量 |
| **加减仓** | 只有在第一买点盈利且形成第二买点（破底翻）时方可加仓 | 突破前高时 | E-62957 | 严禁逆势摊平浮亏 |
| **止盈与退出** | 触及上方关键阻力位（如60日线）或指标出现顶背离分批止盈 | 盘中或收盘 | E-62961 | 原文未明确具体止盈比例 |
| **失效与放弃** | 跌破前期低点或小周期底背离被暴力击穿，立即止损放弃 | 实时 / 破位 | E-62957 | 破前低无条件止损 |

## 规则之间怎样衔接
缩量初筛 -> 多周期逐级底背离 -> 站上5日线 -> 破翻第一买点（止损前低） -> 破底翻第二买点（止损前高） -> 跟踪放量反弹。

## 案例和失败方式
案例：20210728上证打到3312，因60分钟无底背离，双买点均未触发，按规观望；失败方式：在无底背离和未站上5日线前抢跑抄底，破前低不执行止损导致深套。

## 版本分歧与证据限制
破翻与破底翻的具体K线形态参数在日评中直接作为标准术语应用；仓位加码系数依独立风控策略执行。
