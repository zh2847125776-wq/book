# S-2373 基于RSI趋势线与形态突破破位买卖策略

> 来源：SRC-000018（P1_第四节课（增强版））· 证据 E-65884, 证据未逐字回源
- 性质：规则完整的策略
- 规则版本：RSI形态与趋势线过滤交易架构版
- 完整度分级：已给方向
- 效果证据：在K线无法准确画出趋势线时，利用RSI指标准确绘制趋势线并指导突破买入与破位止损（E-65884, 证据未逐字回源）。

## 目的与适用环境
用于在K线波动中无法明显看出形态变化或无法准确画出传统趋势线时，利用RSI指标精准判断上升趋势线、下降压力线、颈线及前高前低，指导买卖、止损与纠错接回。

## 规则之间怎样衔接
RSI画线定位结构 -> 突破趋势线/颈线入场 -> 收盘破线止损 -> 重新站回纠错接回 -> 触及阻力或破上升趋势线卖出。

## 案例和失败方式
小时间级别频繁假破位导致磨损，解决方式为升格操作级别（证据未逐字回源）。
