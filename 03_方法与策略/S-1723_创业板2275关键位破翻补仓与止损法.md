# S-1723 创业板2275关键位破翻补仓与止损法

> 来源：SRC-004736（第2047课 股票日评：危机并存与一个点位最为关键（20221011））· 证据 E-63307、E-63308
- 性质：规则完整的策略
- 规则版本：V1（20221011）
- 完整度分级：已给方向
- 效果证据：原文给出2275作为9月23日盘中最低价与破翻基准位，被套者在破翻/破底翻/站上5日线补仓并以2275或1%止损，可实现主动自救。

## 目的与适用环境
仅适用于持有创业板指数ETF或创业板50ETF被深度套牢的交易者，在关键破翻位（2275点）实施规范化补仓自救与风控（空仓者禁止参与）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线周期 | E-63307 | 处于创业板被深套背景，锁定2275点（9月23日盘中最低价）为基准 |
| 形态或指标形成 | 盘中或收盘突破 | E-63307、E-63308 | 价格向上突破2275点形成破翻，或进一步形成破底翻，或收盘站上5日均线 |
| 确认 | 结构确认 | E-63308 | 确认出现“破翻 / 破底翻 / 站上5日线”三类补仓有效信号之一 |
| 入场 | 深套者补仓入场 | E-63308 | 深套者针对创业板ETF进行补仓；空仓者及无持仓者严禁参与 |
| 初始止损 | 破翻位/创新低/1% | E-63308 | 止损三选一：破翻位跌破止损、创新低止损、或盘中攻破1%敏感止损 |

| 持仓与跟踪 | 5日线跟踪 | E-63308 | 跟踪5日均线支撑，若站上5日线后再度漏掉5日线立即止损 |

| 失效与放弃 | 跌破止损位 | E-63308 | 补仓后若价格击穿2275破翻位或创新低，补仓头寸立即止损认错 |

## 规则之间怎样衔接
1. 盯住2275关键破翻位；
2. 突破2275形成破翻、破底翻或站上5日线时执行补仓；
3. 设置严格的2275破翻位或1%止损线，严防破翻失败导致亏损扩大。

## 案例和失败方式
- 案例：2022年10月11日创业板反弹至2273点受阻于2275点，讲述者明确指出需等待突破2275形成破翻才放行补仓。
- 失败方式：在2275下方左侧抢跑补仓，或突破2275补仓后跌破止损线死扛不割。

## 版本分歧与证据限制
原稿明确强调“该机会是给被深套的人准备的自救机会”，空仓者不值得冒险参与；止损标准提供破翻位、新低或1%三种口径。
