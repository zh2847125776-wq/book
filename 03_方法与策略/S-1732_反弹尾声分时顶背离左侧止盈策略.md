# S-1732 反弹尾声分时顶背离左侧止盈策略

> 来源：SRC-004742（第2052课 股票日评：目标价迫近与左侧止盈信号（20221018））· 证据 E-63332, E-63334
- 性质：局部方法
- 规则版本：原稿初版
- 完整度分级：规则完整的策略
- 效果证据：在日线反弹空间被压缩至不足0.5%的极值区域，精准捕捉分时衰竭点，帮助持仓者锁定7%以上的反弹收益。

## 目的与适用环境
在反弹空间消耗殆尽（已走完三分之二以上路程）、时空目标双重迫近的环境下，利用60分钟周期顶背离与指标缩短，实施微观层面的左侧精确止盈。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线级别反弹逼近2480点目标位，剩余理论空间不足1%，且时间已达第36个周期窗口 | E-63332, E-63333 | 空间极度受限 |
| 形态或指标形成 | 60分钟周期价格创出新高（上冲至2441点上方），但指标未创新高，形成明确的顶背离结构 | E-63334 | 股价新高而指标不新高 |
| 确认 | 60分钟MACD红柱连续出现1~2根柱体缩短，KDJ指标处于高位钝化并转头向下 | E-63334 | 红柱缩短1至2个确认 |
| 入场 | 此前低位建仓多单（如2275点开仓）的退出操作，此处绝对禁止新开多单 | E-63332, E-63334 | 严禁空仓者买入 |
| 初始止损 | 本策略为持仓止盈，不涉及新单止损 | E-63332 | 属于平仓策略 |
| 仓位与资金 | 保守者执行100%全额清仓；中间派执行50%减仓 | E-63332 | 依据风险偏好分类执行 |
| 持仓与跟踪 | 卖出时机选择在盘中或尾盘价格越贴近高点时执行，此时卖出点与最高点差值极小 | E-63334 | 贴近高点抛出 |
| 加减仓 | 不涉及顺势加仓；若保留50%底仓，则转入5日线跟踪状态 | E-63332 | 剩余头寸跟踪5日线 |
| 止盈与退出 | 当日盘中分时触发顶背离且红柱连缩两根，保守者直接清仓出局；若次日盘中有效打漏60分钟关键支撑位2411点，剩余头寸无条件清仓 | E-63332, E-63334 | 2411打漏测多空线 |
| 失效与放弃 | 若卖出后行情出现极端超预期单边暴拉，恪守“合理操作”心法，严禁盘中反手追高 | E-63334, E-63335 | 放弃鱼尾行情 |

## 规则之间怎样衔接
作为低位破翻买入策略（S-1727）与四象图跟踪（K-30322）的终极落地执行方案，配合三类交易者模型完成闭环。

## 案例和失败方式
- 案例：2022年10月18日创业板指60分钟在2441点上方形成顶背离，红柱连续缩短，讲师提示尾盘越贴近高点越可卖出，保守者全抛锁定7.43%收益（E-63332, E-63334）。
- 失败方式：在顶背离出现后犹豫不决未卖出，随后指数跌破2411点并跌漏5日均线，导致利润大幅回撤。

## 版本分歧与证据限制
原稿指出分时止盈与日线最终价格相差无几，但能大幅降低心理煎熬，属于典型的调低敏感性工具。
