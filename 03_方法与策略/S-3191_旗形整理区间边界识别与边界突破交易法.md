# S-3191 旗形整理区间边界识别与边界突破交易法

> 来源：SRC-000336（期货_期货投机分析20250901_趋势尚未突破_耐心做好每一笔交易）· 证据 E-73307, E-73308, E-73309
- 性质：局部方法
- 规则版本：未明确
- 完整度分级：已给方向
- 效果证据：沪锌日线震荡区间振幅缩小打不出去；纸浆上飘旗形贴近红豆有多单机会。

## 目的与适用环境
用于期货日线或大周期形成通道型旗形整理时，界定高低波段边界并制定低吸高抛或突破跟随交易预案（证据 E-73307, E-73308）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线周期 | E-73307, E-73308 | 价格经历前期趋势后进入箱体或通道收敛，大周期振幅明显收窄；若临近大周期区间上限则严禁在低周期追多 |
| 形态或指标形成 | 日线图 | E-73307 | 通道下限与上限需至少有符合5K法则的波段触点，允许少量误差未完全触及；若多个连续波段点均不符合5K法则，则形态画线无效 |
| 确认 | 日线/小时线 | E-73309 | 通道走势可分为标准下飘旗形与异化上飘旗形，根据原趋势方向评估突破概率；上飘旗形形态难看，向上突破概率存疑 |
| 入场 | 小周期触发 | E-73308, E-73309 | 思路一：价格偏近下限支撑附近，在5分钟小周期寻找做多机会；思路二：价格实体放量突破下限顺势开空，或突破上限顺势开多；不可在通道正中无支撑阻力处盲目建仓 |
| 初始止损 | 入场即设 | E-73308 | 下限做多止损设于下限或前低外侧；突破开仓止损设于破位K线内侧；必须防范假突破快速收回 |
| 仓位与资金 | 开仓时 | E-73308 | 原稿未明确具体仓位比例与杠杆倍数 |
| 持仓与跟踪 | 持仓期 | E-73308 | 下限持有多单跟踪目标极限看至区间上限，日线顶在上限附近时必须保持警惕；小周期K线实体过小无法走出趋势时耐心等待 |
| 加减仓 | 边界位置 | E-73308 | 下限多单达到上限附近减仓，或突破形态边界后顺势加仓；原稿未明确具体加仓倍数 |
| 止盈与退出 | 触及上限时 | E-73308 | 小周期多单触及旗形上限平仓，或反向击穿边界止损离场；原稿未给固定盈亏比点位 |
| 失效与放弃 | 破位后反抽 | E-73308 | 若跌破下限一点点与前低形成SFP并迅速捞起突破上限，属于旗形整理失败形态，原空单立即止损翻多；严禁在SFP假突破处死抗空单 |

## 规则之间怎样衔接
5K法则确立触点 → 连线构成上下限通道 → 下限结合低周期信号做多 → 上限止盈或突破顺势开仓 → SFP假突破止损翻转（证据 E-73307, E-73308）。

## 案例和失败方式
案例：沪锌主连日线形成旗形整理，下限触点符合5K法则，上限有轻微误差（证据 E-73307）。
失败方式：旗形下限跌破一点点形成SFP，诱空后急速拉升突破上限（证据 E-73308）。

## 版本分歧与证据限制
常规教科书旗形为顺趋势方向反向飘移（如下飘旗形），原稿指出纸浆出现反向的上飘旗形；原稿未明确旗形通道宽度的绝对阈值（证据 E-73307, E-73309）。
