# S-2174 20对60金叉打漏均线与死叉逃命执行策略

> 来源：SRC-004946（第2236课 股票日评：交叉共振的正常调整维持在ma60上方即可（20230807））· 证据 E-64991, E-64994
- 性质：局部方法
- 规则版本：原稿初版
- 完整度分级：规则完整的策略
- 效果证据：在指数经历极端利空深度打漏60日均线时，以20对60死叉作为最终裁判，为持仓者提供了兼顾洗盘容错与“先测向上再测向下”的完整逃命通道。

## 目的与适用环境
在均线系统已经发生20穿60黄金交叉的大背景下，应对价格跌破60日均线时的防守与识别；区分虚假洗盘跌破与真正趋势恶化，并执行标准化逃命清仓。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线周期，20日均线与60日均线已形成黄金交叉，整体多头环境初建 | E-64991 | 金叉后回调阶段 |
| 形态或指标形成 | 价格受短线利空或剧烈调整打压，向下回落不仅打到60日线，甚至盘中或收盘打漏60日均线 | E-64991 | 均线被有效刺破 |
| 确认 | 观察20日均线与60日均线的相对关系：两条均线是否发生再次死叉 | E-64991, E-64994 | 死叉为硬性破产信号 |
| 入场 | 此前已买入多头仓位的持仓跟踪阶段，此处禁止开新仓；若空仓者，需等待指数回踩60线企稳或重新站上20日线后再做买入 | E-64994 | 破线期禁止开新仓 |
| 初始止损 | 沿用个股设定的技术止损点 | E-64994 | 个股触发止损必须损 |
| 仓位与资金 | 维持既有持仓；若个股触发自身止损，立即减仓出局且不再买新股票 | E-64994 | 严格执行指数止损 |
| 持仓与跟踪 | 只要20日均线未向下跌穿60日均线形成死叉，允许价格在60日线附近震荡，等待其重新站回20日线 | E-64991 | 金叉未死不盲目平仓 |
| 加减仓 | 在均线未死叉且价格站回20日线前，严禁逆势加仓 | E-64994 | 禁止左侧加仓 |
| 止盈与退出 | 若价格打漏60日线后，20日线正式向下跌穿60日线形成死亡交叉，宣告突破彻底失败；必须利用指数“先测向上、再测向下”的反抽动作，果断清仓逃命 | E-64994 | 出现死叉立刻逃命 |
| 失效与放弃 | 一旦死叉确认且逃命清仓完毕，全面回归空仓，等待市场彻底调整完毕并重新站上20日线 | E-64994 | 全面放弃多头持仓 |

## 规则之间怎样衔接
承接金叉买入策略（S-2172），将均线容差口诀（K-30978）转化为遭遇极端破位时的清仓逃命执行案。

## 案例和失败方式
- 案例：2023年8月7日讲师讲解极端行情推演：即使价格极端回落打漏60日线，只要20与60不形成死叉就仍属正常；若20对60死叉确认，则利用先测向上的反抽全面逃命（E-64994）。
- 失败方式：在20对60死叉形成后心存幻想，未在反抽阶段执行逃命清仓，导致在后续主跌浪中遭受深幅套牢。

## 版本分歧与证据限制
原稿指出指数环境极具规律性，“先测向上、再测向下”为死叉后的经典走法，右侧死叉信号清晰明确，不可迟疑。
