# S-1722 指标钝化期左侧交易封杀与观望法

> 来源：SRC-004735（第2046课 股票日评：打铁还需自身硬与下跌合理（20221010））· 证据 E-63298、E-63299
- 性质：局部方法
- 规则版本：V1（20221010）
- 完整度分级：已给方向
- 效果证据：原文明确指出钝化8到9天不意味着不跌、背离还可以同向运行，封杀左侧交易可避免在指标无指示作用时试错割肉。

## 目的与适用环境
在震荡技术指标（如MACD）进入日线底部长时间钝化状态时，全面封杀左侧猜底交易，保持绝对观望。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线周期 | E-63298 | 市场处于单边下跌大趋势，技术指标进入超跌区域 |
| 形态或指标形成 | 钝化状态识别 | E-63298 | 指标数值变动微小，在底部钝化持续8至9天，既未金叉亦未明显收敛 |
| 确认 | 事实发生即确认 | E-63298 | 定性为“指标钝化无法提供参考”，背离不构成买入理由 |
| 入场 | 禁止左侧入场 | E-63299 | 严禁抱侥幸心理进行“试一试收敛、向下再止损”的左侧交易 |
| 初始止损 | 不适用 | 原文未明确 | 属于入场禁止规则，无开仓头寸 |
| 仓位与资金 | 0仓位（完全空仓） | E-63299 | 保持现金状态，防范钝化中行情继续向下击穿 |

| 加减仓 | 禁止补仓 | E-63299 | 严禁在钝化期越跌越买金字塔加仓 |
| 止盈与退出 | 不适用 | 原文未明确 | 无持仓头寸 |
| 失效与放弃 | 右侧指标放量解除 | E-63299 | 当行情放量突破核心均线并带动指标向上解除钝化时，方可按右侧规则评估 |

## 规则之间怎样衔接
1. 识别指标已进入8-9天的长时间数值钝化期；
2. 激活本法，判定当前指标失效，严禁依据背离进行左侧开仓；
3. 保持空仓观望，直至右侧出现放量阳线与均线转折。

## 案例和失败方式
- 案例：2022年10月10日上证日线MACD钝化达8-9天，盲目左侧进场者遭遇价格继续单边下挫。
- 失败方式：在钝化期试图“左侧抄底搏收敛”，结果市场继续加速下跌导致无止损出局机会。

## 版本分歧与证据限制
原稿指出钝化是由于指标数值变动过小无法提供参考，强调背离可能沿同方向继续运行，属于纯粹防守过滤。
