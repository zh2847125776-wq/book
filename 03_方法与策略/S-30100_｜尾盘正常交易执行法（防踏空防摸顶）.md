# S-30100 ｜尾盘正常交易执行法（防踏空防摸顶）

> 来源：SRC-002277（股票_量化技术分析20250723_量能过大_警惕调整_守好五日线（增强版））· 证据 E-90400, E-90403
> 来源：SRC-002278（股票_量化技术分析20250724_阳线平稳_继续安心做多_注意板块轮动（增强版））· 证据 E-90409, E-90411, E-90413

## 一句话定义
趋势完好的连阳市里，放弃盘中主观判断，只在尾盘按客观条件执行买卖：该开单继续开单，不摸顶、不空仓、不早盘追。{E-90403}{E-90411}

## 条件与动作表
| 步骤 | 条件 | 动作 |
|---|---|---|
| 环境过滤 | 日线五日线上行未破，60分钟无调整结构，时间窗口关闭 | 允许进入当日尾盘交易计划，否则休息 {E-90404}{E-90411} |
| 形态或指标形成 | 当日阳线或开高收低但重心不下移，非超长上影、非阴线 | 判定为可参与的交易日 {E-90410}{E-90411} |
| 确认 | 集合净额绝对值仍高，首小时量与前日相当、稳步抬升 | 确认资金热度未塌，计划有效 {E-90408}{E-90409} |
| 入场 | 尾盘时段执行，不做早盘交易 | 当日尾盘下单，当日被套才算风险 {E-90411} |
| 初始止损 | 所选个股必须有合理止损，短线可用昨日低点 | 开仓即设位，触发即走，不硬扛 {E-90415} |
| 仓位与资金 | 指数连阳不调、该涨的阶段 | 保持仓位保证参与，绝不空仓踏空 {E-90400}{E-90403} |
| 持仓与跟踪 | 持有期间跟踪五日线与重心 | 五日线不破、重心不下移就拿着 {E-90411} |
| 加减仓 | 盘中上涨不追高，回调到支撑才考虑 | 止损低的试仓思路，不清楚就小仓试 {E-90403} |
| 止盈与退出 | 到预设目标价或破五日线 | 目标价减半，破五休息，五穿二十彻底不做 {E-90406}{E-90413} |
| 失效与放弃 | 收盘跌破五日线，或五日线拐头 | 休息；五穿二十破位则放弃等站回 {E-90413} |

## 出处与依据
本方法是对7月23日“程序该开单继续开单、人工摸顶反而没挣着钱”与7月24日“重心不下移、五日线不破就尾盘正常交易”两处结论的合并：把主观恐高交给程序纪律，把客观条件交给均线、重心与量能三重确认。{E-90403}{E-90411}

## 与其他概念的关系
本卡的执行前提是K-70160的持有判据：判据成立才开工，判据破坏（破五）即收工。
本卡的退出分支外包给S-30101（目标价兑现）与S-30102（高位龙头兑现），三者构成“持有—兑现”的完整闭环。
