# S-2752 指数止损全盘风控管理法

> 来源：SRC-005137（第2408课 股票日评：调整结束第二买点出现加仓勇敢进攻（20240517））· 证据 E-69021、E-69022、E-69023、E-69025
- 性质：规则完整的策略
- 规则版本：原稿口述版
- 完整度分级：已给方向
- 效果证据：原文阐述能够避免大盘攻破关键价格时全盘恐慌抛售导致踩错，同时杜绝在弱势期逆势建仓放大亏损。

## 目的与适用环境
适用于股票多头交易，当大盘指数跌破关键生命线时，实行全账户禁止开仓、持仓单向逐一退出的系统性风控。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线周期 | E-69023 | 宏观宽基指数处于调整阶段，逼近破位临界点；原稿未明确多个指数产生背离时的判定 |
| 形态或指标形成 | 日线周期 | E-69023、E-69025 | 指数收盘测试20日均线及关键防守价格（如3096点或3090点） |
| 确认 | 日线收盘 | E-69023、E-69025 | 日线收盘确认跌破20日均线或收在关键价格（3096/3090）下方，触发指数止损 |
| 入场 | [不适用] | E-69021 | 触发当日即时禁止下达任何新的多头头寸订单，绝对禁止买入新股票 |
| 初始止损 | 触发后持续生效 | E-69021 | 锁死全盘多头敞口，严禁逆势补仓或摊低成本 |
| 仓位与资金 | 逐日跟踪 | E-69021、E-69022 | 账户总仓位实行单向递减管理（只卖不买）；原稿未明确单只股票清仓先后顺序 |
| 持仓与跟踪 | 每日跟踪 | E-69022 | 对持仓个股严格依照各自规则进行跟踪，不进行一键全盘清仓 |
| 加减仓 | 个股信号触发时 | E-69022 | 个股触发自身止损或止盈时坚决卖出，持仓逐步归零，严禁加仓 |
| 止盈与退出 | 持续至全部出清 | E-69022 | 手中持仓A、B、C全部根据个股信号卖出完毕，账户进入完全空仓状态 |
| 失效与放弃 | 日线收盘确认 | E-69022 | 大盘指数重新走好、重回关键价上方并恢复多头排列时，解除冻结，恢复开仓权限；原文未给出“走好”的全部量化指标 |

## 规则之间怎样衔接
作为宏观总闸门管辖所有个股子策略：指数守住关键位则个股策略正常买卖；指数失守则关闭新开多头接口，各持仓个股依照自身子策略有序退出。

## 案例和失败方式
案例为上证指数测试3090点防守线E-69025；失败方式为指数出现假跌破后迅速V型反转，导致卖出后错失后续涨幅，需等待指数走好后重新买入。

## 版本分歧与证据限制
原文未对持仓个股卖出的优先级排序给出数学公式，仅给出“卖了A、卖了B、卖了C，卖到没有了”的执行方向。
