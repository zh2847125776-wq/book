# S-1273 MACD低位钝化三态核验法

> 来源：SRC-004541（第1871课 补涨补跌公式因子与三级支撑总表）· 证据 E-61527, E-61528, E-61529
- 性质：观察信号
- 规则版本：第1871课牛年收官版
- 完整度分级：已给方向
- 效果证据：2022年1月28日全A仅两柱相近被定为初步钝化，四指标无一止跌，成功规避假见底风险（E-61527, E-61529）

## 目的与适用环境
在指数深跌后日线MACD绿柱出现数值相近时，严格按三柱标准与多指标辅助核验是否真实现钝化止跌。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 指数日线周期MACD处于零轴下方深水区，绿柱绝对值较大 | 日线收盘 | E-61527 | 仅限零轴下空方主导区 |
| 形态或指标形成 | 观察MACD绿柱读数，若连续两个柱读数相近（如-31.15与-31.09），标记为"初步钝化" | 第2柱收盘 | E-61527 | 两柱绝不可确认为真钝化 |
| 确认 | 观察第3柱：必须连续三个柱读数基本相同，无法辨识多空变化，方可确认为"真钝化" | 第3柱收盘 | E-61527 | 严格以三柱为准绳 |
| 入场 | 原文未明确（钝化仅为能量衰竭信号，未形成多头排列不可进场） | 原文未明确 | 无 | 缺口：不可直接买入 |
| 初始止损 | 原文未明确 | 原文未明确 | 无 | 缺口：无止损规则 |
| 仓位与资金 | 原文未明确（钝化确认前保持观望） | 原文未明确 | 无 | 缺口：无仓位配比 |
| 持仓与跟踪 | 辅助核验四指标：DMI的ADX是否拐头、布林线上线是否拐头、CCI是否脱离-100、是否站上5日线 | 每日跟踪 | E-61529 | 四指标无一止跌则继续等待 |
| 加减仓 | 原文未明确 | 原文未明确 | 无 | 缺口：无加减仓规则 |
| 止盈与退出 | 原文未明确 | 原文未明确 | 无 | 缺口：无止盈规则 |
| 失效与放弃 | 若第三柱出现绿柱大幅重新放大拉长，判定钝化根本未形成，空方加速杀跌，放弃止跌预期 | 异动发生时 | E-61528 | 钝化假设彻底推翻 |

## 规则之间怎样衔接
作为MACD指标能量学检验法则，为左侧预警提供门槛过滤，需与DMI、布林线、CCI及5日均线五重印证。

## 案例和失败方式
案例：2022年1月28日全A日线MACD仅有两个柱读数接近（-31.15与-31.09），且DMI未拐头、布林线上线向上、CCI在-100下方加速、未站上5日线，判定止跌无效（E-61527, E-61529）。
失败方式：在出现两个相近绿柱时便抢跑抄底，次日遭遇绿柱重新大幅放大，空头继续杀跌被套（E-61528）。

## 版本分歧与证据限制
原稿仅给出了钝化三种可能演化的方向定性，对于第三柱相通后多空力量逆转的具体确认买点，原稿未做展开。
