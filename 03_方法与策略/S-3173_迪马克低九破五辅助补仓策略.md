# S-3173 迪马克低九破五辅助补仓策略

> 来源：SRC-000158（专题_技术专题_几种基础补仓与止损操作策略详表（增强版））· 证据 E-73110
- 性质：局部方法
- 规则版本：讲师2022年9月18日直播授课版
- 完整度分级：已给方向
- 效果证据：九鼎投资日线低九反面案例与思维导图「低九破五」增信逻辑

## 目的与适用环境
在单边暴跌的大幅浮亏背景下，针对传统5日线补仓频繁试错被扫单的痛点，将迪马克序列（九转序列）与5日均线进行跨指标共振融合，通过提高确定性来提升空头排列下的补仓胜率。· E-73110、E-73111

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线周期，经历严重单边暴跌，标的大幅浮亏陷入被动 | E-73110、E-73111 | 必须在充分单边下行背景中，震荡市中低九无效 |
| 形态或指标形成 | 盘面完成迪马克序列（九转序列）并出现「低九（D9）」信号 | E-73110 | 严禁单独见低九即买，低九仅具备半个权重，非独立架构 |
| 确认 | 出现低九信号之后，等待后续日K线收盘价明确站上5日均线（形成「低九破五」） | E-73110、E-73111 | 必须以站上5日均线作为最终的右侧确认信号 |
| 入场 | 低九之后收盘确认站上5日均线时，果断尝试买入补仓 | E-73111 | 牺牲未出低九即反弹的交易机会，换取更高确定性 |
| 初始止损 | 开单后一旦价格再次跌破5日均线，严格无条件止损 | E-73111 | 参照传统均线系统规则，绝不拖泥带水 |
| 仓位与资金 | 补仓资金严格限定在底仓等量以内，不可满仓单挑 | E-73108 | 遵循补仓理论极限红线 |
| 持仓与跟踪 | 站上5日线后未跌破则持续持有，跟踪逻辑完全参考传统5日均线系统 | E-73111 | 以5日线作为持仓与止盈的跟踪线 |
| 加减仓 | 贴近MA20或MA60压制位，结合跌破5日线信号分批止盈减仓 | E-73101 | 遵循均线系统阶梯出场规则 |
| 止盈与退出 | 到达本周期或更高周期核心均线，且日线收盘跌破5日线全部止盈离场 | E-73102 | 原稿未单独为低九设计特殊止盈公式，依附于均线系统 |
| 失效与放弃 | 低九后横盘向下破位、或低九后迟迟无法站上5日线，策略不予触发；站上后跌破5日线立即止损 | E-73110 | 若个股见低九后继续单边大跌，严禁左侧加仓抄底 |

## 规则之间怎样衔接
本策略是「指标半权重信号 + 均线系统完整确认」的复合架构。迪马克低九提供「超跌动能耗竭预警（半个权重）」，传统5日线收盘站上提供「价格拐点确认（触发开单）」，后续跟踪与退出完全嵌入传统均线系统操作表格，二者紧密相扣。· E-73110、E-73111

## 案例和失败方式
1. 单纯低九反面案例：九鼎投资日线出现低九（收盘价14.37元），交易者若单凭低九直接抄底买入，随后股价一路跌至最低收盘12.50元，再次暴跌超10%，证明单有低九绝不能开单。· E-73110
2. 机会成本代价：过滤掉所有未出现低九而直接站上5日线的反弹行情，属于用交易频率换取确定性的客观代价。· E-73111

## 版本分歧与证据限制
迪马克序列在软件中又称九转序列，原稿讲述者指出徐晓明对该指标的本土化改写与商业软件收录背景；原稿明确指出该架构止损规则完全参照传统5日均线操作法，未提供独立的低九止损公式。· E-73110、E-73111
