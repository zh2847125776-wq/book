# S-2369 竞价开盘承接力三要素确认打板与低吸策略

> 来源：SRC-000239（第218章 揭秘涨停高手的3个必胜秘诀！）· 证据 E-65868
- 性质：规则完整的策略
- 规则版本：早盘竞价开盘承接力确认版
- 完整度分级：已给方向
- 效果证据：有效过滤假突破与冲高回落陷阱，大幅提升短线交易安全度与胜率（E-65868）。

## 目的与适用环境
用于在早盘开盘后快速从竞价异动股票中筛选出真买盘承接标的，进行右侧涨停打板或分时低吸。

## 规则之间怎样衔接
竞价高开 -> 开盘高走 -> 回踩双不破 -> 3-5分钟V型突破或1分钟秒板入场。

## 案例和失败方式
早盘冲动上涨后快速跳水破均价线，属于典型的承接力不足失败形态，需坚决过滤（E-65868）。
