# S-3067 TRP指标变色与贴近均线顺逆势交易及磨损控制策略

> 来源：SRC-000318（期货_期货投机分析20250725_多个品种出现摸顶机会_逆势交易_谨慎尝试（增强版））· 证据 E-71985、E-71986、E-71990、E-71991、E-71993
- 性质：规则完整的策略
- 规则版本：TRP红绿豆系统标准顺逆势交易与仓位管理
- 完整度分级：已给方向
- 效果证据：沪金、豆粕、菜粕、PVC等实盘交易验证。

## 目的与适用环境
适用于商品与贵金属期货在5分钟或更高周期的趋势跟踪与反转捕捉，利用TRP指标变色与贴近信号寻找买卖点，并通过「减半-接回-清空」机制控制震荡磨损（证据 E-71986、E-71993）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 顺势交易优先；逆势交易需大盘共振且严格压缩仓位；多方穿透禁做空，空方穿透禁做多 | 5分钟K线 | E-71985、E-71991 | 需区分顺逆势及多空穿透状态 |
| 形态或指标形成 | 多头形成：TRP变红豆或价格贴近红豆；空头形成：TRP变绿豆或价格贴近绿豆 | 5分钟收K | E-71983、E-71991、E-71993 | 红豆持续过长不可盲目追高 |
| 确认 | K线颜色过滤：做空不能顶着阳线，必须出阴线；做多不能顶着阴线，必须出阳线 | 入场K线收盘 | E-71989、E-71991 | 顶着反向单根K线严禁开单 |
| 入场 | 收K确认站上/跌破对应红绿豆，或贴近指标线且K线同色时入场 | 收K当时 | E-71983、E-71991、E-71993 | 需收K确定信号 |
| 初始止损 | 摆TRP指标线止损或依托近期极值高低点（近高/近低）止损 | 开仓同时 | E-71983、E-71992 | 两种止损方式二选一 |
| 仓位与资金 | 顺势标准仓位；逆势摸顶头寸规模减半（如10手开5手），大空间对折再对折 | 开仓前确定 | E-71977、E-71984 | 原文未给出总资金占用率限制 |

## 规则之间怎样衔接
指标变色/贴近 -> 单根K线阴阳过滤 -> 收K确认入场 -> 设置TRP或近极值止损 -> 顺势跟踪中执行「减半-接回」控制磨损 -> 触碰止损或反向变色清空翻转（证据 E-71986、E-71990、E-71991）。

## 案例和失败方式
1. 磨损盈利案例：沪金5分钟多方穿透后空头排列，24日晚下空单，历经4次「减半-接回」磨损，25日夜盘最终实现盈利（证据 E-71985、E-71986）。
2. 纠错翻转案例：豆粕24日晚做多，25日早9:45减半、11:00清空止损，11:00就地反手下空单，践行「好买点和卖点在一起」（证据 E-71990）。
3. 失败方式：震荡市中反复减半与接回导致磨损过大，或如20号胶、氧化铝摸顶逆势直接遭遇单边打靶止损（证据 E-71983、E-71986）。

## 版本分歧与证据限制
该策略在不同品种的止损设置上存在自由度（可摆TRP止损亦可摆近高止损），缺乏机械硬性约定，且减半与接回的具体点位偏向盘中经验裁量（证据 E-71986、E-71992）。
