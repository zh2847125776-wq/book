# S-2400 大盘逆势涨停选股与站稳三天回踩5日线买入法

目的与适用环境

用于在大盘单边连续下挫的恐慌期，逆势挖掘具有主力控盘吸筹迹象的潜在黑马龙头。适用环境为大盘连续下跌末期至重回5日均线前。

规则之间怎样衔接

大盘连跌末期筛选逆势涨停 -> 次日过滤低开缩量阴与高开放量阴 -> 保留放量阳线并在涨停价上站稳3天 -> 回踩靠近5日均线买入 -> 享受主升浪。

案例和失败方式
成功应用案例：老张在大盘连续多日飘绿后，逆势挑选连续跌停后巨量涨停的个股，次日放量阳线确认后介入，捕获翻倍黑马（E-66055, E-66056）。
失败方式：在次日低开缩量收阴或高开放量收阴时盲目介入，被主力诱多套牢。
