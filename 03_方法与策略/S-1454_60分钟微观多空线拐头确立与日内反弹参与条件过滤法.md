# S-1454 60分钟微观多空线拐头确立与日内反弹参与条件过滤法

> 来源：SRC-004609（第1932课 股票日评：逆停指标的本质是交叉共振（20220512））· 证据 E-62150
- 性质：局部方法
- 规则版本：V1
- 完整度分级：已给方向
- 效果证据：2022年5月12日指数看似继续上冲，但60分钟周期多空线并未拐头向上形成多头排列，精准预警了日内冲高乏力、无法持续大涨的走势。

## 目的与适用环境
用于在日线出现反弹迹象时，利用60分钟微观周期的核心多空线状态进行反弹质量过滤，防范在分时均线未确立多头排列时盲目追高。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线级别处于超跌反弹或低位震荡期，盘中有脉冲上攻动作 | 60分钟分时周期 | E-62150 | 针对日内微观持续性的审计 |
| 形态或指标形成 | 观察60分钟K线形态，价格看似继续往上运行测试压力位 | 60分钟各K线柱 | E-62150 | 容易造成短线突破的假象 |
| 确认 | 审核60分钟多空线核心指标：①核查多空线是否形成多头排列；②核查多空线是否确定拐头向上 | 60分钟收盘核查 | E-62150 | 两项条件缺一不可，缺少拐头则涨不动 |
| 入场 | 若60分钟多空线未形成多头排列、未拐头向上，绝对禁止日内追涨开仓；唯有确认多头排列且拐头向上方可参与短线 | 60分钟信号确认后 | E-62150 | 严防“缺一个拐头”的虚假冲高 |
| 初始止损 | 若参与短线试盘，以该60分钟K线起涨低点或多空线为即时止损位 | 跌破分时支撑时 | E-62150 | 短线交易快进快出，严格止损 |
| 仓位与资金 | 60分钟级别交易严格限定为一成以内的超短线仓位 | 日内执行 | E-62150 | 绝不升级为中长线重仓 |
| 持仓与跟踪 | 密切监控每个小时收盘时多空线的斜率变化，若多空线走平滞涨立即准备退出 | 每小时收盘 | E-62150 | 保持分时高度敏感度 |
| 加减仓 | 60分钟多空线上冲乏力时坚决减仓；未发生右侧顺畅推升绝不加仓 | 冲高受阻时 | E-62150 | 弱势市场分时冲高皆为卖点 |
| 止盈与退出 | 日内脉冲达到阻力位或60分钟多空线出现死叉下弯时果断止盈 | 分时见顶时 | E-62150 | 锁定超短线反抽利润 |
| 失效与放弃 | 价格跌破60分钟多空线支撑并加速下行，短线反弹彻底夭折，全面止损离场 | 跌破多空线时 | E-62150 | 承认日内脉冲反弹结束 |

## 规则之间怎样衔接
本局部方法为 `K-3677`（缩量阳线需修复）提供了微观分时执行工具，并与日线大趋势风控规则形成微观与宏观互补。

## 案例和失败方式
- 案例：`C-2234`；
- 失败方式：漠视60分钟多空线未拐头向上的客观事实，在分时冲高处追进，当日即被套在分时高点。
