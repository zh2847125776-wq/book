# S-2397 F10股东结构与解禁风险前置排查操作法


来源：SRC-000020（P2_f10（增强版））· 证据 E-66027, E-66031

性质：局部方法
规则版本：原文未明确（未分版）
完整度分级：已给方向
效果证据：原文课件指出通过F10排查股东集中度与解禁属性，能有效避开定增抛售大雷，同时借由筹码集中识别主力吸筹完毕的低位买点（E-66027, E-66031）
目的与适用环境

用于在股票建仓前快速完成基本面排雷与主力筹码结构确认。适用环境为所有A股个股开仓前的静态背景核查。

规则之间怎样衔接

技术买点出现 -> 打开F10排查 -> 股东人数减少（筹码集中） -> 无恶性定增解禁 -> 结合大盘环境入场 -> 跟踪技术均线退出。

案例和失败方式
成功应用案例：中国联通在横盘整理末端出现筹码集中，结合均线向上发散确立买点（证据未逐字回源, E-66032）。
失败方式：忽视大比例定增解禁日期，在解禁日前夕盲目抄底，遭遇机构一致性砸盘套现跌停。
