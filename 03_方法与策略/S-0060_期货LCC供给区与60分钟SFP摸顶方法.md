# S-0060 期货LCC供给区与60分钟SFP摸顶方法
> 来源：SRC-003589（第1009课 期货：周五订单复盘与LCC摸顶法（20241021））· 证据 E-0473, E-0474, E-0475, E-0476
- 性质：局部方法
- 规则版本：第1009课实战复盘版
- 完整度分级：已给方向
- 效果证据：棕榈油周五早盘第二笔空单依据60分钟SFP与5分钟顶背离入场，完全覆盖首笔亏损并斩获约3%波段跌幅（E-0476）。
## 目的与适用环境
在品种日线单边暴涨后出现日线与60分钟级别SFP（摆动失败形态）时，依托LCC供给区域红线的阻力，在极小止损保护下寻找左侧/右侧高盈亏比摸顶放空机会（E-0473, E-0474, E-0476）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线周期 | E-0473, E-0476 | 日线横盘突破单边行情末尾，创高后出现日线SFP（至少满足5K最低要求） |
| 形态或指标形成 | 60分钟周期 | E-0473, E-0474 | 价格贴近LCC红线上限，出现倒打K或上影线；盘中影线刺破但收盘实体未破 |
| 确认 | 60分钟/5分钟 | E-0473, E-0476 | 60分钟收出异色K（阴线）；或5分钟级别出现顶背离形成共振确认 |
| 入场 | 贴近LCC或5分钟确认 | E-0473, E-0476 | 贴近LCC上限入场；追求好价格可在5分钟先行入场，追求确定性需等60分钟收阴 |
| 初始止损 | 开仓同时 | E-0475, E-0476 | 设于前期最高价（如新高凑整），控制绝对止损值在0.2%~0.3%左右的小空间 |
| 仓位与资金 | 开仓时 | E-0475 | 必须设定止损上限，单品种连续失败两次或三次即强制停止 |
| 持仓与跟踪 | 5分钟周期 | E-0476 | 价格跌破上涨常态三号位（前低）确认流动性崩溃，站上5分钟5MA代表脱离成本区 |
| 加减仓 | 跌破三号位或收K | E-0476 | 三号位跌破加仓；60分钟收K完全"写死"SFP形态时可加仓 |
| 止盈与退出 | 到达多空线目标 | E-0476 | 第一目标位到达5分钟多空线平一半；第二目标位到达60分钟多空线平全部或收盘站上5MA清空 |
| 失效与放弃 | 60分钟实体破位 | E-0474 | 60分钟收盘实体若有效站上LCC红线，供给区失效，空头必须止损并考虑翻多 |

## 规则之间怎样衔接
入场依赖LCC红线压制与收阴确认；止损卡死新高；脱离成本后以三号位破位加仓；止盈严格执行分批（5分钟多空线平一半，60分钟多空线或收盘前清仓）（E-0474, E-0476）。

## 案例和失败方式
1. 首笔失败：早盘冲高过早追求好价格，未等60分钟异色K，被盘中拉升打损（E-0475）。
2. 二次成功：等待60分钟SFP与5分钟顶背离结合，成功捕捉大跌（E-0476）。

## 版本分歧与证据限制
合约具体交割月份原稿未明确；幅度和距离必须用幅度尺核算。
