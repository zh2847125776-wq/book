# S-3401 黄金交叉窗口与高点周期推算法

> 来源：SRC-001080（第课 股票_20200611量化技术分析（增强版））· 证据 E-75501、E-75502、E-75503
- 性质：局部方法
- 规则版本：原稿未明确
- 完整度分级：已给方向
- 效果证据：2020年6月初上证指数黄金交叉后，根据12-14个周期推算见顶高点在第6或第7个周期，实盘在第7个周期如期见高点2957点。证据 E-75501、E-75502。

## 目的与适用环境
用于在指数或个股日线级别均线或指标发生黄金交叉后，提前推算该反弹波段能够维持的操作周期天数，以及波段最高点出现的时间窗口。证据 E-75501、E-75502。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 价格跳空高开大涨站上20日线，均线或指标形成黄金交叉，属于上涨中继结构 | E-75501、E-75502 | 必须依托前期对称周期支撑（如38周期） |
| 形态或指标形成 | 黄金交叉确立，测算金叉至死亡交叉预期总周期数（如12至14个周期） | E-75501、E-75502 | 原稿未提供预期总周期的通用测算公式 |
| 确认 | 采用除二法则：预期总周期除以二（12/2=6，14/2=7），确认高点在第6或第7个周期 | E-75502 | 计算逻辑基于简单算术对称 |
| 入场 | 在跳空大涨站上20日线当天进场，选股必须要求20日均线具备明显上升斜率 | E-75502、E-75503 | 严禁介入20日线走平或处于箱体内部的个股 |
| 初始止损 | 原文未明确具体数字止损 | E-75502 | 原稿未提供精确止损参数 |
| 仓位与资金 | 原文未明确具体仓位比例 | E-75503 | 原稿未提供资金管理规则 |
| 持仓与跟踪 | 锁定可持股操作周期仅为3至4天，每日计数跟踪是否到达第6或第7个周期 | E-75502 | 严禁超期盲目持股 |
| 加减仓 | 运行至第6或第7个周期接近时间窗口且面临死叉风险时，禁止追买，考虑减仓 | E-75501、E-75502 | 原文未提供分批减仓比例 |
| 止盈与退出 | 到达第7个周期高点窗口滞涨时兑现利润退出，防范后续死叉调整 | E-75501、E-75502 | 原文未给出精确止盈点位 |
| 失效与放弃 | 若个股在20日线下方箱体内横盘无斜率，则该方法放弃不执行 | E-75503 | 标的无斜率则不可操作 |

## 规则之间怎样衔接
识别黄金交叉与站上20日均线的跳空大涨基准日；筛选20日线具有向上斜率的品种进场；按“预期周期除以二”设定3-4天的持股安全窗口；第6-7周期高点兑现离场，避免随后死叉阶段的亏损。证据 E-75501、E-75502、E-75503。

## 案例和失败方式
- 案例：2020年6月1日跳空大涨站上20日线，金叉后预期到死叉约12-14个周期，通过除二法则推算第6或第7个周期见高点，6月9日（第7个周期）上证指数精准见高点2957点，随后震荡回落。证据 E-75501、E-75502。
- 失败方式：选错标的，买入20日线无斜率、在箱体内部横盘的个股，持股3-4天股价完全不涨反而错过波段窗口。证据 E-75503。

## 版本分歧与证据限制
周期总数预估（12-14天）依赖前期中继结构对称推算，未明确通用预估公式；未提供精确的止损价格触发条件。证据 E-75501、E-75502。
