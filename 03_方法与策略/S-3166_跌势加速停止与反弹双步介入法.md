# S-3166 跌势加速停止与反弹双步介入法

> 来源：SRC-001045（股票_20200320量化技术分析（增强版））· 证据 E-73042
- 性质：局部方法
- 规则版本：SRC-001045（20200320增强稿日评版）
- 完整度分级：已给方向
- 效果证据：原文未提供回测胜率与盈亏比数据，仅结合2020年3月20日大盘反弹实盘推演。

## 目的与适用环境
用于指数或个股在单边大幅下跌后，捕捉加速下跌停止带来的超跌反弹或双底反转机会，并针对二次探底风险进行分步应对。〔E-73042、E-73043〕

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤：前期处于空头排列与加速暴跌环境；外盘提前止跌收敛 | 日线级别 | E-73050 | 逆势做反弹，需防范系统性暴跌风险 |
| 形态或指标形成：K线收盘站上布林线下轨，且布林线上轨（上线）由张口发散转为收敛；MACD绿柱缩短 | 日线收盘 | E-73040、E-73042 | 需多个指标同时发出停止信号 |
| 确认：布林线下跌加速停止信号确认成立 | 日线收盘 | E-73042 | 仅确认加速停止，不排除二次探底 |
| 入场：【买点1】若愿承受二次探底风险，在加速下跌停止信号确立时轻仓介入；【买点2】若不愿承受二次探底风险，等待反弹高点确立颈线、二次探底不破前低并突破颈线时介入 | 日线收盘或突破时点 | E-73043、E-73044 | 买点2需等待颈线与双底形态形成 |
| 初始止损：周线关键支撑位（如2734点）跌破且次周无法收回；或跌破前低底线（如2440点） | 周线收盘或日线击穿 | E-73048、E-73049 | 原稿未提供固定百分比点数 |
| 仓位与资金：买点1承担风险大需控制仓位，稳健者等待买点2 | 入场当时 | E-73043 | 具体仓位管理参数完全缺失 |
| 持仓与跟踪：利用60分钟MACD跟踪持仓，金叉后观察红柱运行，监控是否在7~9周期内出现红柱缩短死叉 | 60分钟线 | E-73046、E-73047 | 需密切盯紧分时收盘红柱状态 |
| 加减仓：反弹测试下行重要均线若成交量不足均量，需减仓防回踩；买点2确立后可加仓 | 日线测试均线时 | E-73038、E-73043 | 原稿未给出具体加减仓比例数值 |
| 止盈与退出：买点1入场后若60分钟在7~9周期死叉（下跌中继走双底），需逢高止盈离场；稳健者根据反弹高点颈线位目标测算止盈 | 60分钟死叉或颈线目标位 | E-73044、E-73046 | 颈线目标测算公式原文未细讲 |
| 失效与放弃：若周线关键位2734点失守且下周无法收回，则前低大概率不保，全套反弹逻辑彻底失效，止损离场 | 周线收盘 | E-73048、E-73049 | 关键防守点被有效击穿即策略放弃 |

## 规则之间怎样衔接
首先由日线布林线下轨收复与上线收敛触发买点1信号；进场后切换至60分钟周期通过MACD红柱周期跟踪反弹成色：若在7~9周期死叉，确认走下跌中继双底，买点1退出并等待回踩前低不破形成双脚，随后标定前期反弹高点作为颈线，待颈线突破后触发买点2；全程以周线关键支撑位作为最终安全防线。〔E-73042、E-73043、E-73044、E-73046、E-73048〕

## 案例和失败方式
2020年3月20日上证指数出现买点1触发条件。失败方式：缩量反弹遇均线压制受阻回落，直接砸穿周线2734点防守位，导致二次探底演化为跌破2440点的新一轮深跌。〔E-73038、E-73049〕

## 版本分歧与证据限制
规则仅见于2020年3月20日单期日评增强稿，缺少严格的仓位管理及买点2突破幅度等具体量化参数。
