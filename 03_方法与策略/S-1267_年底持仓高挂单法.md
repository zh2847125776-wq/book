# S-1267 年底持仓高挂单法

> 来源：SRC-004538（第1869课 倒鸭嘴16N公式与标志K线三条件）· 证据 E-61508
- 性质：局部方法
- 规则版本：第1869课春节前版本
- 完整度分级：已给方向
- 效果证据：历史每年年底均存在个别股票尾盘突发拉高偷袭的统计现象（E-61508）

## 目的与适用环境
在年底最后一个交易日应对市场流动性匮乏背景下的突发脉冲拉抬，捕捉异常高挂成交的红包收益。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 年底最后一个交易日，且自身已有股票持仓 | 年底最后一个交易日 | E-61508 | 必须为已有可卖持仓 |
| 形态或指标形成 | 市场处于年底清淡交易期，存在流动性抽离与尾盘异动偷袭预期 | 盘前或盘中 | E-61508 | 原文未明确适用股票板块类型 |
| 确认 | 账户持有底仓且未打算盘中割肉清仓 | 交易日前半段 | E-61508 | 无做空标的限制 |
| 入场 | 原文未明确（本方法针对既有持仓进行卖出挂单） | 原文未明确 | 无 | 非买入建仓方法 |
| 初始止损 | 原文未明确 | 原文未明确 | 无 | 缺口：不涉及买入止损 |
| 仓位与资金 | 基于账户现有持仓执行挂单 | 挂单执行时 | E-61508 | 原文未规定挂单持仓比例 |
| 持仓与跟踪 | 维持卖单委托在交易所主机直至收盘 | 全天委托时段 | E-61508 | 原文未明确分笔撤单要求 |
| 加减仓 | 原文未明确 | 原文未明确 | 无 | 缺口：无加仓动作 |
| 止盈与退出 | 将卖出委托单挂在较高涨幅位置，如挂在7%或9%涨幅处，等待偷袭成交 | 委托挂单动作 | E-61508 | 仅给出7%或9%两个参考数值 |
| 失效与放弃 | 若全天未触发脉冲偷袭，收盘未成交委托自动成为废单退出，不产生额外损失 | 收盘清算时 | E-61508 | 无成交则自动失效 |

## 规则之间怎样衔接
属于假日流动性空窗期的特殊被动防守挂单战术，不与常规趋势策略冲突，成交即为超额兑现，不成交不承担额外成本。

## 案例和失败方式
案例：每年年底个别股票可能出现盘中或尾盘突发偷袭拉高，高挂7%或9%的卖单可被动获利了结（E-61508）。
失败方式：全天股票波澜不惊未发生偷袭拉高，委托单未成交并被主机退回废单，但对原有持仓不产生实质影响（E-61508）。

## 版本分歧与证据限制
原稿仅提及挂7%或9%两个经验涨幅数值，未明确挂单比例分配以及是否适用涨跌停板受限的特定品种。
