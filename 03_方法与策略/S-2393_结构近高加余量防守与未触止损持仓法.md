# S-2393 结构近高加余量防守与未触止损持仓法

效果证据：原文作者自述通过近高加余量防守并在未触发止损前坚决不动单，成功捕获纯碱、螺纹钢、聚丙烯等大单边利润（E-65998, E-65999）
目的与适用环境

用于在期货建仓后遭遇震荡拉锯时，规范持仓纪律，杜绝因盘中浮亏慌乱平仓。适用环境为所有期货合约的多空持仓防守阶段。

规则之间怎样衔接

确立近高加余量止损 -> 开仓后静心等待 -> 忍受3-5天成本区震荡 -> 未触止损坚决持有 -> 走出单边后享受收益。

案例和失败方式
成功应用案例：纯碱与螺纹钢空单忍耐3-4天震荡未破止损线，最终均收获流畅单边收益（E-65998）。
失败方式：在止损未触发时因受不了浮亏焦虑手动平仓，刚平仓行情即展开单边暴跌。
