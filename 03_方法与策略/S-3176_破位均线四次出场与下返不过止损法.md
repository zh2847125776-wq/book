# S-3176 破位均线四次出场与下返不过止损法

> 来源：SRC-001046（股票_20200321量化技术分析_创业板指数（增强版））· 证据 E-73135, E-73136, E-73137, E-73138, E-73139, E-73142, E-73151
- 性质：局部方法
- 规则版本：讲师2020年3月指数与个股防守实操规范
- 完整度分级：已给方向
- 效果证据：2020年3月创业板指数在破位20日线过程中连续给出4次离场机会，未执行者随后遭受向下跳空缺口及单日大跌5.9%的主跌重创（E-73136, E-73137, E-73139）。

## 目的与适用环境
用于指数或个股在上升波段末期跌破关键均线（20日线或快速下跌中的60日线）时，利用主力盘中给予的反抽和确认窗口进行多批次清仓退出，规避破位后的跳空与主跌浪亏损（E-73135, E-73137）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线级别均线由多头排列转为粘合混乱（30/20/10/60/5），进入变盘期 | 日线，E-73151 | 原文未给出量化粘合度指标 |
| 形态或指标形成 | 价格跌破20日均线，且20日均量不足 | 日线，E-73135, E-73136 | 需同时核验成交量是否达到20日均量 |
| 确认 | 跌破当日收盘价收在20日均线下方 | 日线收盘，E-73135 | 原文未定义跌破百分比幅度阈值 |
| 入场 | 不适用；20日线下严禁买入持股，20日线上不盲目放空 | 盘中/收盘，E-73135, E-73137 | 本策略为纯防守退出与止损机制 |
| 初始止损 | 第1次机会：破位首日开盘直接开在20日线下即卖出；第2次机会：破位首日收盘确认破20日线卖出 | 日线破位第1天，E-73135, E-73136 | 盘中与收盘均为明确卖出点 |
| 仓位与资金 | 20日线下坚决清仓，不持股 | 日线，E-73135 | 原文未明确具体分批仓位百分比 |
| 持仓与跟踪 | 第3次机会：破位第2天盘中下返测试20日线不过，必须执行清仓（此为最后期限） | 日线破位第2天，E-73136 | 严禁侥幸期待第3天确认 |
| 加减仓 | 第4次机会：破位第3~4天若再次反弹碰触20日线不过（第3天确认有效），清空全部筹码 | 日线破位第3~4天，E-73136, E-73137 | 该窗口出现频率不高，不可作为常态依赖 |
| 止盈与退出 | 若4次机会均错过，后续一旦出现向下跳空缺口或MACD穿轴，必须市价斩仓出局 | 日线跳空或穿轴日，E-73137, E-73139 | 此时止损已大幅被动滞后 |
| 失效与放弃 | 若跌破向上的20日线后能快速收回，且20日线未拐头向下，则不盲目看空做空 | 日线快速收回，E-73137, E-73142 | 需均线未形成空头排列 |

## 规则之间怎样衔接
以20日线为第一道退出防线；若价格未在20日线下平稳共振而是直接演变为急速单边暴跌，规则平移升级至60日均线替代机制（K-33001），等待反弹测试60日线（如1980点测试1983点不过）执行二次离场（E-73137, E-73138）。

## 案例和失败方式
- 成功防守案例：2020年3月9日创业板指开盘收盘双破20日线（第1、2次机会）；3月10日最高反弹2151测试2160附近的20日线不过（第3次机会）；3月11日最高2162再次反抽碰触20日线（2161）不过（第4次机会）；3月12日直接向下跳空暴跌，验证退出准确性（E-73136, E-73137）。
- 失败方式：交易者抱有侥幸心理，死等第3天确认或企图在20日线下博反弹，导致遭遇向下跳空缺口与3月16日MACD穿轴大跌5.9%，被迫在更低位割肉（E-73136, E-73137, E-73139）。

## 版本分歧与证据限制
讲述者指出常规技术分析常以“第3天确认有效”作为破位标准，但在实盘操作中不可期待第3天确认，因为主力资金往往不给第3天机会，第2天下返不过即为最后清仓期限（E-73136）。
