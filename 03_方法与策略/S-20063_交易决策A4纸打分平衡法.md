# S-20063 交易决策A4纸打分平衡法

> 来源：SRC-001116（股票_20200731量化技术分析_午间简评（增强版））· 证据 E-93614
- 性质：局部方法
- 规则版本：20200731教学版
- 完整度分级：已给方向
- 效果证据：通过A4纸书面罗列与打分，得出做空分20分远大于做多分4分的结果，帮助交易者在盘中冲动时克服侥幸心理，成功抑制盲目做多冲动。[E-93615]

## 目的与适用环境
用于交易者面临盘中情绪诱惑、意志产生波动或拿不准是否入场时，对所有多空条件与风险点进行书面客观梳理和打分权衡，避免盲目主观交易。[E-93614, E-93615]

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤：盘中产生交易冲动、情绪动摇或多空分歧巨大不明确时 | 交易决策前，任意周期 | E-93614 | 仅用于主观冲动抑制与纪律约束 |
| 形态或指标形成：取一张A4纸，画一条横线和一条竖线，分为左栏与右栏 | 决策准备时 | E-93614 | 物理书写工具规范 |
| 确认：左栏逐条书写做多与利好点；右栏逐条书写做空、不能做多或潜在风险点 | 盘前或盘中决策时 | E-93614, E-93615 | 必须详尽罗列，不许遗漏已知风险 |
| 入场：在默认各项条件权重均等的前提下，分别统计左栏与右栏的分值总和，仅当做多分具有绝对优势时方可考虑入场 | 决策敲定时 | E-93615 | 默认权重相同，未提供差异化加权公式 |
| 初始止损：原文未明确 | 决策阶段 | E-93615 | 本方法仅负责开仓前准入评估，未含止损设定 |
| 仓位与资金：依据打分结果对照仓位体系，若风险得分占优则严格禁止开仓买入 | 决策执行时 | E-93615 | 未提供得分差值与具体仓位比例的换算表 |
| 持仓与跟踪：原文未明确 | 持仓阶段 | E-93615 | 原文未说明持仓过程中是否需要重新打分 |
| 加减仓：原文未明确 | 持仓调整时 | E-93615 | 未给出加减仓阶段的打分规则 |
| 止盈与退出：原文未明确 | 退出阶段 | E-93615 | 未给出卖出平仓的打分临界值 |
| 失效与放弃：若右栏做空/风险得分显著高于左栏做多得分（如做多4分对做空20分），直接放弃做多入场计划 | 评估完成时 | E-93615 | 风险压倒利好时坚决不买 |

## 规则之间怎样衔接
作为盘前计划制定或盘中买卖决策的辅助量化过滤器，将宏观外盘表现、指数均线位置、分时量能以及形态突破有效性汇总于纸面上，克服好记性不如烂笔头的认知偏差，与整体仓位管理规则紧密衔接。[E-93614, E-93615]

## 案例和失败方式
2020年7月31日盘中，左边做多项仅有选出好股、重要会议召开等，得4分；右边做空/风险项包含美股看跌、红豆阴线风险、大盘未站上MA20、MA20面临向下拐头等，得20分。做多计划被果断放弃。[E-93615]

## 版本分歧与证据限制
仅增强稿可见；各项做多做空条件的单项权重在原稿中默认视为等权，未给出更为细致的高级加权算法与分值阈值标准。[E-93614, E-93615]
