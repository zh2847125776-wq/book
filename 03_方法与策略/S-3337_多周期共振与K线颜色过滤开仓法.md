# S-3337 多周期共振与K线颜色过滤开仓法

> 来源：SRC-000358（期货_期货投机分析20251029（增强版）） · 证据 E-74831
- 性质：规则完整的策略
- 规则版本：讲师20251029实盘口述规范
- 完整度分级：已给方向
- 效果证据：铁矿石、焦煤、PTA等标的在日内与大周期共振评估中的开平仓指导（E-74831, E-74832, E-74833）。

## 目的与适用环境
用于期货日内小周期交易，通过日线与60分钟大周期趋势方向过滤，结合小周期指标穿轴、形态突破以及执行K线颜色确认，提高顺势开仓质量。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤：核对日线与60分钟大中周期，趋势必须与拟开仓方向一致 | 日线、60分钟级别 | E-74831, E-74832 | 大周期不支持判定为胜率过低，明确放弃 |
| 形态或指标形成：5分钟小周期出现VB穿轴、MVB同向发散或横盘区间突破 | 5分钟级别盘中 | E-74831, E-74833 | 指标穿轴与形态突破提供触发预备 |
| 确认：必须获得对应方向的K线实体颜色确认；做多需阳线，做空需阴线 | 信号K线收盘时 | E-74831, E-74834 | 做多遇阴线或做空遇阳线坚决不下单 |
| 入场：确认K线收盘或紧随其后的开盘点执行下单 | 下单瞬间 | E-74831, E-74834 | 错过点位需等下一根同色确认K线 |
| 初始止损：设在信号K线对应的近高（做空）或近低（做多），必须严格添加余量操作表规定的余量 | 开仓同时 | E-74831, E-74833 | 严禁目测，必须用软件量尺测量止损幅度 |
| 仓位与资金：分仓配置两到三个活跃标的，禁止全仓押注单一口种 | 盘前规划 | E-74827, E-74832 | 具体单笔资金占用比例原稿未明确 |

| 加减仓：有底仓时在横盘突破或反向平仓信号触发时可加仓或反手开仓 | 突破或平仓触发时 | E-74833 | 需满足反向突破要件 |
| 止盈与退出：出现大级别阻力位、反向结构3号位被击穿或系统反向确认信号时果断离场 | 触发出场条件时 | E-74833 | 空单遇向上击穿3号位必须强制平仓 |
| 失效与放弃：若开仓前测算近高近低止损幅度过大，或大周期处于历史极值区间无盈亏比空间，放弃操作 | 开仓前评估时 | E-74831, E-74832 | 空间或止损不达标时执行放弃 |

## 规则之间怎样衔接
由日线与60分钟大周期提供最高层级的方向准入（环境过滤）；小周期（5分钟）MVB/VB及横盘形态提供信号生成；当根K线颜色（阴线/阳线）提供毫秒级触发扳机；近高近低附加余量构成底层防守底线；反向结构3号位击穿作为逆转强制退出纽带。

## 案例和失败方式
铁矿石在29日晚盘做空要求等待阴线确认下单；PTA因60分钟势同SFP且日线不支持，大周期不支持直接放弃做多；焦煤空单在价格向上击穿3号位时强制平仓，并反手执行多单。失败方式：在跳空高开或隔夜跳空中产生无法防御的滑点或直接穿透止损。

## 版本分歧与证据限制
原稿强调“阴线无所阳线”（做多不买阴线）以及“找个阴线下单”（做空必须阴线），严禁在异色K线下单；若大周期不支持则属于低胜率的逆手交易，原则上不予执行。
