# S-3251 TRP顺势波段与减半接回操作法

> 来源：SRC-000346（期货_期货投机分析20250918_联动下跌_区间下限虽破_留下余量再观察（增强版））· 证据 E-73964、E-73966
- 性质：规则完整的策略
- 规则版本：TRP二分仓顺势减半接回规则版
- 完整度分级：已给方向
- 效果证据：白银议息会议下二分仓避免5%~6%全进全出磨损并顺势补齐收益（E-73966、E-73967）；欧线集运守前高免除三对连续磨损（E-73977）。

## 目的与适用环境
用于期货分时与日内波段投机交易，在单边与波动行情中捕捉趋势波段，并通过二分仓与减半机制降低消息面冲击和震荡走势中的来回磨损。

## 条件与动作
| 阶段 | 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- | :--- |
| 环境过滤 | 穿透状态过滤，空方穿透只做空不做多，多方穿透只做多不做空 | 分时/盘中实时 | E-73964、E-73968 | 逆穿透状态变色严禁开仓 |
| 形态或指标形成 | TRP指标变色（做空出现绿豆，做多出现红豆）且发生数值实质穿透 | K线收盘时 | E-73964、E-73972 | 一色K法则逐K判定，指标数值相同不算穿透 |
| 确认 | 收K阴阳线确认，空单必须收阴线且收盘位于绿豆下方，禁止顶着阳线开空，无色K线不下单 | 对应周期K线收盘时点 | E-73965、E-73969、E-73970 | 盘中未收盘不确认，阳线及无色K线严禁下单 |
| 入场 | 优先贴近豆子收K下单；若未碰豆子，则评估止损空间是否在可承受范围（如0.37），能承受即下单，不能承受则等贴近豆子 | K线收盘确认后次K开盘 | E-73965、E-73971 | 远离豆子且无法承受止损空间时不得开仓 |
| 初始止损 | 以豆子价格或前高点设防，允许万分之一等细微容差（如白银59对58） | 入场成立时 | E-73965、E-73971 | 具体止损点数视品种波动幅度承受度决定 |
| 仓位与资金 | 二分仓配置，分为底仓与加仓各半，严禁全进全出操作 | 建仓与加仓时点 | E-73966、E-73967、E-73976 | 全进全出单K波动会白白产生5%~6%磨损 |
| 持仓与跟踪 | 价格运行在豆子顺势方向且收K保持同色时持续持有波段仓位 | 持仓周期内 | E-73971、E-73977 | 盘中剧烈波动不提前离场，等待收K判定 |
| 加减仓 | 价格反抽收K站上绿豆平半仓；重新跌回绿豆下方或出现阴线半仓接回；若顺势延伸且未破前高可执行加仓 | 收K站上或跌回收盘时点 | E-73966、E-73975、E-73976 | 前高未破时后续同级磨损不接回，避免反复磨损 |
| 止盈与退出 | 指标彻底反向变色（如空单遇红豆阳线坐实）清空剩余半仓全部平仓；波段结束 | 变色收K确认时点 | E-73964、E-73976 | 盘中未收定不可提前清仓 |
| 失效与放弃 | 夜盘尾盘最后一个K线不下单；遇跳空大缺口已大幅脱离成本区放弃入场；反向突破防守前高则策略失效 | 尾盘或开盘跳空时点 | E-73969、E-73977 | 原稿未明确缺口回补具体量化规则 |

## 规则之间怎样衔接
以穿透状态为大前提，只有穿透方向与豆色一致才进入K线收盘确认；入场后执行二分仓管理；当价格反抽站上豆子时触发减半平仓；减半后以前高作为防守参考，前高不破则后续同级反复磨损一律不操作；若转为反向变色则清空剩余仓位，若顺势跌破则半仓接回或加仓（E-73964、E-73966、E-73975、E-73977）。

## 案例和失败方式
成功案例见白银2025年9月17日夜盘二分仓平空接回抵御美联储议息会议冲击（E-73966）；失败方式包括：逆多方穿透状态盲目做空（如氧化铝变绿开空被套，E-73968）、全进全出导致承受单根阳线近5%浮亏白白产生5%~6%磨损（E-73967）、顶着阳线开空或在尾盘强行开单遭跳空破坏（E-73969）。

## 版本分歧与证据限制
本策略基于原稿TRP系统讲解，仅增强稿可见；原稿未明确TRP指标的具体数学公式与底层均线参数；对止损承受点数（如0.37）属于交易者主观风险承受度，原稿未给出全品种通用数值量化标准（E-73964、E-73971）。
