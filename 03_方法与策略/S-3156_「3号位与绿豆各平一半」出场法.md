# S-3156 「3号位与绿豆各平一半」出场法

> 来源：SRC-000331（期货投机分析20250820_跌破关键点位_空单大部盈利_注意短线回抽控制回撤）· 证据 E-72905
- 性质：规则完整的策略
- 规则版本：V2.0（基于塑料空单反思改进版本）
- 完整度分级：已给方向
- 效果证据：在塑料反弹及螺纹钢空单中，相较于等待红豆翻色，能显著提前锁定一半利润，有效压缩回撤幅度。

## 目的与适用环境
针对空单盈利后底部反弹剧烈、回撤过大的极端品种，通过将出场分配调整为常态123结构的3号位平一半、绿豆平一半，平衡利润保留与卖飞风险。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 空单持仓处于大幅盈利状态，行情单边下跌后进入底部反弹回抽阶段 | 5分钟周期 | E-72905 | 无 |
| 形态或指标形成 | 底部K线走出123反转形态，且形态必须符合5K法则 | 5分钟周期 | E-72911 | 需满足K线数量约束 |
| 确认 | 形态确立且出现破底翻确认K线，锁定123结构的3号位价位 | 5分钟K线收盘 | E-72906 | 若3号位模糊则无法启用 |
| 入场 | 前序空头单按顺势规则完成建仓 | 5分钟周期 | E-72910 | 原稿未明确前序入场具体规则 |
| 初始止损 | 沿用空头持仓原有跟踪止损 | 5分钟周期 | E-72905 | 原稿未单独定义 |
| 仓位与资金 | 平仓比例由原「绿豆一半、红豆一半」调整为「3号位一半、绿豆一半」 | 出场时点 | E-72905 | 固定比例分批退出 |
| 持仓与跟踪 | 行情未触及3号位前维持空单持仓 | 5分钟周期 | E-72905 | 无 |
| 加减仓 | 当价格触及或收破123结构3号位时，立即执行减半仓操作 | 5分钟K线收盘 | E-72905 | 实现提前兑现利润 |
| 止盈与退出 | 剩余半仓在价格反抽触及或站上TRP绿豆时清空退出 | 5分钟周期 | E-72905 | 不再死等指标彻底变红 |
| 失效与放弃 | 若品种形态不规则导致3号位不清晰（如聚丙烯），该规则放弃，退回按绿豆减半 | 5分钟周期 | E-72907 | 依赖形态清晰度 |

## 规则之间怎样衔接
前接顺势空单的持仓跟踪，中段结合形态学123结构与破底翻，后段结合TRP绿豆指标实现多重退出。

## 案例和失败方式
塑料空单因按旧规则死等变红，半仓盈利遭反弹大幅吞噬；螺纹钢学员在减半兼破底翻K线全清成功规避回撤；失败方式为提早平仓导致后续主跌浪卖飞[E-72905][E-72906][E-72911]。

## 版本分歧与证据限制
旧版本为「绿豆和红豆一样一半」平仓；改进版本为「三号位和绿豆一样一半」平仓。
