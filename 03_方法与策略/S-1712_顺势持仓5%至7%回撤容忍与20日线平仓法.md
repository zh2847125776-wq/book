# S-1712 顺势持仓5%至7%回撤容忍与20日线平仓法

> 来源：SRC-004732（第2043课 股票日评：趋势比单个K线更加重要与不放量的阳线不可靠（20220928））· 证据 E-63263、E-63264、E-63265
- 性质：规则完整的策略
- 规则版本：V1（20220928）
- 完整度分级：已给方向
- 效果证据：原文强调20日线下不做多、反弹找卖点，不平空单可避免被5%至7%的假反弹洗出，防止卖飞顺势大波段。

## 目的与适用环境
适用于在单边下跌大趋势中持有空头头寸（或空仓观望股票）时，通过容忍短均线反弹波动，锁定顺势大波段收益。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线级别 | E-63264 | 价格处于20日均线下方，大势空头排列 |
| 形态或指标形成 | 盘中反弹 | E-63263、E-63264 | 价格出现5%至7%的超跌反弹或站上5日均线 |
| 确认 | 均线级别对比 | E-63265 | 价格仅站上5日线，未触碰或突破20日核心均线 |
| 入场 | 反弹找卖点 | E-63264 | 反弹遇阻时加空或股票高抛，严禁做多 |
| 初始止损 | 20日线突破止损 | E-63265 | 收盘价有效站上20日均线作为空单终极平仓线 |
| 仓位与资金 | 顺势持有 | E-63263 | 空头头寸全程持有，股票账户保持空仓 |
| 持仓与跟踪 | 每日收盘监控 | E-63263、E-63264 | 忍受5%至7%的反弹回撤，不为局部波动所动 |
| 加减仓 | 50线不平空 | E-63265 | 站上5日线时不平空单，等待20日线信号 |
| 止盈与退出 | 站上20日线平仓 | E-63265 | 唯有收盘价站上20日核心均线时才平仓空单 |
| 失效与放弃 | 突破20日线 | E-63264、E-63265 | 突破20日线后空头策略失效，空单全平转入观望 |

## 规则之间怎样衔接
1. 根据“20日线下不做多，反弹找卖点”确立顺势基调；
2. 过滤掉站上5日线的杂波信号，拒绝在5日线平空；
3. 容忍5%-7%的反弹回撤，直至价格站上20日线才触发平仓。

## 案例和失败方式
- 案例：2022年9月28日创业板反弹刺破5日线，讲述者指出不做波段者必须忍受该5%-7%反弹，空单在站上20线前坚决不平。
- 失败方式：在站上5日线时恐慌平空，随后价格在20日线下方再度暴跌导致空单卖飞。

## 版本分歧与证据限制
原稿口误处出现“50线”，讲述者实指5日均线（下文明确为站上20线再平空），已在底本疑点中规范标注。
