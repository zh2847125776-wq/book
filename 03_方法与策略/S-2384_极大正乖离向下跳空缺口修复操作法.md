# S-2384 极大正乖离向下跳空缺口修复操作法

目的与适用环境

用于在标的处于多方穿透但累积极大正乖离率（原稿作正管理率 [原稿如此，疑误]）并突发向下跳空缺口时，介入高风险高赔率的逆势空单。适用环境为期货日内出现跳空低开缺口且伴随极大正乖离的特殊行情。

规则之间怎样衔接

极大正乖离下跳空开盘 -> 首K确认下空单 -> 设最高价加余量止损 -> 下行后出红色箭头果断平仓止盈 -> 闭环结束。

案例和失败方式
实战推演案例：沪金出现跳空向下缺口，按779.58元加余量止损做空，下行至红色箭头处精准止盈（E-65952, E-65956）。
失败方式：不带余量被毛刺打掉，或出反向红色箭头后迟疑不止盈导致利润回吐。
