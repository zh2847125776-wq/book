# S-3258 《日内交易策略》商品期货品种波动率与盈利率过滤法

> 来源：SRC-000172（第课 专题_技术专题_番外--一月实盘验证策略收益（增强版））· 证据 E-74054, E-74055, E-74056, E-74057, E-74058
- 性质：待验证组合方案
- 规则版本：原稿未明确（源自《日内交易策略》一书实盘延伸）
- 完整度分级：已给方向
- 效果证据：2025年6月16日至7月16日一个月实盘验证，金、银、铜、镍、油、锡六品种获得合计 19.15%[原稿如此，疑误] 无杠杆收益；白银胜率 55.55%（语音口播 55.25%[原稿如此，疑误]），黄金胜率 66.66%（语音 66 点多）；油和锡贡献最高绝对盈利；90% 以上交易当日触发止盈或止损（E-74055, E-74056, E-74057）。

## 目的与适用环境
用于商品期货日内回转交易策略的标的初选与过滤，剔除低波动与负收益品种，优选高胜率与高绝对盈利率品种，提高资金利用效率（E-74055, E-74056, E-74058）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 筛选具备充足日内波动率的期货品种，直接剔除波动率过低品种（如铜） | 实盘开仓前初选 | E-74058 | 未给出量化波动率具体计算公式与阈值 |
| 形态或指标形成 | 依据《日内交易策略》书内既定规则形成进场信号 | 日内分时/K线 | E-74054 | 原文未公开具体指标代码与参数 |
| 确认 | 盘中信号满足触发条件 | 白盘与夜盘开盘后 | E-74054, E-74055 | 支持白盘与夜盘交易 |
| 入场 | 日内信号触发后开仓进场 | 日内交易时点 | E-74054 | 未披露挂单类型（市价或限价） |

| 失效与放弃 | 铜因波动率过低淘汰；镍因实盘盈利不佳淘汰，禁止在铜镍上使用该策略 | 策略定期评估时 | E-74055, E-74058 | 明确禁止在铜与镍品种上使用 |

## 规则之间怎样衔接
以日内波动率初筛剔除铜 -> 实盘跟踪盈利能力淘汰镍 -> 选定金与银保障高胜率、油与锡博取高绝对收益 -> 盘中严格执行当日止盈止损或收盘清仓（E-74055, E-74056, E-74057, E-74058）。

## 案例和失败方式
案例：2025年6-7月实盘中，白银胜率 55.55%、黄金胜率 66.66%、原油收益率 8.10%、锡收益率 4.34%。失败方式：在铜与镍等低波动或低适应性品种上机械运用日内策略，导致资金利用率极低或无法获利（E-74055, E-74056, E-74058）。
