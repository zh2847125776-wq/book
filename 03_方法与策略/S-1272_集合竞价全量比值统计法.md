# S-1272 集合竞价全量比值统计法

> 来源：SRC-004541（第1871课 补涨补跌公式因子与三级支撑总表）· 证据 E-61525, E-61526
- 性质：局部方法
- 规则版本：第1871课当日版本
- 完整度分级：已给方向
- 效果证据：通过长期全量总和相除获取真实系数常数，排除单日竞价噪声对全天量能的干扰（E-61525）

## 目的与适用环境
通过大样本量化统计获取指数或板块的真实集合竞价系数常数，用于早盘精准推算全天成交量。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 适用于宽基指数或行业板块，需具备长期连续交易历史数据 | 长期历史截面 | E-61525 | 个股波动过大原稿未推荐 |
| 形态或指标形成 | 抓取过去长期（如5年、10年，概念尺度一万天）的每日集合竞价金额与成交量 | 统计核算期 | E-61525, E-61526 | 原稿提出一万天总和概念 |
| 确认 | 将历史所有集合竞价金额累加，除以历史所有全天成交量累加，得出真实系数常数 | 测算确立时 | E-61525 | 严禁用单日昨日比值代替 |
| 入场 | 原文未明确（本方法用于推算全天成交量，非交易信号） | 原文未明确 | 无 | 缺口：无买卖动作 |
| 初始止损 | 原文未明确 | 原文未明确 | 无 | 缺口：无止损规则 |
| 仓位与资金 | 原文未明确 | 原文未明确 | 无 | 缺口：无资金管理参数 |
| 持仓与跟踪 | 当日早盘获取开盘集合竞价金额后，代入系数常数预估今日全天成交量 | 每日9:25后 | E-61525 | 结合板块特性调整预期 |
| 加减仓 | 原文未明确 | 原文未明确 | 无 | 缺口：无加减仓规则 |
| 止盈与退出 | 原文未明确 | 原文未明确 | 无 | 缺口：无止盈规则 |
| 失效与放弃 | 若标的为新能源、5G等高弹性成长板块，比值差值极大，模型精度下降 | 遭遇高弹性板块 | E-61525 | 原文提示高弹性板块不准 |

## 规则之间怎样衔接
所推导出的全天预估成交量，直接输入到量价关系三角形（K-3393）与序时缩量定性法（S-1266）中进行放量/缩量判定。

## 案例和失败方式
案例：使用一万天集合竞价累加总和除以成交量累加总和，得到稳定的板块特征系数（E-61525）。
失败方式：误以为"昨日竞价/昨日成交量 = 今日竞价/今日成交量"，在大盘股或震荡日推算全天量能产生重大偏差（E-61525）。

## 版本分歧与证据限制
原稿指明该算法在实操中需要抓取过去5-10年数据并进行多组数据平均平滑，但原稿未提供具体的代码或EXCEL执行表格。
