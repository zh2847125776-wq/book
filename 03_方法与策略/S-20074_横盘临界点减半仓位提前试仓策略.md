# S-20074 横盘临界点减半仓位提前试仓策略

> 来源：SRC-000406（期货_期货投机分析20260127（增强版））· 证据 E-93711
- 性质：待验证组合方案
- 规则版本：临界分仓试仓法2026版
- 完整度分级：已给方向
- 效果证据：在氧化铝、苯乙烯等品种上，通过减半仓位提前试仓，将止损控制在3~7跳以内，防范暴力突破无法追入的踏空风险（E-93711, E-93712, E-93713）。

## 目的与适用环境
解决横盘区间上轨突破可能过快导致追高成本过大或无法成交的问题。适用于波动剧烈且贴近箱体上沿、止损点数极窄的临界状态。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 价格运行至横盘区间上线临界区域，且经历多次震荡磨损（接近分布高发期如7~8次） | 5分钟/15分钟周期 | E-93711, E-93712 | 无 |
| 形态或指标形成 | APL轨道红线与绿线距离极窄（如相差3跳），现价距绿线极近（如相差7跳） | 5分钟K线实时 | E-93711 | 无 |
| 确认 | K线坐在红线上，或出现平台刚抬升的第一个平台阳线 | 5分钟K线收盘 | E-93713 | 无 |
| 入场 | 预计仓位减半（如10手先下5手），在现价提前开多单布局底仓 | 临界现价 | E-93711, E-93713 | 必须减半建仓 |
| 初始止损 | 跌破APL绿线（或跌破区间近低，如苯乙烯7613）触发止损离场 | 入场即设 | E-93711, E-93713 | 止损幅度极窄 |
| 仓位与资金 | 首批底仓为预计仓位的一半（50%），突破确认后加另外50% | 分批执行 | E-93711, E-93713 | 控制单次磨损风险 |
| 持仓与跟踪 | 持有底仓等待突破；若盘中走错跌破绿线则在盘中离场 | 盘中跟踪 | E-93712 | 承担时间成本 |
| 加减仓 | 突破横盘区间上线（或指标变红）后，加仓剩余一半仓位（如再加5手） | 突破确认时 | E-93711, E-93713 | 顺势加仓 |
| 止盈与退出 | 原稿未明确具体点位，按单边持仓跟踪或指标翻色离场 | 原稿未明确 | E-93711 | 原稿未明确 |
| 失效与放弃 | 价格跌破区间下沿（如上证类比4090）或跌破近低/绿线，全部止损放弃 | 盘中跌破 | E-93712, E-93713 | 无 |

## 规则之间怎样衔接
临界底仓先行动作由窄止损条件保障；突破后加仓由顺势动能触发；若假突破破绿线则止损小亏出局。

## 案例和失败方式
氧化铝（ao9999）贴近2746上线，红线2731与绿线2728仅差3跳，现价2735距绿线仅7跳，采用减半仓位提前试仓（E-93711）；苯乙烯（eb9999）平台抬升，首批下5手，变红后再加5手（E-93713）。

## 版本分歧与证据限制
属于主动承担磨损换取成本优势的做法，原文指出亦可完全等待突破后再做，两种选择各有优劣，由交易者自选。
