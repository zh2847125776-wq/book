# S-3172 底部箱体突破与回测补仓策略

> 来源：SRC-000158（专题_技术专题_几种基础补仓与止损操作策略详表（增强版））· 证据 E-73112
- 性质：局部方法
- 规则版本：讲师2022年9月18日直播授课版
- 完整度分级：已给方向
- 效果证据：讲师在思维导图中详细给出了仓位拆分与回测买卖规则矩阵

## 目的与适用环境
当价格在单边深跌后均线系统走平、按照均线系统操作连续遭遇频繁被扫单失效时，识别底部横盘箱体修正形态，利用箱顶突破与回测机制进行分批补仓救套。· E-73112、E-73113

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线周期，标的处于单边大幅下跌末期，均线系统连续频繁被扫单失灵 | E-73112 | 必须以均线交易反复失败作为形态切换的前置先兆 |
| 形态或指标形成 | 均线系统（MA5/MA10/MA20）基本走平无斜率，多根K线反复多次穿越、翻越均线，形成清晰的底部箱体形态 | E-73112 | 手划线带有主观性，若个股无规律无法画出明显几何图形则放弃 |
| 确认 | 日K线收盘价放量突破箱顶压力线 | E-73113 | 突破需为有效突破，防范假突破打回 |
| 入场 | 突破箱顶确认成立时，买入总设计补仓仓位的一半（50%仓位） | E-73113 | 首次买入严禁满额，必须预留另一半资金用于回测确认 |
| 初始止损 | 突破入场后若价格跌破箱顶支撑线，立即止损全部已建仓位 | E-73113 | 以箱顶水平线作为多空分水岭硬止损位 |
| 仓位与资金 | 总补仓资金设计严格限制在底仓等量以内，突破买入50%，回测成功再买入50% | E-73113、E-73108 | 严禁超配资金，严格执行分批建仓纪律 |
| 持仓与跟踪 | 买入半仓后价格若未回测且持续上行，则坚定持有已有半仓；若开始回测则密切观察箱顶支撑表现 | E-73113 | 无回测行情不追高，仅享受已有半仓收益 |
| 加减仓 | 价格回测箱顶且未跌破箱顶支撑，确立回测成功，立即买入预留的另外一半补仓仓位 | E-73113 | 若回测跌破箱顶，则触发止损规则，全额止损离场 |
| 止盈与退出 | 回测成功持满仓后，持续上行寻找卖出止盈机会（如跌破5日线出局）；无回测持续上行则持有半仓寻机止盈 | E-73113 | 原稿提及涨幅过大破5日线等作为卖出指引 |
| 失效与放弃 | 回测跌破箱顶全部止损；出现二次以上多次虚假突破导致手划线规划彻底失败时，放弃该形态操作 | E-73113、E-73112 | 手划线天然孱弱，若主力不认箱体则策略全面失效 |

## 规则之间怎样衔接
核心逻辑遵循口诀：「突破买入（半仓）、回测买入（另一半）、回测失败一把止损、回测成功持有待涨」。若行情直接逼空未给回测机会，则仅持有初始半仓寻机止盈，绝不中途追涨，形成攻守兼备的分批风控链条。· E-73113

## 案例和失败方式
1. 典型规划口诀：突破箱顶买入一半，开始回测且未跌破买入另一半；回测若跌破箱顶则全部止损。· E-73113
2. 典型失败方式一（手划线被破坏）：箱体遭遇多次假突破打回，导致箱顶画线规划完全失效。· E-73112
3. 典型失败方式二（回测破位）：突破后回测不仅未能获得箱顶支撑，反而大幅下陷砸穿箱顶甚至创出新低，若不坚决止损将导致两批补仓资金全军覆没。· E-73113

本策略源自讲师思维导图操作表格，手划线可靠性在课中被讲师定性为孱弱的补充分析方法，优先级别低于均线系统；对于其他由上限与下限构成的修正区域（如底部三角形、下倾楔形等），原稿仅称「操作方式大同小异」，未单独展开细化参数。· E-73112、E-73113
