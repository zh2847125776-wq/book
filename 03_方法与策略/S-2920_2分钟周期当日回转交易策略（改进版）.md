# S-2920 2分钟周期当日回转交易策略（改进版）

> 来源：SRC-000300（期货_期货投机分析20250619_趋势订单继续磨损_当日回转表现优异（增强版））· 证据 E-70477, E-70481, E-70482, E-70483, E-70487, E-70489, E-70490
- 性质：待验证组合方案
- 规则版本：大陆期货改进版（增加波段高低点止损与拉回二过滤）
- 完整度分级：已给方向
- 效果证据：原油累计8笔交易5胜3负整体盈利，单笔回报达0.89%~1.16%；白银/黄金单笔亏损约0.19%~0.4%。（E-70490, E-70491）

## 目的与适用环境
用于大陆商品期货高波动、高流动性特定品种（镍、铜、银、金、油）的2分钟超短线日内波段捕捉，追求当日离场不过夜的高确定性收益。（E-70477）

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 盘初选品，2分钟周期 | E-70477 | 仅限镍铜银金油，玉米、螺纹、国债等低波动标的严禁参与 |
| 形态或指标形成 | 开盘第1~2根K线，2分钟周期 | E-70481, E-70483 | 首根K线定方向基准：阳线偏多、阴线偏空、无色K看第2根 |
| 确认 | 回调结构形成时，2分钟周期 | E-70481, E-70483 | 严格要求拉回二才开单，拉回一坚决不做；突破必须高一跳/低一跳 |

| 失效与放弃 | 盘中任意时点，单日维度 | E-70477, E-70478 | 单品种单日达到2笔交易后立即停止交易，严禁开立第3单 |

## 规则之间怎样衔接
首根K线定基调 → 观察拉回深度（拉回二确认） → 寻找高一跳/低一跳的突破时机 → 以4~5根K线的波段拐点定损并计算1:1.5止盈 → 触及目标离场或尾盘退出 → 记录单日笔数达2笔后停止。（E-70477, E-70481, E-70483, E-70489）

## 案例和失败方式
原油20250618第1笔多单依开盘低点设损、1:1.5止盈成功赚取1.16%；第2笔多单再次开出即触发止损亏损0.62%，两笔轧差净赚0.5%后停止操作。（E-70489, E-70490）失败方式主要为窄幅水波下跌中无波段止损点而无法开单，或条件单遭遇SFP假突破套在极值。（E-70479, E-70482）

## 版本分歧与证据限制
原版书做谷物且拉回一即开单，讲述者回测后改为做工业品且拉回二才开单；原版书R为单蜡烛回溯，讲述者强制要求波段高低点。（E-70481, E-70487）
