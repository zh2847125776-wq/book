# S-2394 大市值非ST盈利标的四不买初筛操作法


来源：SRC-002730（读书_10聪明的投资者（增强版））· 证据 E-66007, E-66008

性质：规则完整的策略
规则版本：原文未明确（未分版）
完整度分级：已给方向
效果证据：原文作者自述通过严格执行四不买与市值100亿以上初筛，能有效过滤庄股假突破，确保技术回测（如站上20日线）的高确定性，同时大幅降低暴雷踩雷几率（E-66007, E-66008）
目的与适用环境

用于在股票交易前进行底层标的池清洗，排除垃圾庄股与高风险地雷股。适用环境为A股股票市场日常选股与股票池维护。

规则之间怎样衔接

全市场标的 -> 剔除新股次新股 -> 剔除ST亏损股 -> 筛选市值>100亿 -> 优先国企/行业龙头 -> 构建900只核心交易底池 -> 结合技术系统开仓。

案例和失败方式
成功应用案例：在宁德时代、金龙鱼等大市值知名龙头中依托技术均线捕捉主升收益（E-66007, E-66008）。
失败方式：违背初筛纪律购买小市值ST拉夏等濒临退市品种，遭遇站上20日线后次日不回测直接连续跌停闷杀。
