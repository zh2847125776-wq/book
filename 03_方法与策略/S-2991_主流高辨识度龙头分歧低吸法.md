# S-2991 主流高辨识度龙头分歧低吸法

> 来源：SRC-000263（第955章 分歧低吸绝技，解锁龙头逆袭密码！）· 证据 E-71217
- 性质：局部方法
- 规则版本：分时均线与辨识度低吸版
- 效果证据：原文作者实战案例表明，某设备国产替代概念股回踩10日线低吸后，次日反包阴线开启主升行情，两周涨幅超50%。（证据 E-71219）

## 目的与适用环境
用于在弱市抱团或板块分歧震荡阶段，通过锚定主流题材中的高辨识度新龙头，在市场情绪分歧或均线企稳时低吸介入，获取“买入分歧、卖出一致”的次日溢价或主升收益。（证据 E-71217、E-71218）

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线周期，处于弱市或主流题材分歧期，资金趋向抱团取暖 | 证据 E-71217 | 必须处于国家大基金等重点扶持的主流题材浪潮中，淘汰老龙头 |
| 形态或指标形成 | 日线周期，短期均线走平微翘，股价向上突破平台后缩量回调至关键均线（如10日线）获得支撑 | 证据 E-71219 | 调整过程成交量必须持续萎缩，显示市场惜售心理浓厚 |
| 确认 | 分时周期，分时均线缓缓抬升且股价稳步走高，或均线上行中伴随震荡整理（暗示主力锁仓做T） | 证据 E-71217 | 若均线向下而股价虚拉，属背离预警，主力出逃信号 |
| 入场 | 分时低点，出现缩量止跌或长下影线等明确企稳信号时，分批建仓低吸介入 | 证据 E-71219、E-71220 | 坚决禁止抄底无承接的跌停板，分批操作降低试错成本 |
| 初始止损 | 盘中时点，均线由升转平，股价跌破均线支撑且无反弹迹象时，果断止损离场 | 证据 E-71219 | 规则机械触发，不可带有主观侥幸心理 |
| 仓位与资金 | 建仓时点，严格执行控制仓位、分批建仓原则，留出风险控制机动资金 | 证据 E-71220 | 原文未给出分批建仓的具体资金比例（如3-3-4等） |
| 持仓与跟踪 | 日线周期，股价若沿短期均线稳步上行，则保持持仓；观察成交量温和放大 | 证据 E-71219 | 警惕庄股“拉链式出货”的脉冲式异常放量陷阱 |
| 加减仓 | 持仓周期，原文未明确二次加仓规则，强调底仓分批布局与风险防范 | 证据 E-71220 | 缺加仓触发条件，仅记录建仓控制仓位 |
| 止盈与退出 | 分时与日线周期，遵循“卖出一致”，在连续缩量加速后早盘封板午后炸板跳水瞬间果断卖出逃顶 | 证据 E-71218 | 全民共识狂奔看多时须警惕物极必反，连续缩量炸板为派发窗口 |
| 失效与放弃 | 分时时点，若分时均线与股价同步下滑，或遭遇假突破回抽破位，果断移出自选池 | 证据 E-71217 | 跌破均线且无反抽时交易逻辑彻底失效 |

## 规则之间怎样衔接
以主流题材与高辨识度确立选股池；以短期均线走平微翘及回踩缩量确立买点；以分时均线上行与分批建仓控制风险；以情绪高度一致缩量加速后的炸板瞬间确立止盈退出。（证据 E-71217、E-71218、E-71220）

## 案例和失败方式
1. 成功案例：某设备国产替代概念股横盘后放量长阳突破平台，随后三日缩量回调至10日线附近获支撑，依据“买分歧”原则建仓，次日反包阴线两周涨幅超50%。（证据 E-71219）
2. 失败方式：简单将“买分歧”理解为抄底跌停板导致接盘被套；被庄股“拉链式出货法”盘中多次假性拉升诱多欺骗。（证据 E-71217）

## 版本分歧与证据限制
原文给出了“主流题材辨识度+明确企稳信号+控制仓位分批建仓”三维度系统，但未提供分批资金配比阈值及炸板卖出的分时具体挂单价位，完整度分级为已给方向。（证据 E-71217、E-71220）
