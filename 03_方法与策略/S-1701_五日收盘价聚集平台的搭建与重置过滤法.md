# S-1701 五日收盘价聚集平台的搭建与重置过滤法

> 来源：SRC-004727（第2039课 股票日评：均线压制的两个条件与钝化不可交易（20220922））· 证据 E-63228
- 性质：局部方法
- 规则版本：20220922实盘讲解版
- 完整度分级：已给方向
- 效果证据：2022年9月22日创业板因收盘价与最低价连续两日下行，破坏了此前3天的平台，导致平台搭建倒计时重置，成功过滤抢反弹冲动（证据 E-63228）。

## 目的与适用环境
用于在股价受到5日均线压制时，通过检验是否形成连续5天的收盘价聚集平台，作为站上5日线及反弹有效性的前置过滤工具。

## 条件与动作
| 阶段 | 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- | :--- |
| 环境过滤 | 股价受到下行的5日均线压制，处于缩量阴跌或窄幅震荡中 | 日线周期 | E-63228 | 5日线未站上前禁止做多 |
| 形态或指标形成 | 观察连续交易日的收盘价是否紧密聚集在同一水平区间（如第3、第4、第5天构成初步平台） | 每日收盘后 | E-63228 | 平台要求收盘价高度聚集 |
| 确认 | 若后续交易日收盘价或最低价向下破位，则判定打不出平台，平台宣告作废 | 破位当日收盘 | E-63228 | 破位即作废，倒计时归零 |
| 入场 | 在平台未完整搭建并有效站上5日线之前，严格禁止进场交易 | 盘中及收盘 | E-63228 | 过滤条件，未达标前不入场 |
| 初始止损 | 「原文未明确」 | 「原文未明确」 | 无 | 原文未给出平台交易的初始止损点 |
| 仓位与资金 | 保持空仓，耐心等待 | 全程 | E-63228 | 空仓者必须保持空仓 |
| 持仓与跟踪 | 若平台被破坏，需等待新的连续两至三天收盘价走平聚集重新筑台，重新计算周期 | 后续2-3天 | E-63228 | 需重新耗费两三天时间确认 |
| 加减仓 | 「原文未明确」 | 「原文未明确」 | 无 | 原稿未提及加减仓动作 |
| 止盈与退出 | 「原文未明确」 | 「原文未明确」 | 无 | 原稿未提及止盈动作 |
| 失效与放弃 | 出现放量大阴线或大阳线打破震荡格局，平台整理逻辑转换为单边行情逻辑 | 盘后确认 | E-63228 | 需根据量能重新定性 |

## 规则之间怎样衔接
将5日平台的完好性作为站上5日均线的前提；平台若被跌破，则强行将反弹倒计时重置为零，指令交易者继续空仓等待。

## 案例和失败方式
- 案例：2022年9月22日创业板破坏5日平台，反弹倒计时归零（证据 E-63228）。
- 失败方式：在平台被破坏、价格创新低时过早猜底入场，遭遇无量阴跌。

## 版本分歧与证据限制
原稿仅定性指明收盘价聚集需达到5天平台标准，未给出收盘价偏离率的具体数值公差。
