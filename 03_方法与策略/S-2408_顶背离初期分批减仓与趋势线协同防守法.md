# S-2408 顶背离初期分批减仓与趋势线协同防守法


来源：SRC-001001（股票_20200106量化技术分析（增强版））· 证据 E-66087, E-66097, E-66098, E-66099

性质：规则完整的策略
规则版本：原文未明确（未分版）
完整度分级：已给方向
效果证据：原文讲述者自述在上证指数日线MACD红柱缩短出蓝色箭头、60分钟临波顶背离出现时，通过适度分批减仓而非一刀切清仓，结合上升趋势线与颈线防守，成功平衡了利润锁定与防过早卖飞（E-66087, E-66097, E-66098, E-66099）
目的与适用环境

用于在指数或个股处于上升主升浪末期出现多周期顶背离与超买信号时，科学控制仓位暴露并规避见顶大跌。适用环境为股票上升主升浪出现顶背离初期阶段。

规则之间怎样衔接

日线/60分钟顶背离初现 -> 逢高分批适度减仓 -> 标定上升趋势线与颈线 -> 趋势线未破继续持剩余仓位 -> 破趋势线与颈线全部清仓。

案例和失败方式
成功应用案例：2020年1月6日上证指数60分钟顶背离出现时适度减仓，既锁定了大部分浮盈，又避免了在钝化冲高时完全踏空（E-66087, E-66098, E-66099）。
失败方式：一见背离全仓抛空导致踏空主升钝化拉升，或背离出现后死守不减仓导致趋势破位时利润全部回吐。
