# S-30101 ｜目标价减半法（煤炭ETF 1.129兑现模板）

> 来源：SRC-002277（股票_量化技术分析20250723_量能过大_警惕调整_守好五日线（增强版））· 证据 E-90406, E-90407
> 来源：SRC-002278（股票_量化技术分析20250724_阳线平稳_继续安心做多_注意板块轮动（增强版））· 证据 E-90411

## 一句话定义
到达事先给定的目标价就兑现一半锁定基本收益，剩余一半用最近阳线中线与50线防守去博超额收益；高开跌回目标价下方本身就是有压力的减仓信号。{E-90406}{E-90407}

## 条件与动作表
| 步骤 | 条件 | 动作 |
|---|---|---|
| 环境过滤 | 持有品种接近预设目标价，且允许标尺升级带来的小偏差 | 把目标价当作战术纪律，不臨时改价 {E-90406} |
| 形态或指标形成 | 到价或高开冲过目标价 | 进入兑现流程，不再追买 {E-90406} |
| 确认 | 高开后掉到目标价下面 | 确认目标价有压力，减仓信号成立 {E-90407} |
| 入场 | 本方法只管持有者的兑现，不管新开仓 | 想买必须等回调调好，不追高 {E-90411} |
| 初始止损 | 剩余仓位以最近阳线中线与50线为防守 | 7月23日煤炭对应阳线中线1.092与50线 {E-90407} |
| 仓位与资金 | 不需要复杂分仓 | 减一半或一次性卖出均可，实在拿不准就二分仓 {E-90407} |
| 持仓与跟踪 | 减仓后跟踪目标价得失 | 站回目标价可拿，继续掉就再减 {E-90407} |
| 加减仓 | 到价只减不加 | 减仓部分落袋，剩余部分守线博超额收益 {E-90406} |
| 止盈与退出 | 目标实现即成功 | ETF赚10个点约等于个股20个点且风险更小，知足 {E-90406} |
| 失效与放弃 | 高开追进是错误示范 | 当日高开追进者自行检讨交易纪律，不补仓摊平 {E-90407} |

## 出处与依据
本方法完整复刻7月23日煤炭ETF的处置：目标1.129昨日已到，高开跌回1.129下是减仓与卖出信号，不想走就守1.092与50线；7月24日该品种仍卡在1.129，继续等回调、不追。{E-90406}{E-90407}

## 与其他概念的关系
本卡是K-70163压力位管理的品种级落地：指数看3674一带，品种看自己的目标价。
与S-30102是并列的退出分支：S-30101管“到价兑现”，S-30102管“见顶兑现”，触发条件不同、减半手法相通。
C-30100是本卡的完整实盘对应例，数字与过程一一锚定。
