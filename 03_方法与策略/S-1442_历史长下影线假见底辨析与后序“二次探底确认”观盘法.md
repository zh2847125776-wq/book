# S-1442 历史长下影线假见底辨析与后序“二次探底确认”观盘法

> 来源：SRC-004604（第1928课 股票日评：5%的度量与外资只配大盘股（20220506））· 证据 E-62111
- 性质：规则完整的策略
- 规则版本：V1.0
- 完整度分级：已给方向
- 效果证据：通过复盘A股历史著名大底（2440、3373、2850）均无明显下影线或必有下来确认的事实，识破单凭一根长下影线直接见底的假象，耐心等待二次探底打双底。

## 目的与适用环境
在市场出现长下影线探底反弹时，利用历史实证统计破除“见单根长下影线即见真底”的经验主义迷信，建立二次探底与双底确认观盘模型。

## 条件与动作
| 步骤 | 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- | :--- |
| 环境过滤 | 市场在连续大跌后收出一根带有极长下影线的日K线或周K线，引发全网大底欢呼 | 长下影线出现后 | E-62111 | 视觉见底诱惑 |
| 形态或指标形成 | 激活历史反证数据库：调取历史上所有真正大底（如2440、3373、2850等），核查其成底形态特征 | 历史对表审查 | E-62111 | 历史大底检验 |
| 确认 | 总结历史真实规律：明确在历史上真正的大底几乎没有依靠一根长下影线就落了底的，即便有长下影线，后序也必然存在一次再次下来的二次探底确认过程 | 规律定性瞬间 | E-62111 | 必须下来确认 |
| 决策 | 制定二次探底双底跟踪预案：拒绝在长下影线当天盲目追涨入场，耐心等待指数再次回踩前低附近（如2863点）构筑扎实双底结构 | 决策预案设立 | E-62111 | 等待二次探底 |
| 初始止损 | 不适用开仓；持币防御 | 全流程 | E-62111 | 杜绝左侧冲动 |
| 仓位与资金 | 账户股票仓位保持0%，现金处于完全防守状态 | 观盘全周期 | E-62111 | 保持充分耐心 |
| 持仓与跟踪 | 盯防后序交易日（如下周三前后）是否顺应天数对称再次跌回前低附近，观察二次探底是否形成底背离 | 跨周跟踪时段 | E-62111 | 跟踪双底构筑 |

| 退出 | 待指数完成二次探底打出扎实双底、并以放量阳线站稳右侧颈线时，假见底辨析策略转入右侧双底进攻 | 双底确立时刻 | E-62111 | 迎来右侧做多 |

## 适用边界与失效
适用于宏观大级别底部形态的真伪辨析；若市场出现极端政策暴力干预直接V型连续大阳狂飙脱离成本区且不再回头，则二次探底失效。
