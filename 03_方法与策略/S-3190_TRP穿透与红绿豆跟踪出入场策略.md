# S-3190 TRP穿透与红绿豆跟踪出入场策略

> 来源：SRC-000336（期货_期货投机分析20250901_趋势尚未突破_耐心做好每一笔交易）· 证据 E-73304, E-73305, E-73313
- 性质：规则完整的策略
- 规则版本：TRP2（含正负乖离率自动计算版本）
- 完整度分级：已给方向
- 效果证据：氧化铝第一波盈利，第二波及焦煤多次减半接回产生磨损；热卷空单持续盈利中。

## 目的与适用环境
用于期货小周期（如5分钟）的顺势波段跟踪交易，在均线穿透确立方向后，通过TRP红绿豆系统捕捉顺势机会并以减半接回方式管理持仓波动（证据 E-73304, E-73305, E-73313）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线周期 | E-73304, E-73307 | 日线大周期需支持方向，均线排布较近，非高位滞涨或顶在区间上限压制区 |
| 形态或指标形成 | 5分钟K线 | E-73304, E-73305, E-73310 | 出现多方穿透或空方穿透，指标转为红豆（多）或绿豆（空）状态；穿透前已有大幅波动的单子不追 |
| 确认 | 5分钟收K前 | E-73303, E-73304, E-73305 | K线拉回贴近红豆（多头）或贴近绿豆（空头），正负乖离率极小；距离红豆/绿豆过远时不宜直接开单 |
| 入场 | 5分钟收K瞬间 | E-73304, E-73305, E-73313 | 多方穿透贴近红豆收阳线（或一色K）开多；空方穿透贴近绿豆收阴线开空；阴线不开多，阳线不开空 |
| 初始止损 | 入场同时 | E-73304, E-73305, E-73310 | 依托TRP指标数值止损，或以前期区间上限/下限、极值点为硬止损；5分钟周期止损上限预支1个点以内（如0.7%或0.5%） |
| 仓位与资金 | 开仓时 | E-73299 | 原文未明确初始固定开仓比例公式；在无趋势震荡期严禁加高杠杆比例 |
| 持仓与跟踪 | 持仓期 | E-73305, E-73313 | 持仓过程中K线在红豆上方顺势运行保持多单，在绿豆下方顺势运行保持空单；忽略微小毛刺，遵守收K判定 |
| 加减仓 | 5分钟收K时 | E-73305, E-73312, E-73313 | 收K跌破红豆（多单）或收K站上绿豆（空单）执行仓位减半；随后K线重新攻破并脱离红豆/绿豆时执行接回原减半仓位；震荡中频繁减半接回会产生手续费磨损 |
| 止盈与退出 | 收K变色时 | E-73305, E-73311, E-73313 | 持仓反向变色（红豆转绿豆或绿豆转红豆）执行全部清空离场；或达到预设大周期终极目标位时止盈离场；不可在未变色前主观恐慌平仓 |
| 失效与放弃 | 盘中触发时 | E-73301, E-73305 | 入场后未走出单边即刻反向穿透，或触发初始硬止损，立即止损放弃；被反向穿透后严禁抗单 |

## 规则之间怎样衔接
穿透定多空方向 → 贴近豆且收同色K线定入场 → TRP/形态极值定初始止损 → 逆向破豆减半 → 顺向脱离接回 → 变色清空离场（证据 E-73304, E-73305, E-73312, E-73313）。

## 案例和失败方式
案例：热卷2025年8月29日9:05给空单，止损0.5%，按收K站上绿豆减半、掉落绿豆接回、变红清空持续盈利（证据 E-73313）。
失败方式：震荡市中多次破豆接回导致手续费磨损（如氧化铝第二笔、焦煤夜盘），或开单即遇反向穿透止损（证据 E-73306, E-73312）。

## 版本分歧与证据限制
TRP原版需手工比对，TRP2版本增加了正负乖离率自动计算功能；原稿未明确具体的绝对仓位手数，仅给出“减半”与“接回”的相对操作（证据 E-73305, E-73312）。
