# S-2730 止损破位后重新站回关键位的二次接回评估法

> 来源：SRC-005126（第2399课 股票日评：遇阻整理静待节后方向选择（20240430））· 证据 E-68813、E-68815
- 性质：局部方法
- 规则版本：突破止损后再接回复盘规则
- 完整度分级：已给方向
- 效果证据：电科技术4月16日破38.85元止损后，4月22日彻底站回接回，随后持续上涨最终收涨11.68%（E-68813、E-68816）。

## 目的与适用环境
解决个股因突发利空或主力洗盘击穿技术止损位后，股价迅速收复失地时的“卖飞”与“追回两难”问题，确立客观二次接回条件。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤：标的属于月度投资组合精选个股，且大盘整体处于横盘未崩或走好阶段 | 选股入池时点 | E-68812、E-68816 | 大盘走坏时不适用 |
| 形态或指标形成：持仓个股因突发大跌（如财报避险）击穿初始止损位或整数关口（如电科技术破38.85元、海思科破26元） | 破位当日 | E-68813、E-68815 | 当日出现破位阴线 |
| 确认：第一步：破位当日严格执行止损抛出；第二步：观察次日是否下反回测无法收复（若收复不了确认破位出局） | 破位当日及次日 | E-68813、E-68815 | 严禁破位死扛 |
| 入场：标的随后重新站回原止损关口，且进一步彻底站上20日均线时执行二次接回（如电科技术4月22日、海思科4月23日） | 站回关键价与20MA当日 | E-68813、E-68815 | 若仅站回关口但被20MA压制则不可轻易接 |
| 初始止损：重新接回后以再次跌破该关键关口或20MA为新的止损线 | 接回当日确定 | E-68813、E-68815 | 原文未明确具体容忍点数 |
| 仓位与资金：恢复原组合持仓仓位份额 | 接回当日执行 | E-68813 | 原文未明确资金分配明细 |
| 持仓与跟踪：接回后观察均线是否由走平恢复为顺势助推，跟踪波段上行 | 持仓期间 | E-68813、E-68815 | 若20MA持续走平则持仓面临犹豫 |
| 加减仓：原文未明确接回后的加仓规则 | 持仓期间 | E-68813 | 原稿未提供 |
| 止盈与退出：个股后续触及周期目标位或发出ELG逃顶/剔除信号时止盈退出 | 上涨波段末端 | E-68813、E-68814 | 不同个股依系统信号执行 |
| 失效与放弃：若重新接回后再度失守关键关口或20MA均线反转下行，则二次止损出局并放弃该标的 | 再次破位时 | E-68813 | 防止反复被假突破侵蚀本金 |

## 规则之间怎样衔接
破位严格止损保护本金 -> 次日下反回测确认 -> 站回关口保持观望（受制于20MA） -> 彻底站上20MA消除压制后执行接回 -> 再次破位无条件放弃。

## 案例和失败方式
成功案例为电科技术4月22日彻底站回接回后持续大涨（E-68813）；复杂案例为海思科4月23日接回时20MA持续走平导致持仓犹豫（E-68815）。

## 版本分歧与证据限制
接回条件中“彻底站回20MA”为核心判据，若20MA持续走平原稿表明存在主观犹豫，缺乏绝对硬性判定公式。
