# S-3003 TRP红绿豆贴近加单与反向清仓策略

> 来源：SRC-000310（⏱ 00:03:30、⏱ 00:05:00、⏱ 00:05:30、⏱ 00:08:30）· 证据 E-71323, E-71324, E-71325, E-71327
- 性质：规则完整的策略
- 规则版本：TRP红绿豆波段跟踪策略
- 完整度分级：已给方向
- 效果证据：焦煤、烧碱、铜单笔均实现盈利；欧线集运变色止损小亏

## 目的与适用环境
用于捕捉顺应指标趋势的波段行情，依托价格贴近TRP指标线时的极紧止损空间，进行多次试探、顺势加码与动态减仓防守。 · 证据 E-71321, E-71327

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 开盘扫描时（5分钟/60分钟） | E-71322 | 优先核验高多低多均线系统，避免逆势 |
| 形态或指标形成 | 盘中K线回踩或反弹至红绿豆附近 | E-71321 | 离豆远的品种一律提亮放弃，只做发生相对关系的品种 |
| 确认 | 贴近指标豆豆后收出同向确认K线 | E-71324 | 红豆漏了没法下空单；做多需贴近红豆且收阳线 |
| 入场 | 首次变色后第一次贴近进场，或后续多次贴近进场 | E-71324, E-71327 | 只要接触未破，可连续进行N次贴近开仓 |

| 加减仓 | 空单站上绿豆平一半，跌漏绿豆接回一半 | E-71325, E-71327 | 多单则贴近红豆时持续加单（加单N次） |

## 规则之间怎样衔接
以价格与红绿豆产生相对相交关系为前提触发，结合高多低多均线排列确认；入场后通过两倍仓位的半仓进退化解盘整磨损，保持主仓持续运行；最终以反向站上指标减半、彻底变色清干净完成闭环。 · 证据 E-71322, E-71323, E-71325

## 案例和失败方式
- 焦煤主连（jm9999）：翻红后多次贴近加单连续获利，最终以第N次接触变色止损退出。 · 证据 E-71327
- 烧碱主连（SH9999）：空单经历两次站上绿豆平一半、跌漏接回一半的磨损后最终盈利。 · 证据 E-71325
- 失败方式：在震荡行情中价格频繁穿越指标线导致半仓反复平接磨损；或在均线逆势状态下强行开单导致变色扫损。 · 证据 E-71322, E-71325

## 版本分歧与证据限制
TRP指标自身具备后置确认与迟缓特性，原稿明确指出TRP自身无法自动回避磨损，缺乏辅助筛选工具，必须人工硬扛磨损。 · 证据 E-71326
