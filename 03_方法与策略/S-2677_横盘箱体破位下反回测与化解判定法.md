# S-2677 横盘箱体破位下反回测与化解判定法

> 来源：SRC-005099（第2374课 股票日评：结构完好正常调整不破位就可以继续交易（20240315））· 证据 E-68339, E-68340, E-68348
- 性质：局部方法
- 规则版本：原文未明确
- 完整度分级：已给方向
- 效果证据：原文结合创业板60分钟与5分钟走势分析，说明小周期虽有反复但大周期破位判定有效。

## 目的与适用环境
用于判定震荡箱体下轨被击穿后，属于真正破位确立还是假突破，并利用回测与翻回机制制定应对与化解对策。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 价格处于横盘震荡区间（箱体）内运行，面临方向选择 | E-68339 | 需存在明确的高低点箱体边界 |
| 形态或指标形成 | 倒数第二个小时K线跌破横盘箱体下轨 | E-68339 | 以60分钟级别K线击穿为准 |
| 确认 | 最后一个小时收盘K线下反回测箱体下轨未能重新站上 | E-68339 | 回测不过确认突破有效 |
| 入场 | 破位确立后不做多单，多头止损或清仓；原文未给出反手做空具体规则 | E-68339 | 原文强调多头市场不轻易开净空单 |
| 初始止损 | 原文未明确空头止损点位 | E-68339 | 缺初始止损参数 |

| 加减仓 | 原文未明确加减仓动作 | E-68339 | 缺加减仓参数 |

| 失效与放弃 | 三个K线确认有效：若次日早盘第一个小时重新翻回到箱体内部，则破位化解 | E-68340 | 未能翻回则下跌确立 |

## 规则之间怎样衔接
首先通过“跌破箱体+下反回测不过”初步确立箱体向下突破；随后进入“三个K线确认有效”观察窗口：若次日首个小时翻回箱体内则破位警报解除，若翻不回则彻底转入下跌周期。

## 案例和失败方式
创业板指数在2024年3月14日倒数第2小时跌破横盘区间，最后一个小时下反回测未过；3月15日早盘第1小时未能翻回箱体内部，确立为顶部箱体破位下跌。失败方式为小周期频繁假信号导致T+1机制下纠错被套（见 E-68348）。

## 版本分歧与证据限制
原文指出5分钟小周期频繁出现调整信号，但因非T+0交易制度，频繁纠错会导致亏损幅度累积，需依靠大周期或三个K线确认提高可靠性。
