# S-1633 均线压制双因子评估与逢高离场法

> 来源：SRC-004699（第2013课 股票日评：五日线压制与技术指标钝化（20210730））· 证据 E-62962, E-62963
- 性质：局部方法
- 规则版本：V1.0
- 完整度分级：已给方向
- 效果证据：20210730上证最高3404点精准受阻于向下5日线（3404/3403.86），因连续3日成交不足5日均量，逢高触线坚决减仓清仓。

## 目的与适用环境
在超跌反弹或弱势震荡中，利用均线斜率与均量匹配度精准判定阻力高点，指导持仓筹码逢高离场，防止反弹坐过山车。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| **环境过滤** | 指数或个股处于中短期均线下方运行，上方均线（如5日均线）呈现向下倾斜状态 | 日线 | E-62962 | 顺应空头压制背景 |
| **形态或指标形成** | 评估因子一：上方均线朝向向下且斜率陡峭，具备极强压制与助跌能力 | 日线 | E-62963 | 越陡峭阻力越强 |
| **确认** | 评估因子二：近3个交易日成交量持续低于该均线周期均量（如5日均量） | 每日收盘 | E-62962 | 量能不足则无法突破 |
| **入场** | 本规则为退出与减仓规则，均线压制确认期严禁开仓买入 | 盘中 | E-62963 | 严禁逆向开多 |
| **初始止损** | 原持有多头以向下均线价格作为移动止损/止盈参考 | 实时 | E-62963 | 触线即为防守点 |
| **仓位与资金** | 借助反弹逐步降低多头仓位至空仓 | 盘中 | E-62963 | 不留风险敞口 |
| **持仓与跟踪** | 盘中跟踪价格反弹逼近均线的点位（如5日线3404点） | 盘中 / 实时 | E-62963 | 观察触线后的量价反应 |
| **加减仓** | 价格触及向下均线时坚决执行减仓，严禁加仓 | 触线即刻 | E-62963 | 逢高减磅 |
| **止盈与退出** | 价格触及向下均线阻力位且量能不济时，果断清仓离场 | 盘中触线时 | E-62963 | 兑现反弹利润或减少亏损 |
| **失效与放弃** | 若市场爆出天量且大阳线强力收复均线实体，压制假设解除 | 收盘 | E-62962 | 必须放量站稳方算失效 |

## 规则之间怎样衔接
识别均线陡峭向下 -> 确认成交量不足均量 -> 锁定均线价格阻力 -> 盘中触线果断离场减仓。

## 案例和失败方式
案例：20210730上证最高3404精准受阻于5日线3404，成交量仅5600亿不足5日均量6000亿，触线离场全天最高；失败方式：误以为反弹反转而在5日线阻力位盲目追涨加仓。

## 版本分歧与证据限制
主要应用于5日线短期压制，亦可扩展至10日线、20日线，计算时需严格核对对应周期的成交均量数据。
