# S-3363 三信号二触发分级平仓法

> 来源：SRC-000362（期货_期货投机分析20251104（增强版））· 证据 E-75100
- 性质：局部方法
- 规则版本：原稿未明确
- 完整度分级：已给方向
- 效果证据：黄金实盘空单平仓有效规避后续反弹回撤，铁矿石出场虽卖飞但符合风控一致性。

## 目的与适用环境
用于单边顺势持仓在行情转弱或出现反转迹象时的分批保护性退出，平衡让利润奔跑与防范利润大幅回吐的矛盾。（E-75100）

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 单边持仓中行情由强势单边转弱，小周期开始出现结构性减速或分歧 | E-75113 | 强势单边中无破翻间隔则不触发 |
| 形态或指标形成 | 监控三组退出信号：①破翻形态成立；②VB指标上穿；③MAVB指标上穿或拐头 | E-75100 | 原稿未说明三信号先后顺序要求 |
| 确认 | 信号确认必须满足结构有效性，破翻必须符合5K法则，非5K结构不得作为有效1-2-3号位 | E-75103 | 必须等待K线走完满足5根K线跨度 |
| 入场 | 不适用（本策略专属于持仓退出模块） | E-75100 | 无新开仓动作 |
| 初始止损 | 维持原有持仓的近高或近低初始止损不变，直至触发退出条件 | E-75099 | 若未触及出场信号前先打初始止损则全损 |
| 仓位与资金 | 分批阶梯减仓，每触发一个信号平仓50%头寸 | E-75100 | 固定分两批，各占一半仓位 |
| 持仓与跟踪 | 三个信号中首个信号触发后，平仓50%仓位，剩余50%头寸继续跟踪 | E-75100 | 原稿未提供剩余头寸是否移保本 |
| 加减仓 | 当第二个信号触发时，平掉剩余50%头寸，全部清空离场 | E-75100、E-75114 | 仅减仓与清仓，无加仓动作 |
| 止盈与退出 | 若三个信号中任意两个先后触发，即完成全量止盈离场 | E-75100 | 可能出现离场后顺原方向再创新低的卖飞代价 |
| 失效与放弃 | 强势下跌过程中中间无破翻间隔，则三信号未成立，严禁提前主观平仓 | E-75113 | 仅适用于趋势走弱阶段 |

## 规则之间怎样衔接
作为顺势持仓的后续退出模块，前承开仓后的近高/近低初始止损，后接清仓完毕后的观望状态。（E-75099、E-75100）

## 案例和失败方式
黄金空单在破翻位置平仓一半，随后VB上穿平掉剩余一半，成功锁定利润；铁矿石9:30 VB上穿平一半，9:45 MAVB拐头清空，后续价格继续下跌导致卖飞，但属于一致性规则允许的代价。（E-75100、E-75114）

## 版本分歧与证据限制
仅增强稿可见；讲师提示平仓信号触发后可能遭遇反弹即再创新低导致的“卖飞”，但原稿未给出避免卖飞的附加参数。（E-75100）
