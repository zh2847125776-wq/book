# S-2386 期货持仓管理与保证金占用控制法


来源：SRC-000286（期货_期货投机分析20250523_指数窄幅震荡_及时止盈是不错选择（增强版））· 证据 E-65955

性质：局部方法
规则版本：原文未明确（未分版）
完整度分级：已给方向
效果证据：原文作者自述通过严格限制保证金占用至80%上限，有效防范持仓过多导致的资金断裂与心态失衡（E-65955）
目的与适用环境

用于在期货多品种多策略交易中控制总账户保证金敞口，规范换单纪律，杜绝因持仓过度分散或冲动换单导致亏损与卖飞。适用环境为期货多品种日内与隔夜持仓管理。

规则之间怎样衔接

监控保证金占用 -> 达到80%停止开新单 -> 锁死换单冲动拿住旧单 -> 旧单正常止盈或止损平仓 -> 释放闲置资金后重新开新单。
