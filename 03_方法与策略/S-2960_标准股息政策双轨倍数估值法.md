# S-2960 标准股息政策双轨倍数估值法

> 来源：SRC-002748（第19课 读书_19聪明的投资者（增强版））· 证据 E-70922
- 性质：局部方法
- 规则版本：格雷厄姆经典证券分析乘数法
- 完整度分级：只给名称缺参数
- 效果证据：书中假设测算二类公司估值均为36美元；但讲述者指出该倍数在A股等市场缺乏依据与普适性（证据 E-70922、E-70929）。

## 目的与适用环境
用于在公司遵循标准股息政策（利润三分之二分红）的前提下，基于预期利润或预期股息估算二类普通股的内在公允价值（证据 E-70922）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 公司处于成熟稳定经营环境，遵循标准股息政策（将通常利润的2/3派发股息） | E-70922 | 成长型企业及不分红企业不适用 |
| 形态或指标形成 | 测算出公司未来的预期平均利润（如3美元）与预期股息（如2美元） | E-70922 | 未来利润与股息的预测公式书中未给出 |
| 确认 | 确认股息与利润之间存在正常的 2:3 比例关系 | E-70922 | 若比例发生变动（如派发率降至55%~59.5%）则基准改变 |
| 入场 | 当市场交易价格显著低于公式推导的合理价值（如36美元）时买入 | E-70922 | 买入安全边际折扣比例原文未在此节列出 |
| 初始止损 | 原文未明确 | E-70922 | 格雷厄姆基本面估值法未设技术止损线 |
| 仓位与资金 | 原文未明确 | E-70922 | 未给出单笔投资仓位比例 |
| 持仓与跟踪 | 长期跟踪公司的每股利润与股息派发连续性 | E-70921、E-70922 | 未给出持有期限上限 |
| 加减仓 | 原文未明确 | E-70922 | 缺失动态调仓规则 |
| 止盈与退出 | 估值分别按“预期利润 × 12倍”或“预期股息 × 18倍”进行测算，当价格达到或超出测算目标（如36美元）时退出 | E-70922 | 未交代两套计算结果发生分歧时的取舍标准 |
| 失效与放弃 | 若企业摒弃高股息政策，或利润与股息比值偏离2:3，该公式失效 | E-70922、E-70929 | 对利润变动非线性企业完全失效 |

## 规则之间怎样衔接
利润估值轨道（每股利润 × 12）与股息估值轨道（每股股息 × 18）在利润/股息满足 3:2 时互相印证（3×12 = 2×18 = 36美元）（证据 E-70922）。

## 案例和失败方式
- 书中测算案例：预期利润3美元、预期股息2美元，对应股价均为36美元（证据 E-70922）。
- 失败方式：讲述者指出若股息变为4美元，18倍乘数得出72美元，与利润乘数36美元严重背离，方法彻底失去一致性判据；且A股存在大量多年不分红的“铁公鸡”企业，该公式直接瘫痪（证据 E-70929）。

## 版本分歧与证据限制
- 讲述者质疑乘数12与18的数学与统计来源书中完全未做阐述；且未考虑A股低分红与无分红国情（证据 E-70929）。
