# S-30102 ｜连板龙头开板减半、破五清仓法

> 来源：SRC-002277（股票_量化技术分析20250723_量能过大_警惕调整_守好五日线（增强版））· 证据 E-90405
> 来源：SRC-002278（股票_量化技术分析20250724_阳线平稳_继续安心做多_注意板块轮动（增强版））· 证据 E-90413, E-90415

## 一句话定义
连板或连续大涨的高位龙头，一开板（或收阴线）就至少减半，剩下一半以破五日线为最后防线；高位追买必套，只能等回调。{E-90405}{E-90415}

## 条件与动作表
| 步骤 | 条件 | 动作 |
|---|---|---|
| 环境过滤 | 连板股、连续三阳放量加缺口的高位品种 | 只做兑现计划，不做新开仓计划 {E-90405} |
| 形态或指标形成 | 开板，或冲高回落收阴 | 标志接近完事，进入减半流程 {E-90405} |
| 确认 | 东方电气式下跌收盘或阴线收盘 | 未在板上减半者当日必须减一半 {E-90415} |
| 入场 | 高位不入场 | 一追就套，回调到支撑再说 {E-90405} |
| 初始止损 | 短线以昨日低点、板上价为止损 | 跌漏即走，不等反抽 {E-90415} |
| 仓位与资金 | 开板先减半，不要求一次全出 | 收阴减半也行，开板减半也行 {E-90405} |
| 持仓与跟踪 | 剩余一半跟踪五日线 | 五日线不破就拿，破了清干净 {E-90405} |
| 加减仓 | 昨日板上已减半者今日不重复操作 | 有底仓才有主动权，不加错仓 {E-90415} |
| 止盈与退出 | 破五日线清干净剩余仓位 | 完事离场，等回调再说 {E-90405}{E-90415} |
| 失效与放弃 | 向下突破横盘平台 | 彻底休息，不再接回 {E-90413} |

## 出处与依据
本方法合并两处口述：7月23日电键、西藏天路、东方电器类“开板至少减半、收阴减半亦可、破五清干净”；7月24日东方电气“昨日板上减一半今日不操作、否则下跌或阴线收盘减一半、剩下一半破五出”。{E-90405}{E-90415}

## 与其他概念的关系
本卡是S-30100持有体系的反向刹车：S-30100管趋势内参与，本卡管高位龙头的分段下车。
与S-30101同属退出家族：S-30101按目标价兑现，本卡按开板与破五兑现。
C-30101中字头与C-30102东方电气分别是本卡在板块与个股上的实盘锚点。
