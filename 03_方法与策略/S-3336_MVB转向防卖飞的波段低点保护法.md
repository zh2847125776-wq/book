# S-3336 MVB转向防卖飞的波段低点保护法

> 来源：SRC-000358（期货_期货投机分析20251029（增强版）） · 证据 E-74828
- 性质：局部方法
- 规则版本：讲师20251029实盘复盘口述版本
- 完整度分级：已给方向
- 效果证据：白银2025年10月28日-29日持仓过程中抵御10点20及次日下午向下信号，守住波段低点享受高开暴涨（E-74828, E-74829）。

## 目的与适用环境
用于单边上涨行情持有多单时，应对MVB等敏感系统在震荡或盘整中频繁发出向下卖出信号，防止过早平仓卖飞后续主升浪，通过承担可控回撤换取大波段利润。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤：标的处于明确上涨常态或单边上涨趋势中持有多单 | 日内5分钟/15分钟级别 | E-74828 | 原稿未限定特定期货品种 |
| 形态或指标形成：MVB系统发出向下拐头或转向卖出信号 | 盘中持仓实时 | E-74828 | 信号出现且伴随阴线收盘 |
| 确认：检视盘面最近的定量化波段低点（5K低点）是否被跌破 | 转向信号出现时 | E-74828, E-74829 | 必须有明确量化波段低点锚定 |
| 入场：不涉及新开仓，仅作为持仓管理与退出判定规则 | 原文未明确 | E-74828 | 非独立开仓系统 |
| 初始止损：建仓时设定的5K近低加余量点位 | 建仓时点 | E-74829 | 需在开仓前测算合格盈亏比 |
| 仓位与资金：测试阶段可开两手进行策略效果对照统计 | 盘前规划 | E-74830 | 资金分配比例原稿未明确 |
| 持仓与跟踪：只要最近波段低点（5K低点）未被跌破，忽略系统卖出信号继续持有多单 | 持仓跟踪全程 | E-74828, E-74829 | 需愿意承受浮盈回撤代价 |
| 加减仓：可采用一手按系统信号平仓、一手按波段低点持有的对照测试 | 卖出信号发出时 | E-74830 | 属于实操检验建议 |
| 止盈与退出：若价格有效跌破最近波段低点，形成高低点下移的下降常态，立即全部平仓 | 波段低点跌破时 | E-74828 | 破位即确认趋势转折成立 |
| 失效与放弃：若最近波段低点过远、潜在回撤幅度过大无法承受，则放弃波段防守，改按系统信号离场 | 转向信号评估时 | E-74829 | 回撤超出承受预值时放弃 |

## 规则之间怎样衔接
本规则作为持仓跟踪与退出环节，承接前期背离破翻多单入场；在退出端用“上涨常态前提/波段低点”作为过滤网，屏蔽敏感系统的微小假信号，仅在确认跌破波段低点形成下降常态时与终极退出规则对接。

## 案例和失败方式
白银在10月29日下午1点35分出现向下信号（阳线未下单），1点40分阴线确认向下，若按信号平仓则错失晚盘高开暴涨；按本方法以最近5K波段低点未漏为由坚持持有，成功避免卖飞。失败方式：价格急跌直接击穿波段低点，导致回撤幅度显著扩大。

## 版本分歧与证据限制
存在两套执行标准：一是纯机械化执行系统转向（信号出、穿回接，震荡耗费手续费）；二是守波段低点承受回撤换取单边持仓。讲师指出MVB系统入场精准的代价是出场不太利索，需在确定性与回撤幅度之间进行权衡。
