# S-3487 连续大K线突破异色K线出场策略

> 来源：SRC-000381（期货_期货投机分析20251215（增强版））· 证据 E-92070
- 性质：局部方法
- 规则版本：20251215大K线动态扩利版
- 完整度分级：已给方向
- 效果证据：白银实盘中大K线后异色K出场实现2.33%收益，显著高于固定盈亏比平仓的1.35%（证据 E-92071、E-92079）。

## 目的与适用环境
用于单边脉冲行情中，当持仓单遇到连续大实体K线顶穿关键目标价格时，通过等待反向异色K线收盘平仓以获取超额利润并锁定胜果（证据 E-92070、E-92071）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 盘中持仓处于大幅浮盈状态，行情出现单边加速推进 | 盘中动态 | E-92070 | 必须具备连续大实体K线突破 |
| 形态或指标形成 | 连续出现同向大实体K线强势顶穿关键目标价格 | 突破发生时 | E-92070 | 若仅为微小K线磨过则不适用 |
| 确认 | 观察大K线后是否出现首根反向异色K线（不分大小） | 突破后每根K线 | E-92071 | 严禁在同向大K线盘中抢跑平仓 |
| 入场 | 本策略为已有持仓单的退出策略，不涉及新开仓入场 | 开仓前置 | E-92070 | 仅用于平仓管理 |
| 初始止损 | 沿用原单底仓止损，此时持仓已脱离成本区 | 全程跟踪 | E-92079 | 处于大额浮盈保护下 |
| 仓位与资金 | 一次性全部平仓清退出场 | 出场瞬间 | E-92071 | 原稿未提及分批平仓 |
| 持仓与跟踪 | 连续同向大K线运行过程中坚决持有，享受单边利润伸展 | 推进全程 | E-92070 | 需耐受盘中剧烈跳动 |
| 加减仓 | 无加仓；出场信号确认时直接全额清仓 | 信号点 | E-92071 | 动作单向唯一 |
| 止盈与退出 | 首根反向异色K线收盘价瞬间市价平仓；备选四象图出场 | 异色K收盘瞬间 | E-92071 | 明确不建议选LPAK出场（回撤大） |
| 失效与放弃 | 若大K线顶穿后下一根K线立刻以等量大实体反杀杀回，必须立刻市价平仓 | 极端反杀时 | E-92070 | 此时放弃等待收盘 |

## 规则之间怎样衔接
突破关键价 -> 识别连续大K线 -> 跟踪同向推进 -> 监测首根反向异色K线收盘 -> 市价止盈锁定利润（证据 E-92070、E-92071）。

## 案例和失败方式
- 案例：玉米周五10:45多单大阳线顶穿目标位，异色K线收盘平仓，锁定超额利润规避后续回撤（证据 E-92071、E-92081）。
- 失败方式：异色K线若为极端跳空或长实体反向反杀K线，等待收盘平仓时可能回吐部分峰值利润。

## 版本分歧与证据限制
推荐首根异色K线收盘出场，备选四象图出场，排斥LPAK吞噬出场；底本仅增强稿可见。
