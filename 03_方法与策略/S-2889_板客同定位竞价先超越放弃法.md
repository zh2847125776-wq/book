# S-2889 板客同定位竞价先超越放弃法

> 来源：SRC-000251（第579章 揭秘：选股高手的绝密策略，你也能学会！）· 证据 E-70200
- 性质：观察信号
- 规则版本：板客选股交易模式
- 完整度分级：已给方向
- 效果证据：原文强调“盘前的首选、次选只是一个盘前判断……当你看好的某只被同定位的个股先超越先上板后，你看好的个股就要无条件放弃”（E-70200）。

## 目的与适用环境
用于短线板客在盘前制定多只同板块或同定位个股预案后，盘中根据竞价及分时排他性竞争，及时剔除失去身位优势的被动标的（E-70200）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 盘前选出同一板块或同定位的首选与次选备选股票池 | 盘前准备阶段 | E-70200 | 盘前仅作初步判断 |
| 形态或指标形成 | 盘中观察备选个股集合竞价及竞价后的分时强弱表现 | 9:15至盘中交易时段 | E-70200 | 动态对比同定位个股强弱 |
| 确认 | 备选池中某只个股被同定位个股率先超越并先一步上板封停 | 盘中上板瞬间 | E-70200 | 同定位竞争对手先上板 |
| 入场 | 不对原看好但滞后的个股开仓，转向领先标的或观望 | 确认超越时点 | E-70200 | 原文未详述是否追击领先个股 |
| 初始止损 | 不涉及（未买入原标的） | 不涉及 | E-70200 | 规避了买入被动个股的止损风险 |
| 仓位与资金 | 对原看好的滞后个股开仓仓位归零 | 上板触发时 | E-70200 | 严禁分配资金给后排标的 |
| 持仓与跟踪 | 撤销对原看好个股的挂单监控，停止跟踪 | 领先股上板后 | E-70200 | 彻底放弃原开仓计划 |
| 加减仓 | 不涉及 | 不涉及 | E-70200 | 无 |
| 止盈与退出 | 不涉及 | 不涉及 | E-70200 | 无 |
| 失效与放弃 | 只要看好的标的被同定位个股先超越先上板，无条件放弃 | 领先股上板瞬间 | E-70200 | 绝对放弃，不得心存侥幸 |

## 规则之间怎样衔接
盘前预案提供备选池；盘中以竞价及分时强弱为动态筛选器；一旦同定位对手抢先封板，触发对原目标股的无条件放弃指令（E-70200）。

## 案例和失败方式
若在同定位个股率先涨停后，投资者仍执念于盘前首选目标而买入跟风个股，极易遭遇冲高回落炸板或次日大幅计提；必须坚决执行放弃纪律（E-70200）。

## 版本分歧与证据限制
原文明确规定了“无条件放弃”滞后个股的动作，但未细化同定位标的先超越时是否允许立刻切入率先上板的个股打板（E-70200）。
