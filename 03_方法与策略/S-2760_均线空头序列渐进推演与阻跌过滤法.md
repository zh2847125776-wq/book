# S-2760 均线空头序列渐进推演与阻跌过滤法

> 来源：SRC-005140（第2410课 股票日评：短线调整注意节奏关注关键点位（20240521））· 证据 E-69088

- 规则版本：第2410课推演链版
- 完整度分级：已给方向
- 效果证据：原文用于解释五分钟上证指数早盘跌破多空线后为何“跌不下去”，未给出统计回测胜率。

## 目的与适用环境
在价格击穿关键多空均线看似将要大跌时，推演各级均线穿越与拐头的先后顺序，识别假跌与阻跌机理，避免在均线未排好前盲目追空或恐慌杀跌。

## 规则之间怎样衔接
打漏多空线 -> 下反回测不过 -> 5穿60 -> 10穿60 -> 20穿60 -> 30穿60 -> 60冲下 -> 先测向上再测向下。在推演链条的每一层未完成前，均线结构必然阻碍单边下跌。

## 案例和失败方式
1. 案例：2024年5月21日上证指数5分钟级别早盘打漏多空线后跌不下去，通过均线推演链条层层解析，确认其需要经历5穿60至30穿60及60冲下（E-69088，E-69099）。
2. 失败方式：遭遇重大利空导致价格直接跳空破位，均线推演被动跳过。
