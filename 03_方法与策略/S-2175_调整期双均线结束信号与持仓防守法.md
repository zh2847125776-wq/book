# S-2175 调整期双均线结束信号与持仓防守法

> 来源：SRC-004947（第2237课 股票日评：五日线下返回测耐心等待调整结束（20230808））· 证据 E-65000, E-64997
- 性质：局部方法
- 规则版本：原稿初版
- 完整度分级：规则完整的策略
- 效果证据：在指数经历5日均线下反回测遇阻的折磨期，以5日与20日双均线为锚，清晰指引持仓者既不盲目恐慌杀跌，也不违规左侧加仓。

## 目的与适用环境
在价格跌破5日均线进入调整周期时，利用5日线与20日线构成的双均线系统，为持仓者提供明确的防守边界与调整结束的二次买入/加仓标准。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线周期，20日均线保持向上延伸趋势，多头大结构未坏；价格处于跌破5日线后的调整期 | E-65000 | 20日线必须向上 |
| 形态或指标形成 | 价格打到或打漏较慢均线（20日线），维持5日对20日黄金交叉（或20日线冲上）状态 | E-65000 | 维持双均线多头格局 |
| 确认 | 调整结束的核心双重确认信号：①价格收盘重新站上5日均线；②5日均线斜率发生拐折转为向上冲 | E-65000 | 站上且均线向上为标志 |
| 入场 | 此前持仓的跟踪阶段；若新买入或加仓，必须等待价格重新站上5日均线确认调整结束后执行 | E-65000 | 调整未结束严禁买入 |
| 初始止损 | 个股严格按照买入时依托自身均线设定的2%~3%止损执行，触及必损 | 证据未逐字回源, E-65000 | 个股止损独立执行 |
| 仓位与资金 | 维持原有防守仓位，禁止在调整途中左侧盲目加码 | E-65000 | 保持仓位自律 |
| 持仓与跟踪 | 价格未站上5日线前，耐心等待调整；只要未触及个股止损，保持持仓忍受波动 | E-65000 | 戒除盘中焦虑 |
| 加减仓 | 调整结束信号（站上5日线且5日线冲上）出现后，方可考虑顺势加仓 | E-65000 | 右侧加仓原则 |
| 止盈与退出 | 若价格进一步下挫导致20日均线走平被有效击穿，触发大级别防守退出 | E-65000 | 跌破20日线离场 |
| 失效与放弃 | 若20日均线拐头向下且5穿20形成死叉，双均线多头逻辑彻底失效，全线放弃多头持仓 | E-65000 | 均线死叉彻底放弃 |

## 规则之间怎样衔接
承接突破回踩策略（S-2173），将单均线防守升级为“5日与20日双均线思想”的标准化操作规范。

## 案例和失败方式
- 案例：2023年8月8日大盘回踩调整，讲师指出20日线依然向上，调整结束必须等待“站上5日线且5日线冲上”的双重信号，在此之前耐心等待（E-65000）。
- 失败方式：在5日线斜率向下压制时急躁加仓，随后市场因调整未完顺势深跌击穿20日线，导致加仓筹码被套。

## 版本分歧与证据限制
原稿指出短周期均线系统中10日与30日线可以拿掉，核心即为5日线与20日线构成的双均线博弈。
