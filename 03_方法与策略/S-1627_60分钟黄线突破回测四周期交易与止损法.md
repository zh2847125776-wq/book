# S-1627 60分钟黄线突破回测四周期交易与止损法

> 来源：SRC-004696（第2010课 股票日评：重视个股兼顾指数与突破回测阴线（20210723））· 证据 E-62941, E-62942
- 性质：规则完整的策略
- 规则版本：V1.0
- 完整度分级：已给方向
- 效果证据：20210723在60分钟级别黄线站上第1周期、回测第2周期、确认买进第3周期、打漏第4周期执行止损；金叉波段运行至第12小时死亡交叉。

## 目的与适用环境
在60分钟级别利用多空黄线（MA20）进行短线波段交易，规范从突破回测进场到打漏止损的四周期标准纪律。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| **环境过滤** | 60分钟级别处于突破回测阶段，MA60处于向下状态但在测向上MA60 | 60分钟 | E-62942 | 需结合MA60中长期均线 |
| **形态或指标形成** | 股价在第1个周期收盘站上向上的60分钟黄线（MA20） | 60分钟 / 第1周期 | E-62941 | 必须为向上走势的均线 |
| **确认** | 第2个周期完成上反回测黄线成功，第3个周期再度确认企稳 | 60分钟 / 第2-3周期 | E-62941 | 回测必须获得支撑 |
| **入场** | 第3个周期确认企稳后执行买进操作 | 60分钟 / 第3周期收盘 | E-62941 | 买前必须评估可承受亏损幅度 |
| **初始止损** | 以第3周期入场K线低点或黄线下方设定止损 | 60分钟 / 即时 | E-62941 | 严禁侥幸扛单 |
| **仓位与资金** | 根据个股风险承受能力建仓，买前想好“跌这么多能不能接受” | 60分钟 / 入场时 | E-62941 | 仓位上限原文未明确 |
| **持仓与跟踪** | 沿60分钟金叉周期持续跟踪，计数金叉运行时长 | 60分钟 / 每小时 | E-62942 | 黄金交叉通常持续11~12周期 |
| **加减仓** | 原文未明确加仓动作 | 60分钟 | E-62941 | 原文未明确 |
| **止盈与退出** | 跟踪至第12个周期出现标标准准死亡交叉时执行止盈离场 | 60分钟 / 第12周期 | E-62942 | 死亡交叉无争议时离场 |
| **失效与放弃** | 买入后第4个周期若直接打漏黄线，果断执行止损，不懊悔不沮丧 | 60分钟 / 第4周期 | E-62941 | 纪律执行，不马后炮 |

## 规则之间怎样衔接
第1周期站上 -> 第2周期回测 -> 第3周期确认买进 -> 第4周期若打漏果断止损；若未打漏则持仓跟踪至第12周期死叉离场。

## 案例和失败方式
案例：20210723上证指数60分钟黄线在第4小时打漏触发止损，随后金叉运行至第12小时标标准准死亡交叉；失败方式：第4周期打漏黄线后心存侥幸不执行止损，导致深套。

## 版本分歧与证据限制
黄线在不同软件中一般指代MA20/多空线；第4周期打漏后的具体止损价格容忍度由投资者预设。
