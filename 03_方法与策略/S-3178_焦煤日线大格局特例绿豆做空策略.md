# S-3178 焦煤日线大格局特例绿豆做空策略

> 来源：SRC-000334（期货投机分析20250826_突破之前方向频繁切换_做好交易细节（增强版））· 证据 E-73166
- 性质：局部方法
- 规则版本：大格局日线目标指引下的简化执行版
- 完整度分级：已给方向
- 效果证据：2025年8月26日上午10:10开空单，日内持仓顺利获利，夜盘持续下跌。

## 目的与适用环境
专门针对焦煤单一品种设立的特例交易方法。利用焦煤日线大格局看跌且未到目标价的宏观背景，在5分钟周期通过大幅简化规则快速捕获空头利润 E-73166、E-73167。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线级别大周期 | E-73166、E-73167 | 焦煤日线大格局坚定看跌，且宏观目标价1045.7前低尚未触及；原稿严正声明仅限于焦煤品种，禁止套用其他品种 |
| 形态或指标形成 | 5分钟周期盘中 | E-73166、E-73168 | 5分钟周期指标变为绿豆；特例免除多周期穿透验证要求 |
| 确认 | 变绿后数根K线内 | E-73168 | 观察K线序列，如出现“阳线-无色-阳线-阴线”组合，阴线确认为下单触发信号 |
| 入场 | 5分钟K线确认收盘 | E-73166、E-73168 | 只要变成绿豆并出现阴线，直接开空单；或原多单持有者剔除多单并接回空单 |
| 初始止损 | 开仓时同步设立 | E-73166、E-73168 | 依附绿豆指标位置或开仓阴线上方设防守止损；原稿未明确固定点差数字 |

| 持仓与跟踪 | 持仓全周期 | E-73166、E-73168 | 只要处于绿豆状态且未站上绿豆，保持空单持仓下看1045.7前低目标 |
| 加减仓 | 盘中K线收盘触及 | E-73168 | 价格反向站上绿豆指标时立即执行仓位减半操作 |

| 失效与放弃 | 日线目标达成或反转 | E-73166、E-73167 | 一旦日线触及1045.7目标位，或日线大格局不再看跌，该特例策略即告失效，必须恢复穿透验证 |

## 规则之间怎样衔接
入场直接简化为“日线看跌未到位 + 5分钟变绿豆下空”，摒弃穿透等待；开仓后紧密挂钩绿豆形态，站上绿豆先减半，翻成红豆全清空，红豆剔除多单，变回绿豆再度接回空单，形成机械式多空切换闭环 E-73166、E-73168。

## 案例和失败方式
1. 成功案例：焦煤主连（jm9999）8月26日上午10:10出现第4根阴线触发，学员依据特例绿豆下空，中途未触发站上绿豆减半亦未翻红，全天持仓盈利丰厚，晚盘继续深跌 E-73168。
2. 失败方式与代价：若日线看跌判断错误或遇突发反抽，因未等待穿透确认，会承受比常规品种更多的假变色磨损（从雷区滚过受伤）E-73167。

## 版本分歧与证据限制
该规则属于打破“穿透+红绿豆”常规体系的单品种定制特例版本，其成立的绝对前提是日线未跌到位。原稿明确限制其他品种通通必须结合穿透，不可跨品种迁移 E-73166、E-73167。
