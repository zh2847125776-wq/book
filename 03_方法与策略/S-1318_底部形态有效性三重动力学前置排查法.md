# S-1318 底部形态有效性三重动力学前置排查法

- **目标**：在出现双底（W底）、头肩底等经典技术形态时，进行力学前置排查，剔除假反转并防范“测漏”暴跌风险。
- **触发条件**：
  1. 市场经历较深幅度的单边下跌后，K线图表呈现小级别或日线级别的双底结构；
  2. 市场舆论普遍呼吁“双底确立、右侧反转”。
- **执行步骤**：
  1. **均线排列排查**：调取日线及周线均线系统，核查5、10、20、60均线是否处于空头排列向下发散。若各均线仍呈陡峭下行，直接判定形态处于强压制逆风区；
  2. **下行动力惯性评估**：核算此前主跌浪的垂直跌幅与持续周期。若此前为大波段连阴深跌，必须给反转形态预留足够的动能衰竭减速期，不可轻信单次拉升；
  3. **时空体量对冲校验**：将当前底部盘整的时间（天数）和空间振幅，与前序下跌浪进行对比。若底部跨度极小（又短又小），定性为“小马拉大车”的脆弱形态；
  4. **决策分流处理**：
     - 若三重排查均不合格：判定为假反转，禁止右侧追高建仓，仅按超跌反弹做超短线或彻底观望；
     - 若三重排查逐步改善且放量突破颈线：方可按反转形态轻仓介入。
- **失效与风控**：
  - 若入场后指数跌破W底颈线，视为形态彻底“测漏”，立即无条件砍仓。
