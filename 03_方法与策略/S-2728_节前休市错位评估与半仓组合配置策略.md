# S-2728 节前休市错位评估与半仓组合配置策略

> 来源：SRC-005126（第2399课 股票日评：遇阻整理静待节后方向选择（20240430））· 证据 E-68812、E-68817、E-68831
- 性质：规则完整的策略
- 规则版本：五一长假窗口策略
- 完整度分级：已给方向
- 效果证据：4月投资组合4只股票最终全部收红（电科技术收涨11.68%、广深铁路涨10.14%、广州发展冲高回落前收益良好、电科技术涨7.66%[原稿如此，两次提电科技术]），验证了组合选股与节奏控制效果（E-68816）。

## 目的与适用环境
在A股面临长假休市而外盘正常交易的时间窗口，评估休市错位风险，精选强于大盘的投资组合，通过控制仓位实现防守与进攻兼顾。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤：核对万年历评估A股休市期间实际错过的美股交易日天数；若仅错过3至4个美股交易日且大盘未崩，允许持股过节 | 节前最后一个交易日 | E-68817 | 若长假休市超过5个交易日则需按往期规则空仓为主 |

| 确认：组合个股走势需强于上证指数（如周线多头排列、非跟随大盘受周线多空线压制） | 建仓前确认时点 | E-68826 | 若形态与大盘完全相同则需小心谨慎 |

| 初始止损：每只入场个股设定明确硬性止损位（如整数关口或关键技术价位，参考海思科26元、电科技术38.85元） | 入场同时设定 | E-68813、E-68815 | 各股具体参数依独立个股预案而定 |
| 仓位与资金：节前最多买入半仓（<=50%仓位），坚决不全仓运行 | 节前建仓时点 | E-68817、E-68831 | 严格限制节前风险敞口 |
| 持仓与跟踪：持股过节期间密切关注美股纳指走势（防范4连阴跌至前低）及离岸人民币汇率波动（防范创贬值新高） | 长假休市期间 | E-68829、E-68817 | 长假期间无法在A股盘中操作 |
| 加减仓：节后开盘一切正常且大盘与个股未走坏时，再将剩余仓位打齐补齐 | 节后首个交易日 | E-68831 | 原稿未明确节后补仓具体触发价格 |
| 止盈与退出：持仓个股若次级别（如60分钟）或日线发出ELG左侧逃顶信号，或触发剔除信号时执行减仓退出 | 持仓运行周期 | E-68814 | 不同品种对应不同周期信号 |
| 失效与放弃：若指数收盘跌破3090关键支撑转为破翻，或个股跌破初始止损位，则停止建仓或止损出局 | 盘中或收盘时点 | E-68813、E-68822 | 破位后不可死扛 |

## 规则之间怎样衔接
先通过休市天数过滤确定允许半仓持股过节，再通过市值底线与强弱对比筛选个股，建仓后以半仓防守外盘波动，节后根据大盘与个股表现决定是否补齐仓位。

## 案例和失败方式
成功案例包括4月组合广州发展高位ELG逃顶（E-68814）；失败方式为个股遭遇突发大跌击穿止损位（如海思科财报前大跌6.58%跌破26元）（E-68815）。
