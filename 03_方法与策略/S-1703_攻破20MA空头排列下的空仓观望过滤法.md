# S-1703 攻破20MA空头排列下的空仓观望过滤法

> 来源：SRC-004729（第2040课 股票日评：8月29日推演与国庆节前的垃圾时间（20220924））· 证据 E-63232
- 性质：局部方法
- 规则版本：20220924实盘复盘版
- 完整度分级：已给方向
- 效果证据：创业板8月29日推演选定很差行情，指数在攻破20MA形成空头排列后坚定执行空仓观望，规避了后续一路下跌风险（证据 E-63232）。

## 目的与适用环境
用于在指数或标的跌破关键中期均线（20MA）并形成空头排列时，作为最高优先级的总过滤机制，阻断一切左侧抄底和违规操作，强制保持空仓观望。

## 条件与动作
| 阶段 | 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- | :--- |
| 环境过滤 | 指数跌破20日均线（20MA），均线系统逐步呈现空头排列趋势 | 日线周期 | E-63232 | 适用所有股票指数及个股 |
| 形态或指标形成 | 均线系统进一步形成50、20、30、60均线标准空头排列 | 日线形态 | E-63232 | 排列不整齐时亦以20MA破位为警讯 |
| 确认 | 收盘价确认攻破20MA，空头排列确立 | 当日收盘 | E-63232 | 必须看收盘价确认 |
| 入场 | 「原文未明确」 | 「原文未明确」 | 无 | 过滤法无买入动作，指令为“不去操作” |
| 初始止损 | 若持有持仓，在攻破20MA时执行离场清仓 | 破位当日 | E-63232 | 攻破20MA即为清仓信号 |
| 仓位与资金 | 保持空仓观望状态，禁止新增开仓 | 全程 | E-63232 | 严格执行空仓纪律 |
| 持仓与跟踪 | 空仓跟踪市场持续下行及打平台继续跌的过程 | 下跌全程 | E-63232 | 耐心等待客观见底信号 |
| 加减仓 | 「原文未明确」 | 「原文未明确」 | 无 | 原稿未提及加仓或减仓动作 |
| 止盈与退出 | 「原文未明确」 | 「原文未明确」 | 无 | 原文未给出反向退出参数 |
| 失效与放弃 | 市场重新放量大涨收复20MA并扭转空头排列，空仓过滤指令解除 | 盘后确认 | E-63232 | 均线恢复多头前不得解除 |

## 规则之间怎样衔接
以指数攻破20MA为总开关；开关触发后直接冻结所有交易买入指令，转入被动空仓观察期，直至均线系统重新走好多头。

## 案例和失败方式
- 案例：创业板2022年8月29日推演空仓观望，成功躲过9月全月下挫（证据 E-63232）。
- 失败方式：在攻破20MA且均线空头排列时频繁逆势抄底抢反弹，导致反复割肉。

## 版本分歧与证据限制
原稿指明指数攻破20MA即不操作，亦可结合DIF<0作为辅助简化规则。
