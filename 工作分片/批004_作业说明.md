# 批 004 作业说明

## 四道校验门（Arena 查漏补缺要求，必守）

**门1｜证据清单与卡片同步提交**：抽取记录里的证据清单必须是 TSV 五列（`证据ID<TAB>source_id<TAB>位置<TAB>原文摘录<TAB>用途`），摘录从完整稿**逐字**取。**先写记录与证据清单，再写卡片**——子代理是一次性的，失败后无法补问。

**门2｜底本层级必须逐条标注**：每条关键断言标明出自哪一层——`完整稿可见`／`仅增强稿可见`／`转述待核`。
**依据**：批003 已实证完整稿会有整节/整段缺失（第03课漏「趋势线与20线可换序」、第05课整节缺「突破后回测买卖」、第1348课整段缺唯一有结果的持仓记录）。**不能默认完整稿比精简稿全。**

**门3｜转写疑点必须隔离**：疑为转写错误的数字或术语一律标 `[原稿如此，疑误]`，**不得进入正式规则行**。

**门4｜立场标签必填**：每张卡写明来源立场——课程讲述者采纳／书中作者观点／编辑者评注／被批评的方法／原文态度不明。
**依据**：第1343课正文写「M60向下」而同课【老师点评/批判】段写「M60向上」，方向相反，证明评注段不能当原文用。

## 其他硬规矩

1. 阅读对象是**完整稿**（第 6 列路径）；完整稿不足时回查增强稿与转写，并标底本层级。
2. **不许编造**：原稿没有的定义、参数、公式、成交记录一律不写，写「原文未明确」并登记缺口。
3. **不跨课综合**：不能把甲课入场＋乙课止损拼成一套策略。
4. 只讲多头的课**不得自动镜像成空头方法**。
5. **遇到未定义的术语**（一课时提到、别课才定义）必须登记为「跨批检索目标」，不要绕过去。
6. 原稿没写合约月份的期货案例，「合约」字段一律写「原稿未明确」，不做移仓/换月连接。
7. **不要改 `01_资料与索引/` 下任何共享 TSV，也不要改缺口表**，待合并的索引行写在记录末尾。
8. **同一 ID 号段只允许一个写入者**，建卡前先查目标文件是否已存在（批003 曾发生撞号）。

## 卡片模板

知识点卡 `K-XXXX`：`# K-XXXX 名称` + 一句话定义 + `## 它解决什么问题` + `## 如何识别`（逐条写成立条件，句后标证据ID）+ `## 适用边界与失效` + `## 与其他概念的关系` + `## 案例与证据`

方法卡 `S-XXXX`：`# S-XXXX 名称` + 性质（观察信号／局部方法／规则完整的策略／待验证组合方案）+ 规则版本 + 来源立场 + **完整度分级**（已给方向／只给名称缺参数／完全缺失）+ 效果证据 + `## 目的与适用环境` + `## 条件与动作`（表格十行：环境过滤／形态或指标形成／确认／入场／初始止损／仓位与资金／持仓与跟踪／加减仓／止盈与退出／失效与放弃；每行填 条件或动作｜时点与周期｜证据ID｜限制或缺口）+ `## 规则之间怎样衔接` + `## 案例和失败方式` + `## 版本分歧与证据限制`

案例卡 `C-XXXX`：`# C-XXXX 名称` + 来源行 + 日期、品种、合约、周期、关联方法ID、来源ID + 证据性质（课堂假设／候选预案／作者自述交易／有独立记录）+ `## 当时已知信息` + `## 原计划与触发` + `## 后续过程与结果`（原稿未报告结果就写「结果未提供」）+ `## 本例说明的边界` + `## 数字与证据`

**每张卡 H1 下面必须有一行**：`> 来源：SRC-xxxxxx（第N课 课名）· 证据 E-xxxx`（跨两份资料就都写）
