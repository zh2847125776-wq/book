## 一句话总结

**MACD 是所有技术指标里唯一最重要的（共识最大），但它不是最简单的。它的核心用法 = 零轴定多空 + 快慢线金叉死叉权重表 + 红绿柱看强度，按表操作，不预测、不死扛。**

---

## 二、为什么 MACD 是最重要指标

老师称之为**"技术指标的优胜劣汰"**：
- 指标很多，用的人互相淘汰，最后剩下的大家都看 MACD
- 同花顺、大智慧、东方财富、通达信、券商定制软件——**MACD 永远是默认第一个出现的指标**
- 有的软件有 DMI、有威廉指标，但 MACD "管保齐"，一定有

**但重要 ≠ 简单**：
| 类别 | 指标 |
|------|------|
| 最简单 | 宝塔线、CCI、ASI |
| 最重要 | **MACD**（元素多→变量多→结果多） |
| 最复杂 | 布林线、三浪通道等 |

**MACD 的三大元素**：
1. **零轴**（零轴之上=多方区，之下=空方区）
2. **快慢线**（元素：金叉/死叉、距零轴远近、零轴上下）
3. **红绿柱**（元素：红柱放大/缩短、绿柱放大/缩短）

---

## 三、MACD 的定义与定位

- **1979 年 Gerald Appel 发表**，中文通用译名：**指数平滑异同平均线**
- 两大作用：**寻找买入机会 + 保护到手利润**

**胜率数据（老师给的口径）**：
- 上海机场金叉买/死叉卖，历史成功率 **69%~71%**，最低没掉过 60%，最高超不过 75
- 60% 胜率的意义：十次操作六胜四负，四对四抵消，剩两次是赚的——靠简单操作堆积长期大概率挣钱

**⚠️ 老师的核心警告：过往测未来最要不得**
- 单次操作的胜率不影响下一次（有人连续 40 次金叉买入全"倒压嘴"）
- 胜率随市场环境、个股、盘子大小、热点强弱浮动
- 反面教材：自动化交易把"三加系统历史胜率 70%"写进程序直接实盘→**亏得一塌糊涂**

---

## 四、MACD 的性格：慢

- 变化趋缓、稳定，给你**缓冲空间和操作空间**，连贯性和可靠性强
- 例子：红柱很长的时候，极罕见直接变绿出死叉（哪怕一字跌停也不直接变绿）
- 应对：选**盘子大**的个股，就不容易出现这种极端现象
- 主要应用：金叉死叉、浪形背离、穿轴、判断顶部底部

---

## 五、核心表①：金叉死叉权重表（零轴 × 远近）

快慢线在零轴上下、距离远近的组合表，老师对每格打了权重正负号：

| 结构 | 含义 | 权重 |
|------|------|------|
| 零轴**之上** + 金叉 + **近**零轴 | **最好的金叉**，向上空间大 | **+++（三加，不可改）** |
| 零轴之上 + 金叉 + 远离零轴 | 要穿很长一段空方区，穿轴前涨幅不大 | 差 |
| 零轴**之下** + 金叉 + **近**零轴 | 有穿轴预期，穿轴同时红柱放大→大涨（**二加**，也不错） | ++ |
| 零轴之下 + 金叉 + 远离零轴 | 大幅下跌后的反弹、负乖离修复、前途未卜 | 负（不操作） |
| 零轴之上 + 死叉 + 远离零轴 | 向下空间相对较大 | 减号 |
| 零轴之下 + 死叉 + 近零轴 | 向下空间大，**最差结构（三减，不可改）** | ---（不操作） |

**口诀（背下来）**：
> **零轴之上：金叉大涨、死叉小跌**
> **零轴之下：金叉小涨、死叉大跌**

**"大兴走到天安门"类比**（解释为什么近零轴的金叉好）：
- 远离零轴的金叉在"大兴"，要先穿过整个空方掌控区才到零轴（"天安门"）
- 实盘对照：穿轴前收盘价基本不动，**穿轴后三四天的涨幅就大过之前全部**
- 零轴下方近零轴金叉为什么也好：低位进场大概率演变成"一边穿轴一边红柱放大"

**注意事项**：
1. 表格是参考，并非行情绝对
2. 距离零轴**只有最小值，没有最大值**（远了还能更远，同 20 日线道理）
3. "倒压轴"（靠轴）带来不确定性（后文讲）
4. **除三加、三减结构绝对不可修改外，其他格子都可根据个人想法修改**

## 六、核心概念②：零轴 = 多空分界线

**MACD 是趋势指标，根本原因就是它有零轴这个要素。**

**零轴 ↔ 20日线 对照表**：

| 20日线用法 | MACD 对应版 |
|------------|-------------|
| 20线向上 = 上升趋势（可量化：今天比昨天高） | 快线在零轴**上方** = 多方趋势 |
| 20线向下 = 下降趋势 | 快线在零轴**下方** = 空方趋势 |
| 20线走平 = 震荡 | （无斜率概念，见下） |
| 20线**上不做空**，拉回找卖点 | 零轴**上方不做空**，死叉（拉回）找卖点 |
| 20线**下不做多**，反弹找卖点 | 零轴**下方不做多**，金叉（反弹）找卖点 |

**零轴与 20日线的两个区别**：
1. **20日线有斜率，零轴没斜率**——20日线自己能表达趋势强度；MACD 要**借红绿柱表达强度**（多方区红柱变大=强，空方区绿柱变大=强）
2. 20日线与其他均线有**交叉共振**（5穿20、20穿60）；零轴和快慢线没有交叉共振，但有**助涨助跌**作用

**乖离率（距零轴远近）**：
- 距零轴远 = 正乖离大 → 有向下吸引力；近 = 正乖离小 → 有向上反弹力道
- 负乖离大 → **没有最大值**，所以老师**在零轴下面干脆不做**（不做负乖离修复行情）
- 零轴下方抄底很难，老师明确放弃这个场景

## 七、穿零轴 = 加速信号

- 自下而上穿零轴 → **加速上涨**
- 自上而下穿零轴 → **加速下跌**
- 但有前提：**伴随力量确认**
  - 向上穿轴 + 红柱放大（多方强盛）→ 真加速；没有 → 走势犹疑
  - 向下穿轴 + 绿柱放大（空方强盛）→ 真加速下跌
- 本质原因：①反映趋势逆转 ②**约定俗成信号**——看的人多，大家都堆单子，它就成立（同"20日线为什么是核心"的逻辑）
- 老师叮嘱：**千万不要去背指标公式**——公式导出的结果才是你要的，背公式浪费时间

## 八、核心表③：红绿柱强度表（位置决定好坏）

**柱体本身的含义**：
| 区域 | 红柱 | 绿柱 |
|------|------|------|
| 零轴上方（多方掌控区） | 红柱=多方掌控全局；红柱**放大**=做多看多；红柱**缩短**=多方修整（休息≠撤退，休息后可能再创新高，例：修整7个周期后新高） | 绿柱=多方力量减弱、买盘减少 |
| 零轴下方（空方掌控区） | 红柱=空方力量减弱；红柱缩短=继续看空 | 绿柱=空方掌控全局；绿柱**放大**=看空做空 |

**关键规则：红柱放大好不好，看位置！**
- 红柱放大 + 快线**在零轴附近** = ✅ 好（大涨开始）
- 红柱放大 + 快线**远离零轴** = ❌ 不好（往往是见顶）
- 最好的三加结构 = **红柱放大 + 快线在零轴上方零轴附近**

**"单一指标进出"原则**：
- MACD 又表趋势又表强度，理论上只用 20日线也能交易（20线也表趋势表强度）
- 但 20日线和 MACD **不一定同时发信号**——谁做决定谁做参考，只能选一个
- 实例矛盾：金叉穿轴站上20线 → 次日上影回测20线精准守住（吊人线）但 MACD 红柱缩短像倒压嘴 → 按 MACD 该卖、按 20线不该卖 → **具体情况具体分析**，没有绝对答案

## 九、时间周期（多周期共振）

**原理：高周期支配、保护低周期；低周期服从高周期。**

**操作建议**：
- 用 **2~3 个周期**搭配：日线+周线+月线（凑不出月线就日线+周线，或60分+日+周）
- 选得越多可靠性越高；只盯日线金叉可靠性最低
- 高周期特点：**机会少、风险低**（月线金叉一次要等两三年）
- 卖出节奏：不必等月线死叉，**连续两根红柱缩短就可以走**

**实战案例**：
- **分众传媒**：月线+周线+日线三周期全部金叉选出 → 最后三天涨 8 个点
- **工商银行（价值投资示例）**：月线金叉收盘 3.78 → 月线死叉收盘 5.17，相对最高价涨 20%+；另一次月线金叉 2.25 → 死叉 3.6+，涨 50%+
- 工行月线"倒压嘴"后加速下跌 3~4 个周期（-2%、-7%、-2.8%），4个周期后止跌回升
- **单一周期进出**：按月线金叉进的，就要按月线标准出，别被日线上下翻飞干扰

**价值投资与技术**：价值投资者其实都懂技术分析（老师举例"弹兵"早年全是技术分析文章），看月线 MACD 选股本身就是一种价值投资姿势。

## 十、背离（顶背离 / 底背离）

**定义一句话**：
> 股价创新高、指标不创新高 = 顶背离；股价创新低、指标不创新低 = 底背离。

**老师反复强调：不要怕背离！**
- 顶背离是筹码交换激烈/派发的自然产物，**可以无限累积**（"一万次顶背离都可以"）
- 老师从没说过"出现顶背离就卖"
- 正确做法：**画趋势线**——背离本身不决定走不走，趋势线破了才走；趋势线是衡量标准

**实操中的坑**：
1. 股价每创新高，上升趋势线就要**修正**；上证一般修正 3~4 回，**修正次数越多，行情越大概率进入尾声**
2. 趋势线角度越修正越平坦 = 趋势强度越来越弱
3. 跌破趋势线后股价可能不跌、甚至站回去不创新高沿趋势线走——需要**自己的标准**（老师留了思考题：这是在干啥？）
4. **下降趋势线容易吃亏**：底背离+突破回测反复，最后还是跌下来。解法：**三盏灯结合**——站上均线+站上颈线+站上下降趋势线，三者齐备才稳

**背离的目标与限度**：
- 目标 = 回调到**指标起涨/起跌点位**，但这是**预计不是必然**——要结合成交量（有量可能到，没量到不了，有时有量也不到）
- 背离只有两种：**本波背离、邻波背离**；中间隔了太多波次的别硬比（2020 年高点别跟 2011 年比），**升格到周线月线去看**
- 与波浪理论呼应：**五浪的顶背离要跟三浪比**，跟 B 浪比没有意义
- **化解**：量能化解（不取信）；**时间化解（取信）**——足够长时间上涨后新柱体比旧柱体长，背离即化解

**波峰吞噬（学界有争议）**：
- 第二个波峰比第一个高 → 吞噬掉，算一重背离；比第一个低 → 双重背离
- 学界分歧：一重还是两重（测距目标不同）；**老师观点：算一重**
- 处理原则：**有争议就严守趋势线，别纠结几重**

## 十一、MACD ↔ 波浪理论一一对应

老师用 MACD 状态数浪（数不出浪时看 MACD 就能数出来）：

| 浪 | MACD 特征 |
|----|-----------|
| 一浪 | 零轴下方盘整后**穿零轴放红柱**（时间长、涨得慢、涨幅小） |
| 二浪 | 零轴附近死叉放绿柱，**不跌破零轴或跌破不多** |
| 三浪 | 零轴附近金叉（上头下头都行）**快速上涨、红柱大幅放出** |
| 四浪 | 高位死叉放绿柱，**时间调整有限** |
| 五浪 | 远离零轴死叉、红柱放出较短；常规结束=创新高+顶背离（头肩顶），失败=无背离顶部 |
| A浪 | 高位死叉调整，**一般不穿零轴** |
| B浪 | 反弹至前一定位置，可创新高、可多波次结构 |
| C浪 | 再次死叉后**穿零轴大跌** |

- 浪延伸，MACD 也延伸
- 在**周线、月线**上看浪形更准，别去一分钟级别钻牛角尖
- "只会浪不会算"没用：1.618/1.382/2.382 倍那套=江恩式马后炮

## 十二、本课收尾要点

1. **MACD 确实有滞后性**
2. 仅靠金叉死叉买卖**不一定挣钱**
3. MACD 可以并入"三盏灯"系统：把零轴加进均线+前高/前低体系，自建三盏灯/四盏灯系统
4. **MACD 不反映成交量**——穿轴后若维持时间短+缩量，信号存疑，要结合量能判断
5. 老师说明：今天讲的全是基础知识（百度百科都能搜到），**MACD 进阶用法留待以后课程**
