# 第618课 读书：短线狙击手——买进高值与明日高点预测

> 来源：B站「量化技术分析」读书视频《短线狙击手》（课件标注"安杰尔著"）第17期＝第618课，2023-07-29晚直播，全书300页已读至第165页（105页PDF），本节小标题"买进高值"。
> **一句话结论：买进高值＝今日高点−昨日高点，其历史平均加上今日高点即可预测明日高点，是"卖出封套"中的又一个数字；老师用创业板ETF"四个价格不再逐日抬高即转弱抛出"的实战案例，印证这种"不仅比谁高、还算高多少"的逐日量化思想，同时承认复杂性也会进一步提升。**

## 二、买进高值的定义：今日高点减昨日高点

【书中内容】（课件OCR原话）：
- "二、买进高值：指今天的高点减去昨天的高点，用以衡量今天的高点超过昨天高点的幅度。如果今天的高点没有高于昨天的高点，它会是负数。"
- 老师口语复述："如果今天的高点没有高于昨天的高点 那它就是会是负数 对吧 比如说昨天是3000 今天是2950 那你就少了50个点 是不是"

【老师点评/批判】：
- 老师先自证该方法确实存在："用以衡量今天高点超过昨天高点多少的幅度 这个有没有呢 确实是有"，随后立刻挂到自己先前的实战观察上，说明这类"逐日比较"他一直在用（见第四节案例）。

## 三、买进高值的用法：平均买进高值＋今日高点＝明日高点预测

【书中内容】（课件OCR原话）：
- "使用这个数字时，是将平均买进高值加上今日高点，以判断明天出现的高点位置。这就产生了卖出封套中的另一个数字。"
- 课件示例表（今天的高点 / 昨天的高点 / 买进高值）：
  - 1284.00 / 1281.00 / 3.00
  - 1285.50 / 1284.00 / 1.50
  - 1292.00 / 1285.50 / 6.50
- 本页开头承接上文的残句："可能低于这个数字，也可能超越这个数字。它只代表一个阻力数值，表明基于最近的市场走势，上涨行情应该会在这里终止。"

【老师点评/批判】：
- 老师口语复述用法："使用这个数字时 是将平均买进高值 加上今日高点 判断出明天高点出现的位置 这样就产生了一个卖出风套中的另一个位置 假设今天的高点是1284"——明确该数字属于"卖出封套"体系的又一构成项。
- 老师对方法的定位："它可以说是比我们的研究更进一步 它不管你是怎么想的 它不光是研究今天和昨天谁高 还要研究今天比昨天高了多少 是吧 就是更进一步 但是复杂性也会进一步提升"——肯定其量化精度更高，同时点出计算复杂度上升的代价。

## 四、老师案例：创业板ETF"四价抬高"转弱抛出（行情仅作背景）

【老师点评/批判】（实盘复盘原话）：
- "大家记不记得我们在前一段时间 我们看一下 前段时间我们有一次是直接抛掉了创业板指数ETF 是在哪一天呢 是在这一天……我们下午一点半直播 一边直播一边跟大家去讲 抛掉这个创业板指数ETF 隔天就出现了大跌 是吧 是个经典案例"
- 抛出逻辑："原因就是之前都是四个关键 你讲 开盘价 收盘价 最高价和最低价都能每天抬高 直到这一天就做不到每天抬高了 所以说我们说它转弱了 然后我们做的本身就是站上50线的抄底行情 所以说到了这就抛了"
- 该画面为创业板指（399006）日线，2023-07-28收盘后K线在2187—2272一带窄幅震荡，仅作讲解背景，不构成书中内容。
