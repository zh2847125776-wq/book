## 三、交割单骨架：纸浆 sp2409 空单一笔

画面 OCR 可辨认的表格字段：序号、品种、开单价、开单时间、平空单信号、平空单价格、平单时间。可辨认的一行实例如下：

| 项目 | 内容（OCR 原样照录） |
| --- | --- |
| 品种 | 纸浆 sp2409 |
| 开单价 | 5970 |
| 开单时间 | 2024/6/14 22:56 |
| 开（空）信号 | "5分钟在向下多空线下方"、"macdo轴穿输向下有突破" |
| 平空单价格 | 5948 |
| 平单时间 | 2024/6/15 10:03 |
| 平（空）信号 | "绿柱缩短站上a5或拐头"、"跌幅不大实体站上止盈" |

按表中数字做算术：开空 5970、平空 5948，价差 22 点（5970 − 5948 = 22，为按表内数字的直接推算；对应盈亏金额增强笔记未载，不推算）。表格中另有"220"字样，含义 OCR 无法确证，如实照录。

信号字段读音备注：OCR 原文"macdo轴穿输向下有突破"按上下文疑为"MACD 0轴穿越向下有突破"，"a5"疑指 A5 均线；均照录原样、仅作提示，不改动原字。

【老师点评/批判】前提：纸浆 sp2409 于 2024/6/14 22:56 依"5分钟在向下多空线下方"、"MACD 0轴穿越向下有突破"开空 5970；反例/失效条件：离场同样等信号——"绿柱缩短站上A5或拐头"、"跌幅不大实体站上止盈"，到 2024/6/15 10:03 才以 5948 平空，不是凭持仓时间；风险或盈亏比要点：按表内数字开空 5970、平空 5948，价差 22 点（对应盈亏金额增强笔记未载，不推算）。
