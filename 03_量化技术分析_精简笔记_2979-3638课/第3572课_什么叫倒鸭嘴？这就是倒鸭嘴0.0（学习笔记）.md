# 第3572课 什么叫倒鸭嘴？这就是倒鸭嘴0.0（20220915）

> 来源：B站UP主「量化技术分析」20220915（什么叫倒鸭嘴？这就是倒鸭嘴0.0，星期四）。精简版：只留行情判读、关键点位、指标条件与交易纪律，闲聊与个人经历已剔除。

## 一、关键点位与大盘位置

- 上证已接近前低3155，现价3183，红豆价格3189，当日最低3182。
- 上证已是标准空头排列，放量阴线一阴穿四线。
- 上证走势为先测向上再测向下，向下的60月线用上影线摸到。
- 下方参考位只剩前低2122与上证3155，此前的小支撑当日已被打漏。
- 同花顺权当日跌3.28，属补跌，60分钟仍冲上，跌势刚刚开始。

## 二、倒鸭嘴与加速下跌的证伪

- 创业板指此前四个交易日反复提示倒鸭嘴风险，化解条件是收盘站上50线并实现金叉。
- 前天收盘价已低于50线，昨天跌幅虽小但50线与5线被拉开，倒鸭嘴成立。
- 书中结论是加速下跌三到四个交易日后回到起跌点位，实测胜率不足50%。
- 实测样本100至200只，回到起跌点位的比例为35%多、不到36%，不可作为依据。
- 倒鸭嘴属经验常识，权重远低于均线排列，只能等待其结束，不做左侧介入。

## 三、量能判读

- 昨天判定跌幅有限的四项依据：美股跌得多A股跌得少、没有放量、阴线实体不大、跌停家数不多。
- 当日跌停家数增加、阴线实体变大，1点45分成交量已与昨日相当，放量成立。
- 集合竞价昨天36、今天19，反而萎缩；集合竞价只作前瞻预警，第一小时成交量才基本可信。
- 上证第一小时成交量昨天1367、今天1684，为近七八个交易日最高。
- 创业板指第一小时成交量594对753，为近八九个交易日最高。
- 放量分广义与狭义，狭义放量只与昨日比；量柱绝对值仍在原平台，量放得不够多。
- 没有恐慌盘就不叫见底，后面还需要更高量能的K线，阴线或阳线均可。

## 四、指标条件与时间窗口

- 均线系统的价值在于均线排列，不是某一条均线本身。
- 昨天下影线创新低属股价创新低、指标不创新低，下降趋势线是判定底背离是否生效的标准。
- 下降趋势线本身也不可靠，背离与4小时级别的假破位都不能作为决策依据。
- DMI当日加速下跌而ADX没有冲上，指标会失效，决策仍以均线系统为准。
- MACD绿柱昨天开始放大，当日为放大的第二个，正处在周期分水岭上。
- 完整周期为13个周期，减掉13后进入新周期，新周期6至7个周期见低点。
- 新周期已走2个周期，还差4个，与加速下跌三到四个交易日的节奏吻合。
- 若按此发展，前波波次接中继再接后波波次，两段至少等长，26天与28天差距被抹平。
- 经验结论不能作为交易依据，技术分析分析的是概率。

## 五、周线结构与操作纪律

- 自8月26日起周线连续下行：第一周跌3.44，第二周跌4.06，第三周涨0.6，本周跌幅超过三个点。
- 下跌时间窗口为23个周期，周线对20周均线上反回落，5穿20死亡交叉共振并出现绿豆阳线。
- 创业板指跌幅更大的原因是MACD在零轴下方与零轴附近死叉，属标准死叉结构。
- 迪马克序列周线第九，过去四次三胜一负，但只有半个权重，需要其他条件确认。
- 空头排列下不做低九抄底；只有多头排列回落至60线的低九才可考虑。
- 最明显的破位K线是8月24日，错过之后一路下跌，没有补救办法。
- 60分钟通道下沿已破位，通道突破之后为空头排列，没有交易信号。
- 修复到多空线只是修复负乖离率的机会，没有这个机会也应当早已空仓。
