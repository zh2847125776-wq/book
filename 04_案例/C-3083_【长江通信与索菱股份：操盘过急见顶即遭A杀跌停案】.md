# C-3083 【长江通信与索菱股份：操盘过急见顶即遭A杀跌停案】

- **标签**：#长江通信 #索菱股份 #10cm妖股 #物极必反 #见顶A杀
- **标的属性**：A股主板10cm股票，长江通信（600345）与索菱股份（002766），前排连板妖股。
- **当时已知信息**：两只个股在前期连板推升过程中主力拉抬速度极快、急于求成，在短时间内累积极大获利盘，但随后遭遇市场增量资金匮乏与情绪退潮。
- **决策逻辑**：股市交易切忌“急躁”，一旦操盘过急导致短线透支，必然物极必反；见顶后缺乏承接，极易引发资金踩踏。
- **执行过程**：长江通信与索菱股份在触顶后迅速回落，走出毫无抵抗的“一见顶就A杀连续跌停”走势，跌停板被巨量卖单焊死。
- **最终结果**：两只股票见顶后短期内连续跌停，市值迅速缩水，给市场确立了“高位连板见顶必A杀”的恶劣负反馈示范效应。
- **关键教训**：操盘过急的妖股往往透支了中长期空间，见顶信号出现时必须第一时间离场，绝不可在连续跌停初期盲目抄底。
