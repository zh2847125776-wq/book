# C-20872 盛运环保2017年末破20日均线三减出局与跌停避险案

> 来源：SRC-000198（专题_策略会_2018中期策略会回顾_2018-07-08-08-56-26（增强版））· 证据 E-75836
日期、品种、合约、周期、关联方法ID、来源ID：2017年12月28日至2018年中期、盛运环保（300090）、A股个股、日线周期、关联方法ID: S-3438 / 知识点ID: K-33551、来源ID: SRC-000198
证据性质：作者自述交易

## 当时已知信息
盛运环保在2017年走势中跌破20日均线；随后先回测向上的20日均线，站上不论；之后股价再度跌落，回测拐头向下的20日均线（E-75836）。

## 原计划与触发
根据20日均线破位与三减形态规则，当股价跌破向下拐头的20日均线且反抽无力时，触发最终清仓止损信号；2017年12月28日给出全套技术系统中最后一次“三减形态”离场机会，执行卖出退出计划（E-75836）。

## 后续过程与结果
盛运环保在2017年12月28日三减形态后不久便停牌；复牌后爆发违约及债务危机等利空，股价遭遇连续一字板跌停，深幅暴跌；严格执行20日均线一票否决与三减形态离场的资金成功全身而退，未承受跌停损失（E-75836）。

## 本例说明的边界
个股基本面黑天鹅或停牌跌停前，技术形态必先破位（破20日均线、回测向下均线）；20日均线一票否决权具有防范不可抗力极端风险的强制约束力；若因心存侥幸忽略三减形态与均线破位，停牌后将彻底失去止损主动权（E-75836）。

## 数字与证据
- 最终三减形态离场时点：2017年12月28日（E-75836）；
- 形态路径：破20日线 -> 测向上20日线 -> 测向下20日线 -> 三减形态 -> 停牌 -> 复牌连续跌停（E-75836）。
