# C-21000 上证指数2019年3月大乖离横盘等均线案

日期、品种、合约、周期、关联方法ID、来源ID：
2019-03-07、上证指数（000001.SH）、无合约、日K线、K-33725 / S-3521、SRC-001098
证据性质：有独立记录（历史行情复盘）

## 当时已知信息
1. 2019年开年行情强劲逼空上涨，截至2019年3月7日构筑第一波高点，收盘价达到3106点。（证据：E-92440）
2. 当时下方20日均线位于2848点，指数现价与20日均线的点位差距达到近300点，正乖离率达到约10%。（证据：E-92423、E-92440）

## 原计划与触发
行情在产生10%巨大正乖离率后，面临均线回归与动能衰竭的技术修复需求。（证据：E-92423）
触发形态：指数并未立即出现单边暴跌，而是选择高位横盘震荡。（证据：E-92423）

## 后续过程与结果
指数在高位横盘震荡等待20日均线缓慢上移跟进；随后下探打漏20日均线构筑葛兰碧法则买点2结构，但讲师强调打漏时不买，直至重新站上20日线再度上攻，最终在日线级别形成顶背离结构后才正式终结行情回落。（证据：E-92423、E-92440）

## 本例说明的边界
说明大乖离率的修复存在多样性，高位脱离均线不必然对应即刻暴跌；行情可在高位横盘以时间换空间等待均线跟进，但交易者在当下无法预知路径，必须遵守“常看短作”纪律。（证据：E-92423, E-92424）
