# C-3082 【荣信文化：OpenAI断供消息驱动超跌反抽20cm涨停案】

- **标签**：#荣信文化 #OpenAI断供 #AI应用 #超跌反抽 #20cm涨停
- **标的属性**：A股创业板股票，荣信文化（301231），人工智能/AI应用概念股。
- **当时已知信息**：2024年6月26日早盘指数补跌，市场处于连续下跌后的超跌反弹周期；消息面上OpenAI向中国用户发布邮件称自7月9日起阻止来自非支持国家和地区的API流量，倒逼国内大模型与应用加速自主研发；同时世界人工智能大会定于7月4-6日举办。
- **决策逻辑**：在市场情绪冰点之后，量化资金与短线资金借双重重磅利好刺激进行试错，选择前期连跌已久的超跌方向发动脉冲反抽，拉升首板为主。
- **执行过程**：利好消息刺激下，荣信文化早盘迅速走强，成功封死“20cm”涨停板；带动海天瑞声、秋田微、世纪天鸿等AI相关个股全线大涨。
- **最终结果**：荣信文化在冰点市场中成为当日最亮眼的20cm反弹先锋，但由于尾盘市场整体成交量并未显著放大，资金呈现提前兑现迹象，该反弹主要定性为超跌情绪反抽。
- **关键教训**：突发消息刺激驱动的超跌首板往往具备极强的脉冲爆发力，但若缺乏大盘整体量能配合，多为脉冲性反抽，参与时应严格关注量能持续性。
