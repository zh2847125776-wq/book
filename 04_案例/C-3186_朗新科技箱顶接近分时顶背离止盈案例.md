# C-3186 朗新科技箱顶接近分时顶背离止盈案例


来源：SRC-001000（股票_202000903量化技术分析_午间解盘（增强版））· 证据 E-66042, E-66043
日期、品种、合约、周期、关联方法ID、来源ID：2020年9月3日、朗新科技（300682，原稿作老型科技/朗星科技/网信科技 [原稿如此，疑误]）、不适用、分时与日线周期、关联方法 S-2398、来源 SRC-001000
证据性质：作者自述交易 / 有独立记录

当时已知信息
朗新科技日线处于次高位箱体震荡中，箱顶压力位标定在 19.95 元附近。
9月3日上午盘中最高冲至 19.78 元（涨幅约4.5%），逼近箱顶。
原计划与触发
按照次高位箱体按表操课规则（越接近箱顶越卖）：10点01分分时出现股价创新高而指标不创新高的多重顶背离，红柱缩短，触发止盈信号。
后续过程与结果
讲师于10点01分在局部高点果断卖出止盈，随后股价一路回落，盘中涨幅从4.5%回落至仅剩1%多，成功锁定利润并规避了回撤。
本例说明的边界

验证了在次高位箱体震荡中“越接近箱顶越卖”与“分时顶背离果断止盈”的纪律价值。

数字与证据
箱顶标定价格：19.95 元（E-66043）。
实际最高价格：19.78 元（E-66043）。
止盈触发时点：10:01（涨幅4.5%处出分时顶背离）（E-66042）。
