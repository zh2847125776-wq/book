# C-20189 桂柳工至权证牛市资产起落案例

> 来源：SRC-000265（第1004章 股市逐梦：从挫折到辉煌的逆袭之路）· 证据 E-71369
日期：1993年至2020年7月
品种：桂柳工原始股、权证等股票资产
合约：股票现货及权证（原稿未明确具体权证代码）
周期：多年宏观/牛熊长周期
关联方法ID：S-3006
来源ID：SRC-000265
证据性质：有独立记录

## 当时已知信息
1993年该交易者持有5500元本金进入股市；1996至1997年处于A股大牛市；2007年处于大牛市与权证市场繁荣期；2015年与2020年处于科技与成长牛市周期（证据 E-71369）。

## 原计划与触发
1993年认购“桂柳工”原始股作为启动资金；1996至1997年顺应牛市持股推升市值；后续受贪婪驱使接受大量“委托理财”杠杆运作（证据 E-71369）。

## 后续过程与结果
1. 1993年认购“桂柳工”原始股后半年内资产飙升至2万元，实现近5倍增值（证据 E-71369）。
2. 1996至1997年牛市期间账户市值推升至近百万，达原始本金近200倍（证据 E-71369）。
3. 因接大量“委托理财”在熊市中惨痛失败，本金全部赔光并背负债务（证据 E-71369）。
4. 2007年用8万元本金重返股市，在权证市场获利还清债务并积累百万本金（证据 E-71369）。
5. 2012年后市值未低于30万；2015年3月突破千万，6月突破3000万；2020年7月市值突破1亿元大关（证据 E-71369）。

## 本例说明的边界
说明了严格风险控制、避免盲目委托理财加杠杆是穿越牛熊的底线边界；在熊市中若违背风控纪律将被市场彻底淘汰，而在牛市行情中利用趋势品种与强纪律才能实现长期复利（证据 E-71369）。

## 数字与证据
1993年本金5500元，半年飙升至2万元（近5倍）；1996-1997年牛市达近百万（近200倍）；熊市赔光负债；2007年本金8万元获利超百万；2012年后不低于30万元；2015年3月突破1000万元，6月突破3000万元；2020年7月突破1亿元（证据 E-71369）。
