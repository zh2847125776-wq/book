# C-3191 双成药业竞价弱转强晋级高标案例


来源：SRC-000243（妖股成妖之路_21 第345章）· 证据 E-66066
日期、品种、合约、周期、关联方法ID、来源ID：2024年10月18日与10月25日、双成药业（002693）、不适用、日线与竞价分时周期、关联方法 K-31384 / S-2402、来源 SRC-000243
证据性质：实际盘面记录

当时已知信息
双成药业作为并购重组板块核心标的，在经历前期连板与分歧后，面临市场预期分化。
原计划与触发
观察竞价阶段情绪转变信号：在10月18日与10月25日两次关键节点，双成药业在集合竞价阶段均走出超预期的“弱转强”信号，触发短线高手入场布局时机。
后续过程与结果
竞价弱转强信号确立后，该股连续封住涨停板，主升浪持续推进，实现了从不被看好到成为全市场关注的高标龙头跨越。
本例说明的边界

验证了在连板妖股博弈中，利用竞价“弱转强”作为情绪反转确认信号切入高标主升浪的有效性。

数字与证据
关键异动日期：10月18日与10月25日（E-66066）。
信号类型：竞价弱转强连续涨停（E-66066）。
