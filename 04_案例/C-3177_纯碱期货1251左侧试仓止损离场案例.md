# C-3177 纯碱期货1251左侧试仓止损离场案例


来源：SRC-000287（期货_期货投机分析20250526_多人工订单盈利_周末隔夜损失稍多（增强版））· 证据 E-66000
日期、品种、合约、周期、关联方法ID、来源ID：2025年5月26日前后、纯碱期货（SA）、合约原稿未明确、日线与分时周期、关联方法 K-31365 / S-2393、来源 SRC-000287
证据性质：作者自述交易

当时已知信息
纯碱处于大级别周线与日线横盘区间，盘面在小横盘区出现微型破翻形态。
讲师在未等行情完全翻回上方之前，在左侧提前入场了一部分底仓多单，止损设在 1251。
原计划与触发
原计划：左侧轻仓试水多单，若企稳反弹则后续加码；若盘面打漏横盘区下沿并跌破 1251，则坚决触发止损离场。
后续过程与结果
纯碱随后出现最后一跌并再创新低，盘面真实击穿 1251 止损线，讲师严格执行纪律止损离场，坚决不扛单。
本例说明的边界

展示了左侧交易进场过早遭遇失败时，必须严格执行既定止损、杜绝扛单的风控铁律。

数字与证据
试仓性质：左侧部分底仓（E-66000）。
止损触发线：1251（E-66000）。
