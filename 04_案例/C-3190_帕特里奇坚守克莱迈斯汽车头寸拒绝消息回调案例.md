# C-3190 帕特里奇坚守克莱迈斯汽车头寸拒绝消息回调案例


来源：SRC-002731（读书_11（增强版））· 证据 E-66051, E-66052, E-66054
日期、品种、合约、周期、关联方法ID、来源ID：1900年代初期（美股早期）、克莱迈斯汽车（原稿作克莱曼汽车/克莱迈斯汽车 [原稿如此，疑误]）、不适用、日线周期、关联方法 K-31383、来源 SRC-002731
证据性质：作者自述交易 / 书中记录

当时已知信息
帕特里奇老先生根据埃尔默·哈伍德提供的消息买入了500股（原稿前文作五千股，后文澄清为五百股 [原稿如此，疑误]）克莱迈斯汽车，在10天之内股价上涨了7个点。
埃尔默自己已经清仓卖出，并急匆匆建议帕特里奇立即卖掉锁定利润，声称市场即将回调，等回调时可以更低价格接回以降低成本。
原计划与触发
面对埃尔默一再劝说出场等回调的建议，帕特里奇以“这是牛市”以及“一旦卖掉我的头寸就没了、丢掉头寸会带来极大压力”为由，坚决拒绝卖出。
后续过程与结果
帕特里奇坚定持仓，抵制住了做盘中小差价的诱惑，成功保护住了在牛市中的宝贵底仓头寸，避免了卖出后无法低价接回的踏空风险。
本例说明的边界

印证了牛市大势思维与头寸保护原则（K-31383）的核心价值，证明在牛市中坚守大势头寸远胜于频繁做回调差价。
