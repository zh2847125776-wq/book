# C-3196 沪铜期货趋势策略与价格行为学策略收益对比回测案例


来源：SRC-000289（期货_期货投机分析20250528_多笔订单_触发止盈（增强版））· 证据 E-66091, E-66092, E-66102
日期、品种、合约、周期、关联方法ID、来源ID：2025年5月28日量化回测、沪铜期货（CU）、合约原稿未明确、日线与多周期、关联方法 K-31392、来源 SRC-000289
证据性质：作者自述交易 / 历史量化回测记录

当时已知信息
讲师在盘前使用量化分析工具对沪铜期货过往历史数据进行多策略回测统计。
原计划与触发
对比两类策略在沪铜上的年化收益表现：
趋势类交易策略：APL 策略、TRP 策略、基础 MA60 趋势跟踪；
价格行为学策略：PA3Z 策略（ZR 序列 + 当日回转 + 一色挂件）。
后续过程与结果
量化回测数据输出：
APL 趋势策略年化收益仅为 47.23%；
TRP 趋势策略年化收益仅为 44.56%；
基础 MA60 趋势策略年化收益仅为 55.31%；
PA3Z 价格行为学策略年化收益高达 259%（原稿作259之多 [原稿如此，疑误]）。
证实沪铜品种特性不适合机械趋势类策略，而高度适合价格行为学日内与波段交易。
本例说明的边界

提供了用详实量化回测数据支撑品种与策略适应性匹配（K-31392）的经典证据。
