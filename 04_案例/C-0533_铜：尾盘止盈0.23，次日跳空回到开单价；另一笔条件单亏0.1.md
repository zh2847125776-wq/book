# C-0533 铜：尾盘止盈0.23，次日跳空回到开单价；另一笔条件单亏0.1

> 来源：SRC-003733（第1139课）· 证据 E-3290、E-3292

日期：2025-06-18日盘至06-19早盘；品种：铜；合约：原稿未明确；周期：原文未明确；关联：S-0255、K-0598；来源：SRC-003733
证据性质：课堂回看，讲述者复述

## 当时已知信息
铜的波动太小。E-3290

## 原计划与触发
首根K无色，第二根阴线做空，第三根创高转为多单，回调一、回调二后开单。E-3290

## 后续过程与结果
- 这笔多单尾盘触发止盈0.23；次日早上跳空低开，价格回到开单价。讲述者说"当日回转的精髓就是这个，能够避免白干"。E-3290
- 夜盘另有一笔空单：挂条件单会被触发，亏0.1，讲述者说"十倍杠杆……也才只有1%的亏损，可以接受"；人工盯盘收K确认则"就没触发过"。讲述者随后说"应该把它剃掉"。E-3292

## 本例说明的边界
当日平仓避免了过夜白干；同一笔空单，条件单和人工收K的结果不同。

## 数字与证据
0.1×10＝1%，算术成立。
