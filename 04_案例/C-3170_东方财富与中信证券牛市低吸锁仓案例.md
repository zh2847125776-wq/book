# C-3170 东方财富与中信证券牛市低吸锁仓案例


来源：SRC-000241（妖股成妖之路_19（增强版）# 第283章）· 证据 E-65966, E-65975
日期、品种、合约、周期、关联方法ID、来源ID：2024年10月国庆后、东方财富（300059）/中信证券（600030）、不适用、日线与分时周期、关联方法 S-2387、来源 SRC-000241
证据性质：作者自述交易 / 课堂假设 / 有独立记录

当时已知信息
2024年国庆节后市场成交量暴增，东方财富20cm面临爆天量预期，市场呈现10cm逐步替代20cm与新股的演变格局。
中信证券作为补涨东财的大容量核心券商大票，被提示在早盘9:15前排单或竞价低吸上车。
原计划与触发
原计划：大票具有高确定性与容量优势，不盲目打板，提示投资者在分时回调或竞价头铁吸上，上车后执行“格局锁仓”策略，预期为换手板主升。
后续过程与结果
绝大部分投资者成功排到并建仓中信证券，次日执行锁仓持股，捕获了券商核心品种的波段换手主升收益。
本例说明的边界

验证了牛市中大市值容量白马重在低吸与锁仓持股、不盲目追涨打板的实战操作价值。

数字与证据
东方财富涨跌幅限制：20cm（E-65966）。
替代品种涨跌幅限制：10cm（天风、中信、国海）（E-65966）。
委托申报时点：9:15 之前排单（E-65975）。
