# C-3182 银之杰20cm极致高位引发天地板与10cm批量炸板案例

证据性质：作者自述交易 / 有独立记录

当时已知信息
银之杰将20cm高位情绪推向极致，类似前期的东方财富与润和软件；高位抱团股持续上涨但成交量呈现萎缩背离。
常山北明等高标与银之杰节奏贴合紧密。
原计划与触发
预判情绪已进入高位“疯狗浪”，随时面临大跳水天地板风险；讲师指导持有高位者果断平仓离场，防范极端分歧杀跌。
后续过程与结果
银之杰与常山北明相继出现天地板跳水，剧烈负反馈迅速扩散，导致10cm高标股票批量炸板；双成药业凭借小体量勉强回封。
本例说明的边界

验证了高位缩量疯狗浪阶段20cm极端情绪对全市场10cm连板生态的传导与破坏力。
