# C-2098 2022年3月3日创指早盘假金叉跳空诱多与尾盘收跌验证

- **背景与现象**：
  2022年3月3日早盘，创业板指在外围影响下跳空高开，分时盘口一度呈现MACD金叉迹象，市场多头情绪高涨。然而下午开盘后空头持续施压，最终收盘不仅未能维持金叉，反而收出明显绿柱，且日线级别自2710点反弹以来首次出现连续两个红柱缩短。
- **成因与技术分析**：
  1. **早盘盘中失真**：早盘的金叉仅为瞬时脉冲，未到收盘日线指标无法定型，验证了尾盘交易原则的绝对必要性；
  2. **W底三重动力学测漏**：创业板指此前均线系统处于标准空头排列向下发散，下行惯性巨大，且2710点以来的反弹底座极为窄小，在力学上无法支撑右侧大级别反转；
  3. **衰竭信号坐实**：日线连续两个红柱缩短，确立多方动能彻底衰竭；
  4. **钝刀割肉心理发酵**：不少投资者在盘中追高被套后，抱着亏损从3%到5%慢慢等待的侥幸心理，陷入温水煮青蛙的困境。
- **实战启示**：
  必须坚决执行尾盘交易准则（14:45后再行定夺），坚决拒绝早盘追逐假金叉；当大级别空头排列未改且底部过小时，任何假双底均不得作为重仓做多的依据。
