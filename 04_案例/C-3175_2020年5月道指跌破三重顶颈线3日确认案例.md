# C-3175 2020年5月道指跌破三重顶颈线3日确认案例


来源：SRC-000999（股票_202000516量化技术分析周末素质四连加强版（增强版））· 证据 E-65989
日期、品种、合约、周期、关联方法ID、来源ID：2020年5月13-15日、道琼斯工业平均指数（DJI）/小道指期货、合约原稿未明确、日线与分时周期、关联方法 S-2390、来源 SRC-000999
证据性质：课堂假设 / 有独立记录

当时已知信息
小道指日线级别处于空头排列下跌常态中，近期在反弹高位形成三重顶头部结构。
5月13日（周三）收盘首次跌破关键绿色颈线，5月14日（周四）出现反抽但未能站回颈线上方。
原计划与触发
按照颈线3日确认法则：若5月15日（周五）作为破颈线第3天继续收在颈线下方，则确立头部破位成立，将引发大量机构技术止损盘出逃。
后续过程与结果
5月15日周五盘面确认收在颈线下方，均线系统5条均线中4条向下，破位成立并引发后续技术止损盘抛压。
本例说明的边界

展示了关键颈线破位后利用“破位-反抽不过-第3天收在下方”三步法进行客观确认的风控标准。

数字与证据
破位节点：周三收盘破颈线、周四反抽不过、周五收盘第3天在下方（E-65986, E-65989）。
均线状态：5条均线中4条向下（E-65984）。
