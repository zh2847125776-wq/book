## 当时已知信息

- **锰硅**：此前出现**连续 41 个交易日红柱结构**，此前开空时共出现 **7 个绿柱**；老师用 41+7=48、41+9=50 判定它落在**标准周期**上。
- **热卷**：开单原因是**延续此前趋势下跌**；日线已形成**多头排列**；周线可见低位金叉下返回错状态。
- **白糖**：开仓后出现明显下跌，先测向上再测向下，形成**空头排列**并开始下跌；日线死亡交叉位置较好。
- **苹果**：大趋势向上、**均线多头排列**，老师做的是**猜顶**（换个角度看也是捞底）。

## 后续过程与结果

**有结果报告（本批少见）。**

**第1352课（01-25，节前最后交易日）——四笔全部平仓：**

| 品种 | 结果 |
| --- | --- |
| 热卷 | 尾盘快速拉升、**收盘收在通道上限**；下午约 **1:45** 突破上限时平仓。老师原话「得亏是平掉了是不是，平掉了以后它又突破了」→ **亏损**（由锰硅盈利抵消） |
| 白糖 | 收在**通道下限**位置平仓 → **盈利（承担组合盈利任务）** |
| 锰硅 | 平仓（前一日收盘已出现日线 MACD 缩小） → **略有盈利** |
| 苹果 | → **小亏** |

老师总结：「四笔单子里，有**两笔互相盈利和亏损抵消**了，另外一笔苹果是小亏点，白糖实际上最后是保持盈利的。」**组合总体微利，回避节日持仓风险。**

**第1353课（01-27）——苹果打出止损：**
- 苹果**2022-01-27 上午已打出止损**，止损价即前高 **9017**。上次开单位置到止损**约六七个点**，仓位很低，实际亏损很小。
- 老师：「虽然当天创高、止损打出，但**观点没有太大变化**；只有日线 MACD **绿柱放大一个、红柱放大一个**，观点才变化。」
- **热卷**：单子开立后曾稍微浮亏，仍属盈利状态，**没有远离形态结构上限**；**空头头寸的判断是格兰碧八大法则卖点二**。若突破上限向上试探多空线，就应继续止损。
- **锰硅**：前次穿轴没有加速上涨，这次穿轴却带来加速上涨；日线前一日 MACD 绿柱放大，当天一度缩小但**仍在放大途中**，**还不能确认是否中继结构**。此前设定的止损没有被突破，价格又形成新的蓬勃区域，老师建议**移动止损位置、可取两个位置的平均值**；**坚守日线绿柱缩短收盘的规则**。
- **白糖**：目前盈利最多的单子；下跌过程中出现明显盘整区域，**可取上线三个数字的平均数作为参考**；攻破下线后单面下跌计划更容易兑现。

## 本例说明的边界

1. **组合视角与单笔视角不同**：四笔里两笔互相抵消、一笔小亏、一笔盈利，单看任何一笔都得不到「微利」这个结论——**结果必须按组合读**。
2. **止损被触发不等于判断被推翻**：苹果止损后老师明确「观点没有太大变化」，并给出观点改变的具体判据（日线 MACD 绿柱放大一个／红柱放大一个）。这与 K-0091 一致。
3. **逆势单用敏感止损 + 轻仓**：苹果实例（K-0091）。
4. **「该一仓一仓、该持有持有」**：老师强调不同品种按各自通道、周期和结构管理，**不因短线波动随意改变规则**。
5. **一处未解释的自相矛盾**：锰硅「前次穿轴没有加速上涨，这次穿轴却带来加速上涨」——同一动作两次结果不同，原稿**未给原因**，已隔离。
6. 【老师点评/批判】（**编辑者立场**）：多条「前提／反例／风险」是编辑者归纳，**不是老师原话**，本卡未把它们当规则依据。
