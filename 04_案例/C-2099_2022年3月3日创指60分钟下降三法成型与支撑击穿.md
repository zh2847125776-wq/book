# C-2099 2022年3月3日创指60分钟下降三法成型与支撑击穿

- **背景与现象**：
  2022年3月3日，创业板指在60分钟走势中，走出了一根实体大阴线，随后连接三根小阴小阳反弹K线，紧接着走出了一根等距的下挫阴线，构成了极为标准的“下降三法”形态，直接击穿了此前预设的密集技术支撑。
- **成因与技术分析**：
  1. **看跌中继形态确认**：60分钟三根小K线完全被第一根大阴线的高低点包容，随后的等距阴线砸穿前低，证实小反弹仅为空头蓄势的下跌中继，下降三法正式成型；
  2. **支撑全线崩塌**：该形态的出现导致原有的60分钟分时通道下轨和反弹颈线失去托底功能，宣告了创指反弹行情的彻底夭折与新一轮波段寻底的开启。
- **实战启示**：
  在分时走势中出现大阴线后接弱势三小K线的组合时，切不可误判为主力洗盘，一旦等距阴线破位确认下降三法，必须立即平仓撤离。
- **关联引用**：
  - 支撑知识与方法：`K-3472`、`S-1318`；
  - 证据溯源：`E-61697`。
