# C-2100 2022年3月3日上证一手好牌打烂与3500点二次压制确认

- **背景与现象**：
  2022年3月3日，上证指数早盘借外围强势直接跳空高开于3495点，盘中最高精准触及3500点整数关口。此前系统给出的日线绿柱价格为3492点，3500点的触及使得日线绿柱价格被击穿，锁定次日必出红柱一。然而，高开后多头无力向上拓展，指数逐级回落，收盘收在3492下方，痛失突破3500点打开上升空间的大好局面。
- **成因与技术分析**：
  1. **次级阻力失效与主阻力确认**：3492点在盘中被轻易穿越但回落时未产生任何有效支撑，证明该点位已正式失效作废；而3500点则由单点高位正式确认为横盘箱体双顶上限；
  2. **催命符构型成型**：虽然价格击穿3492导致次日MACD必然产生红柱一，但在3500箱顶重压之下，若次日收出缩头阴线，该红柱一不仅无法提供支撑，反而异化为诱多崩跌的“催命符”。
- **实战启示**：
  当指标翻红条件触发但价格被死死压制在箱体顶盖之下时，切勿盲目乐观；必须将次级无效阻力彻底清除，聚焦核心箱顶，一旦次日收阴即刻启动催命符防御方案。
- **关联引用**：
  - 支撑知识与方法：`K-3475`、`K-3476`、`S-1319`、`S-1320`；
  - 证据溯源：`E-61698`、`E-61699`、`E-61700`、`E-61701`、`E-61702`。
