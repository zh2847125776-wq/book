# C-3195 热卷期货空单累积盈利3.24%两阶段分批止盈案例


来源：SRC-000289（期货_期货投机分析20250528_多笔订单_触发止盈（增强版））· 证据 E-66093, E-66094, E-66095, E-66096, E-66101
日期、品种、合约、周期、关联方法ID、来源ID：2025年5月28日、热卷期货（HC）、合约原稿未明确、5分钟与60分钟周期、关联方法 S-2407、来源 SRC-000289
证据性质：作者自述交易 / 实际盘面记录

当时已知信息
2025年5月28日早盘，热卷空单开仓后顺畅下行，累积跌幅达到 3.24%，属于累积大幅盈利状态。
商品指数呈标准空头排列，但热卷盘面短期跌幅过大开始出现分时反弹异动。
原计划与触发
按照累积大幅盈利两阶段止盈法：
阶段一触发：分时出现红色箭头 + 红色K线 + 价格站上低多线，立即平仓 50% 锁定利润；
阶段二触发：标定上方 123 法则 3 号位（两个近高高点连线阻力位），若突破 3 号位则将剩余 50% 减仓清干净；若不破则继续持有。
后续过程与结果
讲师在直播中指导执行该分批止盈方案，先平一半锁定胜利果实，剩余一半通过承受最多 0.38% 的理论磨损代价，为单边可能继续下行保留了不被卖飞的弹性。
本例说明的边界

完美展示了在单边大赢订单中如何通过两阶段分批止盈法平衡“锁定利润”与“防止卖飞”的实战心理与动作标准。
