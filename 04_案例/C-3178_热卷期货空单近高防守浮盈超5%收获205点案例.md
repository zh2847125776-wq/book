# C-3178 热卷期货空单近高防守浮盈超5%收获205点案例


来源：SRC-000287（期货_期货投机分析20250526_多人工订单盈利_周末隔夜损失稍多（增强版））· 证据 E-66001
日期、品种、合约、周期、关联方法ID、来源ID：2025年5月23-26日、热轧卷板（HC）、合约原稿未明确、日线与60分钟周期、关联方法 S-2392 / S-2393、来源 SRC-000287
证据性质：作者自述交易 / 有独立记录

当时已知信息
2025年5月23日早盘9:05直播中，热卷在两高点连线压力位给出明确空单机会，初始止损设在近高加余量黄线上方。
原计划与触发
建立空单后，盘中冲高未触及黄线余量止损；随后价格大幅下挫，账面浮盈迅速突破 5%，全面切换至低多跟踪保护法。
后续过程与结果
盘面出现红色箭头与横盘整理，但价格始终未向上触及低多线，讲师指导继续格局持有，最终该笔空单捕获了整整 205 点的巨大单边利润。
本例说明的边界

验证了“近高加余量防守”与“浮盈超5%跟踪低多止盈”组合策略在捕获高流动性黑色系单边行情中的有效性。

数字与证据
获利空间：热卷空单盈利 205 点（螺纹钢177点）（E-66001）。
跟踪状态：浮盈超5%未触低多线持续持有（E-65991, E-66001）。
