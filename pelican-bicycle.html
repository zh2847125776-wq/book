鹈鹕骑自行车

纯 SVG 绘制 + CSS 关键帧驱动的 2D 侧视动画：车轮、曲柄、链条、视差背景全部按同一周期联动， 双腿用两连杆反向运动学（IK）逐帧求解，脚踝始终踩在踏板上。

蹬踏周期 --cycle: 0.9s（约 67 rpm）
它是怎么动起来的：所有动画都是 CSS @keyframes，SVG 里没有任何图片或 JS 渲染。 车轮、曲柄、踏板、双腿共用同一个 --cycle 周期变量，因此永远同步；踏板再做一次反向旋转，始终水平。 腿部用「大腿 95 + 小腿 105」两连杆模型，对曲柄每 22.5° 解一次余弦定理得到髋、膝、踝三个角度， 共 16 组关键帧；浏览器在关键帧之间线性插值后，脚踝与踏板的最大偏差只有 0.9 px。 背景按视差分四层（云 29× / 远山 7.7× / 近丘 4.3× / 灌木 1.15× 周期），路面标线的速度则严格等于轮缘线速度。
