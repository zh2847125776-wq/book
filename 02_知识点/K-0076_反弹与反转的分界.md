# K-0076 反弹与反转的分界

> 来源：SRC-003576（第06课 0115午间直播）＋完整稿 SRC-007874＋增强稿 SRC-007865；SRC-003577（第07课 0129早盘）＋完整稿 SRC-007875＋增强稿 SRC-007866 · 证据 E-0174、E-0177、E-0179、E-0183

一句话定义：一根反弹阳线不等于趋势反转；分界是**关键压力位（绿豆／前高、20日线）能否被有效突破**，未突破前一律按负乖离下的技术性反弹处理。

- **立场**：课程讲述者采纳（老师原话，第07课；第06课同向表述）。
- **底本层级**：完整稿可见（第07课"核心"句与情景三；第06课"日线未明确顶背离时，不以小时级信号断言长期趋势已经结束"）。
- **来源**：SRC-003577（第07课）、SRC-003576（第06课）。证据：E-0177、E-0179、E-0174。

## 它解决什么问题

解决"破位之后出现阳线，要不要改口"这个问题。老师的答案是：不改口——先看压力位是否被有效突破，否则阳线只提供**补做止损的机会**，不提供重新看多的理由。

## 如何识别

- **核心句（第07课）**："反弹阳线和趋势反转不是一回事，关键压力位能否被有效突破才是分界"（E-0179）。
- **判定顺序**：
  1. 收盘是否突破绿豆／前高（第07课实例约 **3635～3637**）；
  2. 是否重新站上 **20 日线**；
  3. 突破时**量能是否配合**（"是否有足够成交量"写进复盘检查表）；
  4. 是否只是 5 日线上穿 20 日线——原话"五日线上穿二十日线，不代表绿豆和前高已同时突破"。
  （E-0179、E-0177）
- **未突破时的性质**：仍按**负乖离和反弹**处理；"越反弹越卖"（第07课原始转写"今天只要不能收盘攻破我说的这个点，你都是应该越反弹越卖的"，E-0183）。
- **第06课的同向表述**：日线若仍未出现明确顶背离，**不能仅凭 60 分钟级别就断定大趋势彻底结束**；但在信号未修复前，仍不应开新仓（E-0174）。
- **罕见的反例情景**（第07课情景一）：当天用超级大阳线突破绿豆／前高并重新站上 20 日线、量能明显配合 → 原未卖仓位可以暂缓卖出。老师明确"这不是默认情景"，"概率很小"（E-0179）。

## 适用边界与失效

- **"有效突破"的量化口径原文未给**：只给了"收盘突破 3635／3637 一带"这一个实例，没有给"突破多少算有效""要不要回测确认"的通用判据（E-0179）。相关判据需参考 K-0009（有效跌破与站上的确认），但**两课没有互相引用**。
- **"量能明显配合"没有门槛**：原稿只写"需要量能明显配合""是否有足够成交量"，无倍数或均值口径（E-0179）。
- **5 日线上穿 20 日线单独出现不算数**：这条只否定了交叉本身，**没有说明交叉之外还要满足什么**（E-0179）。
- 原稿**未提供"把反弹误判成反转"的亏损案例**，也未提供"把反转误判成反弹、过早卖出"的案例。这条原则的失败样本仍缺。
- 第07课当日结果：老师给出"技术性反弹"为最常见情景并建议按此执行，**当日之后是否真的转强，原稿未报告**。

## 与其他概念的关系

- 与 K-0075（红豆与绿豆）：绿豆就是这里说的"关键压力位"。
- 与 K-0032（50线走平与拐头预警）／K-0026（走平期核心均线失效）：同属"某一根线被破了之后怎么读"，但 K-0076 的判据是**压力位是否被突破**，K-0032 的判据是**均线自身是否拐头**。
- 与 K-0041（根据所见交易）：本卡是它在上证指数上的具体应用——形态没被兑现就按未兑现处理。
- 与 K-0088（小时级信号的定位）：第06课的"不能仅凭 60 分钟断言长期趋势结束"由 K-0088 承担，本卡只引不作主依据。
- 与 S-0029（破位后减仓触发）：未突破压力位 → 反弹是卖出窗口，不是买回窗口。

## 案例与证据

- **C-0021 上证 2021-01-29**：前一日已破位 → 当日反弹仍在 20 日线下方、未破绿豆 3637 → 按技术性反弹处理，借反弹补做止损（E-0177、E-0179）。
- **C-0020 上证 2021-01-15**：60 分钟顶背离 + 跌破上升趋势线，但日线未明确顶背离 → 定性为"多头趋势中的调整"，不是长期反转；同时仍不开新仓（E-0174）。
- 结果：两课都**未报告**后续是否真的反转或继续下跌。
