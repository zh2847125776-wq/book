# K-0017 MACD零轴：多空分界线与穿轴加速
> 来源：SRC-003571（三加详解（股指双轨买入法））、SRC-003572（MACD精讲（学习笔记）） · 证据 E-0012、E-0028、E-0029、E-0030、E-0031、E-0032
> 来源立场：课程讲述者采纳（建卡时漏标，2026-09-28 按门4回填；若有书中作者或编辑者评注，须拆开标注）

一句话定义：零轴是 MACD 的多空分界线（快线在其上方＝多方趋势、下方＝空方趋势），自下而上穿轴是加速上涨信号、自上而下穿轴是加速下跌信号，但穿轴必须伴随红/绿柱放大才算数。

## 它解决什么问题

**MACD 被称为趋势指标，根本原因就是它有零轴这个要素**（E-0029）。它给 MACD 补上了一个"多空方向"的判据，与20日线的作用对应（E-0029）。

## 如何识别

**零轴 ↔ 20日线对照表**（E-0029）：

| 20日线用法 | MACD 对应版 |
| --- | --- |
| 20线向上＝上升趋势（可量化：今天比昨天高） | 快线在零轴**上方**＝多方趋势 |
| 20线向下＝下降趋势 | 快线在零轴**下方**＝空方趋势 |
| 20线走平＝震荡 | （无斜率概念，见下） |
| 20线**上不做空**，拉回找卖点 | 零轴**上方不做空**，死叉（拉回）找卖点 |
| 20线**下不做多**，反弹找卖点 | 零轴**下方不做多**，金叉（反弹）找卖点 |

**零轴与20日线的两个区别**（E-0029）：

1. **20日线有斜率，零轴没斜率**——20日线自己能表达趋势强度；MACD 要**借红绿柱表达强度**（多方区红柱变大＝强，空方区绿柱变大＝强）。
2. 20日线与其他均线有**交叉共振**（5穿20、20穿60）；零轴和快慢线没有交叉共振，但有**助涨助跌**作用。

**乖离率（距零轴远近）**（E-0029）：

- 距零轴远＝正乖离大 → 有向下吸引力；近＝正乖离小 → 有向上反弹力道。
- 负乖离大 → **没有最大值**，所以课程**在零轴下面干脆不做**（不做负乖离修复行情）；零轴下方抄底很难，课程明确放弃这个场景。

**穿零轴＝加速信号**（E-0030）：

- 自下而上穿零轴 → 加速上涨；自上而下穿零轴 → 加速下跌。
- 前提是**伴随力量确认**：向上穿轴＋红柱放大（多方强盛）→ 真加速；没有 → 走势犹疑。向下穿轴＋绿柱放大（空方强盛）→ 真加速下跌。
- 本质原因：①反映趋势逆转；②**约定俗成信号**——看的人多、大家都堆单子，它就成立（同"20日线为什么是核心"的逻辑）。
- 原稿叮嘱：**千万不要去背指标公式**——公式导出的结果才是你要的，背公式浪费时间。

## 适用边界与失效

- **零轴下方不做多**：课程放弃零轴下方抄底与负乖离修复场景（E-0029）。
- **零轴上方不做空**：死叉只作为"拉回找卖点"的参考（E-0029）。
- 穿轴信号必须与红绿柱配合，否则只能算"犹疑"（E-0030）。
- 原稿把零轴的重要性与20线类比（"零轴上不做空、零轴下不做多"），但**没有给零轴的具体数值口径**（零轴就是 0，原稿未讨论 DIF/DEA 的计算与参数）→ 缺口；原稿另明确"不要背公式"（E-0030）。
- 本卡不含任何空头镜像扩展：零轴下方的用法全部来自原稿原话，不是由多头规则推导出来的。

## 与其他概念的关系

- **K-0001 均线系统与三线制 / K-0014 倒金字塔**：对照表的左列就是20线的用法，20线是课程的唯一核心（E-0029、E-0012）。
- **K-0016 MACD金叉死叉权重表**：权重表的横轴就是零轴上下与远近（E-0028）。
- **K-0018 MACD红绿柱强度**：零轴不能表达强度，强度交给红绿柱（E-0029、E-0030）。
- **K-0020 MACD顶底背离与趋势线**：背离的"目标＝回调到指标起涨/起跌点位"是以零轴为参照的（E-0032）。
- **K-0011 三加形态**：第01课用"20线向上/向下"做一票否决，第02课用"零轴上下"做同样的多空划分，两课是同一逻辑在两个指标上的表述（E-0029）。

## 补充：零轴深处金叉收益微薄如走私饼干冒杀头风险真正的暴利皆在穿轴之后
> 来源：SRC-001622 · 证据 E-52911
> 来源立场：课程讲述者采纳（零轴下方低位金叉非对称风险揭示）
> 底本层级：仅增强稿可见

一句话定义：MACD在零轴下方远离零轴位置的金叉注定只是小涨结构，冒着掉脑袋的风险去赚两块饼干纯属违纪，单边主升浪唯有在DIF穿轴后才会真正爆发。

## 如何识别
- 收益与风险极度不对称：在空头掌控区盲目抄底零轴深处的金叉，向上空间逼仄而向下破位风险极大，如同走私两块饼干却冒着被枪毙的死罪（E-52911）。
- 穿轴确立主升浪：历史实证表明，DIF穿过零轴之前价格均处于反复震荡与微弱反弹阶段；唯有站稳零轴之上，多头主升浪才会真正拉开（E-52911）。

## 适用边界与失效
适用于所有大级别趋势跟踪策略的开仓过滤；空头掌控区严禁依据副图指标微观金叉做多。
