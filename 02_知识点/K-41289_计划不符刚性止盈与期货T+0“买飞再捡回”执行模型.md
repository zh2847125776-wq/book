# K-41289 计划不符刚性止盈与期货T+0“买飞再捡回”执行模型

> 来源：SRC-000516 期货_期货投机技术分析20230704（增强版） · 证据：E-88224, E-88225

### 核心概念与运作机理
在专业期货投机交易体系中，交易者必须树立“计划受阻坚决离场、买飞之后依托T+0重新捡回”的钢铁纪律：
1. 走势与计划不符即刻离场：交易计划无论事前推演多么完美，实盘都绝不可能次次如愿；一旦行情盘中出现跳空高开或异动打破了既定下行推演（如玻璃在1522点直接跳空高开破坏了下行结构），交易者绝不可主观侥幸死扛，必须无条件执行“合理止盈/止损出局”；
2. 期货T+0“不怕买飞、从容捡回”机制：许多交易者不敢止损或止盈，深层心魔是害怕“卖飞/买飞”后行情再次朝预期方向暴跌；系统明确确立对冲心魔的武器——由于商品期货具备“T+0即时回转交易”机制且日内平今手续费极低，交易者即便在1522点平仓“卖飞”了，只要后续走势重新给出破位或跌回信号，完全可以“从容地在更低位把空单重新捡回来”，以极小的摩擦成本换取绝对的本金安全；
3. 大级别空头排列终极压制：在日线空头排列主导下，反弹空间被牢牢锁死在60MA多空线下方，为再次捡回空单提供了确定性技术依托。

### 适用场景与边界条件
- 适用场景：商品期货隔夜持仓遭遇意外反向跳空、破位防守触发时的果断执行与再入场。
- 边界条件：偏离计划必须第一秒清仓；重新捡回必须依托大均线遇阻或跌回关键点，严禁情绪化报复开仓。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
直接承接日内果断执行力（K-41288）：战胜犹豫心魔；与简单事情重复做放空模型（S-25805）构成闭环。

### 案例与证据
- 案例标的与时间：2023年7月4日玻璃期货1522点跳空出局实战复盘。
- 实盘数据特征：玻璃在1522点跳空高开未按计划下跌，系统果断要求执行纪律平仓，并用“期货T+0不怕买飞随时可以低成本捡回来”消解交易员心理包袱。
- 逐节证据标定：1522跳空执行纪律与期货T+0买飞再捡回参见 E-88224，计划不符合理止盈与空头排列看60线参见 E-88225。
