# K-0817 余量要自己精算，不要偷懒用固定 0.2～0.3


> 来源：SRC-003806（第1204课 期货：不卖飞与余量精算（20251111））· 证据 E-4196、E-4195
> 来源立场：课程讲述者采纳（同学的 0.2～0.3 简化法讲述者"不能说不行"，但不推荐）
> 底本层级：仅增强稿可见

一句话定义：有同学每次直接加 0.2～0.3 作余量，好处是"避免测算""速度比较快"。但这样不精确，"导致止损不准，被扫了"，事后发现精算就准了，"你就会非常懊悔"，所以讲述者"建议自己动手算一算"（E-4196）。

## 它解决什么问题
确保余量止损准确落位（E-4196）。

## 如何识别
- 讲述者的余量"每次都特别精准的就能踩在那个值上"（E-4196）。
- 遇到大数价位可以用 Excel 精算，或先化简再算（E-4195）。
- 本例按收盘价判断，没有触发（E-4195）。

## 适用边界与失效
- 余量的计算公式和步长规则，原文未明确，不补。
- E-4195 的化简过程（86855→8685→8700.5→87005）写法难以理解 `[原稿如此，疑误]`，不写进规则。
- 用收盘价还是最高价判断触发，本例说"你看收盘价嘛"，但没有说明这是不是通用口径。
