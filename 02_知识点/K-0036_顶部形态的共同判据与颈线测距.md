# K-0036 顶部形态的共同判据与颈线测距
> 来源：SRC-003959（｜期货市场主要品种周报：螺纹、PTA、豆粕｜2020） · 证据 E-0071、E-0072、E-0076、E-0081、E-0083、E-0085（来源由卡片内容匹配认定，命中12处特征短语）

一句话定义：圆弧顶、头肩顶、勺柄这些名字可以不同，但在下跌之前它们共同表现为——一段筹码交换、均线向下、以及颈线破位；跌破颈线后可用颈线位置推算下行目标价。

## 它解决什么问题

不纠结形态叫什么名字，抓住共同的三件事判断顶部；并给"颈线跌破"一个可数的目标价。

## 如何识别

（逐条写成立条件，句后标证据ID）

- 形态名称不重要，共同点是"下跌之前做的最后一波筹码交换、仓位的闪转腾挪"。老师原话："甭管是圆弧顶还是头肩顶啊，他都要是在下跌之前做的最后一波的这么一个筹码交换仓位的这么一个闪转腾挪的这么一个动作。"（E-0071）
- 同一个日线结构可以同时被读成左肩／头部／右肩，也可以读成箱体中的勺柄结构（E-0071）。
- 均线条件：周线在均线空头排列的大幅运行后形成"比较标准的一个圆弧形顶"（E-0071）；螺纹均线"基本空头排列"（E-0072）。
- 颈线条件：把两个支撑点连线后可见多个触点，低点约 3187、3210、3244、3207，阳线最低价 3183；以约 **3200** 作为颈线（E-0071、E-0072）。
- 颈线本身可以"不够标准"：两个低点过低时颈线不够标准（E-0071、E-0085）。

## 适用边界与失效

- 形态名称可以不同（E-0071），所以**不能凭名称认定顶部**。
- 顶部判断会被后续走势推翻：1344 螺纹明确"周线原先的圆弧顶判断被取消"（E-0081）。
- 1345 螺纹周线"两个低点过低，颈线不够标准"，因此不机械套用圆弧顶测距（E-0085）。
- 若行情化解结构、成为修正波并重新上行，要承认实际走势（E-0071 所在节的编辑者评注；属编辑者整理，非老师原话）。
- 资料未提供"目标价达到"或"目标价未达到"的实例。

## 与其他概念的关系

- **颈线测距**：以约 3200 作颈线时，"颈线跌破满足目标价为 2317"；原稿另给分层参考目标 **3010、2673、2374**（E-0072）。
  **计算公式原文未明确**——3200 与 2317 之间的 883 点如何得出，原稿没有写，不能反推，也不许补常识。这是本卡最大的缺口。
- 与 K-0040（背离判据）：顶部形态常伴随顶背离（E-0083、E-0085）。
- 与 K-0009（有效跌破与站上的确认）：颈线是"有效跌破"的判据载体。
- 与 K-0038：顶部形态在均线仍多头时只读成"不能做空"（E-0076、E-0085）。

## 案例与证据

- **C-0007 螺纹**：1342 判圆弧顶／头肩顶 + 约 3200 颈线 + 目标 2317 → 1344 取消圆弧顶判断（E-0071、E-0072、E-0081）。
- 结果：原稿未报告 2317 目标是否达成。
