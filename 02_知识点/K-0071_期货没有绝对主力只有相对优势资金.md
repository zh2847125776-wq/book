# K-0071 期货没有绝对主力，只有相对优势资金

> 来源：SRC-003964（第1347课 期货跟踪 2020-06-19）＋完整稿 SRC-008262＋增强稿 SRC-011111；SRC-003965（第1348课 期货跟踪 2020-06-24）＋完整稿 SRC-008263＋增强稿 SRC-011112 · 证据 E-0153、E-0159

一句话定义：期货市场里不存在能控盘的"绝对主力"，只有资金实力相对占优的一方；所以不能用股票里"主力吸筹/洗盘"的思路去解释期货的每一次震荡。

**来源立场**：**课程讲述者采纳**（第1348课甲醇段的老师原话）。

## 它解决什么问题

给"期货这段为什么来回震荡"一个正确的归因层次，避免把每一次震荡都读成"主力在洗"。

## 如何识别

（逐条写成立条件，句后标证据ID）

- **原话**（完整稿，**完整稿可见**）："老师解释期货没有绝对主力，只有相对优势资金"（E-0159）。
- **同段的盘面落点**：甲醇"两个触点连成压力线，价格打到附近就不涨"；当前结构是"大、中、小三个震荡单位逐级收窄的等比减波幅收敛结构"（E-0159）。
- **老师对这段结构的定性**（增强稿逐字）："它是一种特别的收敛结构……大的震荡幅度三个单位，中的震荡幅度两个单位，小的震荡幅度一个单位，它在干什么？它在酝酿行情"（E-0159）。
- **对应的操作结论**：这种结构下"你能在这个地方去做多吗？不能。你能放空吗？当然更不能了"（E-0159）。

## 适用边界与失效

- **"相对优势资金"是一个归因层次，不是一个可测量的量**。原稿**未给出**"谁相对占优"的判定方法（持仓量？成交量？增减仓？），这是缺口（E-0159）。
- **本卡不否定股票侧的洗牌/做牌框架**：第153课讲的"投机商行洗牌 ≈ 主力做仓做牌"（K-0061）是**股票/旧商行语境**；本卡是**期货语境**。**两者不可互换使用**，原稿分别在两课出现，未做统一说明。
- **本卡不能用来否定操纵**：原话说的是"没有绝对主力"，不是"没有资金影响价格"；K-0064 里老师讲的"大额卖单压低价格"仍然成立。
- **"三个单位逐级收窄"的量法原稿未给**：单位是多少、怎么量，未写。

## 与其他概念的关系

- 与 K-0061（投机商行的洗牌机制）：见上"边界"——一课股票、一课期货，**不得互相解释**。
- 与 K-0067（均线粘合不能脱离大级别背景）：本卡解释"为什么这段会粘合"（收敛结构在酝酿），K-0067 解释"这段粘合不能读出上涨"。
- 与 K-0003（均线粘合）：收敛结构最终表现为均线粘合，本卡是它的资金侧说法。

## 案例与证据

- **C-0017 甲醇（2020-06-24）**：压力线 + 三个震荡单位等比递减 + 均线粘合 → 多空都不做，等区间外突破（E-0159）。
- **C-0016 甲醇（2020-06-19）**：箱体内操作必须服从止损；大举放空要等黄线被打漏（E-0153）。
- 结果：原稿未报告该收敛结构最终向哪一侧突破；**黄线数值始终未给**（跨批检索目标，见抽取记录）。
