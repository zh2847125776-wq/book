# K-2368 量能判断时间律：越接近收盘越准

> 来源：SRC-004270（第1620课 股票日评：3458关前缩量推演与多空线三测）· 证据 E-59082
> 来源立场：课程讲述者采纳
> 底本层级：完整稿可见

一句话定义：对全天量能的判断按时间逐级修正，9点25分最不准，越接近收盘越准（E-59082）。

## 它解决什么问题
给"竞价缩量→缩量收阴"类盘前推演设置修正出口，避免把竞价量当定论。

## 如何识别
- 判断准确度排序：9点25分最不准 → 9点半次不准 → 第一个五分钟 → 一刻钟 → 半小时 → 一小时 → 半天 → 三小时 → 收盘最准（E-59082）。
- 例外情形：竞价缩量但盘后放量，"那这个就没招了"（E-59082）。

## 适用边界与失效
- 原文只给排序，未给各时点的量能换算系数（原文未明确）。

## 与其他概念的关系
- 是 S-0898（竞价缩量推演）的内置失效条款。
- 与早前"首小时量估全天"类卡同属盘中估量方法，本课未给出具体倍数。

## 案例与证据
- 20201203 上证竞价 32→30 的推演（C-1509，E-59082）。
