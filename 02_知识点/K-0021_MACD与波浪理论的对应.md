# K-0021 MACD与波浪理论的对应（用MACD数浪）
> 来源：SRC-003572（MACD精讲（学习笔记））、SRC-006650（MACD专题：仓位控制表2（加权计分）与MA） · 证据 E-0028、E-0030、E-0032、E-0033、E-0039
> 来源立场：课程讲述者采纳（建卡时漏标，2026-09-28 按门4回填；若有书中作者或编辑者评注，须拆开标注）

一句话定义：课程用 MACD 的状态给波浪编号——数不出浪时看 MACD 就能数出来：一浪＝零轴下方盘整后穿零轴放红柱，三浪＝零轴附近金叉快速上涨、红柱大幅放出，五浪＝远离零轴死叉、常规以顶背离（头肩顶）结束，C 浪＝再次死叉后穿零轴大跌。

## 它解决什么问题

波浪理论"千人千浪"、编号主观；MACD 有零轴与柱体这些客观状态，可以用指标状态反推浪的编号，把主观编号变成可核对的清单（E-0033）。

## 如何识别

原稿给出的对应表（E-0033）：

| 浪 | MACD 特征 |
| --- | --- |
| 一浪 | 零轴下方盘整后**穿零轴放红柱**（时间长、涨得慢、涨幅小） |
| 二浪 | 零轴附近死叉放绿柱，**不跌破零轴或跌破不多** |
| 三浪 | 零轴附近金叉（上头下头都行）**快速上涨、红柱大幅放出** |
| 四浪 | 高位死叉放绿柱，**时间调整有限** |
| 五浪 | 远离零轴死叉、红柱放出较短；常规结束＝创新高＋顶背离（头肩顶），失败＝无背离顶部 |
| A浪 | 高位死叉调整，**一般不穿零轴** |
| B浪 | 反弹至前一定位置，可创新高、可多波次结构 |
| C浪 | 再次死叉后**穿零轴大跌** |

配套表述（E-0033）：

- 浪延伸，MACD 也延伸。
- 在**周线、月线**上看浪形更准，别去一分钟级别钻牛角尖。
- "只会浪不会算"没用：1.618／1.382／2.382 倍那套＝"江恩式马后炮"。

## 适用边界与失效

- 波浪本身在原稿里被质疑过：波浪若为公理就不需要九浪、延伸浪、扩展浪来补窟窿（K-0013 引同一段）（E-0039）。所以本卡是"用 MACD 校验波浪"，不是"用波浪预测 MACD"。
- 对应表没有给"浪的级别"（日线浪还是周线浪）与"红柱大幅放出"的量化标准（E-0033）。
- 五浪"失败＝无背离顶部"与"常规＝创新高＋顶背离"是两种结局，原稿未给判别时点（E-0033）。
- 表里的"零轴附近""高位""远离零轴"均为定性词（E-0033）。
- 本卡不涉及第02课之外的其他波浪课程内容；本批资料内另有"波浪理论1"增强版属他组范围，不引用。

## 与其他概念的关系

- **K-0020 MACD顶底背离与趋势线**：五浪的结束判据之一就是顶背离，且原稿要求"五浪顶背离要跟三浪比"（E-0032、E-0033）。
- **K-0017 MACD零轴**：一浪、C 浪的关键动作都是"穿零轴"，二浪、A 浪的关键是"穿不穿零轴"（E-0033、E-0030）。
- **K-0016 MACD金叉死叉权重表**：三浪的"零轴附近金叉"正是 +++ 那格（E-0028、E-0033）。
- **K-0014 倒金字塔**：波浪理论在金字塔里属"进阶技术理论"，"波浪秘数"属"终极技术理论"（E-0028）。
- **K-0019 多周期共振**：浪形在周线月线看更准，与高周期优先一致（E-0033）。

## 补充：第2253课60分钟反弹的一二三浪与ABC用语并存
> 来源：SRC-004965（第2253课 股票日评：交叉共振上反回测正常调整守好五日线（20230905））· 证据 E-54501

一句话定义：本课用零轴下金叉穿轴、零轴上死叉、零轴附近或上方再金叉叙述三段反弹，并称为ABC结构；保留本课用语。

## 它解决什么问题
记录讲述者怎样解释60分钟反弹需要调整，避免替原文统一波浪编号。

## 如何识别
- 一浪：零轴下方金叉穿轴；二浪：零轴上方死叉；第三浪：零轴附近、零轴之上金叉。（E-54501）
- 讲述者将这一串联称为反弹ABC结构，并说需要休息。（E-54501）

## 适用边界与失效
只保存本课解释。它同时出现“一二三浪”和“ABC”，对应关系原文未明确；不得把此处ABC替换为主卡的标准A/B/C表，也未提供调整持续时间或买卖动作。

## 与其他概念的关系
