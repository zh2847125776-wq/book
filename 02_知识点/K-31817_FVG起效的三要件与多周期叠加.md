# K-31817 FVG起效的三要件与多周期叠加

> 来源：SRC-005067（第2345课 股票日评：放量滞涨今明两日阴线兑现之后走势才是关键（20240126））· 证据 E-67687, E-67688
> 来源立场：课程讲述者采纳
> 底本层级：完整稿可见

一句话定义：FVG（合理价值缺口）在行情中要产生实质性的有效压制或支撑作用，不能独立存在，必须具备与OB区或base区间贴近互证、具备较大K线实体，以及最关键的与更高周期同类型区域产生叠加共振（WFVG、DFVG、HFVG三周期叠加，叠加边界以最小周期为准）三个要件。

## 它解决什么问题
解决在单周期图表上FVG区间泛滥、处处设阻导致分析失真（“任意一个都能产生严重压制，那还得了？那永远它也别涨了”）的问题，建立筛选真正具有压制/阻碍效力的关键FVG区间的过滤规则。

## 如何识别
1. **要件一（不能独立存在）**：FVG区间自身不能孤立起效，必须与其他有意义的分析手段互相配合，例如贴近OB区，或正好压在base区间的上限产生互印 E-67687。
2. **要件二（较大实体）**：形成FVG的对应K线需要是一个较大的阴线或者阳线实体；若K线实体不大则不满足该要件，单独压制力弱可暂时放过（原文未明确量化实体具体阈值） E-67687。
3. **要件三（更高周期同类型区域叠加）**：这是最核心要件，该区间的FVG能与更高周期的同类型区域产生重叠（如周线WFVG、日线DFVG与小时线HFVG三周期重叠） E-67688。
4. **生效边界认定**：当出现多周期同类型区域重叠时，重叠区域的具体生效点位边界以最小周期（如60分钟或1小时线）为准 E-67688。

## 适用边界与失效
- **孤立无配合失效**：在下跌或反弹过程中，孤立无其他形态配合、单一周期的FVG极易被价格直接突破蹿升，无法构成有效阻力 E-67687。
- **实体较小则依赖大周期**：若产生FVG的实体不大，单独压制能力受限，必须高度依赖是否与周线、日线更高级别FVG产生共振 E-67687。
- **以最小周期划定执行边界**：尽管阻力级别由大周期决定，但交易执行和具体点位观察必须聚焦于最小周期的上下限区间 E-67688。

## 与其他概念的关系
- 与 **OB区 / base区间**：FVG不可孤立使用，需与OB区或base区间上限重叠以构成形态互证 E-67687。
- 与 **WFVG / DFVG / HFVG**：分别指代周线、日线、小时线周期的FVG，三者在同一价格带重合构成极强压制带 E-67688。
- 与 **关前/关后整理**：价格运行到多周期叠加FVG等关键点位时往往出现横盘停滞、高低点上行放缓或关前整理，属于正常的结构性反应 E-67695。

## 案例与证据
2024年1月26日上证指数反弹至2906-2917区间，该区间同时为周线WFVG、日线DFVG及60分钟/HFVG三周期叠加位置，且贴近base区间上限，指数在该区间内出现横盘滞涨停顿 E-67687, E-67688, E-67700。
