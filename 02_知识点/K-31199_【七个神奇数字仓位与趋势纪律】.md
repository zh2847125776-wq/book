# K-31199 【七个神奇数字仓位与趋势纪律】

- **标签**：#交易纪律 #仓位管理 #神奇数字 #60日均线 #最大回撤
- **概念定义**：指由数字三、五、六、七、八、二十构成的完整交易风控与持仓纪律体系，涵盖持股集中度、单只仓位上限、牛熊分界线、超短操盘线、单笔止损与账户总回撤红线。
- **关键特征**：
  1. 数字三（持股数量）：资金在百万元以内，持股不超过3只，集中资金与精力深入研究。
  2. 数字五（单股上限）：单只股票最大投资比例50%，走势不明朗时保留五成现金仓位。
  3. 数字六（牛熊分界）：以60日均线为多空分界，股价突破60日均线方可确认中期趋势向上。
  4. 数字七（超短操盘）：以7日均线作为超短线持股与减仓的敏感防守线。
  5. 数字八与二十（止损底线）：单笔交易最大亏损控制在8%以内；账户总资金最大回撤达到20%时强制暂停交易反思。
- **核心逻辑**：散户投资亏损的核心症结在于买股过多、仓位失控、逆势死扛与无底线回撤。通过将关键风险参数量化为明确的数字纪律，能够将不可控的人性情绪转化为标准化的执行约束。
- **常见误区**：
  1. 资金不足百万元却分散持有十几只股票，自以为“分散风险”，实则无法深度跟踪。
  2. 股价跌破60日均线长期走弱依然死扛，拒绝执行单笔8%止损纪律。
