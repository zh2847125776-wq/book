# K-0077 上升三法的兑现条件

> 来源：SRC-003576（第06课 0115午间直播）＋完整稿 SRC-007874＋增强稿 SRC-007865 · 证据 E-0173

一句话定义：上升三法不是看到阳线就成立，必须**同时兑现价格位置与量能**——次日开盘高于参考阳线的开盘价、收盘高于参考阳线的收盘价，且量能继续向上；任一条不兑现，形态就不成立。

- **立场**：课程讲述者采纳（老师原话，第06课）。
- **底本层级**：条件本身（开盘／收盘／量能三条）＝**完整稿可见**；具体数值 **3518／3608 → 3520／3610** ＝**仅增强稿与原始转写可见**（完整稿、精简稿均未收）。
- **来源**：SRC-003576（第06课 0115午间直播）。证据：E-0173。

## 它解决什么问题

防止把"形态名称"当成自动买入信号。老师说得很直白：**形态名称不是自动买入信号，必须等关键价格和成交量条件兑现**（E-0173）。

## 如何识别

- **三条成立条件**（第06课）：
  1. 次日**开盘价**高于参考阳线的开盘价；
  2. 次日**收盘价**高于参考阳线的收盘价；
  3. **量能**继续向上，不能只是价格上涨而成交不足。
  （E-0173）
- **两条否定条件**：
  - 次日**低开到参考阳线开盘价下方** → 上升三法的**开盘条件就不成立**；
  - **放量下跌击穿关键位置** → 也不能继续按上升三法看待。
  （E-0173）
- **参考值与推演值（仅增强稿与原始转写可见）**：原始转录中的参考阳线开盘 **3518**、收盘 **3608**；老师当场推演"次日开盘 3520、收盘 3610"。增强版明确标注"3520 与 3610 属于条件示例，**不是已经出现的次日行情**"（E-0173）。
- **老师的原话结构**（原始转写）："明天开盘价要高于这个阳线……这个阳线的开盘价是 3518，我们来个 3520 开盘价，收盘价要高于这个阳线，收盘价高于它是 3608，它要收一个 3610"（E-0173）。

## 适用边界与失效

- **本课只给了三条条件，没有给"量能继续向上"的门槛**：是比前一日放大、还是均量之上，原稿未写（E-0173）。
- **"关键位置"未定义**：否定条件里的"击穿关键位置"没有指出是哪条线（20 线？红豆？），原稿未明确（E-0173）。
- **形态的完整形态学（三根还是五根 K 线、中间几根的要求）本课未展开**：只讲了"次日"这一根与前一根阳线的关系（E-0173）。
- **原始转写另有"上升三盘"的写法**：ASR 里"上升三法／上升三盘"混用，第06课 ASR 订正表已把"上升三盘"列为常见误写（E-0173 语境）。
- **第06课当日没有兑现**：老师说"当前 K 线形态是否成立，须等对应的价格和量能条件出现"，**当日并未成立**，也没有报告之后是否成立。
- 原稿**未提供上升三法判断错误的失败案例**。

## 与其他概念的关系

- 与 K-0076（反弹与反转的分界）：同属"形态必须被兑现"这一类判据；K-0077 管 K 线组合，K-0076 管压力位。
- 与 K-0041（根据所见交易）：上升三法的三条条件就是"所见"的具体化。
- 与 K-0011／S-0003（三加买入法）：两套都是 K 线组合买点，但**第06课没有把上升三法与三加挂钩**，原稿未说明两者关系，**不得互相替换**。
- 与 K-0009（有效跌破与站上的确认）：站上／跌破的口径问题与第 3 条（量能）相邻。

## 案例与证据

- **C-0020 上证 2021-01-15**：老师用"如果次日要形成上升三法"做条件推演，参考阳线 3518／3608，推演 3520／3610；同时说明低开到 3518 下方或放量下跌击穿关键位置即不成立（E-0173）。
- 结果：**该形态当日未成立，原稿未报告后续是否成立**。
