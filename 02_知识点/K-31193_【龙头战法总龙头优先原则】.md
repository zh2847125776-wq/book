# K-31193 【龙头战法总龙头优先原则】

- **标签**：#龙头战法 #市场总龙头 #分龙头 #抗风险能力 #板块领军
- **概念定义**：在围绕市场核心领涨股票进行交易的“龙头战法”中，当市场存在公认的总龙头标的时，应坚决优先选择市场总龙头，放弃跟风的分龙头或支线龙头，以追求超额收益并获得更强的抗风险保护。
- **关键特征**：
  1. 领军地位明确：市场总龙头通常为行业领军企业，具备强大的品牌影响力和市场占有率。
  2. 收益分享能力强：总龙头最容易分享到板块和行业增长的超额收益，上涨空间与溢价最高。
  3. 综合竞争力与抗风险优势：总龙头拥有更稳定的经营状况与抗风险能力，分龙头在整体竞争力上往往逊于总龙头。
  4. 资金抱团向心力：存量资金优先抱团总龙头，分龙头在退潮期更易被主力弃庄。
- **核心逻辑**：龙头战法的核心在于流动性溢价与合力凝聚。市场总龙头汇聚了全市场最高的关注度、成交量与辨识度，其韧性与弹性远超后排；后排分龙头在主升时涨不过总龙头，分歧时却往往率先大跌。
- **常见误区**：
  1. 误以为总龙头涨幅过大风险高，转而买入“便宜”的跟风分龙头，结果遭遇严重补跌。
  2. 误将支线板块的脉冲涨停个股当成总龙头对待，混淆主次。
