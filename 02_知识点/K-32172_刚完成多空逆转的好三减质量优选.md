# K-32172 刚完成多空逆转的好三减质量优选

> 来源：SRC-005137（第2408课 股票日评：调整结束第二买点出现加仓勇敢进攻（20240517））· 证据 E-69031、E-69032、E-69033、E-69034
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在均线系统刚完成基于长期均线的多空逆转信号序列后，位置最贴近短期均线与中期均线缠绕处出现的好三减形态，属于质量等级最高、盈亏比最优的第一档信号。

## 它解决什么问题
解决同一形态在行情不同演化阶段出现时质量分级不清、跟风追高导致止损幅度过大的筛选问题。

## 如何识别
1. 均线系统完成左侧多空逆转完整信号序列：站上60日线 -> 5日穿60日 -> 10日穿60日 -> 20日穿60日 -> 30日穿60日 -> 回测向上60日 -> 20日线向下后再向上E-69032。
2. 60日均线与20日均线均转头向上，日线级别确立为标准多头排列E-69033。
3. 价格位置处于刚刚完成20日穿60日之后，紧密贴近20日线与60日线，两条均线差值尚未大幅拉开E-69034。
4. 形态越贴近刚刚完成趋势逆转的节点，其质量级别属于第一档（最好的好三减）E-69031。

## 适用边界与失效
适用于趋势逆转确立初期的均线贴近阶段。若20日线与60日线差值已大幅拉开，则属于趋势中后期形态，质量等级下降；若价格反向跌破60日线，则逆转判定失效。

## 与其他概念的关系
类比于FVG（公允价值缺口）中贴近订单块（OB）、多周期叠加的高质量区间；优于均线大幅发散后出现的三减形态。

## 案例与证据
2024年5月17日创业板指数在日线完成20穿60后紧贴20和60日线，止损距离极近且有缺口加持，被评定为刚转过来的最好的好三减E-69031、E-69034。
