# K-33198 戈岩选股指标

> 来源：SRC-000173（专题_技术专题_番外：GYX指标分享（增强版））· 证据 E-74100、E-74102
> 来源立场：被批评的方法
> 底本层级：仅增强稿可见

一句话定义：出自《趋势与拐点交易法》的一种基于典型价格与N日移动平均线差值及其绝对偏差求和构成的技术指标，公式为 (A-B)/(C×0.015)，以数值上穿100作为强势股买入信号（E-74100、E-74102）。

## 它解决什么问题
原书作者试图解决在股市中筛选处于加速上涨状态的强势股、力求“速战速决、局势逆转紧急逃生”的选股与顺势交易问题（E-74102）。但讲师实证指出该指标存在缺乏出场与止损规则的严重设计缺陷（E-74103）。

## 如何识别
1. 典型价格计算：A = (最高价 + 最低价 + 收盘价) / 3（E-74102）。
2. 基准均线计算：B = A 的 N 天移动平均线（E-74102）。
3. 偏差累计计算：C = 【绝对值(当日A-当日B) + 绝对值(前1日A-当日B) + ... + 绝对值(N天前A-当日B)】（E-74102）。
4. 指标输出与触发：戈岩选股指标 = (当日A - 当日B) / (当日C × 0.015)；当数值首次突破100信号线时发出买入信号（E-74102、E-74103）。

## 适用边界与失效
1. 常数拟合限制：公式中引入固定常数0.015，在不同波动率品种或不同时间周期下的有效性存疑（E-74101）。
2. 出场与止损缺失：原书未提供卖出出场点与止损设计；实测以跌破5日线出场时，多数交易收盘进出无利可图，遇大阴线直接亏损（E-74103、E-74104）。
3. 假突破与极端行情失效：实盘中频繁出现突破100后迅速回落至100下方的假突破；且在极端强势暴涨品种上，前一日指标在81.11未发信号，次日直接一字涨停无法盘中成交（E-74105、E-74106）。

## 与其他概念的关系
1. 对照：与讲师提倡的“有依据、有明确止损且经受量化回测”的规则完整交易体系相对立（E-74103、E-74107）。
2. 补充：数学原型与顺势指标（CCI）算法高度重合，属于变相包装指标，并未解决交易系统的出场闭环问题（E-74100、E-74102）。

## 案例与证据
在股票中国联通（600050）与宁波联合（600051）的日线图上实测，中国联通买点进场后迅速掉回100下方，破5日线出场无利可图或直接亏损；宁波联合前一日数值81.11未给信号，次日即一字涨停无法买入，后续买点数值也迅速跌破正100（E-74103、E-74104、E-74105、E-74106）。
