# K-33107 均线有效站稳判据（三天原则）

> 来源：SRC-001054（股票_20200403量化技术分析（增强版））· 证据 E-73669
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：股价突破并站上某条重要均线后，必须经历盘中回测检验且连续三个交易日收盘保持在均线上方，方可确认该均线被有效站稳 [E-73669]。

## 它解决什么问题
解决交易者在股价单日突破均线后盲目追多、缺乏有效过滤机制而屡屡遭遇假突破被套的交易决策问题 [E-73669]。

## 如何识别
1. 股价首个交易日收盘价突破并站上目标均线（如50日线）[E-73669]；
2. 次日盘中必须进行回测动作（即盘中下探测试该均线支撑有效性）[E-73669]；
3. 回测后收盘价不得跌破均线，且必须连续站稳三个交易日，才算多数人认可的有效站稳 [E-73669]。

## 适用边界与失效
1. 处于突破后的第一天或第二天，只能视为初步测试，绝不能轻信已经站稳，不可掉以轻心 [E-73669]；
2. 若根据扣底计算，该均线次日将拐头向下或整体呈现走平状态，则该均线无法提供坚实支撑，三日站稳判据的有效性大幅降低甚至失效 [E-73670]。

## 与其他概念的关系
- 与 [S-3224](file:///C:/Users/赵豪/dsh/交易知识体系汇编)（站上20日均线买入三条件准则）为充要前提关系：S-3224中核心买入第二条件“站上得有效”，直接依赖本知识点中的三日原则与回测不破进行确认 [E-73669]；
- 与 [K-33110](file:///C:/Users/赵豪/dsh/交易知识体系汇编)（量比价先行与均量压制原则）为共振检验关系：突破与站稳过程必须有成交量配合，若缩量且低于五日均量，则属于无量假站稳，极易回测失败 [E-73670, E-73671]。

## 案例与证据
2020年4月3日上证指数，前一交易日首度收盘站上50日线，4月3日盘中最低点下探至2754点，标标准准回测当日50日线（2754点），尾盘拉起收于2763.99点（50日线变为2755点），虽守住均线但仅为站稳的第二天，讲述者明确提示不能掉以轻心 [E-73669, E-73670]。
