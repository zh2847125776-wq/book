# K-0033 连续两个红柱缩短＝短线卖出信号
> 来源：SRC-003579（第09课 0428解盘：吊颈线不算、走平20线无意）、SRC-007877（第09课 0428解盘：吊颈线不算、走平20线无意）、SRC-011817（第09课 _0428解盘（增强版）） · 证据 E-0059、E-0066
> 来源立场：课程讲述者采纳（建卡时漏标，2026-09-28 按门4回填；若有书中作者或编辑者评注，须拆开标注）

一句话定义：MACD 红柱连续两根缩短，即构成短线卖出信号。

## 它解决什么问题

解决"MACD 在没有死叉之前能不能提前给出卖出提示"的问题。课程把它作为可机械执行的规则使用，并与50线拐头（K-0032）构成双确认（E-0066）。

## 如何识别

- **形态条件**：MACD 红柱**连续两根缩短**（E-0066）。
- **实例**：2019-09-13 当周，本周二 MACD 红柱已经缩短、周三缩短、周四缩短——"我们说连续两个红柱缩短就是短线卖出信号"（E-0066）。
- **配套判读**：该位置"虽然是多方掌控区域，但它明显是买力不足、需要修整"（E-0066）。
- **同一课上 MACD 的另一种用法**：零轴下方连续两根红柱缩短 → 攻方力量衰减（E-0059；第09课实例）。
- **未确认的指标不算数**：KDJ 当时是"明显的顶部背离状态，但**现在还没有**（确认）"——信号＝条件恶化＋触发，缺触发不行动（E-0066）。

## 适用边界与失效

- **成立前提（原稿自带批判条款）**：红柱缩短在强势市场会出现大量假信号（缩短两根后再创新高的走法很常见）；该信号**只在"涨幅已大＋超买＋时间窗口临近"的组合下才可靠**。原稿明确"单抄规则不抄前提会挨打"（E-0066）。
- 原稿**未给出红柱缩短的幅度门槛**（缩短多少算缩短）（E-0066）。
- 原稿**未给出该信号的失效条件与止损口径**（E-0066）。
- 原稿未提供该信号的失败案例或统计。

## 与其他概念的关系

- 与 K-0032（50线走平拐头）在本课构成双确认（E-0066）。
- 与 K-0034（红绿凑周期）同属 MACD 柱体记账法，但本条管**短线卖讯**，K-0034 管**周期凑数的归属**。
- 与 K-0006（均线背离）并列时可能给出同向信号；优先级原稿未说明。

## 案例与证据

- 证据：E-0066（第1419课，SRC-004044 / SRC-008342）、E-0059（第09课，SRC-003579 / SRC-007877）。
- 案例：C-0005（上证 2019-09-13 休市解盘；周二至周四红柱连续缩短）。

## 补充：日线MACD红柱缩短敏感度数理测算：指数跌幅超1%即迫使红柱翻跌发出衰竭信号
> 来源：SRC-001633 · 证据 E-53242
> 来源立场：课程讲述者采纳（MACD红柱缩短临界点精确测算模型）
> 底本层级：仅增强稿可见

一句话定义：通过量化模拟推演，当创业板指数次日跌幅超过1%时，即使收盘价尚未跌破5MA，日线MACD红柱数值亦将从53.06骤降至52.95，正式触发动能衰竭卖讯。

## 如何识别
- 指标敏感度的提前量化：不必死等收盘后指标被动显示；盘前输入假设点位测算可知，一旦跌幅达1%，DIF与DEA差值即刻收敛，红柱确定性缩短（E-53242）。
- 动能衰竭先于均线破位：红柱缩短是反弹动量见顶的第一道先验警报，随后才会引发5日均线拐头与破位，为交易者争取宝贵撤退先机（E-53242）。

## 适用边界与失效
指导A股指数日线级别反弹高点的提前推演与预警；若次日多头超预期放量拉升则红柱继续扩张。
