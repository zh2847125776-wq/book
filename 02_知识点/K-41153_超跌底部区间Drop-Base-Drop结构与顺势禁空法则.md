# K-41153 超跌底部区间Drop-Base-Drop结构与顺势禁空法则

> 来源：SRC-000505 期货_期货投机技术分析20230614（增强版） · 证据：E-87882, E-87883

### 核心概念与运作机理
当商品期货在经历大级别长期深幅暴跌后，时间与空间幅度均已高度透支，在技术形态学上确立“超跌底部绝对禁空法则”：
1. 空间与均线偏离：价格远离60MA均线且60MA以极快斜率下行，系统反弹修复负乖离率的空间极其巨大；
2. 禁空与做空条件：在超跌底部平台区域内，绝对不考虑追空，仅考虑右侧抄底做多；若要重启顺势做空，必须等待价格跌破前期大底低点（如甲醇的1953元），从而在形态学上构成“超大Drop区间 + Base基底平台 + 超大Drop区间”的二次破位延续；
3. 移仓换月与除权除息价格压制一致性：在均线粘合再选方向时，期货移仓换月产生的跳空缺口与股票除权除息具有完全相同的技术分析压制意义，无论使用主力合约、主联合约、指数还是复权图，价格高点均会在对应坐标系产生刚性技术反压。

### 适用场景与边界条件
- 适用场景：商品期货（甲醇、玻璃、豆粕等）熊市末期、移仓换月期间的趋势界定与空头头寸管控。
- 边界条件：在底部基底平台内严禁追空；破位大底前仅允许寻找反弹多头机会。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
为无量超跌反弹五天平台（K-41170）提供底部结构前置约束；与MACD穿轴预警及安全期耗竭（S-25705）构成空头动能强弱的分水岭。

### 案例与证据
- 案例标的与时间：2023年6月14日甲醇与豆粕主力/主联合约复盘。
- 实盘数据特征：甲醇自高位深跌已久，系统标出1953前低作为生死分水岭，明确在未跌穿前坚决不做空；豆粕移仓换月缺口与均线粘合，论证了除权图与复权图在压制计算上的技术同质性。
- 逐节证据标定：超跌底部大Drop-Base-Drop做空条件参见 E-87882，移仓换月与除权除息压制同质性参见 E-87883。
