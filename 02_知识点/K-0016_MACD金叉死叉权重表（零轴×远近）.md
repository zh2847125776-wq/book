# K-0016 MACD金叉死叉权重表（零轴×远近）
> 来源：SRC-003571（三加详解（股指双轨买入法））、SRC-003572（MACD精讲（学习笔记）） · 证据 E-0022、E-0028、E-0029、E-0030、E-0031
> 来源立场：课程讲述者采纳（建卡时漏标，2026-09-28 按门4回填；若有书中作者或编辑者评注，须拆开标注）

一句话定义：把快慢线的金叉/死叉按"在零轴之上还是之下"与"离零轴近还是远"分成格子，每格给权重正负号，其中"零轴之上＋金叉＋近零轴"是 +++ 的最好金叉、"零轴之下＋死叉＋近零轴"是 −−− 的最差结构，这两格不可改。

## 它解决什么问题

金叉死叉本身只是"交叉"这一个动作，权重表把它变成**分档的动作**：同样是金叉，位置不同则含义与后续空间不同（E-0028）。

## 如何识别

原稿给出的六格（E-0028）：

| 结构 | 含义 | 权重 |
| --- | --- | --- |
| 零轴**之上** ＋ 金叉 ＋ **近**零轴 | **最好的金叉**，向上空间大 | **+++（三加，不可改）** |
| 零轴之上 ＋ 金叉 ＋ 远离零轴 | 要穿很长一段空方区，穿轴前涨幅不大 | 差 |
| 零轴**之下** ＋ 金叉 ＋ **近**零轴 | 有穿轴预期，穿轴同时红柱放大 → 大涨 | ++（**二加**，也不错） |
| 零轴之下 ＋ 金叉 ＋ 远离零轴 | 大幅下跌后的反弹、负乖离修复、前途未卜 | 负（不操作） |
| 零轴之上 ＋ 死叉 ＋ 远离零轴 | 向下空间相对较大 | 减号 |
| 零轴之下 ＋ 死叉 ＋ 近零轴 | 向下空间大，**最差结构** | −−−（**三减，不可改**，不操作） |

口诀（原稿要求背下来）（E-0028）：

> **零轴之上：金叉大涨、死叉小跌**
> **零轴之下：金叉小涨、死叉大跌**

"大兴走到天安门"类比（解释为什么近零轴的金叉好）（E-0028）：远离零轴的金叉在"大兴"，要先穿过整个空方掌控区才到零轴（"天安门"）；实盘对照是**穿轴前收盘价基本不动，穿轴后三四天的涨幅就大过之前全部**。零轴下方近零轴金叉为什么也好：低位进场大概率演变成"一边穿轴一边红柱放大"。

注意事项（原稿逐条给出）（E-0028）：

1. 表格是参考，并非行情绝对。
2. 距离零轴**只有最小值，没有最大值**（远了还能更远，同20日线道理）。
3. "倒压轴"（靠轴）带来不确定性。
4. **除三加、三减结构绝对不可修改外，其他格子都可根据个人想法修改。**

## 适用边界与失效

- 六格之外的组合原稿未列（例如"零轴之上＋死叉＋近零轴"）；完整稿未给 → 缺口（E-0028）。
- **不可改的只有两格**（+++ 与 −−−），其余格子课程允许个人修改——这与 K-0014 的"不要改参数"是两个层面：改的是分格权重，不是指标参数（E-0028、E-0022）。
- 距离"远/近"的量化阈值原稿未给（只有"只有最小值没有最大值"这句定性说明）（E-0028）。
- 权重表在课程里属"参考"：原稿第一条注意事项就写了"表格是参考，并非行情绝对"（E-0028）。

## 与其他概念的关系

- **K-0011 三加形态**：这里的"三加/三减"是 MACD 口径（零轴之上＋金叉＋近零轴 / 零轴之下＋死叉＋近零轴），**与第01课 20 线口径的三加不是同一套定义**，不可混用（E-0028）。
- **K-0017 MACD零轴**：本表的两个分档维度之一就是零轴上下（E-0029）。
- **K-0018 MACD红绿柱强度**：零轴之下＋金叉＋近零轴要"穿轴同时红柱放大"才大涨，把本表与红绿柱强度绑在一起（E-0030）。
- **K-0019 多周期共振**：按表操作时课程要求用 2~3 个周期搭配，只盯日线金叉可靠性最低（E-0031）。

## 批 004 补充：零轴附近死叉可能是突破失败

**来源**：SRC-003969（第1351课 期货直播20201225）· 证据 E-0235 · 底本层级：完整稿可见 · 立场：课程讲述者采纳

第1351课在直播复盘中把零轴位置与金叉死叉的方向、空间再讲了一遍，与本卡权重表**同源**（口诀一致：零轴之上金叉大涨、死叉小跌；零轴之下金叉小涨、死叉大跌），但补出一条本卡此前没有的细则：

> **零轴上方死叉通常小跌，但零轴附近死叉可能是突破失败。**

这一条与权重表「零轴之下＋死叉＋近零轴＝最差结构（三减）」**方向相反**：权重表把**近零轴的死叉**判为向下空间大，而第1351课说**零轴附近死叉可能是突破失败**（向上）。原稿未说明两处的「近零轴」是否同一位置口径，也**未给判定分界**——已登记为分歧，**未合并、未改本卡条件**。

另补：原稿还提到「零轴上方金叉**远离零轴空间较小**」，与权重表「远离零轴要穿很长一段空方区」一致，属同义复述。
