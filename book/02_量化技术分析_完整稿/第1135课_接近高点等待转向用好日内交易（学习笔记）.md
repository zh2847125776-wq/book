# 第1135课 期货：接近高点等待转向，用好日内交易（20250612）

> 来源：B站UP主「量化技术分析」期货日评视频 20250612
> **核心结论：商品指数在近五天前三根K线区间内横盘、低点连续两次碰不到抖空线，此时不论做多做空都不好做——正确的动作是耐心避过阳线、等新的空头单边出现，而在震荡里唯一还能稳定挣钱的办法是把《日内交易策略》的当日回转规则（首根K线定方向、回调二后创高/创低下单、止损止盈按R倍数执行）机械地用好。**

## 一、商品指数：五天几乎毫无波动，等新空头单边

- 昨天夜盘商品指数是阴线，开盘前就说过：即使是编制可能并不那么科学的商品指数，因为它是连续一贯、相对稳定的指数，**它也有"五穿二十"交叉公正**——你看一开盘又拉红了。
- "这两天就不是特别好做"，包括此时此刻，指数也在**最近五天中前三天的K线范围内运行**；即使昨天白天收盘最高点一度创高，**收K价格也在前三天的最高价里面运行**。
- "最近五天其实几乎毫无波动"，这种情况之下不论做多还是做空都不是特别好做。比较反常的是以前不好做的品种——比如玉米——最近一段时间表现还行，但绝大多数品种都不太好做。
- 指数低点"一二三"这些位置跟**抖空线**接触都非常近，但**最近两次其实都没有到达**。"它也有机会这次碰不着抖空线继续往下走，那我们只好再等一等，等它新的空头的单边行情出现以后我们再做。"
- 回顾：有一天晚上分享了很多空单"全都给嘎了"，但后来结果都是好的；现在做的事一样——**耐心避过这些阳线就可以了**。

【老师点评/批判】指数横盘时"五穿二十"的信号在震荡区里反复失效，前提是它需要一个方向性的单边来兑现；低点碰不到抖空线既可以是"再等一等"，也可以是趋势就此转向向下，这里老师选择的是**不预测、只等触发**，代价是可能错过第一段。反例正是那些"全都给嘎了"的空单：方向对、时机错，照样亏。盈亏比上，横盘期硬做属于低胜率+低赔率，不如空仓。

## 二、实债：书上策略没触发，就不下单

- 昨天实债没有太好的交易机会。用刚学的《日内交易策略》里提供的策略：**第一个K线是阴线，阴线应该做空**；然后不断创低、不断创低，这里是回调一、这个是回调二，**应该等到这个低点创低再开空单**——没触发。
- "作者举了一整个月的交易，里头没有触发的交易也比较多一点，所以说这个就下不了单。"而且我们看的是**五分钟周期，K线数量可能少一点**；要是看一分钟或两分钟周期，这个就更不太好做，也没法触发这笔订单，"所以说也不用管了"。

【老师点评/批判】书里的规则本身允许大量"不触发"，作者一个月的样本里未触发占比不低——这正是规则的正常状态，不是失灵。前提是周期足够、K线数量够，五分钟已经偏薄，一分钟两分钟更容易被噪声吞掉。批判点：不要为了"每天都要下单"而放宽触发条件，不触发就是不下单，胜率优先。

## 三、黄金、白银：一平之内趋势切换四回，绝不能过夜

- 黄金**还是不能过夜**。最近为什么不好做：不论传统均线系统还是APR系统都一样，**它这个趋势变化太快了**——在这一平之内，这是平台低点、这是平台高点、这又是平台低点、这又是平台高点，"**一平之内趋势切换四回，这谁受得了**"。
- 举例：平台下降，这是平台下降以后的**第一个绿色箭头**，那是你的空单成本价，这里就损掉了，亏了。过夜还有跳高，一过夜就出问题。
- 看它的大周期：**六十分钟周期看人家还是个空单**——平台高点、绿色箭头下空单，然后就上去了；"那要是打开了（户金的）交易计划的话，那照样昨天还是亏损"。
- 白银情况能好一点，但照样不太好赚钱。

【老师点评/批判】黄金的问题不是方向判断错，而是**结构切换的频率超过了人工执行的成本**：一平之内四次反向，任何单一平台的止损都会被反复扫掉。老师把"不能过夜"放在方向判断之前——跳空是隔夜无法止损的风险，这条纪律优先于信号。盈亏比上，四次被扫的累计损耗远大于抓住一段的收益，所以结论是"不好做就先不做"。

## 四、铜、铝、氧化铝：跳空缺口与"看穿平台"的陷阱

- **铜**：过夜也麻烦。打开加权看——它是不是跳空缺口？加权也有跳空缺口，**这就是自然跳空缺口，不是换月**。头天晚上过夜时还好好的、平台在抬升，还觉得单子估计能挣钱，"结果第二天来就给你来个暴击，就很麻烦了"。
- **铝**：还是凑合，但平台低点在这里，最近两天都没给到特别好的交易机会。前面还想做空——贴近以后转绿色箭头做空，应该是这个K线，"那这里也被尬了，不是没有尝试过，失败了"。最近它在上涨，但没给个妥当的进场点。
  - 关键细节：这个K线阳线的最低价好像贴着平台很近，**但实际上你看穿了——它贴近的是下一个K线的平台，它是水平方向的**；垂直方向这个平台离得还有一段距离，而且**它的收盘价太高，从线价到这个地方止损不低**，没看穿。
  - 然后一直都没有碰到过中轨；到现在扩张又收缩，又该调整了。你做多试试？还是亏。
- **氧化铝**：跟刚才吐槽黄金的一样——平台低点、平台高点、平台低点、这里又是平台高点，**一平之内切换四回**，所以每次开单都不太成功：这里开多单损了，这里开空单损了，这个地方开空单又损了，这里做多单还是亏损，然后这里做空，目前这次空单还不知道怎么回事。
  - 看大周期：主要的原因还是在大周期上，**大周期从线价到前低倒是支持空的**，这次能不能成功？现在是红色箭头。
  - 做法：想做就试试，**贴近以后一色K、银线下空单，然后出绿色箭头下空单，近高止损**——就不用中轨止损了；最近晃晃悠悠这么多次、频繁被扫，那肯定只能用平台止损。"但是这个单子也很费劲。"

【老师点评/批判】铝这一段是全场最实用的技术批判：**"贴近平台"必须同时看水平方向和垂直方向**——视觉上贴住的是下一根K线的平台，垂直距离还很远，且收盘价太高导致止损空间过大，这种"假贴近"一开就是高成本单。氧化铝则说明：止损方式要跟着被扫频率调整——中轨止损在频繁震荡里失效，只能退到平台止损（近高），但平台止损的止损距离更大，盈亏比同步变差，所以老师给的是"可以试一试"而不是"必须做"。

## 五、锌、锡：为数不多的盈利单与人工执行的桎梏

- **锌**：给过一个多单，在**6月11号昨天早上9点05分**直播时给的，是近期为数不多能盈利的单子之一。箭头位置实际上是个**无色K线**，那是昨天早上来的第一个K线，但又是无色的，**实际上应该是它开单**；开单情况之下也没有触发止损——虽然盘中戳破了，但收盘收回去了，然后一路盈利。
- 但很难受：**它把中轨击穿的话，一共盈利空间是这么多，三分之二没了**；"即使做对方向了，一半利润也吐出去了"，**趋势的持续性非常差、非常糟糕**。
- 有同学说"我绿色箭头就跑、稍微有赚绿色箭头就跑"，可是你又卖飞了——"你看你这个价格卖出和这个价格有区别吗？没区别"；反过来说，你这个箭头要跑的话，也已经跑掉了。所以确实是最近两天**做对方向都不太好赚钱**。
- **锡**：现在应该开空单——**六十分钟正关率修复，日线压制可以**，那再下一个空单吧。但**现在不能下，现在是阳线**，等转绿箭头和一色K可以试一试，**站到红线上面去就不做了**。
  - "你看这个涅槃也吃不到"：第一根阴线下来的时候，平台还在抬高，你能下咱们下不了；第二个阴线下来、确认趋势往下走得很快的时候，**你离中轨已经很远了**。
  - 程序表面上很勇，在这根K线上开单了，可是你的成本是这么多，到现在还没脱离成本区呢；打个比方下一个阳线特别大，蹭一下站到红线上面去，你照样还是会亏损的。"很难做。"

【老师点评/批判】锌单点出核心矛盾：**方向对、趋势持续性差，中轨被击穿后回吐三分之二**——止盈太晚和止盈太早都会亏，所以老师承认"这两天做对方向都不太好赚钱"，这是行情的性质而不是方法的缺陷。锡这一段是对人工交易最尖锐的批判：程序能在第一根阴线上开单、成本极低，人工必须等第二根阴线确认，等确认完价格已经远离中轨，**成本劣势直接吞掉盈亏比**——所以"站到红线上面去就不做了"是硬性风控，不是犹豫。

## 六、焦煤、铁矿石、螺纹钢、热卷、碳酸锂、多晶硅、工业硅

- **焦煤**：有一个空单机会——这是平台高点、这是站上平台上线、这是**绿色箭头加公布平台下线**，倒是有个空单。之前我们在这个平台上线做多，判断是单边向上，中间有一点磨损；然而预判是从这里开始往下走，**结果非常可惜，它没下得去，这个单子就白干了，开单价和收单价格是一样的**。"但是我没有让你做多，因为它缺乏结构。"
  - 大周期（60分钟）：之前低点都在抬、高点也在抬高，**可是最近这个高点抬高的幅度和之前抬高的幅度你自己比一比，差很多，有一点要二次寻底的意思**，包括这里有SFP。
  - 所以想做的话，**从限价到前低、这个二次探底的思路比较可靠一点，做多就不太可靠了**。
  - 昨天下午两点二十接近尾盘，有的同学可能没做、或者当时在直播股票没看它，**那是第二次机会**。现在是不是红色箭头区域？怎么做——**翻一个绿色箭头可以做，或者一色K也可以**；现在上一个K线是阴线，实际上就可以了，**红线止损**。
- **铁矿石**：应该也是空单，做多肯定不行。这是平台低点；第一个平台抬高的K线是它和红色箭头接触以后的一色K，**成本是一样的，就差一跳**，结果出场在这里，**就挣一跳，挣不着钱**。这个空单会不会获得大周期支持？**至少60分钟不支持，日线也不甚支持，那就算了**。比如这里给过空单，下单点是这里、出场价是这里，**也是拿了一天，挣了两跳**。
- **螺纹钢**：也不好做，**现在做空的话离中轨太远**；**热卷**也是。
- **碳酸锂**：之前说想在这里下空单，因为这里是平台高点、攻破下空单，**可是这个单子没有触发**；平台抬高以后你应该在这里做多——这个地方一色K做多、这是红色箭头做多、RPA做多。但还是那个问题：**趋势持续性太糟糕，利润回撤了超过一半的**，"你要是不过夜就好了，一过夜就麻烦"。现在空单也做不了。
- **多晶硅**：这空单也做不了，**价格在近期区间低点，没法做，空向下空间太小了**。
- **工业硅**：给的是多单——**只要箭头指的时候平台是在抬升的，那它必然是多单**。怎么做？**贴近中轨一色K或者转红色箭头**，那就是它，这个K线漏了中轨漏了一点点。
  - 机械操作："这个出这个接，你会错过吗？不会，平台还在抬高，按纪律要求你得接回的"；然后这个出这个接，后面这个阴线就不用出了；这个不用出（收K价格在上面），这个出、这个接。**还是会产生一点磨损，但是可以接受**。
  - 这是近期为数不多挣钱的一个单子，而且**趋势持续性好一点**。

【老师点评/批判】焦煤是"结构缺失就不做多"的典型：白干的原因不是方向判错，而是**回踩没下去**——老师宁可接受白干也不做多，因为缺乏结构。铁矿则演示了"挣一跳/两跳"的低效交易：信号触发但大周期不支持，即便不亏也是无效劳动，**所以"那就算了"本身就是正确决策**。工业硅这一段是全课纪律含量最高的：平台在抬高就只做多、按规则出接、磨损可接受——**这套"出-接"机械动作的价值在于不漏趋势，代价是手续费和磨损**。

## 七、原油：当日回转规则完整实操（首根K线定方向 + R倍数止盈）

- 原油近期也不好做，**从来没碰过中轨**；但如果利用刚看书学的知识，这个单子就能做得到——**昨天晚上9点05分开的单子**。
- 从咱们的APL入手，这个单子是没法做的；尤其是《日内交易策略》，**它无视换月缺口**：主连它产生缺口，你就完全可以无视，**完全不需要去分辨它是自然缺口还是换月缺口**。
- 规则执行全过程：
  1. **第一个K线是阴线**，今天做空；
  2. 创新低下单（放大看应该是这里创新低下单），**把止损放在这里**——第一笔单子就损了，"你别着急"；
  3. 第一笔损了以后**马上创高，趋势发生变化，开始做多**；
  4. 做多**需要两个回调的K线**：这是回调一、回调二。这里虽然创高了，**但收K价没创高，不下单**；
  5. 继续往后走，回调正式开始，**这个K线创高下单，止损放在这里**。
- 目标测算："你自己量一量——下单点在这里，向下亏损是0.56，那0.56的话那么应该是28，那预计盈利是7.84"，这是预计的盈利目标。下单以后**守好止损、下好止损单，往上放个0.84就是你的止盈**。"好家伙这么远"——**这个盈利空间实现了没有？实现了**，刚才亏了那么一点点，这里不就挣回来之外还有盈余吗。
- 比作者更强大：准备平仓时"这个伙计他是个阳线，你会跑吗？你不会跑；他在红色箭头下，你会跑吗？你也不会跑，你就一直拿着他"，可以获得的收益——**作者追求的是1比1.5，你这都已经1比4了，你比作者还厉害**；"你就当他是0.5的亏损，你收益了2.0，你是不是比作者还厉害"。
- 现在出了，现在可以平了，**当然得等收K**。

【老师点评/批判】这一单是全课方法论的样板：**首根K线定方向 → 第一笔被损 → 反向创高切换 → 等回调二 → 创高下单 → 按R倍数挂止盈**。前提是严格机械执行，第一笔亏损是规则成本而非错误。批判点在于：老师自己也承认能拿到1:4是因为"我们的工具更丰富"（一色K、红色箭头辅助持单），普通执行者按书上1:1.5走人就足够了；而且"得等收K"——盘中信号不算数，这是防止假突破的关键约束。另外《日内交易策略》无视换月缺口这一条，简化了判断但要求品种流动性足够，否则缺口性质会影响止损位置。

- **棕榈油、欧线集运**：空单**不能过夜，一过夜就麻烦了**。欧线集运我们给过空单，**近高止损没触发**，然后昨天收盘就是一个能盈利的状态，但是你一过夜就有问题。
- **烧碱**：都不好做，**都在不断地点（走低）**，这个开不了空的，**大周期不支持**。
- **甲醇**：现在也开不了单。昨天直播的时候想着放空，但最后想了想算了、没有给箭头，然后这是平台低点。最近做多机会在这里和这里，**你要是过夜的话就是盈利的**，没做就没做、没办法。

【老师点评/批判】这一批品种的共同结论是"**大周期不支持 → 不开单**"，PVC 是经典案例：平台向下时信号没触发，等信号触发价格已经跑到平台上方，**说明信号与结构错位时宁可放弃**。纸浆点出了"放箭头"和"不放箭头"的胜率差异——**有明确信号才动手，主观发挥只在结构已经成立之后**（比如豆粕那段"你得自己主观能动的发挥"）。玻璃的"想试试就试试"是例外，因为它把目标价锚定在前低、且明确说"不是很好做"，属于可控的小仓位试错。

## 九、豆粕、玉米、豆油：平台抬升下的多单与止盈纪律

- **豆粕**：给过多单交易机会，在这个地方，这老早了——做多，然后这里出，然后这里尝试做空但**空单没触发**，然后**平台又抬高了，那就继续做多**，"你得自己主观能动的发挥"；包括这个地方也是多单。到这里的话，**加仓部分打平没挣钱，接回部分挣到钱了**。
- **玉米**：**该止盈了**——玉米攻破中轨你该止盈，止盈以后平台一下降你就死心了。
  - 那该放空、要不要空？**60分钟不支持，日线也不支持，他俩都是正乖离修复**。你要是想做的话也不是不行，**正乖离修复也是理由之一**，你可以等这个高点去止损，一会儿出一色K或者出绿箭头试一下。
  - 于是放个箭头：大周期都是正乖离修复，都有给过空单，**可是不好触发**——"这就是说这个人工还是稍微有点小问题"。
  - 其实头天晚上11点收盘，最后一个K线能下单，但是都收盘了你还下单干什么呢？转过天来就再也没碰着中轨了。**程序肯定会下单，在这个地方或者这个K线，加上回测关键就是它就下单了，那就有盈利，人工就不太行。**
  - 现在新下单也不行，60分钟不太支持；想做的话一会儿一色K下个单，**这个得严格执行红线支撑，因为它的60分钟不支持**。
- **豆油**：五连豆油下空的可以，我们给到了**豆油空**的认可。

【老师点评/批判】玉米这一段把"止盈"和"反手"分开：**攻破中轨就止盈、平台下降就死心**，止盈先于放空；而放空的前提是"大周期正乖离修复"这个次级理由，老师明确说"不是不行"但"不好触发"——**用次级理由开仓就必须把止损收紧到前高**。同时这段再次点出人工与程序的结构性差距：程序能在收盘最后一根K线挂单、次日就有盈利，人工因为"都收盘了还下单干什么"错过，这是执行层面的现实约束，不是方法错误。

## 十、工具与纪律补充（ZFL、快捷键、工具使用观）

- **ZFL 用法**：如果你的价格在**中轨上面**，我们给它一个多方判断，**出红黄柱、红柱容易出现波段高点**（不是百分百）——它这个波段高点的判断，肯定也是对的，后面比它高就高几条；如果**收K价格在中轨下面**，那它就**容易出现波段低点**。记住这个简单判断方法就可以了。这个信号稍微差一点、没产生什么作用。
- 平台上面的 ZFL 黄线判断波段高点，后面一直确实是横盘，过了一段时间那就刷新了；这个出黄柱以后后面还在继续涨，**你可以结合一色K或者LPA去使用**。
- **快捷键**：成交量按 Alt+1、Alt+2、Alt+3——Alt+1 就一个技术指标，Alt+2 是多指标组合，Alt+3 就是三个指标。**只想出现两个图的话，第二个图必须是成交量，第三个开始才是技术指标。**
- ZFL 在哪里找：上备用群去找，上周日上的课课程里头有课程视频和技术指标。
- **关于知识零散的答疑**："股票技术分析、期货技术分析或者说我们的交易技术分析，它不是线性的，它就是分开的，A和B可能完全毫无关系。"从主题角度就是 Y轴技术分析、X轴技术分析再加一个技术指标三大块；或者均线系统分析、形态系统分析、结构学加价格行为学分析、趋势技术分析和价格行为学分析。"**为什么让你学这么多？你在没学之前、你不了解自己之前，你是不知道你什么技术好使。你把它都刷一遍，刷完以后你重点根据自己的个人偏好、风险风格，你再去选交易方法。**"
- 有的同学就喜欢趋势交易，当日日内回转人家就不做；有的同学每天想睡个好觉、晚上不想持仓过夜，你要是做程序化交易就挂上当日回转挂件；你要是做日内交易，就按作者说的一样挣个0.84就走人、就睡觉去了，不用担惊受怕过夜。**各有千秋，当然有可能会卖飞，看你自己怎么追求。**

【老师点评/批判】ZFL 的定位被说得很清楚：**它只是辅助判断波段高低点的次级信号，不是百分百**，必须叠加一色K或LPA才有用——把单一指标当决策依据是典型误用。工具使用观这一段是方法论层面的批判：**技术是分块、非线性的，先全刷一遍再按自己的风险风格选方法**，而不是先锁定一种技术硬用。批判点：作者规则（1:1.5走人）与老师用法（持到1:4）各有代价，前者放弃后续空间、后者承担回吐风险，选择取决于能否承受隔夜与回撤。
