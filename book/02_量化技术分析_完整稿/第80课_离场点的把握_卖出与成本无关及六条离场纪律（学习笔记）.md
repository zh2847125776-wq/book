# 第80课 离场点的把握：卖出与成本无关，六条离场纪律

> 来源：蓝色视频·优先级四《离场点的把握》（2020-12-29晚8点录制，年底善意提醒，放公共频道）。
> 一句话结论：**卖出价格和你持仓成本无关——进场叫交易架构、离场是斩仓止损割肉或止盈，所有买点和卖点一一对应（三加对三减、金叉对死叉、Y轴颠倒即卖点）；六条离场纪律=破20线/上涨常态前低破/上升趋势线破/较大单阴/极高放量滞涨/五穿二十，守不住这六条就拿不住利润。**

## 一、核心理念：卖出与持仓成本无关

- "我是20块买的现在15块" → 两个问题：①为什么20块要买？②不卖亏损就不扩大了吗？这不是技术问题是逻辑问题。
- 进场=交易架构；离场=斩仓止损割肉+止盈，统称离场。
- **所有买点和卖点一一对应**：三加对三减、指标金叉对死叉、Y轴颠倒就是卖点。
- 盈利卖出哪怕踩空也无所谓——对总资产无损失；不抓住离场点=盈利100又回掉、伤本金。

## 二、六条离场纪律

1. **破20线**（核心立足点MA20，特指日线20线，非20小时/5分钟/20周/20月线）：
   - 20线上不做空拉回找卖点，20线上不做多反弹找卖点。
   - 5日线可走可不走——核心理论没提5日线；5日线与20线距离超**5%**才值得做波段（**3%**也行）。
2. **上涨常态前低破**（多空逆转三盏灯第二点）：
   - 此时往往已短线大幅获利回吐/浮亏；**越下不去手越要动**。
   - 不止损会形成头肩型/双头/三重头部形态。
3. **上升趋势线破**（过大斜率，多空逆转三盏灯第三点）：
   - 斜率过大不期待回测；破上升趋势线当天阴线较大跌幅也不给回测。
   - 例：10块开盘跌9%，回测需第二天涨9~10%阳包阴，太难。
4. **较大单阴**：一般没破50线但该走；较大单阴=破布林上轨+放量+RSI顶背离+CCI破正一把；不走第二天小心跳空低开。
5. **极高放量滞涨**：放量必须涨、量涨价涨才正常；放量不涨出十字星（尤其阴线十字星）小心变**黄昏星**；三K线盘趋势（带十字星做中继转折）。
6. **五穿二十**[?]：不赘述。
