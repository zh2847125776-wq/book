# 第1041课 期货：意外利好·冲高回落·避免过夜（20241210）

> 来源：B站UP主「量化技术分析」期货日评视频20241210
> **核心结论：会议利好消息带来跳空高开，但商品指数198.82关键压力没过去、绝大多数品种受高多与前高压制冲高回落；今天早盘唯一的选择是"卖不卖"，没拿过夜单就没有资格享受这段盈利，过夜风险永远要放在第一位。**

## 一、盘面背景：利好跳空与"提防冲高回落"

- 昨天（12月9日）受会议消息影响，新华富时A50上涨，昨天那根阳线涨得比较多，有十字星、有休息，很正常。
- 老师今天早上强调的主基调：**"不论是估值期货还是商品，主要我们提防的就是冲高回落。"** 这个问题昨晚特别直播里已经讲过——"如果是估值期货昨天晚上没做，今儿早上一追，你可能就容易被弄住"。
- 商品期货昨晚有相应波动。指数方面，老师给的关键压力位是**198.82**，"它没过去"，昨晚跳在这个高点上面来了一根阳线，本以为单边行情要来了。
- 但好的一点是**60MA获得验证了**，前面那个地点没去测试，"这总归是好情况"。老师给的正向推演：明天来个上返测试，后天再突破、夜行。所以这根阳线虽然短线被198.82压制，但"不是说肯定压制就能成功，完全百分百过不去之类的，你不用存在这种想法"。
- 老师的流派定位：**"咱们流派信奉的是技术分析包含一切，价格分析包含一切。"**

【老师点评/批判】前提：关键压力198.82与60MA同时存在，压力没破但支撑获得验证。反例：不能因为压力没破就断言百分百过不去——压力被突破本身也是技术分析的一部分。盈亏比：这类跳空高开日，追多的止损位被跳空拉远，盈亏比天然变差，所以才有"提防冲高回落"的基调。

## 二、过夜风险：老师反复强调的第一纪律

- **"这个期货过夜风险还是大。"** 就算是低杠杆，"它也怎么也得两三倍的杠杆"，高开受不了；五倍杠杆高开、涨2%，"你一个板就没有了"。
- 老师举自己的教训：之前做股指期货碰着雄安新区的事情，"给我搞得灰头土脸，那就是这个问题"。
- 所以今天的操作基调是：既然有高开往上冲的意思，**"我们肯定就不能做空咯，那找机会做多咯，空单要谨慎，你别去猜顶去啊"**。
- 对行情性质，老师只给盘感不给预判：此时此刻什么都不知道，"因为这个消息影响，市场怎么解读，你没法去那么精准的去预判"；但从个人角度讲，"我认为这是一波至少类似924的行情"，能不能实现只能用时间说话。
- 最关键的总结：**"今儿早上起来挣钱的人，都是拿着过夜单的人；你没有拿着过夜单，你就没有资格享受这点盈利，你一定要认清楚这个现实，否则的话也非常容易亏损。"**

【老师点评/批判】前提：期货杠杆下过夜等于承担跳空风险，方向对了收益、错了就是板。反例：老师自己股指期货遇上突发消息被打得灰头土脸，说明这不是理论风险。盈亏比：过夜单的成本是承担隔夜跳空，收益是今天早盘的这段利润——没底仓就不该去追这份利润。

## 三、商品品种逐一复盘

### 铝

- 昨晚也是涨的，20穿60多头交叉、关后整理的情况没有改变。
- 想做多只有60分钟能提供支持；从5分钟看"他也是刚刚穿透"，现在9点03分，所以应该是做多的。**但问题是止损在哪里？**
- 止损取点的推演：一般道理上止损应取这个点，"这个点既是高多，又是上涨常态前高"（老师提醒：老说一二三号，很多同学把常态就给忘了）；取跳空缺口也可以，"航行向着跳空缺口方向运行嘛，跳空缺口去见下限也可以"，但实际上这个点"使不上"，量一量就知道这个点很高。
- 具体测量：0.53也行，但另一个更近一点是0.2。所以从穿透角度讲，铝的高多低多现在都是冲上的，应该是做多，然后高多漏了、前高漏了就止损；60分钟周期也算支持，又有跳空缺口又站在多空线上。
- 但**日线上确实有问题**，在关口整理的结构上走，"所以说实际上这笔单子并不是特别好"。

【老师点评/批判】前提：多周期同向＋跳空缺口方向一致才成立。反例：日线仍在关口整理，结构没走完。盈亏比：止损空间0.2%尚可、0.53%偏大，加上日线拖累，属"能做但不特别好的单子"。

### 沪铅（转写作"签"）

- 老师延续昨天的判断："你签你要是做空又不行"——做空首先得获得至少日线图或60分钟图一个图形的支持。
- 昨天它正好坐在60分钟周期多空线上、坐在高多上，日线图上的5M也没漏、5M也没向下，"所以说你在5分钟周期就不适合昨天去做空的"，高多提供了支撑。
- 另外它有一个上行的通道，"你叫他上飘旗形也可以"，所以做多图肯定有点障碍，**"这个我们可以先放一放"**。

【老师点评/批判】前提：空单必须先有日线或60分钟的图形支持，5分钟单周期信号不够。反例：昨天的5分钟做空信号被60分钟高多支撑证伪。盈亏比：上飘旗形＋通道内的位置做多没有清晰止损，放一放比硬做划算。

### 焦煤

- 涨起来了。之前企图去做SFP但没有触发，昨晚直接高开，"你就可能也就做不到，没有拿不到这个单子"。
- 现在此时此刻正好顶在高多上，"那肯定也不行"，去找那种刚刚有机会的品种。

【老师点评/批判】前提：SFP需要触发条件。反例：昨晚直接高开，条件永远没出现——没做就是没做。盈亏比：顶在高多上的位置做空，止损就是高多上方，但方向与消息面相反，风险不对称。

### 铁矿石

- 也不太行了，也高了。回看它在这个地方尝试一次，失败了，高多漏了止损；尝试第二次，第二次就成功了。
- 老师借此重申磨损问题：**"这个磨损啊，不可避免。"** 有师兄开发了以APL为骨架的组合策略，发愁APL策略碰到磨损区域解决不了。老师的回答是：**"这磨损你要是不硬扛，你总想的是把磨损摘出去——我不做，形成单边行情我做的话，那你单边行情起点你买不到，那你就错过了，那最后导致回撤更高，也不好。所以说你就得在这个磨损的过程中，你去硬扛才行。"**
- 硬扛到最后向相反方向运行了怎么办？股票就没招了，"你可能就是扛了四五次都止损了，那你都挣不着钱"；但**对于期货来讲是非常灵活的**——"你扛了半天，它向下走了，你做空就完事了"。
- 真要是在形态结构内不开单、在买区不开单，突破的时候做不上（像今天这样），"那你就就不做了，只能是认了"。

【老师点评/批判】前提：趋势策略的利润来自磨损期里的持有，不是靠躲磨损。反例：想把磨损完全摘出去，就会错过单边行情起点，反而使回撤更高。盈亏比：期货的双向灵活性（向下走就反手做空）是硬扛磨损的兜底，股票没有这个兜底。

### 中长线与5M的取舍

- 上上个月做的是当日回转，这个月主要做的是中长线。**"对于期货来讲，日线图就算长线了。"**
- 做中长线怎么讲？**"那5M还在乎吗？就不在乎了，我们眼里已经没有5M了，我们眼里只有高多了。"** 昨天以玉米为例强调过好多次。
- 做空单就是在低多下面持有空单，站上去把它平了，再跌下来的时候再把它捞回来，直到低多拐头为止；做多单回测就接着做多单加仓。
- 玉米昨天收盘时低多漏了没漏？没漏就拿着——"你这是顺势交易，你怕什么呢，又有盈利"。

【老师点评/批判】前提：做中长线必须放弃5分钟噪音，只盯高多低多。反例：手里做着日线级别的单子却盯着5M来回翻转，磨损成本翻倍。盈亏比：顺势持仓＋已有盈利＝拿得住的根本。

### 螺纹钢（转写作"罗如刚/罗士刚刚"）

- "罗如刚一直跟你讲啊，有大行情"——但不知道它能开会出消息。之前画的价格压力带"多准呢"，回头看也是准的，"但是实际上你做不到"。
- 老师点出形态结构内部开单的真正价值：**"图的就是它高开的时候、走了的时候，你手上有底仓。"** 昨天盘中直接讲"今天是最好的加仓点"，当时直播时并不知道有这个消息；"昨天你要是不加仓，今儿早上又高开，就没你什么事了，不论是股票还是期货"。
- 现在只能认："油你就拿着吧，没有就跟你没关系了。"

【老师点评/批判】前提：消息不可预知，只能靠结构内的底仓承接跳空。反例：等消息确认再动手，高开已经把利润送完。盈亏比：底仓＝跳空日的期权，没有底仓就没有参与资格。

## 四、股指期货：早盘不追与市价单的止损算法

- 指数方面老师希望它能重复924的行情（924当时是在这里选的股）。老师认为这波行情的基础比924还好：924当时是空头排列、大周期也不好看，924的任务是突破，国庆节以后的行情是回撤；"现在如果能来一个放量起爆K线的话，实际上就比924当时环境好很多"。
- 但就是怕冲高回落：**"你今儿早上来，你就追就容易出问题。"** 做股指期货的同学来了就追其实可以考虑，但做指数ETF和做个股的都不行，"因为你不是T加0"。
- 以沪深300为例，老师特别不建议早盘追。但承认有这种做法，并给出了完整的操作与止盈方案：
  1. 如果跳空高开很多，开盘看集合竞价结束是多少，**挂市价单保证成交**——"你不能挂现价单，也不能挂对手的，你就得挂市价单，保证成交"。
  2. 你的成交价可能就在第一个K线里（基本上不会有下影线），那么**止损就放在这里**，止损空间就是这么多。
  3. 止盈：成本不够低的话，等它往上冲的时候，**第一个阴线（5分钟K线收K）减一半**；"这个下影线戳破止损"就止损。
  4. 5MA需要5个K线、25分钟才能追上来：9点半开盘，**9点55分5MA才起作用**。所以"你冒着风险，你头上顶的这把刀，就是9.55分5MA生效这把刀"；9.55以后5MA漏了，**清另外一半**。
  - 老师评价：**"你要是做估值期货的话，这样是可以的，但是风险极大，你成本还是高。"**
- A50的表现：今早集合竞价开盘就直接兑现昨天4.66的涨幅加隔夜0.48的涨幅，5个点，"来了冲高回落就很麻烦"。所以**"我特别强烈建议大家早盘不要追"**。
- 冲高回落之后的应对：如果今天是冲高回落，其实还是有机会的——红柱会放大一个、两个、三个，然后缩短缩短缩短，然后再放大一个（三重周期），等它调完这一下，"我们还能这个回马枪再去做"，但到时候听指令。
- 今天早上的选择只有一个：**"首先跟买入没有任何关系，你的选择就只有一个，到底卖不卖……你想好啊，现在就得想。"**
- 集合竞价实况（转述）：上证指数集合竞价是个二点多，"有一说一不多啊，比预想的要低"；深圳成指三个点，创业板指数直接高开五个点（五点对应2368，"也没有多少"——因为外周还取在那儿，密度高，"你觉得不高呢，你这么打开就高了"）。

【老师点评/批判】前提：市价单＋第一根K线内成交，止损距离才可控；5MA在开盘后25分钟才有意义。反例：早盘跳空高开直接挂现价单或对手价，成交价滑高，止损被动拉大。盈亏比：这套方案用"第一个阴线减半＋5MA漏了清仓"锁住跳空利润，但老师明确说"风险极大、成本还是高"，属于专业选手的替代方案而非推荐做法。

## 五、日评提炼：可复用方法与纪律

1. **消息面高开先提防冲高回落**，不预设行情性质；"技术分析包含一切"，压力位198.82没破就先按压制处理，但也别当成百分百过不去。
2. **过夜风险是期货第一风险**：低杠杆也两三倍，五倍杠杆高开2%就是一个板；方向对了的过夜单才配享受跳空利润。
3. **早盘不追**：跳空高开追进去容易被弄住；要做也得等触发（沥青：站上5MA、5MA向上再做多）。
4. **跳高必拉回**：昨晚跳高的品种都受高多、前高压制，"你不等拉回的话，你就容易出问题"。
5. **中长线只看高多低多**：日线在期货里就算长线，做中长线就"眼里没有5M了"；空单在低多下面持有，站上平、跌回接，直到低多拐头。
6. **磨损必须硬扛**：想摘掉磨损就会错过单边行情起点，导致回撤更高；期货的优势是反向走可以反手做空。
7. **形态结构内部开单的价值在于底仓**：跳空日有底仓才有参与资格，没底仓就没你什么事。
8. **止损取点优先级**：高多／上涨常态前高／跳空缺口下限都可以，但要量距离——0.2%可用、0.53%偏高；止损取不到就放一放。
