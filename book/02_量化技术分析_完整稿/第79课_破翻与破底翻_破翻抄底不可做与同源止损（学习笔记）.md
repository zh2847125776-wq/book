# 第79课 破翻与破底翻：破翻抄底不可做，突破须同源止损

> 来源：蓝色视频·优先级四《破翻、破底翻》（答疑：纠正一张混用多种结构的错误示意图）。
> 一句话结论：**破翻=逆势抄底、下降趋势还在会反复创新低，不论破翻还是破底翻都不要做、不挣这块钱；突破下降趋势线买进就必须用下降趋势线止损（同源），用前低止损的空间不可接受；破底翻之后均线粘合向上发散形成箱体/三加/假跌破站回才是你的机会。**

## 一、纠正错误示意图：止损必须同源

- 那张图把突破买进、回测买进、前低止损混到一起，是**绝对错误的**。
- 核心原则：**你因为什么买进，就要因为什么止损**：
  - 突破下降趋势线买 → 用下降趋势线止损；
  - 前低附近买（通威[?]式） → 用前低止损；
  - 破翻买 → 用破翻止损。
- 图里因"下降趋势线突破"买进却用"下降常态前低"止损 → 止损空间不可控（恐怕有6~7点）。
- **600050实例**：最高点最低点3点连下降趋势线，开盘价实体上限被压，价格**4.86**突破买进；收盘跌破才止损→**4.74**，差1毛6=**4%**；若跌破前低止损要到**4.48**才走=不可接受。
- 一般止损控制在**2%上下**；20线上1%买、盘中跌破2%，加起来**3%**止损。

## 二、三加为什么好用：20线必须上行

- 三加理论好用因为**20线是冲上的**：今天10块，明天高1分也比今天20线高1分。
- 均线**走平不好**：第二天止损时20线和昨天一样、无法提供支撑；均线**向下更不好**。
- 突破买进、回测买进、回测失败一把卖出 → 主要针对**箱体**。

## 三、破底翻的几种结构

- **下降常态前高**定义：两低一高过前高 → 飞盘即涨[?]（其实盘整更多）。
- 此前位置全是均线空头排列，要在这形成**均线粘合**，粘合完才能再起。
- 两低点差很多=**头肩底**（左肩右肩底）；两低点一样=**W底**（过前高、回测不破、再起买）。
- 收盘跌破价格、盘中跌破2%[?] → 当20线操作即可。
- 三重顶部结构：突破回测再起；倾斜颈线突破颈线、回测颈线、再起 → 与原始下降趋势线**无关**。
- 跌跌跌→创低→不再创低→再创高=头肩底（左底右肩），突破回测再起。
- **破底翻=突破的是颈线**。

## 四、破翻=抄底，不要做

- 破翻：某天创新低、低点比前低更低，但突破站上这个低点你就去买 → 这叫**抄底**，不好。
- 下降趋势还在会再创新低 → 一买就止损；又破低、又突破、又买、又创新低 → 反复止损。
- 下降常是五波（一二三四五）+B浪反弹+又五波，**没有穷尽**。
- 不论破翻还是破底翻都**不要做**，让它随便破，不挣这块钱。

## 五、正确做法：破底翻之后才介入

- 破底翻之后所有均线在此**粘合→向上发散** → 可形成箱体突破/三加/假跌破站回。
- 别在破翻路程上买——你不知道买的是1/2/3号点还是4号点。
- 破底翻之后是**均线系统工作盘（盘整）**，会亏时间。
