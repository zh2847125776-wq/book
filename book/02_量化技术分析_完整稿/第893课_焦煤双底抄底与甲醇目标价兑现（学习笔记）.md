## 一、商品指数：死叉共振阳线不改逢高放空

- 止损/止盈：本节未给具体点位，仍以"逢高放空"为总方向。

【老师点评/批判】前提是"5穿20死叉 + 共振阳线"只是反弹而非反转——老师强调这根阳线的性质要按陷阱考察。反例：若阳线放量突破前期压制，则逢高放空会被反打，所以判断依据是结构而非单根K线颜色。盈亏比上，反弹到位再空，比追空安全。

## 十四、可复用方法与纪律（日评提炼）

1. **结构距离检验**：低点之间距离太远就无法两两构成结构（焦煤前几次）；"没有累积跌幅的破翻"不准，不建议做。
2. **双底/支撑的叠加确认**：60MA关后整理上线（焦煤1543）反复获得支撑 + SFP + 双底 + 小周期均线粘合多头排列，多重共振才支撑一笔逆势抄底。
3. **逆势交易的仓位公式**：止损距离约2% → 头寸杠杆控制在3倍以内 → 最大亏损约5%–6%本金；老师原话"3倍以内杠杆都是可以接受的"。
4. **止损两方案权衡**：新低止损（1538/1530）亏得多但止错概率低；修正区下限止损亏得少但止错概率高——"就这么点区别"。
5. **同色K线不开单**：阴线不能做多，必须等异色K线或结构触发。
6. **主力合约查找法**：交易所→大商所→白色字（自选）→主连价格数字与某合约一致者即主力（铁矿755/756 → 2409）；换月缺口影响分析时切回主力合约。
7. **目标价兑现四选一**：到达目标价平全部 / 到达目标价平一半 / 站上50线平一半 / 站上50线平全部（甲醇2461对2439）。
8. **旗形整理失败判定**：漏一点立刻回到旗面内即失败，该止损止损；回到旗面内不做多，等突破上阶（玉米）。
9. **不逆势**：多头排列不做空（豆油、菜油、棕榈油），宁可晚止盈也不反手。
