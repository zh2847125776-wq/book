# 第460课 读书：股票魔法师Ⅱ——危险点交易与止损风险控制

> 来源：B站UP主"量化技术分析"读书课程《找准下一个买卖点》第04期（第460课），视频时长26分48秒；精读《股票魔法师Ⅱ：像冠军一样思考》第64-65页（PPT逐段讲解，标记[P]课件、[K]K线）。
> **一句话结论：风险要在买入时就控制——把止损设计成选股的一部分，尽可能接近"危险点"（止损位）低风险买进，做到亏小赚大、数学期望为正，而不是等卖出时才补救。**

## 一、再回头说说风险：止损设计是选股的一部分

【书中内容】
- "实际上我的止损设计是我选股过程中的重要组成部分。我可以把目光放在一只特定的股票上，但我可能不会买入，除非它能给我一个低风险的入场点。"
- "你不应该在卖出的时候控制风险，而应该在购买的时候就对其进行控制。当卖出的时候，你只需要承担亏损，但亏损应该是预先确定好的，它应该具有数学意义。"
- 量化原话："如果你的预期收益只有10%或15%，你会承受25%的亏损吗？如果你一直在购买收益比风险更大的股票，随着时间的推移，你将会变得很好。但是，如果你选择不利于自己的赔率，而冒更大的风险，那么你也许更应该去赌场。"

【老师点评/批判】
- 老师对两处原文均直接肯定："这句话说的真的非常好""这话说的很好 是吧"。
- 本课对应课件页码 64/273，屏幕角落同步显示老师账户收益 292.89%——仅为界面背景，不代表本课方法的收益承诺。
- 讲解环境为同花顺(9.60.20)与 SMA(20) 均线图，属背景信息。

## 二、在危险点附近交易：接近止损点的低风险买进

【书中内容】
- "为了控制风险，我想尽可能地在接近我的止损点时进行购买，这被称为接近'危险点'（见图2-1）的交易。"
- "区分正常行为和不正常行为，是你应该花时间学习的重要技能。根据下跌百分比设置止损点并买入突破的股票是一个好的开始，并能使你领先于大多数交易者。"
- "然而，真正伟大的交易者知道如何辨别危险的价格波动和正常的价格波动，并能在股票出现警告、交易开始变坏的时候关闭交易。"

【老师点评/批判】
- 老师概括："我们经常跟大家讲 最好的买点就是最好的卖点""下单的位置一般来说都不会没有风险""只要亏的时候亏的少 盈利的时候盈利的多 总和收益是正数 就已经很不错了"。
- 提示旧课衔接："我们还有一个 一个极限加仓的小的交易技巧 也给大家讲过"。
- 结合图2-1（[K]）拆解示例选点："自然回调 然后出现LPA进场 人家选的这个点真的非常好 转涨以后进场"。
- 对进场方式表态："当然你也可以选择在横盘区内下单 但是我们还是不推荐的 最好是突破买进回测买进 当然都得结合LPA E4K这些东西啊"。

## 三、止损位置的数学：波动空间 × 接近度 × 机会成本

【书中内容】（转录，00:04:00 段作者原文与讲解混排）
- "最佳止损位置应该设置在 使股价有足够的波动空间 但又足够接近危险点 并且数学意义上的风险 并不算太高的位置"
- "聪明的交易者都是根据技术指标 以及自己的算法设置止损"／"危险点附近的交易意味着低风险买入 知道你控制的是什么"。

【老师点评/批判】
- 用机会成本论证为何不在横盘区内埋伏："在这个危险区或者说叫横盘区的时候 你不知道他的突破方向是吧 如果突破方向下 你还要耗费很多时间 机会成本就不划算了"——即等待突破/回测确认再进，避免方向未明的时间损耗。
