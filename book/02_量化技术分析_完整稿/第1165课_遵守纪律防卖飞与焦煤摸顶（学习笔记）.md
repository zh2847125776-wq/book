# 第1165课 期货：遵守纪律防卖飞与焦煤摸顶（20250812）

> 来源：B站UP主「量化技术分析」期货日评视频20250812
> **核心结论：规则必须背书执行——氧化铝、纯碱、白银三笔"卖飞"都出在绿豆阳线上手动减仓；交易过程中只执行不思考，靠交易组合的总体盈利，而不是靠单笔完美。**

## 一、指数：贴近前高的常态思想

- **品种**：大盘指数。
- **结构判断**：老师原话"上面指数还在走强 已经贴近前高了 越是贴近前高越要注意 从咱们流派来讲 就是一个常态的思想"。与左边那个点交汇时有几种常态："左高右低呢 左右一样高呢 左低右高呢 还是无限往上涨呢"，"都是在和它左边这个点交汇交汇的时候 需要注意的点"。
- **订单操作**："目前来看的话 我们还是要集中力量做多 以开多单为主 所有的空单都要谨慎才行"。
- **止损/止盈**：未给点位。风险点是"这里有个极端情况 就是别产生SFP就行"；若"过两天这里产生了SFP 然后往下走的话 然后呢就会出现 0 0 雲波贝离（云波背离，转写存疑）情况了 是不是 那就就会跌下来了"。

【老师点评/批判】前提：指数仍在走强、贴近前高且未出SFP，常态思想下多头延续概率更高。反例：一旦在左侧交汇点产生SFP并向下，整体方向判断立刻反转，"一定要注意啊"。盈亏比：这是方向性判断而非单笔交易，"集中力量做多"的代价是"所有的空单都要谨慎"，即用放弃逆势单来换取顺势单的胜率。

## 二、黄金：横盘区里的空单尝试

- **品种**：黄金。
- **结构判断**："黄金的日线图还没有跌下来 黄金的日线图没有跌下来 五分钟倒是跌下来了"；当前状态是"空方穿透"，"目前是再次变绿的状态"。首次变绿时"还没有穿透"。
- **订单操作**："其实现在可以尝试一个空单"；今日上午9点55分出现订单机会，"应该是这个K线和这个K线都可以"，"到了下午就产生磨损了"。处理方式是"仓位减半 仓位接回 减半 接回 减半 接回"；"我们看今天晚上此时此刻又出现了新的空单机会啊"。
- **止损/止盈**：规则为"价格翻上绿豆减半 然后掉下来 接回一半 然后变红清空就完事了"；老师强调"这个黄金的单子值得尝试啊 失败了也不要紧 因为他亏贵的很少啊 现在离职业（止损）很近啊"。

【老师点评/批判】前提：黄金五分钟空方穿透、累计跌幅已多，且"每个品种都有自己的路要走"，可以顶着多头指数做空。反例："确实最近黄金 磨损特别多 特别不好做啊"，横盘区里"你就尝试好几回 老有磨损 老有挣不着钱"；老师给出退路——"你要是觉着顶着指数做逆势的订单不好 你可以别做黄金这个单子"。盈亏比：止损离得近（亏得少），"但如果一旦是这里订单 如果出现大单边 你就捞着了"，典型小止损博大单边。

## 三、白银：空单止盈与"结构清晰可先平一半"

- **品种**：白银。
- **结构判断**："这个我们昨天有讲是吧 这个倒是有开单机会"；目前"还是应该等空单 毕竟没有穿透 没有多单的机会 等一等 穿透以后再做多 穿不透 咱就等空的"。
- **订单操作**：今日上午9点05分"第一个K就仓位减半了 是吧 应该是这个K"，"然后到了四个K以后 那就空单全部清空 清空以后立刻就上涨啊"。
- **止损/止盈**："这个止盈做的还是不错的啊 这个回撤也比较小"。理想情形是"在底位横盘一段时间 用以盘待涨的形式 让这个副管理率（负乖离率）修复下来 然后上去的话 咱们回撤就非常小了 就挺好了"。

【老师点评/批判】前提：昨日空单已有浮盈，五分钟产生"标准SFP 一色K"，且"又经历了一段时间的单面行情 副管理率又极大 空方有平仓获利 落袋为安的需求"。反例：没有足够大的结构、没有落袋需求就提前平，就是被洗；老师明确"你要是没有那个决心 没有那个毅力全凭的话 那就来上一半 两头赌"。盈亏比：趋势单最怕"在这里触发止盈 亏损一般都比较多 回撤比较多"；平一半是折中方案，兼顾回撤与趋势。

## 四、铜与铝：逆势单的取舍

- **品种**：铜（转写作"同"）、铝（转写作"吕"）。
- **结构判断**：铜"应该是有一个非常好的多单机会 这个昨天咱们直播时候有讲"；铝"这里这几次发的这个空单机会多单机会都是逆势的"。
- **订单操作**：铜——"开盘掉下来以后 我那应该是这个可以先减半 阳线阳线阴线减半 是吧 因为是多单嘛"，剩下的一半"是阳线阳线无色阳线阳线清空"；昨日有同学手里的铜单"可能就没大做好"，老师要求"具体哪个可以像这个逐K分析啊 一定要做好啊"。铝——"下不了单 下不了单做别的金属系有别的可做"。
- **止损/止盈**：按一色K规则执行（阳线阳线阴线减半、无色阳线阳线清空）。

【老师点评/批判】前提：铜多单是昨日直播已讲的机会，逐K分析可精确定位减半/清空位置。反例："逐K分析做不好 你就不能买卖的特别精准 然后下单的位置就不会特别好"；铝的逆势单"规则要背书 你会放空吗 我觉得你肯定不会放空 逆势交易是不是"，直接放弃即可。盈亏比：铜多单按规则兑现；铝逆势单胜率低，不做不亏。

## 五、氧化铝：卖飞案例（本课重点）

- **品种**：氧化铝。
- **结构判断**：8月11日晚直播"给到了一个多头订单下箭头了"，"凡是下箭头的 不论是股票还是期货 就是你可以copy 你可以抄作业的意思"。逐K复盘："变红的时候能做多吗 做不了""空旷穿透 一色K能做吧 不能做空旷穿透 一色K一色K啊"，"所以说实际上最早的交易机会是这儿 但是当时不在直播时间"。
- **订单操作**：昨日开盘直播后"就碰到了新的开单机会 啊 因为他还是维持多方穿透状态"；今日早上9点05分出现"可以先先生"的机会，有同学"给卖飞了"，"就是因为盘中刺破的多了一点"。老师指出正确做法是"退一步减收可以守在红豆下面 规则是什么样 仓位减半 谁让你全抛了"，"结果好像就是像给这种意志不坚定……的同学一记这个响亮的回答"；"第二个可以先突然就拉起来 你再也就接不回来了"。
- **止损/止盈**：箭头下的多个开单点"只要你开了就没问题"；变绿清空。另外"这个氧化铝也有sfp 你要不要减一半呢 你自己合计"。

【老师点评/批判】前提：箭头=可抄作业的订单信号，且流派"已经把高多低多距离远近调餐了"，不再判断逆势，"你就无脑做就行了"。反例："有没有那种一个红豆 然后一个超级大银线跌起来 第二个可以先继续跌的 有 没办法 你捏着鼻子 你就得忍了"；老师自曝"六月份多金贵 二连贵 每次都亏""应该是三连贵 还有一笔多单是亏的"，"后来不是都赚回来了吗"。盈亏比："在一大堆交易组合中 一个小圈代表一笔交易"，单笔可能爆亏，但在"一百比一千比"的组合中总体盈利，"千万不能因噎废食"。

## 六、镍与焦煤：摸顶交易计划（1313/1325）

- **品种**：镍（转写作"念"）、焦煤。
- **结构判断**：焦煤"还记得咱们给他制定的交易计划 你还记得吗 拉回的时候 我们当时讲的就是 还有新高 因为他没有结构嘛 他要是这么直上直下 这不成微型反转了吗"，"今天创高了"；因此"我们现在就不能用TRP去做了啊 你就得考虑要去摸顶了"。"焦煤现在的位置非常高啊"。
- **订单操作**：镍——"今晚上没有交易机会了""已经上去了""那这个应该要考虑做多了"；近期两笔多头订单，第一笔"没触发""绿豆牛（绿豆绿）不做空"，第二笔"这里进场这里减半 然后剩下那半没清空"（罕见案例：出绿豆的K线"它全是阳线"，不必清），"然后他就又变红了……那人家能接回一半 那你应该是就是买入信号了"。焦煤——"收K守在1313下方下空单 然后1325上方止损"。
- **止损/止盈**：焦煤若"等这个公破（功破/共破，转写存疑）再下单的话 止损太高了 是吧 一共1290止损35太高 受不了"；改用小周期摸顶后，外轴比例尺"有0.95啊 就接近我们这个五分钟周期止损 绝对值得极限了啊 极限是1%嘛"。

【老师点评/批判】前提：焦煤无结构、创新高后进入摸顶阶段，"之前咱们做那个多周期穿透的时候老摸顶"。反例："摸顶胜率是不高的啊"、"毕竟是逆势交易 胜率低好不好啊"，老师明确"这是一个高风险的交易机会""你愿意掺和你就摸一下啊 你不愿意插火那就算啊"。盈亏比："摸顶挣的又多"——35点止损、0.95%接近1%极限，小止损博大跌，但胜率低，"要不要舔一舔你自己合计啊"。

## 七、黑色系：螺纹钢、热卷、铁矿石多单持有

## 八、碳酸锂：涨停板跌停板战法

- **品种**：碳酸锂。
- **结构判断**：今日早盘"起来就有一个 涨停板跌停板战法"，"他自始至终就没有触发离场信号 是吧 包括下午有一个超级大拉升啊 你也不会跑啊"。

## 十二、可复用方法与纪律

1. **箭头=可抄作业**："凡是下箭头的 不论是股票还是期货 就是你可以copy 你可以抄作业的意思"；但"我直播给你分享的订单是我们做的练习 而不是让你去带单去做……你自己得模仿的去练动动你的小脑袋"。
2. **一色K/绿豆规则**："价格翻上绿豆减半 然后掉下来 接回一半 然后变红清空就完事了"；"绿豆二绿豆三好家伙 绿豆三个全是阳线 你该怎么办 应该继续持有啊 然后变红了再把它接回啊"。
3. **只有买进和卖出**："咱们流派没有加仓 接回补仓这些 他就只有买进和卖出 这两个概念"；50%仓位时"不能买进 而是接回50%仓位"，变红即买入信号。
4. **TRP参数**："TRP是六十做股票看日线换二十做期货五分钟看六十啊"。
5. **交易中不思考**："你的想法都用在理解交易架构执行交易纪律上 在交易的过程中别想 你想的越多越出问题"；"按照规则来就行 别思考 一思考就出问题"。
6. **接受单笔爆亏**："在一大堆交易组合中 一个小圈代表一笔交易"，"他肯定有这么一笔交易会造成你遵守纪律了 遵守交易架构了 但是产生爆亏了 但是呢 在这个庞大的交易组合中可能是一百比一千比中 你是总体盈利的"；"千万不能因噎废食"，"下次你遵守纪律了 也许会亏 但是也要遵守纪律啊"。
7. **逆势单的定位**："摸顶胜率是不高的啊 摸顶挣的又多"，"毕竟是逆势交易 胜率低 风险高赚的多"——不做不亏。
8. **止盈取舍**：看到足够大且清晰的结构 + 单面行情 + 负乖离极大 + 空方有落袋需求时，可以平一部分；没有毅力全平就"来上一半 两头赌"。
9. **变绿风险**："不要等变绿了啊 变绿的风险太高了"。
10. **逐K分析**："逐K分析做不好 你就不能买卖的特别精准 然后下单的位置就不会特别好"。

【老师点评/批判】前提：以上均为"交易架构+纪律"层面的规则，前提是信号本身成立（箭头/穿透/一色K）。反例：老师自曝6月"三连贵"、还有一笔多单亏损，"后来不是都赚回来了吗"——严格遵守规则也可能单笔亏。盈亏比：纪律的价值在组合期望，不在单笔胜率；"做交易别多想"是这套系统的核心执行原则。
