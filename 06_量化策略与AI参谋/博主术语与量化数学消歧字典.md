## 一、 顶层环境与均线体系消歧

### 1. 均线系统口语纠偏与标准化参数
- **术语口误纠偏**：
  - 语音识别中高频出现的 **“五十线”、“50线”**，在 90% 以上的技术讨论中经逐字证据与 OCR 交叉验证实为 **“5日均线 (MA5)”** 或 **“50日均线 (MA50/MA60)”**（需依据上下文判别，日评超短线 5 穿 20 场景中 100% 为 MA5）。
  - **核心均线参数**：超短线 `MA5`、短线 `MA10`、生命线/波段基准 `MA20`、中长线多空分水岭 `MA60`。
- **均线多头排列 (Bullish Alignment)**：
  - 口语：“均线多头排列，顺风顺水”。
  - **数学公式**：
    $$MA_5(t) > MA_{10}(t) > MA_{20}(t) > MA_{60}(t)$$
    且 $MA_{20}(t) - MA_{20}(t-1) > 0$（20日线斜率必须向上）。
- **均线空头排列 (Bearish Alignment)**：
  - 口语：“均线盖头，空头排列不抄底”。
  - **数学公式**：
    $$MA_5(t) < MA_{10}(t) < MA_{20}(t) < MA_{60}(t)$$
    且 $MA_{20}(t) - MA_{20}(t-1) < 0$。

### 2. “站上 / 跌破 20 日线”的数学确认标准（解决假突破）
- 口语：“今天突破站上20日线了，能不能进？”
- 博主标准铁律（见 S-1451、K-3676）：**下倾均线第一天突破不进场，实行“三级确认”**。
  - **一级确认（激进/试盘）**：当天收盘价 $Close(t) > MA_{20}(t)$，且上影线比例 $< 30\%$（实体有效穿透）。仅限 1 成底仓试错，硬止损设为 $MA_{20}(t) - 0.2 	imes ATR_{14}$。
  - **二级确认（稳健/上反回测）**：突破次日收阴线回踩，且最低价 $Low(t+1) \ge MA_{20}(t+1) - 0.2 	imes ATR_{14}$，且成交量 $Volume(t+1) < Volume(t)$（缩量守线）。
  - **三级确认（保守/右侧成立）**：连续 3 个交易日收盘价均高于 $MA_{20}$，且伴随 $MA_5$ 向上穿越 $MA_{20}$（5穿20金叉）。
- **有效跌破判定**：收盘价 $Close(t) < MA_{20}(t) 	imes (1 - 	ext{余量阈值})$，或连续两日收盘价无法收复 $MA_{20}$。

## 二、 形态结构学与破翻（2B）体系消歧

### 1. 破翻与破底翻架构（一二三号位数学定义）
- 口语：“一号位止跌、二号位破翻、三号位破底翻”（详见 S-1450、K-0053、K-0111）。
- **数学建模**：
  - 设在考察窗口 $N$（日线通常取 20~60 天）内：
    - **一号位（波段极限低点）**：
      $$P_1 = \min_{t-N \le 	au \le t} Low(	au)，\quad 	ext{其发生时间为 } t_1$$
    - **二号位（左侧下降常态前低 / 颈线 1）**：
      在一号位左侧的最近一个显著波谷低点：
      $$P_2 = Low(	au_{	ext{trough}})，\quad 	ext{满足 } 	au_{	ext{trough}} < t_1 	ext{ 且 } P_2 > P_1$$
    - **三号位（反弹常态前高 / 破底翻确认颈线 2）**：
      在一号位与二号位之间的反弹波峰最高点：
      $$P_3 = \max_{t_1 \le 	au \le t} High(	au)$$
  - **状态机判定**：
    - **破翻触发（2B 假跌破收复，左侧轻仓点）**：
      历史出现 $Low(t_1) < P_2$（跌破前低），当前 $Close(t) > P_2$（重新站回二号位颈线之上）。
    - **破底翻触发（右侧反转确立，标准加仓点）**：
      $Close(t) > P_3$（有效向上突破三号位前高）。

### 2. 止损余量缓冲机制（Margin of Error）
- 口语：“止损要在关键价外留出余量，防止被毛刺和杂波洗出去”（见 K-0111、S-0349）。
- **死板等号的缺陷**：若止损刚好挂在支撑价 $20.00$，主力资金经常打到 $19.98$ 瞬间拉起，导致踏空。
- **数学公式**：
  $$	ext{动态止损价 } StopPrice = 	ext{支撑位价格 } P_{	ext{support}} - \Delta$$
  其中余量偏移 $\Delta$ 统一采用 ATR 动态自适应算法：
  $$\Delta = \max(0.02, \; 0.20 	imes ATR_{14})$$
  （对股票价格，最小保证 2 分钱缓冲；大波动品种动态取 0.2 倍 ATR）。

## 三、 量价与动量指标消歧

### 1. “缩量回踩到位”的量化定义
- 口语：“回踩必须是无量回踩，放量下杀不能接”。
- **数学指标**：
  - 今日成交量占比：$Ratio_V = rac{Volume(t)}{MA_{Vol5}(t)}$
  - **缩量合格判定**：
    1. $Ratio_V \le 0.70$（今日成交量显著低于 5 日均量的 70%）；
    2. 今日阴线成交量 $\le$ 过去 10 天内最大阳线成交量的 $50\%$；
    3. 盘中波动幅度振幅 $Amplitude = rac{High(t) - Low(t)}{Close(t-1)} < 1.5 	imes 	ext{平均振幅}$（波动收敛，无恐慌性抛盘）。

### 2. DIF 零轴极简多空滤网（S-1452）
- 口语：“DIF 在零轴下，无论怎么涨都是反弹，坚决不参与”。
- **数学条件**：
  - 多方安全区：$DIF(t) > 0.000$。
  - 绝对禁区：$DIF(t) \le 0.000$（严格执行空仓或只减不加，禁止开立新多头）。

### 3. 交叉共振买卖点（5 穿 20 回测阴线，K-0004）
- 口语：“5 穿 20 当天收阴拉回买，死叉当天收阳拉起卖”。
- **数学触发条件**：
  - 均线金叉触发：$MA_5(t) > MA_{20}(t)$ 且 $MA_5(t-1) \le MA_{20}(t-1)$；
  - 阴线回拉配合：当日收盘价低于开盘价 $Close(t) < Open(t)$；
  - 结构要求：$MA_{20}$ 自身处于走平或向上拐头状态（禁止在向下大幅发散的 20 日线下接刀）。
