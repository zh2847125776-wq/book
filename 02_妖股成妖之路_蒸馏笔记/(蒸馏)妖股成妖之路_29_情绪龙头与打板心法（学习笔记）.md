# 妖股成妖之路·蒸馏29：情绪·龙头·打板心法（第571-600章）

> 来源：《(增强版)妖股成妖之路_29.md》第571-576章（源文件前150行）。
> **核心结论：投机的本质是赚钱效应（情绪）的延续与扩散——紧抓核心/龙头、做确定性的打板，跟随情绪而非追涨杀跌。**

## 一、行情脉络：散户心态 → 龙头战法 → 打板心法 → 盘面实战

本单元前150行覆盖第571-576章，内容呈"理念宣导 → 名家语录 → 实战盘面"的递进结构。

- **第571章**：借张先生的追涨杀跌故事，引出散户的共同败因——看到别人翻倍晒单，焦虑中卖掉"沉睡"的持仓去追热门股，反复割肉、越亏越多。
- **第572章**：陈小群心法，确立"情绪 + 龙头"两条主线。
- **第573-574章**：游资"涅盘重升"的五大/心法，把"打板"与"做核心"上升为可复用的操作纪律。
- **第575章**：转入具体盘面（周五指数低迷 + AI硬件/铜缆板块），从抽象心法落到个股案例（沃尔核材、鑫科材料、宝胜股份、华脉科技等）。
- **第576章**（起）：转入"修心/情绪管理"的软性说教，与本书其余单元的轮回结构一致。

**脉络小结**：这是一组"方法宣讲型"单元，先立"情绪与龙头"的大纲，再用游资语录把它操作化，最后用一日盘面做验证。后续（576章中段起）预期为同质化的日评与心法复述。

## 二、可复用方法论一：打板与做核心（涅盘重升心法）

**量化原话（第573章）**：
- "打板……核心在于确定性和效率。在好行情中，如果不打板，很容易错失机会；而在烂行情中，不打板则容易犯错。"
- "个股而言，市场地位最重要。"
- "下降趋势不做，只做主升。"——主升趋势容错率高，下降趋势容错率低。
- "紧抓核心，做打板就行。"

**四大亏钱情形的排查清单（作者归纳，第573章）**：
1. 最有赚钱效应板块的**对立面**——看似有机会实则风险大；
2. **末期机会**——收益大但做错代价也大，须追求确定性；
3. **非主流冷门**——自以为低风险而重仓，情绪转差时反致大亏；
4. **系统性风险 + 补跌**——情绪差时小转折点不能逆情绪，要从收益风险比与确定性考虑。

【老师点评/批判】这套"打板+做核心+只做主升"的心法，本质是**趋势跟随 + 盈亏比优先**的纪律，逻辑自洽。但书中未给出任何**可证伪的入场/止损量化参数**（何谓"确定性"、"主升"如何界定边界均由盘感兜底）。它是一套"心法"而非"系统"，散户照搬极易因缺乏出场规则而把"做核心"做成了"高位站岗"。补跌/系统性风险的条目是对的提醒，但同样没有落地为仓位硬约束。

## 三、可复用方法论二：龙头与情绪的判定标准（陈小群心法）

**量化原话（第572章）**：
- "纯做龙头股是关键。"
- "高标就是你最好的朋友。"但——"不要轻易尝试抄底"。
- "能带动板块起涨的龙头才叫龙头，龙头上板要能带来跟风的赚钱效应。"（龙头的**定义**：自身强 + 能带板块、带跟风赚钱效应）
- "市场总龙头熄火，但题材未到退潮期，新龙坚挺走出，做新龙。"（龙头更替的**切换信号**）
- "分仓，可控制回撤。"
- "不干杂毛，做龙头或者潜在龙头，没地位不想做。"

**反包判势（第572章）**：总龙头首次下跌后若能迅速"反包"，行情仍可能延续；反之预示调整将至。

【老师点评/批判】陈小群这段的**龙头定义**（"能带动板块起涨、上板能带跟风赚钱效应"）是本单元最有含金量的可操作标准，给出了一条可观察的判据：龙头不是涨幅排名，而是**对板块的带动力**。但"市场地位最重要""高标是最好的朋友"仍是事后归因色彩浓厚的描述，事前如何识别"潜在龙头""新龙"，书中没有可执行的方法，只有"盯盘中观察"这类难以传授的隐性知识。

## 四、可复用方法论三：情绪分层的观察框架（涅盘重升）

**量化原话（第574章）**：投机 / 市场 / 板块 / 整体市场 / 整体投机——多层级情绪需分别观察，并注意其强弱**对比**：
- "整体投机情绪较强时，即使高位龙头炸板，市场仍偏向强势" → 低位超强前排股 + 高板块情绪点成为资金目标；
- "整体板块情绪强" → 龙头股表现关键（例：5月24日海汽集团带动板块上涨）；
- "整体投机情绪极强时，不停地做低位超强前排和高板块情绪点"；
- "有板块等板块走强，无板块但有妖则低位前排或者做妖"。

**情绪 vs 个股定位（第574章）**：3月20日盘龙药业（强势股分歧厉害 → 低风险走强点上仓位）；贵州燃气一批的**超跌反弹**被当作"思维模式差异"的范例。

【老师点评/批判】"情绪分层 + 强弱对比 + 资金轮动"的框架是有结构的，比单纯打板更细：它承认不同层级情绪可以背离（投机强/板块弱 → 轮动）。这是本单元的进阶点。但所有案例（海汽集团、盘龙药业、贵州燃气）都是**事后命名**的印证，未提供当时可得的、可重复的前置信号；"情绪强/弱"的量级本身没有代理指标，仍是经验性判断。

## 五、可复用方法论四：盘面实战的识别手法（第575章 AI硬件/铜缆）

**量化原话 / 个股案例（第575章）**：
- **趋势核心定位**："沃尔核材……硬件端最为核心的定位""日内承接稳健，在五日线之上，让人无法轻易看空"——以**承接 + 五日均线**作为趋势强弱的观测锚。
- **模仿/对标剧本**："鑫科材料……仿中百集团的剧本""宝胜股份……模仿2022年2月恒宝股份底部启动、暴力洗盘后的连板模式"——用**历史相似形态**推演个股路径。
- **预期差案例**：鑫科材料周四一字开口、场外资金来不及切入；周五中百集团给机会而鑫科材料"没有资金的青睐，走不了加速，只能按趋势看"——**预期差 + 资金是否愿意接**决定加速还是趋势。
- **活口判定**："宝胜股份……日内铜缆板块的连板活口。"活口股影响板块回流力度。
- **淘汰判例**：华脉科技周四首个上板、周五未开一字"不及预期，沦为炮灰"。
- **板块节奏**：AI硬件周四高潮、周五兑现分歧；"看好大盘就等于看好AI硬件"，板块高度决定其他细分轮动高度。

【老师点评/批判】这段是全书少见的**半结构化复盘**：承接+五日线、对标剧本、预期差、活口、分歧节奏，都是可复用的观察点，且有明确个股对应。但它仍以主观"剧本"推演为主，缺乏仓位与止损描述；"宝胜股份关乎整个板块回流""AI硬件高度决定其他细分轮动高度"是强因果断言，缺少论证，属于叙事美化。可采纳的是"五日线承接可持有、破位看空、不及预期即炮灰"这套**顺势汰弱**的朴素规则。
