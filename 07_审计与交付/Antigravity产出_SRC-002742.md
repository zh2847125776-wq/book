```markdown
# K-32466 基金经理选拔评价标准
> 来源：SRC-002742（读书_16聪明的投资者）· 证据 E-70399
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：投资基金的核心是选择具有长期稳定管理能力的高水平基金经理，重点考察其多年从业以来的平均年化收益率与回撤波动稳定性，而非追逐短期或单年收益冠军。

## 它解决什么问题
解决普通投资者在面对数千只公募基金时，容易陷入被短期排行榜榜首误导、盲目追逐激进风格冠军基金导致次年亏损的选基决策困境。

## 如何识别
1. 基金经理从业年限足够长，经历过多轮市场周期考验（证据 E-70399）。
2. 从业以来截至目前的长期平均年化收益率能够达到20%以上（证据 E-70399）。
3. 收益曲线平顺稳定，不出现极高幅度的剧烈波动（证据 E-70399）。
4. 排除上一年度收益排名第一的基金，避免选择投资风格过于激进的“买奖”选手（证据 E-70399）。
5. 优先考察该优秀基金经理名下管理的其他基金组合，同一经理旗下产品大概率维持较高水平（证据 E-70403）。
6. 不以管理费率高低（如零费率或极低管理费）作为核心选基依据，核心在于基金经理实际创造超额收益的能力（证据 E-70400）。

## 适用边界与失效
1. 适用范围限于主动权益类公募基金的选择与配置（证据 E-70399、E-70403）。
2. 失效条件：若市场整体进入牛市末期或大盘指数处于历史高位，即便选出优秀基金经理，系统性下跌也会拖累基金净值表现（证据 E-70402）；若基金经理风格发生漂移或老爱冒险追牛股，其稳定性将失效（证据 E-70404）。

## 与其他概念的关系
- 与 S-2913（公募基金择时选人配置法）：前提与核心选人模块，为配置策略提供具体的标的筛选标准。
- 与 K-32467（指数大势与基金表现关联规律）：互补关系，选人解决“买什么”，指数大势解决“何时买”，二者结合方能形成完整投资决策。
- 与 K-32469（业绩基金激进运作的累加风险陷阱）：互斥关系，本标准明确剔除短期拔高、风格激进的单年冠军业绩基金。
- 与 C-20067（2020年中国公募基金规模与收益率对比实证）：实证支撑关系，以创金合信工业周期股票A的基金经理李游（原转写“理由”）为例验证选人逻辑。

## 案例与证据
讲述者在2021年1月23日通过同花顺软件展示2020年公募基金榜单，近一年收益率达166%的创金合信工业周期股票A（代码005968），其基金经理李游（转写为“理由”）重仓三一重工、宁德时代、隆基股份、通威股份等行业牛股，验证了优秀基金经理的专业选股能力（证据 E-70403、E-70416）。
```

```markdown
# K-32467 指数大势与基金表现关联规律
> 来源：SRC-002742（读书_16聪明的投资者）· 证据 E-70402
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：机构专业人士的集中资金决定了股市平均水平走向，而股市平均水平走向从根本上决定了权益类基金的总体业绩表现，投资基金必须服从大盘指数牛熊大势。

## 它解决什么问题
解决投资者误以为买入绩优基金就可以完全免疫系统性风险、在指数处于历史高位时依然盲目追买基金导致被套亏损的择时错误。

## 如何识别
1. 专业机构投资者（如商业银行信托、投资顾问、共同基金等）掌管巨额资金，其资金合力主导了股市平均水平走向（证据 E-70401）。
2. 股市平均水平走向与基金总体结果存在决定性绑定：指数上涨则基金整体表现良好，指数下跌则基金整体表现较差（证据 E-70401、E-70402）。
3. 指数处于历史高位或大涨之后，属于系统性风险释放期，严禁盲目买入基金（证据 E-70402）。
4. 指数处于历史低位附近时，为布局投资基金的优质时间窗口（证据 E-70402、E-70409）。

## 适用边界与失效
1. 适用范围限于权益类公募基金（股票型、偏股混合型）的宏观仓位择时与入场时机把握（证据 E-70401、E-70402）。
2. 失效条件：在极少数极端结构性牛市中，部分高度集中于特定高景气专门领域（如白酒、新能源）的行业主题基金，可能在指数震荡甚至低迷时走出独立超额行情，但整体而言仍受大势约束（证据 E-70418）。

## 与其他概念的关系
- 与 S-2913（公募基金择时选人配置法）：前提环境过滤条件，作为策略启动或观望的首要宏观择时开关。
- 与 K-32466（基金经理选拔评价标准）：互补关系，本规律定择时，K-32466定标的。
- 与 K-32468（基金规模与业绩无规律脱钩）：补充关系，指出决定基金收益的核心外生变量是指数大势而非基金规模大小。
- 与 C-20067（2020年中国公募基金规模与收益率对比实证）：实操背景，2020年上证指数上涨13.87%、创业板指上涨64.96%的大势，为公募基金整体取得高收益提供了系统性基础。

## 案例与证据
讲述者在2021年1月23日分析指出，2020年大盘指数走强（创业板指涨幅显著），公募基金整体业绩优异；而2021年1月中旬仅一周时间散户人均亏损超10万，说明大势与环境对投资结果具有决定性影响；因此买基金必须结合技术分析，在指数历史低位买入，高位坚决不买（证据 E-70401、E-70402、E-70409）。
```

```markdown
# K-32468 基金规模与业绩无规律脱钩
> 来源：SRC-002742（读书_16聪明的投资者）· 证据 E-70407
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：公募基金的管理资产规模与实际收益率之间不存在必然的线性正相关或负相关关系，反驳格雷厄姆关于“规模较小是持续获得优异业绩必要因素”的传统观点。

## 它解决什么问题
解决投资者在选基时机械依据基金资产规模进行筛选，误以为“小规模基金必然好掉头、大基金必然业绩平庸”而错失优质大型基金的教条主义认知偏差。

## 如何识别
1. 格雷厄姆在书中提出传统观点，认为业绩优良的基金规模都不大（平均约6000万美元），据此断言规模较小是持续获得优异结果的必要因素（证据 E-70406）。
2. 讲述者通过实盘数据反驳该观点，指出公募基金收益率与实际盈利能力之间并不存在正比关系，没有任何正相关、负相关或规律性线性关系（证据 E-70407）。
3. 基金排行榜前列中，既有管理规模仅0.01亿（100万元）、0.28亿、0.46亿的小微基金，也有规模达2.33亿、12亿乃至100亿元的大型基金（证据 E-70417）。
4. 规模达100亿的大型基金在经历平稳期后同样能实现4-5年翻3倍的优异业绩，推翻了大基金必然业绩平庸的假设（证据 E-70408）。
5. 获得优异业绩的本质驱动力在于基金持仓的具体行业赛道（如白酒、新能源等专门领域），而非单纯由规模决定（证据 E-70418）。

## 适用边界与失效
1. 适用范围限于现代公募基金多层次市场与特定行业赛道型基金的规模分析（证据 E-70407、E-70418）。
2. 失效边界：在单一股票流动性受限或市场极端单边流动性枯竭时，超大规模基金在调仓冲击成本和个股持仓上限上仍可能受到被动约束（原文未明确量化边界）。

## 与其他概念的关系
- 与 K-32466（基金经理选拔评价标准）：补充关系，明确选基应聚焦基金经理个人能力与长期年化，无需将小规模设立为硬性准入门槛。
- 与 K-32469（业绩基金激进运作的累加风险陷阱）：对照关系，指出业绩陷阱源于激进冒险与资产质量操纵，而非单纯由基金规模大小决定。
- 与 C-20067（2020年中国公募基金规模与收益率对比实证）：直接实证关系，通过同花顺2020年基金规模从0.01亿到100亿的排行榜分布提供反例支持。

## 案例与证据
讲述者在2021年1月23日同花顺行情软件中查阅2020年公募基金榜单前十名，列举排名第一的基金规模为9.81亿，后续基金涵盖2.33亿、12亿、0.46亿、100亿、13亿、0.28亿以及0.01亿（100万元），明确指出100亿大基金同样跻身前列并在4-5年翻3倍，直接证伪了格雷厄姆的规模必要性断言（证据 E-70407、E-70408、E-70417）。
```

```markdown
# K-32469 业绩基金激进运作的累加风险陷阱
> 来源：SRC-002742（读书_16聪明的投资者）· 证据 E-70404
> 来源立场：书中作者观点
> 底本层级：仅增强稿可见

一句话定义：业绩基金为了在短期内追求远超市场平均水平的高额收益，必然导致投资组合风险大规模上升与累加，往往依赖热门股炒作或灰色会计操作制造虚幻利润，最终将遭受灾难性的持续损失。

## 它解决什么问题
解决投资者容易被公募基金单年暴涨（如84%至300%）的狂热表现吸引，盲目追高买入激进型业绩基金，最终在随后的估值崩塌和熊市中遭遇本金永久性损失的风险识别问题。

## 如何识别
1. 基金管理者过度追求短期拔高超越平均水平或道琼斯指数，投资曲线不平顺、频繁冒险追牛股（证据 E-70404）。
2. 巨额资金管理下追求过高回报目标，伴随组合整体风险在短期内大规模累加（证据 E-70404）。
3. 管理者多为缺乏完整牛熊市周期考验的年轻群体，将投资简化为追逐几个月内暴涨的题材股，使资金流入与资产和利润极不相称的高估值企业（证据 E-70405）。
4. 运用非正统手段或灰色财技（如以大幅低于市价购入存信股、在不受公开出售限制后立刻按完整市价计入财报）粉饰出虚幻诱人的当期利润（证据 E-70405）。
5. 辉煌业绩不可持续：暴赚之后（如1-2年内）随后年份必然遭受灾难性的持续损失，甚至重仓股面临破产诉讼（证据 E-70412）。

## 适用边界与失效
1. 适用范围限于牛市狂热阶段涌现的激进成长型、高换手、高估值追热点的股票型业绩基金（证据 E-70404、E-70405）。
2. 失效条件：在极少数严格进行自我资本限制、不向公众过度扩募且深耕单一高景气专门领域的特殊基金上，可能长期维持超额收益而不至于短期崩塌（证据 E-70418）。

## 与其他概念的关系
- 与 K-32466（基金经理选拔评价标准）：互斥对抗关系，K-32466要求的平顺曲线与年化20%原则正是为了避开本陷阱。
- 与 S-2913（公募基金择时选人配置法）：负向过滤条件，在基金池初筛中作为绝对排除项。
- 与 C-20064（蔡志勇曼哈顿基金兴衰案例）：典型历史案例支撑，曼哈顿基金在1967-1968年狂热后迅速爆雷验证了此规律。

## 案例与证据
格雷厄姆在书中记录1967年收益在84%至300%的最佳业绩基金群体，在1969-1970年普遍惨败；其中蔡志勇掌管的曼哈顿基金在1969年底组合异常，其投资最多的重仓公司中有两家在随后6个月内申请破产，第3家于1971年遭债权人诉讼（证据 E-70405、E-70412、E-70413）。
```

```markdown
# K-32470 共同基金对普通投资者的制度性保护与约束
> 来源：SRC-002742（读书_16聪明的投资者）· 证据 E-70410
> 来源立场：书中作者观点
> 底本层级：仅增强稿可见

一句话定义：共同基金通过专业化管理、组合分散投资及强制平仓/清盘线机制，帮助缺乏专业交易能力的普通人培养投资习惯并抑制投机冲动，从而避免直接炒股可能导致的毁灭性本金损失。

## 它解决什么问题
解决散户既缺乏专业交易能力与风控体系、又渴望参与资本市场投资，直接开户炒股往往滑向非理性投机、听消息死扛甚至全副身家爆仓毁灭的散户生存问题。

## 如何识别
1. 机构专业性替代：将专业投资委托给专业机构，其研究与信息渠道非普通散户所能比拟（证据 E-70410、E-70414）。
2. 行为约束与习惯培养：基金培养了投资者长期储蓄与定期投资的习惯，使其参与回报与普通股总体回报相当，诱惑与投机冲动远小于直接交易股票（证据 E-70410）。
3. 风险硬约束保障：公募/私募基金设立有强制平仓线或清盘线机制，能够接受的亏损空间有限，从制度上阻断了散户式无底线下跌死扛（证据 E-70411）。
4. 投资组合广度分散：机构通常分散持有数十至上百只标的，即使单一个股发生极端黑天鹅爆雷，亦不影响组合生存大局（证据 E-70414）。

## 适用边界与失效
1. 适用范围限于没有经过系统化交易训练、缺乏止损纪律的普通非专业个人投资者（证据 E-70410、E-70411）。
2. 失效条件：若投资者选择的是激进型业绩基金（K-32469）或在指数历史极高位追入，仍将承受较长期的系统性净值回撤（证据 E-70402、E-70404）。

## 与其他概念的关系
- 与 S-2913（公募基金择时选人配置法）：价值定位前提，构成了个人投资者选择基金配置法而非盲目炒个股的底层逻辑。
- 与 C-20066（投资者信风水死扛中国汽研案例）：反面对照关系，展示散户直接炒股无风控死扛的悲惨下场。
- 与 C-20065（社保基金重仓南极电商踩雷案例）：制度分散优势支撑，证明机构分散持仓面对个股爆雷的抗风险韧性。

## 案例与证据
讲述者对比指出：某大哥因不懂股票投资而轻信风水算命重仓中国汽研，在漫长下跌中持续死扛加仓遭受凄惨下场，若当时购买的是具有清盘线机制的公募基金则不会亏损如此惨重；同时社保基金即便买入南极电商遭遇4天暴跌25%踩雷，但因组合配置100只股票，个股踩雷对整体投资水平影响极其有限（证据 E-70411、E-70414、E-70415）。
```

```markdown
# S-2913 公募基金择时选人配置法
> 来源：SRC-002742（读书_16聪明的投资者）· 证据 E-70409
- 性质：局部方法
- 规则版本：原文2021年1月23日讲述版
- 完整度分级：已给方向
- 效果证据：创金合信工业周期股票A（005968）近一年收益率达166%，前十名基金中稳健大基金4-5年翻3倍，均显著超越散户年均收益表现（证据 E-70408、E-70416）。

## 目的与适用环境
- 目的：帮助非专业投资者规避直接炒股的投机亏损陷阱，通过宏观大势择时、行业赛道选择与基金经理能力评估，实现长期稳健且超越市场平均回报的复利增长。
- 适用环境：A股公募权益类基金市场，且大盘指数处于历史低位附近、特定行业赛道具备发展潜力但尚未累积大幅涨幅的时期（证据 E-70409）。

## 条件与动作
| 规则类别 | 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- | :--- |
| 环境过滤 | 上证指数处于历史低位附近，大盘未处于历史高位，大势向上概率大 | 宏观择时周期 / 月线或年线级别 | 证据 E-70402、E-70409 | 原文未给出“历史低位”的具体点位数值判据 |
```
