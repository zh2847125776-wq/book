# K-41448 触碰下轨4至6次耗竭律与向上通道同向假突破陷阱
> 来源：SRC-002972 读书_其他_100倍超级强势股_11（增强版） · 证据：E-88620, E-88621, E-88622, E-88623

### 核心概念与运作机理
在价格通道几何动力学与支撑衰竭学中，系统确立了“触碰下轨4至6次主跌确立”与“同向突破上轨不可持续”的物理定律：
1. 向上通道同向突破上轨之“现金耗尽假突破”：向上倾斜的上升通道中，若股价向上加速试图向上突破通道上轨，往往属于严重透支主力动能的消耗性假突破；因为拉升需要源源不断消耗海量现金（能量），向上同向突破通常“维持不了一次两次就会迅速跌回通道内”；
2. 反向旗形整理突破之高确定性：买入突破唯有在“逆向结构”中才具备极高胜率——即在向下的下降通道或水平通道中向上突破上轨（旗形整理）；
3. 触碰下趋势线4至6次之结构耗竭律：支撑线并非“触碰越多越稳固”；实盘铁律揭示——“股价触碰下趋势线次数越多，后续下穿破位的可能性就呈指数级暴增”；即使是最强的超级强势股，在主跌浪来临前触碰下轨的次数通常仅有4到6次；一旦短期内频繁触碰下轨，宣告多头承接力彻底枯竭，大崩盘近在眼前；
4. 布林线突破上线后打回中轨见顶特征：与布林线动力学高度吻合，初次大涨触碰上轨后回踩中轨，若二次冲高无法有效拓展上轨空间，顶部结构彻底坐实。

### 适用场景与边界条件
- 适用场景：A股与美股通道结构健康度诊断、防范向上通道假突破诱多。
- 边界条件：严禁追逐向上通道同向突破上轨；触碰下轨达4次以上坚决禁止开多。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
为股指双轨买入法（K-41449）提供单边通道衰竭依据；与大阴线下收十字星贯穿吞噬量化策略（S-25905）形成逻辑闭环。

### 案例与证据
- 案例标的与时间：杰西·斯泰恩《100倍超级强势股》论通道突破与布林线中轨对比。
- 实盘数据特征：阐释了向上通道突破上轨消耗能量维持不了、旗形整理突破方可买入，指出触碰下轨达4-6次行情见顶的大数定律，结合布林线中轨回踩给出见顶逻辑。
- 逐节证据标定：向上通道突破上轨维持不了与旗形向下通道突破买入参见 E-88620，触碰下趋势线4到6次支撑耗竭主跌将至参见 E-88621，布林线打回中轨二次冲高无力构筑头部参见 E-88622，连续三次新低BCD哭泣点与漫长等待右侧买入参见 E-88623。

# K-41449 股指双轨买入法核心公理与大指数权重阳包阴极低概率律
> 来源：SRC-001242 股票_20210127量化技术分析（增强版） · 证据：E-88624, E-88625

### 核心概念与运作机理
在系统化多因子选股与大盘指数权重风控哲学中，系统确立了“股指双轨买入法”与“大指数权重反包极难假说”：
1. “股指双轨买入法”最高核心公理：交易体系最基石的核心思想为“股指双轨买入法”——交易者在任何实盘决策中，“绝不单看个股自身盘面，而必须严格将大盘指数作为最高操作依据”；只有当大盘指数处于安全可操作的生命周期时，个股技术形态才具备统计学上的有效性；
2. 大盘指数与巨型权重“阳包阴”极低概率律：在小盘妖股中，连续暴跌阴线后次日出现单日反包拉起（阳包阴）屡见不鲜；但对于上证指数、工商银行等体量极其庞大的宏观权重标的，在高位或次高位出现超大阴线（跌幅5%-8%）杀跌后，“次日要想走出完全阳包阴、吞噬前一日大阴线实体的概率极度微弱”；
3. 下跌过程性与反弹无力判定：大市值品种的下跌具有极强的物理惯性与筹码耗散过程，若次日反抽连前一日阴线实体中线（贯穿线）都无法企及，则判定反弹纯属极弱震荡，严禁幻想单日V型反转。

### 适用场景与边界条件
- 适用场景：A股系统性风险来临时的仓位控制、打破大指数单日V型反转幻想。
- 边界条件：大盘指数未企稳前严禁逆势买股；大权重破位后坚决禁止猜阳包阴。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
为大阴线后次日不测第三日再测50线策略（S-25905）提供理论基石；承接20/50MA仓位状态机（K-41401）。

### 案例与证据
- 案例标的与时间：2021年1月27日上证指数大阴线次日弱势平进平出复盘。
- 实盘数据特征：系统阐述了股指双轨买入法必须看指数的核心思想，指出上证指数与工行等巨型权重在高位出现大阴线后次日绝难走出阳包阴。
- 逐节证据标定：股指双轨买入法不光看个股更看指数提供依据参见 E-88624，上证指数工商银行大阴线后阳包阴概率极低参见 E-88625。
```

# S-25905 大阴破位后“次日不测第三日测50线”与未达贯穿弱反离场策略
> 来源：SRC-001242 股票_20210127量化技术分析（增强版） · 证据：E-88626, E-88627

### 策略逻辑与决策流程
本策略为针对大盘或权重股破位杀跌后，利用K线次级演化节奏判断反弹强弱并执行果断离场的量化规程：
1. 大阴线破位后收十字星的节奏律：大盘或标的在放量大阴线跌破50日均线后，次日在低位收出缩量十字星；系统确立实战节奏——“在时间周期上，第二天完全可以不展开向上反测，主力常将反抽延后至第三天；第三天再次向上测试50MA阻力”；
2. 贯穿线（Pierce）与吞噬线（Engulfing）量化检验：
   - 强反转标准（吞噬）：阳线收盘价完全覆盖并超越前一大阴线的开盘价（阳包阴），多头扭转颓势；
   - 弱反转标准（贯穿）：阳线收盘价至少站上前一大阴线实体的50%中线处；
   - 极弱盘整（连贯穿都没有）：若反弹阳线极其微弱，“别说吞噬、连前阴线实体中线（贯穿）都无法触及”，系统宣告反弹纯属死猫跳（跌多必有微弱弱势盘整）；
3. 20日线下沿运行坚决减仓：由于盘面运行在20日线与50日线下方，且反弹缺乏力度，交易者绝不可死等回本，必须趁弱势反抽在下沿将仓位果断降至冰点。

### 适用场景与边界条件
- 适用场景：A股指数及蓝筹股击穿50日均线后的次级反抽强弱度量与清仓。
- 边界条件：未站上阴线实体50%中线一律定性为弱反；第三日触50线不过全清。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
承接股指双轨买入法（K-41449）：以指数未能站上贯穿线为量化依据，指导个股全面撤退；受触碰下轨4-6次耗竭律（K-41448）统领。

### 案例与证据
- 案例标的与时间：2021年1月27日上证指数大阴线后十字星反抽实战。
- 实盘数据特征：大盘大阴破50线后收十字星，次日弱反连贯穿中线都未达到，系统指导关注第三天测试50线阻力，判定其为极弱盘整坚决防守。
- 逐节证据标定：大阴线后收十字星次日不测第三天测50线与在下线运行参见 E-88626，连贯穿都没有弱势盘整定性及破20线MACD走势参见 E-88627。
```
