# K-1334 平仓后重新变色就接回：已做的继续持有，没做的等下次贴近

# K-1335 原油过夜是大难题
> 来源：SRC-003943（第1328课）· 证据 E-5478
> 来源立场：课程讲述者采纳
> 底本层级：转述待核

一句话定义：老师说原油"只要你一过夜，它就必给你脸色看看"。当天尾盘2点25分有多单机会；前面的空单已经跌了很多，做不了了。

## 它解决什么问题

## 如何识别
- 原油持仓过夜 → 风险大、很痛苦（E-5478）

## 适用边界与失效
老师同时说，尾盘这单做了的话当晚也能挣钱，可见他并没有绝对禁止尾盘下单或过夜。

## 与其他概念的关系
