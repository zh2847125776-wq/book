# K-33997 期货持仓过夜三过滤条件
> 来源：SRC-000407（第课 期货_期货投机分析20260128（增强版））· 证据 E-93758
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：指期货日内头寸在尾盘决定是否转为隔夜持仓时，必须同时满足的有浮盈、顺应大周期日线趋势以及严格控制杠杆仓位的三重风控门槛。

## 它解决什么问题
解决日内短线交易者在尾盘面对次日开盘不可控的跳空高开或低开风险时，因盲目侥幸持仓导致开盘大幅亏损甚至爆仓的问题，规避大周期逆势持仓过夜带来的确定性被动风险（E-93774）。

## 如何识别
1. 第一条件为持仓必须具有浮动盈利，尾盘无浮盈或处于亏损状态的头寸绝对不可转为过夜（E-93758）；
2. 第二条件为交易方向必须顺应大周期日线趋势，严禁在大周期日线呈多头排列或强势上涨背景下持空单逆势过夜（E-93758, E-93759）；
3. 第三条件为控制绝对杠杆比例，杠杆高低本质取决于资金仓位（如10万元仅投入1万元属于低杠杆，压上8万元属于高杠杆），必须主动压低过夜仓位（E-93758）；
4. 尾盘新开单通常缺乏充分浮盈积累，且日内逆日线大势开单过夜风险极大，尾盘原则上不推荐新开单（E-93759）。

## 适用边界与失效
仅适用于具备日内交易平仓权限与跨日结算制度的期货品种过夜决策；若市场出现极端同向断崖式跳空或系统性不可抗力行情，即使满足过夜条件亦可能产生回撤；若日线处于震荡走平无趋势状态，顺势过滤效力下降（E-93759）。

## 与其他概念的关系
作为日内APL交易系统与趋势过夜持仓之间的衔接门槛；与日内机械出接规则构成互补关系；与大周期日线多空排列形成前提依存关系（E-93758, E-93759）。

## 案例与证据
2026年1月27至28日沪金主连（au9999）日线处于强势多头排列，尾盘若依据5分钟平台下降逆势开空单过夜，次日开盘因高开被强行嘎掉遭受重大损失（E-93759, E-93777）。
```

# K-33998 APL机械止损与收K破绿线出接规则
> 来源：SRC-000407（第课 期货_期货投机分析20260128（增强版））· 证据 E-93764
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：指在APL交易系统中，价格入场后以动态系统线（绿线）作为即时风控基准，当K线收盘价跌破绿线时机械执行平仓离场，并在重新满足条件时立即接回的无主观执念应对法则。

## 它解决什么问题
解决交易者在试单亏损时主观犹豫、强行寻找前期密集低点（堆底）或盘中价支撑作为借口抗单，导致小亏演变为深套大亏的执行难题，确保以极小代价截断单笔亏损（E-93764）。

## 如何识别
1. 以K线收盘价（收K）作为唯一裁判基准，盘中毛刺刺破不作为判定条件（E-93764）；
2. 多头持仓中，一旦某根K线收盘价打漏或低于绿线，必须无条件立即执行止损平仓，无需主观分析（E-93764）；
3. 严禁事后马后炮式寻找“前期堆底未破”等借口延后止损，即使前期堆底未被收K击穿，亦必须无条件先按收K破绿线止损（E-93764）；
4. 平仓后若后续K线重新收回绿线上方或转阳确认，应毫不迟疑立即执行“接回”动作，接受小幅跳价磨损以防止单边踏空（E-93765, E-93768）。

## 适用边界与失效
适用于5分钟级别APL跟踪系统；在无序横盘震荡区间内，频繁收K穿梭绿线会导致连续出接磨损（连跪）；对于黄金等高波动高外轴密度品种，开单点距离绿线过宽（如1.4%）时，人工机械执行难度显著上升（E-93765, E-93776）。

## 与其他概念的关系
与前期堆底/近低支撑判据互斥，以动态绿线收K替代静态低点；作为多次试单抓单边策略的核心微观止损模块（E-93764, E-93768）。

## 案例与证据
2026年1月27日氧化铝主连（ao9999）下午1点35分试单多头后，K线收盘击穿绿线，系统严格执行收K破绿线出局，随后在重返多头形态时重新接回，规避了深度回撤并成功吃到单边主升浪（E-93764, E-93765, E-93775）。
```

# K-33999 APL平台中轨入场过滤与无色K过滤判据
> 来源：SRC-000407（第课 期货_期货投机分析20260128（增强版））· 证据 E-93768
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：指APL系统在平台发生抬升或下降确定方向后，入场必须等待价格回踩贴近中轨、且必须出现具备明确阴阳属性的转向K线（阳线做多/阴线做空），同时过滤掉无涨跌属性的无色K线的进场确认法则。

## 它解决什么问题
解决短线交易者在看到平台抬升或突破后急于追高追空、入场成本距离止损绿线过远导致风险收益比极差的问题，同时排除分时无色十字星/平盘K线带来的伪方向诱导（E-93761, E-93768）。

## 如何识别
1. 平台方向确认：依据分时图/分钟图平台高低点抬升确定多头方向，平台下降确定空头方向（E-93761, E-93773）；
2. 贴近中轨条件：平台抬升后不能直接追高，必须等待价格回调贴近中轨附近，以确保进场点与止损线距离最小化（E-93761, E-93769）；
3. 阴阳色确认条件：多头开单必须等待转阳线（阳线下单），空头开单必须等待转阴线，阴线不能作为做多开单K线（E-93768）；
4. 无色K线过滤：当到达K线收平、不分阴阳呈无色K线时，一律不得下单，必须等待后续具备明确阳线属性的K线收出再行进场，即使成本高出1-2个跳位亦须遵守（E-93771）。

## 适用边界与失效
适用于5分钟或日内短线周期；若单边走势极强、价格跳空后一路单边暴拉而不产生任何贴近中轨的回调，人工规则将因无法获得贴近中轨确认而出现踏空（如高开直冲行情）（E-93761, E-93769）；当价格处于中轨下方时多单条件全面失效（E-93771）。

## 与其他概念的关系
作为入场时点的微观前置过滤器；与收K破绿线止损规则紧密咬合，通过“转阳且贴近绿线/中轨”将单笔试错成本压制在极低水平（E-93768）。

## 案例与证据
纸浆主连到达入场位置时出现无色K线，系统放弃在无色K下单，等待下一根明确阳线形成后多单入场，虽成本提高一两跳但稳妥获得后续浮盈；焦煤平台抬升但缺乏贴近K线，继续保持观望（E-93769, E-93771）。
```

# K-34000 交易品种惯用专精与横盘试错风控原则
> 来源：SRC-000407（第课 期货_期货投机分析20260128（增强版））· 证据 E-93766
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：指交易者在期货市场中应长期固定跟踪特定惯用交易品种群，接受横盘区间的合理连续试错磨损（如连跪3次暂停），坚决避免因见异思迁挪仓追逐短期暴涨热点而导致两头挨打的交易心理与资金管理法则。

## 它解决什么问题
解决散户交易者频繁追逐市场热点、在原跟踪品种即将启动前放弃并盲目追高其他暴涨品种，最终在新品种高位接盘亏损、原品种单边爆发却完全踏空（两头挨打）的顽疾（E-93767）。

## 如何识别
1. 专精固定品种：交易者必须成为所做品种的“惯用选择者”，通过长期熟悉其波动节奏与磨损周期获取认知优势，不可幻想未曾跟踪的品种突发奇想一次做对（E-93766, E-93767）；
2. 单边爆发不可预判：单边行情起点在事前无法精确预测，捕获单边的唯一现实路径是在惯用品种出现形态时持续按规则试单（E-93766）；
3. 横盘磨损统计：品种横盘震荡时间越长、统计磨损笔数越多，后续爆发大单边行情的概率越高，横盘充分的品种反而更应着手积极尝试（E-93772）；
4. 试错止损纪律：设定明确的连续磨损暂停线，例如规定连续3次试错磨损连跪则主动休息停手，避免情绪失控（E-93762）；
5. 心态与防偷鸡：将心态管理视作与技术、纪律、经验并列的核心要素（各占25%），坚决克制跟风、偷鸡抢热点的侥幸心理（E-93767）。

## 适用边界与失效
适用于大宗商品期货所有活跃板块轮动；若整个宏观市场流动性极度匮乏、长期处于无趋势死水状态，试错成本将累积增加；非系统惯用跟踪名单内的外部突发暴涨品种绝对不追（E-93767）。

## 与其他概念的关系
属于上位交易心智与资金策略规则；为APL微观多次试错策略提供心理防线与纪律保障；与板块轮动规律形成因果支撑（E-93762, E-93767）。

## 案例与证据
部分学员因羡慕金银板块暴涨，将黑色系（螺纹钢、热卷）的仓位撤出转去追涨金属系，结果金属系高位行情结束被套亏损，而黑色系出现单边行情时手中却毫无底仓，遭受典型的两头挨打（E-93767, E-93769）。
```

# S-20078 APL平台突破与中轨回踩短线交易策略
> 来源：SRC-000407（第课 期货_期货投机分析20260128（增强版））· 证据 E-93761, E-93764, E-93768, E-93771
- 性质：规则完整的策略
- 规则版本：APL(60,1) 5分钟日内版本
- 完整度分级：已给方向
- 效果证据：氧化铝（ao9999）试错1次后接回吃到单边主升；沪铝（al9999）凌晨0:20开单后跳空高走脱离成本区持续大幅盈利（E-93763, E-93765）。

## 目的与适用环境
用于捕捉大宗商品期货日内及短期单边趋势行情，以小亏大赚为核心逻辑，利用平台高低点辨识变盘方向，通过回踩中轨与阳/阴线过滤降低入场成本。

## 条件与动作
| 交易环节 | 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- | :--- |
| 环境过滤 | 顺应大周期日线趋势，日线多头排列优先做多，避免大周期逆势开单 | 日线/60分钟周期 | E-93759, E-93761 | 若大周期均线纠缠或逆势则放弃 |
| 形态或指标形成 | 5分钟图表出现明确的平台抬升（做多）或平台下降（做空）形态 | 5分钟周期 | E-93761, E-93773 | 平台未抬升或震荡纠缠时不动作 |
| 确认 | 价格回调贴近中轨，且形成具备明确色彩属性的K线，排除无色K线 | 5分钟K线收盘 | E-93768, E-93771 | 无色K线不可作为确认信号 |
| 入场 | 做多在转阳线收盘时入场（转阳线下单）；做空在转阴线收盘时入场 | 5分钟K线收盘时点 | E-93768 | 必须等待收K确认，盘中不可提前冲动抢跑 |
| 初始止损 | 以K线收盘价跌破/击穿系统绿线为硬性止损线，收K破绿线即刻平仓 | 5分钟K线收盘时点 | E-93764, E-93768 | 不以盘中瞬时毛刺或前期低点为抗单借口 |
| 仓位与资金 | 杠杆比例依总资金严格压低，单品种试错控制在总资金小比例，连跪3次以上强制休息 | 日内开仓前 | E-93758, E-93762 | 严禁重仓赌单 |
| 持仓与跟踪 | 价格运行在绿线与中轨上方持续持仓，平台持续抬高脱离成本区后底仓安若泰山 | 持仓全程 | E-93763, E-93769 | 脱离成本区后无需频繁盯盘折腾 |
| 加减仓 | 价格沿单边趋势运行中出现回踩绿线后再度转强提示时可加仓，破绿线时先行出局 | 5分钟级别走势中 | E-93765, E-93769 | 加仓部分与底仓同等执行绿线纪律 |
| 止盈与退出 | 价格跌破/打漏系统绿线止盈离场，或日内未满足过夜三条件前尾盘清仓离场 | 5分钟K线收盘或尾盘收盘前 | E-93758, E-93773 | 严禁无浮盈逆势强行过夜 |
| 失效与放弃 | 价格跌破中轨并长期运行在中轨下方，或连续3次出接磨损（连跪）触发暂停线 | 即时盘面 | E-93762, E-93771 | 放弃当前交易，等待新平台形成 |

## 规则之间怎样衔接
平台抬升确立多头主基调 -> 回踩中轨确认进场安全垫 -> 转阳线收K发出下单指令 -> 绿线收K位置提供极窄止损保护 -> 破绿线平仓而转强后即刻接回 -> 尾盘依据过夜三条件决定是否隔夜（E-93758, E-93764, E-93768）。

## 案例和失败方式
失败方式为行情处于无序宽幅震荡时，K线在绿线上下反复穿梭造成连续出接磨损；成功案例为沪铝在凌晨0点20分确认进场后跳空高开直接脱离成本区（E-93763, E-93765）。

## 版本分歧与证据限制
原稿未给出APL指标中60.1的具体数学公式与参数构成，仅见于行情界面标注`APL(60.1)`；内上、内下、中线、外上、外下等具体轨线算法原稿未详细展开（仅增强稿可见）。

# S-20079 期货跨日持仓过夜三要素过滤评估法
> 来源：SRC-000407（第课 期货_期货投机分析20260128（增强版））· 证据 E-93758, E-93759, E-93760
- 性质：局部方法
- 规则版本：日内转隔夜风控标准版
- 完整度分级：已给方向
- 效果证据：严格执行过夜三过滤可避开高位高频异向跳空导致的开盘直接被嘎风险（E-93758, E-93760）。

## 目的与适用环境
用于期货日内短线交易者在下午收盘前或夜盘收盘前，对已有持仓进行严格审查，杜绝盲目侥幸过夜导致的次日开盘跳空爆仓风险。

## 条件与动作
| 交易环节 | 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- | :--- |
| 环境过滤 | 审查标的隔夜跳空历史与外盘关联度，高位易发异向跳空品种重点审查 | 尾盘决策时点 | E-93760 | 对外盘敏感品种更须严苛 |
| 形态或指标形成 | 日线图大周期趋势审查，确认均线系统多空排列与趋势方向 | 日K线图 | E-93759 | 日线趋势不清晰时视为中性 |
| 确认 | 逐项核对三条件：①是否有浮动盈利；②是否顺大周期日线；③杠杆仓位是否极低 | 尾盘临近收盘 | E-93758 | 缺一不可，任何一项不满足即判定不过夜 |
| 入场 | 本方法为过夜持有决策，若决定不过夜则在收盘前平仓；严禁尾盘逆势新开仓过夜 | 收盘前5-15分钟 | E-93758, E-93759 | 尾盘新开单无浮盈积累不得持仓过夜 |
| 初始止损 | 若留仓过夜，次日开盘若遭遇不利跳空开在关键防守位外，开盘即刻止损离场 | 次日开盘时点 | E-93777 | 不可抱有日内回补缺口的侥幸心理 |
| 仓位与资金 | 过夜持仓占用保证金严格限制在总资金安全比例内（如10万资金仅用1万），坚决杜绝高杠杆过夜 | 开仓与尾盘审核时点 | E-93758 | 严禁重仓或满仓过夜 |
