# K-2869 箱体的三种类型，要等突破结果出来后回头认定

> 来源立场：课程讲述者采纳

一句话定义：箱体分三种：低位箱体、中部箱体、高位（顶部）箱体。

- 突破不了，或刚突破一点又掉回来 → 是顶部箱体。

## 它解决什么问题
判断箱体的性质。

## 如何识别
- 三种类型（E-60260）。
- 突破并大涨 → 中部箱体；突破不了或突破后又掉回 → 顶部箱体（E-60261）。
