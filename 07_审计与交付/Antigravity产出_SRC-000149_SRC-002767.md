```markdown
# K-32863 逆势向下摊低成本（浮亏补仓）之禁忌
> 来源：SRC-002767（第33课 读书_33（增强版））· 证据 E-72453
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：交易发生浮亏时，严禁通过继续加码买入来试图拉低持仓均价，该行为是投机交易中最严重的致命错误。

## 它解决什么问题
解决交易者在单笔交易发生浮动亏损被套时，由于不愿承认错误、抗拒止损断腕，心存侥幸而试图通过持续追加资金盲目向下补仓，导致风险敞口呈几何级数放大、最终本金被单边下行行情彻底吞噬的灾难性亏损问题。

## 如何识别
1. 账户持仓已出现浮动亏损（原稿作「福亏」[原稿如此，疑误]）（证据 E-72453）。
2. 在浮亏状态下未执行斩仓止损，反而动用后续备用资金追加买入以摊薄持仓成本（证据 E-72453）。
3. 标的价格处于持续下跌趋势中，盲目按固定节奏加码（如每天跌5%即加仓四分之一）（证据 E-72454）。
4. 若真要以摊低成本为由加仓，底线前提也必须是等待行情出现确实的底部形态确认，严禁在下跌趋势未扭转时一路盲目补仓（证据 E-72454）。

## 适用边界与失效
- 适用边界：适用于股票及商品期货等所有投机标的的下行单边行情；原文明确强调“就不该补仓”，浮亏唯一的正确动作是坚决执行斩仓纪律（证据 E-72453）。
- 失效条件：原稿未给出向下补仓可作为常规有效策略的成立边界；仅指出即使理论上要加仓摊薄成本，也必须严格建立在标的已出现确实的底部这一前提条件上，否则一路死扛必遭惨败（证据 E-72454）。

## 与其他概念的关系
- 与「止损斩仓」互斥：浮亏补仓是对止损斩仓风控纪律的直接违反；
- 与「顺势浮盈加仓」对立：浮盈加仓是顺应市场趋势确认扩大战果，浮亏补仓是在错误方向上逆势死扛；
- 与「汰弱留强」互补：汰弱留强要求及时剔除破位亏损标的，禁止向弱势亏损标的继续追加补仓资金（证据 E-72456）。

## 案例与证据
利弗莫尔在棉花头寸出现浮亏后，不仅未及时斩仓收手，反而持仓死扛并一路逆势加码买入，甚至前往利物浦继续加码试图托起市场，持仓由6万包一路补至44万包，最终导致90%本金彻底损失（证据 E-72454、E-72455）。
```

```markdown
# K-32864 多品种持仓的汰弱留强原则
> 来源：SRC-002767（第33课 读书_33（增强版））· 证据 E-72456
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在同时持有多个不同表现的标的头寸时，必须果断卖出造成亏损的弱势品种、坚定保留带来利润的强势品种。

## 它解决什么问题
解决交易者在管理多个持仓组合时，常犯“刚赚两三个点就急忙跑路套现、套了六个点反而舍不得割肉死扛”的心理扭曲与劣质仓位管理问题，避免组合中优质盈利资产被过早切断利润空间、而劣质亏损资产被长期留存演变为深度套牢。

## 如何识别
1. 账户中同时持有两只或两只以上的标的头寸（证据 E-72456）。
2. 组合内标的走势出现明显分化：弱势标的出现破位下行并产生浮亏，强势标的处于盈利与顺势上行通道中（证据 E-72456、E-72457）。
3. 识别出弱势标的破位走弱后，必须立即执行减仓或斩仓，清出亏损持仓（证据 E-72457、E-72458）。
4. 识别出强势标的后，不得过早止盈，在均线系统中以二十线、五十线作为跟踪依据，五十线进出或二十线破位前必须继续持仓跟踪趋势（证据 E-72457）。

## 适用边界与失效
- 适用边界：适用于股票及商品期货等多持仓组合的头寸筛选与动态管理；强势标的的持有需依托关键均线（如二十线破位再离场）提供持仓依据（证据 E-72457）。
- 失效条件：若交易者因心理贪嗔逆向操作（如卖出盈利的小麦、保留亏损的棉花），会直接人为切断利润空间（原案例中小麦后续每蒲式耳大涨20美分，痛失约800万美元潜在利润），同时承受弱势品种的巨额亏损（证据 E-72458）。

## 与其他概念的关系
- 与「浮亏补仓」互斥：汰弱留强要求主动切断弱势头寸，严禁向弱势亏损标的逆势输送资金；
- 与「移动均线跟踪离场」结合：强势标的的留存与退出依托二十线、五十线均线系统作为量化跟踪判据（证据 E-72457）。

## 案例与证据
利弗莫尔在同时持有浮盈的小麦和浮亏的棉花时做出完全错误的决定：因棉花仓位过大担忧风险，却选择卖掉盈利可观的小麦、保留造成亏损的棉花。结果退出后小麦价格每蒲式耳大涨20美分（损失约800万美元利润），而保留的棉花则持续暴跌导致其几乎赔光全部利润（证据 E-72456、E-72458）。
```

```markdown
# K-32865 重大亏损后的强制休整机制
> 来源：SRC-002767（第33课 读书_33（增强版））· 证据 E-72459
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：交易者遭遇重大亏损后，必须立即清仓并强制暂停交易一段时间，待心态恢复稳定、心理创伤愈合后方可重新入市。

## 它解决什么问题
解决交易者在遭受严重本金打击（如本金亏损50%以上）后，心理陷入崩溃失衡与急于快速翻本的非理性状态，导致下周立刻强行盲目入市、造成操作严重变形进而引发二次灾难性亏损甚至彻底爆仓的问题。

## 如何识别
1. 账户发生重大亏损事件（如本金亏损50%或遭受毁灭性回撤）（证据 E-72459）。
2. 交易者心理出现崩溃和零散状态，脑中完全被“急于快速回本”的单一执念占据，导致原有交易纪律与动作变形（证据 E-72459、E-72460）。
3. 触发强制应对动作：必须清仓并停止交易，彻底脱离市场环境（证据 E-72459）。
4. 强制休整时长：根据创伤严重程度，可休整两周、两个月，乃至一年或两年（证据 E-72460）。
5. 重新入场条件：唯有在充分治疗好心理伤口、心态重新归于平静自洽后，方可考虑重新试水步入市场（证据 E-72459、E-72460）。

## 适用边界与失效
- 适用边界：适用于股票、商品期货等各类投机交易中出现重大亏损或连续失利后的心理创伤修复与风控隔离（证据 E-72459）。
- 失效/禁忌条件：严禁抱有“急于还债”或“让股市替你支付紧急账单”的心态进行交易，在华尔街该想法是导致交易者输个精光的最常见原因，心态不稳则所有技术规则完全失效（证据 E-72461）。

## 与其他概念的关系
- 与「报复性交易/频繁交易」互斥：重大亏损后的强制休整是对急于翻本的报复性交易冲动的硬性风控阻断；
- 与「交易心态与纪律」互为基石：纪律、经验、心态与技术是交易的完整支柱，稳定的心态是技术系统能够正常执行的前提条件（证据 E-72461）。

## 案例与证据
利弗莫尔在棉花投机失败亏损90%本金后，面临大病及必须紧急支付20万美元现金的重压，急于从股票市场把钱赚回，讲师结合该案例重点强调华尔街抱有让股市支付账单的想法是最常见亏损原因，必须强制清仓休息治疗伤口（证据 E-72460、E-72461、E-72462）。
```

```markdown
标的价格前期在阻力位（resistance area）出现反转，显示阻力位附近存在明确的抛售压力（selling pressure）；原作者在阻力位附近开仓做空，初始止损设置在反转拐点上方，理论上该笔交易胜率很高（证据 E-72466）。
```
