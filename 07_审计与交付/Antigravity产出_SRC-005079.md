```markdown
# K-31878 50线反弹终结判据
> 来源：SRC-005079（第2356课 股票日评：冲关关注收盘价与2924相对关系（20240220）） · 证据 E-67913, E-67914, E-67921
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在均线空头排列的下跌常态反弹中，当50线向上具明显斜率作为短线进出依据时，反弹宣告终结并转跌的标准判据为收盘攻破50线且50线拐头向下。

## 它解决什么问题
解决在下跌趋势反弹走势中，如何客观定量判定反弹何时结束、重回主跌趋势的标准问题，避免交易者仅凭指数触碰阻力位或单日收阴便主观臆断反弹见顶。

## 如何识别
1. 均线系统处于空头排列或下跌常态，前高未过，价格处于自低点以来的反弹走势中（证据 E-67913）；
2. 50线向上具有明显斜率，作为反弹过程中的短线进出依据（证据 E-67913）；
3. 价格在日线收盘时跌破（收盘攻破）50线（证据 E-67913, E-67921）；
4. 50线方向自身出现拐头向下（证据 E-67913, E-67921）。
上述条件同时满足，即可确认自前期低点以来的反弹正式结束并开始转跌（证据 E-67913, E-67921）。

## 适用边界与失效
1. 行情遇到阻力不漏不等于过不去，必须给行情观察机会，在未跌破50线之前反弹仍可延续（证据 E-67913）；
2. 若收盘跌破50线但50线并未拐头向下，不可断定反弹终结；价格可能再次反弹贴近多空线，需等待第二次有效打漏50线方可确认（证据 E-67914）；
3. 若开盘直接跳空开在多空线上方（如印花税事件），不在该规律讨论范围内（证据 E-67914）。

## 与其他概念的关系
1. 与60MA压制配合：行情贴近60MA受阻回落时，以50线是否攻破且拐头作为反弹是否夭折的裁判标准；
2. 与形态学打漏OB区、ZR序列出低一、MACD红柱连续缩短构成反弹终结的多维度互证系统。

## 案例与证据
1. 历史案例：自3400多点下跌以来，多次贴近60MA受阻后跌破50线转跌，而贴近60MA但50线未破时则能继续上涨（证据 E-67914）；
2. 容错案例：跌破50线但未拐头，后市再度贴近多空线，第二次精准打漏50线后确认大跌（证据 E-67914）；
3. 当下验证：2024年2月20日上证指数虽遇关键阻力，但50线未破且未拐头，不可断言自2635点以来的反弹结束（证据 E-67921）。
```

```markdown
# K-31879 ZR序列放空过滤规则
> 来源：SRC-005079（第2356课 股票日评：冲关关注收盘价与2924相对关系（20240220）） · 证据 E-67915, E-67916
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在下跌常态反弹行情中应用自然序列（ZR序列）寻找放空点时，为避免频繁开单磨损，有效低一序列必须满足跌破前一个红色序列的低点，且当日K线最低价进一步降低。

## 它解决什么问题
解决交易者在震荡或反弹阶段按ZR序列“高一、低一都进”导致频繁进出、止损损耗过大的问题，提供降低开单频次、提高放空确定性的过滤规则。

## 如何识别
1. 行情处于空方掌控区域的技术反弹中，处于等待放空的状态（证据 E-67915）；
2. 指标发出低一序列信号（证据 E-67915）；
3. 过滤判据一：前一个红色序列的低点必须被跌破；若前一个红色序列低点未漏，则不认为该低一有效（证据 E-67916）；
4. 过滤判据二：当日K线不仅产生低一序列，且最低价较前一日进一步降低，该放空信号更为可靠（证据 E-67916）。

## 适用边界与失效
1. 未站上多空线的高一不可作为买点，此时应处于等待放空状态（证据 E-67915）；
2. 长期而言不经过滤的ZR序列亦具备正期望，但过滤规则是避免过度交易的必要手段（证据 E-67916）；
3. 若产生低一序列但未创新低或未跌破前红序列低点，放空信号视为无效。

## 与其他概念的关系
属于形态结构学工具分支，与多空线配合判断顺逆势，与均线系统和MACD共振判断转跌点。

## 案例与证据
1. 2024年2月20日上证指数处于高五序列，未出低一序列，不满足放空标准（证据 E-67915）；
2. 课堂假设推演：若次日平开最高2908、最低2885，产生低一且最低价低于前一日低点，则放空信号有效成立（证据 E-67916）。
```

```markdown
# K-31880 压力位大资金提前偷跑机制
> 来源：SRC-005079（第2356课 股票日评：冲关关注收盘价与2924相对关系（20240220）） · 证据 E-67917, E-67918
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：当市场主体对某一关键阻力位（如60日均线）形成高度一致预期时，大资金因担忧对手盘抢先出逃导致自身卖价变差，选择在未触及阻力均线前提前抢跑出逃，导致行情提前见顶回落的微观博弈现象。

## 它解决什么问题
解释弱势品种在反弹过程中为何往往无法精确触碰技术分析所预期的关键阻力线（如60MA）便提前转弱见顶的微观结构与博弈动因。

## 如何识别
1. 市场普遍知晓上方存在明确的关键阻力均线（如60日线）（证据 E-67917）；
2. 行情反弹出现虚弱迹象，包括技术指标收敛、连续两天无法创出新高（证据 E-67917）；
3. 序列指标提前走弱，相比大盘先一步发出走弱信号（如ZR序列提前一天出低）（证据 E-67917）；
4. 量价关系呈现上涨缩量而下跌阴线放量，表明资金抢跑出逃意愿坚决（证据 E-67918）；
5. 均线系统尚未触及（如50线未触碰60线、K线未能顶到60线）即开始转折下行（证据 E-67917）。

## 适用边界与失效
1. 偷跑属于博弈导致的非标准形态，导致行情的反弹最高点无法次次精确触碰阻力位（证据 E-67917）；
2. 偷跑多发生在弱势品种及分化严重的板块中；若全市场出现强劲合力放量冲关，则偷跑逻辑不成立。

## 与其他概念的关系
与量价背离（阴线放量、阳线缩量）、均线压制机制互为因果；是识别反弹提前衰竭的重要微观行为学解释。

## 案例与证据
2024年2月20日创业板指数盘中分化严重（白线跌1.5%、黄线涨0.83%），连续两天无法创高，ZR序列比上证提前一天出低，前一日阴线放量，在未触及60日线情况下提前偷跑（证据 E-67917, E-67918）。
```

```markdown
# K-31881 顶背离确认与动态化解机制
> 来源：SRC-005079（第2356课 股票日评：冲关关注收盘价与2924相对关系（20240220）） · 证据 E-67919, E-67929
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：顶背离不能仅凭价格创高与指标未创高直接判定，必须满足“技术指标收敛且高位破翻”方能最终确认；若行情维持强势连续上涨、连续多日（如20天）每天低点与高点持续抬高，则顶背离被动态化解。

## 它解决什么问题
纠正仅见价格创新高而指标钝化便主观武断判定见顶的静态思维，提供背离从“嫌疑”到“确认”的严格判据，以及强势趋势化解背离的定量规则。

## 如何识别
1. 背离嫌疑：价格创出阶段新高，但技术指标未同步创出新高（证据 E-67919）；
2. 背离确认双条件：创高仅具备一半状态，必须同时满足①技术指标收敛；②K线结构出现高位破翻（证据 E-67919）；
3. 背离动态化解条件：行情持续不跌，每天低点抬高且每天高点抬高，连续运行（如连续20天），顶背离即宣告彻底化解消失（证据 E-67919）；
4. 关键位置叠加：在前期震荡区间下限受阻且未突破时出现顶背离嫌疑，产生阶段高点的概率大幅提高（证据 E-67929）。

## 适用边界与失效
1. 在未出现指标收敛与高位破翻前，不可提前判定顶背离成立（证据 E-67919）；
2. 处于单边极强多头行情中，背离容易通过持续走高被化解。

## 与其他概念的关系
属于技术指标与K线形态形态互证工具；与关键价格（区间下限）的突破状态相互结合评估顶部有效性。

## 案例与证据
2024年2月20日银行板块指数价格创高但指标未创高，由于技术指标尚未收敛且高位未破翻，顶背离仅处于“一半”状态仍待确认；叠加短线涨幅过大及区间下限未过，构成阶段高点重点监控对象（证据 E-67919, E-67929）。
```
