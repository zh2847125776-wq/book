# K-30010 放不出量就不涨不跌：地板量=等标志阴线
> 来源：SRC-004656（第1973课 股票日评：60线追赶的账与M头的美感）· 证据 E-62572、E-62573
> 来源立场：课程讲述者采纳
> 底本层级：完整稿可见

一句话定义：成交量缩到放不出去的"基本成交量"时，指数既不会涨也不会跌，市场在等标志阴线（E-62572、E-62573）。

## 它解决什么问题
解释横盘低量期为何无方向，并把观察目标定为"标志阴线"的出现。

## 如何识别
- 放不出来量 → 不会涨、也不会跌（E-62572）。
- 成交量变化不大、处于低谷 → 没人买没人卖，大家都在等标志阴线（E-62573）。
- 本课实例：创指首小时 726→735 为"量都放不出去了、没法再缩小"（头部摘要段，未单列证据）。

## 适用边界与失效
- "基本成交量"无数值阈值，原文未明确。
- 放量那天向上还是向下，原文称"不清楚"。

## 与其他概念的关系
- 与 K-30011（核心均线入侵）组合：横盘无量期间均线在追赶箱体。
- 与 S-1535 箱体规则配合：区间内不理会。

## 案例与证据
- 20220727 创指/上证量缩（C-2329）。

# K-30011 核心均线别入侵横盘区间：入侵后再测下线=打漏核心均线
> 来源：SRC-004656（第1973课 股票日评：60线追赶的账与M头的美感）· 证据 E-62576、E-62575
> 来源立场：课程讲述者采纳
> 底本层级：完整稿可见

一句话定义：核心均线一旦从外部爬进横盘区间内，价格再测区间下线就等于把核心均线打漏，"它就撑不住了"（E-62576）。

## 它解决什么问题
给横盘区间的时间极限一个可计算的依据：均线追上区间下线之日。

## 如何识别
- 核心均线（本课为60线，前例为20线、周线多空线）逼近横盘区间下线（E-62576）。
- 入侵区间内后，再测下线 = 核心均线被打漏 = 撑不住（E-62576）。
- 追赶账：目标价 2674、今日60线 2580、差 94 点、每天升 8 点 → 10–12 天赶上（E-62575）。

## 适用边界与失效
- "每天上升8个点"为近期斜率观察，原文未给斜率变化时的修正方法。
- 原文另提前例"7月12日阴线把下线和20线都打漏""去年元旦周线多空线入侵混沌公式"（§三，未单列证据）。

## 与其他概念的关系
- 与 K-30010 并列：量给时刻、均线给极限。
- 与 K-30013（解释不了放一放）相对：本定律是老师认为可算的部分。

## 案例与证据
- 20220727 60线追赶账（C-2329，E-62575）。

# K-30016 A/B两条边九宫格：所有整理形态的统一定义
> 来源：SRC-004657（第1974课 股票日评：变盘点复盘与早盘止损的悲剧）· 证据 E-62589
> 来源立场：课程讲述者采纳
> 底本层级：完整稿可见

一句话定义：上下两条边各取向上/走平/向下三种，排列组合出通道、楔形、箱体、三角形等，统称修正/整理/震荡整固区域（E-62589）。

## 它解决什么问题
把旗形、楔形、箱体、三角形归为一类"整理区域"，简化形态识别。

## 如何识别
- 两边都向上 → 向上通道或上倾楔形；都走平 → 箱体；都向下 → 向下通道或下倾楔形（E-62589）。
- 一上一下 → 收敛/扩张三角形；一平一下 → 三角形（§七，未单列证据）。
- 画边要求：至少两个触点、无K线翻越（§七，未单列证据）。

## 适用边界与失效
- 突破前预判方向看"从哪个方向进入图形"，但"没突破前不做任何多空操作"（§七，未单列证据）。

## 与其他概念的关系
- 与 S-1535（突破上线做多/下线清仓）同一执行逻辑。
- 与 K-30012 同属形态学。

## 案例与证据
