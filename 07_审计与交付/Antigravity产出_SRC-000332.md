```markdown
# K-32971 TRP动态红绿豆出场机制
> 来源：SRC-000332（期货_期货投机分析20250821_交叉没共振_继续空单为主（增强版））· 证据 E-72980
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：基于动态刷新的TRP指标颜色变化与关键K线收盘破位进行分批减半与彻底清仓的出场跟踪机制（证据 E-72980）。

## 它解决什么问题
解决持仓过程中无法在开仓时预先固定止盈止损点位、缺乏客观动态跟踪出场标准以及利润回吐幅度不可控的具体持仓退出问题（证据 E-72980）。

## 如何识别
1. 开仓时无法直接预判固定价位，必须等待每根K线刷新后生成的对应TRP动态价位与红绿豆颜色（证据 E-72980）。
2. 多单持仓中，当K线收盘价攻破红豆位置时，执行仓位减半操作（证据 E-72980）。
3. 多单持仓中，当TRP指标状态彻底由红豆转变为绿豆时，执行清空全部剩余仓位动作（证据 E-72980）。
4. 空单持仓中反向跟踪，5分钟周期下只要出现红豆即平掉空单踢出观望，当重新变回绿豆时再行接回空单（证据 E-72981）。

## 适用边界与失效
当行情处于窄幅剧烈拉锯或频繁在红绿豆边界跳跃时，反复触发减半与清空会导致资金连续产生无谓磨损，甚至出现前期累积浮盈在震荡中完全被侵蚀的情况（证据 E-72982）。

## 与其他概念的关系
- 对照关系：与固定点数或ATR静态止损不同，TRP属于随K线逐根刷新的动态跟踪止损机制，开仓前无法固化数值（证据 E-72980）。
- 前提关系：作为趋势跟踪策略（如S-3161）持仓与退出的执行工具，必须依赖均线排列和K线方向完成入场后方可介入跟踪（证据 E-72980）。
- 互斥关系：在同一次持仓管理中，TRP红绿豆状态机与主观止盈或固定点位止盈互斥，必须严格跟随指标颜色信号（证据 E-72980）。

## 案例与证据
焦煤5分钟空单在目标价未到达前以红豆踢出、绿豆接回进行仓位跟踪（证据 E-72981）；塑料空单因盘中站上绿豆减半及后续反复震荡导致此前浮盈回吐（证据 E-72982）；纸浆8月18日空单经历两次磨损清空（证据 E-72996）。
```

```markdown
# K-32972 破翻与末端诱空陷阱
> 来源：SRC-000332（期货_期货投机分析20250821_交叉没共振_继续空单为主（增强版））· 证据 E-72983
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：价格虚假测试前期区间低点后迅速翻回区间内，并在空头趋势末端以放量大阴线诱导散户追空的反转形态结构（证据 E-72983、E-72984）。

## 它解决什么问题
解决震荡区间边缘与单边下跌趋势尾声中，交易者盲目追空导致的假突破磨损与被套在波段最低点的问题（证据 E-72983、E-72984）。

## 如何识别
1. 价格测试前期重要区间低点，但收K价格并未实质击穿该低点（例如铜在78500低点处收K也是78500，未形成收盘击穿），此形态非标准SFP，属于破翻边缘形态（证据 E-72983）。
2. 开空防守确认判据：必须等待行情将两个连续波段低点均彻底击穿后才能介入开空，否则禁止盲目追单以规避磨损（证据 E-72983）。
3. 在连续下跌趋势中后期，行情距离均线与指标较远时突然打出大幅下挫的大K线，属于典型的末端诱空陷阱（证据 E-72984）。
4. 诱空陷阱成立后，即便指标变绿空头信号显现，因离指标距离过远且形态面临破翻风险，绝对不可顺势追空（证据 E-72984）。

## 适用边界与失效
若行情以强动能大阴线彻底击穿多重前期低点并收盘在关键支撑下方，且与大周期均线系统形成同向共振，则破翻反转假设失效，空头趋势继续顺延（证据 E-72983）。

## 与其他概念的关系
- 对照关系：与SFP（摆动失败形态）不同，破翻更侧重收K是否彻底击穿关键低点；若收K与低点价格完全重合（如78500），则属于破翻判断偏勉强但结构相似的假突破形态（证据 E-72983）。
- 互斥关系：末端诱空陷阱出现时，与常规顺势“绿豆一色K”追空策略直接互斥，此时必须禁止追空（证据 E-72984）。

## 案例与证据
沪铜实盘在78500低点因收K价格也是78500未有效击穿而放弃开空，成功避免假破位磨损（证据 E-72983）；纸浆8月18日空单出场后，尾端出现大K线破翻诱空陷阱，禁止追空（证据 E-72984）。
```

```markdown
# K-32973 同系列关联品种开仓三选一原则
> 来源：SRC-000332（期货_期货投机分析20250821_交叉没共振_继续空单为主（增强版））· 证据 E-72985
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在同一商品板块或产业链多个关联品种同时触发相同交易信号时，从止损空间、目标距离与盈亏比三个维度进行横向优选的决策准则（证据 E-72985）。

## 它解决什么问题
解决同一板块多个高度相关品种共振出现开仓机会时，资金分散、难以抉择最优标的或误选高风险低收益标的的问题（证据 E-72985）。

## 如何识别
1. 确认多个品种属于同一产业链或相关板块，且在相近时段均走出符合入场条件的同步信号（证据 E-72985）。
2. 维度一（选止损最低）：测算各候选品种按规则设定的止损点位距离，优先选取贴近防守位、止损跳数最少的品种（证据 E-72985）。
3. 维度二（选目标价最远）：结合前期波段高低点或关键支撑阻力，优先选取距离第一目标价位获利空间最大的品种（证据 E-72985）。
4. 维度三（选盈亏比最划算）：计算预期获利空间与试错止损空间的比值，选取盈亏比数值最显著占优的品种（证据 E-72985）。

## 适用边界与失效
若同一板块内部各品种基本面或技术走势出现强弱显著分化（例如某品种处于累积涨幅过高位置，或商品指数整体背离），单一维度的静态对比可能因龙头品种的动量溢价而失效，需结合大盘环境审慎决策（证据 E-72986）。

## 与其他概念的关系
- 前提关系：必须建立在各候选品种均已分别满足各自技术买卖点（如K-32971、S-3161）的基础之上（证据 E-72985）。
- 补充关系：作为品种配置与资金管理的前置过滤器，补充单一品种交易系统的选品模块（证据 E-72985）。

## 案例与证据
化工板块中塑料、白乙烯与PVC同时面临多单信号时，因塑料累积涨幅高，可在白乙烯或PVC中根据止损与盈亏比进行优选（证据 E-72986）。
```

```markdown
# S-3161 小周期中周期均线排列空头交易法
> 来源：SRC-000332（期货_期货投机分析20250821_交叉没共振_继续空单为主（增强版））· 证据 E-72987、E-72988、E-72989

- 规则版本：2025年8月修改后版本（由原5与60穿透调整为5与15穿透）
- 完整度分级：已给方向
- 效果证据：螺纹钢与热卷空头排列顺利走出波段盈利（证据 E-72995）；锡在向下排列确认后空单运行顺畅（证据 E-72990）。

## 目的与适用环境
在商品大盘整体破位下行、5与20均线同向下行处于交叉共振偏空背景下，捕捉小周期与中周期均线同向空头排列的单边顺势空单机会（证据 E-72999）。
```

```markdown
- 完整度分级：已给方向

## 版本分歧与证据限制
```

```markdown
# C-20441 热卷主连5分钟攻破红豆空单案例
> 来源：SRC-000332（期货_期货投机分析20250821_交叉没共振_继续空单为主（增强版））· 证据 E-72995、E-72994
日期：2025年8月21日、品种：热卷、合约：主连合约（hc9999）、周期：5分钟周期、关联方法ID：S-3161、S-3162、来源ID：SRC-000332

商品指数大盘已攻破20线偏空运行；螺纹钢同期走势纠结不好做，而热卷近期走势显著强于螺纹钢并率先出现空头转机；早盘热卷出现攻破红豆快变色迹象（证据 E-72994、E-72995）。
```
