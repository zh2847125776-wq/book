# K-33338 反弹四级分类与结构识别
> 来源：SRC-000358（期货_期货投机分析20251029（增强版）） · 证据 E-74815
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：根据反弹价格达到的程度高低，将下跌趋势中的反弹划分为打小底立刻掉下、混沌逻辑设公式区间掉下（左高右低头肩）、与前高齐平掉下（M头）、创高掉下（左低右高头肩）四种形态的技术分类方法。

## 它解决什么问题
解决在下跌趋势中，交易者无法客观评估反弹空间成色，容易将微小途中反抽误判为大级别趋势反转，导致做空头寸过早平仓或逆势盲目抄底的问题。

## 如何识别
1. 第一种形态为打小底后立刻掉下来，属于整个下跌过程中的一部分，小周期仅出现微弱反抽，无法形成有效防御结构（E-74815, E-74816）。
2. 第二种形态为反弹触及混沌逻辑设公式区间后掉下来，形态上构成左高右低的头肩结构（E-74815）。
3. 第三种形态为反弹幅度与前高大致齐平后掉下来，形态上构成M头（双顶）结构（E-74815）。
4. 第四种形态为反弹幅度超过前高（创高）后掉下来，形态上构成左低右高的头肩结构（E-74815）。
5. 辅助识别指标：通过LPA检视前一大阴线最高价是否被吃掉，以及阳线收盘价是否收在阴线中位线一半以上；若未吃掉最高价且收在阴线一半以下，表明仍在下跌途中（E-74816）。

## 适用边界与失效
最难防范的状态是第一种“只弹一点就掉下去”的单边暴跌中继形态；若反弹持续放量上破前日大阴线最高价，并伴随均线（如5穿20）交叉共振形成真正多头排列，则弱势反弹假设失效，需转为多头结构评估（E-74815, E-74816）。

## 与其他概念的关系
1. 对照关系：第二、三、四种反弹均能演化为经典顶部结构（头肩顶、M头），具有形态可测性；而第一种反弹仅为下跌中继无结构形态，二者构成“有结构 vs 无结构”的形态对照（E-74815）。
2. 前提关系：LPA指标对前大阴线极值与中位线的覆盖状态，是评估反弹能否演进为有效反转结构的前置过滤判据（E-74816）。

## 案例与证据
2025年10月29日沪金日线图虽然均线呈多头排列且5穿20技术反弹，但前日大阴线最高价未被吃掉，阳线收盘价仅在阴线中位线一半处，属于反弹成色存疑、需警惕打小底立刻掉下的结构观察案例（E-74815, E-74816）。
```

# K-33339 背离与破翻双要件法则
> 来源：SRC-000358（期货_期货投机分析20251029（增强版）） · 证据 E-74817
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在技术分析系统中，唯有价格创新低伴随指标不创新低（底背离），且价格跌破关键低点后重新收回并站上2号位（123破翻）同时成立时，方可判定为强烈买入信号的技术法则。

## 它解决什么问题
解决单纯依靠指标背离猜底容易在单边趋势中连续钝化亏损，或者单纯依靠价格形态破翻入场却缺乏底层动能支持导致胜率低、止损过宽的交易痛点。

## 如何识别
1. 要件一：价格创出波段新低，但对应动能指标（如MVB冲上或LPA）未创新低，形成底背离形态（E-74817, E-74819）。
2. 要件二：盘面必须先清晰画出123结构，价格跌漏关键支撑位后重新站上2号位形成有效破翻；若画不出一二三结构则破翻不成立（E-74818, E-74820）。
3. 信号共振：破翻发生当根K线若VB大于MVB且系统向上，进一步确认多头买入信号（E-74820）。
4. 逐K检视流程：当K线创新低发出LPA信号后，逐K检视上一个创低的K线是否存在背离；有背离且有破翻方作为强烈信号执行，无背离则必须放弃（E-74819）。

## 适用边界与失效
仅有破翻而无背离属于纯形态破翻，不属于本法则定义的强烈买入信号；若背离破翻形态成立，但测算出的初始止损幅度过大（如达到1%或超过股票5%的硬性风险预值），则属于性价比不足的勉强形态，禁止盲目入场（E-74818, E-74820）。

## 与其他概念的关系
1. 包含与补充关系：纯破翻仅观察K线高低点突破，本法则引入动能背离作为过滤前提，二者为“形态触发”与“动能确认”的补充共振关系（E-74817, E-74820）。
2. 前提关系：123结构画线是破翻成立的物理前提，画不出123结构则无法界定2号位与破翻线（E-74818）。

## 案例与证据
2025年10月28日下午1点多白银价格创低、MVB冲上背离并伴随123破翻，形成近低止损仅0.52的强烈买入信号；而沪铜在10月28日下午3点收盘创低时MVB冲下无背离，虽然后续高开冲上破翻但止损高达1%，被判定为不合格的勉强交易（E-74817, E-74820）。
```

# K-33340 止损余量与防流动性猎杀机制
> 来源：SRC-000358（期货_期货投机分析20251029（增强版）） · 证据 E-74821
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在常规近低或近高技术止损价位的基础上，依据余量操作表向外拓宽一定点位作为缓冲空间，以规避主力失误与故意扫损的技术防守机制。

## 它解决什么问题
解决交易者将止损单机械挂在箱体边缘或前高前低等显性关口，频繁被主力操盘失误或故意的破位刺穿（流动性猎杀）扫掉止损，随后价格立即原方向大幅盈利的被动挨打问题。

## 如何识别
1. 基准定位：根据K线结构确定近低、近高、箱体箱底或缺口边沿作为技术止损基准线（E-74821, E-74824）。
2. 附加缓冲：严禁直接在基准点挂单，必须依据余量操作表计算并叠加对应品种的余量点位（E-74821, E-74823）。
3. 猎杀防范：主力机构存在水平参差、操作失误及故意将价格推过止损位（如推过10.2元打到10.3元扫空单止损，或推过7.8元杀到7.7元扫多单止损）后反向拉升的流动性猎杀行为，余量需覆盖这一恶意穿刺区间（E-74821, E-74822）。
4. 穿透判定：止损有效击穿不仅看盘中瞬时极值，重点通过人工检视是否有K线实体收盘落在余量止损线外侧（E-74824, E-74825）。

## 适用边界与失效
余量机制主要适用于期货日内小周期（5分钟、15分钟等）；带余量无法彻底消除扫损风险，若价格形成不可逆转的趋势逆转并伴随实体收盘跌穿余量位，必须坚决执行止损出局，严禁二次下移止损或无节制放大余量（E-74822, E-74823）。

## 与其他概念的关系
1. 补充关系：近低/近高止损提供刚性技术形态边界，余量提供弹性风控缓冲，二者结合构成完整止损线（E-74821, E-74824）。
2. 对照关系：股票交易因无杠杆且在日线运行通常采用固定百分比止损，而期货小周期交易受杠杆与波动影响必须使用点位级余量操作表（E-74822, E-74823）。

## 案例与证据
2025年10月28日氧化铝多单在横盘区近低2830加设余量至2820，盘中下探至最低2825未被穿透，随后暴涨至2885；豆粕空单近高2982加余量至2995，盘中最高触碰2995但无K线收在上面，成功抵御扫损（E-74824, E-74825）。
```

# K-33341 交易系统出场事后评估与接回机制
> 来源：SRC-000358（期货_期货投机分析20251029（增强版）） · 证据 E-74826
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在头寸平仓后将其置于监控窗口持续跟踪，通过事后评估验证平仓有效性，并在技术形态或指标重新走好时在短时间内果断接回原仓位的动态纠错机制。

## 它解决什么问题
解决交易者在平仓出局后便放弃跟踪，导致因指标敏感钝化或假转向出场后错失大级别单边趋势行情（卖飞），且无法顺畅重新上车的心理与操作障碍。

## 如何识别
1. 职责分工：将个人交易流程拆解为事前企划（选标的保证买后能涨）、事中操作与事后评估（俗称“收尸部”，检验卖出是否合理、卖后是否如期下跌）（E-74826）。
2. 持续观察：单子平仓后严禁置之不理，必须将图表放置在副屏幕或自选观察栏，持续监控后续K线走势（E-74826, E-74827）。
3. 接回触发：平仓后若下一个K线或下下一个K线重新走好，或者VB指标重新顺向穿回原趋势，必须立即执行接回操作（E-74827）。
4. 负荷控制：严格将同时持仓品种控制在两到三个以内（如焦煤与螺纹钢），防止多品种同时触发平仓导致人工精力无法覆盖事后接回监控（E-74827）。

## 适用边界与失效
仅适用于原趋势未遭根本破坏、短期出场属于系统过于敏感或洗盘震荡的情形；若平仓后标的持续下挫或形成明确反向常态，事后评估证实卖出正确，禁止违背技术信号强行盲目接回（E-74826, E-74827）。

## 与其他概念的关系
1. 互补关系：敏感系统（如MVB）以进场精准为优势，但出场容易频繁转向假摔，接回机制是弥补出场钝化缺陷的必要配套制度（E-74827, E-74828）。
2. 前提关系：控制持仓规模是确保人工能够执行事后评估与接回监控的先决条件（E-74827）。

## 案例与证据
2025年10月29日下午1点50分学员做沪铜多单在回调时平仓离场，随后未执行接回跟踪，错过后续大涨行情；讲师指出在多屏环境下将平仓标的置于右侧，一旦VB穿回即可及时接回（E-74826, E-74827）。
```

# S-3336 MVB转向防卖飞的波段低点保护法
> 来源：SRC-000358（期货_期货投机分析20251029（增强版）） · 证据 E-74828
- 性质：局部方法
- 规则版本：讲师20251029实盘复盘口述版本
- 完整度分级：已给方向
- 效果证据：白银2025年10月28日-29日持仓过程中抵御10点20及次日下午向下信号，守住波段低点享受高开暴涨（E-74828, E-74829）。

## 目的与适用环境
用于单边上涨行情持有多单时，应对MVB等敏感系统在震荡或盘整中频繁发出向下卖出信号，防止过早平仓卖飞后续主升浪，通过承担可控回撤换取大波段利润。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤：标的处于明确上涨常态或单边上涨趋势中持有多单 | 日内5分钟/15分钟级别 | E-74828 | 原稿未限定特定期货品种 |
| 形态或指标形成：MVB系统发出向下拐头或转向卖出信号 | 盘中持仓实时 | E-74828 | 信号出现且伴随阴线收盘 |
| 确认：检视盘面最近的定量化波段低点（5K低点）是否被跌破 | 转向信号出现时 | E-74828, E-74829 | 必须有明确量化波段低点锚定 |
| 入场：不涉及新开仓，仅作为持仓管理与退出判定规则 | 原文未明确 | E-74828 | 非独立开仓系统 |
| 初始止损：建仓时设定的5K近低加余量点位 | 建仓时点 | E-74829 | 需在开仓前测算合格盈亏比 |
| 仓位与资金：测试阶段可开两手进行策略效果对照统计 | 盘前规划 | E-74830 | 资金分配比例原稿未明确 |
| 持仓与跟踪：只要最近波段低点（5K低点）未被跌破，忽略系统卖出信号继续持有多单 | 持仓跟踪全程 | E-74828, E-74829 | 需愿意承受浮盈回撤代价 |
| 加减仓：可采用一手按系统信号平仓、一手按波段低点持有的对照测试 | 卖出信号发出时 | E-74830 | 属于实操检验建议 |
| 止盈与退出：若价格有效跌破最近波段低点，形成高低点下移的下降常态，立即全部平仓 | 波段低点跌破时 | E-74828 | 破位即确认趋势转折成立 |
| 失效与放弃：若最近波段低点过远、潜在回撤幅度过大无法承受，则放弃波段防守，改按系统信号离场 | 转向信号评估时 | E-74829 | 回撤超出承受预值时放弃 |

## 规则之间怎样衔接
本规则作为持仓跟踪与退出环节，承接前期背离破翻多单入场；在退出端用“上涨常态前提/波段低点”作为过滤网，屏蔽敏感系统的微小假信号，仅在确认跌破波段低点形成下降常态时与终极退出规则对接。

## 案例和失败方式
白银在10月29日下午1点35分出现向下信号（阳线未下单），1点40分阴线确认向下，若按信号平仓则错失晚盘高开暴涨；按本方法以最近5K波段低点未漏为由坚持持有，成功避免卖飞。失败方式：价格急跌直接击穿波段低点，导致回撤幅度显著扩大。

## 版本分歧与证据限制
存在两套执行标准：一是纯机械化执行系统转向（信号出、穿回接，震荡耗费手续费）；二是守波段低点承受回撤换取单边持仓。讲师指出MVB系统入场精准的代价是出场不太利索，需在确定性与回撤幅度之间进行权衡。

# S-3337 多周期共振与K线颜色过滤开仓法
> 来源：SRC-000358（期货_期货投机分析20251029（增强版）） · 证据 E-74831
- 性质：规则完整的策略
- 规则版本：讲师20251029实盘口述规范
- 完整度分级：已给方向
- 效果证据：铁矿石、焦煤、PTA等标的在日内与大周期共振评估中的开平仓指导（E-74831, E-74832, E-74833）。

## 目的与适用环境
用于期货日内小周期交易，通过日线与60分钟大周期趋势方向过滤，结合小周期指标穿轴、形态突破以及执行K线颜色确认，提高顺势开仓质量。

| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤：核对日线与60分钟大中周期，趋势必须与拟开仓方向一致 | 日线、60分钟级别 | E-74831, E-74832 | 大周期不支持判定为胜率过低，明确放弃 |
| 形态或指标形成：5分钟小周期出现VB穿轴、MVB同向发散或横盘区间突破 | 5分钟级别盘中 | E-74831, E-74833 | 指标穿轴与形态突破提供触发预备 |

| 入场：确认K线收盘或紧随其后的开盘点执行下单 | 下单瞬间 | E-74831, E-74834 | 错过点位需等下一根同色确认K线 |
