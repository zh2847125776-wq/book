```markdown
# K-31484 抄底订单建仓后强弱分辨四档
> 来源：SRC-004989（第2275课 股票日评：空头排列续创阶段新低没有操作机会（20231016））· 证据 E-66393
> 来源立场：课程讲述者采纳
> 底本层级：完整稿可见

一句话定义：指抄底或箱体突破建仓之后，依据价格对建仓成本价或关键突破价的后续运行形态，将持仓强弱提前划分为四个评估等级的标准（E-66393）。

## 它解决什么问题
解决订单建仓或抄底入场之后，交易者无法提前客观分辨头寸走势强弱、无法在走势滞涨破位前及时减仓或防守的问题。

## 如何识别
1. 最强：价格突破建仓价格或箱体之后，或者回撤或者不回撤，直接往上涨（E-66394）。
2. 次强：价格突破以后，在上方形成横盘区间、关后整理再突破再涨（E-66395）。
3. 还行（中等偏弱）：突破以后，在盘整过程中上下围绕该价格区间多次戳破（E-66393）。
4. 弱（最差档）：价格突破之后，再也没法创出新高，最后向下走（E-66396）。
注：若订单建仓以后根本没有实现突破，围绕成本价附近来回盘滞，同样判定为弱势特征（E-66393）。

## 适用边界与失效
- 仅适用于抄底开仓或箱体突破建仓后的后续强弱评估，不能替代入场前的趋势与环境过滤。
- 在空头排列大背景下逆势抄底胜率本身偏低，若建仓后出现围绕成本价盘滞的弱档表现，必须启动防守纪律，不得主观臆测其转强。

## 与其他概念的关系
- 与箱体图突破：两者评估逻辑相通，箱体突破后同样适用此四档强弱分类法。
- 与加仓防守规则：唯有走出强势形态或突破上方加仓阻力位（如2033）才可执行加仓；处于弱档表现时应维持半仓防守甚至准备止损，严禁弱势补仓。

## 案例与证据
- 参见 C-3245 创业板指数抄底建仓后围绕成本价来回盘滞无法突破，属于弱档表现。
- 核心证据：E-66393, E-66394, E-66395, E-66396。
```

```markdown
# K-31485 止损执行与切香肠恶性循环规避
> 来源：SRC-004989（第2275课 股票日评：空头排列续创阶段新低没有操作机会（20231016））· 证据 E-66397
> 来源立场：课程讲述者采纳
> 底本层级：完整稿可见

一句话定义：指在交易触及预设止损时必须坚决执行离场，以防因心存侥幸、拖延割肉而导致亏损如切香肠般逐步扩大并陷入深套自救恶性循环的风控准则（E-66397, E-66398）。

## 它解决什么问题
解决交易者在关键防守位破位时因心存侥幸不愿割肉，导致小亏演变为深套，进而在被动自救中越套越深的心理误区与恶性循环（E-66398）。

## 如何识别
1. 约定止损位一旦跌破，必须坚决执行止损离场纪律（E-66397）。
2. 误差缓冲限制：若仅跌破极小幅度（如仅跌破千分之一的微小误差）且交易者不想割肉，仅有一次收盘缓冲机会——收盘必须重新站回关键防守位上方，且随后分时红柱必须配合放大；否则刺破或收盘破位仍必须离场（E-66397）。
3. 切香肠式亏损特征：该割肉时不割肉，随着价格不断下滑（如从1950一路跌至1940、1930），导致资金亏损被逐步放大（E-66397）。
4. 恶性循环路径：被套牢 -> 未能及时跑路 -> 深套后被迫自救 -> 自救失误导致被套更深（E-66398）。

## 适用边界与失效
- 执行止损离场后若行情站回原位，原割肉理由不在，交易者可进行操作纠正接回；或直接认错寻找下一个标的，无论哪种情况均优于被动深套（E-66399）。
- 若标的自身波动空间极小（如日内差价不足手续费），则不适用频繁的盘中出入纠正，应以收盘破位为底线处置。

## 与其他概念的关系
- 与逆势交易：逆势交易胜率偏低，必须更严格地执行防守纪律，一旦失败不可抱有幻想。
- 与仓位控制：前期留有一半头寸（减仓防守）是降低亏损的前提，触及止损时则必须彻底清空头寸。

## 案例与证据
- 参见 C-3245 创业板指数跌破1962触发止损及对1963收盘要求的处置。
- 核心证据：E-66397, E-66398, E-66399。
```

```markdown
# K-31486 空头最盛形态与底部释放三潮
> 来源：SRC-004989（第2275课 股票日评：空头排列续创阶段新低没有操作机会（20231016））· 证据 E-66400
> 来源立场：课程讲述者采纳
> 底本层级：完整稿可见

一句话定义：指指数或标的所有均线全线冲下、呈现标准空头排列与下跌常态且跌常态前高未过的极弱形态，在该形态下突发利好极易钝化，唯有出现大规模跌停潮、强平潮与赎回潮将空头动能彻底释放后市场方能见底（E-66400, E-66401）。

## 它解决什么问题
解决在极端空头排列趋势中交易者盲目相信突发政策利好、频繁猜底抄底而反复被套的问题。

## 如何识别
1. 均线与形态特征：所有均线全部冲下，呈现标准空头排列、下跌常态走势，且反弹无法越过跌常态前高，构成空头最终（最盛）形态（E-66400）。
2. 多周期共振压制：日线周期、60分钟周期、周线周期等核心三周期同时呈现标准空头排列，每次反弹均受到均线系统或多空线精准压制（E-66400）。
3. 利好钝化（狼来了效应）：利好消息接连出现但市场反应持续减弱，利好行情仅能维持极短时间（如仅一天），甚至无法放量收出大阳线，市场缺乏买盘响应（E-66400）。
4. 见底释放判据：市场必须出现500至1000个跌停规模的跌停潮、强平潮、赎回潮，迫使持有多头头寸的资金慌不择路夺路而出，将全部空头力量释放完毕后，方能确立真正的市场底部（E-66401）。

## 适用边界与失效
- 仅适用于普通受指数影响的股票与宽基指数；不考虑指数环境的热点情绪打板风格不在本规则约束范围内。
- 若市场全天仅出现个位数跌停（如仅8个跌停），表明恐慌盘与空头力量远未释放完全，此时绝不可轻言见底。

## 与其他概念的关系
- 与均线盘好：在空头最盛形态下，交易者要么老老实实等待均线系统彻底盘好，要么等待特定的大阴十字星大阴组合结构出现，否则不得参与。
- 与防御策略：在趋势极弱时，最佳策略是忍着、别动、别做，保持空仓或本金不亏。

## 案例与证据
- 案例见 SRC-004989 中对上证指数2023年10月16日创印花税以来最低收盘价、全日仅8家跌停的盘面评估。
- 核心证据：E-66400, E-66401。
```
