# Arena ModelTrace 路由巡检增强版 (v0.3.0) 使用说明

本版本是基于官方 `ArenaModelTrace` 深度结合我们最新的 **三层探针架构** 与 **Fable-5.1 真实实测模板** 升级构建的增强版浏览器插件（油猴脚本 / Tampermonkey）。

---

## 🌟 核心升级亮点

1. **补全缺失的旗舰模型支持（Claude Fable 5.1）**
   - 官方 Reference Bank 只有 17 个早期模型，不包含 Fable-5.1。
   - 本升级版内嵌了刚刚通过真实探针采样的 **355 维 Fable-5.1 特征指纹**。经实测验证，其指纹相似度识别可从原先的“误报为 Opus-5.5 / 未知”直接拉升至 **Top 1（81.25%+ 相似度）**，彻底实现 `gpt-6-astra`、`claude-opus-5-5`、`claude-fable-5-1` 的精准闭环三选一。

2. **支持“前后两个对话是否被路由漂移”的跨会话比对**
   - 插件浮窗底部新增 **【🔄 跨会话路由比对】** 板块。
   - 点击 **“保存当前会话指纹”**：自动抓取当前对话的指纹特征并存入浏览器本地持久化存储。
   - 点击 **“与当前比对”**：采用严格的 JS 散度距离计算两会话的分布相似度。
     - 若相似度 $\ge 90\%$：判定为 `✅ 同一模型（未发生路由漂移）`；
     - 若相似度 $< 90\%$：判定为 `🚨 检测到路由变化 / 模型不同`，并展示两者的模型名与相似度百分比。

3. **DOM 解析鲁棒性修复**
   - 修正了 Arena 页面因采用 `<span data-agent-word>` 标签包裹数字导致的分词切割 Bug。无论数字如何被 HTML 标签装饰，均能 100% 提取出完整整数序列。

## 🚀 安装步骤

1. 打开 Chrome / Edge 浏览器，确保已安装油猴扩展（Tampermonkey / Violentmonkey）。
2. 打开 Tampermonkey 管理面板 -> 点击“实用工具”或“添加新脚本”；
3. 将 `ArenaModelTrace-v0.3.0-upgraded.user.js` 的全文内容复制粘贴进去并保存（或者直接在浏览器打开此 `.user.js` 文件点击安装）；
4. 刷新 `https://arena.ai/agent` 页面，右下角将出现 **MT** 浮窗标识。

---

## 🎯 跨会话路由检测实操

1. 在对话 A 结束时，点击右下角 **MT** -> 点击 **“开始检测”**（执行 3 轮探针，探针结束后模型被确定）；
2. 展开浮窗底部的 **【🔄 跨会话路由比对】** -> 点击 **“保存当前会话指纹”**；
3. 切换到新对话 B，同样点击 **“开始检测”** 获得当前会话的最新指纹；
4. 在浮窗底部的历史记录中，点击历史对话 A 右侧的 **【与当前比对】**；
5. 浮窗即刻给出结论：是保持了相同模型，还是已经被 Arena 路由机制切换到了其他模型。
