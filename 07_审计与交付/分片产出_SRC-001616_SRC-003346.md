# 补充 K-0297 机械化量化短线策略应优先应用于宽基指数ETF以剔除个股黑天鹅异动

- 30日均线/动量确认：唯有当债券期货收盘价明确高于30天前收盘价时，方才激活股票月初买入指令，使纯粹的日历统计与宏观资本流动形成完美共振（E-52722）。

# K-25489 国债期货月中做空系统引入黄金上涨动量过滤使平均单笔利润翻倍

## 适用边界与失效
