## 三、T2 —— `不补X` / `不静改` 的取舍（**需你拍板，不阻断**）

### 3.1 事实

质检只报 `不补造`。但同类的**方法论措辞**在 Codex 产出里量很大：

| 措辞 | 命中卡数 | 占 18,238 张 | 质检报吗 |

| `不静改`（如 `不静改MACD`、`不静改口述`） | 32 | 0.2% | ❌ 不报 |
| `不补造` | 13 | 0.07% | ✅ 报 |

已核实：`不静改` **不在**任何项目工具脚本里（是 Codex 自己撰写脚本的措辞）；
`不补` 同样不在提示词生成器里。

### 3.2 判断依据

批363 任务书 §四 的原话是：
> **规矩是约束，不是素材。** prompt 里的抽取铁律……**一个字都不许出现在卡片字段里**。

按这个尺子：
- `不补造` = 模板固定句，**该清**（T1 已覆盖）；
- `不补X` / `不静改` = 挂在**具体条目**上的诚实标注（「原稿没给这个，所以没编」），
  与任务书明文允许的 `[原稿如此，疑误]`、`原文未明确` **同族**，只是措辞更啰嗦。

### T5 —— 给分片审计脚本加质检闸门（防复发）

`分片工作区\Codex\reply\进度审计.py` 现在**只验形式**，所以「核对通过」会继续掩盖内容问题。
**改法**：在该脚本 `main()` 末尾，对 `out/07_审计与交付` 调一次质检，
把 ✗ 数写进输出 JSON 与恢复记录，**✗ > 0 时 `finished` 不许为 true**。

```python
# 伪代码，加在 main() 打印前
import subprocess, sys
qc = subprocess.run([sys.executable, '-X', 'utf8', str(BASE/'工具/质检_卡片充实度.py'),
                     '--dir', str(ROOT/'out/07_审计与交付')],
                    capture_output=True, text=True)
m = re.search(r'质检：(\d+) 个文件，(\d+) 个不通过', qc.stdout)
summary['qc_files'], summary['qc_failed'] = int(m.group(1)), int(m.group(2))
if summary['qc_failed'] > 0:
    summary['finished'] = False
```

**验收**：故意留一张不合格卡，脚本 `finished` 必须为 `false`；清掉后恢复 `true`。
