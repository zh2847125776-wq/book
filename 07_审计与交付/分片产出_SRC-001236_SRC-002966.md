```markdown
# K-41376 超级强势股火箭升空轨道模型与泡沫破灭70%崩盘律
> 来源：SRC-002966 读书_其他_100倍超级强势股_05（增强版） · 证据：E-88440, E-88441, E-88442

### 核心概念与运作机理
在极端动量交易（Momentum Trading）与百倍超级成长股动力学中，确立了“火箭升空轨道”与“70%高位崩盘”的双生模型：
1. NASA火箭升空推进物理隐喻：一只货真价实的超级强势股（如早期的宁德时代、九安医疗、特力A），在启动初期如同NASA研制的重型火箭，必须依靠“极其庞大、甚至连续倍增的成交量巨流（巨大推力）”才能彻底冲破大盘地心引力与历史套牢密集区；而一旦成功进入既定主升轨道，股票无需额外的外力刺激，便能凭借自我强化的流动性惯性朝着暴涨方向狂奔；
2. 独立于大盘的抛物线运行：超级强势股凭借难以置信的高ROE与前所未有的时代题材，公然藐视一切传统估值与阻力指标，走出极端加速的“抛物线（Parabolic）”暴涨走势；
3. 动量资金撤离与峰值70%崩盘律：然而此种非理性繁荣蕴含极端毁灭性；一旦动量资金（Momentum Traders）达成获利共识撤离，泡沫瞬间破灭，即便是业绩最优质的超级强势股，也必然在短期内以垂直断崖方式暴跌，“彻底蒸发峰值市值的70%甚至更多（从哪来回哪去）”。

### 适用场景与边界条件
- 适用场景：市场极度狂热期的妖股主升浪识别、泡沫破灭期高位断崖式逃顶。
- 边界条件：加速抛物线一旦放量见顶，动量交易者必须无条件全额清仓，严禁长线死扛。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
为全市场股价大于20日线个股占比广度指标（K-41377）提供微观标的透视；与60分钟平头三顶颈线有效破位策略（S-25860）形成闭环。

### 案例与证据
- 案例标的与时间：杰西·斯泰恩《100倍超级强势股》论火箭推进与A股特力A、宁德时代对照。
- 实盘数据特征：系统以火箭升空需要巨大成交量推力、进入轨道后惯性推进为比喻，阐明抛物线暴涨及动量资金撤离后暴跌70%的铁律。
- 逐节证据标定：NASA火箭巨大成交量推力与进入轨道惯性运行参见 E-88440，抛物线走势藐视传统法则与独立于板块参见 E-88441，泡沫破裂动量资金撤离与峰值大跌70%崩盘参见 E-88442。
```

```markdown
# K-41377 全市场股价大于20日线宽度指标与超跌反弹伪涨停陷阱
> 来源：SRC-001236 股票_20210119量化技术分析（增强版） · 证据：E-88444, E-88445

### 核心概念与运作机理
在全市场微观量化选股与市场广度（Market Breadth）监测中，确立“股价大于20日线真实活跃度”客观标准：
1. 涨停家数虚假繁荣真相：盘面常出现黄线上涨、数十家个股密集涨停的虚假繁荣景象；但量化复盘揭示，其中绝大多数涨停个股全部属于“前期深幅破位后的无量超跌反弹结构”；交易者若在盘前使用标准右侧顺势量化公式筛选，根本搜不出任何符合买入标准的健康标的；
2. 股价大于20日线市场宽度红线：量化衡量全市场真实多头温度的终极指标是——“全市场收盘价站上20日均线的个股绝对数量”；当4000只股票中仅有1600余只站上20日线，而“20日均线多头排列在60日均线上方”的个股数量更为稀少时，系统判定市场宽度极度恶化；
3. A50盘中突发跳水连锁反应：新华富时A50在下午1点24分突发单边脉冲跳水，直接击穿盘中分时最低点，证明大盘主力资金坚决撤退，普涨假象瞬间破灭。

### 适用场景与边界条件
- 适用场景：A股大盘震荡期市场真实温度评估、过滤超跌反弹伪主升浪。
- 边界条件：股价大于20日线个股不足全市场50%时，严禁盲目加大股票仓位。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
为60分钟多重平头顶部颈线破位（S-25860）提供宏观广度数据印证；承接反向剪刀差风格假逆转（K-41329）。

### 案例与证据
- 案例标的与时间：2021年1月19日全市场个股宽度量化统计与新华富时A50跳水。
- 实盘数据特征：全市场涨停多为超跌反弹，股价大于20日线个股仅1617只，20线在60线上方者更少，A50下午1点24分跳水引发全市场杀跌。
- 逐节证据标定：涨停个股多为超跌反弹与股价大于20日线仅1617只参见 E-88444，20日在60线上极少与新华富时A50跳水参见 E-88445。
```

```markdown
# S-25860 60分钟平头三顶形态甄别与颈线有效击穿离场策略
> 来源：SRC-001236 股票_20210119量化技术分析（增强版） · 证据：E-88446, E-88447

### 策略逻辑与决策流程
本策略为针对大盘高位连续受阻于同一密集水平阻力带时，识别平头多重顶并依据颈线击穿果断离场的规程：
1. 60分钟平头三顶（Triple Tops）高位滞涨识别：在60分钟图表上，指数连续数个交易日冲高均受阻于3596点附近的狭窄区间（各小时K线最高价冲至3597，收盘价分别为3594、3596、3591、3596点），受制于60分钟绿豆均线压制，始终无法形成实质性收盘站稳；多次冲高受阻构筑了标准的“三个平头顶部结构”；
2. 颈线精确画线与生效界定：提取三个平头顶部之间的两个波段下探低点，连接两个低点绘制水平“颈线（Neckline）”；系统明确规定——平头三顶在未跌破颈线之前仅为潜在可能，唯有当“价格实质性向下击穿两个低点连线的颈线”时，平头三顶结构方才正式生效做数；
3. 颈线破位坚决离场：一旦盘中或收盘正式跌漏颈线，高位密集成交区全部转化为沉重阻力，交易者必须执行无条件清仓止损指令，规避随之而来的大级别主跌浪。

### 适用场景与边界条件
- 适用场景：A股指数及蓝筹股在60分钟级别构筑平头顶、多头滞涨时的逃顶执行。
- 边界条件：颈线未破之前不可提前抢跑；一旦破颈线必须第一时间出局。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
承接午间加更破趋势线回避策略（S-25845）：进一步补充了高位60分钟平头三顶形态与颈线量化确认标准。

### 案例与证据
- 案例标的与时间：2021年1月19日上证指数60分钟平头顶复盘。
- 实盘数据特征：小时K线连续多次受阻于3596点构筑三平头，系统阐明画出两个低点连线作为颈线，并强调颈线有效跌破才是结构生效做数的放空清仓点。
- 逐节证据标定：60分钟M头双重结构与平头形态画图推演参见 E-88446，3596平头压制与连接两个低点绘制颈线生效条件参见 E-88447。
```
