```markdown
# 补充 K-2387 指数交易环境止损边界：指数跌破后停止开新仓，个股仅按自身止损线管理
> 来源：SRC-001655 · 证据 E-53900
> 来源立场：课程讲述者采纳（指数环境止损与个股止损分离）
> 底本层级：仅增强稿可见

一句话定义：指数下跌后代表整体交易环境恶化，应停止开新仓并保护已有持股；个股仍按自身止损线分别管理，不能混淆两个层级。

## 如何识别
- 指数止损是环境开关：指数失守关键位时，不再扩张组合仓位（E-53900）。
- 个股止损是标的开关：已有个股是否离场，仍由其自身价格与止损规则决定（E-53900）。

## 适用边界与失效
适用于指数与个股组合的分层风控。
```

```markdown
# K-25960 左侧回测与右侧确认信号：突破后横盘整固再测信号决定分批建仓节奏
> 来源：SRC-001655 · 证据 E-53901
> 来源立场：课程讲述者采纳（左侧突破回测与右侧确认的阶段区分）
> 底本层级：仅增强稿可见

一句话定义：左侧信号通常表现为突破后的回测与横盘整固，待价格再次测试并站稳后才形成右侧确认；两者共同构成由空转多的完整循环。

## 如何识别
- 左侧先观察：突破后回测、横盘和再测试是结构形成过程，不等于立即确认主升（E-53901）。
- 右侧再确认：重新站上向上均线并守住，才提高趋势延续的确定性（E-53901）。

## 适用边界与失效
适用于指数及个股突破后的分阶段建仓。
```

```markdown
# 补充 K-1457 风险偏好决定右侧确认数量：降低仓位或等待更多信号避免突破失败重伤
> 来源：SRC-001655 · 证据 E-53902
> 来源立场：课程讲述者采纳（按风险偏好调整仓位与信号数量）
> 底本层级：仅增强稿可见

一句话定义：避免突破失败的方法不是追求绝对确定，而是根据个人风险偏好降低操作仓位，或等待20MA上穿60MA等更多右侧信号再进场。

## 如何识别
- 高风险偏好：一个信号即可参与，价格可能更低但个股止损概率更高（E-53902）。
- 低风险偏好：等待更多确认后进场，虽可能牺牲部分低位价格，却降低误判成本（E-53902）。

## 适用边界与失效
适用于指数突破和个股组合的分层建仓。
```

```markdown
# K-25961 指数突破失败的量价与趋同性风险：环境未确认时降低仓位而非彻底放弃
> 来源：SRC-001655 · 证据 E-53903
> 来源立场：课程讲述者采纳（突破失败原因与风险控制）
> 底本层级：仅增强稿可见

一句话定义：指数突破并非全部成功，成交量不足、上证与创业板方向不同都可能导致失败；解决方案是降低仓位并按风险偏好等待右侧确认，而非因一次失败彻底停用规则。

## 如何识别
- 失败来源：关键突破缺少量能或主要指数缺乏趋同性，信号可靠性下降（E-53903）。
- 风险处置：低仓位试错或等待20MA上穿60MA，平衡价格优势与踩空风险（E-53903）。

## 适用边界与失效
适用于宽基指数突破的仓位管理与失败复盘。
```

```markdown
# 补充 K-25808 量化策略连亏后的耐心验证：焦煤三亏一小赚后仍需坚守才能吃到大单边
> 来源：SRC-000943 · 证据 E-53911
> 来源立场：课程讲述者采纳（连续磨损后不放弃策略）
> 底本层级：仅增强稿可见

一句话定义：焦煤超级大单边前先经历三笔亏损和连续磨损，若因失去耐心而关闭程序，后续大单边收益将完全错失。

## 如何识别
- 连亏不等于系统失效：连续小亏可能只是趋势启动前的成本（E-53911）。
- 持有与接回：程序在平多后及时纠错接回并反手做空，完整覆盖了趋势两侧（E-53911）。

## 适用边界与失效
适用于趋势CTA策略回撤期的运行纪律。
```

```markdown
# 补充 K-25904 日内挂件的收益对称代价：当日回转过滤尾盘风险也会屏蔽可盈利隔夜单
> 来源：SRC-000943 · 证据 E-53913
> 来源立场：课程讲述者采纳（当日回转同时屏蔽盈利与亏损隔夜交易）
> 底本层级：仅增强稿可见

一句话定义：当日回转挂件可在收盘前禁止新开单并强制平仓，从而消除部分隔夜风险；但它也会同步屏蔽原本能够盈利的隔夜订单，不能只看单笔避险效果。

## 如何识别
- 收盘前过滤：倒数十分钟不再开单，倒数五分钟强制平仓（E-53913）。
- 对称机会成本：过滤亏损隔夜单的同时，也会损失盈利隔夜单，必须用长期样本评估（E-53913）。

## 适用边界与失效
适用于期货策略的过夜风险与收益取舍。
```

```markdown
# K-25963 连续磨损后的大单边回报：焦煤三亏后坚持持仓并纠错接回创年度收益高点
> 来源：SRC-000943 · 证据 E-53911
> 来源立场：课程讲述者采纳（焦煤回撤后坚持与恢复）
> 底本层级：仅增强稿可见

一句话定义：焦煤在超级大单边前连续多次亏损，随后通过长时间持仓和纠错接回，从震荡磨损转入双向顺势捕获，最终创出年度收益新高。

## 如何识别
- 时间换趋势：五分钟策略持仓数日需要耐心，不能以短期噪音替代趋势判断（E-53911）。
- 纠错接回防卖飞：平仓后重新接回让策略继续参与剩余趋势（E-53911）。

## 适用边界与失效
适用于高波动期货的趋势持仓与回撤恢复。
```

```markdown
# K-25962 多空反转连续吃满模型：焦煤平多后纠错接回并反手做空实现双向收益
> 来源：SRC-000943 · 证据 E-53912
> 来源立场：课程讲述者采纳（焦煤趋势订单多空转换）
> 底本层级：仅增强稿可见

一句话定义：焦煤程序在多单平仓后没有停止，而是迅速纠错接回多单并在信号反转后立刻开空，从多到空连续捕获两段行情，仅承受一次小幅磨损。

## 如何识别
- 不因一次平仓停止：趋势未结束时，平仓可能只是阶段性退出，纠错接回避免卖飞（E-53912）。
- 多空两侧都可交易：反转确认后立即换向，使收益不依赖单一方向（E-53912）。

## 适用边界与失效
适用于具备双向交易能力的趋势程序。
```
