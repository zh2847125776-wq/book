# K-0483 讲述者：读MACD柱体的逐日差值速率，推算变盘时间窗口

> 来源：SRC-003678（第108课 解盘：指标差值速率推算变盘窗口）· 证据 E-2206、E-2207、E-2208
> 来源立场：课程讲述者采纳（引号内是老师原话）。笔记中"是'所想'而非'所见'"一句是编辑者的解释，不作依据。
> 底本层级：完整稿可见

一句话定义：把MACD柱体数值逐日相减。如果差值变化平滑，就假设之后几天继续按同样速率变化，由此推出"被逼选择时间周期"的时间窗口。本例推出的是两个交易日（E-2207）。

## 它解决什么问题
把"要横多久才出结果"变成可以估算的时间窗口。见 K-0484 的第一问。

## 如何识别
- 从指标见低那天开始，逐日读出柱体数值并计算差值（E-2206）。
- 目测和数值变化都比较平滑时，才能用这个前提（E-2206）。
- 用最近一天的差值推算，得到时间窗口。本例从 -22 到 -15，差 7，推出两天的窗口（E-2207）。

## 适用边界与失效
- 讲述者明说"不构成交易条件"，只是"抱着学习心态来分析"（E-2208）。
- 差值怎样才算"平滑"：原文未明确。
- 差值和天数之间的换算公式：原文未明确。
- 列出的差值里有一处与算术不符，见 E-2206 和"底本层级与疑点"。

## 与其他概念的关系
- 与 K-0034（红绿凑周期）、K-0090（标准周期）、K-0197（绿柱连放的极限）、K-0466（红柱加速度）同属MACD时间周期一类。
- 本课另有"17天是非标周期"的口述，本清单未单列证据。

## 案例与证据
上证指数 2021-03-17，见 C-0310。

# K-0484 讲述者："以盘待跌"是模糊、不负责任的说法——判断要回答四个问题

> 来源：SRC-003678（第108课）· 证据 E-2200、E-2201
> 来源立场：课程讲述者采纳。E-2200 是老师原话；E-2201 是笔记对老师"四问"的转述，原文没有加引号。
> 底本层级：完整稿可见

一句话定义：讲述者认为，"以盘待跌是一个模糊的不负责任的说法"（E-2200），因为它回答不了四个问题（E-2201）。

## 它解决什么问题
拿来检验一个行情判断是否具体、能不能落到操作上。

## 如何识别
这类判断要能回答以下四问（E-2201）：
1. 到底盘多久；
2. 盘了之后是否真的不需要跌；
3. 盘的结束特征是什么；
4. 盘的过程振幅有多大。

## 适用边界与失效
- 本课只拿"以盘待跌"这一个说法作例子。
- 能否推广到别的笼统判断：原文未明确。

## 与其他概念的关系
- 第一问"到底盘多久"，讲述者在本课用 K-0483 的差值速率去回答。
- 与 K-0045（判据必须是数字）、K-0410（带"估"带"猜"的判断不作依据）立场相近，不合并。

# K-0485 讲述者：值得关注的跳空，是超长横盘区间被向上跳空突破（横盘区间至少20—25根K）

> 来源：SRC-003679（第1090课 期货：继续整理，空单机会较多（20250304））· 证据 E-2225、E-2226、E-2227
> 来源立场：课程讲述者采纳
> 底本层级：完整稿可见

## 它解决什么问题
区分哪些缺口可以不管。本例是铁矿石空单遇到跳空（E-2225）。

## 如何识别

- 横盘区间要"起码20到25K才能构成一个结构"，只有五六根K的构不成（E-2227）。
- 横盘区间被向上跳空、突破区间高点，才需要关注（E-2226）。

## 适用边界与失效
- 原文只讲了向上跳空，不镜像到向下跳空。
- 20—25K的推导口述混乱（提到"相距23"），只采用明说的"起码20到25K"。见"底本层级与疑点"。
- 关注之后该怎么操作：原文未明确。

- 与 K-0030、K-0249（跳空缺口止损法）有关。
- 与 K-0136（本课横盘区间没有统一百分比阈值）不冲突：本卡给的是K线数量，不是幅度。
