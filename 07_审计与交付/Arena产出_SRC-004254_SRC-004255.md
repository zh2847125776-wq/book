# K-2305 两根突破阳线的对照双轴：实体长 vs 相对位置强
> 来源：SRC-004254（第1606课 股票日评：跳空上涨与10月12号对照及箱体上盖红线（20201109））· 证据 E-7974

> 底本层级：完整稿可见（笔记逐段标注"原话"）

一句话定义：比较两次站上重要均线的阳线时，一看阳线实体长短，二看K线相对均线的位置（贯穿 vs 整体站上/跳空），各有强处。

- 结论："左边的阳线实体长，右边的相对位置强，但大概这个情况差不了太多"（E-7974）。

# K-2311 颈线概念辨析：3350是下降常态前高而非颈线；颈线必须挂在"某某底"之后
