```markdown
# K-41160 突破后深蹲回踩反转修复模型与浮亏耐受容忍准则
> 来源：SRC-002948 读书_交易择时技术分析_03（增强版） · 证据：E-87900, E-87901, E-87902

### 核心概念与运作机理
在右侧突破买入策略体系中，买入后股价往往不会立即单边暴涨，而是极易出现“深蹲（Squat）”——即盘中或短期回踩洗盘产生短暂浮亏。交易者必须建立基于量价规则的深蹲评估矩阵：
1. 容忍良性浮亏与时间窗口：若价格深蹲但未触及预设刚性止损线，必须给予股票1至2周的时间与合理空间发生自然波动，避免因短期账面浮亏而盲目惊慌过早离场；
2. 反转修复之积极信号：当股票在深蹲后能够快速攻克熄火或反转日的高点并逆转回升，确立“反转修复（Reversal Recovery）”，属于极强的多头二次启动买入信号；
3. 警报堆积与果断出局：若深蹲导致收盘价格跌破20日均线且伴随成交量异常放大，表明警报堆积、胜率骤降，此时必须立即做出止损或大幅减仓决断。

### 适用场景与边界条件
- 适用场景：美股及A股成长股右侧枢纽点突破买入后的持仓观察与动态风控。
- 边界条件：未破止损线前允许正常浮亏；收盘放量跌破20日线必须无条件止损；深蹲时间不可无限拖延，以1-2周为限。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
与各周期核心均线等级律（K-41161）互为依托：日线20日均线正是判定深蹲是否演变为破坏性破位的生命线；与风险优先与开盘心智建设（K-41162）深度交织，为交易者克服浮亏麻痹与后悔恶性循环提供心理防线。

### 案例与证据
- 案例标的与时间：马克·米奈尔维尼经典交易案例解析。
- 实盘数据特征：展示了某股票在突破进场点后发生短暂深蹲产生浮亏，但因未触及止损线，随后迅速逆转回升并创出新高的完整反转修复轨迹；同时列举了放量跌破20日线后果断砍仓的对比案例。
- 逐节证据标定：放量跌破20日线警报堆积参见 E-87900，深蹲容忍与反转修复参见 E-87901，避免麻痹后悔恶性循环参见 E-87902。
```

```markdown
# K-41161 各周期核心均线等级律与日内MA60/日线MA20锚定法则
> 来源：SRC-001218 股票_20201225量化技术分析（增强版） · 证据：E-87904, E-87905

### 核心概念与运作机理
在多周期技术分析体系中，均线并非在所有时间周期上都具备相同的约束效力，而是存在严密的“周期核心均线对应规律”：
1. 日线级别核心均线为MA20：20个交易日代表一个完整的自然月，契合企业财务盘点、机构调仓考核与宏观月度资金结算周期，因此日线级别MA20是无可争议的核心趋势生命线；
2. 60分钟级别核心均线有且仅有MA60：60分钟图上的MA20仅对应日线5个交易日（一周时间），缺乏中周期指导意义，60分钟级别的真正多空分水岭有且仅有MA60（对应15个交易日的大结构）；
3. 临界微幅站上之定性：在日线收盘价微幅超越20日线时（如收盘3396.56对比MA20位于3396.07，仅微幅高出0.49点），属于形式上收盘站上，但缺乏空间摆脱，不能盲目乐观定性为趋势反转，必须配合量能综合判定。

### 适用场景与边界条件
- 适用场景：股票大盘指数及个股在60分钟与日线级别共振判断趋势支撑与反抽性质。
- 边界条件：在60分钟图上严禁将MA20作为主要多空分水岭，必须以MA60为准；日线微幅站上MA20若无放量脱离，不可确认为有效突破。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
为深蹲反转修复（K-41160）中的20日线提供了底层微观周期成立依据；与缩量假阳线量价背离（S-25710）构成研判组合拳：核心均线提供了空间坐标，量价背离提供了动能真伪判据。

### 案例与证据
- 案例标的与时间：2020年12月25日上证指数60分钟与日线收盘结构。
- 实盘数据特征：60分钟图受MA60压制；日线收盘3396.56微幅超过MA20的3396.07，虽形式上站上但仅差0.49点，缺乏成交量配合，不能盲目确立趋势反转。
- 逐节证据标定：各周期核心均线（60分MA60与日线MA20）机理参见 E-87904，微幅站上20日线判据参见 E-87905。
```

```markdown
# K-41162 风险优先原则与交易者每日自我毁灭认知与心智建设
> 来源：SRC-002948 读书_交易择时技术分析_03（增强版） · 证据：E-87903

### 核心概念与运作机理
在专业交易体系中，“风险优先（Risk-First）”构成了顶级交易者的第一底层心智模型：股票完全有潜力从A点涨到B点，但决定交易者生死的核心前提是“到达B点时你是否还留在马背上”。顶尖交易大师在每日开盘前通过极具仪式感的心理锚定（如每天早晨对着镜子提醒自己拥有强大的自我毁灭能力），将“敬畏风险”深深植入潜意识。交易者不可能完全规避市场客观风险，但可以通过“前置制定计划、标定确认信号与警示信号、将单笔风险最小化并严格受控”来扼杀自我毁灭冲动。

### 适用场景与边界条件
- 适用场景：高杠杆衍生品交易、高频股票投资以及交易者遭遇连续止损或盈利亢奋期的心态风控。
- 边界条件：开盘前必须强制完成风险边界标定；严禁无计划开仓；当警报信号出现时必须将本金保全置于获利幻想之上。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
为深蹲浮亏耐受（K-41160）提供心理基石：唯有在风险优先的前提下，交易者才能心平气和地承受良性浮亏并在触及红线时坚决止损；与量价背离防守（S-25710）形成知行合一的闭环。

### 案例与证据
- 案例标的与时间：马克·米奈尔维尼《像冠军一样思考》风险管理哲学。
- 实盘数据特征：每天早晨上班前对着镜子进行自我对话，提醒自己具有自我毁灭能力并铭记“敬畏风险”，以此建立钢铁纪律。
- 逐节证据标定：开盘心智对话与风险优先机理参见 E-87903。
```

```markdown
# S-25710 实体倍增量能萎缩之量价背离识别与节前垃圾时间防守策略
> 来源：SRC-001218 股票_20201225量化技术分析（增强版） · 证据：E-87906, E-87907

### 策略逻辑与决策流程
本策略为基于阴阳K线实体幅度、成交量反向萎缩及节假日资金休假效应的假反弹识别与防守执行体系：
1. 实体与量能背离量化检验：对比连续两日K线，若当日阳线涨幅实体显著放大（如上涨0.99%对比前日下跌0.57%，实体接近翻倍），但全市场成交量却反向严重萎缩（如从3633亿缩减至3591亿），系统明确判定该上涨为“缩量假阳线”或“量价顶背离”，表明增量资金未入场，仅仅是缩量抵抗；
2. 节假日与跨市场垃圾时间定性：结合年底或长假前夕外盘休市（如欧美圣诞假期）、国内机构结算等背景，判定市场进入流动性匮乏的“垃圾时间”，走势以弱势横向盘整为主，价格极易受到20日与60日均线压制；
3. 执行操作决策：面对此类缩量反弹，交易者严禁在次日早盘冲高或跳空高开时追买，必须前置预判冲高回落风险；已有持仓逢均线阻力减仓，耐守至有放量突破确认信号出现。

### 适用场景与边界条件
- 适用场景：A股与指数在震荡区间底部反弹但成交量萎缩、年底节前垃圾时间的操作决策。
- 边界条件：无增量成交量配合的阳线反弹一律不确认为有效反转；均线反压下严禁追涨。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
承接各周期核心均线定律（K-41161）：在均线位微幅站上却伴随量价背离时，由本策略发出卖出减仓信号；与深蹲反转修复（K-41160）形成量价真伪辨析对照。

### 案例与证据
- 案例标的与时间：2020年12月25日上证指数量价异动复盘。
- 实盘数据特征：当日上涨0.99%实体翻倍但成交量仅3591亿较前日3633亿显著萎缩，适逢圣诞外盘休市，系统断定为典型的垃圾时间缩量反抽，警告防范次日冲高回测风险。
- 逐节证据标定：实体翻倍成交量萎缩背离参见 E-87906，节前垃圾时间平淡走势参见 E-87907。
```
