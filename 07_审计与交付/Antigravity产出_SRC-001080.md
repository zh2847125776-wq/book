# K-33477 多空逆转三盏灯判定法
> 来源：SRC-001080（第课 股票_20200611量化技术分析（增强版））· 证据 E-75488
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在上升行情遇阻或出现指标顶背离时，用于客观界定多头趋势是否彻底逆转的三重技术防线判定准则（上升趋势线、形态颈线、重要均线）。

## 它解决什么问题
解决交易者在看到阻力位压制或MACD红柱连续缩短等背离迹象时，因主观恐慌而过早放空或盲目猜顶抢跑的问题；通过客观的三重支撑结构检验多方掌控状态，防止在均线多头排列中逆势做空。证据 E-75488。

## 如何识别
1. 第一盏灯（上升趋势线）：价格有效跌破前期波段低点连接形成的上升趋势斜线。证据 E-75488。
2. 第二盏灯（形态颈线）：价格有效跌破前期头部或中继形态的关键水平颈线支撑。证据 E-75488。
3. 第三盏灯（重要均线）：价格有效跌破当前周期核心均线支撑。证据 E-75488。
4. 逆转确认：只有当上升趋势线、颈线和重要均线三者均被有效击破，且均线多头排列被打破时，方可确认多空趋势彻底逆转；若三者未破，均线仍呈多头排列，属于“一盏多方”掌控状态，严禁放空。证据 E-75488。

## 适用边界与失效
适用于单边上升趋势中出现阻力位压制或指标背离时的趋势逆转判定。若仅出现局部顶背离（如红柱连续缩短），但三盏灯未破且均线系统仍呈多头排列，价格仅属于多方掌控区域内的力竭衰退修整，此时该判定法禁止任何做空动作。证据 E-75488、E-75492。

## 与其他概念的关系
- 与「顶背离化解机制」互为补充：顶背离出现后并不必然直接暴跌，若成交量持续推升可化解背离；在三盏灯未破前不得将背离作为开空信号。证据 E-75488、E-75489。
- 与「均线多头排列」互为前提：均线多头排列是多方掌控的核心标志，只要重要均线与多头排列未被破坏，三盏灯未全灭，多头格局不改。证据 E-75488。

## 案例与证据
2020年6月11日上证指数日线虽然面临上方缺口与下降趋势线压制，且MACD红柱连续缩短，但讲述者指出上升趋势线没破、重要均线没破、颈线没破，均线系统维持多头排列，属于“一盏多方”掌控区域，明确指出此时绝对不能放空。证据 E-75488。
```

# K-33478 收敛三角形有效性判据与浪区失效
> 来源：SRC-001080（第课 股票_20200611量化技术分析（增强版））· 证据 E-75490
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：收敛三角形形态必须源自明确趋势（高位或低位走出）且在尖端2/3之前完成突破，若平走或突破过晚进入浪区（NONE浪区）则形态彻底失效且不可测距。

## 它解决什么问题
解决交易者将无序横向震荡、平着走出来的收敛线，或者末端钝化震荡错误当成有效收敛三角形进行形态测距和突破跟进的误判问题。证据 E-75490。

## 如何识别
1. 趋势来源条件：收敛三角形必须是从明确的高处出来（下降趋势中收敛）或者从低处出来（上升趋势中收敛），平着震荡出来的走势不具备收敛三角形特性。证据 E-75490。
2. 突破时效限制：有效突破时间最晚应发生在三角形尖端的三分之二处。证据 E-75490。
3. 浪区判定：若运行时间过长、超过尖端三分之二尚未突破而来到尖端，即进入无意义的浪区（NONE浪区）。证据 E-75490。
4. 测距失效判定：进入浪区或平着走出的形态，只能视作两条各自独立隔开的上升趋势线与下降趋势线，严禁按照收敛三角形的理论高度进行目标测距。证据 E-75490。

## 适用边界与失效
仅适用于经典形态学中的收敛三角形识别。当形态缺乏明确的前置单边趋势、或者形态运行耗时过长延宕至顶点区域时，形态失效，不可用形态学对称测距法预测涨跌空间。证据 E-75490。

## 与其他概念的关系
- 与「收敛三角形测距」互为互斥：有效收敛三角形可根据形态高度进行突破测距，而进入浪区或平走的伪收敛三角形严禁测距。证据 E-75490。
- 与「独立趋势线支撑压力」互为对照：失效后的收敛三角形退化为两条各自独立的上升与下降趋势线，交易者仅能将其作为各自独立的支撑与压制线观察。证据 E-75490。

## 案例与证据
2020年6月11日上证指数日线上有学员提出高位是否属于收敛三角形，讲述者明确指出指数是“平着来的”，且突破时间过晚已经来到“NONE浪区”（无意义区域），因此不是收敛三角形，不需要也不得按照收敛三角形测距。证据 E-75490。
```

# K-33479 下跌取量成立条件
> 来源：SRC-001080（第课 股票_20200611量化技术分析（增强版））· 证据 E-75491
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：下跌取量是指在长期下跌行情的尾端、市场杀出极端恐慌盘时出现的主力承接放量，而非上升途中的震荡回调放量。

## 它解决什么问题
解决交易者在上升途中或震荡盘整阶段遇到单日放量调整时，误将其当作主力洗盘吸筹的“下跌取量”盲目抄底的交易误判问题。证据 E-75491。

## 如何识别
1. 发生阶段：必须发生在持续下跌行情的尾端，严禁在上升途中或高位震荡阶段套用。证据 E-75491。
2. 市场心理特征：伴随市场极端恐慌盘涌出、非理性抛售集中释放。证据 E-75491。
3. 成交量阈值：成交量必须达到足以体现主力大规模吸收恐慌筹码的特定级别，普通幅度的温和放量不算下跌取量。证据 E-75492。

## 适用边界与失效
仅适用于波段下跌末端恐慌杀跌时的筑底信号识别。在上升途中、高位盘整或突破后的回踩阶段，出现的阴线放量均不属于下跌取量，不可作为多头进场依据。证据 E-75491。

## 与其他概念的关系
- 与「上升途中力竭调整」互为对照：上升途中缩量或放量收阴属于多方动能衰退的正常技术修整，与下跌末端杀恐慌盘的下跌取量性质完全不同。证据 E-75491、E-75492。
- 与「基本量价关系」互为补充：下跌取量是特定阶段的极端形态，常规行情仍须遵循“放量收阴、缩量收阳”的基本量价重置规则。证据 E-75492。

## 案例与证据
2020年6月11日上证指数收跌0.78%且成交量微幅放大，有学员提问是否属于“下跌取量”，讲述者批驳指出指数处于上升途中而非下跌尾端，且单日成交额未达到恐慌杀跌取量的特定标准，完全不符合下跌取量定义。证据 E-75491、E-75492。
```

# K-33480 指标与股价高点的时间错位
> 来源：SRC-001080（第课 股票_20200611量化技术分析（增强版））· 证据 E-75493
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：技术指标（如周线MACD/KDJ）见顶与价格实体创出最高点在时间周期上往往不同步，通常表现为指标提前一周或数个周期见顶。

## 它解决什么问题
解决交易者机械认为“价格最高点必定对应指标最高点”的认知缺陷，防止在指标先行见顶时忽视风险，或在价格创新高而指标钝化走平时间发生重大亏损。证据 E-75493。

## 如何识别
1. 指标提前见顶：在多头运行周期的后段，辅助指标在特定周期（如前一周）达到极值并开始衰减。证据 E-75493。
2. 价格惯性冲顶：价格实体在指标见顶后的下一周期（如次周）继续放量冲高创出波段最高点。证据 E-75493。
3. 周期错位确认：股价见高点的周期与指标见高点的周期不在同一天或同一周，二者呈时间错位分布。证据 E-75493。

## 适用边界与失效
适用于大级别（如周线级别、日线级别）的波段顶部结构识别与风险预警。若市场处于超强单边趋势中持续放量推升化解背离，则指标可能随价格钝化同步刷新高点。证据 E-75489、E-75493。

## 与其他概念的关系
- 与「顶背离」互为前提：顶背离本质上正是价格高点与指标高点在幅度与时间上的不同步表现。证据 E-75489、E-75493。
- 与「周线周期推算」互为补充：结合周线下跌中继或上涨周期的推算，可提前识别指标见顶窗口并防范次周股价冲顶诱多风险。证据 E-75493。

## 案例与证据
2019年4月12日当周上证指数创出波段股价最高点（3288点附近），但技术指标的实际高点出现在前一周（2019年4月初），两者相差整整一周，成为指标与价格见顶时间错位的经典实盘范例。证据 E-75493。
```

# S-3399 次日平开5日均线手工测算法与下反预判
> 来源：SRC-001080（第课 股票_20200611量化技术分析（增强版））· 证据 E-75494、E-75495、E-75496
- 性质：局部方法
- 规则版本：原稿未明确
- 完整度分级：已给方向
- 效果证据：2020年6月11日盘后推算次日平开5日线为2937-2938点，结合左肩2942点预判反抽5日线将构成复合头肩顶。证据 E-75495、E-75496。

## 目的与适用环境
用于在价格放量跌破5日均线（50线）收阴后，提前在盘后或集合竞价推算次日5日均线的静态点位，预判次日缩量反抽（下反5日线）的压力位与复合形态结构。证据 E-75494、E-75496。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 日线放量跌破5日均线收阴后，前期均线多头排列 | E-75492、E-75494 | 仅限跌幅不大且指标仍处于多方掌控区域 |
| 形态或指标形成 | 当日放量收阴，前一日缩量收阴，短线跌破5日线 | E-75492、E-75494 | 原稿未提供放量的严格倍数阈值 |
| 确认 | 盘后手工代入前4日收盘价与当日收盘价计算次日平开5日线点位 | E-75494、E-75495 | 假设次日平开；若跳空则点位需动态修正 |
| 入场 | 原文未明确多头入场点；本方法用于反弹高抛或减仓定位 | E-75496、E-75504 | 明确指出无仓位者不适合开新仓 |
| 初始止损 | 若开盘直接大幅跳空低开击破关键均线/下轨黄线，放弃下反预期 | E-75496 | 原文未给出精确点位数字止损 |
| 仓位与资金 | 有仓位者保持随时可跑状态，禁止新开多头仓位 | E-75504 | 原文未给出具体仓位百分比 |
| 持仓与跟踪 | 跟踪次日早盘集合竞价开盘价及第1小时反弹力度 | E-75497 | 依赖开盘价验证是否出现下反5日线动作 |
| 加减仓 | 价格缩量反抽至测算出的5日线受阻时，作为高抛减仓契机 | E-75494、E-75496 | 原文未提供具体减仓手数/比例 |
| 止盈与退出 | 若价格无法站稳5日线且与左侧高点形成对称头肩形态，退出多头 | E-75496 | 原稿未明确止盈价位 |
| 失效与放弃 | 次日早盘直接跳空大幅低开击破支撑，则不反5日线，直接寻找20线支撑 | E-75496、E-75506 | 放弃5日线反抽逻辑，转入20线防守 |

## 规则之间怎样衔接
盘后根据前4日收盘价与当日收盘价（假设平开）手工计算次日5日均线静态值；次日早盘结合集合竞价校验开盘位置，若平开则跟踪其向测算出的5日线缩量回抽；若反抽到位受阻，结合60分钟级别形态（如左肩高点）确认是否构筑复合头肩顶并执行减仓。证据 E-75495、E-75496、E-75497。

## 案例和失败方式
- 案例：2020年6月11日上证指数收盘2920.90点破5日线，讲述者代入前4日收盘价（2937、2956、2943、2920）及当日2920点计算，得出次日平开5日线约为2937-2938点，与左肩2942点仅差5个点，预判次日若缩量反抽将构成复合头肩顶。证据 E-75495、E-75496。
- 失败方式：次日开盘若直接大幅跳空低开打穿关键支撑线，则走势不会出现下反5日线过程，下反复合形态预期直接落空，指数将直接寻找20日均线支撑。证据 E-75496、E-75506。

## 版本分歧与证据限制
原稿讲述者口述计算公式时出现两种表述：“今天50线减去5天前的50线再加上今天50线再除以5”与“连续4日收盘价加今日收盘价除以5”，实操中采用后者计算五日均价；原稿未提供具体的做空交易执行细节。证据 E-75494、E-75495。

# S-3400 周线缩量与阴阳线方向推算法
> 来源：SRC-001080（第课 股票_20200611量化技术分析（增强版））· 证据 E-75498、E-75499、E-75500
- 性质：局部方法
- 规则版本：原稿未明确
- 完整度分级：已给方向
- 效果证据：2020年6月11日（周四）通过周均量目标14098亿减去已成交10590亿，得出单日缺口3508亿无法补足，锁定当周必缩量收在周开盘价2941点之下。证据 E-75498、E-75499。

## 目的与适用环境
用于在交易周后半段（如周四盘后），根据周均量目标与当周累计成交额的差值，预先推断当周全周是放量还是缩量，进而判定周线能否收阳线以及周收盘价与周开盘价的相对位置。证据 E-75498、E-75499。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 交易周运行至第4个交易日（周四盘后），大级别面临均线压制 | E-75498、E-75500 | 适用于周线级别趋势与结构分析 |
| 形态或指标形成 | 当周周开盘价已确定，前4个交易日累计成交额已确定 | E-75498、E-75499 | 原稿未明确周均量基准参数来源 |
| 确认 | 计算每周均量目标值减去前4日累计成交额得出的差值 | E-75498 | 需对比前4日单日平均成交额 |
| 入场 | 原文未明确多头入场点；仅作为防范风险与持仓安全度的过滤依据 | E-75499、E-75504 | 周线缩量预期下禁止新开多头仓位 |
| 初始止损 | 原文未明确具体点位止损规则 | E-75499 | 原稿未提供精确止损参数 |
| 仓位与资金 | 保持随时可跑状态，禁止在高位盲目追涨加仓 | E-75504 | 原文未提供具体仓位比例 |
| 持仓与跟踪 | 跟踪周五实际成交量是否出现极端异常爆发 | E-75499 | 若无突发巨量则维持缩量判断 |
| 加减仓 | 在周线缩量收阴预期下，结合日线阻力择机减持多头 | E-75499、E-75504 | 原文未给出减仓比例数值 |
| 止盈与退出 | 当周线上方MA60均线方向朝下无法提供支撑且缩量时，退出多头 | E-75500 | 原文未给出确切退出价格 |
| 失效与放弃 | 若周五突发极端重大利好促使单日成交量补足均量缺口，缩量判定失效 | E-75499 | 需全天巨量成交才能逆转 |

## 规则之间怎样衔接
周初记录周开盘价与周均量目标；周四盘后累计前4日成交额，做减法得出周五成交量差额；对比前4日单日成交量水平，若差额显著超过常规单日成交量，则断定当周全周缩量；根据“周线缩量无法收阳”规律，推导周收盘价必定收在周开盘价之下。证据 E-75498、E-75499。
