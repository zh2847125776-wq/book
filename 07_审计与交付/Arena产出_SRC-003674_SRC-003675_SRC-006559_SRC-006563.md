# K-0477 讲述者：跳空缺口里没有成交的部分，不算K线实体

> 来源：SRC-003675（第1087课 期货：下返回测，关注重点长线品种即可（20250227））· 证据 E-2149、E-2150
> 来源立场：课程讲述者采纳。这是老师答疑时的原话；被否定的是学员提出的那种"凑"法。
> 底本层级：完整稿可见

一句话定义：跳空缺口中没有产生成交的那一段，不能算进K线实体；"实体有多少是多少"（E-2149）。

## 它解决什么问题
防止有人把缺口算进实体，从而把一根普通K线主观地"凑"成标志K线、突破K线或休息K线，再据此开单（E-2150）。

## 如何识别
- 缺口里没有成交的部分，不算实体（E-2149）。
- 缺口就是缺口，实体就是实体，不能主观去凑（E-2150）。

## 适用边界与失效
- 学员曾设想：把缺口算作实体，再用"休息K上限加余量"做止损来开单。老师说"这也是一个思路"，但结论仍是不能凑（E-2150）。
- 实体大小的其他判别标准：原文未明确。

## 与其他概念的关系
- 与 K-0377（标志阳线的四个条件）、K-0376（有效缺口）有关，本卡规定的是"实体"怎么算。
- 与 S-0229 出自同一段 PTA 讨论。

## 案例与证据
PTA，第1087课，合约原稿未明确。

# K-0478 书中：结束交易的三条法则（止损／bailout／反向信号）

> 来源：SRC-006559（第417课 读书：股票魔法师——何时结束交易：三条出场法则）· 证据 E-2135、E-2136、E-2137、E-2138
> 来源立场：书中作者观点。笔记说课程实际朗读的是《短线交易秘诀》第11章，书中作者的归属见"底本层级与疑点"。
> 底本层级：完整稿可见

一句话定义：书中把结束交易的方式收拢为三条：所有交易都设止损；bailout，即第一次获利就出场；出现反向信号就退出并反向交易（E-2135、E-2136、E-2137）。

## 它解决什么问题
让出场按规则执行，而不是凭情绪。原文中"不要贪心"一句本清单未单列证据。

## 如何识别
- 所有交易都采取止损，这样即使全部失败也有保护（E-2135）。
- bailout：第一次获利就出场，即使获利只有一点点（E-2136）。
- 得到反向信号时，退出交易并进行反向交易（E-2137）。

## 适用边界与失效
- 书中限定 bailout 非常适合标准普尔指数；对行动缓慢的市场，作者会推迟一两天再退出（E-2138）。这句书中原话出现在编辑的【老师点评/批判】段里。
- 止损幅度、"获利"怎么算：原文未明确。
- 老师当场插话"那不就卖飞了吗？"，并存疑留待案例。这句本清单未单列证据，不作为规则。

## 与其他概念的关系
- 与 K-0469（书中：只延长持有时间，总利润上升）的方向相反，两者都是书中内容，不作裁决。
- 与 K-0479 同章，但书中没有把两者合成一个系统。

## 案例与证据
本课没有交易数字。
