# 补充 K-0090 20220125非标41周期叠加7与9构造48和50标准周期
> 来源：SRC-000896 · 证据 E-52500

- 非标红柱计数：锰硅日线走出罕见的连续41根MACD红柱，该数字不属于斐波那契或常规对称的标准周期，必须保持高度警觉（E-52500）。

适用于单边强趋势运行后寻找对称变盘窗口；若后续由于重大产业政策干扰走出超长异常单边，则以均线跌破为准。

# K-25400 零售存货高周转率模型在股票交易中的高换手复合增长律
> 来源：SRC-003339 · 证据 E-52510
> 来源立场：书中作者观点（拉里·威廉斯与米勒维尼资金周转哲学）
> 底本层级：仅增强稿可见

一句话定义：如同零售商通过压低单件毛利但大幅提高存货周转率战胜高价精品店，高频快速的低收益短线交易在复合增长上远胜低周转大波段。

## 它解决什么问题
解决交易者迷信单笔数十倍暴利的神话，忽视资金换手率与时间复合增长巨大威力的认知盲区。

## 如何识别
- 复合增长数学实证：6次10%的复利上涨（累积达77.1%），其复合总幅度几乎是单次40%上涨的两倍；3次20%复利上涨（72.8%）亦与6次10%幅度相当（E-52510）。
- 存货周转逻辑：若投资组合周转极为迅速，交易者即便采用较低的单笔收益目标和更低胜率，亦能通过优势信号的高频重复实现惊人的年度复合回报（E-52510）。

## 适用边界与失效
建立在单笔交易具有正数学期望且交易佣金滑点极低的前提下；若交易成本过高，高周转率将被手续费彻底侵蚀。

## 与其他概念的关系
母库 K-0444 记录用平均收益倒推止损；本卡确立米勒维尼以零售高周转率类比高频小收益复合增长的策略哲学卡。
```

# K-25401 客观交易第一原则以规则为唯一解药根治贪婪与恐惧
> 来源：SRC-003339 · 证据 E-52511
> 来源立场：书中作者观点（米勒维尼心理控制与规则第一哲学）
> 底本层级：仅增强稿可见

一句话定义：交易者心态在后悔与犹豫、贪婪与恐惧之间摇摆，打击心理内耗的唯一解药是坚守客观规则，不求绝对极值只求大赚小亏并不断重复。

## 它解决什么问题
解决交易者因害怕卖早卖飞而贪婪死扛、因害怕回撤而过早平仓，陷入情感决策与精神内耗的恶性循环。

## 如何识别
- 心理摇摆根源：投资者总试图将每一分利润收入囊中，既害怕卖早错过后续暴涨，又害怕卖晚吐出既得浮盈，导致决策受制于情绪（E-52511）。
- 规则解药机制：彻底放弃以最低点买入、最高点卖出的虚妄幻想，将交易定义为“在客观规则指引下，以高于买价卖出，确保总收益大于总亏损并持续重复”的科学系统（E-52511）。

## 适用边界与失效
所有专业投资者的核心心理框架；要求系统必须具备客观明确的进出场量化触发条件。

## 与其他概念的关系
母库 K-0440 记录交易中只有四件事可直接控制；本卡确立米勒维尼以规则彻底置换情绪波动的客观交易底线卡。
```

# 补充 K-24680 股票魔法师两头堵卖半规则在大幅浮盈时锁定双赢心灵平衡
> 来源：SRC-003339 · 证据 E-52512
> 来源立场：书中作者观点（米勒维尼卖半规则与心态对冲）
> 底本层级：仅增强稿可见

一句话定义：当个股获得可观浮盈（如涨20%）面临回撤犹豫时，果断砍掉一半仓位锁定利润，剩余一半让利润奔跑，实现涨跌皆赢的心理平衡。

## 如何识别
- 浮盈锁定机制：涨幅达到平均收益两倍或止损三倍时，平掉50%仓位；已锁定的利润足以确保即使剩余仓位跌至成本平手甚至亏损10%，整笔投资依然稳赚不赔（E-52512）。
- 双赢心理平衡：卖出一半后，若股价继续冲高，交易者庆幸还持有一半；若股价掉头大跌，交易者庆幸已提前兑现一半，彻底中和遗憾情绪（E-52512）。

## 适用边界与失效
专用于大幅浮盈后的保护性持仓；卖出比例必须严格对半，卖75%会遗憾卖多，卖25%会后悔卖少。
```

## 适用边界与失效
一切交易流派的生存死线；任何行情、任何品种、任何借口下均不得违反。
```
