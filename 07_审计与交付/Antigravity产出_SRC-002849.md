# K-33990 相对强度选股与买入卖空原则
> 来源：SRC-002849（读书_专业投机原理_22（增强版））· 证据 E-93721
> 来源立场：书中作者观点
> 底本层级：仅增强稿可见

一句话定义：相对强度是个股与指数或股票群之间的比率关系，顺势买入需等待市场领导股在跌势中回档介入，顶部卖空则应选择相对强度适中的股票并严格服从移动平均线过滤。

## 它解决什么问题
解决交易者在牛市中易陷入低价心理偏好误买弱势股、在创新高时盲目追高被套，以及在顶部卖空时误空强势股导致严重亏损或误空极弱股缺乏下档空间的选股与择时失衡问题（E-93721, E-93722, E-93723）。

## 如何识别
1. 相对强度定义：通过计算单只股票与一组股票或大盘指数（如S&P 500或道琼斯指数）的比率关系建立指标，亦可通过时间加权变动率给予1~99分位数评价（E-93721）。
2. 市场领导股识别：当大盘指数（道琼斯工业指数）创出新高时，寻找在同一天或稍早也创出新高的股票，确立为相对强度最高的市场领导股（E-93722）。
3. 顺势买入形态：选定领导股后，不可在创新高时追涨，必须等待股价回档并在跌势中企稳买进（E-93722）。
4. 顶部适中做空池识别：在市场顶部附近，排除相对强度最高的强势股与下档有限的极弱势股，筛选相对强度处于中等水平的股票作为卖空标的（E-93723）。

## 适用边界与失效
1. 指标构建前提是存在有效的大盘基准指数或可比股票群，缺乏基准则比率失真（E-93721）。
2. 顶部卖空若错误选择相对强度较高的股票，一旦多头逼空未止，亏损将十分惨重（E-93723）。
3. 卖空最弱势股票将因股价已被充分压制、下档空间非常有限而缺乏盈亏比（E-93723）。
4. 出现1~3天的恐慌性暴跌走势中必须迅速获利了结，防止先前展现相对强势的买盘在低档迅速接手反弹（E-93723）。

## 与其他概念的关系
1. 与移动平均线的前提约束关系：移动平均线是绝对优先级上位规则，相对强度仅为辅助工具。若个股相对强度极高但价格低于移动平均值，坚决不考虑买进（E-93724）。
2. 与相对强度策略（S-20075）的指导关系：本知识点为 S-20075 提供底层标的池筛选与多空方向过滤依据。

## 案例与证据
道琼斯工业指数创新高时寻找同日或更早创新高的市场领导股，等待回档介入（E-93722）；市场顶部排除极强与极弱标的、卖空相对强度适中股票（E-93723）。
```

# K-33991 行情宽度与价格震荡指标系统
> 来源：SRC-002849（读书_专业投机原理_22（增强版））· 证据 E-93725
> 来源立场：书中作者观点
> 底本层级：仅增强稿可见

一句话定义：通过统计纽交所上涨下跌家数净值移动总和（行情宽度）与纽约综合指数多日收盘价差净移动总和（价格），衡量市场变动率以辅助预测行情转折的技术指标体系。

## 它解决什么问题
解决股票指数因少数高权重龙头股异常波动而掩盖整体工业类股真实走势的失真缺陷，并在中期价格趋势反转前提供基于市场变动率的先行或同步预警（E-93726）。

## 如何识别
1. 震荡指标本质：衡量市场参数在特定期间内的差值，属于重要参数变动率指标，围绕基线上下震荡（E-93725）。
2. 腾落线（A/D线）与背离识别：每日计算纽约证券交易所上涨家数减下跌家数的净值并绘图，当腾落线与道琼斯指数走势出现背离时，识别为趋势变动信号（E-93726）。
3. 短期行情宽度指标：以纽交所近10天数据为准，每天计算前一天上涨下跌净值，计算10天移动总和（E-93726, E-93727）。
4. 长期行情宽度指标：取30天为期计算A/D净值移动总和，并将计算结果除以3作为10天约当期的移动总和（E-93727）。
5. 长期价格震荡指标：以纽约综合指数每日收盘价为基准，每日计算前一天与先前第5天收盘价差值，加总近10天差值获得10天期移动总和；再以昨天的10天移动总和减去先前第10天的10天移动总和，得到5天价差的10天期净移动总和（E-93728）。

## 适用边界与失效
1. 短期震荡指标（如10天宽度震荡指标）极易发出假信号，若仅依据短期指标交易经常会“挨耳光”（E-93727）。
2. 长期宽度震荡指标转折点经常落后于中期的价格趋势，若单独据其交易无法及时掌握入场机会，仅能作为辅助工具（E-93727）。
3. 自20世纪80年代中期电脑交易程式出现以后，短期的价格震荡指标便不再有效（E-93728）。

## 与其他概念的关系
1. 互补关系：价格震荡指标在评估行情时的重要性高于行情宽度震荡指标，两者结合以确认行情转折点（E-93728）。
2. 从属关系：震荡指标仅属于辅助性确认工具，必须服从平交道警示原则（K-33992），不得替代主趋势判定。

## 案例与证据
1990年7月24日纽交所短期10天移动总和为-1118，长期30天总和除以3为-841（E-93727）；1990年8月3日纽约综合指数价格震荡指标净移动总和为-1531（E-93728）。
```

# K-33992 震荡指标平交道警示原则与KISS准则
> 来源：SRC-002849（读书_专业投机原理_22（增强版））· 证据 E-93729
> 来源立场：书中作者观点
> 底本层级：仅增强稿可见

一句话定义：震荡指标仅扮演类似铁路平交道红绿灯的风险预警辅助角色，提示趋势反转概率但无法预测危险的具体形态与发生时点，必须严格奉行简单至上的KISS交易准则。

## 它解决什么问题
解决交易者过度依赖复杂技术指标、试图单凭震荡指标超买超卖进行单边交易而导致严重亏损，以及信息过载干扰核心趋势辨识的交易执行问题（E-93729, E-93730, E-93731）。

## 如何识别
1. 极值预警识别：当震荡指标数值处于极端偏高或偏低区间，且接近或穿越先前的重要高点或低点时，识别为中期价格趋势发生反转概率极大的危险信号（E-93729）。
2. 功能定位识别：指标仅提醒交易者“是否需要谨慎行驶或全速前进”，不能提供危险具体内容与确切降临时间（E-93729）。
3. 简单原则识别：摒弃过度复杂的指标堆砌，仅采用少数几个指标以确认或否定主要趋势变动，严格执行“Keep it simple, stupid!”（KISS）原则（E-93731）。

## 适用边界与失效
1. 绝对不可脱离主趋势指标而仅凭震荡指标交易获利，一旦在趋势单边市中盲目依据指标超买超卖逆势操作，判断错误时损失往往极其严重（E-93730）。
2. 在商品期货市场中，由于个别商品价格行为常变，震荡指标可靠性远低于股票指数，必须针对特定商品重新寻找适合的均线期间（E-93740）。

## 与其他概念的关系
1. 与行情宽度和价格震荡指标（K-33991）的规范关系：为 K-33991 的具体参数应用划定风控底线，确立指标从属于趋势的地位。
2. 与趋势交易系统（S-20075）的协同关系：在 S-20075 中担任离场减速与高位防守的警示哨兵。

## 案例与证据
铁路平交道红绿灯警示比喻（E-93729）；弗兰基·乔（Frankie Joe）提出的“Keep it simple, stupid!”准则（E-93731）；商品市场中活牛期货日线采用7天与21天均线差值震荡指标进行特定拟合（E-93740）。
```

# K-33993 牛熊市消息反应定律与量化交易禁忌
> 来源：SRC-002849（读书_专业投机原理_22（增强版））· 证据 E-93732
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在牛市中再大利空也不跌、在熊市中再大利好也不涨，量化交易必须严格按照计划操作并严禁随意起性、反手做多做空与失控仓位。

## 它解决什么问题
解决交易者在大趋势与突发消息冲突时的认知迷茫，以及散户因情绪驱动冲动反手、随意加仓、违背交易计划导致反复爆仓破产的致命纪律问题（E-93732, E-93733, E-93735）。

## 如何识别
1. 牛熊消息口诀判定：在确认的牛市中，利空袭击而市场不跌；在确认的熊市中，出现增发红利等重大利好而股价拉升乏力不涨，识别为大环境主导、消息无法逆转趋势的特征（E-93732, E-93738）。
2. 冲动反手违纪行为识别：多头刚平仓立刻反手做空，或头天下午买进次日开盘因情绪波动立即卖出看空，均属于无确认的盲目反手行为（E-93733, E-93734）。
3. 量化流派大忌识别：随意起性、反手做多、反手做空、随意加大仓位、不进行仓位控制、逆势操作、不按操作计划操作（E-93735）。

## 适用边界与失效
1. 牛熊消息口诀依赖对宏观与大盘整体趋势的先验定性，若牛熊背景研判错误，口诀失效且易误判反转（E-93732）。
2. 传奇作手（如利弗莫尔）凭借直觉与盘口经验反手或许偶能获利，但对初学者而言该做法必然导致资金断崖式亏损，属于不可复制的禁忌（E-93734, E-93735）。

## 与其他概念的关系
1. 与利弗莫尔自述交易（C-21164, C-21165）的批判对立关系：讲述者将利弗莫尔刚平多即做空安纳康达定义为严重犯错，作为反面典型提倡严格量化风控（E-93733, E-93735）。
2. 与熊市反弹做空法（S-20076）的条件支持关系：为 S-20076 提供“熊市利好不涨”的做空触发逻辑与严禁随意反手的风控红线。

## 案例与证据
讲师针对美斯梅尔特增发红利提出的“牛市利空不跌，熊市利好不涨”口诀（E-93732）；利弗莫尔平仓多头后秒做空被讲师判定为犯错（E-93733）；利弗莫尔因随意操作、逆势与不控仓位多次破产的历史教训（E-93735）。
```

# S-20075 相对强度顺势回调买入与适中做空法
> 来源：SRC-002849（读书_专业投机原理_22（增强版））· 证据 E-93722
- 性质：规则完整的策略
- 规则版本：维克多·斯波朗迪相对强度交易法则（增强稿讲义版）
- 完整度分级：已给方向
- 效果证据：原文指出相对强度领先的领导股回升机会高且上涨快于其他股票（E-93722）；顶部做空适中股票在判断错误时损失不惨重、正确时利润可观（E-93723）。

## 目的与适用环境
在股票上升趋势中筛选涨速最快、确定性最高的市场领导股，等待回调介入；在市场顶部准备卖空时，规避极强股暴涨与极弱股无空间的风险，选取风险收益比最佳的中等强度标的（E-93722, E-93723）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 大盘指数处于明确上升趋势，或中期大盘已处于顶部区域 | 日线/中期趋势 | E-93722, E-93723 | 大盘趋势未明时不建仓 |
| 形态或指标形成 | 多头端：大盘创新高时，寻找同日或稍早创新高的市场领导股；空头端：筛选相对强度处于适中水平的股票池 | 日线 | E-93722, E-93723 | 原文未给出适中强度的量化阈值数字 |
| 确认 | 股价必须位于移动平均线上方；若价格低于移动平均值，即便相对强度极高也坚决不买进 | 日线 | E-93724 | 移动平均线具体周期参数原稿未明确 |
| 入场 | 多头端：禁止在创新高时追涨，必须等待回档并在跌势中买进；空头端：在顶部区域对适中股票择机卖空 | 回档企稳时点 | E-93722, E-93723 | 回档幅度与具体入场K线形态原稿未给 |
| 初始止损 | 多头以破均线或支撑位止损；空头以突破顶部防守线止损 | 入场同时 | E-93723, E-93724 | 原稿未提供具体点位或百分比参数 |
| 仓位与资金 | 严格控制仓位，遵循简单至上的KISS原则，禁止单笔重仓押注 | 建仓时 | E-93731, E-93735 | 原文未给出资金分配比例与杠杆上限 |
| 持仓与跟踪 | 以移动平均线与震荡指标持续监控趋势动能，观察指标是否触及极值区域 | 持仓全程 | E-93724, E-93729 | 原文未给动态追踪移动止损具体规则 |
| 加减仓 | 震荡指标接近或穿越极值高低点时提高警惕，谨慎调整仓位，禁止随意加码 | 持仓中 | E-93729, E-93735 | 缺具体加减仓参数 |
| 止盈与退出 | 空头持仓若遇1~3天恐慌性暴跌走势必须迅速获利了结，防止强劲买盘回抽；多头在震荡指标严重超买或价格破均线时退出 | 恐慌暴跌1~3日内 | E-93723, E-93729 | 获利了结点位原稿未给出具体公式 |
| 失效与放弃 | 多头标的跌破均线立即放弃；空头标的若展现极端相对强势立即止损平仓 | 触发失效时 | E-93723, E-93724 | 缺均线死叉或破位量化标准 |

## 规则之间怎样衔接
以大盘趋势与均线系统为一级门槛（过滤无效买点），以相对强度为二级筛选器（挑选领导股或适中做空标的），以回档跌势为三级入场触发器（杜绝追高），以恐慌暴跌1~3天与震荡指标平交道警示为退出依据。

## 案例和失败方式
道琼斯工业指数创新高时筛选市场领导股并在回档中买进（E-93722）；顶部卖空若违规选择相对强度最高股票，遭遇强庄逼空将导致惨重损失（E-93723）。

## 版本分歧与证据限制
本策略来自课件所载《专业投机原理》原文，仅给出相对强弱与均线定性规则，原稿未披露均线计算参数与具体量化止损百分比。

# S-20076 熊市反弹利用消息诱多做空法
> 来源：SRC-002849（读书_专业投机原理_22（增强版））· 证据 E-93737
- 性质：局部方法
- 规则版本：利弗莫尔经典反弹做空模式（讲师量化风控评注版）
- 完整度分级：已给方向
- 效果证据：安纳康达铜业持续大跌至秋季大崩盘，美斯梅尔特做空获利超75万美元（E-93737, E-93739）。

## 目的与适用环境
在确认的宏观熊市中，识别多头集团利用残存动能反弹或借公司利好分红拉抬诱多的破绽，逢高布局空头头寸（E-93732, E-93737, E-93738）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 宏观大环境确认为熊市，银根进一步收紧、短期利率节节攀升，大盘多数股票下跌 | 宏观/周线 | E-93732, E-93738 | 需宏观利率与流动性背景支持 |
| 形态或指标形成 | 市场经历剧烈反弹但动能衰竭，或公司在金融恐慌关口异常宣布增发额外红利哄抬股价 | 日线/反弹高点 | E-93737, E-93738 | 缺乏技术形态量化阈值 |
| 确认 | 出现“在熊市中再大的利好也不涨”的滞涨特征，或实际成交价比报价板显著偏低表明买盘虚弱 | 盘口/日线 | E-93732, E-93739 | 依赖盘口成交与报价偏差观察 |
| 入场 | 在多头反弹尽头或确认利好诱多时，分批发出卖空指令建仓 | 反弹见顶当日 | E-93737, E-93739 | 原文未给具体挂单价位算法 |
