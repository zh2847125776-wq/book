# K-32799 幅度尺测算与外轴价格密度视觉陷阱
> 来源：SRC-000320（期货投机分析20250729_多空转换_反手操作_一口气吃到饱）· 证据 E-72125
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：指交易者在软件图表上看K线与止损支撑位距离时，极易受变动的外轴价格密度视觉误导产生距离很近的错觉，必须调用画图工具中的“幅度尺”进行客观精确测量，以避免止损过大导致高杠杆爆仓的技术验证动作。

## 它解决什么问题
解决交易者仅凭肉眼主观判断K线与止损位（如红豆）的远近，因行情软件Y轴自适应缩放导致“看似两厘米实则止损空间极大”的视觉陷阱，杜绝在期货杠杆交易下因开仓止损幅度过宽而承受单笔过大亏损甚至全仓亏损的问题（E-72125, E-72142）。

## 如何识别
1. 打开行情软件自定义画线工具，在“黄金分割线组”中找到“幅度尺”工具（E-72125）。
2. 用幅度尺精确测量现价（或开仓K线）至最近红豆/绿豆止损参考点之间的实际百分比距离，绝不相信肉眼距离判断（E-72125, E-72138）。
3. 结合账户杠杆（如期货默认10倍杠杆或2倍杠杆）核算全仓风险比例，若测算幅度达到0.7%以上导致两倍杠杆全仓亏损达6%即属于止损过高，严禁开仓（E-72125, E-72133, E-72142）。
4. 止损比例处于安全范围（如纸浆测算为0.5%属于不太远）方可入场，离得太远则判定为不具备妥当入场条件（E-72125, E-72138）。

## 适用边界与失效
适用于5分钟等日内高频周期及期货杠杆交易的开仓前风控测算；当标的由于波动背景极大、价格连续大涨大跌暴拉而产生巨大技术乖离时，幅度尺必然测出极大止损，此时该标的交易机会失效，必须放弃追高、等待回调回测红豆转阳，或切换至其他未拉大距离的同板块替代品种（E-72126, E-72133, E-72136）。

## 与其他概念的关系
- 前提关系：作为 S-3081（TRP红绿豆多空转换与反手操作策略）入场动作的前置风控工具，只有幅度尺测量合格才能执行开仓（E-72125, E-72138）。
- 对照关系：与凭借肉眼“看着好像两厘米”的主观目测形成客观量化与主观臆断的对照，杜绝视错觉（E-72125）。
- 互斥关系：当幅度尺测算出止损过宽时，与顺势直接追单动作互斥，强制执行等待回测或放弃操作（E-72125, E-72126）。

## 案例与证据
在2025年7月29日焦煤5分钟走势中，行情大涨至1144上方转红豆，肉眼看距离不大，但用幅度尺测量发现若以两倍杠杆计算全仓亏损将达6%，止损太高被迫放弃多单（E-72125）；同日豆油13:40翻红但距离达到0.7%过高而放弃，转做菜油（E-72133）；纸浆测算距离为0.5%属于不太远可入场（E-72138）。
```

# K-32800 TRP红绿豆多空支撑压力识别机制
> 来源：SRC-000320（期货投机分析20250729_多空转换_反手操作_一口气吃到饱）· 证据 E-72132
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：指通过TRP指标预设算法在主图上输出红豆与绿豆两种点状信号，以点位与K线的相对上下空间位置及颜色状态，客观界定日内多空支撑与压力的量化判定机制。

## 它解决什么问题
解决交易者在盘中因K线短期剧烈波动而主观猜顶猜底、对指标计算逻辑产生怀疑乱动脑筋的问题，将复杂的动态多空判断简化为极低门槛的“颜色+上下相对位置”客观信号（E-72130, E-72132）。

## 如何识别
1. 绿豆分布在K线上方，对价格形成动态压力，表征空头状态（E-72132）。
2. 红豆分布在K线下方，对价格形成动态支撑，表征多头状态（E-72132）。
3. 识别时仅需关注红绿颜色及K线与豆点的上下相对位置，无需主观关注豆点短期朝上翘或朝下走的微观倾角（E-72132, E-72138）。
4. 指标算法已由底层固化设计，无论绿豆往上翘还是红豆往下走，均代表预设算法的客观反馈，严禁主观干预或臆测算法故障（E-72132）。

## 适用边界与失效
适用于大涨大跌的单边趋势行情或强波幅行情；在窄幅横盘震荡区间中极易钝化失真产生频繁磨损摩擦，因此趋势类指标最怕横盘区（E-72139）。

## 与其他概念的关系
- 核心组件：是策略 S-3081（TRP红绿豆多空转换与反手操作策略）的核心信号源，提供入场、减半、清仓与反手的直接视觉信号（E-72124, E-72132）。
- 补充配合：必须与 K-32799（幅度尺测算）配合使用，仅有红绿豆信号而幅度过宽时不能开仓（E-72125, E-72138）。
- 补充配合：必须受 K-32801（趋势共振原则）过滤，在大趋势空头压制下即使出现红豆多单信号亦不可开仓（E-72127）。

## 案例与证据
2025年7月29日豆粕5分钟图给出空单，后续价格触及减半与清空点位后空单离场，清完后行情上涨（E-72132）；纸浆翻红豆时虽红豆走势向下，但讲师强调光看颜色与下方支撑即可开单（E-72138）；烧碱与纯碱在红豆出现后顺势持续走高（E-72129, E-72132）。

# K-32801 趋势与交易系统信号共振过滤原则
> 来源：SRC-000320（期货投机分析20250729_多空转换_反手操作_一口气吃到饱）· 证据 E-72127
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：指交易决策必须遵循“大趋势级别在先、微观交易系统信号在后”的层级秩序，唯有大级别趋势与小级别指标信号方向完全一致呼应时才能开仓，严禁在逆大势背景下执行逆向指标信号。

## 它解决什么问题
解决交易者“见指标出信号就盲目开仓”导致的胜率低下问题，以及在看到逆势品种短期反弹上涨时产生“错过踏空”焦虑心理而违规逆势接飞刀的交易心态问题（E-72127, E-72140）。

## 如何识别
1. 开仓前必须执行“先读趋势”：研判标的所处的大级别趋势背景是多头还是空头（E-72127）。
2. 观察底层趋势形态，若标的处于“空方穿透”或高位跌破关键均线的大空头背景，趋势定性为空（E-72127, E-72140）。
3. 观察微观小周期指标或交易系统信号，只有当系统信号方向与大趋势定性互相呼应（如趋势空+指标空，或趋势多+指标多）时，信号才被激活有效（E-72127）。
4. 若趋势为空，即使小周期指标给出翻红做多信号，由于两者冲突，判定该多单开不了，必须放弃（E-72127）。

## 适用边界与失效
适用于所有跨周期、顺势交易系统的信号过滤；当全市场商品指数面临关键均线（如50日线）下方回测承压甚至正压嘴压制时，整体商品品种做多信号的寿命与胜率均面临系统性压制（E-72140）。

## 与其他概念的关系
- 前提准入：作为策略 S-3081 与 S-3082 的最高级总过滤网，拥有对微观信号的一票否决权（E-72127）。
- 对照关系：与螺纹钢、热卷、纯碱等趋势同向标的形成顺逆势对照（螺纹钢多空共振顺畅盈利，铁矿石逆势多单禁止操作）（E-72127, E-72129）。
- 互斥关系：与在空头趋势中开多单的交易行为绝对互斥（E-72127）。

## 案例与证据
2025年7月28-29日铁矿石在790.5开空，792.5减半，791.5清空；随后行情出现反弹上涨，但由于铁矿石处于“空方穿透”状态，大趋势为空，讲师明确指出交易系统虽出多单也绝对不能开，不可觉得没做到可惜；而同板块螺纹钢、热卷趋势多头互相呼应，多单做进去均顺利大赚（E-72127）。
```

# S-3081 TRP红绿豆多空转换与反手操作策略
> 来源：SRC-000320（期货投机分析20250729_多空转换_反手操作_一口气吃到饱）· 证据 E-72124
- 性质：规则完整的策略
- 规则版本：TRP 5分钟多空转换反手版（20250729）
- 完整度分级：已给方向与参数
- 效果证据：在纯碱、玻璃、PVC、聚丙烯等多品种日内实战中实现空单止盈与多单反手无缝衔接，实现“多空通吃吃到饱”，单边行情运行利索（E-72129, E-72130, E-72141）。

## 目的与适用环境
用于捕捉期货日内或短波段强单边趋势，解决空头走完转多头时犹豫不决、不敢反手或者过早平仓卖飞的交易痛点；适用于波动大、单边涨跌利索的非横盘市场（E-72124, E-72129, E-72139）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 趋势与指标呼应，非横盘震荡区间，商品指数未遇致命逆向压制 | 日线/5分钟 | E-72127, E-72139, E-72140 | 震荡市易受频繁假突破磨损 |
| 形态或指标形成 | 绿豆（空）转红豆（多），或红豆（多）转绿豆（空），且K线出现对应阳线/阴线确认 | 5分钟 | E-72124, E-72128 | 红豆初期前三根K若全为阴线需防失败 |
| 确认 | 幅度尺测量现价距离红豆/绿豆止损位在安全阈值内（如0.5%左右），无过大乖离 | 5分钟 | E-72125, E-72138 | 离豆太远（如0.7%以上）禁止入场 |
| 入场 | 刚变色下单、贴近豆下单，或在原有反向持仓清空的同时在同根K线直接反手入场 | 5分钟 | E-72124, E-72130, E-72141 | 追高或未贴近开单会放大止损 |
| 初始止损 | 以入场点对应的红豆（做多）或绿豆（做空）价位作为基准止损线 | 5分钟 | E-72125, E-72132 | 未给固定点数，动态随豆点移动 |
| 仓位与资金 | 结合品种杠杆（默认10倍）控制单笔亏损，或采用底仓+回测加仓各半的布局 | 开仓时 | E-72125, E-72142 | 杠杆过高时单笔止损不得超承受极限 |
| 持仓与跟踪 | 保持持仓，不听凭主观猜测，顺从红豆支撑或绿豆压力跟踪运行 | 持仓全程 | E-72130, E-72132 | 严禁主观恐高或猜底提前离场 |
| 加减仓 | 多单若红豆被攻破/漏了先减仓一半；若价格重新站回红豆，则接回减掉的半仓 | 5分钟实时 | E-72128, E-72130 | 仅限站回后接回，未站回不得加仓 |
| 止盈与退出 | 空单价格站上绿豆减半，变红豆清空；多单价格漏红豆减半，变绿豆全部清空 | 5分钟实时 | E-72124, E-72128, E-72141 | 遇红豆阴线空单可暂等阳线再清 |
| 失效与放弃 | 开仓后即跌破/突破豆点触发清空止损，或标的被监管公开指导（提保限仓）时放弃 | 盘中触发 | E-72126, E-72139 | 指导品种存在非技术性极端风险 |

## 规则之间怎样衔接
- 平仓与反手无缝衔接：前序空单在站上绿豆时先减半锁定利润，在指标正式翻红豆时将剩余半仓清空；清空动作完成后，在同一平仓K线立即开仓反手做多，无缝切入多头持仓（E-72124, E-72129, E-72141）。
- 动态防守与修正：做多过程中若跌破红豆减半，跌破后若再次站上红豆，立即接回半仓；若未能站回且指标翻绿豆，则清空多单并触发空头反手（E-72128, E-72130）。

## 案例和失败方式
- 成功案例：纯碱主连（20250729）空单平一半、清干净后直接反手做多，从头到尾多空双向盈利（E-72129）；聚丙烯空单减半、清空后反手做多小幅盈利（E-72141）。
- 失败方式：苯乙烯做空后减半清空产生小亏损（E-72139）；PTA持多遇红豆下漏时违背规则全清，导致直接割在最低点并错过后续大幅拉升（E-72128）。

## 版本分歧与证据限制
讲师提到部分学员对变色初期是红豆还是绿豆分不清，可通过软件风格设置修改线条颜色（如红蓝搭配）；空单清空时，遇红豆阴线究竟是立刻清空还是等阳线清空存在微调空间，原稿指出等阳线清空若遇大阳拉升则成本被拉高（E-72124, E-72131）。

# S-3082 高多低多关后整理与收敛突破操作法
> 来源：SRC-000320（期货投机分析20250729_多空转换_反手操作_一口气吃到饱）· 证据 E-72131
- 性质：局部方法
- 规则版本：高多低多均线通道整理版（20250729）
- 完整度分级：已给核心判据与A点定位
- 效果证据：在玻璃、纯碱中高多低多极度接近时走出极具爆发力的顺势拉升行情，而在铜、铝关后整理未转头前成功规避了盲目做空被套的风险（E-72126, E-72131, E-72134）。

## 目的与适用环境
用于研判价格跌破或突破高低关键多头线后的形态整理阶段，通过定位关后整理的关键A点以及等待高多线拐头，识别假突破与真启动；特别适用于高多低多距离极度收敛的低风险高赔率暴击环境（E-72131, E-72134）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 均线与通道系统呈现明确方向，标的未处于高多与扣位反向拉扯阶段 | 5分钟 | E-72134 | 扣位太低往上爬时拐头费劲 |
| 形态或指标形成 | 价格跌破高多线后展开横盘，形成“关后整理”结构，多个低点横向排列 | 5分钟 | E-72134 | 仅跌破不代表转势，仍属关后整理 |
| 确认 | 逐K分析精确定位A点：即跌破高多以后的第一个K线对应的盘整高点K线 | 5分钟 | E-72134 | 必须全员识别出唯一确定K线 |
| 入场 | 最佳入场法：等待高多线转头拐过来后，价格回到A点附近（或略高/略低）下单，攻破低多再次下单；或高多低多极度接近时顺势冲入 | 5分钟 | E-72131, E-72134 | 未拐头时贴近开空胜率不高 |
| 初始止损 | 以A点关键K线高点或收敛区间另一侧为防守止损线 | 5分钟 | E-72131, E-72134 | 原稿未给出具体点数固定值 |
| 仓位与资金 | 在高多低多距离极近时可重拳顺势出击，平时按常规杠杆防守 | 5分钟 | E-72131 | 原文未详述具体手数比例 |
| 持仓与跟踪 | 沿通道方向顺势跟踪持仓，不逆通道趋势对抗 | 持仓期间 | E-72131 | 严禁逆势扛单 |
| 加减仓 | 价格有效攻破低多线时追加开仓 | 攻破时点 | E-72134 | 必须待攻破确认 |
| 止盈与退出 | 价格重新逆向反穿高多/低多关键线，或顺势修复正负乖离率达成目标 | 盘中触发 | E-72129, E-72131 | 原文未给固定止盈点位 |
| 失效与放弃 | 价格未能在A点受阻而是直接强势站回高多上方，或高多始终无法拐头 | 实时跟踪 | E-72126, E-72134 | 无法拐头时震荡消耗，放弃操作 |

## 规则之间怎样衔接
- 关后整理与A点防守：在震荡关后整理中，先确定A点作为多空分水岭；当高多线未拐头时，即使贴近早盘均线也不急于开空，必须等待高多与低多同步转换（E-72134）。
- 收敛突破与爆发：当高多与低多两条线极度靠拢接近时，均线通道压缩到极限，此时一旦顺势突破，亏损风险极小而盈利空间巨大，与红绿豆系统同向共振（E-72129, E-72131）。
