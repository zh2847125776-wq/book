```markdown
# K-25280 书中收盘价18日均线连续两日完全脱离的圆点预兆与波动条件
> 来源：SRC-003329 · 证据 E-52203、E-52204
> 来源立场：书中作者观点（讲述者对均线拐点作补充说明）
> 底本层级：仅增强稿可见

一句话定义：价格连续两天完全处于18日收盘价移动平均线同一侧构成重要趋势变化的圆点预兆，且趋势确立须伴随价格脱离均线区域后的短期强劲波动。

## 它解决什么问题
解决单日价格瞬时刺破或触碰均线产生的虚假趋势变化信号，建立两日完全脱离并配合短期波动的过滤机制。

## 如何识别
- 圆点预兆：当价格连续两天完全处于18日收盘价均线上方即为买点预兆，连续两天完全处于均线下方即为卖点预兆，图表中出现圆点提示变化开始，随后配合短期精选信号进场（E-52203）。
- 趋势确认条件：单日刚刚超过或触碰均线不足以构成趋势转变；长期趋势变化的必要条件是价格进入均线区域后，在短期内发生强劲的单边波动（E-52204）。

## 适用边界与失效
讲述者插话说明18日均线与20日均线拐点并无实质差异，在横盘震荡中均线均会失效；原书中未量化短期强劲波动的百分比门槛。

## 与其他概念的关系
母库 K-1445 确立参数固定原则；本卡记录拉里·威廉姆斯利用18日收盘价均线及连续两天完全脱离的趋势过滤规则。
```

```markdown
# 补充 K-0397 20250411期货面对人祸与突发极端波动时尽量少掺和
> 来源：SRC-000886 · 证据 E-52210、E-52211
> 来源立场：课程讲述者采纳（事件避险风控）
> 底本层级：仅增强稿可见

一句话定义：面对由政策或突发人祸引发的无法控制的极端波动，普通交易者由于无法全天候盯盘应尽量回避少做，防范大幅利润回吐。

## 如何识别
- 当对行情没有把握、尤其是遭遇“人祸”而非普通天灾引发的突发事件冲击时，尽量少掺和、少做交易（E-52210）。
- 典型案例：纳指隔夜因突发消息单日暴涨12%，导致按技术开立的空单利润瞬间损失五分之四甚至无法止盈；若不能昼夜盯盘，极端行情极易被拉爆（E-52211）。

## 适用边界与失效
本原则侧重主观无法掌控的黑天鹅与政治事件冲击期的防守；在市场恢复平稳、技术结构重现后恢复常态化技术分析流程。
```

```markdown
# 补充 K-0539 20250411商品指数20穿60与负乖离修复带结构最好做
> 来源：SRC-000886 · 证据 E-52213、E-52214
> 来源立场：课程讲述者采纳（形态辨析与修复操作性）
> 底本层级：仅增强稿可见

## 如何识别
- 商品指数出现20日线下穿60日线的死亡交叉，但当日交叉共振收阳线展开负乖离修复；此时多空拉锯剧烈，难以判定是一日游还是持续反弹（E-52213）。

## 适用边界与失效
死叉共振收阳往往带来均线压制与技术反弹的剧烈博弈；若无右侧形态确认，不可提前假定反弹必定能触及缺口或60日线。
```

```markdown
# 补充 K-0917 20250411收K重要性与五分钟周期过滤盘中毛刺破线
> 来源：SRC-000886 · 证据 E-52215

> 底本层级：仅增强稿可见

一句话定义：五分钟周期每五分钟完成收K，只有收K才能确认真实跌破，不可因盘中瞬时刺破红线而盲目提前离场导致卖飞。

## 如何识别
- 在持仓跟踪过程中，必须严格坚持“收K”确认原则；五分钟周期的核心优势在于固定时间节点提供确定的收盘价（E-52215）。
- 盘中瞬时刺破红线或支撑线不能立刻出局，否则极易在收回后被“卖飞”；必须等待该根K线完全收盘确认破位后再行执行平仓（E-52215）。

## 适用边界与失效
本规则适用于震荡与趋势跟踪中的防毛刺误伤；但在遭遇极端闪崩或巨量破位时，仍受整体底层止损规则制约。
```
