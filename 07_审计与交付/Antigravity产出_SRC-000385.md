```markdown
# K-33713 TRP与VB双指标变色共振原理
> 来源：SRC-000385（期货_期货投机分析20251219（增强版））· 证据 E-92367
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：指交易者通过TRP色豆与VB指标的方向一致性来判断行情的顺逆状态与进场时机，以两指标刚变色且方向一致作为最高优先级进场信号，在两指标方向相左时判定为横盘并放弃开仓的过滤判据（支撑证据：E-92367、E-92368）。

## 它解决什么问题
解决震荡行情中单指标频繁发出虚假信号导致反复拉锯磨损，以及趋势大幅延伸后交易者盲目追单导致盈亏比极差、回撤过大的交易执行问题（支撑证据：E-92367、E-92370）。

## 如何识别
1. 刚变色共振识别：TRP出现颜色切换（转为红豆或绿豆）且VB指标方向同步转头（向上或向下），两系统刚变色起步阶段，判定为最高质量的试单时机（支撑证据：E-92367）。
2. 晚期状态识别：若行情已经累积了一堆绿豆或红豆，且VB指标已大幅延伸向下或向上，判定为该趋势的晚期阶段，不可再去开单追击（支撑证据：E-92367）。
3. 冲突状态识别：若TRP与VB方向相左（如VB向下但为红豆，或变绿豆但VB向上），判定市场大概率处于横盘区间，不强行开仓（支撑证据：E-92370）。
4. 单指标独立使用识别：交易者若仅看单一坐标系（纯看TRP或纯看VB），允许单指标开单，但胜率相对双指标共振略低，必须从头到尾固定模式不可来回切换（支撑证据：E-92368、E-92369）。

## 适用边界与失效
适用于单边行情展开初期的品种识别；当两指标频繁冲突、处于横盘无序震荡区间时失效，强行入场胜率极低；若已错过变色初期且指标已深度延伸累积，该信号失效且禁止顺势追单（支撑证据：E-92367、E-92370）。

## 与其他概念的关系
作为环境过滤判据，为堆顶堆底共振交易策略（S-3515）提供多空方向前提；与单指标策略构成补充与胜率提升对照关系，双指标互相参考可有效过滤假信号并避免单指标带来的潜在亏损（支撑证据：E-92368、E-92369）。

## 案例与证据
在焦煤与铁矿石行情中，当VB向下但显示红豆时，两指标意见相左形成横盘区间，强行入场极易被止损；在塑料行情中，绿豆与VB向下共振配合堆顶下降，走出顺畅单边下跌（支撑证据：E-92370、E-92372）。
```

```markdown
# K-33714 期货换月跳空缺口平复规则
> 来源：SRC-000385（期货_期货投机分析20251219（增强版））· 证据 E-92371
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：指期货主力合约轮换（如03合约换成05合约）形成的价格跳空缺口属于价格体现与合约基准切换，交易者必须等待技术指标平复60根K线周期后，方可恢复指标信号判断与交易决策的规则（支撑证据：E-92371）。

## 它解决什么问题
解决期货主力合约换月产生的机械性价差跳空导致图表比例尺失真、指标数值（如均线、振荡指标等）严重失真，进而引发分析误判和错误触发开平仓信号的问题（支撑证据：E-92371）。

## 如何识别
1. 换月缺口确认：前主力合约A（如03）换至后续合约B（如05），由于两合约绝对价格差异在连续图表上产生明显跳空缺口（支撑证据：E-92371）。
2. 指标等待期：在产生换月跳空缺口后，必须耐心等待60个K线周期，待指标系统完成跳空数据的平滑消化（支撑证据：E-92371）。
3. 恢复交易信号：60根K线运行完毕且技术指标变过来恢复正常后，方可重新依据指标发出的信号执行交易分析（支撑证据：E-92371）。

## 适用边界与失效
仅适用于国内期货品种主力合约轮换换月时段；在缺口出现后的前60根K线内指标处于失真期，一切常规技术指标发出的买卖信号均处于失效或不可信状态（支撑证据：E-92371）。

## 与其他概念的关系
作为期货图表分析的底层时间与形态过滤规则，构成执行S-3515等依赖均线或技术指标系统的前置等待约束（支撑证据：E-92371）。

## 案例与证据
PVC品种在03合约换成05合约时产生巨大跳空缺口，导致图表比例尺与价格密度失真，原稿明确指出需等待60个K线后指标变过来才能进行交易决策（支撑证据：E-92371）。
```

```markdown
# K-33715 周末防剧烈波动过夜与尾盘检视规则
> 来源：SRC-000385（期货_期货投机分析20251219（增强版））· 证据 E-92361
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：指在周五尾盘对持仓进行全面风险检视，强制平仓了结逆势不盈利头寸及周五夜盘新建头寸，并原则上周五晚不开新单，以规避周末消息面冲击引发周一隔夜跳空大幅亏损的风控纪律（支撑证据：E-92361、E-92362）。

## 它解决什么问题
解决周末不可控消息突发导致周一开盘行情剧烈跳空，持仓隔夜风险敞口暴露从而引发本金巨额亏损的交易风险控制问题（支撑证据：E-92361）。

## 如何识别
1. 周期时点识别：每周五尾盘及周五夜盘交易时段（支撑证据：E-92361、E-92362）。
2. 逆势持仓检视：周五尾盘检视所有持仓，凡属于逆势交易且处于浮动不盈利状态的头寸，必须在收盘前平仓了结（支撑证据：E-92362）。
3. 周一再接判据：平仓后若周一能够平价接回则周一再接；若顺着方向高开低开没赚到也属正常，以回避风险为核心（支撑证据：E-92362）。
4. 周五晚新单规避：周五夜盘交投相对清淡，原则上不开新单；若周五晚开单，建议当晚收盘前了结平仓，不得持仓过周末（支撑证据：E-92362）。

## 适用边界与失效
适用于期货交易中的周五尾盘与夜盘收盘时点；对于具有充分浮盈保护的顺势中长线头寸原稿未展开强制平仓要求，但明确逆势不盈利单与周五夜盘单严禁盲目过夜（支撑证据：E-92361、E-92362）。

## 与其他概念的关系
作为账户级全局出场风控纪律，强制优先于S-3515、S-3516等具体战术策略的普通技术出场条件；在周五尾盘触犯该规则时，策略的技术跟踪自动让位于资金保护清仓要求（支撑证据：E-92362）。

## 案例与证据
2025年12月19日（周五）晚间9点复盘时，讲述者开篇强调周末谨慎过夜，指出周五晚上交投清淡不建议开新单，当晚开单需当晚了结，尾盘逆势不盈利头寸必须平掉（支撑证据：E-92361、E-92362）。
```

```markdown
# S-3515 VB堆顶堆底共振交易策略（12345下单法）
> 来源：SRC-000385（期货_期货投机分析20251219（增强版））· 证据 E-92374
- 性质：规则完整的策略
- 规则版本：VB堆顶堆底双指标共振版
- 完整度分级：已给方向
- 效果证据：在塑料、橡胶、纯碱、铝等品种单边行情中实现顺畅止盈与正收益，在焦煤、铁矿石横盘相左行情中及时止损控制小亏（支撑证据：E-92372、E-92373、E-92374、E-92379）

## 目的与适用环境
在期货单边趋势发展中，利用TRP色豆与VB指标共振确定方向，通过相邻两个堆顶下降（空头）或堆底抬高（多头）捕捉趋势入场点，并依托堆顶/堆底给出具体的进场点、止损点和收K止盈出场点。适用于具备单边波动的期货品种，在横盘震荡或双指标冲突时不可使用（支撑证据：E-92372、E-92374）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | TRP显示绿豆且VB向下（做空），或TRP显示红豆且VB向上（做多），刚变色时为最佳时机 | 5分钟或60分钟周期，指标刚变色时点 | E-92367, E-92372 | 指标累积过多或两指标方向相反时严禁强行开单 |
| 形态或指标形成 | 形成连续两个堆顶下降（做空）或连续两个堆底抬高（做多） | 指标形成高低堆顶/堆底时 | E-92372, E-92378, E-92380 | 原稿未提供堆顶堆底的具体数学计算公式 |
| 确认 | 堆顶下降后从堆顶后面进行1、2、3、4、5计数，或堆底抬高后倒数第5根K线确认 | 计数达到第5根K线时 | E-92372, E-92379, E-92380 | 计数若未满足5根K线或形态被提前破坏则不成立 |
| 入场 | 做空时等出现阴线以下单，做多时等出现阳线以下单；第5根K线收K或第6根K线开盘市价下单 | 满足条件的阴线/阳线收K或下一根开盘 | E-92372, E-92379, E-92380 | 若多头阳线低点击穿前堆底，则入场条件失效作废 |
| 初始止损 | 空单止损设在近期堆顶的近高；多单止损设在近期堆底的近低 | 入场同时即刻设定 | E-92372, E-92376, E-92379 | 原稿未提供是否在近高近低外加固定点位缓冲 |
| 仓位与资金 | 依据止损空间评估接受度，止损过大不入场，止损小（如0.15%）可承担10倍杠杆下1.5%投入波动；可采用一半仓位操作波段 | 开仓决策时点 | E-92373, E-92379 | 原稿仅举例杠杆与止损比例，未提供固定资金比例公式 |
| 持仓与跟踪 | 空单持续跟踪堆顶不断下移且绿豆/VB向下未变；多单跟踪堆底持续抬升 | 持仓运行期间 | E-92372, E-92373, E-92378 | 出现反向堆顶但收K未站上其上方时保持持仓 |
| 加减仓 | 行情出现不确定或面临关键波动（如破五或疑似平水点）时，可拿出一半头寸做波段减仓 | 持仓过程中遇分歧时 | E-92373 | 原稿未提供标准的逐步加仓规则，仅提及半仓应对 |
| 止盈与退出 | 做空时观察K线收K价格站到堆顶上方即刻止盈平仓；或辅助减交指标变色出场 | K线收盘确认站上堆顶时点 | E-92372, E-92373, E-92374 | 不以固定目标位止盈，必须等待收K实体突破堆顶 |
| 失效与放弃 | 做多时候选阳线低点跌破前堆底，或堆顶已被价格提前突破，或指标冲突且止损过大时放弃开仓 | 计数完成但未满足入场约束前 | E-92380, E-92374 | 属于形态与风险提前放弃条件 |

## 规则之间怎样衔接
1. 先由TRP（红/绿豆）与VB方向完成多空环境统一过滤（E-92367、E-92372）。
2. 在同向环境下识别高低堆顶/堆底的抬高或下降（E-92372）。
3. 进行12345根K线计数，空头等待阴线、多头等待阳线确认后下单（E-92372、E-92380）。
4. 进场时严格锚定近高（空）或近低（多）设定初始止损（E-92372、E-92376）。
5. 持仓过程以K线收盘价突破反向堆顶或指标变色作为明确止盈出场指令（E-92372、E-92374）。

## 案例和失败方式
- 成功案例：塑料在绿豆与VB向下共振下，堆顶下降经12345阴线下单，近高止损从未触发，一路下跌顺畅止盈（E-92372）；橡胶堆顶下降阴线下单后持仓，收K未站上堆顶一路持有一半仓位获利（E-92373）。
- 失败方式：在焦煤、铁矿石行情中，两指标意见相左（VB向下但红豆），强行入场极易被震荡扫损（E-92370）；铝初次入场被扫损0.15%，但第二次堆底抬升重新入场扳回盈利（E-92379）。

## 版本分歧与证据限制
讲述者明确指出该系统相比于传统“三家”体系最大的优势在于具备确定的止盈价与出场价，但原稿中堆顶与堆底的具体计算公式未公开，且属于增强版笔记记录，未给出完整的自动化代码参数（支撑证据：E-92374）。
```

```markdown
# S-3516 日内开盘K线突破与波段回调交易方法
> 来源：SRC-000385（期货_期货投机分析20251219（增强版））· 证据 E-92363
- 性质：局部方法
- 规则版本：日内开盘K线突破条件单版
- 完整度分级：已给方向
- 效果证据：原稿展示白银、锡、黄金、原油多笔日内单，在震荡日均出现0.46~0.77不等的连续小额亏损，说明该方法在缺乏单边日内行情时面临磨损（支撑证据：E-92364、E-92365）

## 目的与适用环境
利用日内开盘第一根K线形态界定日内初始方向，通过突破极值或回调创极值时下达条件单（盘中价或收盘价模型）捕捉日内趋势。适用于日内具有强单边脉冲的交易日，在日内窄幅震荡、反复拉锯市况下严禁频繁开单（支撑证据：E-92363、E-92365）。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 开盘首根K线定基调：首K为阳线则默认做多、创低做空；首K为阴线则默认做空、创高做多 | 日内开盘第1根K线（如2分钟周期） | E-92363, E-92365 | 原稿未说明不同品种开盘时间差异的处理标准 |
| 形态或指标形成 | 价格创出阶段低点/高点后出现1、2、3根K线回调 | 盘中创阶段极值并回调时 | E-92363, E-92364 | 回调K线中的低点必须满足5K波段低点要求，否则不成立 |
| 确认 | 回调后价格再度跌破前低点（空单）或突破前高点（多单）触发条件单 | 跌破/突破前极值点瞬间或收盘 | E-92363, E-92365 | 盘中价模型为即时突破触发，收盘价模型需等收K确认 |
| 入场 | 预先在阶段极值点挂出条件单，以市价单成交进场 | 价格触及设定条件价位时 | E-92363, E-92365 | 实盘在快速波动下必然存在滑点拉大进场成本 |
| 初始止损 | 止损设在回调形成的5根K线近高点（做空）或近低点（做多） | 入场后立即设定 | E-92364, E-92365 | 原稿未给出额外加减跳数的具体保护垫数值 |
| 仓位与资金 | 需在开仓前评估止损空间与滑点承受度，若止损过大（如原油0.44、锡0.77）则放弃开仓 | 挂单与触发时点 | E-92364, E-92365 | 原稿未给出具体固定仓位比例或手数计算表 |
| 持仓与跟踪 | 顺势持有直至触发止损或尾盘平仓；若行情未创出新极值则不追加新单 | 日内交易时段 | E-92364, E-92365 | 原稿未说明保本移动止损的具体点位触发阈值 |
| 加减仓 | 原稿未明确提供日内突破单的加减仓规则 | 原文未提及 | E-92365 | 原稿未细化加仓机制 |
| 止盈与退出 | 日内收盘前平仓出场；或达到固定比率止盈平仓 | 日内尾盘收盘前 | E-92365, E-92366 | 临近收盘不足45分钟（如下午两点一刻后）不新开仓 |
| 失效与放弃 | 回调波段不满足5K高低点标准；或距离收盘不足45分钟（如14:15之后）；或跨品种连续两笔亏损时当天停手 | 盘中检视时点 | E-92364, E-92366 | 属于严格的风控弃单与停手纪律 |

## 规则之间怎样衔接
1. 首根K线界定多空预案方向（E-92363、E-92365）。
2. 行情创极值后等待1至3根K线回调，核验回调是否构成5K高低点（E-92363、E-92364）。
3. 设立极值突破条件单，价格突破即以市价单成交入场（E-92363）。
4. 入场后以回调高低点设定12345近高/近低止损（E-92365）。
```
