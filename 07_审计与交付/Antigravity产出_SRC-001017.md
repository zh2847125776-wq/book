```markdown
# K-32551 昏星形态（反转K线组合）
> 来源：SRC-001017（股票_20200208量化技术分析周末版（增强版））· 证据 E-70884
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：股价经历一段时间上涨后，由大阳线、跃空十字星与贯穿阴线组成的三根K线顶部反转组合形态。

## 它解决什么问题
解决在资产长期上涨后如何识别多头战局衰竭与空方逆转信号的问题，避免仅凭单根K线片面判断趋势，提供三K线组合判定趋势转向的具体判据。（证据 E-70884）

## 如何识别
1. 前置趋势与第一根K线：股价经历过一段时间的上涨，第一天收出一根较长的大阳线，代表战局一边倒向多方。（证据 E-70884）
2. 第二根K线过渡：第二天出现一根跃空（实体不相交）十字星收盘，代表多空双方短兵相接、陷入胶着。（证据 E-70884）
3. 第三根K线确认：第三天收出一根大阴线，且阴线实体贯穿第一根阳线实体，预示战局结果向空方逆转倾斜，昏星形态正式成立。（证据 E-70884、E-70885）
4. 判研原则：遵循“一个k线看多空，三个k线判趋势”的组合研判逻辑。（证据 E-70884）

## 适用边界与失效
昏星形态预示夜晚即将到来、股价即将反转走跌；但在持续创历史新高、缺乏历史采样背景的极端单边市场中，单一形态出现可能伴随震荡反复，需结合均线破位（如五穿二十）及局部指标共振评估；若第三根阴线未贯穿第一根阳线实体，则形态不成立。（证据 E-70885、E-70896）

## 与其他概念的关系
- 对照关系：与“晨星”互为镜像反转形态，晨星出现在下跌后预示黎明到来、股价走升；昏星出现在上涨后预示夜晚到来、股价走跌。（证据 E-70884）
- 前提与组合关系：与单根K线“看多空”相比，昏星遵循“三个k线判趋势”的更高层级组合逻辑。（证据 E-70884）
- 协同验证关系：与移动平均线五穿二十（MA5死叉MA20）、S2指标收阴等局部指标形成头部转折共振。（证据 E-70885）

## 案例与证据
道琼斯工业平均指数在2020年2月6日创出历史最高点29408点后，2月7日收出下跌阴线（报收29102.510点），日线与前两日K线组合构成标准的历史高位昏星形态。（证据 E-70885、E-70886）
```

```markdown
# K-32552 极弱势超卖区KDJ低位金叉的卖点属性
> 来源：SRC-001017（股票_20200208量化技术分析周末版（增强版））· 证据 E-70895
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在市场经历暴跌后的极度弱势反弹环境中，KDJ指标处于20线以下低位超卖区形成的金叉，是寻找反弹减仓高点的卖出信号，而非做多买入信号。

## 它解决什么问题
解决交易者在暴跌或弱势行情中机械遵循“指标金叉必买”教条、盲目追高抄底弱反弹而导致二次套牢的交易亏损问题。（证据 E-70895）

## 如何识别
1. 环境背景：市场处于极端大幅跳空低开或严重单边暴跌后的超跌弱反弹阶段。（证据 E-70894）
2. 指标区间：KDJ指标各数值线处于20数值线以下的低位超卖区间。（证据 E-70895）
3. 交叉动作：KDJ在20线下方形成向上交叉（低位金叉）。（证据 E-70895）
4. 信号属性定性：明确界定该金叉不是做多买点，而是反弹减仓离场的“卖点2”信号。（证据 E-70894、E-70895）

## 适用边界与失效
相同指标在不同的区间做出相同的动作具有不同含义。本规则仅适用于暴跌极弱势反弹背景，若在常态牛市震荡或强趋势回调中，20线下金叉不可机械定性为绝对卖点。原稿未给出低位金叉后反弹结束的具体数值目标点。（证据 E-70895）

## 与其他概念的关系
- 对照关系：与传统技术分析中“超卖区金叉为做多买点”的常规用法形成反直觉对照与修正。（证据 E-70895）
- 补充与衔接关系：与均线“触碰50线卖点1”构成前后呼应的分批减仓体系，低位金叉作为后续的“卖点2”。（证据 E-70894）

## 案例与证据
2020年2月3日A股上证指数大幅跳空低开逾7%后企稳弱反弹，周四反弹触及50均线构成卖点1，周五KDJ在20线下方形成金叉，被明确指示作为弱反弹中的卖点2执行卖出离场。（证据 E-70894、E-70895）
```

```markdown
# K-32553 无历史采样背景资产的交易禁忌（双向不可操作性）
> 来源：SRC-001017（股票_20200208量化技术分析周末版（增强版））· 证据 E-70887
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：当资产持续创出历史新高、缺乏上方历史成交密集区与结构形态时，技术分析无法量化计算目标价位，处于既不可盲目做多、也绝不可主观做空的交易禁区。

## 它解决什么问题
解决交易者在面对持续单边上涨且不断刷新历史新高的资产时，仅凭涨幅过大等主观“恐高”感觉逆势摸顶做空、导致连续被逼空暴亏的严重交易风险。（证据 E-70887、E-70888）

## 如何识别
1. 价格状态：资产天天创历史新高，上方没有任何历史价格成交区间作为采样参考。（证据 E-70887）
2. 形态特征：缺乏顶部结构形态与可量化的阻力位。（证据 E-70887）
3. 目标位测算缺失：没有任何有效计算方式能估计或计算出资产未来的目标价位。（证据 E-70887）
4. 操作准则成立：定性为“不论做不做多，也绝不能做空”的双向谨慎观望状态。（证据 E-70887）

## 适用边界与失效
仅适用于价格持续处于历史真空区、无历史数据作为技术分析采样背景的单边多头市场。一旦日线级别出现明确的多K线反转组合形态（如昏星）或破位结构，方可重新纳入跟踪评估。（证据 E-70885、E-70887）

## 与其他概念的关系
- 互斥关系：与主观臆测见顶、仅因“涨得太多”即逆势做空的摸顶交易行为完全互斥。（证据 E-70887、E-70888）
- 前提关系：是介入顶部反转策略（如昏星确认）前必须遵守的风险过滤前提。（证据 E-70885、E-70887）

## 案例与证据
道琼斯工业平均指数在2020年2月持续创历史新高并达29408点，此前市场各方及讲述者多次尝试看空均遭失败；此时道指宛如搭积木至百层，技术上缺乏采样背景而无法预测目标价。（证据 E-70886、E-70887、E-70888）
```

```markdown
# S-2956 极端大幅跳空低开后的等反弹分批卖出法
> 来源：SRC-001017（股票_20200208量化技术分析周末版（增强版））· 证据 E-70894
- 性质：局部方法
- 规则版本：原稿未明确（2020年2月解盘复盘版本）
- 完整度分级：已给方向
- 效果证据：2020年2月3日A股暴跌后上证指数周四反弹触及50线、周五KDJ 20线下金叉

## 目的与适用环境
应对指数或股票遭遇不可抗力突发事件出现7%以上极端跳空低开时的减仓避险问题。适用于开盘大幅跳空低开后走平、多空分歧显著的市场环境，避免开盘恐慌踩踏割肉，通过等待弱反弹捕捉卖点分批离场。（证据 E-70894）

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 指数大幅跳空低开7%左右且开盘后走平，显示多空分歧明显 | 发生极端低开当日早盘 | E-70894 | 仅限大幅低开走平形态，若持续跌停则不适用 |
| 经历恐慌杀跌后进入技术性超跌反弹周期 | 低开后数个交易日内（日线） | E-70894 | 原稿未说明反弹周期的最小K线根数 |
| 放弃开盘盲目杀跌割肉，执行“等死等反弹卖出”策略 | 低开企稳确认后 | E-70894 | 原文未给放弃持仓的具体时间上限 |
| 本方法为持仓减仓退出法，不涉及新开仓买入动作 | 反弹期间 | E-70894 | 严禁在反弹中加仓做多 |
| 原稿未明确设置硬性绝对点位止损 | 交易全程 | E-70894 | 规则缺口：未给出反弹夭折的应急止损点 |
| 原持仓分批执行撤离，未给具体每批百分比 | 卖点出现时 | E-70894 | 原文未明确两批卖点的具体仓位分配比例 |
| 耐心持有等待价格向上修复并监控关键均线与超卖指标 | 极弱反弹持续期（日线） | E-70894、E-70895 | 需承受反弹途中的波动压力 |
| 卖点1：反弹中K线首次接触50线时执行第一批卖出 | 盘中或收盘（日线） | E-70894 | 无法预知能否有效站稳50线，触碰即卖 |

| 若低开后未能走平而是持续跌停封死，则反弹假设失效 | 当日交易时段 | E-70894 | 原稿未详述跌停封死时的替代方案 |

## 规则之间怎样衔接
首先以“大幅低开走平”确立持仓等反弹策略；反弹第一阶段以价格触碰50均线作为“卖点1”执行初步减仓；随后跟踪副图KDJ指标，当其在20线极弱区间完成低位金叉时，触发“卖点2”完成剩余仓位退出。（证据 E-70894、E-70895）

## 案例和失败方式
- 成功案例：2020年2月3日A股受突发疫情影响上证指数低开逾7%，随后连续反弹，周四触及50均线触发卖点1，周五KDJ低位金叉触发卖点2，捕捉了弱反弹中的高点离场机会。（证据 E-70894、E-70895）
- 失败方式：将超卖区的KDJ低位金叉错误理解为买入做多信号而逆势追高加仓，导致在反弹终结时被深套。（证据 E-70895）

## 版本分歧与证据限制
本方法源于解盘回顾“2月3日该怎么办视频”的内容，属于增强稿口播复盘总结。原稿中未给出50线是50日移动平均线还是其他特定均线，亦未给出卖点1与卖点2的仓位拆分比例。（证据 E-70893、E-70894）
```

```markdown
在周末或非交易时段外盘（如道指）出现大跌时，利用提前开市运行的新华富时A50股指期货走势，推演A股上证指数下一个交易日的开盘跳空方向与幅度，为开盘前交易决策提供基准参考。（证据 E-70892、E-70893）

| 若A股集合竞价出现强力资金逆势承接，开盘实际低开幅度远小于推算幅度，则推演失效 | 开盘集合竞价后 | E-70892、E-70893 | 原稿未给出对冲抵消机制 |

## 规则之间怎样衔接
```
