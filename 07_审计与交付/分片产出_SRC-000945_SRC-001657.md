# 补充 K-30399 弱势市场脉冲护盘失灵与黄白线背离分化定性
> 来源：SRC-001657 · 证据 E-53960
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在空头弱势行情中主力拉抬权重指数时，加权白线飙升而代表个股真实生态的未加权黄线创区间新低并击穿横盘支撑，实证脉冲护盘失灵且对全市场个股造成严重抽血破位。

## 如何识别
- 盘中上证50与中字头突发大幅拉抬，指数加权白线直线拉起，但中小盘未加权黄线不涨反跌，跌幅持续扩大（E-53960）。
- 黄线在权重拉升过程中直接击穿前期横盘区间的多个支撑低点、创出区间新低，表明拉抬权重并未带来普涨反弹，反而是掩护出货或资金抽血的虚假繁荣（E-53960）。

## 适用边界与失效
适用于大级别下行趋势中盘中突发的权重异动定性；若全市场个股普遍放量跟涨、黄线涨幅超越白线，则护盘失灵定性失效。
```

# 补充 K-30940 首小时成交量与后续小时的估算比例
> 来源：SRC-001657 · 证据 E-53961
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：大盘全天最高成交量柱80%出现在早盘首小时（首小时成交量约为后续单小时的2倍），若下午异常放量却无法推动价格上涨反而持续阴跌，实证买盘动能衰竭与内在颓势。

## 如何识别
- 统计规律：全天最高量柱80%在开盘早段、20%在尾盘，早盘首小时成交量通常按其他单小时的2倍进行全天量能预估（E-53961）。
- 动能与形态背离：正常逻辑下真金白银放量必须推动价格上涨；若下午出现异常放量却无法拉升反而持续回落走低，即可确认量价严重背离、空头主导的颓势已然确立（E-53961）。

## 适用边界与失效
适用于上证等宽基指数日内量能节奏分析与真假放量鉴别；不适用于个股不规则的盘口成交量分布。
```

# 补充 K-31364 震荡期主观过滤磨损必然同步错失单边暴利
> 来源：SRC-000945 · 证据 E-53963
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：趋势跟踪策略在震荡磨损期的连续亏损属于必然承受的系统成本，交易者若试图通过过滤机制回避磨损订单，必然在随后爆发流畅大单边时被同步过滤而错失暴利。

## 如何识别
- 趋势策略在原油等品种震荡阶段频繁出现小额止损磨损（E-53963）。
- 交易者若主观进行磨损订单过滤，表面上减少了试错亏损，但实质上随后的单边爆发大盈利订单也必定被系统过滤掉；唯有严格坚守执行、扛过磨损，方能完整捕获后续大单边（E-53963）。

## 适用边界与失效
适用于所有趋势跟踪与通道类量化策略在震荡行情中的风控认知，严禁在磨损期主观关闭策略。
```

# 补充 K-1075 胜率太高会让开单机会变少
> 来源：SRC-000945 · 证据 E-53964
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：交易者不可盲目追求高胜率，胜率越高的策略往往因过滤条件严苛而大幅削减高盈亏比单边机会，最终总净值与年化收益率反而更低。

## 如何识别
- 讲述者以原版APL策略（如原油、螺纹钢年化180%至220%以上但胜率仅23.73%）与高胜率至真趋势策略（胜率更高但年化仅34%至35%）作量化对照（E-53964）。
- 确立“胜率越高有可能收益反而会更低”的量化规律，强调无论是程序化量化交易还是人工主观交易，核心在于大盈亏比而非单纯胜率（E-53964）。

## 适用边界与失效
适用于跨策略评估与交易心智矫正；不否定低胜率系统必须具备严格的止损控撤纪律。
```

# 补充 K-33103 异色K线挂件机制
> 来源：SRC-000945 · 证据 E-53965
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：APL等趋势策略加装异色K线挂件能够大幅减少开仓交易手数、显著削减震荡磨损次数，是压降交易成本与平滑回撤的最优挂件之一。

## 如何识别
- 在APL基础趋势策略上加载异色K挂件后，原本在震荡区间的9笔磨损单直接缩减为3笔（E-53965）。
- 挂件通过等待反向异色K线确认回调后再行入场，大幅降低交易手数，把连续无效磨损转化为极少数精准盈利单，效果显著优于思想图等其他过滤挂件（E-53965）。

## 适用边界与失效
适用于震荡偏多或交易手续费摩擦成本过高的品种；若遇极端不回踩的暴风骤雨式单边，可能推迟入场点位。
```

# 补充 K-0545 强制当日回转挂件
> 来源：SRC-000945 · 证据 E-53966
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：针对原油等隔夜容易出现剧烈高开低开跳空的品种，量化策略加装当日回转挂件执行“收盘前10分钟不开单、前5分钟清空全部头寸”的刚性风控。

## 如何识别
- 原油等外盘联动品种日内频繁跳空，隔夜持仓面临巨大的不可控缺口风险（E-53966）。
- 策略配置当日回转挂件：强制设定日内交易时段结束前倒数10分钟停止发出新开仓信号，倒数5分钟时不论盈亏立刻强制市价全平（E-53966）。
- 品种适应性：当日回转挂件在原油等跳空品种上能显著规避隔夜回撤并提升净值，但在单边延续性品种上可能因切断隔夜趋势而降低收益，需因品种特性而异（E-53966）。

## 适用边界与失效
仅适用于日内隔夜风险极高的高跳空外盘关联品种；对顺势隔夜单边延续性好的内盘品种不可盲目套用。
```
