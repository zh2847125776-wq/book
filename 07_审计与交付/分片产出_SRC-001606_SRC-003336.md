```markdown
# 补充 K-0427 读书领读股票魔法师二恶劣市场环境高波动必须缩小损失空间而非放大容忍度
> 来源：SRC-003336 · 证据 E-52420
> 来源立场：书中作者观点（马克·米勒维尼波动与风控哲学）
> 底本层级：仅增强稿可见

一句话定义：在恶劣与高波动的市场环境中，交易者必须主动收窄止损幅度以缩小损失空间，坚决反对随市场波动盲目放大亏损容忍度。

## 如何识别
- 逆向直觉陷阱：面对高波动行情，常规交易者往往误以为应当给股票更大的震荡空间；但困难时期真实胜率往往跌破50%、平均盈利萎缩，若放大止损将迅速导致期望值为负（E-52420）。
- 缩减敞口铁律：恶劣环境下必须以更严格的硬性止损或干脆放弃开仓来保护本金，若加上安全余量后潜在亏损净值过大，该笔交易坚决不予参与（E-52420）。

## 适用边界与失效
适用于系统性震荡弱市与单边下挫环境；在牛市主升浪的健康回调中，方可依常规标准配置正常容错空间。
```

```markdown
# 补充 K-0482 读书领读股票魔法师二几何级数对抗律同样二比一盈亏比小盈亏比大盈亏更赚钱
> 来源：SRC-003336 · 证据 E-52421
> 来源立场：书中作者观点（马克·米勒维尼期望值与几何非对称算法）
> 底本层级：仅增强稿可见

一句话定义：亏损在几何级数上严酷对抗交易者，在相同2比1盈亏比与40%胜率下，平均收益4%对亏损2%的十次净利润（3.63%）远高于收益42%对亏损21%（1.16%）。

## 如何识别
- 几何复利非对称：大比例亏损需要极高涨幅才能挽回（如亏50%需翻倍回本），导致大盈大亏模型在复利乘法中产生巨大的几何耗损（E-52421）。
- 数学实证对比：在40%胜率下维持2比1盈亏比，小比例组合（+4%/-2%）十次交易后资金净增3.63%，而大比例组合（+42%/-21%）由于单笔亏损净值过大，复利净利润被严重吞噬至仅剩1.16%（E-52421）。

## 适用边界与失效
指导系统化交易者严格压低单笔止损比例的绝对上限；严禁为了追逐大涨幅而按比例放大绝对止损空间。
```

```markdown
# K-25368 股票魔法师数学事实胜率低于五成严禁放大下行容忍度
> 来源：SRC-003336 · 证据 E-52422
> 来源立场：书中作者观点（马克·米勒维尼容忍度数学边界）
> 底本层级：仅增强稿可见

一句话定义：当交易胜率低于50%时，放大股票下行容忍空间在数学上必然导致账户加速灭顶，必须刚性锁定最大亏损百分比。

## 它解决什么问题
解决交易者在连续亏损或弱势行情中，由于害怕卖在黎明前而主观放宽止损线，导致单笔亏损持续失控并最终被市场淘汰的致命心理惯性。

## 如何识别
- 数学事实非主观意见：当系统平均成功率降至50%以下时，任何放大下行容忍度的行为都会在数学期望上直接推向毁灭，这是客观概率法则而非个人意见（E-52422）。
- 淘汰机制：盲目给予头寸更大呼吸空间的投资者，往往在数次深度下挫后本金腰斩被清出市场，即便股票随后反弹也早已失去留在牌桌上的资格（E-52422）。

## 适用边界与失效
属于所有交易者在低胜率周期必须严格遵守的生存铁律；若要提高盈利期望，唯一途径是放大盈亏比（如寻找1比3以上机会），绝不可放大止损。

## 与其他概念的关系
母库 K-0444 记录用平均收益倒推止损；本卡确立在低胜率困境中从数学上绝对否决放大止损容忍度的风控准则。
```

```markdown
# 补充 K-0444 读书领读股票魔法师二困难市场环境下主动收紧止损线
> 来源：SRC-003336 · 证据 E-52423
> 来源立场：书中作者观点（马克·米勒维尼动态收敛止损法）
> 底本层级：仅增强稿可见

一句话定义：在环境恶劣、跳空频发或连续受挫的困难时期，明智的做法是主动将常规止损线向下收紧（如从7%-8%降至5%-6%）。

## 如何识别
- 降档收紧机制：当观察到市场赚钱效应低迷、反向跳空缺口增多时，主动调低单笔风险敞口，常规7%至8%的止损幅度立即下调收敛至5%至6%（E-52423）。
- 动态恢复原则：收紧止损配合去杠杆降低资本暴露；唯有当市场环境好转、个人实盘胜率与盈亏比指标恢复至正常水平后，方可逐步将止损参数恢复至基准值（E-52423）。

## 适用边界与失效
专用于熊市震荡期与困难周期的防守降速；在系统性牛市顺风局中应保持标准空间以防被正常毛刺误扫。
```
