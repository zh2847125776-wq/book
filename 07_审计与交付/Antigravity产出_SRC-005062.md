# K-31788 均线先行与K线后行（均线把关原则）
> 来源：SRC-005062（第2340课 股票日评：跳空下跌耐心等待时机到来下跌惧怕下影线（20240118））· 证据 E-67589, E-67590
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在技术分析中，均线系统处于首要的把关过滤地位，任何K线与局部形态信号（如晨星、破翻、标志阴线吞没）必须服从于均线趋势与均线排列环境，均线先行、K线后行。

## 它解决什么问题
解决交易者单纯依赖裸K反转形态（如晨星结构、破翻、大阴吞没）盲目进场做多，因忽视大级别均线压制和空头环境而落入诱多陷阱、导致严重亏损的问题（E-67589）。

## 如何识别
1. 交易分析中不可随意剔除均线系统只看裸K线（E-67589）。
2. 当K线图表呈现破翻、晨星结构或大阳线吞没标志性阴线等看多形态时，必须由均线系统先行把关（E-67589, E-67590）。
3. 均线把关的关键要素包括多空线方向、均线是否处于多头排列、多空线是否拐头向上以及是否存在FVG等；若均线系统未给出多头背书，不得仅凭K线形态盲目进场（E-67590）。

## 适用边界与失效
- 适用边界：适用于股票及指数波段交易中的形态有效性检验与假信号过滤。
- 失效：若均线系统处于空头排列或整理区间被向下突破，K线反转形态极易沦为诱多陷阱；若违背均线把关强行做多，容易遭遇单边暴跌（E-67589, E-67590）。具体均线参数除多空线外原文未详列全部数值。

## 与其他概念的关系
- 与裸K交易法对立：否定了脱离均线背景的裸K反转形态独立操作价值；
- 与晨星结构、破翻：晨星与破翻属于局部K线形态，必须经由“军先行、K后行”的层级逻辑过滤；
- 与多空线/均线排列：均线系统是把关者与前提过滤网。

## 案例与证据
2024年1月18日上证指数60分钟周期在关后整理向下突破时，曾画出晨星结构、破翻与吞没标志阴线的形态陷阱，但因多空线未拐头、未呈多头排列，被均线系统成功过滤，避免了做多被套（E-67589, E-67590）。
```

# K-31789 均线发散均一性与循环演化
> 来源：SRC-005062（第2340课 股票日评：跳空下跌耐心等待时机到来下跌惧怕下影线（20240118））· 证据 E-67591, E-67592
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：均线系统在趋势发散过程中，当两条主要均线或任意均线的最大间距被其他各级均线间距普遍达到时所呈现的相对均匀发散状态，是评估发散进程是否充分的形态特征。

## 它解决什么问题
解决在单边趋势行情中主观臆测拐点或过早断定调整结束的问题，通过观察均线发散的均一程度来评估趋势发散是否充分、调整/下跌进程是否走完（E-67591, E-67592）。

## 如何识别
1. 系统中两条主要均线（或任意均线）的距离达到最大，其他相邻均线（如60到30、30到20、20到10、10到5）的间距逐步扩大到与之相近的幅度，即呈现均一性（E-67591）。
2. 均一状态形成后，行情运行不久会走向均线粘合，变得不均一（E-67591）。
3. 粘合后行情会再次发散并向新的均一性演化，直至最终完成方向转换（如转变为多头排列位置）（E-67591）。
4. 若当前各级均线间距尚未达到均匀发散状态，表明发散进程尚未结束，不可盲目判定见底（E-67592）。

## 适用边界与失效
- 适用边界：适用于日线等较大周期的均线发散趋势完整度评估。
- 失效与限制：均一性仅用于评估发散进程，不能用于精确测算底部或顶部具体点位；正负乖离率只有最小值没有最大值，不可据此逆势抄底（E-67592）。相邻均线间距偶尔存在局部不均一扰动（E-67591）。

## 与其他概念的关系
- 与均线粘合：均一性与粘合是交替循环的两个阶段（发散均一 -> 粘合不均一 -> 再次发散均一）；
- 与多头/空头排列：均一性是发散排列充分展开时的形态描述；
- 与乖离率：均一性反映了多组均线间的相对乖离均衡，但绝对乖离率没有上限。

## 案例与证据
2024年1月18日日线上证指数横盘向下突破，主要均线发散尚未完全均一，讲述者评估其均一进程“恐怕还得再有两天”，说明下跌趋势尚未到头，不可盲目抄底（E-67591, E-67592）。
```

# K-31790 AC等长对称测距的局限性
> 来源：SRC-005062（第2340课 股票日评：跳空下跌耐心等待时机到来下跌惧怕下影线（20240118））· 证据 E-67593, E-67594
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：基于传统旗形或箱体整理“一肩挑两边”假设的AC等长对称测距法仅为辅助测距工具之一，在单边急跌且调整时间未达标时极易严重失真，不具备绝对预测效力。

## 它解决什么问题
解决交易者迷信几何对称测距法、误以为下跌幅度达到与前期下跌等长（AC等长）即可安全抄底导致被深度套牢的认知误区（E-67593, E-67594）。

## 如何识别
1. 传统旗形整理假设横盘区间一肩挑两边，理论上倾向于下跌幅度与下跌时间具有对称性（E-67593）。
2. 当行情下跌速度过急（“跌的有点急”），实际下跌幅度会快速击穿AC等长理论目标位（E-67594）。
3. 当下跌幅度已超标但下跌时间明显未到达对应周期时，AC等长形态假设即告破裂（E-67594）。
4. 所有技术测距方法均不具备百分之百可靠性，不能因测距目标看似“到位”而逆势抄底（E-67594）。

## 适用边界与失效
- 适用边界：适用于箱体整理与旗形旗面突破后的常规目标位预估参考。
- 失效：在单边加速行情中必然失效；行情即使跌至所谓理论测距位，随后仍可能出现连续第5天、甚至6至8天的单边顺势运行（E-67594）。

## 与其他概念的关系
- 与旗形整理：AC等长是旗形整理的标准测距假设；
- 与单边行情：单边行情具有强动量，会彻底摧毁对称性假定；
- 与“不测底”原则：AC等长的不可靠性直接支撑了“下跌不测底”的核心纪律。

## 案例与证据
2024年1月18日上证指数下跌过程中，本波下跌起点到箱体上线跌幅为2.36%，而跌破箱体后盘中实际跌幅已达3.32%至3.6%以上，远远超出AC等长计算幅度，且下跌时间远未达到对称周期，学员提出的AC等长抄底设想被讲述者明确否定（E-67593, E-67594）。
```

# K-31791 机构操作人手有限与轮动补跌机制
> 来源：SRC-005062（第2340课 股票日评：跳空下跌耐心等待时机到来下跌惧怕下影线（20240118））· 证据 E-67595, E-67596
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在普跌或空头市场中，主力机构受限于人工盯盘、策略风控与操盘执行等物理人手约束，只能分批分批次操作不同板块，导致暂时未跌的板块呈现错位与滞后补跌。

## 它解决什么问题
解释了为什么在普跌大势中某些板块（如创业板权重、光伏、新能源）能暂时抗跌或跌幅较小，打破交易者“抗跌即强势安全”的虚假安全感（E-67595, E-67596）。

## 如何识别
1. 主力机构并非具有无限操作能力的实体，其操盘人员规模有限（如比喻为500人），无法在单日内将所有板块头寸全部出清（E-67595）。
2. 即便采用量化交易，仍需要人工进行盯盘监控、制定策略开关、设定阈值、策略调教与基础数据调整（E-67595）。
3. 操盘执行在不同交易日具有先后次序：例如今天操作大盘权重，明天操作小盘题材（E-67595）。
4. 暂时未跌或表现尚可的板块，并非基本面转好或资金护盘，仅因前期跌幅过大暂获喘息，或者“人手不够、没轮到你收拾”（E-67595, E-67596）。

## 适用边界与失效
- 适用边界：适用于全市场单边下跌或系统性流动性收缩背景下的板块分化解释。
- 失效：若机构具备近乎无限的操作人员或全自动化极速出清能力（如比喻有一万人一天全部抛完），则轮动分化消失，直接转化为全面无差别暴跌（E-67595）。

## 与其他概念的关系
- 与补跌：人手有限是产生板块先后补跌（如中小市值补跌、全A补跌）的物理微观成因；
- 与量化交易：指出量化策略背后仍存在人工干预与阈值管理的物理带宽瓶颈；
- 与风格转换：护盘时只能集中有限力量拉升权重（如银行、保险），绝不可能拉中小市值。

## 案例与证据
2024年1月18日光伏与新能源板块跌幅较小、表现凑合，讲述者指出并非板块企稳，而是因为前期跌得惨且“今天没轮到他”；讲述者以“父亲收拾兄弟，兄弟被收拾完再把你滴溜起来收拾”作比喻，强调不可盲目博弈抗跌品种（E-67595, E-67596）。
```

# K-31792 单边下跌行情不测底与左侧接飞刀禁忌
> 来源：SRC-005062（第2340课 股票日评：跳空下跌耐心等待时机到来下跌惧怕下影线（20240118））· 证据 E-67592, E-67597, E-67598, E-67605
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：当市场进入单边下跌行情且跌破原始上升趋势线时，历史参照背景即告丧失，任何基于历史低点（如2440点抬高线）的抄底均属不可靠的接飞刀行为，必须耐心等待右侧底部结构与均线粘合。

## 它解决什么问题
解决交易者在单边下跌大势中频繁猜测历史低点支撑、过早左侧接飞刀做多导致严重亏损的行为偏差（E-67597, E-67605）。

## 如何识别
1. 行情跌破原始上升趋势线，缺乏大周期有效形态背景，进入单边下跌状态（E-67597）。
2. 单边下跌中“上涨不测顶，下跌不测底”，负乖离率只有最小值没有最大值（E-67592, E-67597）。
3. 历史低点抬高线（如998、1641、1849、2440连接的下线）虽然历史上未曾被有效跌穿，但不能作为当下抄底依据，其可靠性不足（E-67605）。
4. 单边下跌确立后，必须等待行情出现第一个低点并在其右侧构筑双底、三底、漫长箱体或均线系统充分粘合，方可考虑进场，严禁左侧接飞刀（E-67598, E-67605）。

## 适用边界与失效
- 适用边界：适用于股票市场、大盘指数的单边空头下跌周期。
- 失效：在震荡市或强趋势多头市中不适用；若市场未走出充分的右侧结构就盲目抄底，前期所有的形态尝试都会以失败告终（E-67598）。

## 与其他概念的关系
- 与接飞刀：左侧依据单一点位或支撑线盲目买入即为“接飞刀”；
- 与右侧交易：强调只有等待均线粘合或多重底结构成型才是合规进场时机；
- 与乖离率：论证了负乖离率无极值是“不测底”的数理基础。

## 案例与证据
2024年1月18日上证指数单边下跌，市场讨论2440点历史连线支撑，讲述者明确指出“到了2440去抄底随他去……不可靠”，不可接飞刀，必须等均线粘合或右侧结构出现（E-67597, E-67598, E-67605）。
```

# K-31793 跌幅分布峰值迁移与恐慌出局判据
> 来源：SRC-005062（第2340课 股票日评：跳空下跌耐心等待时机到来下跌惧怕下影线（20240118））· 证据 E-67599, E-67600, E-67606
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：通过全市场个股跌幅分布区间的峰值迁移方向以及跌停个股绝对数量，量化评估市场做空动能消耗阶段与恐慌盘出局程度的盘面观察方法。

## 它解决什么问题
解决仅看指数跌幅无法看清全市场内在亏损杀伤力、无法判断做空力量是否消耗完毕与机构止损盘是否真正释放完毕的问题（E-67599, E-67600）。

## 如何识别
1. 统计全市场个股跌幅分布直方图，观察分布峰值所处的区间（如0%~3%、3%~5%、5%~10%）（E-67599）。
2. 若峰值从温和下跌区间（0%~3%）向中度下跌区间（3%~5%）甚至重度下跌区间（5%~10%）发生右移迁移，表明普跌杀伤力在加剧扩展（E-67599）。
3. 观察全市场跌停个股家数，若跌停家数过少（如仅16家），表明市场尚未打出全面恐慌盘，做空力量尚未消耗完毕（E-67600）。
4. 只有当做空力量全部消耗干净、机构与杠杆盘被迫集中止损出局时，底部才有成型可能（E-67600）。
5. 配合第一小时成交量规律，利用每日第一小时的小间隔高度预判全天成交量规模，确认是否有突破平台的大成交量配合（E-67606）。

## 适用边界与失效
- 适用边界：适用于A股全市场普跌阶段的做空动能与情绪周期监测。
- 失效：若市场处于结构性分化或指数失真行情，个股跌幅分布迁移可能出现非对称扰动；具体恐慌出清的绝对跌停家数阈值原稿未给出定论（仅指出16家太少）。

## 与其他概念的关系
- 与全A补跌：分布峰值右移是中小市值和全A补跌的具体量化体现；
- 与放量见底：恐慌盘涌出必须伴随第一小时及全天的显著放大成交量，否则属于“跌得没劲”的阴跌。

## 案例与证据
2024年1月18日盘中，全市场个股跌幅分布峰值从原来的0~3%迁移至3~5%，但跌停家数仅16家，讲述者判断“跌的确实有点多，但是跌的够多？恐怕还不太够多”，依然未能打出恐慌（E-67599, E-67600）。
```

# S-2587 均线把关形态过滤法
