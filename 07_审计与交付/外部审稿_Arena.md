# 《均线与趋势判断》样章审稿意见
五类问题在稿中都有，没有需要写「无」的类别。下面按严重性从高到低排列。
**1. 读者误解 + 概念混淆：稿子的核心买入动作「三加」从未定义，也没有登记为缺口**

- 位置：「拉回三加找买点」「按三加纪律找买点」「还向上是好三加、已经向下是坏三加」「不要用三加频繁操作」。

- 问题：

- S-0001 的「确认」一步完全依赖三加，全章却没有给出三加的条件。

- 缺口表只登记了「三加表格八大状态未转录」，没有登记「三加本身未定义」。

- 结果是一个缺口被写成了现成规则，读者会以为自己知道怎么操作。

- 建议：

- 单独登记「三加定义缺失」（或注明定义在哪一课、为什么没收进本章）。

- 在第一次出现处加括注「定义见缺口N」。

**2. 断言强于证据 + 自相矛盾：S-0001 自称多个环节「已明确」，自己的表格却标着缺口**

- 位置：章末「环境过滤、形态、确认、入场、初始止损、持仓跟踪与退出已明确」。S-0001「完整度：已明确……」。

- 问题：

- 形态：「原文未给拉回的幅度或时间阈值」，而且拉回到哪条均线也没说。

- 确认：三加未定义。

- 初始止损：N=1 口径未展开。

- 退出：「第二天那个数」没说取收盘价还是盘中价（缺口7）。

- 七个环节里至少四个带缺口，「已明确」与卡片内容冲突。

- 建议：

- 完整度改为分级写法，例如「已给出方向：环境过滤、持仓跟踪；已给名称但缺参数：形态、确认、止损、退出；缺失：仓位、加减仓」。

- 章末那句同步修改。

**3. 概念混淆 + 自相矛盾：把「价格站上20线」和「20线方向向上」混为一谈**

- 位置：「站上20线才进入选股视野」。第八节「卖点二与卖点三分别是'下反20线不过'与'下反20线站上'……都是卖」。

- 问题：

- 第二节说站上20线就进入选股视野，第八节说站上（向下的）20线也要卖。

- 两处冲突，只能靠「20线方向」这个稿中没写进一票否决条件的变量来化解。

- 「一票否决」到底看价格位置、均线方向，还是两者都看，全章没有统一。

- 建议：一票否决条件明确写成「20线方向＋价格相对位置」两个维度；如果原稿只说了「站上」，就把方向条件登记为缺口，不要自行补上。

**4. 概念混淆：「多空线」口径前后打架**

- 位置：表格「60日线：多空线、景气线」。紧接着又说「其他时间级别用'多空线'承担同样的角色」，这里指的是20线的角色。

- 问题：

- 日线上，多空线指MA60。

- 其他级别上，多空线又顶替MA20的角色。

- 同一个词指两个不同功能，读者没法确定60分钟、5分钟图上该看哪条线。第一节明确要求三个级别都判断，这里却没有口径。

- 建议：

- 分开两个术语，比如「趋势核心线」（日线=MA20）和「多空分界线」（日线=MA60）。

- 60分钟、5分钟级别各用什么线，原稿没给就登记为缺口。

**5. 断言强于证据：编者替参数矛盾打圆场，违反本书的整理原则**

- 位置：分歧3「两者可以并存（正因影响大才不应随意改），但课程未把这一层说透」。第二节「随意改动等于换了一套系统」。

- 问题：

- 登记表第2条写的是「原话并列保留，不替其圆场」，正文却给出了调和解释。

- 「随意改动等于换了一套系统」在残缺稿里是否有原话，存疑。

- 这份残缺稿只覆盖约一分钟，证据最弱，推论却写得最顺。

- 建议：

- 删掉括号内的调和句。

- 「换了一套系统」如果不是原话，要删除或标为编者推论。

- 另外统一分类：登记表把这条算作「缺口」，章末算作「分歧」。

**6. 断言强于证据 + 漏掉失效条件 + 自相矛盾：粘合「铁律」**

- 位置：「课程给了一条铁律：粘合程度越高、整理时间越长，行情爆发力度越强」。「粘合时间长等于主力吸筹时间长」。「越纠结越好，意味着趋势马上出现」。

- 问题：

- 没写方向：长期粘合同样可能向下突破。上一节刚说过「方向转换不能预判」。

- 「等于主力吸筹」默认没有派发的可能。

- 「马上出现」和「时间越长越强」相互矛盾。

- 「铁律」二字是否来自原话，需要核实。

- 建议：

- 补上「爆发方向不确定，可能向下」的失效条件。

- 「吸筹」改为「课程解读为吸筹」。

- 「铁律」如果不是原话，就删掉。

- 「马上」按原话保留，同时注明与前文的张力。

**7. 概念混淆：扣抵法的时点、变量和公式口径有多处错误**

- 位置：

- 公式一「前提是假设明日平开、明日收盘等于今日收盘」。

- 反推「得出明日开盘或收盘的最小值」。

- 用途「买前在尾盘2:50算明天20线」。

- 公式二「（前N−1天…＋今天＋今天）÷N」。

- 问题：

- SMA只用收盘价，「平开」「开盘」和均线无关，写进去会误导。

- 2:50时今日收盘价还不知道，公式里的「今日收盘」其实只能用现价估算，稿子没有说明误差。

- 公式一扣掉的是「N天前收盘价」，速率公式也写「N天前」，而两者实际扣掉的不是同一天，存在差一位的计数问题。

- 公式二列出的项数是 N−1+2 = N+1 项，和 ÷N 对不上。

- 建议：

- 删掉「平开」和「开盘」。

- 注明2:50计算用的是现价近似值。

- 用 C(t−N+1) 这类下标统一两处「N天前」的写法。

- 公式二照原稿核对，原稿本身有误就加注。

**8. 概念混淆（点数与百分比）：「速率」用的是点数**

- 位置：「速率＝（今日收盘价－N天前收盘价）÷N，等于均线每天变化的点数。速率大表示波动强」。

- 问题：用点数衡量，高价股天然「速率大」。拿它比较不同股票，或同一股票不同价位时的强弱，会失真。

- 建议：注明速率是绝对点数，只能在同一标的、相近价位内做纵向比较。原稿如果没有百分比版本，不要自行补上，只加限制说明。

**9. 自相矛盾 + 读者误解：背离的定义把所有跌破都包进去了，又和三档确认冲突**

- 位置：「本该提供支撑而股价在均线下方……只要均线不能起到相应作用，就叫背离……多方应观望、空方继续卖出」。

- 问题：

- 按这个定义，任何跌破当天就已经是背离，应该观望或卖出。

- 第八节却说默认等第二天「下反回测」。两套规则在同一时点给出不同动作。

- 「空方继续卖出」读起来像一条独立的卖出信号。

- 建议：写清背离判定和三档确认谁优先、适用于哪条均线。「空方继续卖出」注明是课程原话，不是本方法的做空规则（S-0001已写明只做多）。

**10. 自相矛盾：格兰碧买点三的表述自我否定**

- 位置：「均线向下的情况下，站上均线依然不可买进持有，只能等站回均线再按三加纪律买」。

- 问题：

- 「站上」和「站回」字面上是同一个动作，读者无法区分。

- 「买点三＝四浪低点附近」的编号和常见版本的格兰碧八法不一定一致，没有注明这是课程自己的编号。

- 建议：按原稿写清差别，例如是不是「等20线转向上后再站回」。另注「编号依课程版本」。

**11. 自相矛盾 + 无法执行：斜率的数值不可能成立，也无法复现**

- 位置：「合值已经七八百度、接近七八十度才去买」。「大于60°单边推进……」。「用两脚器量出」。

- 问题：

- 5条线每条都小于90°，合值最多450°，不可能到「七八百度」。

- 角度取决于图表的纵横比例，没有固定坐标比例时分档无法复现。

- 空头排列下斜率为负，「斜率再'强'」没有意义，正负号约定也没写。

- 建议：

- 核对原话，可能是「七八十度的均值」之类的误记。

- 把「坐标比例未规定」「符号约定未规定」登记为缺口。

- 「两脚器」疑为「量角器」，需要订正。

**12. 逻辑问题 + 口径缺失：「多头排列中的金叉」**

- 位置：「多头排列中的金叉正向信号更强……多头排列中的死叉可能只是短线调整」。

- 问题：

- 严格的多头排列下，短期均线本来就在长期均线上方，不会再发生金叉。这个说法要么指排列正在形成的过程，要么指别的均线组合。

- 通篇没说金叉、死叉指哪两条线交叉（5/10？5/20？）。机理里又扯到「看20线的长线持有者」，口径更乱。

- 建议：写明是哪两条线交叉；原稿没说就登记为缺口。「多头排列中」改成原稿的准确说法。

**13. 自相矛盾：「未跨课综合」的声明和证据来源对不上，案例也标错了**

- 位置：

- 「本章所有条件均来自课程均线系列内部（第04、05、10、32、53课）」。

- WMA 的2020年4月案例没有登记为案例。

- 建议：

- 补全课次清单。

- C-0001 改标为「环境读数示例，与本方法无直接对应」。

**14. 自相矛盾：适应性均线既在用，又被弃用**

**16. 读者误解 + 自相矛盾：江恩八分等的仓位算术不通**

- 位置：「站上1/8买1成、2/8加2成，8/8满仓且留2成机动」。

- 建议：核对原话，确认是累计仓位还是逐档加仓，并注明这条只适用于江恩八分系统，不能移植到 S-0001。

**17. 自相矛盾 + 读者误解：斐波那契变盘点**

- 位置：「四个以上则明天是变盘点……只能倒推不可正推」。

**18. 自相矛盾：粘合期「画箱体做」和其他规则冲突**

- 问题：股价在20线下方做箱体，违反20线一票否决。S-0001又说不参与。三处口径互相冲突。

- 建议：注明箱体做法是课程给的「不推荐的替代做法」，不适用一票否决的原因原稿有没有说明；没有说明就登记为缺口。

**19. 漏掉失效条件 + 读者误解：退出规则的判定细节和优先级都缺**

- 「20线走降」和「有效跌破」两套退出规则，哪个优先没说。

- 建议：以上几点逐一登记为缺口，并写明两套退出规则按原稿各自适用的场景。

**20. 读者误解 + 口径混淆：「不看」的线后面又被拿来用**

**21. 读者误解：粘合突破部分的示例容易被当成阈值，关键动作也没定义**

- 位置：「例如1亿到2亿到4亿到8亿，或1到1.2到1.5到1.8到2.2」。「大幅放量突破一年半新高；突破后回测买，突破失败卖出止损」。

**22. 断言强于证据 + 读者误解：鸭嘴**

**23. 断言强于证据：「唯一」这类绝对化用词**

**30. 概念混淆（小问题）：「交叉共振」的命名**

**最可能误导读者的一条**
是 S-0001 被包装成「环节已明确」的可执行方法（第2条），而它的核心动作「三加」从未定义（第1条）。
读者看到的是一张完整的表：环境过滤、确认、入场、止损、退出一应俱全，还写了尾盘2:50这样精确的时点。他们会直接拿去下单。实际上，确认靠的三加、止损靠的 N=1、拉回的幅度、退出取哪个价，全部没有定义。这正是「把缺口当成规则」。
