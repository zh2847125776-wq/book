# 补充 K-30058 早盘浮亏断言限于盘中点评不等全体成交事实
> 来源：SRC-001595 · 证据 E-52100、E-52101、E-52102
> 来源立场：课程讲述者采纳（对早盘追涨的批评，非账户统计）
> 底本层级：仅增强稿可见

一句话定义：本课在13点40左右回顾早盘冲高回落；“任何早盘开单都浮亏”是讲述者的概括，不是逐笔核对后的全体交易结果。

## 它解决什么问题
母卡标题中的“开盘八法被证伪”容易被读成已严格检验完整方法，正文“避免浮亏”也容易被当作全体订单的既成结果。本补充限定证据强度。

## 如何识别
1. 录制开场明确说2022年8月16日1点40（E-52100），并非收盘后统计；“没有带来全天的拉升”须理解为此时的盘中点评，不能补写最终收盘。
2. 所讨论的开盘八法仅由讲述者大概转述，含“还是怎么怎么之类的”“我大概也读了读”（E-52101）；未给出原方法全部分类、适用条件与样本。
3. 原声同时给开盘约2725、当前约2730，然后概括早盘开单都浮亏（E-52102）。当前指数仍高于开盘这一组近似数值，已不足以证明所有早盘价位入场都浮亏；更没有ETF逐笔入场价、手续费或账户记录。

## 适用边界与失效
本例可说明早盘冲高不保证持续走强、不要临时追价破坏自己的计划；不能由此推导所有早盘交易均亏损，或把某一日盘中反例当作完整开盘八法的统计检验。不替讲述者虚构回测，也不取消具体系统另有早盘入场规则的可能性。
```

# 补充 K-30060 日线交叉所报2704由OCR支持为MA5而非MA50

## 当时已知信息
母卡以20426作标题“近低止损”，又记口述算出20306，并已提示算法矛盾。本次同节OCR直接标沪铝主连5分钟APL（E-52111），不采用Vision的“沪镍”识别。

原声从20426去尾位成为2042，再说“减30应该是2030”，再加回6（E-52110）。这段算式本身不成立，20426应先标为计算所用近低基准，与拟留余量后的最终保护价区分；不能同时把它当作精确可执行的最终止损价。20306仍是母卡所保留的口述结果，不据此反算实际余量或擅自修正算式。

## 后续过程与结果
讲述者提及价格跌到20330，并说所讨论保护当时未触发；另以“要是破中轨”提出平掉多头的条件性安排（E-52112）。这不是已经发生的平仓成交，也不能把盘中触及近低基准与另一套中轨退出混作同一触发。

## 本例说明的边界
原声要求挂市价单，并明确不知道具体成交位置（E-52113）。“保证成交”“也不亏损”属于讲述者的执行期待，不是本材料已验证的流动性、成交价或账户盈亏保证。没有交易所订单类型细节、委托日志及滑点数据，不能将这段话改造成无条件保证成交且保本的规则。

## 数字与证据
20426、2042、减30、2030、加回6按转录顺序保留，[原稿如此，疑误]。20330由原声与盘口最低价同向支持；本补充不把近低基准、加余量保护位、中轨或实际成交价互相替代。
```

## 底本层级与疑点

- 根代理本地逐窗完整阅读两份增强稿：股票2090行、期货4144行，每窗不超过180行；无子代理或外部软件代读。全文阅读增强稿不等于独立听看完整原视频。证据仅取语音转录或OCR连续子串。
- 股票的60分钟30/36/48时间窗口、12小时调整、明日平开穿轴、红柱首次缩短时间与C浪方向均是课堂条件推演，不是未来已确认结果；末段“暴跌不可能”不视为保证。206/207所指创50ETF报价的小数单位没有自行补定。十元至九块八为假设，不建实盘收益案例。
- 股票MA5对校有直接OCR，Vision关于上汽、创业板代码399001、SAR信号等猜测均不取。上证3308突破前仍在下降常态，局部上升趋势线不自动反转大结构。指数环境与个股20大于60的筛选分别保留，已有卡覆盖，不重复造卡。
- 期货高风险跳空讨论含“不开单旁观”与参与方式两种选择；5750开盘、5765保护是假设且承认滑点不可控，不能依Vision误写成5750买入5765止盈。两手/偶数手供减半退出讨论，不是固定资金适用规则；“只有这一种方法”是讲述者强说法，未作全面方法比较。
- 期货沪铝转录2042减30等算式保留疑误，不反推余量；Vision错认沪镍、沪铅为沪锡、沥青为游资主连以及5分钟误作1或15分钟均不作为证据。主连图示不是可成交合约。螺纹、烧碱、沥青、尿素/生猪等多周期候选与保护不同，不串成真实账户交易链。
- 清明前清仓为2025年4月3日本课安排；没有夜盘与外盘仍交易只作当时讲述，不当现行交易日历。最后股票指数3314与3319为课堂支撑/盘中读数，应等收盘的要求不能替代最终结果。节选截图与前后30秒语音跨品种时按语义和OCR交叉辨认，不将字幕邻接当同品种证据。
