K-31366 股票四不买原则与大市值初筛指标池构建

来源：SRC-002730（读书_10聪明的投资者（增强版））· 证据 E-66002, E-66003
来源立场：课程讲述者采纳
底本层级：仅增强稿可见

一句话定义：在股票交易前必须建立硬性前置过滤门槛，严格执行“非新股非次新股、非ST股、非亏损股、流通市值大于100亿”的四不买标准，将全市场数千只标的精简为高流动性优质候选池。

它解决什么问题

解决交易者在全市场4000多只股票中盲目选股、频繁遭遇小盘庄股技术指标失灵、以及踩中劣质亏损股突发减持黑天鹅等恶性风险。

如何识别
剔除新股与次新股：新发行股票缺少历史走势沉淀与充分博弈，坚决不作为常规技术交易标的（E-66002）。
剔除ST与亏损股：F10只需关注净利润非负数、不亏损、市盈率（原稿作适应率 [原稿如此，疑误]）不畸高，排除潜在退市暴雷股（E-66002, E-66003）。
锁定流通市值>100亿：只在流通市值（或总市值）大于100亿元的容量标的中选股，确保技术分析（如站上20日线回测）具备充足流动性支持（E-66002, E-66008）。
适用边界与失效
适用环境：A股股票现货市场的选股初筛与底池构建。
限制：若遇到极端单边微盘股投机炒作行情，大市值策略在短期弹性上可能相对落后。
与其他概念的关系
为大市值非ST盈利标的四不买初筛操作法（S-2394）提供顶层规则支撑。
案例与证据
A股全市场3753只非新股中筛选出907只市值大于100亿的非ST盈利池（E-66002）。
K-31367 成长股分散化投资未能跑赢基准指数规律

来源：SRC-002730（读书_10聪明的投资者（增强版））· 证据 E-66004
来源立场：书中作者观点
底本层级：仅增强稿可见

一句话定义：格雷厄姆与历史权威数据证明，单纯对成长型公司股票进行分散化投资组合，在长期统计上并不能带来显著超越基准指数的回报，多数专业机构业绩反而落后于大盘。

它解决什么问题

打破交易者对“买入一篮子成长股就能轻松躺赢大盘”的盲目迷信，确立择时与趋势交易的必要性认知。

如何识别
美股历史统计：美股126家成长型基金中，绝大多数长期业绩均不如标普500和道琼斯指数（E-66004）。
A股现实印证：2020年A股7000多个公募基金中，有90%的产品无法跑赢创业板指当年64.96%的涨幅（E-66004, E-66011, E-66012）。
分散化未能增效：与普通指数化投资相比，盲目分散购买多只成长股无法获得显著优异的超额阿尔法收益（E-66004）。
适用边界与失效
适用环境：基金组合评估与成长股长期配置策略分析。
限制：若极度集中持有单只超级核心总龙头（如特斯拉、宁德时代等），可能获得阶段性超额收益，但伴随极高个股风险。
与其他概念的关系
阐明了从宏观被动分散转向精细化技术择时的重要性。
案例与证据
1961-1970年美股成长基金统计与2020年国内公募基金跑输创业板指案例（E-66004, E-66011）。
K-31368 预期提前兑现机制与利好变利空/利空出尽反转

来源：SRC-002730（读书_10聪明的投资者（增强版））· 证据 E-66005, E-66006
来源立场：课程讲述者采纳
底本层级：仅增强稿可见

一句话定义：股票市场价格往往提前反映并透支利好或利空预期；当重大利好正式落地时极易形成“利好兑现变利空”的高位暴跌，而当重大利空消息完全披露并被市场消化后，股价往往展开“利空出尽”的强劲反弹。

它解决什么问题

解决交易者在媒体公开报道重大利好时冲动追高被套在山顶，或在突发重大利空恐慌杀跌割肉在最低点的人性误区。

如何识别
利好透支引发暴跌：股价在利好公布前已翻倍透支预期，利好一旦正式落地或稍不及预期，即刻引发多杀多暴跌（如南北车合并兑现变利空）（E-66005）。
利空完全兑现展开反转：重大利空消息（如被减持、负面曝光、退市预期等）在盘面充分下跌宣泄后，消息落地次日往往收出十字星或连续大阳线反弹（E-66006）。
消息滞后与盘面先行：必须以价格的技术波动与真实承接为第一准绳，绝不根据公开新闻消息做反向追随（E-66005, E-66006）。
适用边界与失效
适用环境：事件驱动型交易、重组并购、财报与重大消息落地前后的多空博弈。
失效环境：若利空属于不可逆的毁灭性造假暴雷，股价可能连续一字跌停无反弹机会。
与其他概念的关系
呼应了价格波动核心论（K-31349），揭示了基本面消息滞后于价格波动的博弈本质。
案例与证据
中国南北车合并兑现后股价见顶暴跌案例，以及南极电商贴牌利空曝光后第3天大涨8%的反弹案例（E-66005, E-66006, E-66009, E-66010）。

C-3179 中国南北车合并利好兑现变利空暴跌案例

来源：SRC-002730（读书_10聪明的投资者（增强版））· 证据 E-66009
日期、品种、合约、周期、关联方法ID、来源ID：2015年5-6月、中国南车/中国北车/中国中车（601766）、不适用、日线与周线周期、关联方法 K-31368、来源 SRC-002730
证据性质：作者自述交易 / 有独立记录

当时已知信息
2015年牛市期间，市场盛传中国南车与中国北车重组合并为“中国中车”的超级国家战略利好，股价此前已连续暴涨数倍，充分透支合并预期。
原计划与触发
预期驱动：市场普遍认为合并重组落地后将进一步打开海外高端制造空间。
触发节点：中国中车正式完成合并复牌上市，重大利好正式完全兑现。
后续过程与结果
合并利好落地当天即成为历史最高见顶之日，股价随后上演天地板瀑布式暴跌，从最高近40元一路阴跌，利好彻底演变为灭顶之灾式的利空暴跌。
本例说明的边界

极其生动地验证了“利好兑现变利空”的市场运行本质，证明在重大利好正式落地前后必须高度防范多头一致性踩踏风险。

数字与证据
标的名称：中国中车（南北车合并）（E-66009）。
走势特征：利好预期兑现后暴跌（E-66009）。
C-3180 南极电商贴牌利空消息完全兑现后反弹案例

来源：SRC-002730（读书_10聪明的投资者（增强版））· 证据 E-66010
日期、品种、合约、周期、关联方法ID、来源ID：2021年1月初、南极电商（002127）、不适用、日线周期、关联方法 K-31368、来源 SRC-002730
证据性质：作者自述交易 / 有独立记录

当时已知信息
南极电商因“贴牌内衣不筛选”等严重财务与商业模式负面新闻曝光，引发市场舆论集中声讨，股价连续遭遇恐慌性暴跌。
原计划与触发
识别利空完全宣泄节点：在全网舆论最激烈的负面声讨落地当天，股价探底并收出企稳十字星，判定极端利空消息已完全被盘面价格消化。
后续过程与结果
舆论抨击落地后次日收出十字星，第3天盘中直接大涨 8%，第4天继续上涨 2%，利空出尽后股价迅速展开报复性技术反弹。
本例说明的边界

展示了非毁灭性利空消息在盘面连续暴跌完全兑现后，极易出现短期情绪超跌反弹的博弈规律。

数字与证据
利空后第2天走势：收十字星（E-66010）。
利空后第3天涨幅：大涨 8%（E-66010）。
利空后第4天涨幅：上涨 2%（E-66010）。
C-3181 2020年公募基金90%未能跑赢创业板指案例

来源：SRC-002730（读书_10聪明的投资者（增强版））· 证据 E-66011, E-66012
日期、品种、合约、周期、关联方法ID、来源ID：2020年度、全市场公募基金 / 创业板指（399006，原稿作创止 [原稿如此，疑误]）、不适用、年度周期、关联方法 K-31367、来源 SRC-002730
证据性质：有独立记录

当时已知信息
2020年全年A股创业板指走出波澜壮阔的结构性牛市，全年累计涨幅高达 64.96%。
东方财富天天基金网全市场开放式公募基金总数达到 7000 余只（原稿作6969至7069个）。
原计划与触发
对比格雷厄姆书中“成长股分散投资无法跑赢基准指数”的论断，对2020年国内全市场公募基金近一年收益率进行全样本统计排查。
后续过程与结果
统计显示，在7000余只基金中，排名第600名的基金年收益仅刚过70%，超过90%的公募基金全年收益率均无法跑赢创业板指64.96%的基准表现。
本例说明的边界

用严谨的全市场真实数据证实了“分散化成长股投资未能带来显著超额收益”的客观历史定律。

数字与证据
创业板指2020年涨幅：64.96%（E-66012）。
基金全样本数量：约 7000 只（E-66011）。
跑输基准比例：90% 的基金未能跑赢创业板指（E-66011）。
