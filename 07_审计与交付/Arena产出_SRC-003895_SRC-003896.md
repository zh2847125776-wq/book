# K-1150 先由大周期定方向，逆方向的单子不开
> 来源：SRC-003895（第1285课 期货：选好方向再屏蔽磨损（20260423））· 证据 E-5065、E-5066

# K-1152 标志K线是相对屏幕而言的；之后的信号怎么取舍
