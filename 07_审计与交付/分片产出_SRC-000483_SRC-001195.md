```markdown
# K-40888 集合竞价预估全天成交量模型与量能支撑法则
> 来源：SRC-001195 股票_20201126量化技术分析（增强版） · 证据 E-87220、E-87221、E-87222
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在早盘开盘阶段利用集合竞价成交额与昨日全天成交额的等比测算关系预估当日成交总量，并以关键均量线（如20日均量线）为量能基准判定指数均线测试真伪与变盘风险的量化推演法则。

## 它解决什么问题
交易者往往在日线均线呈现多头排列时盲目乐观追高，忽略了日线反弹若无量能匹配将导致上攻动能迅速枯竭；同时在缩量收阳的弱势走势中误判为反转，在无量回测关键生命线（如20日均线）时遭遇破位打漏与补跌下杀（E-87220）。

## 如何识别
1. 集合竞价等比测算模型：在缺乏历史精细统计表的情况下，通过比例公式预估全天成交量：`预估当日成交量X = 昨日全天成交量 × 今日集合竞价成交量 / 昨日集合竞价成交量`（E-87221）。
2. 量能门槛与均量线对标：将预估的全天成交额与20日均量线（MA20量能）进行刚性比对；若预估值或实际成交量显著低于20日均量线，判定为量能不足，缺乏推动价格实质上行的动能基础（E-87220）。
3. 缩量收阳反转预警：在行情未站上短期均线（如5日线）且严重缩量时收出的阳线，本质属于弱势反抽而非企稳，往往次日即面临新一轮阴线回杀（E-87222）。
4. 均线回测无量必漏法则：当价格在缩量状态下向关键支撑均线（如20日均线）靠拢时，若成交量不足以达到均量线标准，一旦进行价格回测将大概率直接击穿打漏（E-87222）。

## 适用边界与失效
适用于大盘宽基指数及流动性充裕的个股在日内早盘的量能定性推演。该比例测算法为日内估算工具，若盘中突发重大利好/利空政策导致午后成交量剧烈脉冲放大，或者早盘由于集合竞价异常单干扰出现量比失真，则全天成交额与估算值可能出现偏离；此时应以盘中实际成交速率进行动态修正。

## 与其他概念的关系
该法则属于微观量价关系与前瞻性推演的结合。它通过开盘集合竞价将全天的量能预期前置，打破了传统成交量分析“收盘才能确认缩放量”的滞后性；与均线多头排列概念形成辩证互补，强调“均线排列是形，成交量能是神”，若无量能支撑，再完美的多头排列均线测试也会演变为假突破或破位打漏。

## 案例与证据
在2020年11月26日上证指数解盘中，指数报收3369.73点（+0.22%），20日均量线为3402亿元，而当日实际成交仅3173亿元（不足均量）。讲师指出昨日全天成交3835亿元、集合竞价32亿元，今日集合竞价仅26亿元，依公式测算 `3835 × 26 / 32 ≈ 3115亿元`，精准锁定了全天缩量格局；并在指数未站上5日线且距离20日线（3333.98点，当日最低3344点仅差11点）极近时发出预警：量能不够测试20日线必打漏（E-87220、E-87221、E-87222）。
```

```markdown
# K-40889 大阴线贯穿多均线的分步与异日回测机制
> 来源：SRC-001195 股票_20201126量化技术分析（增强版） · 证据 E-87223、E-87224、E-87225
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：当单根大阴线实体一次性向下打穿多条重要均线或趋势线后，市场在后续反抽中往往采取时间不确定、空间分步离散的形式分别对各均线展开阻力测试的量化运动结构。

## 它解决什么问题
交易者面对单日大阴线跌穿多条均线后，常教条式地预期次日必须出现一根长上影K线同时向上回测所有被穿均线；一旦次日未回测或仅微弱反弹，交易者便误以为企稳而盲目抄底，或者在分步测试过程中对反弹性质产生严重认知混乱（E-87223）。

## 如何识别
1. 均线群贯穿现象：单根实体大阴线向下连续跌破多条重要均线（如20日线与60日线）以及关键上升趋势线，导致短期与中长期支撑结构同时失效（E-87224）。
2. 回测时间非对称离散性：击穿后的回测并非固定在次日发生，既可以在跌破后的第二天展开回测，也可以在震荡下跌至第十天甚至更久后才展开回测，在时间周期上无机械定规（E-87223）。
3. 空间分层逐步回测路径：反抽行情不一定一蹴而就回测所有均线，可以表现为第一天先回测下方的60日均线，次日以60日线为依托向上递进测试20日均线，在逐层确认上方阻力有效后再度恢复单边下跌（E-87225）。
4. 综合共振判定：若低级别（如60分钟级别）出现指标底背离，可能驱动指数向上展开分步回测（如先测试上升趋势线、次日测试60日线），但若无放量配合站上关键均线，均属下跌中继回测（E-87225）。

## 适用边界与失效
适用于指数或个股在趋势破位初期对均线密集带的承压测试分析。若市场遭遇极端流动性危机或重磅系统性利空，导致股价连续跌停板或单边跳空暴跌脱离均线区域，分步回测可能被完全压制而无法发生；反之，若在测试过程中伴随巨量大阳线强势站回所有被穿均线之上，则原均线破位演变为假跌破（空头陷阱），分步下跌回测逻辑失效。

## 与其他概念的关系
该概念深化了经典技术分析中“支撑跌破转为阻力”的单线逻辑，将其升级为多均线复合阻力带的非线性演化模型。它与左侧交易的猜底行为彻底划清界限，告诫交易者在大阴线贯穿后绝不可因局部的次日小阳线而放松警惕，必须将分步测试视为多头抵抗衰竭与空头加仓确认的右侧防守节点。

## 案例与证据
在2020年11月26日创业板指数（日线收于2609.39点）走势推演中，讲师回顾了此前大阴线一举贯穿20日线、60日线及上升趋势线的结构。讲师通过画图板详细拆解：大阴线打漏后，反抽测试不一定在次日发生，可能第2天测也可能第10天测；在空间上可以第一天测试60日线、次日以60日线为基础再测试20日线，测试未果后继续下挫。讲师以此警示不可因为60分钟底背离就盲目认定见底，创业板指短线仍处于下跌边缘（E-87223、E-87224、E-87225）。
```

```markdown
# K-40890 双MZ均线系统开单共振与初次贴近一色K确认法
> 来源：SRC-000483 期货_期货投机分析20260727（增强版） · 证据 E-87226、E-87227、E-87228
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：基于本周期与高级别周期的MZ均线颜色同向共振作为趋势方向过滤，并在价格修复过大乖离率后以首次触碰本周期MZ且形成一色K与LPAK共振K线作为高盈亏比入场的量化交易模型。

## 它解决什么问题
解决日内与波段交易者在趋势刚出现时因价格脱离均线（正乖离率或负乖离率过大）而盲目追单、随即遭遇剧烈均值回归回撤导致频繁止损的问题，同时规避在大小周期方向冲突时逆势开单的磨损陷阱（E-87226）。

## 如何识别
1. 双周期颜色同向共振：开仓前必须满足本周期MZ与高周期MZ颜色严格一致——做多必须是“两红加两黄”（本周期红MZ配合高周期黄MZ）；做空必须是“两绿加两蓝”（本周期绿MZ配合高周期蓝MZ）；任何单周期变色或颜色冲突一律禁止开单（E-87226）。
2. 拒绝大乖离追单并耐心等待贴近：当共振信号出现但价格远离均线（正乖离率或负乖离率过高）时，坚决放弃追单，必须等待价格逐步回落或反弹贴近本周期MZ（E-87226）。
3. 第一次贴近空间定义：贴近K线的下影线或最低价正好坐在本周期MZ上，或盘中轻微刺破后迅速收回，且K线收盘价与本周期MZ距离极近（E-87227、E-87228）。
4. 一色K与LPAK特征共振触发：到达贴近位置后的确认K线必须同时具备“一色K”（颜色与开仓方向一致且实体明确）与“LPAK”双重技术特征；此时以本周期MZ价格设立刚性初始止损，以极小试错成本介入（E-87227）。

## 适用边界与失效
适用于商品期货与股指期货的5分钟及日内主流分时周期顺势交易。当标的处于极窄幅横盘无趋势震荡时，双MZ频繁变色交织，可能造成连续假信号磨损；若市场跳空低开直接开在MZ下方，或者共振后迟迟未给贴近机会直接单边加速奔跑，则策略应客观接受错失机会，严禁盘中破坏规则硬追。

## 与其他概念的关系
该策略是动量趋势过滤与均值回归入场的经典结合体系。双MZ共振保证了顺应大周期主浪方向，而“第一次贴近一色K”则在微观层面上锁定了最佳赔率买点；它与道氏理论中“顺大势、逆小浪”的思想高度契合，通过放弃“变色即买”的激进冲动，换取了兼顾高胜率与极低止损风险的确定性入场优势。

## 案例与证据
在2026年7月27日沪金主连（au9999）5分钟行情中，早盘9点30分出现两红加两黄的多头共振信号，但由于正乖离率过高未给贴近点；直至下午1点50分价格逐步回落完成修复，下影线正好落在本周期MZ上，随后的K线同时呈现一色K与LPAK双重特征，构成当日最佳低止损多单开仓点（E-87226、E-87227）。反观当日白银（ag9999），早盘虽出现两红两黄，但因K线距离太远始终未出现坐在MZ上的第一次贴近K线，系统果断放弃下单从而成功避免了逆势低开造成的亏损（E-87228）。
```

```markdown
# K-40891 近邻堆顶合并防守与白线止损对等缩减法则
> 来源：SRC-000483 期货_期货投机分析20260727（增强版） · 证据 E-87229、E-87230、E-87231
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在震荡或多重测试行情中将初始止损与邻近波段前高前低合并设防以过滤假破位磨损，并在采用开盘区间中线白线紧凑止损时必须刚性同比例缩减止盈目标的风险对等量化风控法则。

## 它解决什么问题
解决交易者在均线附近反复进出遭遇“一止损就反向、一接回又被扫”的连续多轮磨损痛苦；同时破除交易者“既想用极窄止损抗风险、又妄想获得远期超额止盈”的非理性贪婪偏误（E-87229、E-87230）。

## 如何识别
1. 近邻堆顶（近高）合并防守机制：在空头开单后若价格在均线附近反复纠缠，若系统初始止损价距离前方最近的波段高点（近高/堆顶）在空间上极其接近，应将防守基准统一盯牢该堆顶；在堆顶未被实质突破前不盲目执行频繁的止损与反向接回，从而过滤微观噪音（E-87229）。
2. 开盘区间中线白线的双刃剑性质：在日内开盘区间（P点高点与B点低点）突破模型中，引入P点与B点的中值（中线白线）作为参考；若交易者因恐惧亏损过大而采用白线替代P/B点设立紧凑止损，虽降低单笔金额但极易被日内脉冲噪音扫损（E-87230）。
3. 风险与收益同向对等法则：确立“权利与义务对等，风险与收益对等”的铁律；若交易者主动选择白线等紧凑止损使预设风险空间变小，其止盈目标空间（绿色区域）必须同比例严格缩减，严禁在收窄止损的同时维持远大止盈预期（E-87230）。
4. 止损绝对值超标过滤与折半仓位应对：日内开单前严格核算止损绝对值，对于普通工业品/农产品若单笔止损绝对值超过1%（如1.53%或1.86%），首选规则是坚决不开单；若策略必须参与，必须通过将标准仓位减半（如平时开两手此时只开一手），将绝对风险敞口压缩至可控区间（E-87231）。

## 适用边界与失效
适用于股指期货、大宗商品期货日内日线及分时突破策略的资金管理与出场风控。若行情处于极端大单边单向趋势中，直接采用远端堆顶防守可能导致单笔亏损幅度过大，因此近邻堆顶合并防守的前提是两者空间距离确实极其微小；若盘中遇到流动性瞬间枯竭导致的跳空滑点，无论是白线还是堆顶止损均需配合市价刚性离场。

## 与其他概念的关系
该法则属于交易期望值管理中的动态平衡艺术。它直指业余交易者在止损与止盈设置上的双重标准，从数学与博弈本质上证明了“窄止损必然伴随低胜率与窄止盈”的守恒定律；同时提出的近邻堆顶合并防守与仓位动态折半规则，将离散止损技术与资金头寸规模严密缝合，是抑制系统过度交易与磨损消耗的核心风控盾牌。

## 案例与证据
在2026年7月27日焦煤（jm9999）5分钟实盘复盘中，上午11点出现两绿两蓝空单信号后在均线处反复发生3次假突破打漏与接回，产生多重连续磨损；讲师指出若止损价距前方堆顶极近，可直接以近高堆顶为准未破不出，从而避免重复割肉（E-87229）。在沪金（au9999）日内策略中，第二K高点为P点、第一K低点为B点，讲师指出以P点与B点中值的白线止损容易被扫，若强行用白线止损则止盈空间必须等比例压缩对齐（E-87230）。在中证1000主连（IM9999）多单中，止损绝对值达到1.86%远超标准，讲师明确指出要么放弃不开，要么将常规2手仓位降为1手以实现风险折半至0.9%（E-87231）。
```
