# K-0480 讲述者：大左侧、小左侧与右侧（用高多、低多的朝向来界定）

> 来源：SRC-003676（第1088课 期货：关后整理，3天有效，注意拐头时机（20250228））· 证据 E-2164；SRC-003677（第1089课 期货：关后整理重心降低（20250303））· 证据 E-2188
> 来源立场：课程讲述者采纳
> 底本层级：完整稿可见

一句话定义：讲述者用高多、低多的朝向给入场位置分级。第1088课的多单语境里，低多冲下叫"小左侧"，高多冲下叫"大左侧"（E-2164）。第1089课的空单语境里，高多和低多都冲下，叫"右侧交易机会"（E-2188）。

## 它解决什么问题
在开单前说清楚这一单属于左侧还是右侧，好决定仓位怎么配、要不要等待。

## 如何识别
- 多单，低多冲下：小左侧（E-2164）。
- 多单，高多冲下：大左侧（E-2164）。
- 空单，高多、低多都冲下：右侧交易机会，讲述者说"可靠性更高一点"（E-2188）。
- 两课分别只讲了一个方向，这里不把任何一条镜像到另一个方向。

## 适用边界与失效
- 小左侧的仓位做法（先放一半，低多转过来再加一半）只出现在第1088课的螺纹钢案例里，见 C-0304，不作为通用规则。
- 讲述者说右侧也可能止损（E-2189，见 C-0309）。
- "冲下""冲上"用什么数值判定：原文未明确。第1089课另有"看均线数值"的口述，本清单未单列证据。

## 与其他概念的关系
- 与 K-0068（左侧交易）、K-0474（"左左侧"）同属一个话题。本卡给出的是用朝向来分级的口径。
- 与 K-0276（高多作趋势参照、低多给下单信号）有关。

## 案例与证据
- 螺纹钢多单（C-0304）。
- 聚丙烯空单，第1089课，合约原稿未明确，未单独建案例卡。

# K-0482 书中：亏损在几何级数上对抗你——同样2:1的盈亏比，收益和亏损幅度都小的，反而赚得更多

> 来源：SRC-006564（第421课 读书：股票魔法师Ⅱ——止损余量与期望的科学）· 证据 E-2178、E-2179、E-2180、E-2181
> 来源立场：书中作者观点（米内尔维尼《股票魔法师Ⅱ》）。E-2181 是讲述者的认同，单独标出。
> 底本层级：完整稿可见（笔记注明只依据转录前200行和课件OCR）

一句话定义：亏损在几何级数上对抗你（E-2180）。所以在同样的2:1盈亏比、同样的成功率下，小幅度的收益和亏损，结果好过大幅度的收益和亏损。

## 它解决什么问题
说明为什么单笔亏损的幅度不能太大。讲述者的解释是：亏损50%就需要翻倍才能回本（E-2181）。

## 如何识别
- 书中例子一：成功率40%、平均收益4%、平均亏损2%，交易10次净利润3.63%（E-2178）。
- 书中例子二：成功率40%、平均收益42%、平均亏损21%，交易10次写的是"净利润1.16%"（E-2179）`[原稿如此，疑误]`，不作为正式数字。疑点见"底本层级与疑点"。

## 适用边界与失效
- 书中只给了2:1盈亏比、40%成功率这一组条件，其他组合原文未明确。
- 例子二的数字与算术不符，只能保留定性结论（小幅度优于大幅度）。

## 与其他概念的关系
- 与 K-0464（止损不按波动性放宽）同出一节，属补充关系，不合并。
- 与 K-0453、K-0444 同属期望值一类的讨论。

## 案例与证据
没有交易记录，只有书中的数值例子。
