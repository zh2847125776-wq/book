```markdown
# 补充 K-1220 双MZ过滤空单与单MZ多空双吃取舍
> 来源：SRC-000944 · 证据 E-53940
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：高低MZ构成的双MZ系统在顶部反转破位时可能因高周期约束而开不出空单，而单MZ可顺畅开空实现多空全吃但胜率更低，二者各有优缺点。

## 如何识别
- 黄金出现左肩右肩颈线打漏、破MZ且破颈线的标准空头破位K线后，单MZ系统能顺利开出空单实现从头吃到饱（E-53940）。
- 双MZ系统因高周期MZ方向尚未反转而过滤了该笔空单，免于部分小磨损的同时也损失了右侧反手大利润，验证了双MZ保确定性、单MZ占好价格的固有代价（E-53940）。

## 适用边界与失效
适用于单MZ与双MZ系统的对比决策；不能将单MZ能够多空通吃的某一单笔收益推断为整体年化必然占优。
```

```markdown
# 补充 K-0825 突发拉升反抽平仓中盘中价与收盘价模型的两难代价
> 来源：SRC-000944 · 证据 E-53941
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：持空仓遭遇盘中突发单根巨幅大阳线拉升时，盘中价模型能第一时间刺破即平但日常容易被假突破频繁扫损，收盘价模型收K平仓虽具确定性但易被单根长阳严重吞噬利润。

## 如何识别
- 碳酸锂空单在午盘开盘后遭遇突发大阳线拉升，若采用盘中价模型可在刚刺破平仓线时即刻止损（加上滑点代价），但平时面临频繁被扫的问题（E-53941）。
- 若采用收盘价模型平仓，则必须等待该巨幅阳线收盘，导致单笔亏损过大、直接吃掉前期盈利的三分之一，展示了极端脉冲行情下收盘价模型的剧烈回撤代价（E-53941）。

## 适用边界与失效
仅记录两种离场触发模型在突发急拉时的现实表现与两难权衡，不作为废弃任一模型的依据。
```

```markdown
# 补充 K-1223 策略对品种的特化属性与定期总结选品
> 来源：SRC-000944 · 证据 E-53942
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：任何交易策略并非对所有品种皆普适有效，必然存在特定品种的适配特化，交易者必须根据定期绩效表总结策略与品种的匹配偏好。

## 如何识别
- 讲述者指出同一双MZ策略在金银上表现抢眼，但在铝、螺纹钢等低波动或震荡品种上持续磨损（E-53942）。
- 明确要求交易者依据季度末绩效表选品，挑选高流动性、高波动品种，定期总结哪些品种与策略高度契合，防范机械全品种通套（E-53942）。

## 适用边界与失效
品种特化是策略适应性特征，历史周期好做的品种未来仍可能随波动率衰减而进入磨损期。
```

```markdown
# 补充 K-31364 日线横盘区不可预测性与严禁主观停关策略
> 来源：SRC-000944 · 证据 E-53943
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：标的处于大级别横盘震荡区间时趋势策略必然频繁止损磨损，交易者无法事前预知磨损与单边起点，若因厌恶亏损而主观停关策略必将错失单边大行情。

## 如何识别
- 焦煤在超大底部横盘区间内连续出现多笔亏损磨损（E-53943）。
- 交易者若试图在磨损开始时关闭策略、单边启动时开启策略，在实盘中根本无法做到；盲目主观开关只会导致精准踩中磨损且踏空单边行情起点，因此必须纪律性坚持硬扛（E-53943）。

## 适用边界与失效
适用于趋势跟踪策略应对既有持仓或策略系统的执行原则；若确定人工干预，仅可在宏观大横盘区间上下限重新开启。
```

```markdown
# 补充 K-0450 触及止损线必须一把清仓严禁使用卖半规则
> 来源：SRC-003387 · 证据 E-53950
> 来源立场：书中作者观点＋课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：仓位减半的“卖半规则”仅适用于大幅浮盈状态下保护心灵与锁定利润；一旦价格下跌触及止损线，没有任何商量空间，必须坚决一把清仓，绝不可卖半抗单。

## 如何识别
- 作者与讲述者口径完全一致：浮盈大幅拉大时可分批卖半两头堵（E-53950）。
- 当账户产生亏损并触及初始或移动止损线时，仓位减半方法绝对失效，严禁卖出一半并抱有侥幸心理赌剩下的一半反弹回升，必须果断全平执行纪律（E-53950）。

## 适用边界与失效
所有规则化股票与期货系统的绝对止损执行准则，无任何协商或缓冲余地。
```

```markdown
# 补充 K-0452 单利提现保本与部分利润复利投入的结合机制
> 来源：SRC-003387 · 证据 E-53951
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：纯单利无法利用资金规模效应，纯复利在连续盈亏交替下回撤风险过高；最佳途径是初期单利提现直至全部操作资金转为利润，后期将部分利润转为复利滚存、部分利润继续单利提现。

## 如何识别
- 书中对比拉里（固定金额单利赚120%）与斯图尔特（全额利润复利亏损71.75%）的统计对照，论证纯复利的脆弱性（E-53951）。
- 讲述者提出单利复利结合的执行模型：先以单利操作并持续提取本金与收益，让交易账户完全由纯利润运转；随后分流一部分利润享受复利扩增，另一部分利润单利提现锁定落袋（E-53951）。

## 适用边界与失效
建立在系统长期具有稳定正期望且能产生持续利润的前提下；具体利润留存与提现比例由交易者自主决定。
```

```markdown
# 补充 K-25712 定期事后交易分析与消除借口全责法则
> 来源：SRC-003387 · 证据 E-53952
> 来源立场：书中作者观点＋课程讲述者采纳

一句话定义：如同专业摄影师以顶级器材消除外部借口，交易者必须养成按季度和年度定期进行事后交易分析的反馈习惯，直面亏损困境，对投资结果承担100%完全责任。

## 如何识别
- 作者将事后分析视为生活习惯和系统自我调节反馈循环，规定每季度及每年定期评估；顺利时分析无痛，不顺利时更须剖析失败教训（E-53952）。
- 作者以业余摄影使用顶级设备消除借口作比喻，强调成功与平庸的分水岭在于消除借口并承担全责；讲述者进一步强调不能将亏损推卸给量化、主力机构或市场制度，市场与数字永远没错，亏损只能归咎于自身（E-53952）。

## 适用边界与失效
适用于所有专业交易者的复盘心智与长期反馈闭环建设。
```
