# 补充 K-0494 2025股指期货结算拆分为盈亏金额与不细分综合手续费两大构件
> 来源：SRC-000895 · 证据 E-52460
> 来源立场：课程讲述者采纳（流派特色费效比核算基石）
> 底本层级：仅增强稿可见

一句话定义：在一笔交易的结算体系中严格划分为盈亏金额与综合手续费两大构件，并将印花税、佣金、日内及隔夜等所有杂费合并为综合手续费不作内部细分。

## 如何识别
- 结算两分法：交易结算明确拆解为“盈利或亏损金额”以及“综合手续费”两个独立核算单元（E-52460）。
- 费用合并计算：股票印花税与佣金、期货当日回转手续费与隔夜手续费等所有成本费用统一打包，除盈亏本金外一律归并为综合手续费（E-52460）。

## 适用边界与失效
属于该交易流派内部独特的交易评价规范，声明与通用百科定义存在统计口径差异。
```

# 补充 K-0289 2025股指期货亏损交易手续费加重亏损不讨论费效比记录为无
> 来源：SRC-000895 · 证据 E-52461
> 来源立场：课程讲述者采纳（亏损交易费效比统计除外规则）
> 底本层级：仅增强稿可见

一句话定义：当交易发生亏损时，综合手续费直接放大实际亏损金额，该笔交易技术上不讨论费效比，统计结果一律记录为“无”。

## 如何识别
- 逻辑前置条件：费效比专用于度量产出与成本比率，缺乏正向产出的亏损交易不存在费效关系（E-52461）。
- 记录规范：在复盘统计表格中，亏损交易项对应的费效比字段严格填报为“无”，禁止计算出负数或强行归零（E-52461）。

## 适用边界与失效
适用于系统化复盘统计，防止负值干扰整体平均费效比算法。
```

# 补充 K-0121 2025股指期货盈利交易以盈利金额比总手续费记录具体费效比
> 来源：SRC-000895 · 证据 E-52462
> 来源立场：课程讲述者采纳（盈利交易费效比量化公式）
> 底本层级：仅增强稿可见

一句话定义：唯有当交易产生正向盈利时，以盈利金额除以总手续费的比值作为费效比，并在统计表中精确记录具体数值。

## 如何识别
- 定量计算公式：费效比 = 盈利金额 ÷ 综合手续费（E-52462）。
- 评价功能：通过统计盈利交易所获取的具体费效比数值，客观评估单笔交易质量以及系统费率负担能力，辅助决策后续交易节奏（E-52462）。

## 适用边界与失效
要求手续费数据完全真实完整；若券商出现返佣或税费减免，需按最终实际结算费用核算。
```

# 补充 K-0050 20220902横盘震荡通道下线严禁混淆为上升趋势线
> 来源：SRC-001607 · 证据 E-52470
> 来源立场：课程讲述者采纳（趋势线与横盘通道界定）
> 底本层级：仅增强稿可见

一句话定义：横盘震荡区间内的低点连线仅属于横盘通道下线，缺乏单边上升背景与前低结构支撑，技术上严禁混淆定性为上升趋势线。

## 如何识别
- 上升趋势线界定：上升趋势线必须满足单边上升趋势背景，由波段最低点与最高价之前的有效回踩低点顺次连接而成（E-52470）。
- 横盘下线本质：价格处于横盘震荡整理状态时，多点连线仅构成横向通道的下限支撑线；一旦跌漏该下线仅代表横盘区间破位看跌，不可按趋势线破位反转测距（E-52470）。

## 适用边界与失效
适用于K线手画线的性质核验，纠正交易者在无趋势横盘行情中随意胡乱画线的常见毛病。
```

# K-25384 多周期技术分析方法同构性原理捂住周期标签技术逻辑完全一致
> 来源：SRC-001607 · 证据 E-52471
> 来源立场：课程讲述者采纳（技术分析分形与同构性规律）
> 底本层级：仅增强稿可见

一句话定义：技术分析在不同时间周期上具有高度分形同构性，即便遮挡住左上角时间周期标签，其均线、形态与指标的研判逻辑完全相通。

## 它解决什么问题
解决初学者误认为日线、周线、小时线与1分钟分时图具有截然不同的神秘分析体系，导致跨周期认知割裂、无所适从的障碍。

## 如何识别
- 遮挡周期验证：将图表左上角的时间维度标签遮盖，无论1分钟分时还是日线，遵循完全相同的分析法则——有均线看均线排列，无均线看形态通道，均无则看指标共振（E-52471）。
- 分形本质：小周期的横盘破位回测是高周期破位走势的微观投影，技术规则在不同尺度空间下自相似复现，仅振幅与时间标尺存在差异（E-52471）。

## 适用边界与失效
跨周期适用时需注意交易摩擦成本约束；极小分时周期虽技术同构，但手续费和滑点在振幅中占比剧增，实操不可过度下沉超短周期。

## 与其他概念的关系
母库 K-0019 确立多周期共振；本卡建立遮挡周期标签后技术分析方法完全同构的分形哲学卡。
```

# 补充 K-0539 20220902六十日线初拐头即逢巨大负乖离时的两难困境与反抽减亏
> 来源：SRC-001607 · 证据 E-52472
> 来源立场：课程讲述者采纳（初拐头与深负乖离冲突处理）
> 底本层级：仅增强稿可见

一句话定义：60日均线初次拐头向下即伴随极深负乖离时，虽然均线确立看跌，但切忌在刚拐头瞬间急躁割肉，应等待反抽修复以更高价格减亏离场。

## 如何识别
- 信号冲突两难：60日均线历经长期走平后第一天正式向下拐头，确认中期趋势转空；但价格由于前期急跌已远离均线，初次产生负乖离即已处于极深位置（E-52472）。
- 应对纪律：此时追割极易卖在地板；理性的做法是如同双均线第二买点一样，等待价格展开对拐头60日线的向上反抽抽测，趁反弹修复极端负乖离时再从容减仓少亏（E-52472）。

## 适用边界与失效
属于破位滞后处置的减亏防守策略；若遭遇重大基本面崩塌导致单边无量跌停，则不可等待反抽。
```
