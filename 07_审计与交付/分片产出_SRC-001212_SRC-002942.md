```markdown
# K-41088 核心均线突破回测买入法与五穿二十再次金叉确认律
> 来源：SRC-001212 股票_20201217量化技术分析（增强版） · 证据：E-87720, E-87721, E-87724

### 核心概念与运作机理
在技术分析交易架构中，底部左侧抄底虽然在教科书上成立，但因上方空间有限且面临持续磨损，并非最优解；真正的标准右侧买点是“突破后买进”与“回测确认后买进”。当价格放量站上核心均线（如20日均线）后，贯穿后续交易的核心主线是验证回测有效性：次日回测允许盘中最低价刺破均线，但收盘价必须刚性收在20日均线之上（如3398点）；随后等待5日均线向上金叉20日均线（五穿二十），完成均线多头形态共振。若回测收盘失守均线则果断一把清仓止损，若回测成功则以极窄试错成本确立波段底仓。

### 适用场景与边界条件
- 适用场景：适用于股票与指数在经历震荡盘整或底部筑底后，首次放量站上20日均线的右侧建仓与风控防守。
- 边界条件：回测成败以全天收盘价为唯一裁决标准（盘中下影线刺破不破坏有效性）；若收盘跌破20日线必须执行“一把卖出”纪律。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
与多周期均线时空映射（K-41089）紧密联动：日线20日均线与周线5周均线在空间点位上高度重合，形成跨周期共振支撑；与早盘破位卖权锁定策略（S-25680）互为攻防：本法则指导右侧入场与底仓确立，S-25680保障盘中卖权与防守纪律。

### 案例与证据
- 案例标的与时间：2020年12月17日上证指数（000001）与创业板指。
- 实盘数据特征：上证指数收盘站上20日线，测算次日20日线位于3398点，周线5周线位于3396点，确立次日回测收盘守住3398点即可等待5穿20金叉；若跌漏则回测失败一把离场。
- 逐节证据标定：突破回测机理参见 E-87720，5穿20再次金叉参见 E-87721，收盘守线判据参见 E-87724。
```

```markdown
# K-41089 跨周期均线共振映射与葛兰碧卖点二假突破防御机理
> 来源：SRC-001212 股票_20201217量化技术分析（增强版） · 证据：E-87722, E-87723, E-87725

### 核心概念与运作机理
均线系统具有跨时间周期的内在数学映射关系：一周包含5个交易日，因而“5周均线”在空间与时间权重上等价于日线级别的“20至25日均线”。在多周期检验中，价格反抽受阻于向下5周线并留上影线收阴，构成典型的“下反回测五周线”空头中继；同时在小周期（60分钟）上，价格若仅依靠单根K线脉冲式站上多空线而未形成多头排列，极易在随后的回落中跌漏多空线，直接演变为葛兰碧八大法则中的“卖点二”（反弹假突破破位卖点）。因此，在短时均线仍处空头排列且日线指标处于绿豆压制时，必须保持高度警惕，严禁将局部单日阳线误认为反转。

### 适用场景与边界条件
- 适用场景：指数或个股在弱势下跌途中迎来单日反弹时，评估反弹性质（反抽还是反转）与上方多周期共振压制。
- 边界条件：60分钟单K站上多空线不能确认突破，必须等待回测不破或均线系统理顺；短期5、10、20日均线呈空头排列时，反弹均按弱势反抽对待。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
作为均线回测法则（K-41088）的防御反面：前者从多头角度指导有效回测买入，本法则从空头葛兰碧卖点二揭示伪突破的假信号特征；同时与指数环境前置准入准则（K-41090）共同确立弱势行情的防御底线。

### 案例与证据
- 案例标的与时间：2020年12月17日上证指数60分钟与周线级别结构。
- 实盘数据特征：当时上证指数5周均线在3401/3396点形成盖头反压，短时5、10、20日线处于空头排列，60分钟多空线仅站上一根K线，若跌漏多空线即坐实葛兰碧卖点二。
- 逐节证据标定：葛兰碧卖点二风险参见 E-87722，五周线映射参见 E-87723，短时均线空头客观性参见 E-87725。
```

```markdown
# K-41090 指数站上20日线准入前提与均线多头抗暴雷防御法则
> 来源：SRC-001212 股票_20201217量化技术分析（增强版） · 证据：E-87727, E-87728

### 核心概念与运作机理
在大盘与个股的宏观联动体系中，确立“大盘指数站上20日均线”作为全市场个股开启右侧主动交易的一票否决前置前提：在指数未站上20日线之前，市场缺乏系统性赚钱效应，个股极易受到系统性风险拖累；仅当指数收盘稳稳站上20日线后，右侧交易机会方才打开。在选股端，必须严格执行两大风控铁律：其一，坚决不碰经历过一浪、二浪乃至主升浪已具备巨大累计涨幅的高位股；其二，优选均线系统呈现“多头排列”且处于相对低位滞涨的标的。大样本统计表明，盘中大面积跌停（如40多只个股跌停）时，均线多头排列个股跌停概率极低，具有显著的抗系统性风险与防黑天鹅暴雷属性。

### 适用场景与边界条件
- 适用场景：A股弱势行情与高位分化环境下的仓位总闸门控制及个股选股排雷。
- 边界条件：指数收盘位于20日线下方时，全市场严控仓位甚至空仓；严禁在相对高位追买已有显著累计涨幅的热门股。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
为核心均线买入法（K-41088）提供宏观前置准入闸门：只有指数满足K-41090的前提，个股的K-41088回测买点才具有高胜率；同时为早盘破位卖权锁定策略（S-25680）提供选股范围约束。

### 案例与证据
- 案例标的与时间：2020年12月17日A股全市场盘面复盘。
- 实盘数据特征：当日盘中一度有40多只个股跌停，但跌停标的几乎全为破位空头或高位庄股，均线多头排列标的极少跌停；大盘反弹时唯有确立指数站上20日线才是安全开仓信号。
- 逐节证据标定：均线多头抗跌停优势参见 E-87727，指数站上20日线准入前提参见 E-87728。
```

```markdown
# S-25680 早盘破位卖出执行与尾盘卖权锁定交易策略
> 来源：SRC-001212 股票_20201217量化技术分析（增强版） · 证据：E-87726

### 策略逻辑与决策流程
针对A股T+1流动性制度约束，构建“早盘坚决卖、尾盘方买入”的卖权保护交易策略，执行步骤如下：
1. 盘前预案准备：头天收盘后完成选股推演，标定各候选标的的关键防守价位与均线支撑；
2. 早盘破位一票否决卖出：次日开盘若持仓标的出现跌破关键支撑或放量跳水破位，早盘9点30分后坚决执行卖出纪律，果断斩断亏损；
3. 早盘严禁追买铁律：早盘即便看好某只股票，也绝对不许在早盘冲高时抢买，坚决规避“早盘买入、盘中跳水被套无法止损”的流动性死锁；
4. 尾盘确认买入与锁定次日卖权：耐心等待至14:30至14:50尾盘窗口，此时全天实体K线形态与量能基本定型，若标的稳稳守住20日均线支撑，果断在尾盘进场。此举虽然局部可能损失部分涨幅或多付微小成本，但核心价值在于确保次日开盘即享有完整的无条件主动卖权，实现进退自如。

### 适用场景与边界条件
- 适用场景：A股股票波段交易、个股突破回测买入及防范日内冲高回落大面风险。
- 边界条件：早盘绝对禁止新开仓；尾盘买入必须满足个股守住防守均线且大盘环境协同。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
作为微观执行策略承接K-41088与K-41090：将大盘准入与均线回测规则具象化为分时执行纪律；通过主动放弃早盘微小差价换取确定性次日卖权，构筑交易闭环。

### 案例与证据
- 案例标的与时间：2020年12月17日A股实战操作策略。
- 实盘数据特征：系统推演并解答学员“早盘不买尾盘就高了”的心理误区，明确指出早盘买入一旦被套面临全天锁死，尾盘买入虽然稍高但换来全身而退的主动卖权。
- 逐节证据标定：早盘破位可卖但严禁追买、尾盘锁定卖权机制参见 E-87726。
```
