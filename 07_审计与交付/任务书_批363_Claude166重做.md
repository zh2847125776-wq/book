## 四、质量闸门（**每组必跑，这是本批的成败判据**）

```powershell
python -X utf8 工具\质检_卡片充实度.py 分片工作区\Redo166\out\07_审计与交付\分片产出_<组>.md
python -X utf8 工具\质检_卡片充实度.py --dir 分片工作区\Redo166\out\07_审计与交付   # 每 ~20 组全量
```

| 级别 | 含义 | 处置 |
|---|---|---|
| **✗ 不通过** | 抽取规矩被抄进正文 / 关系段是空占位 / 案例段无内容 | **该组作废重做，不许放过** |
| △ 告警 | 来源头课号为空（外观）/ 同一组证据铺满 ≥3 个节 | 记录，不阻断 |
| ✓ 通过 | — | 继续 |

> **这批资料正是当初空心化的那批，所以质检尤其关键。**
> `严格官方入库` 的 `guard: PASS` **单独不算通过** —— 它只验正确性
> （证据数==验证通过数 / 新卡数==回复卡数 / 逐字回源），抓不到内容空心。

### 三条硬规矩（**当初就是踩了这三条**）

1. **规矩是约束，不是素材。**
   `prompt` 里的抽取铁律（「仅记录≤300字完整原文字面」「不采信Vision推断」「禁截断铁律」…）
   **一个字都不许出现在卡片字段里**。
   「它解决什么问题」要写这条知识**解决什么交易问题**，不是复述抽取规则。
2. **禁止占位符。**
   `关联Sx与Cx；不跨源混用`、`见Sx与Cx` 这类句式一律视为未完成。
   - 「与其他概念的关系」必须写出**实际概念关系**：对照 / 前提 / 互斥 / 补充。
   - 「案例与证据」必须有**具体标的、时间、数据**。
3. **逐节取证。**
   不同小节挂各自支撑的证据号。若一整张卡每节都挂同一组证据号，说明没真正逐节回源。

### 质量基准线

`07_审计与交付\Antigravity产出_SRC-011810.md`（K-32255 MACD精讲）——
写卡前先看一遍，照着这个厚度和结构来：
`一句话定义` 给提出者/年份/构成/功能；`如何识别` 四条独立判据各挂不同证据；
`适用边界` 有真实失效条件与补救 + 诚实的「原文未明确」；`关系` 有实质对照；`案例` 有标的与数据。

### 这批资料的特殊注意

166 个源**全是日评**（`股票_2020xxxx` / `期货_xxxx` 盘面解盘），特点是：
口述流水多、单条信息碎、大量点位与持仓描述。**不要整段搬原文** ——
日评的价值在于**当日的判据与处置动作**，要提炼成可复用的判据，
而不是把解盘流水抄进「一句话定义」。
