# K-33128 修正区向上突破与关键节点防守原则
> 来源：SRC-000343（期货投机分析20250915_交易机会频现_单边突破到来（增强版））· 证据 E-73763
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：商品指数或品种在上行行情后构筑横盘修正区，当收盘突破区间上限后确认开启多头趋势，其核心防守底线为价格坚决不得翻回到原修正结构内部。

## 它解决什么问题
解决横盘修正区向上突破后交易方向确立、上涨空间测算，以及防范“失败旗形/失败三角形”跨度高背离假突破诱多陷阱时的底线防守与做空仓位控制问题。

## 如何识别
1. 前置存在明确的上行行情，随后行情进入相对位置的横盘修正区，向上突破概率更高（E-73763）。
2. 收盘突破区间上限宣告突破，完美走势的目标空间按AC等长测算（前面涨多少后面涨多少）（E-73763，E-73764）。
3. 警惕假突破陷阱形态：防范形成失败旗形或失败三角形突破，即构筑跨度非常高的背离（类似头肩结构过程被修正区域替代），或突破后未创高直接掉落（E-73764）。
4. 确立核心防守节点：创不创高次要，关键防守节点是价格坚决不能翻回到原修正结构内部（E-73764，E-73765）。

## 适用边界与失效
1. 适用边界：向上突破后整体操作确立以做多为主；空单应保持高度谨慎，尽量少做或不做；若非要做空，仓位必须强制降低一半（如平时开30手降至14~16手）（E-73765）。
2. 失效条件：一旦价格跌回并翻回到原修正结构内部，则多头突破假设彻底失效，多头逻辑解除（E-73764，E-73765）。

## 与其他概念的关系
1. 前提关系：本原则必须以前置上行行情与横盘修正区域作为成立前提。
2. 互斥关系：在指数确认突破修正区上限后，与逆势满仓开空策略互斥（逆势空单必须减半）。
3. 补充关系：补充了经典头肩结构被局部修正区域替代时的背离演化判据与底线防守法则。

## 案例与证据
2025年9月15日商品指数收盘宣告彻底突破前期横盘修正区上限，确立做多为主基调，量化策略全面开启顺势做多，逆势空单仓位严格减半执行（E-73763，E-73765）。
```

# K-33129 震荡磨损常态极值过滤规则
> 来源：SRC-000343（期货投机分析20250915_交易机会频现_单边突破到来（增强版））· 证据 E-73767
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在持仓遭遇震荡反复穿透产生连续磨损时，以首次磨损形成的K线极值（做多看最低点，做空看最高点）作为结构过滤基准，未击穿该极值前不再重复执行减半平仓。

## 它解决什么问题
解决均线或红绿豆跟踪策略在震荡行情中频繁触发“破位减半-拉回接回”带来的连续点位与手续费摩擦损耗，避免持仓在震荡平台过早被清洗出局或卖飞后续单边行情。

## 如何识别
1. 入场后遭遇价格反复震荡磨损，触发首次破位减半并形成包含3根K线的局部震荡（E-73766，E-73767）。
2. 做多场景下，比对首次磨损产生的3根K线，确认其中的最低点（E-73767）。
3. 设立常态极值过滤判据：后续再次发生破位磨损过程中，只要收盘K线未攻破前面的最低点，就保持持仓不再执行减半动作（E-73767）。
4. 做空场景下同理对照：价格必须有效突破前波高点才证明上次打回来的空方彻底投降，未破前高前不重复执行动作（E-73768）。

## 适用边界与失效
1. 适用边界：适用于多周期穿透架构（如APL下降平台等）与均线/红绿豆持仓跟踪中的震荡防守；若交易者不愿进行形态计算，亦可选择机械执行固定低磨损（E-73767，E-73768）。
2. 失效条件：当收盘K线实体击破首次磨损产生的前期最低点（多头）或前期最高点（空头）时，过滤保护失效，必须清空离场（E-73766，E-73767）。

## 与其他概念的关系
1. 补充关系：作为穿透跟踪模型中“破红豆减半、拉回收阳接回”基础规则的精细化形态过滤补充。
2. 对照关系：与机械执行每次破位均减半的无脑磨损规则形成对照，以增加结构观察换取更少的磨损次数。

## 案例与证据
2025年9月12日晚11点沪铜5分钟多头遭遇3对磨损与1次平仓，原稿明确讲解以首次磨损3根K线中最低点作为防守过滤，收K不破不减半，以减少无谓摩擦（E-73766，E-73767）。
```

# K-33130 开单距离约束与收益率优先原则
> 来源：SRC-000343（期货投机分析20250915_交易机会频现_单边突破到来（增强版））· 证据 E-73770
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在量化或规则化入场中，严控开单价格与信号点（红绿豆）的距离参数虽能过滤部分不利入场进而抬高单笔胜率，但会导致严重错失趋势利润而降低账户整体年化收益率，体系确立“年化收益率优先于胜率”。

## 它解决什么问题
解决交易者在入场时因价格偏离信号点较远产生恐惧迟疑、试图通过卡死点位距离来盲目追求高胜率，反倒严重牺牲系统总体年化收益率的认知与决策难题。

## 如何识别
1. 量化规则中可引入变量参数a，定义开单价格距离红绿豆的距离为m（如m>1%，0.5%<m<1%，或m<0.5%）（E-73769）。
2. 卡严参数限制（如要求必须接近0.5%才能开单）可在测试中将系统胜率从35%抬高到41%（E-73769）。
3. 识别胜率代价：提高胜率的直接代价是错失趋势大波段，导致年化收益率显著降低（E-73770）。
4. 确立价值抉择：在年化收益率与胜率冲突时，必须确立年化收益率更重要，不得为了规避潜在亏损而盲目追求高胜率（E-73770）。

## 适用边界与失效
1. 适用边界：适用于程序化量化交易与趋势跟踪系统（如欧线集运、菜油等品种）；交易者不可因差值较大而放弃执行开单（E-73769，E-73770）。
2. 失效条件：在极高杠杆或单笔硬性风控额度极小的情境下，若偏离过大导致初始止损幅度超出单笔风险上限，需由资金管理规则统一约束（E-73770）。

## 与其他概念的关系
1. 对照关系：与“高胜率低盈亏比”策略思维形成根本对立，属于典型的“低胜率高盈亏比趋势跟踪”设计哲学。
2. 前提关系：是执行低波红绿豆模型“见色即建仓、不因距离迟疑”的底层思想基石。

## 案例与证据
欧线集运量化模型在信号触发时无论距离多远直接开单；测试显示若要求价格接近0.5%开单，胜率虽从35%提升至41%，但年化收益率降低，直接错失趋势利润（E-73769，E-73770）。
```

# K-33131 交易架构驱动与点位脱钩原则
> 来源：SRC-000343（期货投机分析20250915_交易机会频现_单边突破到来（增强版））· 证据 E-73772
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：交易开仓的唯一合法依据是当前K线与指标满足客观的交易架构，严禁以历史成交成本、固定心理价位或全市场公开消息作为入场判定依据。

## 它解决什么问题
解决交易者习惯将操作与特定静态点位（如“到了某价格就能空”）或过往成本挂钩，以及因宏观公开消息过度干扰交易计划执行的顽疾。

## 如何识别
1. 开仓合法性判据：能否下单只取决于是否符合完整的交易架构，绝非因为价格到达某一静态数值（E-73772）。
2. 关键位置动态性：下一次可以开仓的关键位置完全由下一次出现的交易架构实时确定，无法主观预设固定点位（E-73772）。
3. 架构决定入场点：例如前波高点840，盘中最高冲至841后收阴线在839，构筑5分钟SFP形态，关键下单价格为839，由实时K线架构决定而非历史成本（E-73773）。
4. 公开消息面脱钩：全市场已知的公开消息（如美联储降息预期，类似“南北车”效应）在开盘时已充分反映，严禁因公开预期推翻原交易计划，坚持按计划执行止损与开仓（E-73771）。

## 适用边界与失效
1. 适用边界：全品种、全周期入场判定的通用底线原则（E-73771，E-73772）。
2. 失效条件：若行情未形成完整交易架构（如无穿透变色、无SFP收阴确认），任何价位均严禁主观盲目入场（E-73772，E-73773）。

## 与其他概念的关系
1. 前提关系：必须具备明确且客观的形态或指标架构规则（如SFP架构、红绿豆穿透架构）。
2. 互斥关系：与“成本锚定心理”、“预设挂单猜顶底”完全互斥。

## 案例与证据
2025年9月15日晚直播中有学员称“靠近336[原稿如此，疑误，现价833附近]可以空”，老师严正驳斥必须依据交易架构，并举例前高840出现841触顶收阴839的5分钟SFP架构，止损设于339.4[原稿如此，疑误，应为839.4]（E-73772，E-73773）。
```
