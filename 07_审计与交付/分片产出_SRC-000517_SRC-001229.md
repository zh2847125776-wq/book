# K-41296 箱顶突破微幅破50线不走与守住箱顶底线博弈法则
> 来源：SRC-000517 期货_期货投机技术分析20230705（增强版） · 证据：E-88242

### 核心概念与运作机理
在价格行为学与波段持仓管理中，针对“突破形态初期的微幅破均线”确立了灵活的“守箱顶大底线博弈”模型：
1. 均线跌破与空间相对论：常规规则要求做多头寸跌破50均线止盈；但在品种刚强势放量突破箱顶（如甲醇突破2116阻力位）不久、整体涨幅尚处于极小萌芽期时，若价格盘中仅微幅跌破50均线，由于此处距离建仓成本极近，若机械平仓根本没有锁定多少利润空间；
2. 箱顶与跳空缺口双重支撑垫：低杠杆或追求大波段收益的交易者，允许执行高阶容忍策略——“将防守底线直接后移至箱体顶端（2116点）及突破跳空缺口上限”。只要2116箱顶未被向下跌穿（“守住白干线”），该回踩在技术上完全定性为健康的“箱顶突破回测”；
3. 大幅拉升后破50线必须走：相反，当品种已经经历数十点乃至数百点的单边主升暴涨之后，若再度跌破50均线，则表明主升动能彻底枯竭，交易者必须无条件坚决止盈离场。

### 适用场景与边界条件
- 适用场景：商品期货大级别突破初期的波段多单防洗盘、低杠杆波段持仓管理。
- 边界条件：仅适用于突破初期未大幅拉升时；若收盘有效跌穿箱顶2116则必须无条件清仓。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
承接箱体突破开盘即入策略（S-25780）：为入场后的防洗盘持仓提供依据；与高九不破五顺势持仓（K-41297）形成均线与结构双重支撑。

### 案例与证据
- 案例标的与时间：2023年7月5日甲醇期货主力合约箱顶回测。
- 实盘数据特征：甲醇突破2116后微幅跌破50均线，系统分析因涨幅微小若平仓盈利极低，允许仓位低者以2116箱顶作为终极底线博弈大波段。
- 逐节证据标定：箱顶突破回测守住2116与小涨破50线不走参见 E-88242。

# K-41297 趋势持仓收盘不漏50线定力与高九不破五出局铁律
> 来源：SRC-000517 期货_期货投机技术分析20230705（增强版） · 证据：E-88243

### 核心概念与运作机理
在单边动量趋势波段持仓中，确立“以50日均线为总锚点、高九不破五坚决不出”的定力法则：
1. 收盘捋在50线上方之绝对持仓律：在品种（如玉米）自低点拔地而起展开多头推升途中，盘中无论出现多么剧烈的日内洗盘与震荡，只要“每日收盘价始终稳稳捋在50日均线上方”，系统判定多头生命线完好无损，交易者必须坚守持仓定力，绝不盲目被小震荡震出筹码；
2. TD高九不破五不走原则：面对指标系统触发的日线级别“高九（TD九转高位衰竭信号）”，绝大多数业余散户产生盲目恐慌提前抢跑卖飞；专业交易系统确立钢铁执行口诀——“高九破五方考虑离场，高九不破五坚决不出”；
3. 右侧破位确认：唯有当价格在高九出现后、且收盘实质性打漏50日均线，多头才启动主动平仓响应。

### 适用场景与边界条件
- 适用场景：商品期货（玉米、农产品等）及股票主升浪多单防卖飞波段持有。
- 边界条件：未破50日线前禁止主动猜测顶部；收盘跌漏50日线必须在第一时间离场。

### 与其他概念的关系
为指数破五日线清空仓位（K-41298）提供跨周期均线逻辑映射；与大盘风格轮动假象（S-25810）互为印证。

### 案例与证据
- 案例标的与时间：2023年7月5日玉米期货主力合约日线波段。
- 实盘数据特征：玉米自低点反弹以来每日收盘均守在50均线上，系统明确指出即便出现高九也不要怕，坚决执行“高九不破五不出”的定力准则。
- 逐节证据标定：收盘不漏50线不走与高九不破五不出参见 E-88243。

# K-41298 指数跌破5日线禁开新仓与回调期陆续卖出清仓律
> 来源：SRC-001229 股票_20210111量化技术分析（增强版） · 证据：E-88244

### 核心概念与运作机理
在A股主升浪波段交易中，“5日均线（5MA）”构成了整个账户进攻与防守的总总闸门：
1. 均量不足与破5日线风控触发：当大盘指数5日均量不足以支撑连续上攻（如5日均量5322亿而实际仅5022亿），指数放量滞涨并收盘正式跌破5日均线；
2. 绝对禁开新仓硬红线：五日均线未破之前，交易者必须顺应多头持有仓位；而一旦“5日线被收盘实质性跌破”，系统立即触发最高级别禁令——“绝对禁止再开任何新仓、绝对禁止追涨买入！”；
3. 回调期阶梯式清空：在指数跌破5日线展开回调的时间窗口内，交易者必须顺应反弹波段，将持仓个股“陆陆续续卖得干干净净、全部清仓出局”，绝不将高位浮盈股票死扛至深度套牢；随后耐心保持空仓观望，直到下一次大级别右侧建仓信号出现。

### 适用场景与边界条件
- 适用场景：A股大盘指数（上证、深成、创指）高位破位、牛市短期波段见顶撤退。
- 边界条件：收盘破5日线一票否决一切新买入行为；持仓必须在反抽中全额清空。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
承接高位极端正乖离杀伤律（K-41281）：5日线破位是B向深幅调整正式启动的第一微观确认；为中小市值均线不粘合弃买（S-25810）提供宏观清仓背景。

### 案例与证据
- 案例标的与时间：2021年1月11日A股三大指数破5日线走势。
- 实盘数据特征：上证成交量跌破5日均量，指数收盘跌穿5日线，系统下达刚性禁令：破5日线绝对不可开新仓，必须在回调途中把股票陆续卖得干干净净。
- 逐节证据标定：五日线破位绝对禁止开新仓与回调陆续清仓参见 E-88244。

本策略为针对市场分析师鼓吹“中小创颠倒乾坤、大小盘风格切换”虚假反弹的排雷与防御手册：
1. “大小盘颠倒乾坤”假象破灭：早盘创业板一度出现黄线在上（代表中小盘）、白线在下（代表权重）的大小盘风格切换假象；但盘面迅速被无情现实击碎，午后全市场呈现“起涨共跌、中小盘跌幅更深”的残酷格局（创业板权重跌1.84%而黄线暴跌2.6%）；

- 适用场景：A股权重股高位震荡、中小盘个股诱多脉冲时的假反弹甄别。
- 边界条件：均线未粘合前严禁左侧博反转；中证1000零轴下死叉时一票否决中小盘。

### 案例与证据

- 实盘数据特征：创指黄线早盘假冲锋收盘暴跌2.6%，中证1000不仅均线相差甚远无粘合，收盘更破红豆且MACD零轴下死叉，系统彻底宣告中小创接班梦碎。
