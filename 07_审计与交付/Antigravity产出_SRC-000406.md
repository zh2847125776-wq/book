```markdown
# K-33987 到达K与一色K判定法则
> 来源：SRC-000406（期货_期货投机分析20260127（增强版））· 证据 E-93705
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：到达K（触碰轨道或特定线位的K线）与一色K（满足特定颜色要求的K线）是判定入场条件的两个独立维度，单根K线可因影线触碰且实体同色而身兼两职。

## 它解决什么问题
解决交易者混淆K线触线触发属性与颜色确认属性、无法判断无色K能否作为到达K，以及在人工交易与程序交易执行一色K时因动作方向分歧而产生的选择困惑。

## 如何识别
1. 到达K与一色K是两个完全不同的概念，不可混为一谈（E-93705）。
2. 无色K线同样具备作为到达K的资格，不影响其触线成立（E-93705）。
3. 阴线若带上影线戳破绿线，因其自身既触碰了轨道线位又是阴线，能够同时作为到达K与一色K身兼两职（E-93705）。
4. 人工交易与程序交易在一色K的处理逻辑存在分歧：人工单等待一色K拉回时，以阳线开多单、阴线开空单；程序经过数据统计则反向处理（如阴线开多），以此提升统计效率（E-93706）。

## 适用边界与失效
仅适用于APL系统轨道交互与单根K线属性判定；当盘面缺乏回调直接以单一巨幅单边拉升或跳空破坏结构时，等待一色K拉回的人工逻辑会面临踏空（E-93706）。

## 与其他概念的关系
- 与 [S-20073](file:///C:/tmp/arena_stage/SRC-000406_(增强版)期货_期货投机分析20260127.md) 构成必要前置判定，到达K提供位置接触，一色K提供形态确认。
- 与「无色K」为相互独立关系，K线有无颜色不剥夺其充当到达K的判定资格。
- 与「程序化一色K」为执行逻辑对照关系，人工追求确认胜率，程序追求回测统计效率。

## 案例与证据
在2026年1月27日螺纹钢5分钟盘面中，平台高点出现后，出现无色K线作为到达K触发人工入场点（E-93705）；焦煤5分钟盘面中，程序在平台下降首个像素的阳线开单，而人工则因胜率规则未满足一色K回调而放弃（E-93706）。
```

```markdown
# K-33988 多周期过滤与逆大势交易风控
> 来源：SRC-000406（期货_期货投机分析20260127（增强版））· 证据 E-93707
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：高周期决定主要交易方向，低周期信号频发但可靠率低，逆大势操作必须严格下调风险偏好且在关键线位被突破时立刻止损。

## 它解决什么问题
解决在低周期交易中频繁遭遇假跳空和杂波毛刺被洗出局的问题，以及交易者在逆大级别趋势顺小级别信号开仓时风险暴露过大的风控缺陷。

## 如何识别
1. 低分析周期内交易信号数量多，但信号可靠率显著偏低；避免被虚假K线欺骗的唯一途径是抬高分析周期（E-93707）。
2. 抬高周期的代价是承受的最大回撤幅度显著增大（E-93707）。
3. 当高周期（如60分钟、日线）处于多头趋势时，在5分钟低周期开空单的胜率极低，属于逆大势交易（E-93708）。
4. 逆大势交易的风险偏好必须设定得更小，一旦低周期价格向上突破红线，必须立即平仓止损（E-93708）。

## 适用边界与失效
适用于大级别趋势明朗的单边行情；若大周期外部轨道已经长时间走平（如铜的外部边界走平），失去单边航行效应，则基于高周期定方向的动能优势衰减（E-93708）。

## 与其他概念的关系
- 与「三重周期思想」属于核心风控原则，高周期负责提供开单方向，低周期负责执行进出场。
- 与「APL红线止损」为规则绑定关系，逆势空单以突破红线作为强制止损红线。

## 案例与证据
2026年1月27日沪金日线累计涨幅极高，5分钟开盘反向跳空跌破平台，而抬高至15分钟周期后低开恰好落在轨道上，未被虚假信号欺骗（E-93707）；白银在60分钟与日线多头背景下，5分钟尝试空单若遇红线向上突破必须果断平仓（E-93708）。
```

```markdown
# K-33989 APL负乖离与盖头反压原理
> 来源：SRC-000406（期货_期货投机分析20260127（增强版））· 证据 E-93720
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：价格远离系统价格中枢时产生正负乖离率，横盘不动等待指标下压形成盖头反压，是修复乖离并触发趋势反转的重要演化机制。

## 它解决什么问题
解决交易者仅能理解价格主动下跌修复乖离、无法理解横向震荡等待轨道压制下移（盖头反压）导致趋势转变的机理盲区。

## 如何识别
1. 均线或APL系统存在两种回调修复乖离率的方式：一是价格主动下跌修复正乖离，二是价格横盘等待线位转过来修复乖离（E-93720）。
2. 距离价格中枢越远，乖离率越大；距离中枢越近，乖离率越小（E-93720）。
3. 价格在低位横盘不动，上方线位（如60MA或APL中轨）持续向下压制价格，形成横不出去即转为下挫的结构，称为「盖头反压」（E-93720）。
4. 负乖离率达到极值同样对应绩效值，由APL系统提供的修复逻辑与传统均线修复原理一致（E-93720）。

## 适用边界与失效
适用于价格偏离中枢后进入无序横盘的阶段；若出现外部突发利好直接高开暴涨，横盘盖头反压形态将被暴力摧毁（E-93720）。

## 与其他概念的关系
- 与「主动回调」构成修复乖离率的两种互补方式。
- 与「三减原则」为等价变体关系，传统三减由均线提供，此处由APL轨道中枢提供。

## 案例与证据
2026年1月27日原油（sc9999）5分钟盘面中，空单在横盘压制下运行，价格横向整理等待线位下压形成盖头反压，随后顺势下跌（E-93720）。
```
