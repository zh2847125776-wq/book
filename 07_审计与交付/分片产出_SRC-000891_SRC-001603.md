# 补充 K-30483 20220829美股暴跌历史统计映射与创业板低开区间推演
> 来源：SRC-001603 · 证据 E-52340
> 来源立场：课程讲述者采纳（跨市场统计映射）
> 底本层级：仅增强稿可见

一句话定义：基于外盘暴跌历史样本统计建立映射区间：纳指大跌背景下创业板历史约六成概率低开，低开幅度多集中在1.5%至2.0%区间。

## 如何识别
- 历史样本对照：提取历史上纳斯达克暴跌与次日创业板开盘的13组对照数据，其中8组出现跟随低开，低开幅度最小为1.2%，绝大多数维持在1.5%以上（E-52340）。
- 统计参考区间：据此给出基准低开幅度预估区间为1.5%至2.0%；实盘当日创业板实际低开1.53%，精准落在统计推演范围内（E-52340）。

## 适用边界与失效
外盘映射主要影响早盘集合竞价与开盘点位，不可直接将低开等同于全天单边暴跌，盘中走势仍由国内资金量能与自身均线结构主导。
```

# 补充 K-30097 20220829创业板集合竞价15亿门槛与20亿恐慌大阴线先决条件
> 来源：SRC-001603 · 证据 E-52341
> 来源立场：课程讲述者采纳（竞价量级与实体形态关系）
> 底本层级：仅增强稿可见

一句话定义：低开后走出单边大阴线必须以恐慌性爆量为先决条件：创业板集合竞价需达20亿元以上，实开14.32亿元低于15亿元门槛故未收大阴线。

## 如何识别
- 恐慌抛售量能门槛：低开后多头夺门而出、收出实体大阴线，必须伴随集合竞价巨量（创业板需在20亿元以上，约等同于上证指数40亿元门槛）（E-52341）。
- 实盘量能否决：若集合竞价实际成交低于15亿元常规门槛（实开14.32亿元），表明多头虽受惊但未发生不计成本恐慌踩踏，大阴线概率被技术否决（E-52341）。

## 适用边界与失效
此原则用于开盘瞬间预判全天K线实体级别；若早盘缩量但午后突发重大利空导致盘中放量跳水，则需结合盘中分时量能动态修正。
```

# 补充 K-30045 20220829跳空低开幅度次之而收盘是否留下缺口才是关键
> 来源：SRC-001603 · 证据 E-52342
> 来源立场：课程讲述者采纳（缺口保留与绊脚石判定）
> 底本层级：仅增强稿可见

一句话定义：低开点位高低属于次要次级矛盾，收盘是否留下未补缺口才是核心关键，收盘补齐缺口消除了未来反弹的沉重绊脚石。

## 如何识别
- 缺口残留权重高于低开点位：无论盘中低开幅度大小，关键看收盘最终状态；若收盘留下未回补跳空缺口，将成为未来反弹极其沉重的阻力绊脚石（E-52342）。
- 形态修复定性：当日指数虽然低开收阳未破大位，其最大积极意义仅在于“没有留下向下跳空缺口”，消除了技术死角，但并不代表反转确立（E-52342）。

## 适用边界与失效
未留缺口仅排除了最恶劣的单边下挫形态，若均线系统整体仍处空头排列，震荡修复后依然面临二次下探风险。
```

# 补充 K-0037 20220829下降常态前高与下降趋势线趋于平行构成重压
> 来源：SRC-001603 · 证据 E-52343
> 来源立场：课程讲述者采纳（切线与结构前高共振压力）
> 底本层级：仅增强稿可见

一句话定义：最高点与反弹次高点连成的下降趋势线，与下降常态前高水平位高度趋于平行重合，构成双重共振压制，未突破前上涨无望。

## 如何识别
- 双线平行重叠：由波段最高价与前期高点连接绘制下降趋势线，发现该切线与下降常态前高（2803点）基本平齐并行（E-52343）。
- 突破门槛：在价格有效带量攻克2803点并打破下降常态之前，上方受到切线与水平前高的双重严密压制，不可对反弹抱有不切实际的幻想（E-52343）。

## 适用边界与失效
专用于下降常态初期的反弹空间度量；唯有放量收盘突破下降常态前高三号位，方宣告下跌常态终结。
```

# 补充 K-0552 20220829收阳而MACD穿轴绿柱继续放大属于典型假阳线
> 来源：SRC-001603 · 证据 E-52344
> 来源立场：课程讲述者采纳（假阳线技术特征辨识）
> 底本层级：仅增强稿可见

一句话定义：低开后当日收盘虽呈红色阳线，但收盘价低于前日且MACD死叉穿轴、绿柱持续放大，技术上属于具有强烈迷惑性的假阳线。

## 如何识别
- 假阳线指标特征：K线实体虽然收红，但收盘价低于前一日收盘价；同时MACD指标快线持续击穿零轴，绿色动能柱不但未缩短反而继续放大（E-52344）。
- 空头本质：此类阳线仅仅是多头在低开后的日内抵抗，并未改变指标向下发散动能，真正的大级别杀跌仍在酝酿之中，不可误判为企稳止跌（E-52344）。

## 适用边界与失效
适用于空头破位初期指标发散阶段的假企稳辨识；若次日伴随倍量长阳并使MACD绿柱大幅收窄，则假阳线被多头强力逆转。
```

# 补充 K-0038 20220829下降通道未向上突破前严禁开设任何多头头寸

> 底本层级：仅增强稿可见

一句话定义：指数在日线级别受到客观存在的下降通道绝对压制，在通道上轨被有效放量向上突破前，严禁开设任何多头头寸。

## 如何识别
- 下降通道确立：价格在多空均线空头排列引导下形成倾斜向下的轨道区间，走势受限于轨道内部运行（E-52345）。
- 绝对风控禁令：在下降通道被客观放量向上突破并确认摆脱之前，任何买入行为均属逆势博弈，风险极大，必须坚决空仓防守（E-52345）。

## 适用边界与失效
指导波段交易者的总仓位风控；对于极小周期的日内超跌反抽，即使参与亦仅能以极小仓位快进快出，不可留置波段多单。
```
