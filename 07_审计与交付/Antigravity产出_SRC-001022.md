```markdown
# K-32635 大时间级别支配小时间级别原则
> 来源：SRC-001022（股票_20200214量化技术分析（增强版））· 证据 E-71318
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：当不同时间级别的趋势方向或技术指标发生矛盾背离时，遵循更大时间级别的主导方向裁决多空大势的研判法则。

## 它解决什么问题
解决日线或周线反弹（小周期趋多）与月线趋势（大周期趋空）发生冲突时，交易者容易受困于局部反弹假象、误判主趋势方向及无法确立行情终结预期的决策问题（证据 E-71318）。

## 如何识别
1. 跨周期趋势背离识别：当月线级别变趋空，而周线级别显现多头反弹趋势时，确立跨级别周期冲突（证据 E-71318）。
2. 大级别指标破位定性：月线级别将红豆指标打漏，且时至2月中旬形态已无法逆转（下月确认出绿豆 [原稿作“出绿洲”，疑误]），确认大级别空头主导地位（证据 E-71318）。
3. 小级别服从大级别演变：周线趋多最终必须服从月线趋空（原稿转述为“周线提供月线”[原稿如此，疑误]），小级别反弹到达阻力区即面临尾声竭尽（证据 E-71318、E-71319）。

## 适用边界与失效
- 适用环境：适用于大级别下行通道内的次级别反弹行情定性，用于指导反弹末端防守（证据 E-71318）。
- 失效与转折：若小级别多头强势收复上升趋势线并带量突破2950-2955点构筑的强阻力隔离带，则原有大级别压制格局面临扭转；但在未有效逾越前，大级别压制持续有效（证据 E-71319）。

## 与其他概念的关系
- 与 [S-3002](file:///C:/tmp/arena_stage/SRC-001022_(增强版)股票_20200214量化技术分析.md)（反弹尾声多级别共振左侧减仓方法）构成前提过滤关系，确立大级别为空头压制背景，反弹行情具有阶段性尾声特征；
- 与 [K-32637](file:///C:/tmp/arena_stage/SRC-001022_(增强版)股票_20200214量化技术分析.md)（破位后回测上升趋势线规律）构成宏观与微观互补关系，大级别决定阻力边界，小级别决定回测节奏。

## 案例与证据
上证指数在2020年2月中旬（2020-02-14），月线打漏红豆锁定空头趋势，周线虽有多头反弹但受制于月线空头，行情被定性为接近尾声，上方2950-2955形成难以逾越的隔离带（证据 E-71318、E-71319）。
```

```markdown
# K-32636 均线扣减动态走平推演法
> 来源：SRC-001022（股票_20200214量化技术分析（增强版））· 证据 E-71312
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：通过推算后续交易日预期收盘价与历史基期收盘价的扣减关系，提前测算均线拐头、走平及支撑失效时点的量化分析方法。

## 它解决什么问题
解决移动平均线指标存在滞后性，交易者无法在盘前提前预判均线拐点与支撑失效节点，往往在均线明显掉头后才被动应对的交易痛点（证据 E-71312）。

## 如何识别
1. 均线点位预推算：以5日均线为例，假设下一交易日（周一）平开（以2917为基准），将前4个交易日收盘价（2901、2926、2906、2917）加上平开预估价后除以5，预估下一日5日线位置（约2913附近）（证据 E-71312）。
2. 支撑转失效临界点：当价格跌破基期扣减日收盘价（2901）时，5日均线即由向上转为掉头向下，不再具备均线支撑作用（证据 E-71313）。
3. 走平掉头确认：若后续交易日收出十字星（约2913附近），再下一交易日（周二）5日均线完全走平；在均线走平且成交量不足时，支撑无法守住（证据 E-71313）。

## 适用边界与失效
- 适用环境：适用于短线震荡或反弹阶段中短期均线（如5日线）支撑强度的前瞻推演（证据 E-71312）。
- 失效情况：若后续交易日出现超预期大幅放量大阳线，大幅推高当日实际收盘价，则均线继续向上延伸，原本的走平掉头预判被破坏（证据 E-71313）。

## 与其他概念的关系
- 与 [S-3002](file:///C:/tmp/arena_stage/SRC-001022_(增强版)股票_20200214量化技术分析.md)（反弹尾声多级别共振左侧减仓方法）构成时点确认关系，为左侧减仓提供日线级别均线支撑瓦解的前瞻时间窗口；
- 与 [K-32638](file:///C:/tmp/arena_stage/SRC-001022_(增强版)股票_20200214量化技术分析.md)（60分钟多空线连续压制与三减形态）构成跨周期互补关系，日线级别看均线走平，日内级别看多空线阻力。

## 案例与证据
2020年2月14日上证指数收盘2917，当日5日线为2908；测算若周一平开收在2917附近，5日线将上移至2913附近；一旦跌破2901收盘价则5日线掉头向下；若周一收出2913附近十字星，周二5日线将完全走平（证据 E-71312、E-71313）。
```

```markdown
# K-32637 破位后回测上升趋势线规律
> 来源：SRC-001022（股票_20200214量化技术分析（增强版））· 证据 E-71309
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：价格跌破既有的上升趋势线后，无论是以盘中击穿还是跳空缺口形式破位，通常都会出现向上回抽确认原趋势线压力位的技术行为。

## 它解决什么问题
解决趋势线破位后交易者在反抽过程中误以为突破重启而盲目追涨、或未能把握回抽受阻这一高位减仓离场时机的实战交易误判问题（证据 E-71309）。

## 如何识别
1. 趋势线破位：价格跌破前期在K线上精准绘制的上升趋势线（如连接2733.92与2857.32构筑的趋势线），破位形式包含盘中直接跌破或跳空缺口跌破（证据 E-71309）。
2. 回测行为展开：破位后价格展开反抽，连续数个交易日均受到原上升趋势线的反压压制（证据 E-71309）。
3. 压力有效确认：回测未能收复趋势线，且上方缺口上限（2955）与二合一压力位（2950）未被触碰，重心随即下移（证据 E-71309）。

## 适用边界与失效
- 适用环境：适用于各周期确立的上升趋势线被有效击破后的反抽阻力研判（证据 E-71309）。
- 失效情况：若回测不仅收复上升趋势线，且强势放量越过2950-2955隔离带，则回测演变为趋势修复或真突破，破位压制预判失效（证据 E-71309、E-71319）。

## 与其他概念的关系
- 与 [K-32635](file:///C:/tmp/arena_stage/SRC-001022_(增强版)股票_20200214量化技术分析.md)（大时间级别支配小时间级别原则）构成逻辑补充，破位回测是小级别顺应大级别空头压制的典型技术走势；
- 与 [S-3002](file:///C:/tmp/arena_stage/SRC-001022_(增强版)股票_20200214量化技术分析.md)（反弹尾声多级别共振左侧减仓方法）构成空间阻力维度的研判依据。

## 案例与证据
上证指数在2020年2月14日及此前连续三天，均受到由2733.92与2857.32画出的短时上升趋势线压制，破位后反复回测但始终未能尝试2955缺口上限与2950压力位，重心开始下移（证据 E-71309）。
```

```markdown
# K-32638 60分钟多空线连续压制与三减形态
> 来源：SRC-001022（股票_20200214量化技术分析（增强版））· 证据 E-71315
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：价格在60分钟级别反弹中连续三次向上冲高均受阻于多空线，形成三度冲顶不过的受压滞涨形态（原稿称“三减形态”[原稿如此，疑误]）。

## 它解决什么问题
解决日内分时级别反弹波段中缺乏精确受阻信号、交易者难以识别日内滞涨拐点并犹豫不决错失左侧减仓时机的问题（证据 E-71315）。

## 如何识别
1. 观察周期与指标：在60分钟K线周期上观察价格与多空线动态位置（证据 E-71315）。
2. 连续三次压制过程：上午收盘前多空线为2928、最高价达2926受阻；下午第一小时多空线为2925、最高价达2924受阻；下午最后一小时收盘时多空线为2925、最高价达2927受阻（证据 E-71315）。
3. 形态确立与跳水：三次冲击多空线均无法逾越，三减形态形成，指数随即掉头向下跳水（证据 E-71315）。

## 适用边界与失效
- 适用环境：适用于反弹行情中60分钟级别的微观高点确认与左侧减仓时机判定（证据 E-71315）。
- 失效情况：若价格带量突破多空线并在回测中确立多空线为有效支撑，则连续压制失效，形态转为多头向上突破（证据 E-71315）。

## 与其他概念的关系
- 与 [S-3002](file:///C:/tmp/arena_stage/SRC-001022_(增强版)股票_20200214量化技术分析.md)（反弹尾声多级别共振左侧减仓方法）构成直接触发关系，是执行日内左侧减仓的微观形态依据；
- 与 [K-32636](file:///C:/tmp/arena_stage/SRC-001022_(增强版)股票_20200214量化技术分析.md)（均线扣减动态走平推演法）相互呼应，共同验证反弹动能衰竭。

## 案例与证据
2020年2月14日上证指数60分钟K线级别上，全天多空线先后位于2928、2925、2925，指数对应最高点分别为2926、2924、2927，三次受阻形成形态后快速下行跳水（证据 E-71315）。
```
