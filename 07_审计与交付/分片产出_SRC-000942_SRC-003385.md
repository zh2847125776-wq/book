# 补充 K-25904 单边品种主动参与与日盘纯净度：多晶硅高收益背后是少磨损的趋势环境
> 来源：SRC-000942 · 证据 E-53880
> 来源立场：课程讲述者采纳（单边多、操弄少的品种应积极参与）
> 底本层级：仅增强稿可见

一句话定义：欧线集运、多晶硅、工业硅等单边行情较多且人为操弄较少的品种，具备趋势策略的天然优势，应积极主动参与而非因短期磨损退缩。

## 如何识别
- 单边与操弄的组合优势：趋势订单最需要方向持续性；单边多、来回操弄少的品种能让持仓更完整地吃到趋势（E-53880）。
- 多晶硅的日盘结构：仅有白天交易，K线连续且外盘噪音较少，适合观察趋势持续性与回撤承受力（E-53880）。

## 适用边界与失效
适用于CTA组合中筛选趋势连续性较高、流动性足够且不易被短期噪音反复扫损的品种。
```

# 补充 K-25880 趋势订单涨停缺口代价：机械持仓吃到大趋势却无法兑现单日涨停超额
> 来源：SRC-000942 · 证据 E-53881
> 来源立场：课程讲述者采纳（趋势订单的规则化持仓与涨停日内收益不可兼得）
> 底本层级：仅增强稿可见

一句话定义：趋势订单能够长时间持有并捕捉大单边，但因规则不做盘中主动止盈，遇到当天涨停时无法完整吃到涨停带来的额外利润，这是系统化持仓必须接受的机会成本。

## 如何识别
- 趋势与短线的收益差异：趋势模型关注波段终值，不追求每个日内峰值；涨停当天的“白给利润”可能在后续回撤中重新定价（E-53881）。
- 不以单日得失推翻系统：若为了吃涨停而频繁人工干预，可能失去后续更大的趋势段，因此需以长期曲线评估策略取舍（E-53881）。

## 适用边界与失效
适用于比较趋势持仓、日内止盈和人工干预三种模型的收益结构。
```

# K-25952 大单边后磨损不可预测律：超级趋势结束后横盘时长与回撤起点无法事前界定
> 来源：SRC-000942 · 证据 E-53882
> 来源立场：课程讲述者采纳（大单边后的磨损阶段缺乏可靠时间边界）
> 底本层级：仅增强稿可见

一句话定义：大单边出现后，策略通常会进入磨损期，但磨损何时开始、会持续多久无法可靠预测，不能用短期回撤去判断趋势系统已经失效。

## 如何识别
- 趋势后的均值回归：超级行情结束后，盘面常从单方向切换到横盘，连续小亏是策略适应新状态的正常成本（E-53882）。
- 放弃精确择时幻觉：任何人都无法提前知道横盘会持续多少天，只能按预设风险继续运行、降低暴露或阶段性暂停（E-53882）。

## 适用边界与失效
适用于趋势策略在创出阶段新高后的回撤管理和运行状态评估。
```

# K-25953 逆向复盘识别可避免亏损：阴线与程序回测信号冲突时人工可少亏但难完全避免
> 来源：SRC-000942 · 证据 E-53883
> 来源立场：课程讲述者采纳（人工逆向识别部分阴线可优化但不能消除亏损）
> 底本层级：仅增强稿可见

一句话定义：部分程序订单在阴线环境中出现后续止损，人工凭盘面方向可能比程序少亏一些，但程序回测并非实时预测，人工也无法保证完全避免该类亏损。

## 如何识别
- 人工与回测的边界：回测模型只能按照既定历史规则执行；人工能利用新出现的阴线稍早退出，但仍无法知道随后是否会反弹（E-53883）。
- 少亏不等于免亏：人工优化的价值是降低单笔损失，而不是把所有失败交易变成盈利交易，评估仍须回到长期样本（E-53883）。

## 适用边界与失效
适用于比较主观盘面干预与程序化回测在趋势转折期的优缺点。
```

# 补充 K-0425 持仓时间与利润正相关：突破后延长持有至第六交易日显著提升平均净收益
> 来源：SRC-003385 · 证据 E-53890
> 来源立场：书中作者观点（同一规则下仅改变持仓时间，持有更久获得更高利润）
> 底本层级：仅增强稿可见

一句话定义：在买入规则、卖出规则和标的完全不变的前提下，仅将持仓从当日延长至后续交易日，平均每股收益显著提高，时间是趋势交易的利润放大器。

## 如何识别
- 单变量实验：同一操作方式仅改变持有期限，延长至第二、第六交易日，结果显示平均利润与总收益同步提升（E-53890）。
- 以停止条件为边界：持有并非无条件死扛，而是持续到目标时间窗口结束或股票先触发停止条件，两者先到者执行卖出（E-53890）。

## 适用边界与失效
适用于短线动量和波段交易中评估持有期限对期望收益的影响。
```

# 补充 K-0176 时间是利润助手与耐心持仓：收盘前抛售会错失光头光脚大波段
> 来源：SRC-003385 · 证据 E-53891
> 来源立场：书中作者观点（耐心持有而非收盘前轻易出售）
> 底本层级：仅增强稿可见

一句话定义：时间是盈利的最好助手，大波段K线往往以光头或光脚形态持续运行；若在收盘前因短期波动过早卖出，就无法捕捉完整趋势。

## 如何识别
- 大K线的趋势信息：光头光脚K线显示单方向力量持续到收盘，过早兑现会丢失剩余趋势空间（E-53891）。
- 耐心不等于放弃止损：持有应服从既定退出机制，只有在没有触发停止条件时，才让时间发挥复利作用（E-53891）。

## 适用边界与失效
适用于趋势交易中区分正常波动与真正失效、减少过早卖飞。
```

# K-25954 波动性突破构建趋势：爆炸性单向运动持续至相反力量同等爆发
> 来源：SRC-003385 · 证据 E-53892
> 来源立场：书中作者观点（价格爆炸性突破形成趋势并持续到反向力量出现）
> 底本层级：仅增强稿可见

一句话定义：价格在小时、周或月级别出现爆炸性上扬或下挫，即构成明显单边行情；市场通常会持续沿该方向运动，直到反向出现同等或更强的爆发力量。

## 如何识别
- 爆发幅度与持续性结合：不是所有上涨都叫趋势，需同时出现显著幅度、方向一致和持续运动（E-53892）。
- 反向力量才是趋势终止条件：在没有同等强度反向爆发前，不应因普通回调轻率判断主趋势结束（E-53892）。

## 适用边界与失效
适用于股票、期货和商品市场的动能趋势识别与顺势持仓。
```

# K-25955 前一日波幅突破测距法：今日超过昨日波幅若干比例即视为趋势方向变化
> 来源：SRC-003385 · 证据 E-53893
> 来源立场：书中作者观点（前一日波幅作为当日爆发性突破的比较基准）
> 底本层级：仅增强稿可见

一句话定义：以前一交易日的价格波幅作为基准；若今日波幅超过昨日波幅若干百分比，说明市场受到了方向性刺激，趋势可能已经发生变化。

## 如何识别
- 波幅基准标准化：昨日小麦波幅12美分，今日若显著超过该基准，就不再是普通噪音，而是需要重估方向概率的有效信息（E-53893）。
- 波幅突破不等于立即入场：它首先用于判断趋势是否可能改变，仍需结合时间、位置和其他入场规则确认（E-53893）。

## 适用边界与失效
适用于商品、指数及股票的波动性突破初筛与动能确认。
```
