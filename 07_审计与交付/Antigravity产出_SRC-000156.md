# S-3158 开板收阴破五日线连续涨停退出法
> 来源：SRC-000156（专题_技术专题_从跌幅较大个股看风险（增强版））· 证据 E-72927
- 性质：局部方法
- 规则版本：讲师个人实战经验卖出规则
- 完整度分级：已给方向
- 效果证据：原文明确指出“如果你严格按照开板收银破五日线这三个顺序往出卖的话 基本收益 还是可以得到保障的 而且还应该是所有策略里头相对靠前的”（E-72928）

## 目的与适用环境
本方法旨在解决持有个股经历连续一字涨停后，在高位缺乏明确纪律导致浮盈大幅回吐甚至遭遇跌停闷杀的获利保护与退出问题。适用于A股市场中连续一字涨停或超强势连板标的打开涨停板后的阶段性多头退出管理。（E-72927）

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 个股经历连续一字涨停或多日连板加速上涨 | 日线级别持仓期 | E-72927 | 原稿未限定最少涨停天数要求 |
| 形态或指标形成 | 涨停板被打开（开板），盘中封单松动且未能回封 | 开板当日盘中 | E-72927 | 开板即触发第一阶卖点预警 |
| 确认 | 开板当日收盘收出阴线（收阴），或后续收盘跌破5日均线（破五日线） | 日线收盘时点 | E-72927, E-72929 | 破五日线以收盘价最终确认 |
| 入场 | 原文未提供（本方法专用于持仓获利兑现，非建仓买入规则） | 无 | E-72927 | 原稿明确禁止逆向用于买入 |
| 初始止损 | 原文未提供（规则针对盈利脱离成本区后的跟踪退出） | 无 | E-72928 | 非入场初期的防守参数 |
| 仓位与资金 | 开板可全部平仓，亦可先行卖出一半；后续收阴与破5日线出清剩余持仓 | 卖出一至卖出三执行点 | E-72928 | 原稿未限定死具体的仓位百分比硬性配比 |
| 持仓与跟踪 | 开板未全出者，持仓观察当日是否收阴及5日均线得失，可辅助结合RSI等指标 | 日线收盘跟踪 | E-72928, E-72929 | 原文未给出辅助指标的具体参数界限 |
| 加减仓 | 卖一为开板卖出；卖二为开板收阴卖出；卖三为跌破5日均线卖出 | 分步触发时点 | E-72927, E-72929 | 原稿强调为连续三个梯级卖出信号 |
| 止盈与退出 | 严格依照“开板、收阴、破5日线”三个顺序完成清仓，不追求卖在绝对最高价 | 信号确认时点 | E-72927, E-72928 | 放弃摸顶幻想以保住大部分连板收益 |
| 失效与放弃 | 严禁将本套逻辑逆向镜像用于连续跌停抄底；连续跌停开板收阳站上5日线不可买入 | 跌停板打开时 | E-72930 | 涨跌停多空机制不对等，不可反向套用 |

## 规则之间怎样衔接
以涨停板打开作为卖一初始动作，锁定首批利润或建立心理防线；若当日收盘进一步收阴，则确认抛压加剧，执行卖二动作继续降仓；若后续交易日收盘跌破5日均线，则表明短期超强动能衰竭，触发卖三动作执行最终清仓，形成层层锁盈的离场链条。（E-72927, E-72929）

## 案例和失败方式
典型成功案例为蓝英装备（300293），在连续4个涨停开板后按开板、收阴及破5日线顺序分步出局；典型失败方式为持股者贪恋最高价不愿按顺序离场，随后遭遇放量长上影墓碑线甚至连续跌停打击，造成盈利大幅回吐。（E-72929）

## 版本分歧与证据限制
本策略属于以K线与均线为基准的稳健退出法，与书中提及的华丁老师“盘中分时回撤固定数值（如数值4或回撤10%）即行退出”的策略存在分歧；原稿未提供开板首日减半或全出的具体资金量化依据，属于方向性指导。（E-72928, E-72933）

# K-32962 连续涨跌停卖出与买入不对等原则
> 来源：SRC-000156（专题_技术专题_从跌幅较大个股看风险（增强版））· 证据 E-72930
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：连续一字涨停后可依据「开板、收阴、破五日线」依次作为卖出止盈信号，但连续一字跌停后即使出现「开板、收阳、站上五日线」，也绝对不可作为抄底买入信号，多空两端在规则应用上完全不对等。（E-72930）

## 它解决什么问题
解决交易者在单边暴跌极端行情中，机械对称套用多头技术形态与指标，在个股连续跌停开板收出首根阳线时盲目进场抄底，进而遭遇二次加速暴跌甚至再度连续跌停的具体交易亏损问题。（E-72930）

## 如何识别
1. 标的处于连续一字跌停或单边断崖式急速下跌形态中；（E-72930）
2. 盘中跌停板被打开并收出阳线，或收盘站上5日均线；（E-72930）
3. 判定该信号为虚假反弹或极高风险区域，严格禁止作为买入开仓信号；（E-72930）
4. 明确将连涨卖出逻辑与连跌买入逻辑彻底隔离，不可反向镜像复制。（E-72930）

## 适用边界与失效
适用于A股极端连续涨跌停行情。即使个股跌停开板后偶然走出强力反弹，在交易系统内亦属于必须放弃的高风险交易，不得因少数特例而推翻“连续跌停开板收阳站上五日线不可抄底”的防守边界。（E-72930, E-72931）

## 与其他概念的关系
与「开板收阴破五日线连续涨停退出法（S-3158）」构成正反方向的边界约束，明确了多头离场规则绝不可反转为空头入场规则；与「三减形态（E-72941）」在弱势股防守哲学上互为补充，强调在下跌趋势未扭转前坚决不抄底。（E-72930, E-72941）

## 案例与证据
讲述者在复盘连续跌停个股时批评所谓的跌停抄底战法，明确指出“想亏的多 你就在跌 跌 停的时候 第一个阳线买进 那你可能亏的更多 对不对 啊 所以说呢 虽然开板收阴破五日线 可以参考连续涨墙的买出 但是啊 我们说啊 连续跌停 开板收羊站上五日线 是不可以抄底买进啊 这是两个完全不对等的观念啊”。（E-72930, E-72942）
```

# K-32963 跌破20日均线备用闸防守壁垒
> 来源：SRC-000156（专题_技术专题_从跌幅较大个股看风险（增强版））· 证据 E-72935
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在持仓跟踪过程中，为防范盘中跌破20日均线后因等待尾盘确认而遭遇单日快速跌停或次日一字跌停，在盘中预先设定跌破20日均线的一定百分比作为不可接受的止损防线，一旦触及立即执行清仓。（E-72935, E-72936）

## 它解决什么问题
解决常规“等收盘确认跌破20日均线才卖出”纪律在遭遇主力快速砸盘或闪崩时，持仓者因盘中被动等待下午拉回，导致尾盘直接封死跌停无法成交、次日遭遇一字跌停严重闷杀的交易执行盲区问题。（E-72935, E-72937）

## 如何识别
1. 个股处于20日均线上方的多头持仓或防守跟踪周期；（E-72935）
2. 盘中股价跌破20日均线（如早盘9:45前后出现击穿）；（E-72935）
3. 跌破幅度达到或超过交易者预先设定的止损百分比壁垒（原稿未给固定统一参数，由交易者预设不可接受阈值）；（E-72935）
4. 不抱有“下午可能收回”或“下方颈线能提供支撑”的侥幸幻想，触发即无条件止损离场。（E-72935, E-72940）

## 适用边界与失效
适用于防范单日急速砸盘与断崖式跌停的极端风险。若市场处于宽幅震荡市，盘中击穿备用闸止损后下午股价重新被主力拉回站上均线，则会产生被动踏空或摩擦止损成本；原稿明确未给出全市场通用的具体百分比数值。（E-72935, E-72940）

## 与其他概念的关系
是对「三减形态中收盘破20日均线离场」常规规则的极端风险防御性补充；在盘中触发该备用闸时，与「危急跳水行情的向下深挂单避险纪律（K-32964）」配合执行以确保即时成交。（E-72936, E-72940, E-72942）

## 案例与证据
神州数码（000034）在2020年3月27日早盘9:45跌破20日线28.91元，讲述者指出若未设盘中备用闸壁垒，下午将无法收回并直接遭遇跌停；东方银星（600753）3月26日收盘破20日线19.32元未走，次日直接一字跌停开盘。（E-72935, E-72936, E-72937）
```

# K-32964 危急跳水行情的向下深挂单避险纪律
> 来源：SRC-000156（专题_技术专题_从跌幅较大个股看风险（增强版））· 证据 E-72938
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在盘中发现行情恶化、个股出现闪崩或快速下杀时，严禁挂买一、买二或卖一、卖二价格委托，必须保持盯盘并将卖单价格大幅往低档深挂以确保即时成交离场。（E-72938, E-72939）

## 它解决什么问题
解决个股急速跳水或主力一把打向跌停时，散户若将委托单挂在买一或买二浅档，因跌速过快导致委托瞬间变为高位废单而反复无法成交，最终眼睁睁看着个股封死跌停且丧失出逃机会的交易踩踏问题。（E-72938, E-72939）

## 如何识别
1. 交易者在持仓出现险情时必须保持实时盯盘；（E-72938）
2. 盘中股价出现失去抵抗的快速下杀（如分时图从跌2%迅速扩大至跌5%以上）；（E-72938, E-72939）
3. 卖出委托时，坚决不挂买一价、买二价，更不可挂卖一价、卖二价；（E-72938, E-72939）
4. 采取“往下低低的挂”方式连续向深档低价报单，以牺牲部分滑点为代价换取全额成交。（E-72939）

## 适用边界与失效
专用于突发性闪崩跳水、流动性可能在数分钟内完全丧失的极端避险时刻。若在常规慢速阴跌、缩量回调或正常震荡中采用此法，会导致不必要的滑点亏损与被动贱卖。（E-72939）

## 与其他概念的关系
属于交易委托执行层面的微观实战技术，是「跌破20日均线备用闸防守壁垒（K-32963）」以及各类破位止损动作在极端盘面下的底层执行保障。（E-72938, E-72940）

## 案例与证据
东方银星（600753）在2020年3月26日下午1:10左右，分时自跌2%处快速跳水，讲述者明确指出“千万在想跑的时候 不要挂买一价买二价 你就往下滴滴的挂 它总归上面会成交的”，若挂买一买二瞬间就会失效并被封死跌停。（E-72937, E-72938, E-72939, E-72941）

# C-20435 金自天正（600560）天量天价无背离次日跌停与分时回撤对比案
> 来源：SRC-000156（专题_技术专题_从跌幅较大个股看风险（增强版））· 证据 E-72931
日期：2020年3月26日-3月27日
品种：A股 金自天正（600560）
合约：股票现货（不适用期货合约）
周期：日线、分时
关联方法ID：S-3158、K-32962
来源ID：SRC-000156
证据性质：讲师课堂复盘实盘K线与分时走势

## 当时已知信息
截至2020年3月26日（周四），金自天正放量大涨，天价与天量同一天出现，且日线级别MACD无顶背离，均线多头排列，技术形态看似无懈可击。（E-72931, E-72934）

## 原计划与触发
张老师常规稳健策略为持股直到收盘跌破5日均线卖出；书中提及的华丁老师策略为主张在盘中分时图出现固定数值（如数值4或回撤10%）即行止盈。（E-72932, E-72933, E-72934）

## 后续过程与结果
该股在周四强势后次日直接跌停，甚至后续出现跳空低开连续跌停。分时图上出现了短线10%的大幅回撤。若等待收盘破5日线，则直接被跌停闷杀；若采用分时回撤10%策略则能提前保住大部分利润。（E-72932, E-72934）
