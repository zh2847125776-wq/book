```markdown
# 补充 K-0528 四月十日三种多周期仓位口径必须分开记录
> 来源：SRC-000885 · 证据 E-52170、E-52171、E-52172、E-52173
> 来源立场：课程讲述者采纳（列举可选方案，不评统一优劣）
> 底本层级：仅增强稿可见

一句话定义：本课以PVC仅5分钟支持、60分钟和日线不支持为例，并列按三周期各三分之一、按大周期支持数决定零半全、只看5分钟三种选择，而非一套同时适用的仓位表。

## 如何识别
1. 方案一：5分钟、60分钟、日线各分配三分之一；明确5分钟不支持不做（E-52170）。PVC拟开三手而两大周期不支持，则只试一手；这只是示例，不是资金三分之一或固定保证金比例。
2. 方案二：一个大周期都不支持则不做，有一个支持下一半，两个都支持才下全部（E-52171）。这里的大周期承接60分钟、日线；“全部”相对于本来计划的订单仓位，不代表账户满杠杆。
3. 方案三：只要5分钟有机会就做，并称没有谁好谁坏（E-52172）。这是另一套过滤选择，不能用其取消方案一的前提后仍声称遵循同一模型。
4. 环境是PVC在60分钟顶住中轨、日线亦不支持（E-52173）。视觉分析把A/B/C分仓记号猜成波浪理论，不采用。

## 适用边界与失效
母卡原本记录另一课的顺逆势半仓模型，本补充保留日期版本，不覆盖其原规则，也不把“两个逆势再减半”的疑音用本课补齐。没有账户风险上限、各品种风险相关性、止损距离或调仓流程，不能据此构造完整可执行策略。讲述者所称大周期不支持胜率低未附统计检验；本课PVC没有实际结果。

## 与其他概念的关系
参考C-0406已经保存PVC候选示例；本补充专门厘清其所提三方案，避免把课堂自我修正的“典型第三种”误认成唯一推荐。原卡与本补充均非收益保证。
```
