```markdown
# K-41136 应急预案五要素框架与止损后重新买入标准模型
> 来源：SRC-002946 读书_交易择时技术分析_01（增强版） · 证据：E-87840, E-87841, E-87842

### 核心概念与运作机理
在专业交易体系中，确保投资成功的核心不在于精准预测行情，而在于开盘前完备的“如果-则（If-Then）”应急预案框架。一套健全的应急预案必须完整覆盖五大核心情景：
1. 异动离场点：头寸表现与预期不符时的果断离场触发条件；
2. 重新进场标准：股票因回撤触发红线止损离场后，若重新回到上升轨道并清洗弱势持有者，系统严禁将该股票自动永久废弃，必须制定基于重新放量突破或重返支撑线的再次买入标准；
3. 盈利目标止盈：实现预设风险回报比时的阶段获利了结方案；
4. 利润保护机制：在出现浮盈后由初始刚性止损平滑切换为追踪移动止损（Trailing Stop）；
5. 突发黑天鹅应对：面对隔夜突发灾难事件或极端单边反向跳空时的抗压执行纪律。
专业交易者恪守“小亏大赚”哲学，将止损视为正常商业成本，在果断止损保全本金的同时，随时保持对优质标的二次右侧上车的客观冷静。

### 适用场景与边界条件
- 适用场景：美股与A股趋势跟踪、成长股突破交易及黑天鹅突发事件防守。
- 边界条件：买入前必须前置确立初始红线止损；止损后严禁带报复情绪立即抄底，必须等待标的明确重回上升轨道并出现右侧确认信号。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
为强势与弱势双重出场策略（S-25695）提供框架基石：第三、四要素直接派生出高位主动获利与回撤被动止盈；与大盘关后整理时空窗口（K-41137）形成宏观与微观的防守协同。

### 案例与证据
- 案例标的与时间：马克·米奈尔维尼冠军交易应急预案体系。
- 实盘数据特征：展示了某只优质成长股在建仓后遭遇快速洗盘回撤触发止损，交易者果断止损后保留在自选池，待其重新放量突破回升至轨道上方时果断二次接回，最终捕获数倍主升浪。
- 逐节证据标定：应急预案五大情景参见 E-87840，初始止损与追踪止损切换参见 E-87841，重新进场标准与非废弃纪律参见 E-87842。
```

```markdown
# K-41137 破位后关后整理标志阴线度量横与时空双向突破判据
> 来源：SRC-001216 股票_20201223量化技术分析（增强版） · 证据：E-87844, E-87845, E-87846

### 核心概念与运作机理
当指数或个股跌破关键上升趋势线后，次日走势若完全被限制在破位标志性大阴线的实体幅度以内震荡，在形态学上定性为典型的“关后整理”。交易者不可将关后整理主观武断认定为必然破位下跌，必须建立严密的“时空双向突破验证判据”：
1. 空间度量横：以破位标志阴线的高低点及中位线为基准构建方块箱体，上方核心阻力为多空线与原上升趋势线（如3393点）；
2. 时间倒计时窗口：反弹中继结构的成立具有严格的时间衰竭极限（如60分钟级别通常约束在5个周期以内）；
3. 时空判决法则：若在时间窗口耗尽前（如次日收盘前）能够放量突破方块上轨并收复多空线与趋势线，则前日大跌被定性为“洗盘假摔”，多头行情延续；反之，若在规定时间窗口内无法突破，系统判定向上反抽动能衰竭，随后极大概率顺势向下打穿标志阴线低点展开主跌。

### 适用场景与边界条件
- 适用场景：宽基指数及个股在遭遇单日大阴线破位后的次日企稳假象辨析与多空方向裁决。
- 边界条件：整理若未突破标志阴线实体上轨，一律按弱势反抽对待；必须在规定时间周期内完成突破，拖延即视为向下破位信号。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
与子孙三代母子孕线弱势收敛（K-41138）共同构成破位后震荡体系：前者从标志阴线时空度量横给出突破条件，后者从K线微观包含结构揭示动能衰退特征。

### 案例与证据
- 案例标的与时间：2020年12月23日上证指数60分钟级别盘面推演。
- 实盘数据特征：全天四个小时震荡完全落在前日大阴线实体内部，系统建立3393点（趋势线与多空线共振位）空间阻力与次日收盘前5周期时间窗口，明确若不能突破则将向下破位。
- 逐节证据标定：标志阴线关后整理度量横参见 E-87844，5周期时间窗口与中继要求参见 E-87845，时空突破真假判定法则参见 E-87846。
```

```markdown
# K-41138 子孙三代母子孕线三层包含形态与动能极度收敛律
> 来源：SRC-001216 股票_20201216量化技术分析（增强版） · 证据：E-87847

### 核心概念与运作机理
在K线形态学中，“母子孕线（Harami）”代表原有动能的停顿；而当出现“前天的阳线包含昨天的阴线，昨天的阴线又完整包含今天的阳线”时，构成极其罕见的“子孙三代母子孕线（三重连续内包线）”。该形态反映了市场多空博弈力量在极窄空间内的极致内敛与流动性深度观望，属于盘面极端弱势且方向极度钝化的典型表象。三重内包形态无法自行化解之前的破位疑惑，其本质类似于微观分时上的极致三角形收敛整理，能量积蓄已达临界点，随后必然以剧烈的单边突破（放量长阳突破外包母线高点或跌破母线低点）来打破僵局。

### 适用场景与边界条件
- 适用场景：A股指数及强势个股在高位回调过程中的连续缩量窄幅震荡定性。
- 边界条件：在三重包含结构未发生有效方向突破前，严禁主观押注方向；必须以最外层母线的高低点作为真突破的确认基准。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
作为微观K线结构，与关后整理度量横（K-41137）形成大小尺度的共振：三层内包孕线往往嵌套在关后整理的标志阴线内部，预示着时空变盘窗口的即将来临。

### 案例与证据
- 案例标的与时间：2020年12月23日创业板指数（399006）日线K线组合。
- 实盘数据特征：创指连续三日呈现“首日大阳包含次日大阴、次日大阴又包含第三日小阳”的子孙三代母子孕线，全天缩量收阴虽守住5日均线，但形态极度弱势等待变盘突破。
- 逐节证据标定：子孙三代母子孕线定义与弱势收敛特性参见 E-87847。
```

```markdown
# S-25695 强势主动卖出与弱势保护性止盈双轨出场策略
> 来源：SRC-002946 读书_交易择时技术分析_01（增强版） · 证据：E-87843

### 策略逻辑与决策流程
本策略为基于持仓心理学与风险回报比最大化的专业卖出体系，确立“宁可后悔少赚，绝不容忍浮盈变亏损”的刚性铁律，划分两种标准化出场执行路径：
1. 强势主动卖出（Selling into Strength）：当股票走出凌厉主升浪、达成交易计划预设的全部盈利空间（如自10元大幅飙升至50元），且市场情绪处于极度亢奋、成交量出现高潮脉冲时，专业交易者主动逢高分批获利了结，放弃赚取最后一枚铜板的贪婪幻想（后续再涨至60元与己无关）；
2. 弱势保护性止盈（Selling into Weakness）：若股票未能达成强势暴利目标，而是冲高后出现顶部形态反转回落，当价格自高位回撤至预设的“利润保护阈值”（如自50元高点回撤跌破35-40元关键均线或支撑位）时，系统坚决触发被动止盈离场，绝对禁止让一笔丰厚的浮盈单滑落为亏损单；
3. 执行复盘与情绪隔离：无论以何种方式出场，离场后严禁为“卖早了”或“未能卖在最高点”产生挫败感，通过机械化规则切断情绪内耗。

### 适用场景与边界条件
- 适用场景：波段持仓盈利脱离成本区后的获利了结、防范主升浪转大回撤坐过山车。
- 边界条件：浮盈达到一定比例后必须上调止盈线至成本区上方；严禁浮盈单变成亏损出场。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
直接承接应急预案五要素框架（K-41136）：将第三要素（盈利目标）与第四要素（利润保护）具象化为强势与弱势双轨实操逻辑。

### 案例与证据
- 案例标的与时间：专业成长股机构投资获利了结模型。
- 实盘数据特征：详述了股票从10元涨到50元的主动强势卖出逻辑，以及从50元回落跌破40元保护线必须坚决弱势止盈的典型实操对比。
- 逐节证据标定：强势卖出与弱势卖出双轨逻辑参见 E-87843。
```
