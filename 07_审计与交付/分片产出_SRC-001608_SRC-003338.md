# 补充 K-0289 读书领读股票魔法师二跟踪平均持有时间防止持亏过长卖盈过早
> 来源：SRC-003338 · 证据 E-52480
> 来源立场：书中作者观点（马克·米勒维尼交易真相复盘法）
> 底本层级：仅增强稿可见

一句话定义：交易者必须独立统计盈利与亏损头寸的平均持仓时间；若盈利平均持有时间小于亏损平均持有时间，暴露出致命的持亏过长、卖盈过早缺陷。

## 如何识别
- 持仓时长对比：统计历史样本中盈利单的平均持仓天数与亏损单的平均持仓天数（E-52480）。
- 致命缺陷诊断：若亏损持有时长显著大于盈利持有时长，表明交易者在浮亏时心存侥幸死扛拖延，而在浮盈时因恐惧回撤过早兑现，系统期望值严重受损（E-52480）。

## 适用边界与失效
指导个人交易数据的量化审计；在系统性暴跌或单边牛市中应结合大盘背景审视。
```

# K-25392 股票魔法师交易三角形模型即胜率平均盈利与平均亏损三维构架
> 来源：SRC-003338 · 证据 E-52481
> 来源立场：书中作者观点（马克·米勒维尼交易三角模型）
> 底本层级：仅增强稿可见

一句话定义：如同摄影曝光三要素（ISO、光圈、快门），交易系统由“平均获胜规模、平均亏损规模与获胜胜率”三条边构筑起决定成败的交易三角形。

## 它解决什么问题
解决交易者盲目孤立地追求单边高胜率或单一高盈亏比，忽视三者之间相互制约、动态平衡的系统工程本质。

## 如何识别
- 三条边构成：边一为所有盈利单的平均盈利幅度；边二为所有失败单的平均亏损幅度；边三为盈利交易次数占比的胜率（E-52481）。
- 动态平衡机制：如同摄影三角形曝光调节，提升一边往往需要权衡另外两边；唯有三者乘积产生的数学期望保持正向且拉大优势，系统方能持续稳定复利（E-52481）。

## 适用边界与失效
所有量化与规则化交易系统的通用底层模型；三要素数据必须基于客观统计的大样本真实交易记录。

## 与其他概念的关系
母库 K-0444 记录用平均收益倒推止损；本卡确立米勒维尼以胜率、平均盈、平均亏构筑三维交易三角形的系统框架。
```

# 补充 K-0440 读书领读股票魔法师二不同交易策略数据必须独立建表严格隔离统计
> 来源：SRC-003338 · 证据 E-52482

> 底本层级：仅增强稿可见

一句话定义：不同周期的交易策略（短线、波段、长线）或不同逻辑的子策略，其统计报表必须完全独立建档，严禁混在一起计算平均值。

## 如何识别
- 策略分类隔离：横盘突破策略与三加进场策略的回报表严禁混淆，SFP策略与MZ策略亦不可混合计算（E-52482）。
- 结论失真规避：将高胜率低盈亏比的短线与低胜率高盈亏比的波段混合统计，会彻底污染样本分布，导致平均亏损与平均盈利失去指导实盘的基准意义（E-52482）。

## 适用边界与失效
适用于多策略并行的系统化交易账户；单策略交易者则需按不同市场环境分别建档。
```

## 如何识别
- 防火墙刚性锁定：在钟形曲线左侧设定能承担损失的最大极限作为硬性止损墙（如10%），目标是绝大多数常规止损收敛在3%至5%以内，确保极少有交易穿透该墙（E-52483）。

## 适用边界与失效
若突发极端黑天鹅跌停穿仓穿透该墙，属不可抗力小概率事件，需在大样本中通过极低发生率稀释。

# 补充 K-30228 20220905指数低量能区间运行偶日微放量仅够五日均量无济于事

用于排除熊市地量区间的假放量诱多，指导交易者在均量系统未形成多头共振前保持空仓耐性。

# 补充 K-2632 20220905均线回测收盘微幅站上不足一个点仍定性为下反回测未过

```
