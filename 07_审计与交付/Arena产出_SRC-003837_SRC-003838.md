# K-0925 APL会自动脱离成本区：平台不停移动，出场点跟着移到成本之外
> 来源：SRC-003837（第1232课 期货：选品、SFP权重与脱离成本区（20260107））· 证据 E-4505、E-4506、E-4507

> 底本层级：仅增强稿可见
