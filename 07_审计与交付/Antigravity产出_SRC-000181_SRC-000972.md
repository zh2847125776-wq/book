```markdown
# K-33318 百分比价格振荡器（PPO）
> 来源：SRC-000181（专题_技术专题_这个指标有一点比MACD还好用！（增强版））· 证据 E-74727
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：基于价格百分比变化计算的动能振荡指标，形态与动力变化与MACD类似，但数值以标准化百分比形式呈现。（证据：E-74727）

## 它解决什么问题
解决普通MACD在不同股票或外汇市场间绝对数值差异极大、无法跨标的横向比较动能强弱的具体交易问题。普通MACD在不同资产图表上绝对值相差悬殊（如一个标的在100左右，另一个标的不超2），而PPO将数值标准化为百分比，使交易者能够横向比较不同资产的动能强弱。（证据：E-74728、E-74729）

## 如何识别
1. 指标形态与动力变化类似MACD，具有快线、慢线与讯号线（原稿展示中快慢参数为12与26，信号线为9）。（证据：E-74727）
2. 数值呈现为百分比形式，围绕0轴（标准线）上下波动。（证据：E-74727、E-74730）
3. 跨过0线代表动能转向，数值高于0线代表处于上升动能，数值越高代表动能越强。（证据：E-74730）

## 适用边界与失效
1. PPO仅用于衡量相对动能强弱与跨标的比较，原稿未提供具体的买卖入场点位与止损退出阈值规则。（证据：E-74729）
2. PPO与MACD在单品种走势上显示完全相同的动力形态，无法替代趋势背景判断，若无趋势配合容易发出无效信号。（证据：E-74727、E-74730）

## 与其他概念的关系
1. 对照关系（MACD）：PPO与MACD动力形态一致，但MACD使用绝对价格差值（无法直接跨品种比较），PPO使用价格百分比差值（可跨品种比较动力大小）。（证据：E-74727、E-74729）
2. 互补关系（跨品种动能排序）：在多个同样处于某种趋势的标的中，通过PPO相对0轴的高低来衡量哪一个标的的动能更强。（证据：E-74730）

## 案例与证据
在原稿展示的两个处于下降趋势的对比图表中，第一个图表PPO数值跨过0线达到约0.24；第二个图表PPO数值达到0.53，表明第二个图表的上升动能强于第一个图表。（证据：E-74730）
```

```markdown
# K-33319 股指双轨
> 来源：SRC-000972（第01课_三加详解（增强版））· 证据 E-74731
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在买入个股前，必须同步核对个股与对应相关指数价格及20日均线状态的双重共振观察方法。（证据：E-74731）

## 它解决什么问题
解决交易者孤立观察个股而忽略大盘指数环境导致的逆势开仓风险，通过要求在买入个股前先核对指数价格与均线状态，校准整体市场风险背景。（证据：E-74731、E-74733）

## 如何识别
1. 「股」指拟买的个股，「指」指相关指数。（证据：E-74732）
2. 20日线是核心观察均线。（证据：E-74734）
3. 核对个股与指数所处价格与20日均线的相对位置与方向。（证据：E-74733）
4. 20日线向上时，价格回到线附近可观察多头机会。（证据：E-74735）

## 适用边界与失效
1. 20日线向下时，不能只凭价格短时站上线就认定趋势转强。（证据：E-74736）
2. 股价远离20日线后再追买，遇到回撤时更难控制止损。（证据：E-74737）

## 与其他概念的关系
1. 前提关系（指数环境与个股走势）：指数所处均线状态是评估个股做多安全度的背景前提，两者不可割裂。（证据：E-74731、E-74733）
2. 基础组件关系（与20日线）：20日线是双轨系统的基准均线，用于锚定趋势方向与入场风险距离。（证据：E-74734、E-74735）

## 案例与证据
原稿强调20日线向上时价格回到线附近观察多头机会；反之股价远离20日线追买则面临回撤止损失控的风险。（证据：E-74735、E-74737）
```

```markdown
# K-33320 20日线状态权重组合
> 来源：SRC-000972（第01课_三加详解（增强版））· 证据 E-74738
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：按20日均线方向（向上/向下）、价格相对位置（线上/线下）及价格与均线距离（接近/远离）三个维度组合而成的八种市场状态筛选工具。（证据：E-74738）

## 它解决什么问题
解决对均线状态主观定性判断模糊的问题，通过线向、价位、距离三维度量化组合，明确区分易于计算风险的做多安全区与回归回撤/趋势失效的风险区。（证据：E-74738、E-74739、E-74740）

## 如何识别
1. 维度一（均线方向）：20日线方向分为向上和向下两种状态。（证据：E-74738）
2. 维度二（价格位置）：价格位于20日线上方或下方。（证据：E-74738）
3. 维度三（距离状态）：价格与均线距离分为接近和远离。（证据：E-74738）
4. 三个维度交叉组合形成八种待比较状态，判断前应逐项记录。（证据：E-74738）

## 适用边界与失效
1. 权重表属于筛选工具，不保证所选个股必然上涨。（证据：E-74741）
2. 价格位于20日线下时，原有做多判断应重新检验是否仍成立。（证据：E-74740）
3. 价格在线上但离线太远，可能先经历向均线的回归。（证据：E-74737、E-74739）

## 与其他概念的关系
1. 深化细化关系（对股指双轨）：将股指双轨中的20日线观察标准化为八种离散状态组合。（证据：E-74731、E-74738）
2. 筛选与执行关系：权重表仅用于前置状态比对与风险排序，执行买入仍须结合次日止损测算。（证据：E-74739、E-74742）

## 案例与证据
原稿明确指出最优风险计算情景为「价格在向上20日线上方且接近均线」。（证据：E-74739）
```

```markdown
## 规则之间怎样衔接
1. 标的初筛与形态确认衔接：先筛选流通盘>100亿且指数状态良好的标的，再核对个股20日线是否向上。（证据：E-74733、E-74735、E-74746）
2. 入场与动态止损衔接：在价格接近均线买入前，先计算到次日20日线的风险距离，并将次日升高的均线作为次日止损线。（证据：E-74739、E-74742、E-74743）
3. 异常破位与退出确认衔接：若次日收盘跌破止损线即执行预定规则，或通过观察次日下返测试失败、连续约三日在线下进行确认退出。（证据：E-74744、E-74745）

## 案例和失败方式
1. 失败方式一（追高被套）：股价大幅远离20日线后再追买，遭遇均线回归回撤导致止损距离失控。（证据：E-74737）
2. 失败方式二（逆势摸顶底）：在20日线向下时仅凭短时站上线便误判趋势转强做多。（证据：E-74736）
3. 失败方式三（违规抗单）：买入后首次回测均线跌破因持仓短而拖延，或寄希望于过去曾守住均线而拒绝止损。（证据：E-74744）
```
