# 补充 K-0459 制定条件应急计划体系：以如果则预案流程从容应对突发黑天鹅与行情异动

# 补充 K-0456 买入前提前确立刚性初始止损红线：触及瞬间毫不犹豫平仓换取清醒头脑
> 来源：SRC-003358 · 证据 E-53081

## 如何识别
- 事前定损而非事后补救：买入前就界定好如果市场与我作对时退出头寸的确切价格，将单笔亏损额锁死在账户绝对安全阈值之内（E-53081）。

## 适用边界与失效
适用于所有投机交易的买入开仓风控底线；任何以“公司基本面好”为由击穿止损拒不砍仓的行为均属致命违规。

# K-25632 止损离场后绝不可轻率废弃目标股：洗盘结束后符合再入标准果断重新接回
> 来源：SRC-003358 · 证据 E-53082
> 来源立场：书中作者观点（止损与再次买入规则分离模型）
> 底本层级：仅增强稿可见

一句话定义：被触碰止损被迫砍仓是执行纪律保护本金，但绝不可因此将该股从自选股中永久剔除；若其仅为震荡清洗浮筹并重回上升轨道，必须依规果断重新买入。

## 它解决什么问题
解决散户在止损离场后产生“心理受伤与厌恶偏见”，将止损股票打入冷宫不再跟踪，导致在主力完成深幅洗盘重新暴风拉升时踏空数十倍主升浪的认知盲区。

## 如何识别
- 保护自己与客观跟踪分立：触发止损必须立刻砍仓先保护本金安全，但不能带情绪将股票废弃；主力震荡洗盘正是为了清洗意志不坚定的浮筹（E-53082）。
- 重新触发买入信号果断跟进：只要该股仍具备大牛股的潜在技术与基本面胜面，一旦重新放量突破并重回上升轨道，交易者必须毫不犹豫重新买回（E-53082）。

## 适用边界与失效
适用于优质成长股与强势趋势股在主升浪途中的持仓管理；若公司基本面造假暴雷破位则坚决剔除。

## 与其他概念的关系
母库 K-25570 记录依纪律接回；本卡确立米奈尔维尼止损出局与重新买入规则绝对解耦、严禁主观废弃候选股的模型卡。

# K-25633 专业交易者与业余散户的止损分水岭：业余者因亏损恐惧而专业者保持客观小亏大赚
> 来源：SRC-003358 · 证据 E-53083
> 来源立场：书中作者观点（专业心智与单笔交易独立性认知）
> 底本层级：仅增强稿可见

一句话定义：业余散户会因一两次止损而陷入恐惧与情绪失控，而专业交易者始终保持客观冷静，将每笔交易视为全新机会并依托“小亏大赚”实现长期复利。

## 它解决什么问题
解决交易者在遭遇单笔止损后被负面情绪支配，产生报复性频繁交易或畏手畏脚不敢开仓的心理障碍。

## 如何识别
- 业余者的情绪化陷阱：业余投资者把单笔止损看作个人能力的挫败，产生沮丧、懊恼与恐惧，进而破坏后续交易系统的一致性执行（E-53083）。
- 专业级的心智与概率思维：专业人士深知止损是做生意的正常进货成本，客观评估每笔交易的盈亏比，以平常心面对微小亏损，永远将注意力聚焦在捕捉下一笔大赚机会（E-53083）。

## 适用边界与失效
指导所有交易者从散户思维向职业操盘手心智升级；必须建立在拥有正期望值交易系统的基石之上。

## 与其他概念的关系
母库 K-0456 记录专家与业余分水岭；本卡确立将止损视为正常商业成本、保持单笔交易绝对独立性的专业心智模型卡。
```

# 补充 K-30643 持续地量交投下K线实体收敛定性：极致缩量必然对应十字星与微幅阴阳

## 如何识别
- 成交量对振幅的物理约束：大盘首小时成交量缩回到千亿左右的地量水平，没有增量资金参与的盘面犹如失去动力的钟摆（E-53090）。
- K线形态的收敛预期：在缺乏流动性推动的环境下，盘面只能走出小阴线的阴跌或小阳线的微弱抵抗十字星，切莫在此阶段幻想单日长阳大暴动（E-53090）。

## 适用边界与失效
适用于股票大盘与个股缩量整理期的日内振幅预判；若盘中突发地量反转巨量脉冲则打破收敛。
```
