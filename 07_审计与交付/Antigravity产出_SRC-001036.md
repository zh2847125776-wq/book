```markdown
# K-32855 上涨常态结构
> 来源：SRC-001036（股票_20200305量化技术分析（增强版））· 证据 E-72431
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在特定分析周期（如60分钟级别）K线走势中，价格高点逐步抬高且回调低点亦逐步抬高的多头推进形态，并以前一波回调形成的低点作为不可跌破的绝对防守基准。

## 它解决什么问题
解决日内或波段多头趋势延续性的客观确认问题，避免交易者凭借主观臆测判断趋势，并为持仓防守提供明确的形态底线参考点位。（证据 E-72431）

## 如何识别
1. 在特定时间周期（如60分钟级别）图表上，观察K线波段的高低点分布，确认呈现高点持续抬高、低点亦同步抬高的阶梯状走势。（证据 E-72431）
2. 一旦确认形成上涨常态结构，立即锁定该结构确立的前一个波谷低点（上涨常态前低），作为趋势维系的底线，规则要求该点绝不许跌破。（证据 E-72431）
3. 跟踪价格运行位置，若价格推进至上方前期密集阻力带，需识别出短线压力已显著增大，注意节奏变化。（证据 E-72432）

## 适用边界与失效
适用于具有清晰波段高低点的分时或日线趋势跟踪。当价格下行跌破此前确立的上涨常态前低时，该上涨常态结构即告破位失效；当价格触及高位关键压力位导致短线压力过大时，结构推进可能受阻。（证据 E-72431, E-72432）

## 与其他概念的关系
- 对照关系：与价格高点降低、低点降低的「下跌常态」互为多空对称的相反结构。
- 前提关系：上涨常态前低的有效性是多头趋势跟踪策略设置防守止损线的基础前提。
- 补充关系：与MACD红柱时间窗口（如12小时、24-26周期）形成空间形态与运行时间的互补验证。（证据 E-72431, E-72432）

## 案例与证据
2020年3月5日上证指数在60分钟级别3067点位置横盘震荡，盘中走出高点抬高且低点抬高的结构，讲述者明确指出该形态已构成上涨常态结构，其前序低点即为绝对不许跌破的关键防守点。（证据 E-72431）
```

```markdown
# K-32856 收敛三角形横盘突破的原趋势动力不足判定
> 来源：SRC-001036（股票_20200305量化技术分析（增强版））· 证据 E-72425, E-72426
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：收敛三角形形态突破后倾向于沿原趋势方向运行，但若该形态是由横盘震荡整固演化而来，则突破后缺乏原趋势动能支持，不足以产生强劲的单边行情。

## 它解决什么问题
解决交易者在看到收敛三角形突破（如价格站上下降趋势线）时盲目追涨、过度预期单边大涨的问题，通过追溯整理前的原趋势性质来客观评估突破后的动能级别与持续性。（证据 E-72426）

## 如何识别
1. 由前期高点（如3127点）向下引出的下降趋势线与下方低点引出的上升趋势线相连，构成向右收敛的三角形形态。（证据 E-72425）
2. 在价格未有效突破趋势线之前，严格按照震荡区间对待，不得提前按已突破处理。（证据 E-72425）
3. 收盘价有效站上下降趋势线，确认顺势突破收敛三角形形态。（证据 E-72426）
4. 追溯收敛形态前的原趋势：若原趋势既非自上方大幅下跌而来，亦非自下方强劲单边上涨而来，而是横盘震荡整固演化而来，则判定沿原趋势运行的动力不足以推动大幅单边上涨或下跌。（证据 E-72426）

## 适用边界与失效
适用于由上升与下降趋势线共同构成的收敛整理形态。若收敛形态前存在强劲且明确的单边原趋势，则本判定不适用（突破后动力仍可充足）；若突破后未能维持在趋势线上方而跌回区间内，则形态突破失效。（证据 E-72425, E-72426）

## 与其他概念的关系
- 补充与修正关系：对传统形态学中「三角形突破沿原趋势运行」的经典假定进行了动力源维度的修正，补充了横盘原趋势无法提供充沛动力的约束。
- 协同关系：与「正乖离率过大不宜建仓」协同作为突破行情中防范追高被套的过滤规则。（证据 E-72426, E-72427）

## 案例与证据
2020年3月5日上证指数自3127点高点相连构成的下降趋势线与下方支撑线形成收敛三角形，当日收盘站上下降趋势线顺势突破，但讲述者提示因原趋势来自横盘震荡整固，突破后的运行动力不足以造成大涨大跌之奇，告诫不可大意。（证据 E-72425, E-72426）
```

```markdown
# K-32857 量价背离与阴线修复机制
> 来源：SRC-001036（股票_20200305量化技术分析（增强版））· 证据 E-72423, E-72424
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：价格上涨创新高但成交量不足20日均量线构成量价背离结构，技术面在未来两个交易日内存在大概率通过收出阴线进行回踩修复，放量至20日均量以上可化解背离。

## 它解决什么问题
解决指数或个股在量能不达标状态下冲高突破时的多头虚涨识别问题，为交易者提供未来1至2个交易日大概率出现阴线回踩的技术预期，防范追高风险。（证据 E-72423, E-72424）

## 如何识别
1. 价格上涨突破或创新高，但当日成交量低于20日均量线，确立为量价背离结构。（证据 E-72423）
2. 量价背离结构确立后，预期在未来两个交易日内大概率会出现一根阴线进行技术修复。（证据 E-72424）
3. 若后续交易日成交量显著放大且达到或超过20日均量，放大的量能可以起到化解背离的作用；但若当日仍未完成阴线回踩，次日依然存在大概率修复预期。（证据 E-72423, E-72424）

## 适用边界与失效
阴线修复属于大概率统计事件而非必须发生的绝对规律。若市场持续保持巨量成交（稳定维持在20日均量上方）化解背离，则阴线修复的紧迫性被稀释；若后市未现阴线而是横盘消化，亦属背离化解路径之一。（证据 E-72423, E-72424）

## 与其他概念的关系
- 对冲转化关系：与「放量化解顶部背离」形成对立统一，量能充足可化解背离风险，量能不足则引发阴线回踩。
- 前提过滤关系：量价背离带来的阴线修复预期，与突破追入策略构成互斥，是判断突破后是否面临回测短亏的重要依据。（证据 E-72423, E-72426）

## 案例与证据
2020年3月4日上证指数收盘成交量不足20均量形成量价背离结构；3月5日两市大涨放量超过20均量但未收阴线，讲述者指出3月4日的量价背离在3月5日未得到修复，3月6日（次日）大概率仍面临一波阴线修复。（证据 E-72423, E-72424）
```

```markdown
# K-32858 最大干涉角阻力容差与筹码交换效应
> 来源：SRC-001036（股票_20200305量化技术分析（增强版））· 证据 E-72420, E-72421, E-72422
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：关键测算阻力位（最大干涉角）对行情的影响体现为一个伴随充分筹码交换的容差价格带，收盘价微幅超越并不代表摆脱其压制影响。

## 它解决什么问题
解决交易者对技术阻力点位机械套用单一绝对数值、将盘中或收盘微幅破位误判为有效突破的问题，确立关键技术点位具有容差区间与换手缓冲的客观规律。（证据 E-72421, E-72422）

## 如何识别
1. 技术系统提前测算给出关键阻力点位数值（如最大干涉角3067点）。（证据 E-72420）
2. 价格在全天大部分交易时间内围绕该关键点位反复震荡，表明该处正在发生较长时间的筹码交换。（证据 E-72421）
3. 收盘价即使微幅高出该点位（如收盘3071点对比点位3067点），由于距离并不十分遥远，技术上判定其尚未脱离最大干涉角的影响。（证据 E-72421）
4. 点位对应存在容差（多一点或少一点属于常态），需待后续交易日进一步上涨拉开幅度（如再涨1%~2%或突破前高3127点），方可确认有效摆脱阻力压制。（证据 E-72422）

## 适用边界与失效
适用于重要技术测算点位（如角度线、甘氏角/干涉角阻力位）处的盘面评估。当价格在后续交易日持续大幅拉升拉开空间（如涨幅脱离1%~2%以上或攻克上一级高点3127点）时，该阻力压制判定正式失效。（证据 E-72421, E-72422）

## 与其他概念的关系
- 修正关系：对机械式单点突破理论构成修正，强调技术点位的概率性与容差带特征。
- 互补关系：与收敛三角形突破形成双重验证，收敛三角形突破后若仍处于关键干涉角容差带内，则突破有效性仍需观察。（证据 E-72421, E-72426）

## 案例与证据
2020年3月5日上证指数测算最大干涉角为3067点，指数盘中突破前高3058点最高至3074点，下午全天基本在3067点附近震荡换手，收盘于3071点；讲述者明确指出收盘虽微幅站上，但因距离很近，绝不能判定已经脱离最大干涉角的影响。（证据 E-72420, E-72421, E-72422）
```

```markdown
# K-32859 MACD加速上涨周期与顶部背离结构假定
> 来源：SRC-001036（股票_20200305量化技术分析（增强版））· 证据 E-72429, E-72430
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：价格与MACD指标加速上涨达到3至4天时随时面临上涨动能衰竭，若此时股价创出新高而MACD指标未创新高，则在价格见顶的前提下构成顶部背离结构。

## 它解决什么问题
解决在连续加速拉升行情中如何预判动能衰竭敏感时间窗口的问题，以及在股价创新高时识别潜在的MACD顶背离风险，指导交易者提前建立风控预案。（证据 E-72429, E-72430）

## 如何识别
1. 跟踪日线MACD指标加速上涨的持续周期，基准加速上涨周期通常为3到4天。（证据 E-72429）
2. 当加速上涨运行至3到4天的时间窗口时，技术指标随时可能反馈加速上涨阶段的结束。（证据 E-72429）
3. 盘面表现为股价突破前高创出阶段新高，而MACD指标未能同步创出新高，呈现“股价创新高、指标不创新高”的状态。（证据 E-72430）
4. 在假定当前收盘最高价成为未来数周或数月最高点的前提下，该形态被推演确立为本波日线MACD顶部背离结构。（证据 E-72430）

## 适用边界与失效
该顶部背离在原稿中属于课堂情景假设推演，其实质确立依赖于当前价格高点能够压制后市这一前提。若后市行情继续放量强势上攻、MACD指标跟随创出新高，则顶背离假设被化解失效。（证据 E-72423, E-72429, E-72430）

## 与其他概念的关系
- 阶段衔接关系：紧跟在「站稳20日线建仓」与「持股待涨」之后，作为加速上涨末期判断冲高风险的预警信号。
- 转化关系：与「放量化解顶部背离」互为矛盾转化关系，若量能维持高位则背离被化解，若量能不济则背离压制生效。（证据 E-72423, E-72428, E-72429）

## 案例与证据
2020年3月5日上证指数日线MACD已加速上涨3天，当日最高价触及3074点突破前高3058点；讲述者做出情景假设：若3074点成为未来阶段最高点，则形成股价创新高而指标不创新高的MACD本波顶部背离结构，并提示出现顶背离不要慌乱。（证据 E-72420, E-72429, E-72430）
```

```markdown
# S-3113 站上20日均线三日建仓与乖离率风控方法
> 来源：SRC-001036（股票_20200305量化技术分析（增强版））· 证据 E-72419, E-72426, E-72427, E-72428

## 规则之间怎样衔接
1. 均线观察与建仓确认：每日观察日线均线系统粘合状态，一旦价格站上20日均线并满足连续站稳3天的确认条件，触发建仓动作。（证据 E-72419, E-72428）

3. 突破与回测两难衔接：在突破下降趋势线或阻力位后，面临等待回测可能踏空、不等待回测尾盘进场可能遭遇回测短亏的两难，由交易者自主在防踏空与防短亏之间做出权衡。（证据 E-72426, E-72427）
```
