```markdown
# K-41184 收益亏损几何非对称性与固定盈亏比数学期望模型
> 来源：SRC-002950 读书_交易择时技术分析_05（增强版） · 证据：E-87960, E-87961, E-87962

### 核心概念与运作机理
在量化交易期望值科学中，“亏损在几何级数上严厉对抗交易者”构成了第一底层数学铁律：当本金亏损50%时，必须实现100%翻倍才能回本，亏损与盈利在几何复利曲线上具有天然的不对称性。在胜率低于50%（如40%平均成功率）的现实交易环境中：
1. 盈亏幅度同比例放大的陷阱：若将单笔盈亏幅度由“4%收益对2%亏损”（2:1盈亏比）同比例放大为“42%收益对21%亏损”（同样2:1盈亏比），经历10次交易后，前者净利润达到3.63%，而后者净利润竟锐减至1.16%；若单笔亏损进一步放大，系统期望将不可逆转地滑向负值；
2. 绝对亏损净值刚性压制律：决定交易系统能否长期活下来并稳定盈利的根本，不是盲目追求高回报率，而是“刚性锁死单笔绝对亏损比例（如严格控制在2%至5%以内）”；
3. ATR波动止损批判：威尔斯·怀尔德提出的真实波动幅度均值（ATR）止损法使高波动标的承受更宽止损，反而放大了亏损绝对值并降低了数学期望，因而必须被更严密的MZ动态边界系统所替代。

### 适用场景与边界条件
- 适用场景：全市场程序化量化策略、股票趋势跟踪及带杠杆期货的盈亏比数学建模。
- 边界条件：严禁在胜率低于50%时同比例扩大单笔亏损幅度；单笔最大亏损必须刚性受控。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
为下行容忍度禁止放大法则（K-41185）提供底层的纯数学证明；与箱体突破跌回破翻机制（K-41186）互为表里：一旦发生假突破破翻，通过极窄止损将亏损锁死在2%以内，确保账户数学期望。

### 案例与证据
- 案例标的与时间：马克·米奈尔维尼《像冠军一样思考》期望值数学模型。
- 实盘数据特征：40%胜率下，4%收益/2%亏损的10次净利润（3.63%）显著高于42%收益/21%亏损的净利润（1.16%）；在20%收益/10%亏损下达到最优回报率10.2%，证明单笔亏损绝对值必须受到刚性压制。
- 逐节证据标定：ATR批判与负期望陷阱参见 E-87960，亏损几何对抗与小收益胜过大收益参见 E-87961，10次交易数学推演量化参见 E-87962。
```

```markdown
# K-41185 弱交易能力胜率下行容忍度禁止放大法则
> 来源：SRC-002950 读书_交易择时技术分析_05（增强版） · 证据：E-87963

### 核心概念与运作机理
在交易行为金融学中，存在一个极其致命的心理误区：“当交易者处于连续回撤、平均成功率低于50%的逆境时，往往产生主观幻觉，认为自己被扫损是因为没有给股票足够的波动空间，进而主动放大止损幅度或容忍度”。此项行为被系统明确裁定为“绝对自杀式违规”：
1. 数学事实 vs 主观意见：在胜率低于50%的环境中，放大下行容忍度不仅不能提高留存概率，反而会使每次止损的本金出血量呈几何级数扩大，导致账户在极短的交易周期内被直接淘汰出局；
2. 逆境紧缩风控律：当交易状态不佳或市场缺乏系统性赚钱效应时，唯一正确的数学应对是“反向收紧最大容忍亏损百分比”（如将原本7%-8%的止损进一步紧缩至5%-6%），同时缩短持仓周期更早地获利了结；唯有缩小亏损敞口，才能在低胜率环境中活下来等待顺风周期。

### 适用场景与边界条件
- 适用场景：交易者遭遇连亏心理挫败期、熊市及震荡市中的风控硬约束。
- 边界条件：胜率低于50%时，绝对禁止以任何借口扩大预设止损点；容忍度只准紧缩、不准放宽。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
作为亏损几何非对称性（K-41184）的行为风控推论；与A股跨年1月份季节效应（S-25725）配合：在1月高跌幅低涨幅的历史恶劣环境中，强制执行逆境紧缩风控。

### 案例与证据
- 案例标的与时间：交易逆境期下行容忍度实证检验。
- 实盘数据特征：许多投资者因给予更大空间而导致亏损滚雪球被市场扫地出门，系统明确反向收缩至5%-6%止损并提早至10%-12%止盈的逆境法则。
- 逐节证据标定：下行容忍度禁止放大与逆境紧缩机理参见 E-87963。
```

```markdown
# K-41186 盘整箱体假突破跌回之破翻形态与衰竭弱势定性
> 来源：SRC-001220 股票_20201229量化技术分析（增强版） · 证据：E-87964, E-87965

### 核心概念与运作机理
在K线形态学与箱体理论中，“突破箱顶后重新跌回箱体内部”被明确定义为性质极其恶劣的“破翻（False Breakout / Liquidity Grab）”弱势形态：
1. 破翻动力学机理：价格经过漫长盘整后向上突破箱顶，若该突破为真突破，价格必须迅速放量拉开距离脱离成本区；若价格在箱顶上方仅停留数小时（如仅维持6个小时），随后在回测中不仅跌破原下降趋势线，甚至反向打穿箱顶跌回箱体内部，系统判定该突破彻底失败，盘面形态比不突破更为难看；
2. 诱多衰竭与空头反扑：跌回箱体内部坐实了高位突破纯属诱多诱买陷阱，原突破点由支撑瞬间反转为强力反压，上方套牢盘沉淀，随后价格往往顺势加速向下测试箱底甚至下轨破位。

### 适用场景与边界条件
- 适用场景：股票与期货分时60分钟级别箱体突破真伪甄别、防范假突破追高被套。
- 边界条件：收盘跌回箱顶下方必须无条件止损；破翻确立后严禁任何做多幻想。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
与下行容忍度禁止放大（K-41185）深度契合：在识别箱体破翻失败后，必须依赖紧缩止损果断砍仓；为跨年1月效应（S-25725）提供微观技术破位前兆。

### 案例与证据
- 案例标的与时间：2020年12月29日上证指数60分钟级别盘整箱体。
- 实盘数据特征：大盘向上突破箱顶后仅维持6小时，上午收盘前跌回箱顶内部，回测下降线打漏，系统明确标定为“比不突破还难看的破翻弱势结构”。
- 逐节证据标定：箱顶打漏跌回破翻机理参见 E-87964，箱体突破失败弱势定性参见 E-87965。
```

```markdown
# S-25725 A股跨年1月份历史盈亏非对称效应与防守应对策略
> 来源：SRC-001220 股票_20201229量化技术分析（增强版） · 证据：E-87966, E-87967

### 策略逻辑与决策流程
本策略为基于A股跨年1月份11年大样本统计分布的季节性非对称风险规避决策流程：
1. 11年历史统计非对称规律：量化统计2010年至2020年长达11年间的全市场1月份涨跌数据：
   - 涨跌概率：5年下跌、6年上涨，上涨概率仅为55%左右（基本呈现一半一半的抛硬币概率）；
   - 盈亏幅度极端非对称：在上涨年份中，全月平均涨幅仅为3.44%；而在下跌年份中，全月平均跌幅深达7.71%（跌幅几乎是涨幅的2.3倍）；
   - 期望值为负：11年全月算术平均月度收益率为-1.62%，在统计学上呈现显著的“涨得少、跌得多”特征；
2. 机构行为学动因：元旦过后距农历春节时间极短，主力机构为避免在年报披露期暴露持仓底牌，往往将主攻建仓计划推迟至年后，节前资金面整体偏向抽离防御；
3. 防守执行决策：在1月份交易中，交易者坚决抛弃“春季躁动必然暴涨”的盲目乐观幻想，严格控制仓位在半仓以下，逢高结利，坚守防御。

### 适用场景与边界条件
- 适用场景：A股岁末年初跨年阶段、每年1月份的仓位总闸门控制与预期管理。
- 边界条件：1月份历史期望值为负，严禁重仓博弈；若叠加微观技术破位（如破翻），必须坚决空仓。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
宏观承接几何亏损非对称性（K-41184）：1月份“跌7.71% vs 涨3.44%”的非对称性正是亏损几何对抗在季节分布上的具象体现；与箱体破翻（K-41186）共同构筑岁末年初的双重安全防线。

### 案例与证据
- 案例标的与时间：2010年至2020年上证指数1月份历史大样本定量统计。
- 实盘数据特征：详述了11年间上涨6年均涨3.44%、下跌5年均跌7.71%、综合均值-1.62%的铁证数据，破除1月暴利迷思。
- 逐节证据标定：11年历史涨跌样本统计参见 E-87966，上涨均涨3.44%下跌均跌7.71%非对称数据参见 E-87967。
```
