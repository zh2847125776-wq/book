# K-41144 趋势四维量化判定体系与长短均线双同向共振法则
> 来源：SRC-002947 读书_交易择时技术分析_02（增强版） · 证据：E-87860, E-87861, E-87862, E-87863

### 核心概念与运作机理
在技术择时分析中，确立“认识趋势、敬畏趋势、顺从趋势”的顺势交易哲学，并通过四大客观量化维度界定趋势性质：
1. 均线运行方向与共振概率：20日均线波动灵活敏锐反映短期趋势，60日均线稳重反映中长期大趋势；当20日线与60日线同向向下运行时，系统做空胜率极高，反之双同向向上时做多胜率极高；
2. 趋势线方向与斜率力量：趋势线的运行方向指出主导方向，其倾斜斜率直接量化趋势爆发力度（大斜率代表涨跌凌厉，小斜率代表动能乏力逼近盘整）；严格遵循有效画线法则，严禁绘制被K线实体肆意穿越的无效趋势线；
3. 动能指标状态（MACD零轴与DIFF快线）：快慢双线在零轴之上的向上运行确立强势上升趋势，零轴之下的向下运行确立下跌趋势；实战中剔除慢线滞后性，专注盯紧DIFF快线变化；
4. 价格结构形态：依托高低点抬升或下降的ABC常态结构界定趋势生命期。

### 适用场景与边界条件
- 适用场景：全市场股票与期货中长线趋势跟踪、过滤逆势杂波及多周期趋势对齐。
- 边界条件：短期均线与长期均线方向矛盾时，必须服从大周期方向；严禁绘制多根实体穿越的假趋势线。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
作为趋势判定大纲统领微观执行：均线共振与趋势线斜率直接指导微观分时中的逆势轻仓（K-41145）与分批止盈策略（S-25702）。

### 案例与证据
- 案例标的与时间：经典长短期趋势量化判定模型。
- 实盘数据特征：展示了20日线与60日线双双向下共振时的单边下跌范例；对比了规范趋势线（无实体穿越）与错误画线（多次穿越）的有效性差异；阐释了MACD快线DIFF在零轴下方的空头定性。
- 逐节证据标定：顺势哲学与均线量化维度参见 E-87860，长短均线同向共振概率参见 E-87861，趋势线斜率力量与画线有效性参见 E-87862，MACD指标零轴与DIFF快线法则参见 E-87863。

# K-41145 大周期负乖离顺势与分时小周期逆势之轻仓试错模型
> 来源：SRC-000504 期货_期货投机技术分析20230613_玻璃_甲醇_豆粕_玉米.md（增强版） · 证据：E-87864, E-87867

### 核心概念与运作机理
在多周期嵌套博弈中，交易者经常遭遇“日线级别大周期呈现深跌后的负乖离顺势，而5分钟分时级别却处于短线多头脉冲反弹”的周期矛盾。此情境下系统确立“跨周期定性与轻仓试错原则”：
1. 周期定性辨析：在大周期主跌背景下，分时图的做空操作在5分钟微观尺度上属于“逆势摸顶交易”，但在日线宏观尺度上属于“修复负乖离后顺势放空”；
2. 试错执行代价与轻仓约束：由于进场点（如1633元）逆着小周期的反弹冲力，单价格点波动对应的资金亏损敞口偏大，交易者必须刚性执行“轻仓/极少手数开仓”；
3. 分时微观中继突破信号：在5分钟分时图上，若价格跌漏短期微小上升趋势线，系统确认小级别反弹动能耗尽转为中继下跌结构，此时以“跌漏趋势线开空、收盘重新站回即刚性止损”构建极窄风控闭环。

### 适用场景与边界条件
- 适用场景：商品期货日内高频T+0交易、大级别熊市背景下分时反抽的高位放空试错。
- 边界条件：逆小周期开仓必须严格压缩头寸规模（轻仓打底）；跌漏趋势线进场后一旦收盘站回必须无条件止损。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
为趋势四维量化体系（K-41144）补充微观周期落地手法；与前低停损波段持仓（S-25702）互为期货日内做空与做多的攻防双翼。

### 案例与证据
- 案例标的与时间：2023年6月13日玻璃期货主力与苹果期货5分钟走势。
- 实盘数据特征：玻璃在1633位置逆5分钟小周期放空，强调轻仓试错与日线负乖离顺势属性；苹果期货5分钟图跌漏微小上升趋势线后构成下跌中继做空点。
- 逐节证据标定：大周期负乖离与分时逆势轻仓参见 E-87864，5分钟跌漏微趋势线开空中继与站回止损参见 E-87867。
```

# S-25702 超跌前低防守窄幅停损与红柱缩短分批止盈策略
> 来源：SRC-000504 期货_期货投机技术分析20230613_玻璃_甲醇_豆粕_玉米.md（增强版） · 证据：E-87865, E-87866

### 策略逻辑与决策流程
本策略为基于超跌前低极限防守、窄幅停损垫设计及分时指标衰竭分批止盈的执行流程：
1. 超跌前低点位进场与3个价格点停损：在品种经历深度暴跌探明前低支撑时，以极窄风险敞口介入右侧多单（如甲醇在1953元开多），停损线严格下移放置在前低下方微小缓冲垫处（如1950元停损，风险仅3个点）；
2. 盈亏比非对称爆发与顺势持仓：若价格如期探底回升，3个点的微小试错成本瞬间撬动2.6%至2.7%以上的巨大涨幅，交易者顺势持有并以前期阻力高点（如前高绿豆位）作为理论止盈目标；
3. 60分钟红柱缩短分批锁定利润：在利润奔跑过程中，若持仓者对高位波动心存顾虑或盘中出现滞涨阴线，密切盯紧60分钟级别MACD指标；一旦60分钟红柱出现首次“缩短一个”，系统强制触发“主动止盈平仓一半（清一半）”，锁定大半利润落袋为安，剩余半仓继续沿原计划博弈终极前高目标。

### 适用场景与边界条件
- 适用场景：商品期货（如甲醇、纯碱等）日内与隔夜超跌波段做多、浮盈单的主动风控锁定。
- 边界条件：单笔停损必须控制在极窄点位（如3个价格点）；红柱缩短一个必须无条件减半仓，严禁贪婪。
- 底本层级：仅增强稿可见。

### 与其他概念的关系
承接四维趋势判定（K-41144）：在多周期矛盾期，通过前低3点极窄停损将试错成本压缩至极限；红柱缩短清一半机制有效防止浮盈大幅回吐。

### 案例与证据
- 案例标的与时间：2023年6月13日甲醇期货主力合约多单实战操作。
- 实盘数据特征：甲醇1953开多、1950停损（仅3点风险），随后价格自低位大涨超2.6%，系统指导以前高绿豆为目标，并明确60分钟红柱缩短一个清一半锁定收益。
- 逐节证据标定：前低1953开多与3点停损参见 E-87865，前高目标与60分钟红柱缩短清一半参见 E-87866。
```
