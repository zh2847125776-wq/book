## 四、每组九步流程（照 Claude 线原样执行）

命令一律 `python -B -X utf8`。除「取组」在仓库根跑，其余路径相对
`分片工作区\Shard3\`。

```powershell
cd C:\Users\赵豪\dsh\交易知识体系汇编
python -X utf8 工具/分片_组.py Shard3 取组
```

1. **核现状**：读 `reply\pending_group.json`、`reply\pending_prompt.md`、`next_ids.json`。
   确认来源与号段**未越界**、**未重复取组**。三个文件不一致就停下记录原因，
   **不要自行改号或跳组**。
2. **通读原文**：到 `stage\` 逐字读完该组 1–2 份原文全文（不许只看标题、不许只读摘要）。
3. **抽取 + 合稿**：按 `pending_prompt.md` 的全部规矩写卡片＋证据＋底本层级与疑点＋与已有卡的关系。
   可用并行来源读者 / 并行草稿做备料，然后合稿：
   ```powershell
   python -B -X utf8 out/07_审计与交付/并行合稿.py <冻结草稿.py>
   ```
4. **主代理复核（不可外包）**：完整阅读合稿回复，逐卡核对原文、证据、关系、
   底本层级、修订差异。没核对完当前组，不许取下一组。
5. **预审三连**（任一不过就重做回复，不改库）：
   ```powershell
   python -B -X utf8 out/07_审计与交付/本地严格核对.py check <回复文件>
   python -B -X utf8 out/07_审计与交付/核对卡内关联.py <回复文件>
   python -B -X utf8 out/07_审计与交付/核对品种代码依据.py <回复文件>
   ```
6. **严格官方入库**（fail-closed）：
   ```powershell
   python -B -X utf8 out/07_审计与交付/严格官方入库.py <回复文件>
   ```
   必须同时满足：**证据总数 == 验证通过数**、**未通过 == "无"**、
   **新卡数 == 回复卡数**、**证据入索引数正确**、**`guard: PASS`**。
   缺一条即视为未完成，按报错重做回复；pending 保留可重试，**不换号段**。
7. **sync**：
   ```powershell
   python -B -X utf8 out/07_审计与交付/本地严格核对.py sync <归档回复>
   ```
8. **记录主代理复核**：
   ```powershell
   python -B -X utf8 out/07_审计与交付/记录并行组复核.py <组号> "<主代理复核说明>"
   ```
9. **更新接续状态**，然后回第 1 步取下一组。
