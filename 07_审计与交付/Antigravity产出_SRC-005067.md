# K-31817 FVG起效的三要件与多周期叠加
> 来源：SRC-005067（第2345课 股票日评：放量滞涨今明两日阴线兑现之后走势才是关键（20240126））· 证据 E-67687, E-67688

> 底本层级：完整稿可见

一句话定义：FVG（合理价值缺口）在行情中要产生实质性的有效压制或支撑作用，不能独立存在，必须具备与OB区或base区间贴近互证、具备较大K线实体，以及最关键的与更高周期同类型区域产生叠加共振（WFVG、DFVG、HFVG三周期叠加，叠加边界以最小周期为准）三个要件。

## 它解决什么问题
解决在单周期图表上FVG区间泛滥、处处设阻导致分析失真（“任意一个都能产生严重压制，那还得了？那永远它也别涨了”）的问题，建立筛选真正具有压制/阻碍效力的关键FVG区间的过滤规则。

## 如何识别
1. **要件一（不能独立存在）**：FVG区间自身不能孤立起效，必须与其他有意义的分析手段互相配合，例如贴近OB区，或正好压在base区间的上限产生互印 E-67687。
2. **要件二（较大实体）**：形成FVG的对应K线需要是一个较大的阴线或者阳线实体；若K线实体不大则不满足该要件，单独压制力弱可暂时放过（原文未明确量化实体具体阈值） E-67687。
3. **要件三（更高周期同类型区域叠加）**：这是最核心要件，该区间的FVG能与更高周期的同类型区域产生重叠（如周线WFVG、日线DFVG与小时线HFVG三周期重叠） E-67688。
4. **生效边界认定**：当出现多周期同类型区域重叠时，重叠区域的具体生效点位边界以最小周期（如60分钟或1小时线）为准 E-67688。

## 适用边界与失效
- **孤立无配合失效**：在下跌或反弹过程中，孤立无其他形态配合、单一周期的FVG极易被价格直接突破蹿升，无法构成有效阻力 E-67687。

- **以最小周期划定执行边界**：尽管阻力级别由大周期决定，但交易执行和具体点位观察必须聚焦于最小周期的上下限区间 E-67688。

## 与其他概念的关系
- 与 **OB区 / base区间**：FVG不可孤立使用，需与OB区或base区间上限重叠以构成形态互证 E-67687。

# K-31818 放量小K线不可持续规律与博弈选向
> 来源：SRC-005067（第2345课 股票日评：放量滞涨今明两日阴线兑现之后走势才是关键（20240126））· 证据 E-67689, E-67690
> 来源立场：课程讲述者采纳
> 底本层级：完整稿可见

一句话定义：在反弹或运行过程中出现成交量明显放大但实体仅为小K线或十字星（放量滞涨）时，该放量小K线形态极难持续，次日要么缩量演变为无量无价下跌，要么继续放量形成大K线（针尖对麦芒博弈）快速选择突破方向。

## 它解决什么问题
解决在放量滞涨日交易者容易被成交量放大迷惑、误以为买盘强劲而盲目追涨，却忽视放量小实体背后多空剧烈分歧与不可持续性的研判盲区，明确放量小K线次日的演变路径与关键观察点。

## 如何识别
1. **量价背离特征**：集合竞价或全天成交量明显放大（如相比前日显著增量），但价格涨幅微弱，收出十字星或小K线实体，形成放量滞涨特征 E-67699。
2. **量能持续性规则**：缩量小K线属于可以持续的量能状态；而放量小K线在次日很难再维持同等级别的持续放量 E-67689。
3. **路径一（缩量小K下行）**：若次日无法继续放量而转为缩量，后续通常全呈现无量无价的小K线，价格重心将顺势往下走 E-67689。
4. **路径二（持续放量大K决胜）**：若次日继续保持高放量，则必须通过大K线打破僵局，如同“两个针头或者针尖对麦芒”，由于多空对峙无法长时间维持，市场将快速决出胜负并选择方向 E-67690。

## 适用边界与失效
- **次日开盘价是决定性信号**：放量滞涨当日收阴线或收阳线并不起决定作用，次日（或下一个交易日）的开盘价和相对位置才是关键判定信号。若低开下走则确立转向阴线；若平开或高开上走则继续维持反弹修复 E-67690。
- **不可推导为空头绝对必胜**：放量滞涨仅表明“有人在卖”且对峙加剧，并非直接等同于见顶下跌，若次日能够承接卖压继续放量收出大阳线突破关键阻力，则对峙向上破局 E-67690。

## 与其他概念的关系
- 与 **缩量小K线**：缩量小K线表明多空分歧有限、量能平稳可延续；放量小K线表明多空剧烈交锋、筹码松动不可持续 E-67689。
- 与 **针尖对麦芒**：形容高成交量下多空双方势均力敌的对峙状态，因能量消耗极大，必然以快速选择方向告终 E-67690。
- 与 **负乖离率修复**：在均线下方反弹中，放量滞涨若能高开向上破局，则继续完成对60MA等均线的负乖离率修复 E-67690。

## 案例与证据
2024年1月26日上证指数集合竞价放量至45.7亿-46亿（前一日为39亿），但盘中滞涨收出小K线，课程指出放量小K难持续，下周一开盘价和前五分钟走势将直接决定是缩量向下还是放量选向 E-67689, E-67690, E-67699。

# K-31819 弱势品种关键结构点突破优先于空头均线规则
> 来源：SRC-005067（第2345课 股票日评：放量滞涨今明两日阴线兑现之后走势才是关键（20240126））· 证据 E-67691, E-67692

一句话定义：在长期空头趋势且均线系统呈空头排列或仅走平的极弱势品种中，不能寄希望于均线（如走平的50线）产生托举转强作用，而必须以形态结构中符合K线数量要求的有效阻力位（如创业板1727点）被真实突破作为转强与反弹成立的首要判据。

## 它解决什么问题
解决在长期阴跌、空头排列的极弱品种中，交易者频繁以“均线走平”、“站上均线”为由抄底却屡屡遭遇创新低止损的系统性亏损问题，确立“点位突破优于均线托举”的判据优先级。

## 如何识别
1. **空头环境特征**：品种周线持续连阴（如6周连阴接续），周周基本都会创新低，属于标准空头弱势特征 E-67692。
2. **均线托举无效性**：在空头排列系统中，即使短期均线（如50日线或60分钟50线）走平甚至价格短暂停留，由于大周期均线整体向下，均线无法形成有效向上托举支撑 E-67691。
3. **结构点位优先级**：与其观察走平的均线，不如直接盯住符合K线数量要求的结构关键点（如创业板指60分钟周期的1727点），只有该点位被真实突破，才能确认转强并开启反弹 E-67691。
4. **反弹性质定性**：即使该关键结构点被突破，在整体空头趋势下，其性质依然仅仅是“跌得多了”的负乖离率弱势修复，而非反转走强 E-67691。

## 适用边界与失效
- **周线连阴期严禁抄底**：在品种呈现周周创新低的空头格局下，历史回测显示“任何一周，以任何理由抄底都是失败、都是错误的、都挣不着钱”，在未盘整完毕前禁止操作或持有头寸 E-67692。
- **123号位有效性约束**：用于判定的关键阻力点必须符合结构波浪/K线数量要求，不能因创出新低而随意将距离过近（如仅差3根K线）的次级高点选为2、3号位 E-67701。

## 与其他概念的关系
- 与 **123号位**：在持续创新低过程中，1号位（低点）可以随新低反复下移重置，但有效的2号位与3号位必须保持结构间距并符合K线数量要求 E-67701。
- 与 **负乖离率修复**：在弱势品种中，突破关键点引发的上涨仅为负乖离率的均线修复，反弹空间有限且随时可能重回跌势 E-67691。
- 与 **空头排列**：大周期均线向下发散时，小周期均线的金叉或站上均不具备主导权，必须服从大周期趋势 E-67692。

## 案例与证据
2024年1月26日创业板指数盘中反弹至1727.14点（距关键点1727仅差约13点），周线呈现6周连阴下跌特征。课程指出创业板无大资金呵护，与其看走平的50线托举，不如盯紧1727突破，未突破前任何抄底皆为错误预案 E-67691, E-67692, E-67702。

# K-31820 权重护盘期轮动补涨无征兆防套规则
> 来源：SRC-005067（第2345课 股票日评：放量滞涨今明两日阴线兑现之后走势才是关键（20240126））· 证据 E-67693, E-67694

一句话定义：在市场由银行、保险、券商、中字头等大市值权重股用于护盘托底的极端结构性行情中，非主线品种（如新能源、芯片、光伏、医药等）的“轮动补涨”尚无任何征兆，盲目买入非护盘品种极易被套亏损，操作总原则为“没做不值得做，做了别追高”。

## 它解决什么问题
解决散户在指数被权重股拉升时产生的“指数涨了其他股票也会轮动补涨”的心理幻觉，遏制在极端分化行情中因盲目潜伏非主线超跌品种而遭受阴跌或横盘不涨的无效持仓风险。

## 如何识别
1. **护盘工具独涨特征**：行情呈现极端分化，拉升主力高度集中于银行、保险、中字头等长期未轮动且市值大、便于国家队护盘当工具的品种（如银行涨2%稳定军心） E-67693。
2. **成分权重保护差异**：同为大金融板块，缺乏300权重成分股保护的品种（如普通券商）亦无法充分享受护盘红利，板块内部并非彻底同涨共跌 E-67693。
3. **补涨无征兆判定**：非护盘主线板块（如新能源ETF、光伏ETF、军工ETF、芯片/半导体ETF、医药ETF）均处于无机会、高止损或横盘不涨状态，市场整体不存在“轮到我补涨”的资金迹象 E-67693。
4. **防套行动原则**：
   - 处于空仓或未参与状态：“没做：这个地方不值得做，一买容易被套” E-67694。
   - 已持有主线头寸：“做了的话：看好主题板块的热度——别追高：有逢低的、不涨的（如中字头里还没涨的），去考察考虑” E-67694。

## 适用边界与失效
- **仅适用于极端护盘分化期**：当市场增量资金有限、仅靠政策/国家队资金定向撬动权重指标股护盘时严格适用，不可套用于全市场普涨牛市阶段 E-67693。
- **主线品种仅限低吸未涨个股**：即便是中字头等主线板块，亦严禁盘中追高，只能在主题热度持续前提下考察滞涨个股逢低潜伏 E-67694。

## 与其他概念的关系
- 与 **人手有限与轮动**：权重护盘是因为其市值大、工具属性强；存量资金有限导致资金无法溢出到成长赛道，造成补涨落空 E-67693。
