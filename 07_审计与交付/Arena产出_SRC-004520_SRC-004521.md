# K-3327 晨星要求阳线有一定长度：阳包阴是主体，十字星只是附带

- 阳线吃掉阴线，或者形成贯穿结构，或者至少达到接近阴线实体开盘价的位置（原文未单列证据）。
- 即使没有十字星，阳包阴结构本身也能在局部看涨（原文未单列证据）。

## 适用边界与失效
- 具体的长度数值：原文未明确。
- 晨星定义的中段在缺段中（00:03:30后半）。

## 与其他概念的关系
- 老师称晨星是"不很靠谱的K线组合"（原文未单列证据）。

# K-3331 以盘待跌与"观后整理"的区别：价格要在颈线上下来回才算以盘待跌
> 来源：SRC-004521（第1853课 无量大跌与砧板论收官课）· 证据 E-61347
> 来源立场：课程讲述者采纳（"资格条款"是编辑者评注）
> 底本层级：转述待核

一句话定义：头部结构出现后，价格围绕颈线上下震荡，有时上去、有时下来，才叫以盘待跌（或以盘待涨）。如果价格跌破颈线后几天一直在颈线下方运行，就不能叫以盘待跌（E-61347），这叫"观后整理"，终究会往下走。

## 它解决什么问题
区分两种盘整，判断后续是否还会继续下跌。

## 如何识别
- 价格在颈线上下来回运行 → 以盘待跌（原文未单列证据）。
- 价格一直在颈线下方运行 → 不叫以盘待跌（E-61347）。

## 适用边界与失效
- 观后整理也可能发展成以盘待跌，在发展成之前要提个心（原文未单列证据）。
- "几天"是多少天：原文未明确。

## 与其他概念的关系
- 与 C-1996、C-1998（以盘代跌剧本）相关，出自不同课。

## 案例与证据
