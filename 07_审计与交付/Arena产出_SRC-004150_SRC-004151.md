# K-1923 第一公式的变量取新华富时A50，不取道指

- 判断A股时，第一公式的变量＝新华富时A50（E-7035）。
- 道指不是该公式变量（E-7035）。
- "第一公式"的具体内容、A50如何取值：原文未明确。

- 编辑者评注称"A50领先性依赖外资定价权假设"——为编辑者评注，不作规则依据。
