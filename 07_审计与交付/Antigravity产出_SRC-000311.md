```markdown
# K-32663 TRP红绿豆首发与初触入场法则
> 来源：SRC-000311（期货_期货投机分析20250708_从多到空趋势绿豆掌控全部（增强版））· 证据 E-71444
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在TRP辅助交易系统中，趋势入场的最佳时间窗口仅限于红绿豆指标刚发生颜色反转的第一时间，或反转后价格首次回测贴近红绿豆的触点，其后豆数累积越多则可靠性越低。

## 它解决什么问题
解决顺势交易者入场时机过于迟钝、在单边趋势已充分展开后追单导致频繁被短线反弹清洗（磨损）的难题，通过界定首发与初触两个黄金时间窗实现低成本入场（E-71443）。

## 如何识别
1. 观察盘面时，首要查看价格是否运行在红豆或绿豆关键位附近（E-71437）。
2. 指标刚变色（红变绿或绿变红）时相对可靠，其核心优势在于获取极佳的建仓成本价（E-71443、E-71445）。
3. 变色后价格出现回调并首次贴近接触红绿豆时最为可靠，其核心优势在于获取趋势确立后的高确定性（E-71443、E-71444、E-71445）。
4. 最优入场机会严格限定为“第一次变色”与“第一次接触”，其后随着红绿豆数量增加，再次贴近时可靠性急剧下降（E-71443、E-71444）。

## 适用边界与失效
1. 绿豆或红豆累积数量过多时（如单边行情已延伸很长），若价格再次大幅反弹靠近绿豆，严禁顺势追空，此时不可靠度显著增加（E-71443）。
2. 在无序横盘行情中，指标易出现“一会红一会绿”的频繁跳色，导致在刚变色阶段产生连续换向止损磨损（E-71443）。

## 与其他概念的关系
1. 与「N次三加」为对照关系：绿豆连续出现的次数与三加次数逻辑一致，次数越多可靠性越低，均强调只做拐头结束后的首次交易（E-71443）。
2. 为方法策略 `S-3013`（TRP趋势跟踪操作法）的基础入场与加仓过滤条件。
3. 与 `K-32664`（正乖离摸顶法则）为补充关系：正乖离摸顶针对均线死叉前的极值，本法则针对变色后的标准顺势起爆与回踩。

## 案例与证据
1. 螺纹钢案例中，明确指示最佳空点为变绿初次放空，随后反弹站上减半、跌回接回，再次接触绿豆处为二次加仓点（E-71446）。
2. 氧化铝转为红豆后首次回测贴近红豆，确认为高确定性做多与加仓买点（E-71444）。
```

```markdown
# K-32664 均线正乖离率逆势摸顶与死亡交叉长持法则
> 来源：SRC-000311（期货_期货投机分析20250708_从多到空趋势绿豆掌控全部（增强版））· 证据 E-71439
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在价格与中长期均线形成巨大正乖离率阶段，依托TRP绿豆信号提前逆势开空摸顶，待下跌顺畅演变为均线死亡交叉后无缝切换为顺势长持，从而全额捕获整段单边下跌利润。

## 它解决什么问题
解决传统均线顺势交易系统必须等待两条均线正式形成死亡交叉后才能开仓所导致的大幅滞后、成本过差与踏空前段大幅下跌行情的交易痛点（E-71439）。

## 如何识别
1. 当市场呈现巨大的正乖离率时，TRP系统提前出现绿豆信号，允许交易者高位逆势摸顶开空（E-71438）。
2. 乖离率大小的定性与定量判据：对比前期峰值高点的乖离数值H，当前数值大于前高H即定性为偏大；亦可借助BE指标（将参数调整为对应高多数值，如720）进行定量衡量（E-71440）。
3. 行情演变结构：前半段属于价格向均线回归的正乖离率修复行情，后半段中长期均线受压下行转为死亡交叉顺势行情（E-71439）。
4. 下跌过程中只要未触发绿豆变红的反转磨损，便保持空单底仓从头拿到尾（E-71438、E-71439）。

## 适用边界与失效
1. 当高多与低多两条均线均向下倾斜时，均线对价格构成全面压制且不提供任何支撑，此时逆势摸顶转顺势空单阻力最小（E-71449）。
2. 若高多低多均线距离过远且下方支撑强劲，或乖离修复中途价格反扑站上并转红，则摸顶判定失败，需依规止损离场（E-71442）。

## 与其他概念的关系
1. 与「SFP（摆动失败形态）」为互补替代关系：顶部若未出现SFP假突破信号，常规系统无法在高位入场，而TRP配合大正乖离率提供了无SFP时的摸顶建仓手段（E-71438）。
2. 与 `K-32663` 构成阶段衔接：摸顶建仓后，若经历绿豆持续下行并死叉，进入顺势持有阶段。
3. 是方法策略 `S-3013` 中激进左侧向右侧顺势转化的核心逻辑。

## 案例与证据
1. 沪铜主连案例：周五早盘高多仍在低多上方尚未死叉，因正乖离率巨大提前开空，一路下行贯穿至死叉，持仓至7月7日仍为绿豆，形成从头吃到饱的史诗级大空单（E-71438、E-71439、E-71447、E-71448）。
2. 菜油案例：在多头排列下因高多与低多双双向下倾斜压制，提前试空并一路持有至死叉大跌（E-71449）。
```

```markdown
# K-32665 TRP趋势持仓防卖飞与回撤磨损应对纪律
> 来源：SRC-000311（期货_期货投机分析20250708_从多到空趋势绿豆掌控全部（增强版））· 证据 E-71441
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在TRP单边趋势持仓中，将盘中最低价至绿豆均线之间的反弹回撤空间统一定义为持仓“手续费”，并通过收盘破位减半、跌回接回、彻底变色清空的动态规则对冲震荡磨损以防卖飞。

## 它解决什么问题
解决单边趋势行情中交易者因无法承受浮盈回撤而过早平仓（卖飞），以及面对盘中假反弹频繁进出被双向打脸的执行难题（E-71441）。

## 如何识别
1. 认知定位：做空持仓时，将价格从最低价反弹至绿豆之间的全部浮亏距离均视作必须支付的交易“手续费”，以格局抵御卖飞心理（E-71441）。
2. 减半动作：若交易者忍耐度不足或盘中出现LPA反向信号（如阳线拉起），允许主动减仓50%，但剩余半仓必须严格守住绿豆（E-71441）。
3. 破线与清空：当单根K线实体收盘站上绿豆时，强制减半仓；唯有当指标彻底翻红时，才将剩余半仓全部清空（E-71442）。
4. 接回全仓：当K线站上绿豆被动减半后，若下一根K线重新跌破绿豆下方，必须把减掉的半仓立即接回，继续以全仓状态跟踪单边行情（E-71442、E-71446）。

## 适用边界与失效
1. 专用于单边顺势大行情；在无趋势的窄幅横盘区间，价格反复穿梭红绿豆会导致连续的减半、清空与接回磨损（E-71442、E-71443）。
2. 必须具备严明的纪律执行力，严禁减半后在价格重新下行时不执行“接回”操作（E-71442）。

## 与其他概念的关系
1. 与「LPA出场信号」为对照关系：LPA出场灵敏但极易卖飞单边，本纪律以减半折中方式保留底仓享受单边红利（E-71441）。
2. 与 `K-32663` 形成闭环：初触加仓，破线减半，跌回接回，翻色离场。
3. 为方法策略 `S-3013` 的核心持仓与仓位管理规则。

## 案例与证据
1. 铜、铁矿石实盘案例：在大幅单边下跌中出现红绿豆反复测试，通过“站上减半、跌回接回”仅付出三五跳极小磨损，成功从头拿到尾（E-71442）。
2. 螺纹钢操作推演：变绿空、站上去减半、跌回来接回半仓保持全仓运行（E-71446）。
```

```markdown
# K-32666 日内开盘突破交易之波段止损锚定原则
> 来源：SRC-000311（期货_期货投机分析20250708_从多到空趋势绿豆掌控全部（增强版））· 证据 E-71450
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在期货日内开盘突破交易中，严禁以开盘首根K线极值作为止损位，必须等待盘中确立符合5K法则的波段高点或波段低点方可设损开单，无明确波段止损点时坚决不开单。

## 它解决什么问题
解决日内交易者开盘盲目以第1根K线高低点设止损导致被早盘宽幅杂波频繁扫损，以及在无技术防守依托时冲动抢跑开仓的风险失控问题（E-71450、E-71456）。

## 如何识别
1. 开盘首根K线（DK）仅用于界定日内多空方向倾向，因刚开盘不属于波段极值，绝对不能作为止损依托（E-71450）。
2. 开盘第1根K线后仅回调1根K线便创极值（即早盘第3根K线）的走势严禁直接入场，需等待行情充分走开（E-71455）。
3. 入场点必须与止损点绑定：只有当盘面震荡走出符合5K法则的波段高点（空单）或波段低点（多单）时，方可挂出触发条件单（E-71450、E-71456）。
4. 交易前置硬约束：若找不到波段极值点设立止损，则无论突破信号多强均不得开单（E-71456）。

## 适用边界与失效
1. 适用于期货高波动品种的日内回转交易（开盘法优化版）。
2. 当早盘行情剧烈拉扯形成异常宽阔的波段高低点时（如白银单笔止损达0.39%），若符合规则仍须执行，但单笔风险暴露会相应增大（E-71453）。

## 与其他概念的关系
1. 与原书「开盘八法」为修正批判关系：原书在第3根K线创新低/高即主张开单，讲述者明确优化剔除该规则，要求至少回调2根K线且具备波段防守位（E-71455）。
2. 为方法策略 `S-3014`（开盘回转交易策略）的强制风控前提。
3. 与 `K-32667`（双轨止盈）共同构成开盘突破策略的进出场架构。

## 案例与证据
1. 原油20250707日内多单：9:15虽创高转多，但因缺乏波段低点一直等待，直至10:31走出符合5K法则的波段低点后才开单，下午成功拉起止盈（E-71456）。
2. 沪锡20250707日内空单：开盘阴线创低后，未用开盘K线止损，而是锚定回调形成的波段高点挂损，下午顺利击中止盈（E-71450）。
```

```markdown
# K-32667 开盘回转交易之双轨止盈与盯盘分仓机制
> 来源：SRC-000311（期货_期货投机分析20250708_从多到空趋势绿豆掌控全部（增强版））· 证据 E-71451
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在日内突破交易中，单笔委托建立2手（或2的倍数），1手挂1:1.5固定盈亏比条件单自动止盈保底，另1手在有时间盯盘的前提下借助LPA或收盘站上5MA出场跟踪单边大波段以博取综合超额收益。

## 它解决什么问题
解决日内单边瀑布行情中单一挂固定盈亏比条件单严重卖飞（仅吃一半利润），与单一依赖均线/指标跟踪在反弹时回撤过大的两难选择问题（E-71451）。

## 如何识别
1. 基础盈亏比锚定：日内短线设定1:1.5固定盈亏比条件单，统计上行情打到1:1.5目标位后极易发生即时反弹，具有极高的点位兑现价值（E-71454）。
2. 分仓构建：下单时开仓2手或2的整数倍（E-71451）。
3. 轨道一（机械保底）：其中1手直接挂1:1.5固定条件单，自动止盈兑现基础利润（如单笔收益0.6%）（E-71451）。
4. 轨道二（盯盘跟踪）：在具备盯盘条件的前提下，另1手采用LPA信号或K线收盘站上5MA出场，跟随下午单边暴跌以获取大幅利润（如收益1.2%），使整笔交易综合收益达到折中高位（如0.8%）（E-71451）。
5. 极端条件约束：若交易者无暇盯盘，则全部头寸采用1:1.5固定条件单执行（E-71451）。

## 适用边界与失效
1. 实施双轨出场必须以有充裕时间连续盯盘为前提（E-71451）。
2. 当单边下跌行情遇到长实体突破大K线时，LPA出场与5MA出场的回撤绝对值会显著放大（E-71451）。

## 与其他概念的关系
1. 与「单一条件单止盈」及「单一LPA出场」为组合改良关系：吸收条件单的高兑现率与移动止盈的波段延展性（E-71451）。
2. 为方法策略 `S-3014`（开盘回转突破策略）的资金与出场分配管理机制。

## 案例与证据
1. 沪银20250707日内空单：下午13:30开盘跳水精准打中1:1.5条件单止盈（0.59%），随后价格立刻强劲拉起，验证1:1.5点位效应（E-71454）。
2. 沪锡20250707日内空单：下午暴跌行情中条件单止盈（0.66%）大幅卖飞，而LPA/5MA跟踪能吃到全部瀑布跌幅（E-71450、E-71451）。
```

```markdown
# S-3013 TRP红绿豆单边趋势跟踪与加减仓操作法
> 来源：SRC-000311（期货_期货投机分析20250708_从多到空趋势绿豆掌控全部（增强版））· 证据 E-71437
- 来源立场：课程讲述者采纳
- 底本层级：仅增强稿可见
- 性质：规则完整的策略
- 规则版本：TRP指标趋势辅助交易系统（2025年7月实盘版）
- 完整度分级：已给方向
- 效果证据：沪铜从正乖离率摸顶到死亡交叉持续盈利，持仓至7月7日仍为绿豆（E-71438、E-71439、E-71447）；焦煤、铁矿石均实现从头拿到尾的超级单边盈利（E-71442）。

## 目的与适用环境
适用于期货主力连续合约日线及大周期单边趋势行情。旨在通过TRP红绿豆形态捕捉大波段，解决必须等待均线死亡交叉才顺势开单的严重滞后问题，并利用规则化的减半与接回机制规避假反弹造成的卖飞。

## 条件与动作
| 条件或动作 | 时点与周期 | 证据ID | 限制或缺口 |
| :--- | :--- | :--- | :--- |
| 环境过滤 | 大周期/日线多周期穿透 | E-71449 | 高多与低多均线均向下倾斜形成压制，不提供支撑 |
| 形态或指标形成 | 信号初显时点 | E-71438, E-71440 | 正乖离率大于前高H或BE极值出现绿豆；或指标刚变色 |
| 确认 | 接触测试时点 | E-71443, E-71444 | 第一次变色求价格，变色后第一次贴近接触求确定性；豆多不追 |
| 入场 | 突破或回踩K线 | E-71437, E-71446 | 贴近绿豆开空，或贴近红豆开多 |
| 初始止损 | 开仓同时 | E-71442, E-71446 | 原文未给出固定跳数，以红绿豆价格或反向变色为防守依据 |
| 仓位与资金 | 建仓期 | E-71446 | 常规基础仓位；原文未明确固定保证金比例 |
| 持仓与跟踪 | 单边运行全程 | E-71439, E-71441 | 将现价至绿豆距离视作手续费，不破绿豆一直持有至死叉之后 |
| 加减仓 | 盘中破位与接回 | E-71441, E-71442, E-71446 | 出LPA信号或K线站上绿豆减半仓；下根K线重新跌破绿豆下方接回全仓；二次触豆加仓 |
| 止盈与退出 | 反转确立时点 | E-71442, E-71446 | 绿豆翻红清空多单/空单全部底仓 |
| 失效与放弃 | 震荡周期 | E-71443 | 刚变色后反复红绿交替产生连续磨损；红绿豆数量累积过多放弃追单 |

## 规则之间怎样衔接
1. 激进摸顶与顺势衔接：在正乖离极大处通过TRP绿豆逆势开空，价格下行修复乖离，均线转入死亡交叉后顺势无缝长持（E-71439）。
2. 防卖飞闭环：持仓遇反弹破线收盘减半 -> 次根K线重归线下接回恢复全仓 -> 彻底翻色清空离场（E-71442）。
```
