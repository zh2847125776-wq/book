# 补充 K-0164 读书领读股票魔法师二止损距离合理设定过近易被扫过深不可接受
> 来源：SRC-003334 · 证据 E-52360
> 来源立场：书中作者观点（马克·米勒维尼止损心法）
> 底本层级：仅增强稿可见

一句话定义：止损位必须合理设定，过近极易被盘中杂波扫出导致卖飞，过深则产生10%以上不可承受的巨亏。

## 如何识别
- 极窄止损陷阱：虽然理论上止损越近越好，但若设置过窄，股价极易被正常的日内波动或震荡洗盘打穿止损线，被迫卖出后又因犹豫未能接回，最终错失单边大主升（E-52360）。
- 过深止损危险：若止损放得过宽，一旦趋势破位将承受两位数百分比的惨痛本金折损，违背短线投机的生存底线；合理的止损应当兼顾波动滤网与风控极限（E-52360）。

## 适用边界与失效
此原则指导买入前的止损参数配置；若遇到流动性极差的极端跳空缺口，仍需以硬止损纪律为最高准则。
```

# 补充 K-0459 读书领读股票魔法师二突破中枢点深蹲后反转修复等待机制
> 来源：SRC-003334 · 证据 E-52361
> 来源立场：书中作者观点（马克·米勒维尼深蹲与反转修复）
> 底本层级：仅增强稿可见

一句话定义：股票突破中枢点后回跌至前期筑底范围内（深蹲），只要未触及止损线，需耐心等待一两天至数周观察其反转修复。

## 如何识别
- 深蹲现象界定：股价向上突破关键中枢点后，并未立即拉升，而是在冲高后回撤至前期底部震荡区间内部，形成看似失败的“深蹲”（E-52361）。
- 耐心等待纪律：遇到深蹲切忌惊慌失措跳下甲板盲目平仓，只要未触发初始硬止损，应当给予标的至少一两天甚至数周的缓冲期，观察其能否迅速攻克熄火阴线完成反转修复（E-52361）。

## 适用边界与失效
等待反转修复的绝对前提是“未触及初始止损线”；若回撤跌幅直接击穿既定止损位，必须立即斩仓出局，严禁死扛幻想。
```

# 补充 K-0427 读书领读股票魔法师二未触发止损线容忍短期正常波动浮亏

## 如何识别
- 浮亏认知：股票买入后极少能够瞬间腾飞直达盈利目标，中途回踩产生微小浮亏属于市场的自然生理呼吸，浮亏本身不构成失败判定（E-52362）。
- 空间与时间宽容：给股票预留一至两周的观察时间和充分的波动空间；只要止损线完好无损，不要被盘中短暂浮亏吓破胆，耐心等待其逆转回升（E-52362）。

## 适用边界与失效
适用于右侧突破顺势单的持仓跟踪；若盘面伴随巨量跌破核心均线等重大系统性警报，需主动启动降仓或提前离场。
```

# K-25344 股票魔法师黑兰花隐喻警惕难以驯服的高波动野马股优先选温顺阿尔法
> 来源：SRC-003334 · 证据 E-52363
> 来源立场：书中作者观点（马克·米勒维尼选股与风险哲学）
> 底本层级：仅增强稿可见

一句话定义：将高波动妖股隐喻为难以驯服的野马“黑兰花”，警惕其虽有爆发力但极易将骑手摔下马背，应优先选择平稳上行的温顺阿尔法马。

## 它解决什么问题
解决交易者贪图极端振幅、盲目追逐上蹿下跳的超高波动妖股，导致在频繁剧烈洗盘中屡遭洗劫、身心俱疲的认知偏差。

## 如何识别
- 黑兰花特征：波动剧烈、日内振幅巨大、节奏难以捉摸，虽然可能从A点大幅飙升到B点，但途中频繁甩背，交易者极大概率在途中被震出止损、遭受重创（E-52363）。
- 阿尔法马优选：风险优先原则要求主动放弃黑兰花式的极端博弈，优先寻找走势平稳规整、均线守候严密、能带领账户行稳致远的温顺优良标的（E-52363）。

## 适用边界与失效
属于选股层面的风险过滤准则；在牛市主升浪的极短脉冲阶段，若具备极高超短纪律方可小仓参与高弹性品种，常规波段交易必须规避野马。

## 与其他概念的关系
母库 K-0427 确立风险优先原则；本卡通过米勒维尼童年驯马童话隐喻，确立规避不可控高波动、优选稳健阿尔法的标的过滤规范。
```
