# 补充 K-30086 20220825创业板第7个红柱后死叉精准闭合36时间窗口
> 来源：SRC-001601 · 证据 E-52280

> 底本层级：仅增强稿可见

一句话定义：创业板日线红柱在第7个周期收尾、第8个周期转入死亡交叉，28加7等于35个周期、第36天精准闭合调整时间窗口。

## 如何识别
- 周期推演验证：此前28个周期的飞镖调整，在经历7个红柱周期后于第8周期形成死叉并翻出绿柱，28+7=35个周期，第36天精准对应标准终极窗口（E-52280）。
- 性质界定：前期由最高点回落至60日线的下行仅属于正乖离率修复与行情酝酿期；酝酿期以均线死叉向下破位告终，确立跌势正式开启（E-52280）。

## 适用边界与失效
时间窗口是对波段变盘节点的节奏检验，最终方向与交易决策必须依赖客观价格破位与均线系统确认。

# K-25312 均线系统与红绿豆指标不可构成独立交易架构及其排列依赖
> 来源：SRC-001601 · 证据 E-52281
> 来源立场：课程讲述者采纳（指标定位与依赖大环境原则）
> 底本层级：仅增强稿可见

一句话定义：红绿豆指标属于次要辅助工具，不可与均线交叉并列构成独立买卖架构；其信号有效性完全依赖于大均线多空排列大环境。

## 它解决什么问题
解决盲目迷信单一特色指标、试图将红绿豆作为确定性买卖依据的误区，阐明均线主导与指标从属关系。

## 如何识别
- 架构本质：交易系统不存在专门寻找“红豆阴线”或“绿豆阳线”开仓的独立架构；该指标仅作为辅助参考，绝非开仓主依据（E-52281）。
- 排列决定论：整体均线多头排列且20日线向上时，跌破下翻回测通常会出现绿豆阳线；而在空头排列且20日线向下时，绿豆阳线几乎不会出现，直接破位下杀（E-52281）。
- 多头排列下的红豆阴线常被直接拉起，而空头排列下的红豆阴线则往往继续探底，信号表现完全由均线大趋势决定（E-52281）。

## 适用边界与失效
在均线趋势不明的无序震荡期可作微观节奏参考；但在关键趋势破位或均线死叉节点，严禁等待或期待红绿豆反转信号。

## 与其他概念的关系
母库 K-0447 确立形态服从均线；本卡确立红绿豆指标从属于均线多空排列、不可独立建构交易规则的技术定位。
```

# 补充 K-31179 20220825标志阴线胯下运行属于高危期吃掉前不布置仓位
> 来源：SRC-001601 · 证据 E-52282
> 来源立场：课程讲述者采纳（标志K线定方向与仓位冷冻纪律）
> 底本层级：仅增强稿可见

一句话定义：大阴线确立向下突破方向即成为标志阴线，在其下沿（胯下）运行期间属于持续风险期，在彻底收复前严禁布置任何仓位。

## 如何识别
- 标志阴线定性：一阴穿多线或放量击穿关键均线的大阴线决定了市场的主导方向，即确立跌势开始（E-52282）。
- 风险期判定：只要价格始终在该标志阴线的实体及下沿下方（胯下）震荡运行，说明空头绝对掌控局势，行情并未脱离风险期（E-52282）。
- 操作风控：在没有完全放量“吃掉”并收复该标志阴线之前，交易者严禁盲目开立多头仓位，必须保持空仓观望（E-52282）。

## 适用边界与失效
此原则针对波段操作的趋势安全准入门槛；激进短线极窄止损试错若遇此形态亦需严格大幅压缩仓位。
```

# 补充 K-3747 20220825四个关键价格均低于前日构成典型空方信号
> 来源：SRC-001601 · 证据 E-52283
> 来源立场：课程讲述者采纳（K线四价强弱判据）
> 底本层级：仅增强稿可见

一句话定义：当日开盘价、最高价、收盘价和最低价均全面低于前一交易日，构成明确的空方主导信号与弱势延续。

## 如何识别
- 四价全低对比：当日K线的开盘价、最高价、收盘价、最低价无一例外全部低于前一日对应价格，表明多头全天毫无反击能力（E-52283）。
- 强弱转换界碑：若要行情转强或维持横盘抵抗，次日至少需要产生高于前日的价格元素；若持续四价走低，则反弹随时夭折并加速下挫（E-52283）。

## 适用边界与失效
日线四价对比适用于连续单边弱势行情的日间跟踪；若盘中出现放量低开高走的包容大阳线，需以收盘最终四价综合评估。
```

# 补充 K-0028 20250417指数站上十日线三天大幅降低倒鸭嘴连跌概率

## 如何识别

## 适用边界与失效
说明短期空头单边加速风险解除，但不等同于多头主升确立；若上方仍有60日线压制，仍属震荡反弹范畴。

# 补充 K-0217 20250417横盘框框中间不交易而两边上下轨边缘高抛低吸打漏反手
> 来源：SRC-000889 · 证据 E-52291
> 来源立场：课程讲述者采纳（区间操作与边界交易策略）
> 底本层级：仅增强稿可见

一句话定义：在明确的横盘区间内禁止在框框中间无序开仓，严格在上线做空站上止损、在下线做多跌破止损并立刻反手。

## 如何识别
- 框框中间禁止区：在多日横盘整理区间内部，价格处于中轴附近时多空混沌且极易磨损，严格不建议进行任何交易（E-52291）。
- 边界操作规范：当价格触及区间上线时开立空单，站上上线即刻止损；当价格回落至区间下线时开立多单，击穿下线止损出局并可顺势反手追空（E-52291）。

## 适用边界与失效
此法专用于横盘箱体震荡的边界博弈；一旦单边行情伴随实体巨量脱离框框，必须立刻停止区间思维并转入顺势跟踪。
```

# 补充 K-0161 20250417同系列高相关品种按技术形态规整度与止损空间择优
> 来源：SRC-000889 · 证据 E-52292
> 来源立场：课程讲述者采纳（同板块品种优选原则）
> 底本层级：仅增强稿可见

一句话定义：同系列、同题材的高相关品种（如螺纹与热卷），必须对比技术指标规整度与止损空间，谁守均线准、止损低就优先做谁。

## 如何识别
- 标的类比：同板块品种如同同质大型企业（如螺纹、热卷、铁矿），趋势方向大致趋同但微观走势差异巨大（E-52292）。
- 择优标准：对比各品种均线守候精度与回撤止损点位；若A品种守20日线极准、止损空间极小且形态规整，而B品种走势混乱毛刺多，则坚决选A放弃B（E-52292）。

## 适用边界与失效
适用于同板块多标的横向比价与初选；若不同品种由于基本面突发利好出现严重分化，则需重新审视个别品种的独立驱动。
```

# 补充 K-0490 20250417放过最低价到通道平台距离以防卖飞且小磨损换大单边
> 来源：SRC-000889 · 证据 E-52293
> 来源立场：课程讲述者采纳（APL持仓心法与磨损交换比）
> 底本层级：仅增强稿可见

一句话定义：顺势跟踪单边行情必须主动放弃最低价到中轨平台的利润回撤距离，坚守“站上出、漏了接”，以局部小磨损换取完整大单边。

## 如何识别
- 利润回撤放过原则：在空头单边中，行情极值低点距离平仓中轨往往存在较远空间，交易者必须主动“放过”这段空间，不可因贪恋极值而频繁提前止盈导致卖飞（E-52293）。
- 磨损与大单边交换比：执行“站上通道平仓、再次跌漏坚决接回”时可能产生微小的磨损，但与捕捉到的数百点超级大单边相比，此类磨损微不足道，必须坚决执行（E-52293）。

## 适用边界与失效
适用于成熟趋势跟踪系统中的波段防护；在无趋势的窄幅牛皮市中频繁出接会面临连续磨损，应结合大周期位置使用。
```
