# 诊断：卡片空心化（Shard3 全废 / Claude 片部分污染）

日期：2026-10-13 ｜ 签发：lead ｜ 触发：Shard3（gd6/gpt-6.1-sol）47 组产出抽检

---

## 一句话结论

`严格官方入库` 的 guard 是**正确性闸门**（证据数==验证通过数 / 新卡数==回复卡数 / 逐字回源），
**不是质量闸门**。它抓不到「格式全对、内容全是套话」的卡片。
Shard3 因此交出 47 组空心产出，且**全部打印 `guard: PASS`**。

## 三、根因：草稿阶段把「抽取规矩」当成卡片正文抄了进去

直接证据 —— `分片工作区/Shard3/out/07_审计与交付/草稿_SRC-000129_SRC-000038.py`
（草稿是确定性 Python，卡片正文以字符串字面量硬编码）：

```python
'原稿仅7行（152字符），无语音与OCR正文，所有具体规则严格留缺。{E0}',
'关联S0与C0；不跨源混用。{E0}',                       # ←「与其他概念的关系」整节
'见S0与C0；20秒短视频原稿留白核查观察。{E0}',          # ←「案例与证据」整节
'仅记录≤300字完整原文字面的均线是否站稳有均量衡量、无法预知一次突破的真假及箱体突破伴随boll
 发出相应信号，不采信Vision推断，不补造交易流水。{E1}{E2}{E3}',   # ←「它解决什么问题」整节
```

五个具体机制：

1. **规矩回显**：`prompt` 里的铁律（「仅记录≤300字完整原文字面」「不采信Vision推断」「禁截断铁律」）
   被复制进「它解决什么问题」「适用边界与失效」等**内容字段**。规矩是**约束写什么**的，不是**拿来抄**的。
2. **关系段占位**：`关联S0与C0；不跨源混用` —— 占位符 + 一句规矩，没有任何实际概念关系。
3. **案例段占位**：`见S0与C0；…` —— 只做交叉引用，没有案例内容。
4. **证据均匀化**：`{E0}{E1}` 占位被整段替换成同一组证据号，于是**每一节末尾挂着完全相同的 `[E-70880][E-70881]`**，
   而不是逐节取证（对照 Antigravity：各节证据号不同，案例段还引了 E-69414）。
5. **外观**：来源头 `（第课 股票_…）` 课号为空（`第%s课` 的 `%s` 没填）。

## 五、为什么 guard 拦不住

`严格官方入库.py` 的判定项：证据总数 == 验证通过数、未通过 == "无"、新卡数 == 回复卡数、证据入索引数正确。
这四项**全部是关于「引用是否成立」的**，没有一项检查**卡片正文是否承载了知识**。

Shard3 的 47 组产出：证据逐字回源 ✓、卡数对得上 ✓、证据号在号段内 ✓
—— 于是 `guard: PASS`。**闸门开在正确的维度，只是这个维度不覆盖空心化。**

## 六、修复方案

### 6.1 已落地：新增质检闸门

`工具/质检_卡片充实度.py`

```powershell
python -X utf8 工具/质检_卡片充实度.py --dir <产出目录>
python -X utf8 工具/质检_卡片充实度.py <回复文件> [更多文件...]
```

判级：

| 级别 | 触发条件 |
|---|---|
| **✗ 不通过** | 抽取规矩被抄进正文 / 「与其他概念的关系」是空占位 / 「案例与证据」无实际内容 |
| △ 告警 | 来源头课号为空（外观，不阻断）/ 同一组证据铺满 ≥3 个节（疑似未逐节取证） |
| ✓ 通过 | 以上皆无 |

退出码 0=无实质问题，1=有文件实质不通过。

**自校验（用已知答案的四组反压）**：

| 样本 | 结果 | 是否符合预期 |
|---|---|---|
| Shard3 47 组产出 + 53 份回复 | **102/102 ✗** | ✅ 全部抓出 |
| Claude 片全量 2,335 份 | **188 ✗**（8%） | ✅ 与人工抽检一致 |
| Codex 片最近 60 份 | 0 ✗ | ✅ 不误报 |
| Antigravity 批362 10 份 | 0 ✗ | ✅ 不误报 |
| 主库最近 80 张卡 | 0 ✗（1 条告警） | ✅ 不误报 |

> 注：`（第课 ）` 刻意降级为**告警**而非不通过 —— Claude 片 100% 命中该外观缺陷但内容合格，
> 若判死会把 112 批已完成的合格产出全部误杀。

### 6.2 草稿指令要加的三条硬规矩

1. **规矩是约束，不是素材**：`prompt` 里的抽取铁律**一个字都不许出现在卡片字段里**。
   「它解决什么问题」写这条知识**解决什么交易问题**，不是写「仅记录≤300字…」。
2. **禁止占位符**：`关联Sx与Cx；不跨源混用` / `见Sx与Cx` 这类句式一律视为未完成。
   关系段必须写出**实际的概念关系**（对照、前提、互斥、补充）；案例段必须有**具体标的、时间、数据**。
3. **逐节取证**：不同小节挂各自支撑的证据号。若一整张卡的每节都挂同一组证据号，说明没有真正逐节回源。
4. （配套）修 `第%s课` 的空课号填充。

### 6.3 流程上必须补的一步

**合并前质检**。在 `工具/分片_合并.py` 之前加一道：
先跑 `质检_卡片充实度.py --dir 分片工作区/<片>/out/07_审计与交付`，有不通过就先重做，再合并。
否则空心卡会直接进主库，而主库的 guard 同样抓不到。
