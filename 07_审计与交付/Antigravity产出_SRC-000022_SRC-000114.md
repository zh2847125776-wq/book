# K-32303 均线由发散向下转为横向收敛粘合的变盘蓄势特征
> 来源：SRC-000022（P2_rb实测与细节掌握2（增强版））· 证据 E-69589
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：标的在经历大幅下跌或急跌回调后，均线系统由前期的发散下行逐步减速走平并收敛粘合，反映多空力量暂时达到动态平衡、变盘蓄势即将选择方向的临界技术特征。

## 它解决什么问题
解决交易者在单边下跌行情后无法客观判断跌势何时放缓企稳，容易在均线尚未收敛时盲目逆势左侧猜底被套，或在震荡收敛变盘前夕因缺乏耐性过早放弃观察的择时难题（E-69590）。

## 如何识别
1. 前期经历大幅急跌或快速回调，价格跌势放缓并进入低位横盘震荡整理构筑底部雏形（E-69590）。
2. 均线系统由之前的发散向下转为横向收敛粘合，短期均线与中期均线相互纠缠（E-69589, E-69591）。
3. 短期均线（如MA5）在低位走平并开始出现向上拐头迹象，价格站在短期均线附近（E-69589）。
4. 副图RSI线在50中轴附近呈现粘合向上态势，动能逐步积聚（E-69592）。

## 适用边界与失效
均线收敛粘合仅表明多空动能达到暂时均衡与变盘前夕，不能单凭粘合本身盲目预判必定向上突破；若变盘时价格跌破盘整平台下轨且均线重新向下发散，则企稳变盘做多逻辑失效（E-69591, E-69592）。

## 与其他概念的关系
- 与「底部反转短周期均线金叉修复与量价配合波段操作法（S-2825）」是形态前置与确认触发关系：均线由发散向下转为横向粘合是底部反转的前置形态准备，均线金叉上穿则是多头修复的确认信号（E-69589, E-69591）。
- 与「支撑买入与压力卖出分级标记体系（K-32304）」是形态背景与关键点位执行关系：在均线粘合震荡蓄势过程中，以标记体系中的关键支撑与阻力位作为高抛低吸和突破防守的参考（E-69591, E-69593）。

## 案例与证据
迈克生物（300463）日K线实测演示中，前期大幅下跌后进入低位横盘，MA5、MA10、MA20等均线横向粘合纠缠，短期均线走平微翘，价格处于均线附近蓄势选择方向（E-69589, E-69590, E-69592）。
```

# K-32304 支撑买入与压力卖出分级标记体系
> 来源：SRC-000022（P2_rb实测与细节掌握2（增强版））· 证据 E-69593
> 来源立场：课程讲述者采纳
> 底本层级：仅增强稿可见

一句话定义：在实盘分析软件中通过价格轴左侧逐级标注“数字+b”（买盘支撑）与“数字+s”（卖盘阻力）标记，用于辅助识别行情关键技术分水岭与波段操作点位的静态价格标定体系。

## 它解决什么问题
解决交易者在波段交易与趋势跟踪过程中缺乏连续、客观的阻力与支撑价位坐标，导致开平仓决策主观随意、无法精准执行“支撑位买入、压力位卖出”纪律的执行难题（E-69594, E-69596）。

## 如何识别
1. 软件界面主图左侧沿价格轴垂直排列一系列预设的历史关键点位（E-69593, E-69595）。
2. 点位以“数字+b”（如 22.78b、24.24b、28.11b、40.20b）标识支撑买入参考位（b=bid/buy）（E-69593, E-69594）。
3. 点位以“数字+s”（如 22.41s、28.43s、26.35s、36.68s、38.68s）标识阻力卖出参考位（s=ask/sell）（E-69593, E-69594）。

## 适用边界与失效
标记点位属于静态价格坐标，必须结合当前K线形态、均线排列趋势及盘口承接综合研判；当价格跌破最低支撑位或以放量大阳线有效贯穿压力位时，原点位的阻力/支撑性质发生转化或失效（E-69594, E-69595）。

## 与其他概念的关系
- 与「均线由发散向下转为横向收敛粘合的变盘蓄势特征（K-32303）」是静态空间与动态形态的配合关系：在均线收敛纠缠阶段，以左侧b/s点位界定震荡区间的箱体上下轨（E-69593, E-69595）。
- 与「底部反转短周期均线金叉修复与量价配合波段操作法（S-2825）」是点位执行与规则触发关系：在底部均线金叉确认趋势转强后，依托b点作为回踩买点参考，依托s点作为压力止盈参考（E-69594, E-69596）。

## 案例与证据
迈克生物日K线实测演示中，主图左侧列出密集技术价位标记：22.78b、22.41s、24.24b、28.11b、26.35s、28.95b、36.68s、40.20b、38.68s、37.33b、36.62s、37.55，展示支撑位买入、压力位卖出的波段操作思路（E-69593, E-69594, E-69595, E-69596）。
```
